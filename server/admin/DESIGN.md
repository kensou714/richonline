# RichOnline 原生管理器界面约定

## 0. Research Log
参考 `protocol-analysis/richonline-rebuild/architecture/REFERENCE.md` 中已核验的 openNanaimo 管理流程：服务与游戏分离、只读账号表格加明确编辑、真实日志与备份结果。采用 Windows WinForms 原生控件，不复制上游代码或像素。frontend 技能中的 React、浏览器 Lighthouse、mobile viewport 与 Imagen 网页概念流程不适用于此原生桌面界面；视觉验收以实际 Windows 窗口为准。

## 1. 方向与用户
中文桌面运维工具。管理员先确认实例与游戏可用状态，再查看日志、账号和配置。管理服务已启动不能暗示游戏已可玩。

## 2. 字体与颜色
Microsoft YaHei UI 10pt；标题 18pt bold；日志 Consolas 9pt。使用 Windows 系统窗口、文字、边框、禁用和焦点颜色，尊重高对比模式。状态额外以完整文字呈现。

## 3. 空间与布局
基础间距 8，页面内边距 16，栏间距 12。默认窗口 1120×780，最小 900×640，DPI 自动缩放。固定顶部标题与状态，五个原生 TabPage：服务、账号、设置、日志、备份。正文各自负责滚动；长路径和错误可复制。

## 4. 信息层级
先显示服务管理状态、PID、客户端版本、大厅/HTTP/黑名单/游戏端口监听状态与游戏流程状态，再显示所选路径和动作。gameListenerReady仅表示端口监听，gameReady单独决定游戏流程就绪文案；两者均不代表已通过原生客户端验证。日志按时间保留最多 2000 行，筛选不影响接收；每200ms批次最多消费500条，后台读取不占用UI同步上下文。错误同时显示 stable code 和诊断文本。

## 5. 原语与状态
Ui.Button：AutoSize、键盘可达、原生 focus/default/disabled 状态；Ui.Row：自动高度横排工具栏；Ui.Field：左侧说明+右侧可伸缩输入；Ui.Page：统一内边距；DataGridView：只读、整行单选、列标题清晰；TextBox：配置多行、账号原因单行；Status label：未启动、启动中、管理服务已就绪、停止中、失败。

## 6. 交互
服务页在“启动客户端”旁提供“结束客户端进程”，不依赖管理服务在线。异步核实选定RnClient.exe完整路径，先正常关闭并等待3秒，再仅强制结束该进程（不结束进程树），等待最多5秒。服务PID/服务路径和管理员自身被排除；失败、无法核实路径、未运行均有明确状态及日志。不会仅按同名批量结束不同路径客户端。
网络操作异步；操作中禁用同组按钮；失败保留输入。客户端版本明确选择Big5/GBK，默认Richonline；不从路径猜测编码。无profile标记迁移库采用选中编码必须用户显式勾选，默认不选，服务启动成功后清除勾选；仅登记而不转换/重置密码。保存账号必须原因且带加载时快照；配置带revision，冲突要求重新读取。密码只用于创建请求且提交后清空。关闭GUI先停止自己启动的服务，超时仅终止持有的进程。

## 7. 可访问性与动效
所有动作中文标签；字段有AccessibleName；Tab导航；无装饰动画。状态不只依靠颜色。原生DPI字体缩放及可伸缩布局，禁止绝对坐标放置主要表单。

## 8. 验收与限制
真实 C++ 后端联调通过前不宣称功能可用。各页运行截图、窗口缩放及空/错误/运行状态需留证；管道自测不能替代视觉验收。
