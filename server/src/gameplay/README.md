# 新版共享游戏层

`boss_session.cpp` 接收已经选择的地图包，读取该包的阶段资源并装配会话。它不猜地图名，不把普通地图的事件索引、价格、建筑上限复制到其它地图。

文件职责：

- `boss_turns.cpp`：当前双角色回合状态、封包分发、等待/超时、迟到请求、行动顺序。
- `route.cpp`：EMP 道路、方向和成对传送，支持传送禁用条件的参数；不生成地图专属奖励。
- `junction.cpp`：最终方向决策 `0034→4035`、合法邻接和取消/超时。
- `landing.cpp`：已确认的共享落点行为和权威点券状态。
- `cards.cpp`、`shop.cpp`：已有道具库存、购买/售卖/退出；当前卡片支持仍不完整。
- `property.cpp`、`construction.cpp`：按实际地图地产价格和建筑配置处理购买、建造、升级。

`../maps/` 保存具体地图配置；`../resources/` 保存共用资源解码和边界校验；现有 `richonline_*_wire.cpp` 负责与地图无关的字节协议。大厅、网络封装、账号 SQLite 与管理服务继续由各自模块负责。

新增地图时注册独立包，选择自己的资源和策略。地图的专属事件及 BOSS 行为应写在该包目录，并调用共享层的类型化操作；共享封包格式和库存/资金事务不可复制。当前包仅完成资源、事件配置和运行入口的分离，特殊攻击与全部事件仍需按 coverage/GOAL.md 逐项实现。

原有三参数地产构造器及全局卡片配置属于兼容入口。真实会话已使用地图包与四参数地图构造器。保留旧入口用于现有配置及回归，不作为未知地图回退。
