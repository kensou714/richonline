# RichOnline 官网设计契约

## 1. 来源与方向
继承 item-catalog 的原版图片、八类资料表和16px中文正文。2026-10-12通过浏览器访问原版大宇官网 http://richol.softstar.com.tw/gameinfo/index-gameinfo-3.aspx ，确认玩法、股票、房地产、操作、会员与奇迹栏目，以及深红外框、金色内衬、白色正文和插画式栏目标题。旧版大陆域名 `rich.9you.com` 当前不能解析，仅取其历史公开报道中的官网信息，不臆造页面细节。本站按“玩法模式 → 系统说明 → 资源图鉴 → 玩家服务”的路径重组页面，不复制失效Flash区或历史活动。首页、指南、资料、账号服务共用一个index.html外壳、导航与页脚，资料数据按路由延迟加载。

## 2. 用户任务
新玩家从首页认识模式，接着查看系统说明、地图与卡片，注册后回到游戏；老玩家从游戏跳转后领取代币或修改密码；查资料的玩家可直接进入图鉴。导航顺序：首页、玩法指南、资源图鉴、注册账号、修改密码、领取代币。指南保留旧站资料的历史属性提示，不把旧版规则直接标作当前服务器承诺。

## 3. Tokens
颜色：外框 red-rail #8b2030、深红 red-dark #64182c、正文纸面 background #fffdf5、白色 paper #fff、浅纸 panel #fbf6e8、边界 border #e9dcc8、文字 text #292022、次要 muted #655d58、强调 accent #982627、选中 selected #fff0ba、金色 gold #f4bf31、浅金 gold-light #ffe08a、首屏 hero-start #fff3c2、行悬停 row-hover #fff8df、错误 danger #9b2525。字体 Microsoft YaHei / PingFang SC / system-ui；正文16px、辅助14px、三级20px、二级28px、主标题48px（手机32px）；行高1.7。间距4/8/12/16/24/32/48/64px。页面最大1120px，表单最大560px，圆角4px、表单容器8px；纸张与金色边框制造层级，首页棋盘画面使用原版资源与简单投影。按钮及输入最小44px。

关卡横幅16670.png的原始比例为3:1，按原比例完整展示；角色图按78px方框contain展示。图鉴表格的既有预览框保持原样。

## 4. 布局
文档负责纵向滚动；导航在窄屏单独横向滚动；资料表沿用自己的横向滚动容器。主栏 max-width + 居中内边距；首页首屏左右分栏，下方“玩法／资料”主栏与玩家服务侧栏形成不等宽结构；指南按独立章节阅读，股票与奇迹章节是文字＋说明面板。760px以下叠放，正文和表单 min-width:0，长文本换行，不通过隐藏溢出来掩盖布局错误。

## 5. 可复用原语及状态
SiteHeader/SiteFooter：各服务页共享；导航含 aria-current。ServiceLink：标题、说明和可辨识链接。FormField：可见 label、辅助文字、必填提示、autocomplete、focus-visible。SubmitButton：默认、hover、disabled/处理中；禁止重复提交。Notice：普通、成功、错误，使用文字及 role=status，不单靠颜色。RoleSelect：查询成功后展示所属角色及余额，账号或密码改变即失效。资料页沿用 table/columns/pagination 原语。
GuideToc：指南章节锚点、浏览器默认锚定定位和可见焦点；ModeRow：序号、标题、明确链接，hover/active/focus有状态；SystemLinks：三个系统入口。HomeRail：账号服务和领取规则的单独侧栏。GuideSection：标题、正文、事实面板，保持长文段最大宽度。CatalogNav：八分类、选中态和横向滚动。页面没有自动播放音视频或背景动效；按钮反馈180ms，减少动态效果偏好下禁用位移和过渡。

## 6. 内容与安全交互
页面明确每次领取10000代币、余额必须低于10000、无需付费与审核。注册使用游戏可兼容的账号/密码字符；修改密码必须验证原密码。成功后清除密码输入，不存浏览器存储。领取网络不确定时保留操作编号用于幂等重试；不得把断网报成明确未发放。账号服务强制 HTTPS，旧 HTTP 入口仅跳转。

## 7. 可访问性与性能
语义 landmark、跳到正文、输入标签和可见焦点；反馈 aria-live；触屏目标至少44px；无自动动画、无外部字体、无广告或跟踪代码。首页不加载资料站大JSON和音频，资料页保留分页及 preload=none。

## 8. 验证边界
用户仅允许静态检查和编译，不新增或运行测试、不启动本机服务。故本轮不执行 skill 的组件浏览器展示、Lighthouse 和视觉 QA，不声称这些门禁通过；后续实机反馈用于继续修正。非 React 项目不安装 React 开发依赖。

## 9. 官网资料统一改版
统一SiteHeader/SiteFooter和页面1120px宽度。首页的三条ModeRow引向同一玩法指南，不再用三个等权通用卡片模拟模式深度；暖色首屏、原版地图和角色图提供游戏识别。指南分“模式、股票、房地产、奇迹”四章，再把人引到八分类资源图鉴。CatalogNav保留八分类横向滚动，Table/Pagination沿用资料表列宽、图片与音频尺寸，不另建站点导航或iframe。分类、分页滚动属于正文，账号页保持原验证和反馈状态。采用一套实际存在的导航，未开放的下载、活动、客服入口不造假。
浏览器只用于用户要求的外部历史网站研究；按既有约束未运行本项目视觉测试、Lighthouse或账号测试，保留为验收边界。
