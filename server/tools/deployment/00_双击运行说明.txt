/*
 * 部署连接初始化与错误采集
 * 在目标 Windows 服务器运行，安装目录 D:\richonline。
 */

// 操作
// 将整个压缩包解压到服务器 D:\richonline\deploy-bootstrap。
// 双击 Start-DeployChannel.cmd；如弹出管理员授权窗口，点击“是”。
// 不需要手工输入 PowerShell 命令；执行策略仅对这次子进程临时放行。
// 运行窗口会保留，结束后生成同目录 deploy-diagnostics.txt。
// 将该文件发回维护会话，或复制回本机供维护会话读取。

// 范围
// 使用随包公钥建立 SSH 登录权限，私钥不包含在此包内。
// 初始化脚本配置 SSH 服务和 Windows 入站防火墙，不修改游戏进程或数据库。
// 采集 Windows 版本、sshd 服务信息、相关错误日志、监听状态、配置和文件权限。
// 不采集密码、私钥内容或账号数据库，不自动上传报告。
// 如 TCP 22 仍无法从外部连接，还需要核对云平台安全组或端口映射。
// 自动部署通道以远程密钥登录、文件传输和执行验证均通过为准。

// 已安装 SSH 但服务启动失败时
// 解压修复包，双击 Repair-DeployChannel.cmd，管理员授权窗口点击“是”。
// 修复 ssh_host_*_key 主机私钥的所有者与访问权限，再尝试启动已有 sshd 服务。
// 所有者设为 SYSTEM，仅 SYSTEM 和 Administrators 保留访问权限。
// 旧权限描述符会备份，修复前后比较文件哈希，主机密钥内容保持不变。
// 修复模式不重新安装 SSH，不改 sshd_config，不改游戏配置或数据库。
// 结果及仍有的服务错误保存到同目录 deploy-diagnostics.txt。
