# 股票资源、地图槽映射与首次行情准备

## 新补的只读客户端证据

`stock-map-initialization.json` 保存本轮五个模式谓词、EMP股票表读取窗口和初始化调用点。IDA输入元数据哈希与当前磁盘客户端不同；已逐字节核对所用五个函数体、88条读取窗口指令和21条开局调用指令，与当前磁盘完全相符。只读访问现有IDA数据库，没有修改IDB或客户端。

`64F562`把ECX指向G+0x65C地图对象，`64F568 -> 602DBD -> 63ECA0`要求以下之一：地图+24为0；或地图+24为2且+108为0。`63ED10 -> 6024AD -> 629DD0`判断等于0，`63ED50 -> 60B65C -> 63EDD0`判断等于2。满足后才读取地图+124/+128并在G+0xCD0调用80E170初始化市场。这证明不能向当前类型3的BOSS地图强塞股票初始化。

`7DF010`在EMP解包后的地产记录末尾消费固定120字节，然后读取股票数量和DWORD配置编号表；`7E03F2`检查运行时map+124数量，`7E0419`存表地址到map+128，`7E043A`按数量*4复制，`7E044E`推进源游标。服务端既有 `original_map.cpp` 在尾部120处也已跳过该DWORD数组，本轮为它补上股票语义，未改动旧地图读取器。

## 实现

`parse_richonline_stock_resources`按每条STOCK的indx装入配置表，拒绝重复、缺号、非法数字、零股数、非有限活泼度及不合法涨跌阈值。RANGE缺省保持客户端+10/-10；当前资源是+8/-8。名称保存为原Big5字节，不传入Lua JSON或行情包。配置表允许扩展，但一局股票槽上限仍是10。

`richonline_stock_map`验证EMP版本和必要字节，按地图类型门禁返回是否启用，读取尾部股票编号顺序并检查数量、截断和重复编号。地图类型/子类型来自文件头，不能混用房间显示名或BOSS资源编号。版本1缺少子类型时不擅自开放类型2的股票。

`prepare_richonline_stock_opening`要求外部明确提供与地图槽逐一对应的30点历史及大盘前值/当前值/因素。每个值必须有限且价格为正；拒绝整段平线，避免已有图表消费者的相同高低点除零边界。不在准备器中生成伪历史、不套用未闭合调用来源的80E770随机走势。

准备器先生成16字节4200，再按局内槽序生成128字节4201（+6保留WORD填零、+8开始30个float）；Lua `stock.open`独立组织全部消息，核心逐字节复核。每槽权威报价与涨跌幅直接取历史最后两点，与80F1F0一致，不套用4203的内阈值修饰。全部消息通过后创建零持仓成交内核，供后续会话工厂接入。
