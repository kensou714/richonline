# 医院、监狱入口与退出几何

## 本轮修正

原道路拓扑只加载监狱，并要求入口、出口都可走。原资源的建筑内部入口恰好是terrain=-1，因此有效监狱被判成缺失。本轮医院和监狱共用坐标对读取：入口只要求在地图内；出口要求在地图内且是道路。保留无设施地图的空optional，不把哨兵坐标换成0号格。

客户端退出动画只支持四种二维位移：向下两格、向上一格、向左一格、向右两格。加载时拒绝其他形状以及跨行伪邻接，不给未知形状猜方向；不把建筑入口或动画经过的非道路格加入普通道路寻路。

## 原客户端依据

- `7DF010`：88字节地产数组之后的尾部+0/+8坐标对写map+64/+66（医院），+32/+40写map+70/+72（监狱），线性位置为x+width*y。
- `604B36`、`60A757`分别跳转医院和监狱坐标读取器。
- `631640`、`631D20`分别构造医院和监狱退出路线。`6045A5 -> 63E340`是+width；`600392 -> 63E390`是-width；`6017A1 -> 63E370`是-1；`605EA5 -> 63E3C0`是+1。依次比较下两格、上一格、左一格、右两格，填方向0、2、1、3。
- `631800`、`631EE0`退出回调先清住院／坐牢状态；movement552为0时归到出口，且非幽灵、非梦游、本地行动槽才发四字节0015。`63E530`构造的21是十进制，不能当成十六进制升级请求0021。

## 静态资源核对

`inspect-facility-map-geometry.py`读取121份原EMP资源；医院、监狱各46对符合退出几何。有效坐标中的建筑入口为非道路，出口为道路。原客户端20个函数窗口、2601条指令与磁盘RnClient.exe逐一匹配，详见两个JSON证据文件。该脚本仅做静态资源及字节核对，不执行玩法测试。

## 接入边界

新增hospital_positions供后续经典处罚新闻使用，尚未接入住院事件、保险或免罪，也不开放生产经典mode0。现有BOSS地图没有这些设施，不能凭本轮位置解析声称已支持BOSS住院。既有BOSS出狱的4010/420F与0015续接尚需独立修正：客户端阶段4才启动退出动画，幽灵／梦游不发送相同ACK；本轮不修改该状态机。

用户此前反馈的黑贝贝胜负提示和战后宝箱已经由此前版本修正；飞弹基地连续攻击后回1血仍缺新逐发字段日志，未确认唯一根因。本轮没有启动本机服务或客户端，没有新增或运行测试；交付采用固定提交的Release编译及Lua语法检查。
