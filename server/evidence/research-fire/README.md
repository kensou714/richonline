# NEW1183 火焰卡会话接入

## 原始客户端证据

`fire-new-decompile.json` 保存当前 NEW 客户端输入SHA256及实际函数反编译。

- 157→40ED：8字节，WORD+2 calendar/game、BYTE+4 slot、BYTE+5 bank、signed WORD+6中心。677EE0按GValue26=1的坐标方形范围放置NPC26；排除非道路、现存动态物、演员占用、静态28/58/61。静态2/3并非火焰排除项。即使全部候选被排除仍消费卡片。
- 火焰owner为当前演员；仅mode4合成Boss改为-1，mode3没有该特例。服务端当前只支持mode3本地玩家背包放置。
- 7C3220 case26通过60AA81→7D6E30读取动态物owner，进入7CC970。7CE420读取Npc26.hurt（当前2000），使用共享攻击/防御修正，不能使用Prop1183常量替代。
- 7CC970排队本地6060扣款，693220检查现金+存款严格大于伤害才能继续落点；相等进入破产。不移除火焰，不触发导弹头盔或地雷车辆免疫，没有额外网络效果包。
- 7C0C50活跃状态阶段调用612AB0→7E2F00。活跃owner只在owner回合递减；无主或失活owner在907==906轮锚递减。正值减1，0移除；当前GValue27=3。与401E地雷时钟分离。
- 7CE420还通过7FA270记录攻击来源/伤害原因字段1648/1649/1651供客户端后续显示使用；当前服务端仍使用既有终局协调器，没有新增这些本地字段的网络封包。

## 实现

生产能力要求地图允许1183，具备共享地面物、背包、战斗桥接、落点预检和终局处理。放置沿用研究卡纯规划器及无回调原子提交；40ED不追加ACK或重复效果。毒卡156仍返回400B。

回合协调层只在开始一个新角色回合时推进火焰；冻结回合也执行该时钟。地面落点通过战斗桥接读取地面owner，重新解析共享装备/状态/建筑修正，只扣当前落点角色。先预检存活续接，再经共享账本CAS提交；致命落点绕过不再执行的静态/地产阶段，4013之后进入现有终局流程。火焰保留，后续落点可再次受伤。清地卡、核弹和地雷链仍通过原共享地面容器移除物件。
