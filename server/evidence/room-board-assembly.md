# 房间成员与棋盘开局组装

普通地图目前尚无可用实战入口：生产provider仍调用单真人BOSS工厂；共享回合、每人手牌、普通地产和结算仍需接入。本轮不放宽该模式门禁。

新增 `build_richonline_room_boards`，将一至四名真人的房间连接、身份、技能、位置和资金组装为每个接收者自己的4000/4004。按原房间槽升序压紧局内槽，资金与角色一起排序；每份4000的local_slot指向该连接自己的身份。输入资料顺序不影响结果，离房留下的槽间隙不被当成棋盘空角色。合成角色只允许身份-1，排在全部真人后面，总角色数不超过既有编码器的8槽限制。

组装前拒绝未准备成员、重复连接/身份/房间槽、缺失房主、缺失或重复资料、连接与身份错配、真人技能越界、资金超出有符号32位及头部局号不同。全部输出通过现有4000/4004编码器验证后才返回；函数没有外部状态写入。

BOSS生产开局已改为调用该组装器，仍使用同一装备初始现金算法、真人0/BOSS1、相同出生点和显式opaque字节；合成角色未消费技能字节保留原输入。普通地图未来可复用这一实际被调用的组装边界，但这不等于多人同步已实现，也不提供普通地图资源或出生政策。

协议依据沿用现有 `richonline_board.cpp`：NEW65B450消费20字节头和16字节角色记录，local_slot位于+18；4004资金按同一角色槽顺序编码。本轮未新增客户端语义推测。

验证范围：静态审阅、Release编译及构建内Lua语法检查。按用户要求不新增/运行测试、不启动本机服务或游戏；普通多人开局与现有BOSS实机回归均未执行。
