# 经典多人梦游自动投骰

用户报告线上梦游玩家卡住，应该自动投骰。此前提交 8c26dbe59536 已修复
BOSS 会话。静态检查发现经典多人会话的 random_move 已支持受控角色投骰、
金豆不足时退回免费骰数以及自动路线，但 poll 没有主动调用入口，仍依赖客户端 0010。
本次经典模式缺口来自源码检查，不声称线上已捕获经典模式故障日志。

## 处理

- 仅 Phase::roll 中梦游或睡神附身、且没有冰冻/停走时，poll 调用现有 random_move。
- 日历事件、出院/出狱、饭店、节日、移动和落点等待均保留原阶段；恢复 roll 后再自动投骰。
- 只有成功提交移动后，按角色槽保存日历号；客户端随后到达的同次 0010 被接纳并忽略，
  不再抽骰、扣金豆或重复移动。下次轮到该角色时清理标记，不影响新一轮操作。
- 复用原骰数、载具免费额度、余额降档、账号拒付回退规则，不额外创建收费动作。
- 日志 richonline_classic_controlled_roll_automatic 标记实际服务端自动投骰。

按用户约束仅静态检查和 Release 编译，不新增或运行测试，不启动本机服务/游戏。
本文件初次提交时构建和发布结果见后续发布记录；不把编译通过当作实机验证。
