# 局内商店出售未定价卡时的诊断异常

2026-10-11静态核对 `server/data/logs/native-60844.jsonl` 的一次现场：商店打开时玩家库存包含卡1118（Prop.kpd 未配置 priceG）；随后收到6字节0031出售请求，服务端报 `lua_script_error:richonline_shop_price_unknown` 并关闭游戏连接。该日志没有记录槽号，但同一份库存中1118是已知无价卡，和异常来源一致；不能据此断言本次点击一定指向1118槽。

根因在 `boss_session.cpp` 的商店外围诊断采样：它在调用 `shop->handle` 前无条件执行 `shop->card_price(card)`。因此对未定价卡的出售请求先由日志路径抛错，无法走到 `shop.cpp` 已有的 `sale_card_unpriced` 安全关闭分支。诊断是非业务逻辑，不应抢先拒绝玩家请求。

现改为先查 `card_has_price`：无价卡的日志价格记 `null`、`price_known=false`，商店实际处理后再记录决策。`sale_refund` 只在真正售出时记半价，关闭/拒绝时记0。商店本体直接按价格表资格判断无价卡，沿用4031(-1)关闭当前商店，保留库存及点券并继续回合；不伪造原资源没有的售价。随机卡池现有出售资格过滤继续阻止新的无价随机奖励，开局或旧库存中的无价卡仍可能存在。

只进行静态日志/协议核对、编译和Lua语法检查；依用户要求未新增或运行测试，未在本机启动游戏。上线后需实机确认无价卡点击出售时不会断线、商店正常关闭，其他已定价卡仍能出售并刷新点券。
