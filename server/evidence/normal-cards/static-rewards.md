# 专用卡牌奖励格（2026-10-10）

## 缺失分支

当前地图规格中 BS_2_1 包含51毒气格，BS_2_2包含54骰子格。原 `RichonlineBossCards::land` 仅处理8、41、42以及旧68单卡新闻兜底，因此新格子通过地图开局后仍会在落点处进入未支持分支。NPC/地雷落点预检也只接受旧的奖励格集合。

本轮为源码审计发现，没有新的实机日志证明已触发。未启动服务复现。

- 解码当前 `Tex/event.dat`：EVENT_43=定时炸弹，51=毒气，52=红黑，53=火焰，54=骰子，58=乱传。
- 解码 `Data/Prop.kpd`：1045定时炸弹、1182毒气卡、1183火焰陷阱、1038遥控骰子均为启用的 CARD。

## 当前实现

专用格固定奖励策略为 `native-fixed-themed-card-tile-v1`：41→1044、42→1046、43→1045、51→1182、53→1183、54→1038。**资源证明物品主题及合法性，客户端证明4029字段及续接；固定奖励选择（尤其54固定遥控骰子）是模拟器策略，不是已还原的原版服务器掉落概率。**

复用4013→4029、库存空槽/合成、满包不覆盖的既有处理。专用奖励须在本地图的自动卡牌成员表中。正常落点、NPC/地雷预检以及合成BOSS跳过分支共用同一个奖励格分类函数，避免只补玩家分支。

本轮不开放52红黑格，当前13张BOSS地图没有该类型；不能用不生效的经典股票卡冒充闭合玩法。58是乱传格，不使用4096新闻兜底。已定位4209→67C080可按+4 WORD移动当前角色、保留朝向并播放离开/出现动画；但尚未接入58的目标选择与终止续接，不能声称58已修复。4008虽然也移动角色，却排608A参数6回到操作阶段，不能代替乱传结束回合。
