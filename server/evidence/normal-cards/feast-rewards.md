# 节日赠卡与点券同步（2026-10-10）

## 原因与采证

检查 `data/logs/native-54416.jsonl` 未发现对应节日奖励提交或独立的节日C2S请求。源码只有重阳节账本同步，缺少其他赠券及赠卡处理；这是日志和源码排查发现的实现缺口，未在游戏中复现。

本轮通过IDA-MCP实例 `5c7b48b1123e` 在线确认客户端分支：

- `7D8DE0` 按资源顺序选首个日期匹配槽；`7D89D0` 再检查模式并分派节日函数。
- 赠卡分支只排队UI30通知并返回0，须等待服务端响应，通知本身不插卡或发请求。
- `66A970` 处理 `40A0`：WORD opcode、WORD game、八个有符号WORD卡号；有效角色对应字段为-1则跳过，否则通过 `6110BB -> 7F8780` 插入一张卡。随后排队阶段3继续回合。
- `66AC20` 处理 `40A1`：WORD opcode、WORD game、八个BYTE胜负标志；非零赠41点券，零扣41。随后排队阶段3。
- 本地6062处理器 `67FC80` 调用 `605022 -> 7F9D20` 增券或 `60B076 -> 7F9D70` 扣券；后者明确将负余额归零。
- 正常插卡 `7F8780` 使用首个空槽后运行组合；八槽已满则保持手牌不变，仍继续事件。
