# 请神卡按目标距离选神（2026-10-10）

## 定位

用户反馈目标附近1格的神没有被召来，反而召来远处神。最新日志 `data/logs/native-45308.jsonl:2231` 记录112请求，随后发送40C0和4024并继续行动，未发生拒绝或断线；旧日志没有神位置/目标位置，不能事后恢复两者的距离。

源码确认生产npc_summon_candidates返回全地图位置，npc_session筛出已支持神明后调用choose(candidates.size())均匀随机选择。该实现不考虑目标距离，确实可能忽略近处神。

客户端证据不能证明原服如何排序距离或处理等距，本次明确按用户所述近处神优先修正项目政策：以目标角色当前位置为中心，用格坐标平方欧氏距离排序，同距离按格号升序；不按施卡者位置、不按道路绕行步数、不把格号差当距离。不新增未经证实的距离门槛，也不声称全地图候选等于客户端视口。

## 实现

- Turns使用权威目标角色位置对允许候选排序，传入固定首项选择器。
- NPC会话保留调用方候选顺序，过滤掉非神物件或未接入神明后选首项，避免容器按格号重新排序或随机重抽。
- 选择结果随成功提交的NPC结果返回，输出 `richonline_summon_selected`，记录施卡者、目标、目标位置、神ID/位置、平方距离和政策名。
- 只更改选择策略，保持原40C0、奖励/转盘、地面补充、附身时钟和库存共同提交。普通踩神等其他入口不受影响。
