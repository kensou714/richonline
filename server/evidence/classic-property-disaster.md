# 经典新闻：地产灾难408B至408F

本轮将台风、瓦斯爆炸、外星怪兽、山洪、强拆接入经典静态1新闻格，目标由只读新闻策略显式提供。新增property字段表示地图地产表索引，不复用金额或道路格号，不要求目标属于当前行动者。原服务器的随机新闻概率和目标抽取规则仍未恢复，本轮不自拟随机分布，也不开放生产经典模式。

## 客户端依据

`classic-property-disaster-client.json`保存36个代码窗口和1501条指令，均与当前磁盘RnClient.exe逐字节一致。IDA导入哈希与磁盘哈希分开记录；632EB0、6330F0、6332F0没有可用伪代码，按入口到ret结束的指令窗口保留汇编，未修改IDA函数定义。

- 669590/669730/6698E0/669A80的UI30提示取+4 signed WORD图索引，+6 signed WORD为地产索引；408F的669C30只取+4地产索引，提示用UI4，没有图片载荷。
- 6014DB到7E3DF0排除建筑种类8/9/10，再要求signed等级大于0；条件不成立仍显示新闻、排6080阶段2，不当成错误目标或擅自重抽。
- 台风动画15的633040在1000ms后降1级，632FA0结束时按应用标志补做；爆炸/山洪/强拆发送动画16的[地产,5]；怪兽动画17在6332F0明确把对象+16置5。更新一次后刷新建筑，结束阶段不会再重复扣级。
- 7E4020先做BYTE减法，再把signed结果<=0归零。本服务端经典地产初始化只接受0..5级，降1或5的有效域与饱和减法等价，不将此公式推广到客户端任意BYTE值。
- 到零级时sprite11住宅kind归0；sprite12大型建筑kind归-1。住宅原kind1且有主时先7E3E60清owner，再7E3C00恢复原owner，因此最终产权不变。价格和其他地块不变。
- 怪兽结束时633420的三条额外清理仅在604703成立时运行；63E990到61260F/629E10证实是mode4，经典mode0不执行，不能据此改动经典产权或库存。

## 提交及续接

地产对象提供封装的Disaster计划，保存所属对象、降级量和前后快照。准备阶段拒绝未知地产、未决购地选择和非法降级量；业务无法改写计划。零级和保护类型返回原样快照，仍允许显示合法新闻。

Lua tile_1按opcode计算降级、零级种类及完整4013/新闻报文。C++从同一地产快照计算期望值，逐值、整数类型及逐字节复核Lua输出；图索引沿用当前客户端已加载的29个UI30槽。408B..408E共8字节，408F共6字节；所有事件amount必须为0，其他新闻不允许携带property。

共享会话准备完报文和日志后，核对活动名单、当前状态、落点、地产对象身份及目标快照才提交。只写目标level/kind，保留owner和price；不会先变更地产再发现Lua输出错误。随后仅发送一次灾难新闻，沿用complete处理同格效果和岔路，不另发第二次降级或额外扣款。客户端动画队列负责先应用降级再进入stage2，服务端不把动画完成伪装成网络ACK。

静态审阅覆盖本人/他人/无主地产、level0及1..5、类型8/9/10、两种sprite、住宅kind1归零、未知索引、Lua错误和准备后目标变化。验证仅包含Release编译、Lua语法及客户端字节比对；按用户要求不新增/运行测试，不启动本机服务或客户端。实机动画时序、完整经典业务装配与原服随机策略仍待继续完成。
