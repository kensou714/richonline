# 经典普通行情生成与日期衔接

用户于本轮确认采用客户端本地模拟作为服务端策略：每推进一天波动一次，大盘为各股
现价之和，额外影响因子为0；行情卡仍覆盖方向、重置三次并使用资源涨跌停幅度。
当前资源为+8/-8，不写死10。此策略不宣称是已恢复的原服线上算法。

## 客户端依据

`classic-stock-simulation-client.json`保存同代EXE指纹、完整函数chunk和磁盘比对。
80E170初价为单精度资产/股数，再叠加-30/-20/-10/0/+10%扰动。
80E770经60C4A8调用80E710，随机范围为-7..+7，步长0.01；不能误用80E6B0的-3..+3。
乘活泼性后写回float，累加走势夹至±9，方向计数按符号加减，越过±3清零。
在1和999.99边界处向内走势增强、向外走势减半，普通模拟最终报价夹在此范围。
80E510未在当前IDA中定义为函数，但存在完整代码段及入口跳板610D14，逐股调用
60013A→80E770后逐项float求和；该范围单独保存反汇编与文件哈希。
这些证据支持本地算法，不证明线上服务器的频率及启用路径。

## 服务端实现

新增每局独立模拟器，显式`simulation_seed`启用，与外部history/fluctuate互斥。
采用mt19937_64和拒绝采样生成均匀随机桶，不共享全局CRT随机流。
以初价加29次真实模拟生成4201所需30点历史。这是明确的服务端预热策略；原初始化
函数没有直接生成30点历史。全平行情有限次重新生成，仍全平则明确拒绝，避免客户端
曲线除零，不人为捏造拐点。初始大盘取第28/29下标的价格和。

非初始日轮首推进一次行情，先复制模拟器，生成所有价格和大盘；报文、Lua核验及
发送队列准备完成，市场成功提交后才无异常地移入随机流和走势。失效计划不推进
模拟器或强制次数。独立4203不推进日期或模拟随机流，次日按市场实际现价计算。
强制卡期间潜在普通走势仍推进，但最终严格采用市场核心强制价格，不再次夹价、
减半或叠加因子。三次结束后恢复普通模拟。

生产经典完整services仍未装配；此轮提供可显式启用的会话策略，不解除生产准入门。
本轮只静态分析和编译，不新增/运行测试，不启动服务或游戏，不部署或重启线上。
