# 经典电脑公司落点收费

仅在server目录接入大型建筑kind5的落点、自有升级及资金续接。客户端并没有在该落点
请求选股；不能按建筑名称创造股票玩法。生产经典准入仍未开放，房产公司kind6等缺口继续保留。

## 客户端依据

同代RnClient.exe的SHA256及20个函数完整chunk与磁盘字节核验见
`classic-computer-client.json`。7C6640保存普通地产分支节选，另存关键调用点反汇编。

- `60ECEE -> 692A90`检查kind5；`5FF46F -> 7E42F0`计算
  signed level × 150 × 物价系数。`601837 -> 7ECB10`读取D+5，正数使报价翻倍。
  客户端32位乘法回绕，服务端与独立Lua按同样的低32位语义计算，再拒绝不可支持的负收费。
- 7C6640先检查地主的睡神、梦游、冰冻及住店/医院/监狱/绑架状态，另检查地产查封。
  7C9491等调用点的ECX取地主槽；关系1472/1480检查则取当前付款者。本轮复用已实现
  的抑制条件，关系卡仍未开放，没有把付款者受控误当免租条件。
- 进入电脑公司收费分支后，财神免付，穷神翻倍；免费卡1050门槛5000，嫁祸卡1056
  门槛10000，先免费后嫁祸。两者仍受地图自动卡资格及库存证明限制。
- `7CD090`在电脑公司使用type0，与普通租金一致；不使用贸易type1或饭店type2。
  `6712B0`取消/成功处理复用现有嫁祸资金事务和地产续接，不新增协议码。
- `7FA0F0`将实际收费截到现金加存款；先给地主存款，再扣付款者现金/存款。
  `693220`要求支付前总额严格大于实际收费才继续，等额也进入破产路径。
- 4013触发客户端本地金额事件。服务端只提交同笔账本和卡牌消费，不再发6060/6061，
  不伪造独立电脑公司选择。正常付费、免付和免费卡后走7CB3F0地产附加效果，继而同格续行。
  自有电脑公司沿用现有4021升级流程，不收自己的费用；从空大型建筑选择建成电脑公司
  才使用既有4025选择及许可证流程，不能给已建成的每次升级额外扣许可证。

## 实现与验证边界

`classic_computer.cpp`及`buildings/classic_computer.lua`独立计算报价，核心核验Lua整数结果。
经典会话kind5准入后共用已有租金事务，覆盖支付、免费卡、嫁祸等待/取消/超时和破产。
日志使用`richonline_classic_computer_payment`；嫁祸延续既有专用日志。

工作区Release及Lua语法编译通过，未新增或运行玩法测试，未启动服务或游戏。
固定源码构建、本机EXE/脚本同代交付和GitHub提交另附回执；不部署重启线上实例。
