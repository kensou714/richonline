## 服务端行为与边界

- 生产接入要求地图CARD/EMP允许1181、共享背包/地面物、可见性策略和后续落点预检。当前资源BS_1_1/1_2/1_4的1181成员资格已测试。
- 放置先规划并准备共享地面事务，再核对背包和地面版本；无回调的提交区同时扣卡及放置NPC25，最后发送40EB。
- 落点先投影冻结后的状态并预检；消耗冰块与状态/附身时钟使用准备提交，保留神明剩余时长和角色回合身份。普通路过不会触发。
- 正常回合开始递减冻结3→2→1→0，前两个自身回合发送4010/420F，1800ms服务端恢复定时器接续下一角色；不制造客户端ACK。冻结落点跳过银行、卡片与机会格；地产仍交由现有地产模块。
- 当前本地玩家合法行动阶段的无效155或未实现156/157返回400B，保持背包/地面不变，不发送成功包。155立即重发因地面已占用而拒绝；旧calendar、移动阶段请求继续按既有协议错误处理，未引入不可靠的跨回合重放缓存。
- 仅独立规划器支持actor1696免疫；当前回合引擎并未开放产生该状态的新能力。火焰1183、毒1182效果仍不开放。地图BS_1_3、V_BS_1_1仍禁用。
