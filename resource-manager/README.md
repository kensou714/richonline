# 大富翁 Online 资源工作台

面向美工、策划的 Windows 资源维护工具。双击游戏目录里的 `RichOnline.Resources.exe`，不需要启动服务端或安装开发环境。`ResourceCodec.dll` 必须放在程序旁边。界面默认简体中文，游戏原有文本按原编码保存，不自动繁简转换。

## 日常使用

1. 从首页或左侧选择分类，搜索中文名称或原文件名。
2. 选择资源，在右侧预览或编辑。
3. 点击“保存修改”或按 Ctrl+S。切换资源、关闭窗口会提醒处理未保存的内容。
4. 用“历史与回收站”恢复修改前的文件。每次保存、替换、复制、导入、删除均记录历史。

历史保存在当前游戏目录 `.resource-workbench/history`。不要把该目录删掉；它包含恢复所需的完整原文件。恢复会拒绝覆盖后续修改，可先导出备份进行比对。新增文件使用未占用的位置，不自动覆盖同名资源。

## 已开放的功能

| 分类 | 维护功能 |
| --- | --- |
| 全部资源 | 扫描真实目录、中文名称、分类搜索、导入、复制、导出、替换、回收站、版本恢复、外部修改冲突检测 |
| 音乐、音效 | 读取包内声音目录，试听、停止、音量调节，声音导出、同类替换、新增、删除；展示跨资源包的同编号覆盖关系 |
| 图片、动画 | NP 透明图像预览、逐帧查看、按原帧时长播放、导出 PNG；单帧图片同尺寸替换、水平翻转 |
| 地图 | EMP 道路与地产结构预览，点选地块，编辑开局现金、存款、点券、物价指数、关联地产的初始等级和地价基数 |
| 角色 | 角色名称、性别、介绍等表格编辑，服装等扩展属性按需展开；角色、服装、神仙、语音表情配置按文件管理 |
| 道具卡 | 名称、说明、价格、启用与出售状态等表格编辑，条目搜索、复制新增、删除；合成表、商店表共用同一入口 |
| 文本 | 游戏文字、帮助、新闻等条目搜索和编辑，保留编号及原文件编码；普通文本编辑 |
| 界面与其他设定 | 文件管理；已经识别的文本配置可表格编辑，尚未支持的内部格式明确提示 |

这里不是完整的游戏场景制作器：地图暂不支持绘制地形、铺设道路、摆放装饰及改变地图尺寸；角色暂无整套换装合成预览；动画不开放逐帧重绘和重新打包；UI/MS 专用格式暂无可视化编辑器。新增条目或文件也不会自动补齐游戏中的关联引用。以上能力不能用文件复制或表格新增冒充已完成。

现有 Richonline 文本使用繁体 Big5 编码。无法表示的字符会阻止保存，避免静默变成问号。部分原文已有问号，工具保留原样。资源中的规则和编号需与游戏保持一致；建议改动后重新启动客户端实测，文件回读成功不代表游戏玩法验证完成。

## 源码与构建

源码独立放在本仓库 `resource-manager`，沿用现有管理器的 .NET 8 / WinForms 技术，不依赖上级目录的管理器源码。不会改变账号管理或正在开发的服务端代码。

需要 .NET 8+ SDK，以及支持 Windows x64 的 clang++。解压/压缩组件复用仓库已有的 MIT 许可 `server/vendor/lzokay`，未引入在线包依赖。

```powershell
cd resource-manager
./build.ps1 -Publish
```

发布为携带 .NET 运行时的可执行程序，并复制到游戏根目录。独立分发时至少同时提供 `RichOnline.Resources.exe`、`ResourceCodec.dll`、`ResourceCodec.LICENSE.txt`。

## 验证

```powershell
dotnet bin/Release/net8.0-windows/RichOnline.Resources.dll 'F:\大富翁online\Richonline' --self-test 'test-artifacts'
dotnet bin/Release/net8.0-windows/RichOnline.Resources.dll 'F:\大富翁online\Richonline' --render 'test-artifacts/screens'
```

测试只读取原始游戏资源，写入隔离的测试目录。覆盖全部 121 份 EMP 往返保真、63 个声音包及 1161 条声音的编号与内容保真、19592 份 NP 解码、7283 份动画、透明像素回读、繁体编码、损坏输入、冲突保护和删除恢复。另有真实表格编辑提交，以及 MP3/WAV 系统播放器静音播放状态检查。界面渲染检查覆盖角色、道具、地图、音乐、文字、图片页面。

当前范围的客户端完整游玩验收、所有音频逐条试听、全套 UI/角色/地图场景编辑尚未完成。
