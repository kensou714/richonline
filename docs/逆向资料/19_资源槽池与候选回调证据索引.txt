// 01 / 从OTHER记录+4到十二类别共用的slot池
// ----------------------------------------------------------------------------
// 先分三层：P=C+40是可用slot栈；C+580CC是DWORD反向记录表；C+92A4C是BYTE状态表。
// P+0为DWORD数组基址，+4为元素容量，+8为可弹出数量；已知字段不等于完整类大小。
// 62EAE0只清基址和数量；6DFC30另写数量0/容量实参，按low32(capacity<<2)分配。
// 6D75A0传容量30000，再按29999..0压入；成功且无并发改池时首次pop为0，然后1、2……。
// 总申请120000字节；这些是静态正常路径推导，不是游戏运行中取槽顺序或当前剩余量的实测。
// 满池谓词是signed N>=K，完整EAX为0/1；push仅按该门拒绝满池，不查slot范围或重复。
// pop先--N再读取，无空池门；负N、空池或重复归还的条件风险不能写成已复现的游戏BUG。
// 6DBDF0调用push后，无论成功与否都清BYTE[C+92A4C+slot]，并保留push返回值。
// 它不清反向记录表、不清原12字节记录+4；“归还失败无副作用”和“归还注销全部引用”均不成立。

// ----------------------------------------------------------------------------

// 03 / 共享记录地图候选回调
// ----------------------------------------------------------------------------
// 6BA170接收ECX容器、callback与context两个DWORD；先判callback，再判容器+0/+4非零。
// +0为首节点，+4只证实非零门；沿node+80h后继遍历，不把80h称作节点大小或数组步长。
// 间接调用为cdecl callback(node,context)，遍历器ADD ESP,8清栈；回调完整EAX非零即命中。
// 首命中返回完整1，全未中或空门返回0，返回域不是节点指针；100h同样可触发搜索命中。
// 6AAA40调用strcmp(context,node)，两个指针都不加偏移；节点首址作为NUL结尾文本消费。
// 相等返回完整EAX=1，否则0；NULL、终止符、编码和回调修改链的影响仍无全域保证。
// 上层6A54F0十路搜索共用共享记录R+8文本；容器字段属于调用对象，不能当作R内偏移。
// 各路搜索EAX非零后才过6AAA80模式门，后者只保证AL；搜索100h与模式100h的结果不同。
// 6AAA80是模式兼容门，不是自动名ATL::AppendChar所暗示的字符串追加。
// 模式0/1/2/3分别兼容配置值{3,0}/{3,0,1}/{3,0,1,2}/{3}，域外或查询-1失败。
// 一路成功后跳过余路；全部失败时仅R+38h完整DWORD==3可作兜底，不能只比较低BYTE。
// 候选门通过后读取地图文件开头16字节到局部地图Q+8，并与R+28h逐字节比较。
// R+8文件名、R+28h比较字节、Q+8读入区为不同字段；16字节相等不证明MD5或网络鉴权。
// 路径格式Map\%s；RTC描述符确认szFullMapName为64字节，68仅是相邻栈槽间隔。
