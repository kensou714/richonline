//   +0x640       20字节  游戏内层记录队列对象；记录本身288字节，勿与+0x20混同。

//   +0xC48       DWORD   行动令牌；4004写入，多条上行只带其低WORD。
//   +0xC84       72字节  商店商品表，由4030复制；刷新另有flag和金豆路径。
//   +0xCD0       嵌入    游戏内股票Market，不是独立StockName/StockRace单例。

// Map的不同数组
//   DWORD[Map+48]：静态地图引用的基址，不能用动态格switch规则解释。
//   DWORD[Map+56]：68字节地产记录基址，D=base+68*index。
//   DWORD[Map+60]：4字节动态物件记录基址，动态格type12/27用于连锁效果。
//   D+0地产种类(11/12)、+1建筑种类、+2等级、+3owner；符号扩展按具体消费者核对。
//   D+6处是分组字段；某些调用读取WORD，不能笼统称一个BYTE。
//   D+32是显示名称入口；4056用它显示，不会因此同步地产状态。
//   具体类型和等级上限见地图与路径/、回合继续与落点调度/及原始资源。
//
// Summary与P必须分开
//   Summary[s]=G+156+160*s；401B +16写Summary+153的胜者标志。
//   400A的远端普通分支会把该标志清0，并设置其它摘要状态。
//   400F打开战绩界面不等于它携带完整战绩；显示依赖之前已接收的摘要。
//   见胜负结算与离场/；真实服务端发送顺序仍需日志或协议实现另证。
