// 地址来源
//
// 已核实：启动参数先选择区域配置，配置中login/server字段是下载URL。
// 客户端解析下载列表的IPAddress、Port，再调用TCP连接。
// Serverlist.kpd在已查路径只提供标识和名称，不直接决定连接IP。
// 地址记录长308字节，文本IP位于+140，端口DWORD位于+268。
// 证据：0x623030、0x69EEE0、0x69F750、0x82C470、0x87DFE0。
// 待验证：静态配置链不能证明当前在线URL实际返回的内容。

// 大厅初始化依赖
//
// 大厅消息编号均为十进制，payload偏移从8字节S2C头之后算起。
// wire3    注册对象，辅助解析器0x88AE80读取80字节。
// wire9    两个DWORD：自身ID、对象查找键。
// wire7    144字节基础记录，再加固定32个DWORD，共272字节。
// wire30   一个DWORD和三个F64，共28字节。
// wire9的查找键必须命中已存在对象；wire7的ID必须与自身ID一致。
// wire30会使用前面保留的数值和当前对象，随后同步调用UI路径。
// 包长正确但对象ID不一致，仍可能在客户端解引用时失败。
// wire140在当前大厅分发器中被忽略，不能用作已证明的刷新消息。

// 房间创建与更新
//
// C2S3创建记录为固定128字节加扩展；C2S23编辑另带4字节前缀。
// 当前解析器要求两个固定字符串槽内存在NUL结束符。
// 记录+32为标志，0x40表示携带扩展；+120为扩展长度。
// 当前创建实现要求扩展标志与非零长度一致。
// 记录+124的线上标记在当前实现要求为小端DWORD 1。
// 内存对象里的指针、线上标记和房间模型键必须分开解释。
// S2C5和S2C10前缀含房间键；序列化时重写参与者、槽位等字段。
// 响应不是把C2S创建记录整体原样回显。
// 当前标志掩码与字段校验是实现边界，不代表所有客户端组合均支持。

// E88房间扩展
//
// 已核实：新版扩展长88字节，UI与游戏设置会复制22个DWORD。
// 已弃用旧版80字节扩展不可用于当前客户端。
// 以下偏移相对于扩展E，不是整个创建包。
// 0..31     地图资源名称。
// 32..47    地图文件前16字节；校验算法未在该链中证明。
// 48        配置模式DWORD。
// 52        房间容量DWORD。
// 56        等待时长标量，游戏内转换为毫秒。
// 60        时长标量，客户端按30倍写入对应内部字段。
// 64        金额/配置DWORD，外层记录将其转换为double。
// 68        分类及BOSS表选择器；分类2选第二张表。
// 72..87    标志及未归类字节，保留原值，不擅自清零。
// 其中+74涉及密码使用，+75控制外层标志0x1000。
// 游戏配置模式、实际EMP地图模式和299标志是三个不同来源。

// 房间转游戏
//
// S2C22载荷是18字节紧凑结构，处理入口0x8825DC。
// 0..3      IPv4四字节，已经是网络顺序的地址字节。
// 4..5      小端端口，connect前由客户端执行htons。
// 6..9      额外DWORD，业务名称未完全确定。
// 10..17    不透明64位令牌。
// 地址DWORD直接写sockaddr，不再执行htonl。
// TCP成功后0x87A110至0x87A2B0发送游戏type0。
// 载荷依次含管理器键、当前房间键、自身身份、令牌和额外DWORD。
// 此处房间键来自房间对象+124，不能换成E88指针或其他房间编号。
// 静态路径未证明存在另一个独立“开始游戏”操作码。

// 验证边界
//
// 函数返回成功或保存连接上下文，不等于内部TCP一定成功。
// E88必须既保持字节完整，又满足地图、分类、人数和资源约束。
// 启动过程的静态调用顺序不能直接证明原服务器推包时序。
// 实测应记录大厅连接与游戏连接各自的收发，不混用连接ID。
