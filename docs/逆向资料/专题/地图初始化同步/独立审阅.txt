// 65BDB0将ECX改为G+0x65C，将p+4作为7E0F30的列表起点。
// 7E0F30以signed比较遍历M+0x124条数N；每条步长4，位置WORD=-1时跳过。
// 最后一条WORD末偏移为4+4*(N-1)+1=4N+1，最低前缀长度因此为4N+2。

// 7E2320写动态格类型/-1/-1，再经63E8C0写末字节1；重发有清字段副作用。
//
// 65BE80与65C140均以movsx读取p+4槽号，ECX取[G+0xE00+4*槽]。
// 库存目标是消息指定的参与者P，并非一律本地玩家，也不属于地图对象M。
// 7F7710分别复制48字节到P+0x11A和P+0x14A；来源p+6，最低前缀54字节。
// 7F86A0/7F8710确认槽步长6及组0/1/2偏移；7F89D0只读组1/2的槽+4。
// 第6字节未获业务定义；全量复制仍会保留它，不应以猜测字段名生成库存。
