// ==========================================================================
// Ko 配置加载及地图记录布局
// ==========================================================================
// 623CB0 的调用现场依次压入 Data\\KoNpc.kpd、Data\\KoNews.kpd、
// Data\\KoBuild.kpd；按调用约定还原实参后，805660 的逻辑读取顺序是
// KoBuild -> KoNews -> KoNpc。
// 805660 是三次读取的短路链：前一次返回 0，后续文件即不读取。
// KoBuild 实际读取器为 8056C0；成功返回 1 的直接条件是文件打开成功，
// 不能据此认定每一字段存在、合法，或 MAP 数组和建筑数值均已完成校验。
// 806670 按行以 sscanf 解析 KoNews；resources.json 的 sections=[] 只表示
// 当前解包检查器没有找到 [SECTION]，绝不表示该文件为空。
// 806A30 读取 KoNpc 的 indx/name/speak/比例与效果等字段；它是同一加载链，
// 但不充当地图等级上限来源。
//
// 全局对象
//   628010：dword_A7671C 为 0 时分配 0x4588 字节，再返回缓存指针。
//   8056C0 在对象 +0x457C 保存 MAP 记录数，在 +0x4580 保存数组指针。
//   每条 MAP 记录步长 0x1A4，即 420 字节。
//   807C40 按 mapName 对记录逐条 strcmp；找到返回记录指针，未找到返回 0。
//   调用者对返回 0 是否逐处保护，不能由该访问器独自保证。
//
// MAP 记录局部布局，依据 8056C0 的写入地址
//   +0x000..+0x07F  mapName[128]
//   +0x080..+0x0FF  mapDesc[128]
//   +0x100          defaultBuild，DWORD 建筑编号
//   +0x104..+0x12B  十个 DWORD 上限，按 Yan/Pao/Chang/Zhong/Kong/Mi/
//                    Ba/Shan/Zhao/Shou 顺序排列
//   +0x12C..+0x1A3  npc[30]，DWORD 数组，共 120 字节
// 第十项上限的 DWORD 起点 +296=0x128；npc 从 +300=0x12C 开始。
//
// 初始化与可选字段
//   8053C0 将 +256 的 defaultBuild 和 +260..+296 的十个 DWORD 上限清零。
//   8056C0 先构造数组各记录，再逐节读取。maxLev_* 仅在键存在时覆盖初值；
//   缺失键在当前构造链下仍为 0。defaultBuild 经过 807BD0 字符串转换写 +256；
//   无匹配 token 返回 -1，读取器不显式拒绝。
//   npc[30] 初始化为 -1；随后的 k 循环按值写 +300+4*k，静态未见 k<30
//   的界限检查。当前样本每张图仅四项，不代表任意资源输入安全。
//
// 当前资源样本，非格式规格
//   KoBuild.kpd 含 3 个 MAP：QJ_GW_01.emp、QJ_SM_01.emp、QJ_HD_01.emp。
//   三者 defaultBuild 均为 Yan，六个显式 maxLev_Yan/Pao/Chang/Zhong/
//   Kong/Mi 均为 6；Ba/Shan/Zhao/Shou 均未出现，构造后的对应字段为 0。
//   三条 npc 分别为 0,1,2,3 / 2,3,6,7 / 4,5,0,1。
//   中文 mapDesc 只按 Latin-1 保留原字节，不将乱码样本解释成真实文本。
//   KoBuild、KoNews、KoNpc 的原始/解包哈希见证据/resources.json。
//
// 对照读取器
//   7AF4A0 也读取七级表，但目标 DWORD 偏移相对 8056C0 的前半部整体
//   大 4；它没有 MAP 记录循环。不能把两个函数误认成同一对象布局。
