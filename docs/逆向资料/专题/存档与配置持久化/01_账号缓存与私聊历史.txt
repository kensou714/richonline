// 账号缓存与私聊历史：从业务触发到磁盘格式
// ============================================================================
// 地址为 VA；错误自动命名 CMFCRibbonCollector / CRecentFileList 不代表真实类。
// 完整原证和审阅范围见本目录索引。离线样本摘要不包含实际账号或姓名。
//
// 登录对象的相关布局
// ----------------------------------------------------------------------------
// 对象 +72：内嵌路径字符串，初始化为 Config\\User.kpd。
// 对象 +200：账号输入缓存；+328：密码输入缓存；两起点相距 128 字节。
// +456：软键盘大小写状态；+496：登录等待计时字段（相关 UI 路径导航）。
// 72A080 把两个缓存首字节置零；未见对账号缓存全部 128 字节清零。
// 72B180 从 control10/11 分别复制到 +200/+328，并要求二者首字节均非零。
// 两字段通过 604672 交给登录层；本轮不据此还原认证协议、密码算法或服务器校验。
//
// Save 开关与保存时机
// ----------------------------------------------------------------------------
// 配置访问器 796D90 返回配置对象 +69；6052B6 为其跳板。
// 72B180 command6 反转该字节，并设置勾选图像；这里不删除旧 User.kpd。
// 72A080 初始化：Save 非零才调用 60CD3B -> 72B820，并填充 control10。
// 72B180 command2：输入有效，604D1B 返回非零之后，Save 非零才调用
// 610DC8 -> 72B910；随后显示等待提示并写入 GetTickCount。
// 因此这是发起登录流程中的保存，不是已证明“服务器认证成功后保存”。
// Save 自身写回 App.ini 的路径见文本与容器/04；账号文件与开关不是一个文件。
//
// User.kpd 负载与边界
// ----------------------------------------------------------------------------
// 72B910：81B050 复制对象 +200 起的 128 字节 -> 81B0C0 压缩 -> 81B150 保存。
// 密码起点 +328 正好在这 128 字节区间之外；本保存函数没有复制密码字段。
// 这是裸固定字节缓冲，不含节名、键名、长度字段或内部版本号。
// 外层仍为 KPD 九字节头与偏移变换压缩流；变换不是密码学保密方案。
// C 字符串 NUL 后的剩余字节也会被保存，未见本函数清零尾部。
// 不应把保存内容简化成 strlen(account)+1，也不应宣称尾部一定全零。
//
// 72B820：打开成功后解包，把容器声明的原始长度原样 memcpy 到对象 +200。
// 本函数未检查长度是否等于/小于128，也未追加终止 NUL；解包状态亦未验证。
// 损坏文件可能覆盖后续字段；即使外层打开成功，也不代表可以安全填入文本控件。
// 读取失败只清理容器；返回值是清理返回值，不能当作可靠的读取成功布尔值。
// 保存链未检查压缩/写入返回；低层 fopen/fwrite 缺少检查的情况见容器专题。
// 所有路径是相对路径，调用点未传绝对根目录；不能声称支持任意工作目录启动。
// 输入使用 char 字节和 ANSI 控件链；没有证据把账号文件定义为 UTF-8。
// 当前磁盘 User.kpd 仅28字节，头声明原始长度64、压缩长度19，实际解包64字节。
// 它与当前72B910固定写128的行为不同；来源可能是其他写入版本/工具，尚未证明。
// 当前读取器按声明长度复制，能进入64字节复制路径；这不能反推当前写入器写64。
// 样本包含NUL，NUL后的字节并非全零；不公开账号内容或明文摘要。
//
// Private.kpd 的业务含义
// ----------------------------------------------------------------------------
// 70ED20 的聊天模式2分支读取收件人，拒绝空值、无效对象及自己的姓名，
// 调用发送层后执行 60C5DE -> 70F830；本分支和配置 Private 开关关联。
// 70F830 从 control11 取姓名，遍历 control13 用 strcmp 精确比较，存在则返回，
// 不存在才追加列表。因此本链可定为私聊收件人历史，不是密码或好友授权数据库。
// strcmp 为字节级、区分大小写比较；函数本身没有显式条数上限或最近使用重排。
// 发送层调用返回后即追加，未见先等服务器私聊送达确认。
//
// Private.kpd 文本负载
// ----------------------------------------------------------------------------
// [NAME] 节；键 item0、item1、item2……；值是类型6的字符串。
// 70FC60 加载到 control13；7391E0 加载到另一界面 control26。
// 769500 的局部加载分支还将同一文件加载到 control4026。
// 每条读取容量128；从 item0 开始，第一个缺失键即结束，因此中间不能留编号空洞。
// 路径打开或节查找失败仅清理退出；不能从其返回值判断列表是否完整恢复。
// 解包后直接交公共文本解析器；文本字节编码应与客户端 ANSI/本地代码页链兼容，
// 当前 Private 样本不能严格按 GBK 解码；审计仅按 ASCII 节名/键识别结构，
// 不强行转码姓名；完整字节可被某编码接受也不能单独证明该编码就是实际来源。
// 当前样本头声明原始69、压缩66字节，ASCII键为连续4项；cp950严格解码可接受。
//
// 保存闭环与失败传播
// ----------------------------------------------------------------------------
// 70F9E0（control13）与 738F60（control26）均在析构路径中保存。
// count>0 才创建 Private.tmp，写 [NAME] 与所有 itemN，关闭文本流；
// 随后按 0x4000 文本模式读临时文件，压缩，覆盖 Private.kpd，再 remove 临时文件。
// 文本模式读意味着 CRLF 可转换成 LF；不能要求保存后的负载与临时文件逐字节相等。
// 整条链未检查写文本、读临时文件、压缩、写最终文件及 remove 返回值。
// 这不是临时文件成功后 rename 原子交换；失败/中断可以丢失原有最终文件。
// 若当前列表空，析构跳过保存，也没有删除旧 Private.kpd；旧历史可能在下次恢复。
// 两界面共用同一路径；如果它们持有不同快照并依次析构，后保存者可覆盖前者。
// 这里是代码条件导出的风险，不是已复现并发生过的用户故障。
// 临时 Destination 上的 strcpy 未显式限制长度；正常读取128不担保全部 UI 输入安全。
//
// 二次开发契约
// ----------------------------------------------------------------------------
// 离线工具兼容读取 User 时接受1..128字节且NUL在负载内；写出当前格式固定128字节，
// 清零尾部，并在报告中标记旧样本长度差异。不能把当前64字节样本静默冒充128字节。
// Private 工具保持连续编号，限制单条字节长度，明确代码页，并保留原文件备份。
// 工具先在旁路文件完成压缩与复读校验，再原子替换；不要复刻客户端忽略错误的行为。
// 本轮仅形成格式与风险依据，未修改客户端保存策略，也未运行登录或聊天回归。
