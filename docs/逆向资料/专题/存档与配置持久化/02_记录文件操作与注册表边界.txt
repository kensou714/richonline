// 此处只证明记录文件的管理操作，不把 .rcd 后缀当成内部录像格式证据。
// 未执行文件改名、删除或注册表修改；Windows API 语义用于解释静态分支。
//
// 对话框路由与路径生命期
// ----------------------------------------------------------------------------
// 761CA0：从三个 DWORD 参数取得界面位置与路径，将第三项存到对象 +72。
// 761D50：事件参数 a3==1 才关闭 UI116；command2 将该路径交 UI117（改名），
// command3 将路径交 UI118（删除）。这里存的是借用指针，没有复制字符串。
// 761EA0 和 7623C0 分别将改名/删除对象 +72 设置为传入路径指针。
// 路径所在上层对象必须活到确认操作完成；本专题尚未核定 UI104 路径容器生命期。
//
// 改名输入并非完整原文件名
// ----------------------------------------------------------------------------
// 761EA0：调用 753AC0 去掉目录及扩展名，再调用 753B70 缩短，填 control3。
// 753AC0 从末尾倒找 '.'，再倒找 '\\'；没有起点检查或目标容量参数。
// 因而依赖路径含反斜杠和扩展名，不能作为通用跨平台 basename 实现。
// 753B70：strlen>10 时统计前8字节的有符号负字节数量。
// 奇数则从字节7写入“...”；偶数从字节8写入“..”；最终字符串10字节。
// 这是特定多字节文本的截断启发式，不是 Unicode 字符/字素边界算法。
// 缩短后的显示名直接进入可编辑文本框；若用户不改就确认，可能用简写名改名。
//
// 762060：改名提交
// ----------------------------------------------------------------------------
// command10：取 control3 字符串；空值调用 this 虚表+160 回调后结束，不执行改名；
// 非空则向前查找旧路径最后 '\\'。
// 拼接：旧目录 + 新输入 + “.rcd”，传给 MoveFileA(old,new)。
// MoveFileA 成功才更新 UI104 路径并刷新，显示文本1004；失败显示1005。
// command11：取消并关闭 UI117。当前函数未见路径字符过滤或长度边界检查。
// MoveFileA 不覆盖已存在目标；权限、目标冲突等失败也走同一提示分支。
// 新名固定补 .rcd，不根据旧扩展名推导；输入已含后缀时也不会先去掉。
//
// 762480：回收站与永久删除
// ----------------------------------------------------------------------------
// 7622C0 初始化对象 +76 字节为0；control4显示复选框并注册操作。
// command4 切换该标志，更新勾选图像。
// command10 且 +76!=0：DeleteFileA(path)，成功/失败直接采用该 API 布尔结果。
// command10 且 +76==0：GetFullPathNameA(path,512,buffer)，再补第二个NUL；
// SHFileOperationA 使用 wFunc=3（FO_DELETE）、flags=0x454：
//   0x004 FOF_SILENT；0x010 FOF_NOCONFIRMATION；0x040 FOF_ALLOWUNDO；
//   0x400 FOF_NOERRORUI。ALLOWUNDO 请求可撤销删除，不保证所有介质都进回收站。
// 仅判断 SHFileOperationA 返回0；未检查 fAnyOperationsAborted。
// GetFullPathNameA 返回长度/失败未检查，随后 strlen；异常路径不安全。
// 成功刷新 UI104，显示文本1006；失败显示1007；command11关闭 UI118。
// 文本编号语义依成功/失败分支确定，未转录当前语言包的完整提示词。
//
// 注册表导入：不能误认为账号持久化
// ----------------------------------------------------------------------------
// 已枚举静态导入的 RegOpenKeyA / RegQueryValueExA / RegCloseKey。
// 962940、97779F：打开 HKLM\\Software\\Microsoft\\Direct3D，读取调用者给定值，
// 关闭句柄，并检查 API 状态及类型；属于环境读取链，不是账户写入链。
// 反编译把类型输出 DWORD 与数据指针均叫 Type，必须按实际 API 参数区分。
// 977841：读取同键 DisableMMX，若 REG_DWORD 且值非零则禁用缓存能力标志；
// 否则按 x86 处理器架构、处理器级别>=5、辅助检测决定是否启用 MMX。
// dword_A6B81C 缓存检测结果；没有写回注册表。
// 还存在 VisualStudio 7.1 Setup 路径引用，未在此批展开其库函数。
// 未发现直接 RegSetValue/RegCreateKey 导入；GetProcAddress 或其他模块路径仍须另查，
// 因此仅能说当前已审调用不是游戏账户注册表存档，不能断言整个客户端从不写注册表。
