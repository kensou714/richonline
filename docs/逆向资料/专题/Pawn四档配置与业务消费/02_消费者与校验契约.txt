// 押金表消费者：选项构造、选择读取、组合校验
// ============================================================================
// 档位访问器
//   0x7F2630 返回 count；0x7F26E0 返回 items 地址；输入档位均为DWORD。
//   unsigned cmp/ja 只接纳0..3；负数及大于3都走非法分支。
//   非法分支调用 0x922570 未初始化变量诊断；若诊断返回，仍取栈中
//   0xCCCCCCCC 返回。它不是“返回0 / 空表”接口，也不是边界钳制接口。
//   映射核对三张独立跳转表原字节，未把表后的调试数据计作函数指令。
//
// 0x75CE30 的局部选项显示，范围 0x75D03C..0x75D138
//   查控件12；经 0x64F200 取配置对象+64地址并解引用，作为四档索引。
//   分别调用count、items访问器，按 i<count 的signed比较扫描items[i]。
//   每项DWORD作为sprintf参数，格式来自文本库索引80，随后提交控件12。
//   count=1传16，否则传14*count至0x8E3610；不凭自动名定义为按钮数。
//   控件12末尾调用0x8F3FD0时使用界面对象+60的值恢复选择。
//   本批未闭合文本库索引80格式、控件虚方法及所有其他控件业务。
//   因此0x75CE30登记“局部完成”，完整声明块可核不等于整体语义已完成。
//
// 0x75E6F0 的局部选择读取，范围 0x75EC9B..0x75ED35
//   同样经0x64F200读取配置+64作为档位。
//   mode=3分支取既有Boss信息+98 DWORD，写入栈局部var_200。
//   其余分支查控件12，取押金items表后，以0x8F3B70返回值为索引直接
//   读取items[index]，写var_200；再次读取选择值存界面对象+60。
//   此局部未做 index<count 的二次核验，也没有空表保护。
//   var_200后续具体消息、资金扣除及服务端确认协议不在本批认领。
//
// 0x7F2790：成员检查，而不是 min/max 比较
//   参数顺序：(档位, 押金值, 模式)，this为共享配置对象。
//   mode=2或3直接AL=1；不会检查档位是否有效，也不会读取押金表。
//   其他模式：档位0..3扫描对应count个DWORD，相等即AL=1。
//   无匹配、非法档位、零或负count路径AL=0；大于8的count未限制。
//   本函数没有读取任何LMT double字段；不能称作金豆范围校验器。
//
// 0x7BA0B0：组合校验门，this为另一对象，参数为记录指针
//   记录+30 = 模式；+34 / +38 / +3C = 三个前置选择字段。
//   记录+40 = 押金值；+44 = 四档索引。
//   顺序调用：0x7B9EF0(mode,+34)，0x7B9F80(+38)，0x7B9FD0(+3C)，
//   0x7BA020(mode)，最后0x7F2790(+44,+40,mode)。任何门AL=0即退出0。
//   全部通过才AL=1；多个函数仅定义低字节，调用者用movzx al读取。
//   上述AL为RTC调用前的业务结果；正常出口还依赖0x91F6D0的寄存器
//   保持与返回行为，本专题不重新认领调试运行库契约。
//   伪码误标stdcall未体现ecx this；应以汇编的this保存和retn4为准。
//
// 三个前置表与模式门
//   0x7B9EF0：第二参数=1且模式2/3时通过；否则扫描this+228的3个DWORD。
//   0x7B9F80：扫描this+3B4的6个DWORD，与输入相等时通过。
//   0x7B9FD0：扫描this+6CC的6个DWORD，与输入相等时通过。
//   三表业务标签及生产过程未知，不凭字段位置命名地图/人数/期限。
//   0x7BA020：依次短路检查模式0、1、2、3、4，任一相等AL=1。
//   五个leaf谓词分别复用当前磁盘已核原证；MFC自动名不作业务依据。
//
// LMT消费边界
//   getter原证收录的五个直接调用者为启动、两个选项操作路径和组合门。
//   本批在这些可见调用路径中没有找到min/max八字段的读取。
//   这不是“金豆限制无效”的全局结论；间接别名与未声明范围仍需调查。
// ============================================================================
