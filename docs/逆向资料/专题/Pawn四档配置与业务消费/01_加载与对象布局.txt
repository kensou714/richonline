// 频道限制与押金配置：加载、对象布局、资源事实
// ============================================================================
// 命名依据
//   当前 Pawn.kpd 两条资源注释按 GBK 候选解码为“各类频道金豆限制”和
//   “各类频道押金数值”。加载器、选项显示与成员校验支持押金表解释。
//   未发现典当物品交易流程，不能把 Pawn 文件名直接解释为典当业务。
//   原字节与 ASCII 段键是事实；GBK 为阅读候选，未核运行时代码页。
//
// 生命周期
//   0x623EE0@0x623F8B → 0x60104E → 0x628C10 取得共享对象，随后
//   0x623F92 → 0x60264C → 0x7F1D70 加载 Data\Pawn.kpd；返回零则启动退出。
//   0x628C10 在 0xA76700 为零时 new(0xD0)，缓存并返回指针。
//   0xA76700 位于有磁盘原字节的.data，当前磁盘4字节为00000000；不是BSS。
//   完整汇编没有对象构造、memset 或逐字段初始化；不能认定未用槽已清零。
//
// 对象重建，偏移为字节
//   档位   段后缀   double min / max   int32 count   int32 items 起点
//     0     CHU       +00 / +08           +40            +44
//     1     ZHONG     +10 / +18           +64            +68
//     2     GAO       +20 / +28           +88            +8C
//     3     XIN       +30 / +38           +AC            +B0
//   每个 count+items 区块跨度 0x24；计数后有 8 个 DWORD 物理槽位。
//   最后一组槽位止于 +CC，恰好落在 0xD0 分配范围内。
//   “8槽”来自布局与分配交叉核验；加载器未执行 count<=8 的限制。
//
// 0x7F1D70 的有效加载路径
//   调 0x81B4C0 的返回值为零时，清理局部对象并返回0，不写共享对象字段。
//   非零时调用资源缓冲取得路径，再以 mode=2、preprocess=0 交给文本解析器。
//   依次查八个段：四个 LMT 段读 min/max，四个 PAWN 段读 num/item%d。
//   LMT 使用 0x924720 转换，ST0 以 fstp qword 写入八个连续 double 字段。
//   PAWN 使用 0x91F950 转换，EAX 以 DWORD 写 count 和每个 item。
//   min/max不是32位整数；4294967295不会在此步写成 signed -1。
//   num及item为32位转换结果；异常文本、溢出值的CRT转换细节不在本批认领。
//
// 当前资源快照
//   文件252字节，key=27，压缩体243字节，无尾部；解包453字节、45行。
//   四档 min/max：0..10000；9000..40000；40000..4294967295；0..4294967295。
//   押金0档：50,100,300,500；1档：1000,2000,3000,5000。
//   押金2档：10000,20000,30000,50000；3档：10,20,30。
//   0档与1档范围重叠9000..10000，1档与2档边界相接40000。
//   这是配置内容，不证明运行时范围比较采用包含或排除端点。
//
// 失败与容量边界
//   所有段定位、键定位、值提取返回值均未在加载器逐项检查；到尾部返回1。
//   “加载成功”只能代表通过最初资源入口且完成控制流，不能代表每项有效。
//   item循环从0开始，以 signed jge 与 count 比较；负count不会写任何item。
//   count>8可覆盖下一组count或越出对象，访问器和成员校验也不钳制count。
//   少写的槽不清理；重新加载不能假定旧item尾槽消失。
//   当前解析器mode2精确复制长度、不附加NUL，且不执行CR清除；具体格式
//   边界复用“文本段键解析与预处理”及“大厅URL读取与缓冲契约”的值提取契约。
//   0x81B4C0 / 0x81B7F0 完整资源打开/变换语义另专题核实，本批不扩写。
//
// 原证
//   证据/functions_raw.json：加载器完整本体、异常尾块、调用桥。
//   证据/bridges_constants_raw.json：段名、min/max/num/item%d磁盘窗口。
//   证据/reused_raw.json：getter与启动局部的完整来源，含文件哈希。
//   证据/resource_rows.json：资源身份、完整解包字节、逐行双编码阅读候选。
