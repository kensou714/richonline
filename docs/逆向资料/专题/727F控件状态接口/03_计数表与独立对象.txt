// 相邻入口的独立对象契约

// 728150与7281B0：WORD计数表
// ----------------------------------------------------------------------------
// 地址 = this + 0xEA0 + 10000*row + 2*column；乘法和地址计算保留32位。
// 728150读取WORD，add CX,1，再写回同一位置；65535递增为0，不饱和。
// EAX最终等于column参数位型，不是新计数；ret 8。
// 7281B0以movzx EAX,WORD读取，返回0..65535；ret 8。
// 本体没有行列界限、空this或对象容量检查，也没有锁或原子递增。
// 10000字节步长等于5000个WORD，但不能凭步长推断实际分配了多少行。
// row=0,column=5000与row=1,column=0计算到相同地址，说明越界列可能别名到下一行。
// 模型对非法索引只计算地址，不在真实进程读写它们。
//
// 7113A0代表消费（既有卡片专题局部复核，不重复计新增）
// ----------------------------------------------------------------------------
// 起始629C90返回对象保存为var_8；727890(var_8)提供row，v21提供column。
// 满足当前模式非0且限制v17!=-1时，7281B0读计数，再以32位+1和v17有符号比较。
// 超限会显示编号892文本并置v19=0；其余情况下经AB5368[v21]函数指针分派。
// 回调结果为0且v18非0时调用728150；不在限次条件下不递增。
// 计数65535时，“检查的+1”是32位65536，而“实际递增”仍可能回绕为WORD的0。
// v21来源、所有回调语义、限制对象和索引范围未闭合，不据此承诺完整限次玩法。
// 该计数表属于var_8对象，不属于正在操作的UI控件this。
//
// 728220：388字节记录末字段
// ----------------------------------------------------------------------------
// 从DWORD[this+4]取得数组，读取DWORD[base+388*index+384]是否不等于-1。
// 返回AL布尔，不判断整个记录是否有效，也不检测数组容量、负索引或NULL。
// 712750从628900取得接收对象，遍历index=2..6调用本函数。
// 若返回0则目标UI虚表+200接收1；若返回非0，另取693EE0记录值经7F85C0判定后
// 决定传1或0。不能把末字段!=-1直接命名为“按钮可用”或“已拥有道具”。
// 记录完整结构、填入-1的全部写入者、虚表+200真正状态含义尚未闭合。
//
// 727FC0：输入对象的左键双击沿
// ----------------------------------------------------------------------------
// 单函数只证明AL=BYTE[this+6]。已有736D10在627270取输入对象后调用它，
// 根据该值处理五个矩形候选项；此代表消费确认接收对象来源。
// 输入专题81DCA0在WM_LBUTTONDBLCLK(0x203)写+6=1，81DEC0帧末清+6=0。
// 因而在该输入对象上它是左键双击沿getter，不是本目录字体配置对象的+6。
// 普通构造、主循环提前返回和全部三个调用点仍沿用输入专题边界。
//
// 727F90：浮点字段getter
// ----------------------------------------------------------------------------
// fld dword ptr[this+540]将一个32位float载入x87 ST(0)；没有转换成整数。
// 仅观察到三个导航调用点，未采写入端、对象类型和单位，故不命名为缩放或速度。
// 局部加载与ABI可确认，字段业务含义保持未知；不与+344/+348拼成统一类。
