// 727F10原样传this和行参数给727F50；727F50调用8F4050读取行宽字符串，
// 再传给8E0590宽转窄，EAX一路返回。两个封装都没有复制到调用者拥有的内存。
// 已有8F4050：有符号比较index >= DWORD[this+804]则返回0；否则返回
// DWORD[DWORD[this+592]+160*index+8]。没有index<0检查；负索引可走计算分支。
// 指针来自现有行记录的+8，不代表复制、新分配或自动延长行内容生命期。
//
// 8E0590：260字节局部数组地址逃逸
// ----------------------------------------------------------------------------
// 8E0590 sub esp,104h；保存ESI/EDI后清零当前帧内260字节数组。
// 输入0或空串直接返回这个数组地址；并非返回NULL。
// 非空时，若全局ACC3C8+56回调非0，则调用callback(dst,src,260)。
// 无回调时调用WideCharToMultiByte(CP_ACP=0,flags=0,src,wcslen(src)+1,
// dst,260,NULL,NULL)，没有检查转换API返回值。
// CP_ACP是运行系统代码页，不是固定GBK、Big5或UTF-8；自定义回调语义未闭合。
//
// 两条真实返回锚点
//   8E05DA lea eax,[esp+10Ch+MultiByteStr]；pop edi；pop esi；
//   8E05E0 add esp,104h；8E05E6 ret。
//   8E060B pop edi；8E060C lea eax,[esp+108h+MultiByteStr]；pop esi；
//   8E0611 add esp,104h；8E0617 ret。
// 以函数入口ESP=S计算，EAX均为S-260；覆盖[S-260,S)的局部数组已经随帧回收。
// 这是静态可证的返回栈地址，不是全局共享缓存，更不是调用方拥有的稳定内存。
// 返回后内容碰巧尚未覆盖不意味着生命周期有效；封装随后还有RTC调用与返回。
// 独审复读0x91F6D0：正常快路径直接ret，慢路径保存并恢复EAX，不会替换该地址。
// 本专题未执行它，也未声称任何一处调用已实机崩溃或总能读到原内容。
// 即使行越上界使8F4050返回0，8E0590仍返回它自己的空局部数组地址。
//
// 窄转宽封装：不同的存储来源
// ----------------------------------------------------------------------------
// 727EC0：8E0650(narrow)后将结果和低byte参数交8FAE70编辑插入。
// 727FE0：8E0650(narrow)后交8F41B0列表按换行分段追加。
// 已有8E0650先清全局ACC3C8+108起0x5000字节；输入0/空也返回该共享地址。
// 可用全局+52回调(src,dst,10240)或MultiByteToWideChar(CP_ACP,0,
// src,strlen(src)+1,dst,10240)，返回值未检查。容量单位是WCHAR，非字节。
// 此共享宽缓冲可能被后续调用覆盖；与8E0590的失效栈地址是两种不同风险。
// 8F41B0临时把LF、可选反斜杠n位置写0后调用虚表+244，再恢复原字。
// 虚表回调是否保存输入指针、是否重入转换，不能由封装一侧保证安全。
//
