// ============================================================================
// GetFlags误名：实际是控件局部Y坐标
// ============================================================================
// 728120：ECX=this，读取DWORD[this+0x158]（344字节）至EAX，ret。
// 728060：ECX=this，读取DWORD[this+0x15C]（348字节）至EAX，ret。
// 本体没有范围检查、坐标变换或位运算。返回位型32位，符号由消费决定。
// CMFCToolBarsCustomizeDialog::GetFlags是IDA识别名称，不能推为MFC标志字段。
//
// 结构与写入端交叉证据
// ----------------------------------------------------------------------------
// 已有8E31B0写+344，8E3340写+348，分别与+352宽、+356高组合裁剪。
// setter先写目标，调用虚表+8，再依据+387标志选择是否约束在父对象尺寸。
// 父对象来自+400；无父时取全局根区域；然后向关联控件传播位置差。
// 完整传播、环与所有权边界沿用控件树/关联控件专题，不在本篇重算完成量。
// 因此+344/+348记为局部X/Y；不等于屏幕鼠标坐标或绝对坐标getter。
//
// 715140代表消费（复用4023系列原证）
// ----------------------------------------------------------------------------
// 获取编号100的参考控件尺寸，遍历1..32控件，读取局部X/Y和宽高。
// rand()%4选择方向，rand()%9+5选择位移；更新X或Y，做参考区域检查，
// 再经8E31B0/8E3340写回。此数据流排除了“位标志GetFlags”的解释。
// 7113A0也将同二字段与宽高组合后比较鼠标位置，作为代表交叉证据。
// 当前这些消费不证明所有控件可见、所有回调安全或任意负坐标均合法。
//
// ECX与栈参数
// ----------------------------------------------------------------------------
// 727F10/727F50保存ECX再传给下一thiscall，并ret 4；是带一个参数的对象封装。
// 727EC0/727FE0保存ECX，带文本和byte参数，ret 8；不是无this的纯__stdcall。
// 727EC0/727FE0先mov AL,第二参数再push EAX，高24位未在这里清理。
// 下游只读低byte；不要依据push宽度把参数推广成完整DWORD枚举。
// 727F90用fld dword ptr[this+0x21C]，返回在x87 ST(0)，不是EAX整数或内存double。
// 727FC0用mov AL,[this+6]；只有AL有效，不能假定EAX高24位清零。
// 728220用setnz CL再mov AL,CL，布尔结果在AL；EAX高位并非该布尔契约。
// 7281B0用movzx EAX,WORD[...]，因此返回0..65535；728150递增后EAX保留列参数。
// 名称、伪码返回类型和调用约定均需按这些真实指令校验。
