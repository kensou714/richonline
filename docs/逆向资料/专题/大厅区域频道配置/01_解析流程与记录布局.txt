// 三条路径的共同骨架（静态已核实）
// --------------------------------------------------------------------------
// 1. 调用 0x601369 获取对象，取其中的 URL 字段交给 0x609AF5。该调用及两个后续检查
//    均非零，才把取得的内容交给 0x60ACA7(a1=2, ..., a4=0/1)。
// 2. 查找 "area"，成功后读取 "areasum" 文本并用 atoi 转成区域数；
//    逐个查找 "area%d" 中的 "channelsum"，用 atoi 得到各区频道数。
// 3. 累加频道总数，按总数乘 308 字节分配频道记录，逐个构造；再依序
//    查找 "channel%d_%d"，填入与配置键对应的字段。
// 4. 正常填表结束，释放每区域频道数数组，清理解析对象，返回 1；
//    前置调用链或 "area" 查找失败的显式分支返回 0。
// 这些返回值是本函数局部结果，不证明网络连接已经建立。
//
// 差异（静态已核实）
// --------------------------------------------------------------------------
// 0x69EEE0：URL 地址为 0x601369 返回对象 +256（0x100），0x60ACA7 的 a4=0；
//   输出指针写 this+80、总频道数写 this+84。没有看到 LobbyType 键分支。
// 0x69F750：URL 地址为 0x601369 返回对象 +516（0x204），0x60ACA7 的 a4=1；
//   输出指针写 this+92、总频道数写 this+96。0x60D1BE 和四次
//   0x60DF8D(32,16) 在传入 URL 的 0x609AF5 调用之前执行。
// 0x6A0130：同样使用 0x601369 返回对象 +516、a4=1、this+92/+96；上述五次
//   初始化调用移到 "area" 查找成功之后、读取 "areasum" 之前。
// 0x623030 上下文伪代码显示 +256 对应 "login"，+516 对应 "server"；
//   该上下文未做字节校验，故这里只把字段名作为辅助线索，目标函数直接证明的
//   是偏移和参数值。两个 server 解析器不能据此认定运行时完全等价。
//
// 频道记录：跨度 308 = 0x134 字节（静态已核实）

//            69EEE0 不在本函数内设置该字段，不能推定默认值。
