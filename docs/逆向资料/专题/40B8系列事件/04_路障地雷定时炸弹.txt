// 40BC 路障（66DF70）、40BD 地雷（66E1E0）
//   包+6 signed WORD是地图格索引；使用动作42/43和“使用 卡名”提示。
//   694720构造601A / 8字节，默认+5、+6均为-1。
//   路障：+2位置，+4=11，+5=current，+6保留-1。
//   地雷：+2位置，+4=12，+5=current，+6=A870CC低BYTE（GValue19，当前3）。
//   此处未见handler对负位置或超地图上限的本地检查。
//
// 601A消费者67E370 -> 7E2380：
//   map=G+1628；occupancy=DWORD[map+60]+4*位置。
//   写occupancy+0类型、+1所属角色字节、+2额外参数；第四字节本链不写。
//   随类型更新资源、索引及刷新标记；没有地产归属判断要求。
//   动态物件完整添加/删除/渲染索引管理见对应专题，本节只确认本次写入契约。
//
// 地雷的视口分支
//   mode来自地图对象+24；63E160/63E1A0测试3，63E990/629E10测试4。
//   这些模式中，7E6DA0(map,index,1)==0时进入“当前视口未覆盖”路径。
//   7E6DA0由地图首DWORD取得G，再取G+3092的视口对象；参数1选+32四个signed WORD。
//   格索引转列/行，构造(col*64,row*48,col*64+64,row*48+48)矩形。
//   7D8440只测试其四个角是否落入视口；不是任意矩形相交的完备判定。
//   此路径先6005聚焦目标，将6003+6设0取消提示自身暂停，插601A后排6009等待1000，
//   再6005回当前角色位置。其他路径保留6003常规1000暂停，不加这组视口消息。
//   “提示时长1350”“队列暂停1000”和“视口切换”是不同参数。
//
// 40BE 定时炸弹（66E5A0）
//   公共动作44、包含目标名的提示后，排6064 / 6字节。
//   +2=target，+3=A87080低BYTE（GValue0，当前36），+4=current。
//   67FDC0对三个字节movsx，取目标P，调694640写P+1491=步数、P+1492=来源槽。
//   与40BA交换1491/1492形成相互印证；这是附身计数与来源，不是地图物件owner字段。
//   后续扣来源卡、current==local时恢复6006(1)。此handler没有B8/BA的狂暴保护门。
//   本事件只写入计数；每步递减、跨人传递、自然爆炸的完整生命周期应另专题跟进。
