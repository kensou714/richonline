// reset是局部写者：+04/+60/+78清DWORD，四+64 DWORD置-1，四+74 BYTE置0；

// rep movsd的22DWORD是DF=0前提下88字节；本体无cld，不把该长度当源容量。
// 完整writer的三个失败位置保留内容不同，AL0不等于回滚或R+04必空。
// 64CDC0(P,0)确沿实际保留栈参数，对P起始NUL结尾内容原地替换字节。
// 该副作用先于后续计数门；重置记录不回滚来源修改或已复制的R+08..5F。
// signed上限及两列表实际count不等于四槽容量证明；累计t无t<4门。
// 第二轮BYTE分类及DWORD列表可互相覆盖并进入状态或后续记录；动态可达性未证。
// 来源bit11经EDX的and/neg/sbb/neg规范为DWORD0或1，非保存掩码或旧位。
// 短writer先于6AB280后续UI门；6AAD70的packet+4门也发生在writer和两UI之后。
// 6ADEC0的低12位type4/12才调短writer；packet WORD均按实际signed域记载。
