// ============================================================================
// 清理与两种内容刷新 / 6A4DC0、6A4E70、6A51A0
// ============================================================================
// 地址按当前磁盘逐范围核验；原始指令见formal_functions.json对应va条目。
// M=this，B=DWORD[M+5D8]，R(i)=B+124*i。三个入口都不调用6B7D60索引门。
//
// 6A4DC0 / 派生字段清理
// ----------------------------------------------------------------------------
// 6A4DE6：DWORD[R+04]=0；6A4DFD：DWORD[R+60]=0；6A4E14：DWORD[R+78]=0。
// 6A4E46：DWORD[R+64+4*k]=-1；6A4E60：BYTE[R+74+k]=0。
// 循环unsigned k<4，名义四个DWORD及四个BYTE；retn4，没有规范BOOL返回契约。
// 不清R+00，不清R+08..5F，不分配、不释放R+04指向对象，也不检查B/N/i。
// 清理只是局部状态写入，不证明嵌套对象已销毁或其他消费者可用。
//
// selector / 三个WORD组成的局部选择值
// ----------------------------------------------------------------------------
// 64F200返回M+64，其+130 WORD即WORD[M+194]；第二WORD为low16(i)，第三WORD为-1。
// 调用前sub esp,8，写首DWORD和+4 WORD；保留的+6..7两字节未在本入口初始化。
// push kind后调82B090，caller add esp,12；kind5实际按第二WORD signextend查来源。
// 记录寻址用完整32位i，selector却截成16位，两者域相等依赖外部约束。
// 82B090这里只复核kind5/10/11/12/13的有限契约，其他case不算本批新增语义。
//
// 6A4E70 / 完整重建，AL表示局部结果
// ----------------------------------------------------------------------------
// 首先6A4DC0(i)；kind5返回P，6A4EE4写R+04=P。
// 6A4EFB检查DWORD[P+7C]非零，没有检查P本身非零。
// 源非零：ESI=DWORD[P+7C]，EDI=R+08，ECX=0x16，6A4F36 rep movsd。
// DF=0的调用约定下连续复制22DWORD=88字节，覆盖R+08..5F；本函数未执行cld。
// 本地不检查源长度、目标容量、重叠或DF；不能从复制长度推定整个来源对象大小。
// 随后push R+08，call627450取得ECX，再调用7BA0B0；push跨getter留给后者。
// 627450是A766B4惰性根getter，没有把该pointer当参数消费；不能按push邻接误读。
// 7BA0B0 AL假时再次reset，返回AL=0；已复制的R+08..5F不会被reset清除。
// 后续push0、pushP跨628EF0根getter，传64CDC0(P,0)。
// 64CDC0以BYTE NUL为停止条件，在P起始内容中替换A67342→A67343，原地写入。
// 不应把这个副作用写成R+08副本的回滚或来源对象的生命周期管理。
// 通过计数门及列表填充后AL=1；AL高位不作规范整DWORD BOOL解释。
//
// 失败后的字段状态
// ----------------------------------------------------------------------------
// P+7C为0：R+04仍是P；其他派生已清；88字节副本保持此前内容。
// 7BA0B0为假：R+04再清0；副本保持这次复制；外部根getter副作用未回滚。
// 计数超过R+3C：再reset并AL0；副本与64CDC0对P的原地修改均未回滚。
// AL0不等于整条记录恢复到调用前状态，也不等于R+04一定为空。
//
// 6A51A0 / 内容直接刷新
// ----------------------------------------------------------------------------
// 同selector/kind5；6A520B写R+04=P，6A5222直接读P+7C。
// 6A523D rep movsd，DF=0时同样覆盖R+08..5F的88字节。
// 不先reset、不检查P/P+7C、不调用7BA0B0，不重算计数/列表/BYTE分类/DWORD状态。
// R+60、R+64..73、R+74..77、R+78可能保留旧来源的派生值。
// retn4，没有AL成功结果契约；不能按完整writer的失败语义解释此入口。
