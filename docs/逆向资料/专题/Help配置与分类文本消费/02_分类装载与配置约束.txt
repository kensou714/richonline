// 公共装载流程
// ----------------------------------------------------------------------------
// 五个装载入口只在本类flag为零时执行；flag非零直接走返回，不重复打开文件。
// 81B4C0读取容器；返回零则清理临时对象并退出，flag保持零，下次调用仍可重试。
// 读取非零后调用81B7F0解包；本体没有检查解包调用结果。
// 819250以模式2、解包指针、长度和去CR标志0创建解析对象，复制输入数据。
// 五类各自创建解析对象；不是在一个共享游标上依次解析五类。
// 正常走完本类扫描后置flag=1，即使零条目或部分键未找到，也不能把flag当完整校验。
//
// OP与RULE
// ----------------------------------------------------------------------------
// 分别寻找大写节OP/RULE，再找小写num，读取容量128的临时文本并atoi为计数。
// 初始找节、找num不检查返回；缺失键不能认定自动使用零或其他默认值。
// count>0才申请count*512字节；从item0递增找键，首次找键失败结束。
// 每值写到array + index*512，传入容量512，并按编码谓词决定是否原地转换。
// 循环没有index<count条件；num控制分配长度，连续键控制实际写入数量。
// 条目多于num可能越界；少于num时尾部没有在本体中初始化，也不回填实际计数。
// num<=0仍会尝试item0；因此编辑器必须独立验证数量一致，不能只检查连续键。
//
// EVENT与NPC
// ----------------------------------------------------------------------------
// 大写EVENT/NPC节的num控制分配count*580；随后从event0/npc0递增找节。
// 这两类是编号节，不是OP/RULE的编号键；节匹配按解析器的大小写精确比较。
// 每条记录：+00 DWORD资源引用；+04名称缓冲64字节；+44描述缓冲512字节。
// id先按容量128读取并atoi；name/desc分别按64/512直接写入记录内部。
// EVENT用6DBA40(2,id,0,-1)的返回值写+00；不能把此字段继续当原始配置id。
// NPC先写id；id!=-1时改写为6DBA40(6,id,0,-1)返回值，-1则原样保留。
// 名称与描述在编码谓词允许时各自原地转换；资源引用的全局释放责任未在本体中证明。
// 和前两类一样，循环遇缺号停止且不比较num；各条id/name/desc找键结果也未检查。
//
// 小写prop重复节
// ----------------------------------------------------------------------------
// 69D510先反复找prop节累计实际数量，count>0时申请count*12字节。
// 69D656调用81A090(0,0)重置游标，再从头扫描相同名称的重复节。
// 每节只读id；+00存6DBA40(9,id,-1,-1)返回值。
// +04存693370返回的名称地址；+08存69DEC0返回的描述地址，不复制文本正文。
// 这两个地址属于627C20取得的外部表，分别为base+id*1128+660和base+id*1128+724。
// 本地未夹取id索引；借用地址的有效性依赖该表的装载与生存期。
//
// 文本与格式的实际边界
// ----------------------------------------------------------------------------
// 819470从当前节游标向后找节，找键819660每次从当前节起点扫描，遇下一节停止。
// 因而eventN/npcN编号节需按查找次序出现；相同prop节可重复，不能被通用INI库合并。
// 8198E0按行复制，以换行结束；高位字节按双字节处理，反引号+n转成换行。
// 它先写完再做容量断言，不是安全截断API；512/64/128是传参约束，不是防越界保证。
// 编码条件为64F000读取状态字段等于1；8190B0再按既有表改写双字节内容。
// 不能把这些ANSI字节按UTF-8字符数截断，或把未检查返回的缺键写成受支持输入。
