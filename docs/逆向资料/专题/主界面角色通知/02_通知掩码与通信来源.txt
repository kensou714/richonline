/*
 * 7053D0通知掩码与通信来源
 * ============================================================================
 * N是进程内通知结构，不是原样接收的网络包。
 * +0 DWORD flags；+4 DWORD角色槽s；+8 DWORD表情；+12 DWORD语音短句槽。
 * +16 DWORD文本指针；+20仅消费低BYTE的他人复活按钮启用值。
 * 只确认消费者读取布局；不据此推定全部通知生产者都初始化所有字段。
 */

// [执行次序] 0x100,0x1,0x2,0x4,0x8,0x10,0x20,0x40,0x80。
// 各项是独立if，可组合；不是switch事件枚举。
// 0x2与0x8同时出现时，0x8后写表情状态；0x10与0x20组合会后隐藏。

// [0x100] 找s对应面板；若b>=30，写W+431+b/15=1。
// 给他人复活按钮留下禁止启用标志。后续0x40即使N+20为真也禁用它。
// 本地面板15不写入；本函数没有反向清除此标志的分支。

// [0x1] 刷新控件1本地大头像。
// 7F76C0读取本地P+380头像ID、P+388帧编号，申请图像(type8,头像ID,帧+1,-1)。
// P+388的getter是7FDB70；IDA自动MFC命名不代表真实游戏字段。

// [0x2] 直接表情：若映射存在，R(s)+8=N+8，R+12=GetTickCount。
// s为本地槽时立即更新b+5小头像并显示b+10表情框。
// 他人槽只修改状态，后续708330刷新小头像。
// 小表情资源由709D30申请(type8,R+4,表情+13,-1)。
// 本分支不播放声音，不设置气泡文本。

// [0x4] 直接文本：将N+16指向文本交给b+9，显示b+8，并记录R+16。
// 不设表情、不播放语音；文本地址只能是客户端进程内有效指针。
// 未确认该通用文本控件接口是复制还是持有源指针，不据此设计异步生命周期。

// [0x8] 角色语音短句：role=R+0，phrase_slot=N+12。
// textID = (role<<8)+phrase_slot+1664，69B150。
// sndID  = 1000*(role+1)+phrase_slot+128，69B170。
// 读取文本、更新b+9、显示气泡、记录R+16；调用69A540(sndID,0,0)。
// expression = VoiceFace[role*stride+phrase_slot]，69AFD0。
// 写R+8/R+12；本地立即更新小头像并显示表情框。
// 69AFD0从音频资源对象+56取数组，+52取stride，没有角色/槽边界检查。
// 69A540受对象+8和首指针所指开关控制；底层返回声音句柄，末参0不保存句柄。
// 看见气泡不能证明声音实际播放，声音开关和底层资源仍可阻止播放。

// [0x10] 尝试显示复活按钮，并先设为禁用。
// 前提：s有面板、G+3664+s==0、G+3672+s==0、控件存在。
// 本地：W+432==0、状态545资格为真、地图mode==3，才显示b+13并禁用。
// 他人：G+3632+local非零，才显示b+13并禁用。
// 这是条件成立才显示的操作；失败时不自动隐藏原来已显示的按钮。

// [0x20] s有面板且控件存在时，隐藏b+13。
// 不直接清W+432..435，不等同于重置复活资格或复活完成。

// [0x40] 本地与他人分别更新可用状态。
// 本地前提：G+3640+local非零、G+3632+local==0、G+3664+local==0。
// 若28当前禁用、W+432==0、545资格真且mode3，则W+432=1并启用28。
// 他人b30/45/60：按钮已显示且G+3632+local非零，才更新。
// W+431+b/15非零则禁用；否则按N+20低BYTE启用/禁用。
// 本地启用不使用N+20；不要以同一个BYTE解释所有四个复活按钮。

// [0x80] 只刷新他人复活按钮提示，没有扣款。
// 点券P+1512 >= DWORD[A87100]：文本335，格式化点券费用。
// 否则金豆DWORD[G+1536+4*local] >= DWORD[A87498]：文本336。
// 否则文本337。优先级为点券、金豆、不足。
// 写W+304，并给可见的43/58/73设置提示；不为28设置该提示。
// 6FAB30把多字节文本转换后交给control+12文本对象；编码内部未展开。
// 缓冲128字节使用sprintf/strcpy，资源扩写须控制字节长度，不能只数中文字。

// [网络4041] 662920：先检查包+2 WORD GmsvID。
// 成功时构造flags2，N+4=包+4 signed BYTE，N+8=包+5 signed BYTE。
// 读取跨度至少6字节；该函数不包含长度检查，也不检查表情/角色范围。
// N的其余字段未赋值，但flags2只读取前三DWORD，因此不会在本分支消费余字段。
// signed BYTE会扩展负数，服务端不能把128..255当作普通正槽号发送。

// [网络4043] 先进入游戏状态G+20通知队列，队列细节见诊断消息专题。
// 64FBD0按约3000ms节流取一项，再构造flags8、角色槽、语音短句槽。
// 它只写N[0]/N[1]/N[3]；7053D0的flags8读取的恰为这些字段。
// 4043不是收包即播放，也不是客户端本地自动选择任意语音。
// UI0通知经6E4640的虚表+16同步转交；该桥接通用保护逻辑仍为局部分析。

// [边界] 通知入口未统一验证s/表情/短句范围。
// 映射存在降低了部分无效s风险，但不构成完整的资源合法性校验。
// 新增协议字段须审查实际生产者与掩码组合，不能复制未初始化的通知栈块。
