/*
 * UI0对象与角色映射
 * ============================================================================
 * 约定：W为UI0实例，G为游戏状态对象，P为角色对象，s为角色槽号。
 *       b为面板基号，只取15/30/45/60；role为角色资源编号。
 *       这些是本文便于阅读的分析名，不是恢复出的原始类型名称。
 */

// [入口] 构造6FAD70；虚表A242D0。
// 虚表+4  -> 7045A0 初始化；+16 -> 7053D0 接收通知。
// 虚表+20 -> 705C70 周期更新；+120 -> 7061F0 控件点击。
// 入口都经E9跳板，不能直接用虚表DWORD误认函数本体地址。
// 基础类构造和UI0全部其他虚函数未在本专题恢复；不宣称W的完整sizeof。

// [局部布局]
// W+72/80/88：三个8字节计时器，首DWORD阈值，后DWORD起始tick。
//             构造阈值30，初始化分别设置500/1000/1350。
// W+96：8个20字节角色UI状态槽；709E00把每槽五个DWORD清0。
// W+304：复活费用提示缓冲；到W+431共128字节。
// W+432：本地复活按钮启用的单次锁存位。
// W+433/434/435：他人面板30/45/60对应的禁止启用锁存位。
// 初始化7045A0清上述四BYTE；通知0x100只会写后三位，不写本地位。

// R(s) = W+96+20*s
//   +0 DWORD  角色资源ID；初始化读取P+40，getter691B70。
//   +4 DWORD  头像资源ID；初始化读取P+380，getter63E1E0。
//   +8 DWORD  当前表情编号。
//  +12 DWORD  表情更新时的GetTickCount。
//  +16 DWORD  气泡更新时的GetTickCount；0表示未计时。
// 初始化只对G+3640+s非零槽填入角色/头像ID；其余保持构造的0。
// 角色指针：63E230(G,s)读取DWORD[G+3584+4*s]。
// 本地指针：63F840(G)读取相同数组的G+8槽。
// 该数组访问不检查槽范围；P是否有效由调用者状态保证。

// [四个面板] 资源Intf的indx0指向G_TopBar.ui。
// b=15是“我的信息”；b=30/45/60为三个他人信息面板。
// b+5 ：小表情头像；本地20=my_smallface，他人35=ply_smallface。
// b+8 ：气泡容器；本地23=my_paopao，他人38=ply_paopao。
// b+9 ：气泡文本；本地24=Label2，他人39=Label21。
// b+10：表情框；本地25=“我的表情框”，他人40=Label7。
// b+13：复活按钮，编号28/43/58/73。
// 编号35既是面板30的小头像，又是7061F0的头像点击分支，不是复活按钮。

// [用户数据] 8E1570(control,index)读取control+420指针的DWORD数组。
// 8E15B0(control,value,index)写同数组；708330始终把映射写到index0。
// 两函数只比较index < 全局容量，未检查index >= 0；缺数组返回0或失败。
// 709D70使用W的控件树遍历b=15..60，取data[0]等于s的面板；没有则返回-1。
// 709D70伪码标为__stdcall不可信；汇编使用ECX=W，并retn4。

// [映射主干] 708330，所述路径已分析，其余金额/图标刷新仍为局部分析。
// 本地槽local = DWORD[G+8]，首先写入b15的data[0]。
// participant_count = DWORD[G+3616]，getter727820。
// 从(local+1)%participant_count按环形顺序扫描到local。
// 他人b从30开始，按15递增；槽是角色索引，不等于面板序号。
// 当G+3672+s非零且地图mode为3或4时，该角色可能被跳过，不占面板。
// 其余槽：G+3632+s非零显示正常背景；否则若G+3640+s非零使用备用背景。
// 两类仍把s写入data[0]；都不满足时写-1。剩余面板也置-1。
// mode存于地图对象+24；不要把63E160误认为返回mode的getter。
// 63E160读取地图+24，再调用63E1A0判是否等于3；它返回BOOL。
// count与local未在该主干统一校验，环形扫描也没有以b<=60为停止条件。
// 增员或改地图时须另核初始化约束，不能据八个状态槽宣称UI支持八面板。

// [过期] 708330尾部遍历已映射面板。
// 若R+8非零且当前tick-R+12 >= 2700，则清表情编号。
// 本地表情框b+10立即隐藏；他人小头像在下一轮刷新中用表情0恢复。
// 若R+16非零且当前tick-R+16 >= 2700，则清tick并隐藏b+8气泡。
// 705C70只在W+80计时器通过时调用708330；初始化阈值1000。
// 因而2700是判断阈值，实际消退依赖下一次面板刷新，不能称精准2700ms。
// tick为0哨兵，表情0也不参与同一过期分支；不能把所有表情都说成自动消失。

// [计时器] 81BCB0写阈值并记录GetTickCount；81BC80转交该设置。
// 81BD10仅当now > start且差值 >= 阈值时返回1，并重新记录tick。
// now <= start返回0；没有采用完整的DWORD回绕兼容比较。
// 帧循环频率、阻塞和系统tick回绕均可能影响观察到的刷新时间。
