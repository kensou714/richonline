// ============================================================================
// 4090..4096：入口、字段与实际操作顺序
// ============================================================================
// 原证：证据/handlers.json、dependencies.json、dispatch_dependencies.json。
// 七入口均先 6023CC -> 63E5B0(G)，得到 G+0x640 队列的当前 head 游标。
// CDialog::OnInitDialog 是错误库名；63E5B0 实际取队列 head，不能命名为窗口初始化。
// 随后 607A2F -> 64F710 比较 WORD[p+2] 与游戏 ID，不等时跳过本组操作。
// 身份检查原证复用 ../地图初始化同步/证据/map_sync_helpers.json。
// 本组入口没有独立长度参数或局部长度检查；signed 字段以 movsx 核对。
//
// 本地结构
// ----------------------------------------------------------------------------
// T30(data) 长24：WORD0=6003、WORD+2=30、BYTE+4=1、BYTE+6=1，
// DWORD+8=1800、+12=1350、+16=data 指针、+20=12。BYTE+5由构造器清0。
// data 为三个 DWORD {来源种类,标签/索引,文本指针}，不是网络包。
// S(action) 长12：WORD0=6002、WORD+2=action、BYTE+4=低8位 current，
// BYTE+5=0、BYTE+6=1、DWORD+8=1350。+7未初始化，不能称为稳定保留字节。
// C(a,减) 长12：WORD0=6060、BYTE+2=current、+3=0、+4=1、+5=1、+6=0，DWORD+8=a。
// 693320 写的是十进制24672，即6060；它不是6004等待事件。
// E 长4：WORD0=6080、BYTE+2=2、BYTE+3=-1；693BE0只默认写消息号和+3。
// 64FA50 按 cursor 复制结构并返回后继位置；每次入队再使用返回游标。
// 队列复制的指针结构不等于它已经深复制 data 或文本，见03。
//
// 4090 @669DD0 / 桥接7F0650 / 至少6字节
// ----------------------------------------------------------------------------
// signed WORD[p+4]只进入提示标签；A7A7CC={0,标签,RichStr[293]}，先排T30。
// 然后 ECX=G+0xCD0 调 694430，写该股票市场对象 DWORD+284=DWORD[A870C0]。
// 静态参数来自全局，不能仅凭文本“3天”把本次运行写值固定为3。
// UI 管理器 6279C0 -> 6E4020(35) 关闭 G_Stock.ui，随后排E。
// 原文293“股市暫停交易3天”。本 handler 没有遍历或改写每只股票价格。
//
// 4091 @669F20 / 桥接7F0670；4092 @66A050 / 桥接7F0690 / 各至少6字节
// ----------------------------------------------------------------------------
// 分别 A7A7DC / A7A7EC = {0,signed WORD[p+4],RichStr[295/296]}。
// 均只排T30 -> E；不具备4090的停市字段写入和关闭UI35操作。
// 原文分别“股市氣勢如虹全面上漲”“股市低迷不振重挫崩盤”。
// 涨跌文字不证明本 handler 调整行情；行情同步需联读股票专题4202/4203。
//
// 4093 @66A180 / 桥接7F06B0 / 至少12字节
// ----------------------------------------------------------------------------
// +4 signed WORD为提示标签；+8 DWORD为最终存款；+6..7没有被本入口读取。
// 先排6063长4：+2=current低8位、+3=1；再T30，A7A7FC={0,标签,RichStr[297]}。
// 紧接着以当前P依次执行：7F9DE0求持仓市值 -> 7FA0A0(市值,0)追加存款 ->
// 7F9950清持仓 -> 63F6B0(DWORD[p+8])直接覆盖存款。最后一步不是再追加。
// 7F9DE0对每个正持仓使用float现价*float数量、ftol2后以32位add累计。
// 7F9950对正持仓先回写市场数量，然后清P+1568+4*i数量与P+1608+4*i成本。
// +1504是现金，+1508是存款；这里不能把包+8写成现金或仅股票出售所得。
// UI35可见时6E4640(35,0)刷新；随后6E4640(32,0)刷新我的股票窗口，最后E。
// 上述刷新是虚表+16的数据更新，不是关闭窗口；伪代码GetCursorPos不可按字面解释。
// 原文297“變賣所有股票求現”；资金和持仓立即修改，6063状态实际待队列消费。
//
// 4094 @66A390 / 桥接7F06D0；4095 @66A5D0 / 桥接7F06F0 / 各至少8字节
// ----------------------------------------------------------------------------
// 标签=signed WORD[p+4]，a=signed WORD[p+6]。
// 先以ECX=G+0xC5C调用693CE0(a)：DWORD[G+0xC80]+=a；不是直接改P现金。
// a分别代入RichStr[319/320]，写文本A7A820/A7A8D0；data A7A80C/A7A8BC={0,标签,文本}。
// 入队顺序T30 -> S(69B040(a,DWORD[G+0x1475C])) -> C(a,减)。
// 69B040：a<1000*scale返回15，a>=5000*scale返回13，其余14，32位乘法无溢出保护。
// 在C被消费之前，693220(P,a)比较 signed32(P.cash+P.deposit)>a；只有严格大于才排E。
// 等于、资金不足均不追加E；不能误写为>=，也不能因此声称该回合一定永久卡住。
// 该分支后续缺钱/破产路径属于其他事件；这里记录继续条件，不替它补发确认。
// 原文319“車輛年檢繳納%d元”；320“違規駕駛罰款%d元”。
//
// 4096 @66A810 / 桥接7F0710 / 公共读取至少6字节
// ----------------------------------------------------------------------------
// M.mode=DWORD[M+24]；模式3走7B2E20，模式4走807CD0，其他模式不追加任何记录。
// 两个helper都收到(G,p,&cursor)，读取signed WORD[p+4]作为当前模式新闻表索引。
// 下游按表记录DWORD+0类型分派；返回非0才由4096追加E，详见02。
// 不能把“至少6字节”当成4096所有分支长度；下游还有DWORD和变长数组读取。
