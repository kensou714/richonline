// 语义资源索引：角色、建筑、NPC与特效
// ============================================================================
// 6DAA10解析下划线资源名，6DBA40按类型和数字坐标返回运行时图像槽。
// 字符串函数在IDB被误标为CFile::GetFilePath；这里按函数体重新解释。
// 运行时槽是每个12字节映射记录的+4 DWORD，不是NP文件编号。
//
// 参数
//   type、main、subA、subB；每类main均要求>=0且小于该类记录数。
//   无效返回-1。subA/subB在6DBA40按unsigned范围比较，负数通常失败。
//   下列地址式是对应类数组起点之后的字节偏移，最后读取DWORD。
//
//   类型  名称      记录内偏移                                 子索引范围
//    0    road      180*main + 12*subA + 4                     subA 0..14
//    1    thing     12*main + 4                                无
//    2    event     120*main + 12*subA + 4                     subA 0..9
//    3    build     1200*main + 120*subA + 12*subB + 4         各0..9
//    4    vehicle   480*main + 120*subA + 12*subB + 4          subA0..3/subB0..9
//    5    role      4800*main + 1200*subA + 12*subB + 4        subA0..3/subB0..99
//    6    npc       1200*main + 12*subA + 4                    subA0..99
//    7    fx        12*main + 4                                无
//    8    mood      1200*main + 12*subA + 4                    subA0..99
//    9    card      12*convertedMain + 4                      先经60DD17转换
//   10    other     1200*main + 12*subA + 4                    subA0..99
//   11    extend    12*main + 4                                无
//
// 角色资源合作边界
//   role名称可带main、subA、subB三数字，四个subA组各有100槽。
//   本函数证明容量与索引，不单独证明100槽中每个动作名称或四组的朝向顺序。
//   实际动作/方向由角色子对象的状态消费者建立，不能凭文件名自行补表。
//   图像资源专题负责NP解码、帧时间和运行时缓存，本专题只描述语义索引。
//
// 与ANIM.surf的区别
//   6DAA10是一般资源名解析，支持12类；
//   7A5910是动画清理范围解析，只支持other和npc，最后两个数字是闭区间。
//   不要把other_15_28_29当作普通单图像资源名，也不要在surf里填role。
//   两个解析器存在扫描下划线不检查字符串结束的问题；
//   编辑器应先按字段数、整数范围和资源存在性校验，不依赖客户端拒绝。
