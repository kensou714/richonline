// ============================================================================
// NewProps与CombCard / 同一管理器，三组数组
// ============================================================================
// M为ECX指向的管理器；偏移全部以字节计，避免DWORD索引与字节混读。
// 627C20：A766E0为空才申请0x14C字节并经610760构造，之后返回缓存。
// 7FEA80本体清M+0、+8、+C、+94、+98及其他数组指针；未清M+4或M+90。
// 不把未写的count/limit宣称默认0；正常旧表加载及本批NewProps加载承担各自写入。
// 三组数组不是三个独立管理器，也不把源码类名从IDA自动库名恢复出来。
//
// 已闭合字段
// ----------------------------------------------------------------------------
// M+00 DWORD：旧道具数组基址；M+04 DWORD：旧道具数量。记录步长0x468=1128。
//   805380按index*1128取首DWORD，首DWORD!=-1则AL=1，否则0；无本体索引检查。
//   8009A0在signed i<M+4内调用该判断，成立才复制两组QWORD：
//   旧记录+2C -> +1C，+34 -> +24，均通过x87 fld/fstp完成。
//   这是已有数值恢复，未清表、未清NewProps/CombCard、未释放内存。
//   未把QWORD业务命名为售价/租金；x87动作不等于按字节memcpy或源码double已恢复。
// M+08 DWORD：合成数组基址；M+0C DWORD：合成数量。记录步长0x3C=60。
// M+90 DWORD：NewProps的PRI/limit数值，atoi结果原宽度保存。
// M+94 DWORD：NewProps的NEW节数量；M+98 DWORD：8字节记录数组基址。
// 旧期限getter800AD0/800B30/800B90读旧1128B记录+68..100，与两新数组无关。
//
// 合成记录 C，60字节
// ----------------------------------------------------------------------------
// C+00..47：8个6字节源槽S；S+0 WORD编号、S+2 WORD所需匹配slot数、+4/+5为BYTE。
// 800BF0对src0..src7分别读取逗号字段0/1，atoi结果只保存AX至S+0/S+2。
// 800FD0读取两者均movsx，运行比较按有符号16位；不是无符号需求数量。
// C+48 DWORD：本节实际连续src键数；范围0..8，由加载循环终止下标写入。
// C+52 DWORD：dest数值；C+56 BYTE：strcmp(enable,"true")==0。
// C+57..59未在loader或7FEA30显式写入，不据分配器推断padding全零。
// 7FEA30先调用vector构造迭代器构造8个6B槽，后写+48=0,+52=-1,+56=0。
// callback为609695 E9 -> 7FEA30；槽callback6009E1 E9 -> 7D5BD0。
// 7D5BD0写S+0 WORD=FFFF、S+2 WORD=0、S+4 BYTE=0、S+5 BYTE=FF。
// 未填src槽保留这些构造初值；末两BYTE不是一个默认0的WORD。
// loader及本批消费不读取S+4/+5，不把它们自行命名为概率/状态。
//
// NewProps记录 N，8字节
// ----------------------------------------------------------------------------
// N+0 DWORD：NEW/prop；N+4 DWORD：NEW/pri，分别从原键读取后经atoi写入。
// 8015B0只扫描N+0与参数DWORD完全相等，首个相等返回AL=1，全无相等返回0。
// signed i<M+94，数量非正不读数组；count正而指针NULL没有本体防护。
// 该函数不读取limit或pri，不区分重复prop、价格、优先级或上限。
// 字符串常量A2E12C/130/13C/148直接分别为NEW/PRI/NEW/pri加NUL。
// off_自动名不表示运行中先DWORD解引用；80135F等指令push直接字符地址。
//
// 字段归属依据：02各字段写点详见03，消费读点详见04；磁盘块原证见证据目录。
// 以上为有限结构布局，不提供可直接编译的恢复类，不认领原始源码类型与全部成员。
