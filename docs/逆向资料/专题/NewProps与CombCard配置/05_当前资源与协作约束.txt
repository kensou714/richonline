// inspect_resources.py只读解包、保留物理节顺序与重复键，写作者证据副本。
// 它是严格离线解析器，不把其strip/整数验证行为冒充原客户端容错。
// 作者与独审分别复算容器源SHA、长度、解包SHA；当前样本无尾部额外压缩字节。
// NewProps.kpd：216B，key39，raw990B，packed207B；37节、148行。
// 第一节PRI/limit=5，后36个NEW均有prop/pri；当前pri全部0。
// NewProps可用CP950严格无损往返；既有37节与编码成果严格复用，不再次认领发现。
// CombCard.kpd：260B，key42，packed251B；
// raw437B，6个ITEM、37行；GB18030可严格往返且中文注释可读。
// 编码往返是当前样本事实，不证明运行时CP_ACP、完整GB18030支持或统一代码页。
//
// 当前六配方，括号是所需输入slot个数
// ----------------------------------------------------------------------------
// 1044(8) -> 500；1038(8) -> 504；1062(8) -> 505。
// 1070(2)+1051(1) -> 1052；1181(4) -> 506；1058(3) -> 1121。
// 当前全部enable=true，src从0连续且没有重复键；样本没有零源或重复source。
// 六配方用途名称需另联Prop/RichStr，不凭注释文字给编号编造业务名称。
//
// 编辑器与合作预检
// ----------------------------------------------------------------------------
// 保留重复ITEM/NEW和原顺序，不能用INI字典把同名节覆盖成一个记录。
// PRI应在消费NEW之前，limit、prop、pri、dest、enable都必须存在。
// src从0连续，1..8项；编号与需求限制可表示为有符号16位并要求需求>0，
// 各source需求的组合需按原算法实际slot分配检查，不能只验总需求<=8就承诺正确。
// dest范围要同时适配DWORD检查与最终低WORD存储；这是编辑器要求，非原程序验证。
// enable只认完整小写true，不trim尾空白；TRUE、1和true后空格均不能当启用。
// 819470/819660按字节精确段键匹配；共享暂存、无独立锁，不能承诺线程安全。
// 所有解析资源保留LF、闭合右括号及等号；缺键时不得继续按空值假定。
// 8198E0以原始LF结束，819A20按逗号字段/原始LF，二者先写内容和NUL，
// 后做容量断言；传128不是安全截断。高位字节按双字节读取，反引号n转LF。
// 数值输入缓冲最多127输出字节加NUL是合作预检上限，不是client提前保护。
// atoi调用者未验证合法数值/溢出；预检须检查整串、范围和输出编码。
// 本批不启动游戏、不编辑或重封包资源、不打补丁、不把静态解析当实机回归。
