// 入口65E680以ECX=M=G+0x65C调用7E3B80(new,old)。
// 地产记录R=DWORD[M+56]+68*index；动态格M+60不在这条链中。
// 7E3B80遍历index<M+36总格数，仅比较signed BYTE[R+3]是否为old。
// 匹配时先7E3E60(old,index)，再7E3C00(new,index)；不在入口筛选地产kind。
// 因而必须保留服务器合法角色域，不能把old=-1当作普通倒闭主体。
//
// 解除旧归属7E3E60
//   kind=12、建筑种类=2，且7E4B10表中存在{格号,old}时，7E4F60清匹配项。
//   表指针M+304，项数M+308，每项6字节；清理只把首WORD格号写-1。
//   无论上述特殊门控是否通过，R+3最终写-1。
//   分类2按{kind,变体0,-1}重取地块句柄，写R+24。
//   建筑种类10时再7E73F0重取建筑句柄；这是特殊视觉更新，不是拆除建筑。
// 不清空该格建筑种类、等级或整个6字节特殊记录；不作资金结算。
//
// 赋予新归属7E3C00
//   R+3写new低8位。
//   默认显示序号为new；模式3才按G+3672分类字节选择64FD40或64FDE0映射。
//   分类字节0从0累计，其余类别从4累计；G来自DWORD[M+0]而非把M当G。
//   地块句柄=6DBA40(分类2,kind,显示序号+1,-1)，写R+24。
//   建筑种类10时刷新7E73F0；本函数不增加建筑等级。
//
// 建筑种类10消费者7E73F0
//   仅kind11/12进入；等级0直接把R+28写-1。
//   非零等级且owner!=-1：分类3、种类10、变体0、帧子索引0。
//   非零等级且owner==-1：分类3、种类10、变体1、帧子索引0。
//   其他建筑使用{分类3,建筑种类,等级-1,0}；本次归属改变不逐类调用该分支。
// 解除和重新归属顺序会使种类10先取中立再取新归属图，不能省略成一次owner写入。
//
// 图像域与当前样本
//   分类2是6D8130装入图像管理器的event.dat，kind11/12为小/大地产格。
//   分类3来自build.dat；BUILD_10资源名为“碉堡”，提供中立/已归属两张图。
//   6DBA40返回运行时槽句柄，不是npid；未找到合法记录时可返回-1。
//   表中的npid再通过既有图像加载链映射到Tex分组NP文件，不在此处发送网络消息。
// 当前已检查E_11_S_0..5、E_12_S_0..5和B_10_L_0/1_F_0的NP容器与头。
// 完整分类容量、所有角色/地图资源或实际绘制成功不能由这14个样本替代。
//
// 提示文字与继续阶段
// RichStr328的%s分别来自old和new角色名；来源对象是P，而非地图或UI77。
// 649A30将文字分段写入340字节环形记录，并推进写入/显示索引。
// 超过环容量会覆盖最旧记录；-32768只是本次写入的属性值，本专题不强行命名。
// 主状态<12时另以事件128进入文字记录入口7DCFE0，不能把它误认作socket上行。
// 401D、归属写入和提示入环主干未构造6090/6080，也未调用动画完成回执。
