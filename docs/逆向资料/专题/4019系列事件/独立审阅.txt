// 401A：状态标签更新与等待窗口生命周期
// ----------------------------------------------------------------------------
// GmsvID 通过后，主状态必须不等于 12，且 G+3672+槽的分类字节为零。
// 处理器构造 {1,显示序号,原角色槽}，调用 UI 管理器的槽 77 更新入口。
// 0x6E4640 只在槽对象存在时调用虚表 +0x10，没有为缺失 UI77 创建对象。
// 0x739500 在返回前消费该栈载荷，不保存载荷指针，不读第四 DWORD。
// 载荷首值 1 选择控件 21+显示序号，以原角色槽取角色名；首值 0 选择服务端标签 20。
// 正文没有把其他首值、缺失控件或无效显示序号误写成受支持输入。
//
// 0x64FD40 非模式 3 原样返回角色槽；模式 3 按分类零的槽进行压缩编号。
// 循环上界为 G+3616；未命中返回累计数量，不能据此假设非法槽也会得到有效控件。
// 0x64FDE0 对非零分类从显示序号 4 累计，用于归属图像映射，不是 UI77 的额外标签证明。
// 当前资源 UI77 确实只有四个玩家标签 ID21..24，提示图为 ID10，服务端标签为 ID20。
// 0x739410 按配置序号选择一张提示图，更新序号并隐藏标签，不产生动画完成回执。
//
// 连接准备成功分支先切主状态 1，再打开 UI77；401A 本身不执行这一步。
// 4010 的 packet+6==0 且原主状态为 1 分支切到 2、关闭 UI77，再打开游戏界面。
// packet+6 非零另走延时/队列分支；所有标签亮起也不能证明 4010 关闭条件已发生。
// 窗口关闭与延后释放是两个阶段，UI pending 不能混作回合或网络 pending。
//
// 401D：owner 转移、特殊记录与图像重取
// ----------------------------------------------------------------------------
// +4/+5 是 signed BYTE 新/旧归属；0x65E6DE 把 ECX 调整为 M=G+0x65C。
// 0x7E3B80 遍历 M+36 总格数，仅以 M+56 数组中 68 字节记录的 owner 匹配旧归属。
// 匹配后按“解除旧归属 -> 设置新归属”依次调用，不先筛地产 kind。
// old=-1 可以命中未归属格，因此正文保留合法角色域必须由上游保证的边界。
//
// 0x7E3E60 对 kind12、建筑种类2且特殊记录存在者清一条匹配记录的首 WORD。
// 特殊表来自 M+304，项数 M+308，步长 6；不清整个记录，也不直接结算现金。
// 随后 owner=-1，按分类2/变体0重取 R+24；建筑种类10另刷新 R+28。
// 0x7E3C00 写新 owner；模式3按分类映射显示序号，再取分类2/变体(序号+1)图像。

// 独立确认分类查询边界：0x6DBA40 默认返回 -1，只有合法索引才读运行时句柄槽。
