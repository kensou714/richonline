// ============================================================================
// 三个入口的字段ABI和对象归属
// ============================================================================
// 310注册 -> cdecl(G,packet)桥接 -> ECX=G、push packet -> thiscall业务处理器。
//   4019：601918 -> 7EF9D0 -> 6039D4 -> 65E310。
//   401A：607C28 -> 7EF9F0 -> 609672 -> 65E380。
//   401D：60A31F -> 7EFA50 -> 603371 -> 65E680。
// 三个业务入口均以ret 4清理packet参数；65E310伪码的stdcall标签不代表没有this。
// WORD[packet+2]通过64F710与WORD[G+83844]比较，不符弹Error GmsvID并退出。
// 本专题复用动态专题该函数原证，不重复导出或宣称新增完成。
// 本组处理器未校验包长和角色下标；下面是业务读下界，不是完整帧封装长度。
//
// 4019：65E310，业务读取下界30字节
//   +2 WORD：身份核验。
//   +4 signed WORD：角色槽i，movsx后用于G+0xE00指针数组索引。
//   +6..+29：原样24字节，传给7F46F0。
// 65E357读取P[i]放入ECX，7F46F0执行memcpy(P+1520,packet+6,0x18)。
// 没有图标刷新、按ID叠加、材料合成、本地通知或网络发送。
//
// 7F86A0的group0 ID读取及7F8780插入循环证明：
//   group0共8槽，每槽6字节，首signed WORD为ID，下一signed WORD为数量。
// 因而24字节仅覆盖槽0..3，不写槽4..7；不能把它改写成48字节或8个3字节记录。
// 这一长度差异必须保留；究竟是协议设计的局部同步还是历史缺陷仍需捕包。
// memcpy只覆盖固定区段，不核对ID/数量、未查角色槽，返回值不是服务端确认。
// 4019不会自动安装或清除等待阶段；后续库存消费者另见4050与道具专题。
//
// 401A：65E380，业务读取下界6字节
//   +2 WORD：身份核验。
//   +4 signed WORD：初始化完成的角色槽i。
// 条件：主状态62A0F0()!=12，且63F390(G,i)==0。
// 63F390只读BYTE[G+3672+i]；此处不把该字节统一命名为玩家/BOSS枚举。
// 传给UI77的栈上DWORD载荷：{1,64FD40(G,i),i,未使用的第四DWORD}。
// 首值1选择角色完成分支；显示序号不一定等于原角色槽。
// 64FD40：模式不是3时原样返回i；模式3时只对分类字节0的槽压缩编号。
// UI调用为6E4640(UI管理器,77,&载荷)，若槽对象为空则跳过消费。
// 没有调用窗口显示入口；收到401A本身不会补建尚未创建的UI77。
//
// 401D：65E680，业务读取下界6字节
//   +2 WORD：身份核验。
//   +4 signed BYTE：新归属槽new；+5 signed BYTE：旧归属槽old。
// 两字段都movsx到DWORD；以ECX=M调用7E3B80(new,old)。
// 随后取P[old]+112和P[new]+112两串，以RichStr328执行sprintf。
// 本地128字节缓冲中的格式为“%s倒閉，名下地產歸 %s。”，参数依次old、new。
// 容量依据65E77F/65E787的RTC描述：栈偏移-144、长度128；伪码Buffer[132]不准确。
// 原始描述数据见证据/rtc_buffer.json，并由build_review核对当前磁盘20字节。
// 文字送649A30环形提示记录，属性值-32768，来源串为空。
//
// 输入约束
// 三个入口均不钳制负角色槽、槽数量或空P；不能把signed字段写成0..255无符号范围。
// 401D的old=-1还会使遍历命中未归属记录；正常服务端值域必须另证。
// 这些是静态缺少检查的边界，不等于正常通信已复现崩溃或服务端可以任意发送。
