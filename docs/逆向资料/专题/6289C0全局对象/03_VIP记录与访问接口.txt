//   7DBE50 的普通等级资源加载成功后调用该函数。
//   打开 Data\\VipLev.kpd，第一次遍历连续 [ITEM] 段，计数写 O+8。
//   条数大于 0 时申请 136*(O+8) 字节写 O+0xC，再回到文件起点
//   逐 ITEM 填表。未见按 level 值排序，数组顺序按文件中的段顺序。
//   当前资源 4 条，level 为 0、1、2、3；VIP 级别和普通等级不同表。
//   文件不存在的分支不填子表；7DBE50 本身仍沿其成功路径返回 1。
//   该函数返回局部解析对象清理调用的值，不能误写成 VIP 加载成功标志。
//   重复加载时的旧数组释放与异常路径尚未闭合。
//
// VIP 记录 / V=O+0xC 数组元素，条宽 0x88
//   V+0x00 DWORD：level，当前资源为 0..3。
//   V+0x04 BYTE[128]：name，会员名称。
//   V+0x84 DWORD：icon 解析结果；文本 NULL 写 -1，其他文本查图标索引。
//   当前 level0 的 icon 为 NULL，其余为 other_14_85/86/88。
//
// 访问器 / 六个入口的真实目标
//   607C64 -> 6B78C0：按普通等级索引取 role，即 R+0x88。
//   602967 -> 797880：返回普通等级 title 缓冲区地址 R+0x08。
//   607B38 -> 7DC640：计算当前等级经验进度的百分值；末级直接 100。
//   60D853 -> 7DC730：按 VIP level 线性查找 icon；未找到返回 -1。
//   611426 -> 7DC7A0：按 VIP level 线性查找 name；未找到返回
//                       unk_A2D660 的借用地址，文本内容另核。
//   601BD9 -> 7DC8A0：按普通等级索引取下一等级 exp；末级返回
//                       本级 exp。两分支均直接按索引读取。
//   这些接口自身不校验传入的负索引或超界索引；调用者输入约束需另核。
//
// 经验进度边界 / 7DC640
//   若等级参数等于 O+0-1，立即返回 100。
//   若经验达到最后一条 exp，同样返回 100；经验为负或低于本级
//   exp 返回 0。其余按 (经验-本级exp)/(下级exp-本级exp)*100 转整数。
//   伪码显示的 64 位临时变量来自反编译类型恢复，不作接口宽度断言。
//   分母为零、等级参数超范围、O+0 为零等异常输入行为未闭合。
