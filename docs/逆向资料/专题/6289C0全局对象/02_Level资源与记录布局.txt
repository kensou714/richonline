// 当前资源身份
//   文件大小 630 字节；SHA256
//   daa7e5c8a1a3af9dab15af72aad52cbe15689fbcd0ba9e03f56ff88f8019fe54。
//   解码为 2528 字节 CP950 文本，严格编码往返一致；解码 SHA256
//   8866a82137d018711436365ce448d3de4ce5aa1a705279a9fb23901bc84114c9。
//   当前有 [all] 和 [level0] 至 [level20] 共 22 段；[all] num=21。
//   这些是当前资源事实，不是引擎支持的等级上限。
//
// 加载顺序 / 7DBE50
//   先读 [all] 的 num，atoi 后写 O+0，以 160*num 申请 O+4 数组。
//   从 i=0 起拼出 level%d；找不到该段即停止，逐段写 i 和各字段。
//   当前所见循环没有在写记录前比较 i 与 num；num 小于实际连续段数
//   时可能越界，仍须用函数块和实机测试确定完整错误行为。
//   IDA 将 160*num 分配调用自动命名为 MFC 工具栏 AddCommand；
//   该名称与数据流不符，不用作业务解释。
//
// 每条 0xA0 字节记录 / R=O+4 指向数组中的一条
//   R+0x00 DWORD：level 段序号 i。
//   R+0x04 DWORD：exp，经 atoi 转换的升级经验门槛。
//   R+0x08 BYTE[128]：title，称号文本缓冲区。
//   R+0x88 DWORD：role，可拥有角色数。
//   R+0x8C DWORD：card，功能卡片格子数。
//   R+0x90 DWORD：cqCard，传情卡片格子数。
//   R+0x94 DWORD：func，功能道具格子数。
//   R+0x98 DWORD：avatar，装饰品格子数。
//   R+0x9C DWORD：icon 解析结果；先写 -1，键存在才改写。
//   字段用途由资源原文注释支持；运行时具体消费仍须对访问器审阅。
//
// 当前资源取值特征
//   exp 从 level0 的 0 增至 level20 的 15000，分段递增。
//   role 在 level0..7 为 1，level8..12 为 2，level13 起为 3。
//   所有现有级别的 card、cqCard、func 均为 8，avatar 均为 32。
//   icon 为 other_14_85 至 other_14_94 系列，当前各条均有该键。
//   这些常量不应硬编码为客户端可扩容上限；应以对应消费代码判断。
//
