// 474个启发式候选
//   在非可执行PE区按DWORD对齐寻找至少3个连续可执行区代码地址。
//   已通过COL完整链确认的14表不计入这474候选。
//   43入口候选125个、4入口117个、3入口101个，其余131个长度更大或不同。
//   这些可包括虚表、回调表、相邻数组、分派表或其它指针集合。
//   代码地址能落入可执行区并不证明地址是函数入口，更不证明每槽已恢复语义。
//   每个候选保留起点、全部连续指针和前DWORD，仅供后续按构造写入/虚调用定位。
//   此474项均不计函数业务审阅、已确认类数或已确认结构体数。
//
// 需要保留的漏项边界
//   只扫描PE32磁盘raw映射，不含运行态动态生成/改写、纯虚拟零填充数据。
//   TypeDescriptor只接受ASCII .?AV/.?AU类型名、4B对齐、spare=0、@@结尾。
//   COL只接受signature=0及有已验证TD的经典x86链；其它RTTI版本待独立解析。
//   不扫描可执行区里的数据，不覆盖非对齐或不足3项的无RTTI表。
//   连续数组中的真实边界、重叠表、纯虚桩、导入槽等情况仍需使用者证据。
//   RTTI可被编译选项关闭、链接合并/裁剪；本专题不凭现存数量推测全部原始类。

// 合作时提升候选等级的证据
