//   62B590 / 91C040先默认构造exception；回写各自表，再构造E+12短字符串。
//   62C7B0 / 91C230先拷贝exception，再复制源E+12到目标E+12。

//   62B620 / 91C0C0以E+12调用62B8E0取data；伪码没有表达ECX偏移。
//   E+12是28B字符串成员，布局依据短字符串与缓冲所有权专题。
//   已确认成员操作范围至少到E+39；不能凭本专题把全部派生对象尺寸强制为40B。
//   length_error / out_of_range仅调用logic_error构造、拷贝、析构后调整+0表。
//   ios_base::failure同样调用runtime_error对应操作后调整+0表。
//
// 删除包装与普通析构
//   表slot0多解到标量删除析构，参数flag低位1决定是否operator delete(this)。
//   普通析构中的“回写本类表 -> 清理成员 -> 清理基类”不代表在调用虚业务动作。
//   本批删除包装保持原this作为返回值；retn4说明本包装清理一个栈参数。
//   原始flag读取为DWORD、仅最低位生效；伪码char类型不能用于恢复完整原型宽度。
//   92直接调用跳板的原字节已核；外部delete、malloc、free算法未在本批完整审阅。
//
// locale / ios
//   facet构造7DB7B0写+0表、+4参数；析构7DB840只回写表，删除包装另行释放对象。
//   _Locimp构造91D750：facet(1)，+8/+12/+16清0，+20 bool，+24星号字符串。
//   _Locimp析构91D840在Lockit(0)范围反向遍历+8表，+12为数量。
//   非空项经7DA7C0后交7DB2C0处理；不在此把返回值宣称完整引用计数算法。
//   正常及尾块分别清理锁、字符串、facet；+16的业务意义仍未闭合。

//   同一路径处理+36指针；完整ios状态字段需沿91CB60等使用者继续恢复。

// type_info

//   A31BC8 SEH表为{-1,0,921196}，filter=0的finally处理器就是unlock块。
//   静态TD+4初值0与运行态缓存槽重合；禁止把初值0推广成运行态常量。
