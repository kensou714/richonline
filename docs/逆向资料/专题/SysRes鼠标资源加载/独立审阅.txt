// 独立语义复核
// ----------------------------------------------------------------------------
// M是A766C0鼠标根，C是A766B0配置根；loader保存M后以C调用6DB9D0。
// 计数每轮读Q=[C+3AC00]，遍历100个12B步长项，只统计DWORD[Q+12C4+12*i]!=FFFFFFFF。
// n在正常内存条件下为0..100，既不是最大有效索引加一，也不是某个数量字段直接读取。
// loader取连续i=0..n-1组成文件名；稀疏原记录位置不会成为文件编号。
// 最多100槽写至M+198；新构造只清M+0C起190h，不能认整个对象已清零。
// 先写BYTE[M]=1、BYTE[M+1]=0；中途失败不回滚这两BYTE或先前已写表项。
// LoadImageA参数为NULL、相对路径、IMAGE_CURSOR=2、宽高0、flags=10h即LR_LOADFROMFILE。
// flags未含LR_SHARED/LR_DEFAULTSIZE；NULL时才LoadCursorA(NULL,7F00h系统箭头)。
// 两次API均NULL时MessageBoxA并令EAX=0；文件失败而箭头可用时仍可继续成功。
// 结束时槽0写+19C和+1A4，槽1写+1A0和+1A8；SetCursor用槽0并丢弃其旧句柄返回值。
// n=0仍可返回1且调用SetCursor，n=1仍读槽1；仅首次已清零且无其他写者时可推出未加载槽为0。
// 后续6BAD80不相等分支只把选中值同时写+19C/+1A0，未更新+1A4/+1A8。
// 等值分支返回旧缓存，系统调用分支返回API旧句柄；不能将两个返回统一命名新光标。
//
