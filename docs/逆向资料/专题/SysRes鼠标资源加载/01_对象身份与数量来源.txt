// 本批只针对Richonline当前RnClient.exe，SHA见00；地址均为静态VA。
// 两新本体6BAB70与6DB9D0均为ECX传this、无栈参数、普通RET；不是同一个对象的方法链。
//
// 启动与this传播
// ----------------------------------------------------------------------------
// 623CB0@623CE6经5FFCCB取得6278F0返回M；623CEB将M置ECX，再@623CED调6BAB70。
// 6278F0读写A766C0，空时分配1ACh并条件构造；分配失败可返回0，本调用点无NULL门。
// 6BAB70@6BAB97保存M；随后@6BAB9A经60554A调用627760，返回C改置ECX传6DB9D0。
// C来自另一全局A766B0；旧根空时分配99FE8h，分配失败可返回0，不能与M合并字段。
// 两根的主块和异常附属块已复用旧字节核验；本批不重认其构造内部或线程安全。
// C称“配置根”只是沿用旧资料导航；本批真正已证身份是627760返回值与A766B0。
//
// 6DB9D0 / 104字节、29指令
// ----------------------------------------------------------------------------
// 局部计数n=0、索引i=0；i从0递增至99，@6DBA0B以signed JGE结束100项扫描。
// 每轮重读Q=DWORD[C+3AC00]；@6DBA19计算12*i，@6DBA1C读DWORD[Q+12C4+12*i]。
// 仅当该DWORD不等于FFFFFFFF时n++；等于FFFFFFFF跳过，不检查正数或特定类型。
// 返回n，因此正常有效内存条件下0<=n<=100；中间没有调用或溢出，非稀疏索引列表。
// n是合格项数量，不是最大记录编号加一；原记录值也没有被返回给loader。
// 若只有第99项非FFFFFFFF，结果仍是1，下游加载04_00.ms而非04_99.ms。
// 本函数未读其余两个DWORD，不能据12字节步长命名完整记录或把字段叫光标ID。
// 不检查C/Q为NULL或可读容量；并发时每轮重读Q，不能声称100项来自原子快照。
// C+3AC00写入者、12C4来源、缺项初始化和配置文件名称未在本批闭合。
//
// 计数到文件编号
// ----------------------------------------------------------------------------
// 6BAB70@6BABA6把n保存到[EBP-10]；循环i=0，@6BABCE signed JGE判i>=n则结束。
// 正常n界限保证最大i=99，因此最多写M+0C至M+198，共100个DWORD槽。
// 每次文件名仅使用连续i；当前磁盘有39文件不证明运行时n=39，也不改变n的100项上界。
// n=0不执行加载但仍走缓存和SetCursor；n=1只加载槽0，槽1保留进入函数前表值。
// 在已执行旧构造6BAAC0且没有其他写者的首次路径，未加载槽可由旧清零契约推为0。
// 对复用旧对象或再次调用，不能套用“未加载槽总为0”的首次条件。
//
// 证据导航
