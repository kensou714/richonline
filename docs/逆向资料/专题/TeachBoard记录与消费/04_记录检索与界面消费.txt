// 0x798CE0(record)：0x799F70从全局取内层对象，0x63F870返回图片数量。
// 0x798D80(record,page)：取同一记录，经0x63F8D0定位页，再读取DWORD ID。
// 两个包装与外层0x799F70本身没有record/page范围检查。
// 内层叶边界未知；不能保证空记录、负索引、过大索引有定义的返回值。
//
// 0x768470以this+0x48为record、this+0x4C为page；本体不更新这两个字段。
// 0x768496经import槽0xAD3CBC调用GetTickCount，结果写this+0x54。
// import槽是间接指针地址，不能计成已导出的GetTickCount实现。
// 0x7684B7取得图片ID后，控件1调用0x6FA7F0。
// 0x6FA7F0将this+0xA4、参数0及ID转交0x8E1C70；仅证图像ID更新入口，
// 本批未审后端绘制，不保证纹理已载入或画面显示成功。
//
// 0x7684E5判断记录数量是否等于1。
// 等于1：控件11、12分别调用虚表+0xC8(0)。
// 其他数量：控件11、12分别调用虚表+0xC4(0)。
// 控件13固定调用+0xC4(0)；控件14调用0x6FA7F0提交ID=-1。
// 虚槽含义尚未闭合，本文不把+0xC4/+0xC8强行命名为显示/隐藏。
//
// 0x768614以"%d/%d"格式化page+1和记录数量，然后交控件16虚表+0x90。
// 输出局部区16字节，sprintf入口不传容量。
// 两个完整signed int最大各11字符，加斜杠与NUL理论需要24字节；
// 但本批没有证明如此大的真实索引可达，这只是静态容量风险。
// 当前四行样本在图像转换成功时最多2页，正常样本计数字符串很短。
//
// 未闭合：record/page初始赋值与翻页动作、UI134/L_TeachBoard.ui归属、
