// 外层全局对象地址0xA839A4位于.data虚拟尾部，未对应磁盘raw字节。
// 不能把读取不到磁盘初值描述成“原文件全零”，启动构造来源仍待闭合。
// 外层相关访问：+0x04 begin，+0x08 end，+0x0C capacity_end。
// 记录跨度16字节；这里只描述已使用字段，+0x00不擅自定为allocator。
//
// 0x6E0250：begin==0返回0，否则(end-begin)算术右移4，得到记录数。
// 0x6E01B0：begin==0返回0，否则(capacity_end-begin)算术右移4。
// 0x6E0100在count<capacity的无符号比较分支调用0x6E03B0(end,1,源记录)，
// 返回值写回+0x08；其他分支通过end迭代器和0x6E02B0插入。
// 0x6E03B0调用0x6E0DC0，随后返回起点+数量*16。
// 0x6E0DC0经0x611E6C调用0x6E1290。
// 0x6E1290逐记录调用0x6E1520，输出地址每轮加16；异常分支调用0x6E1560。
// 两个叶实现未展开，不能把此链描述成已证深拷贝或简单16字节memcpy。
//
// 0x6E02B0先保存插入相对索引，调用0x6E0490，再按新begin恢复迭代器。
// 0x6E0490局部：容量不足时候选为旧容量+旧容量/2，必要时提升到新size；
// 0x6E066C/0x6E067B/0x6E0684写回capacity_end/end/begin。
// 分配、记录移动、释放与异常清理依赖仅保存跳板目标，完整契约未知。
//
// 迭代器是一DWORD指针值：0x6E0CE0把参数写入[this]。
// 0x6E0A80包装该赋值；0x6E0370/0x6E0210分别由begin/end构造迭代器。
// 0x6E0AC0令[this]+=index<<4；0x6E0400在局部副本上推进后写出结果。
// 0x6E0D10计算(*this-*other)算术右移4；0x6E0AF0包装差值。
// 0x79C850读取[this]，0x79B020包装该解引用。
// 0x799F70由begin推进指定索引后取记录地址，全链自身未见范围检查。
//
// 每行临时内层对象同样16字节，0x6466C0构造时调用0x646960(0)。
// 0x646960先把+4/+8/+C清零；参数非零时经allocator建立DWORD容量。
// 当前loader调用参数为0，不进入分配分支。+0字段的类型仍不确定。
// 0x646750仅复用DWORD追加包装契约；增长、复制、释放叶层未在本批展开。
// 0x646720为析构包装；不能由“调用了析构”推导所有权与深层释放正确。
// 0x63F870读取数量：begin==0为0，否则(end-begin)算术右移2。
// 0x63F8D0仅复用页索引桥接，自身未见范围检查；605EE6/609C71/60FDC9
// 叶链不在本批覆盖，不能扩大成已审完整元素访问后端。
//
