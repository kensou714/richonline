// 链路：启动0x623CB0@0x623E85 -> 0x609E29 -> 0x6DFD80。
// 启动调用点未检查业务返回。0x6DFDCF资源入口0x81B4C0返回零时AL=0，
// 非零则继续；正常循环结束后AL=1，随后仍有析构、RTC与cookie检查。
// 文件读取器深层失败、解包与异常行为不在本批认领范围。
//
// 0x6DFE2C -> 0x819250，mode=2、preprocess=0。
// 复用解析器按资源长度精确复制，不额外附NUL，不预处理删除CR。
// 循环前0x6DFE37 -> 0x607B10 -> 0x6C5510读取AL：
//   signed((this+0x94游标)-(this+0x04基址)) >= this+0x88长度。
// 这个EOF判断只发生在取行之前，不能保护取行内部的每次读取。
//
// 0x6DFE6D -> 0x605FF4 -> 0x81A2E0逐字节复制，直到源字节等于LF。
// 0x81A2FA比较0x0A；0x81A30D复制；0x81A327递增+0x94。
// 结束时0x81A332写NUL，+0x94再加1跳过LF，+0x9C计数加1。
// 本体不比较源末尾、不接受输出容量、不以源NUL或CR作为停止条件。
// 结论：每行必须以LF收尾；缺末尾LF时存在越界读取及写出风险。
// 行缓冲从EBP-0x2D8开始清零512字节；含NUL的写入应不超过此范围。
// 这不是输入校验器，也不能仅凭调用前EOF判断声称异常资源安全。
//
// 0x6DFE81起连续清零128字节，四个扫描输出起点间隔32字节。
// 0x6DFEB6格式地址0xA24088："%[^\t]\t%[^\t]\t%[^\t]\t%[^\t]"。
// 每个scanset没有宽度；0x6DFEC2调用0x920600后只清栈，未检查字段数。
// 由此32字节字段区并没有扫描器容量保护，长字段存在写出风险。
// 扫描器内部未重审，空字段、短行、额外TAB等不承诺精确运行结果。
//
// 0x6DFEE5到0x6DFF4C固定遍历四个扫描区。
// 0x6DFF07只比较strlen结果与1：任意单字节字段都跳过。
// 长度0也进入名称转换；不能把这一条件解释成“非空才追加”。
// 0x6DFF26调用0x6DAA10，自动MFC名称不是可信业务名称。
// 返回-1时跳过；其他值由0x646750追加为DWORD，顺序沿原列方向。
// 0x6DFF5A向全局0xA839A4追加行记录，随后0x6DFF69析构临时列表。
// 本loader未见全局清空；若再次调用且无外部清理，会再次追加记录。
//
// 原证：functions_raw.json、closure_raw.json、constants_raw.json、reused_raw.json。
