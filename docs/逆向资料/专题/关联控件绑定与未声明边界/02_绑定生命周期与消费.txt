// 悬空与地址复用的精确边界
//   数组里的值仅与有效同层节点指针比较，没有直接对数组取出的值解引用。
//   因此不应直接把“目标先删除留下槽值”写成必然use-after-free。
//   残留值通常不命中；若新同层对象复用旧地址，则可能被误识别为原关联目标。
//   正count配空数组则消费者确实会读数组地址；是否可达取决于分配失败/接口调用路径。
//   上述均为静态契约风险，当前未进行运行态复现。
