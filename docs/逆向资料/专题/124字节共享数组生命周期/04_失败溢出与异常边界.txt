// 124字节共享数组生命周期 / 失败、溢出与异常边界
// ============================================================================
// 分配包装与正常返回
// ----------------------------------------------------------------------------
// 6A4A80所有申请经609997 -> 91BD80 -> 601274 -> 91BD30。
// 91BD80只转发cdecl Size并回传EAX；91BD30循环malloc(Size)。
// 只有malloc非0才到正常返回；malloc0会调newhandler，handler0再调_Nomemory。
// 若这些深调用返回，继续回环；本批不展开其异常类型及运行时handler。
// 所以调用者虽显式处理主块0，但不能把它说成普通分配失败已证实返回0。
// 列表返回直接写字段，无本地NULL分支；异常与失控handler路径另限。
//
// 整数值域与容量
// ----------------------------------------------------------------------------
// N来自DWORD[M+4D0]，没有本地非负或上界检查；N*124和N<<2只保留低32位。
// 初始化622D50用减1后的符号位；末端编号循环用signed i<N判断。
// 正N的无溢出必要条件：124*N不超过32位size_t，11列表各4*N亦不溢出。
// 32位无符号124*N上界为N<=34636833；实际可用堆容量远小于理论上界。
// 该数值只是算术条件，代码没有落实这个检查，不是已证实有效业务范围。
// N=0：编号循环不进，但仍有12次Size=0申请，不能推定不会申请或返回NULL。
// 除INT_MIN外负N：两个元素循环首轮不进，仍把回绕后的大小交给allocator。
// N=INT_MIN：622D50首轮count--回绕INT_MAX，可进入巨量回调；编号循环仍不进。
// 分配容量与signed循环行为必须分别记录，不能泛写“负数不执行”。
//
// NULL分支与直接写
// ----------------------------------------------------------------------------
// 主块0分支将B写0；若后续到达编号循环且signed N>0，直接写B+124*i。
// 这是静态条件路径，无B校验；当前allocator正常返回规则限制其普通可达性。
// 不以静态路径替代游戏重现、服务器输入可达性或真实崩溃证据。
// 列表容量只有申请4*N这一构建事实，实际消费数量仍需各writer的门分别证实。
//
// 异常与部分构建
// ----------------------------------------------------------------------------
// 6A4A80主分配后设EH状态0，调用逐元素初始化；成功后恢复-1，再写B。
// 异常尾A12079..A1208E完整21字节：取局部主base并经601CD3调用91F7E0。
// 尾块释放局部主块，不等于遍历析构已初始化的R+04对象。
// 列表申请阶段没有对应列表回滚EH状态；部分已写字段由未来清理如何处理另限。
// 释放集合只覆盖B和9列表；5F4/608在部分构建时也不应被假定能完整回收。
// N和current在主申请前已改；计数直到11列表申请后才清0，失败态可混合新旧。
// 未进行动态异常注入；不声称客户端具有强异常保证或统一BOOL失败返回。
//
// 局部配对缺口的准确表述
// ----------------------------------------------------------------------------
// 确认：6A4860没有5F4/608的直接free或置0，6A4A80后续重新申请并覆写它们。
// 未确认：所有深析构/外部owner是否另管这些分配，真实多次重建是否泄漏。
// 不用“11次分配、10次释放”直接判定漏1项；这两种次数的对象集合不同。
// 修复建议须在owner全局证据与运行验证后提出，不能直接改EXE或补free猜所有权。
