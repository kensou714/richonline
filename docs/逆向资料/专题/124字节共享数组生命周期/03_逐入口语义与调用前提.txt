// ============================================================================
// 124字节共享数组生命周期 / 逐入口语义与调用前提
// ============================================================================
// 6B7CB0 / 数量来源getter
// ----------------------------------------------------------------------------
// ECX=this；6B7CBE取this，6B7CC1读DWORD[this+4D0]到EAX，retn无参数。
// 无this NULL、数量符号、上界、状态或业务有效域门；返回不是BOOL。
// 6A4ABB经603D7B调用，6A4AC3把结果写入M+5DC。
// 只闭合“4D0 -> getter -> 5DC”，不闭合4D0的上游写者或可信性。
//
// 6A4A80 / 创建与重建
// ----------------------------------------------------------------------------
// ECX=M，无栈参数，retn；不能用EAX残值当成功标记。
// 6A4AB3经6118F9调用6A4860；6A4ABB取N；6A4ACC置current=-1。
// 6A4AE5做32位N*124，6A4AE9申请主块；无乘法溢出或N值域门。
// 6A4B10之前依次压callback、N、124、base，调用622D50。
// 非0主块走初始化，0走B=0分支；6A4B37把结果写M+5D8。
// 11个4*N列表依次分配并存指针；随后11计数写0；最后signed i<N循环。
// 本地没有B非0门、列表NULL门、实际可写长度门或构建完成标记。
// 两个未clear列表字段5F4/608会在本次重建被覆写，详见配对文档。
//
// 6A4860 / 部分资源清理
// ----------------------------------------------------------------------------
// 完整532字节本体，retn，无栈参数；十组非0门包含B和9个列表。
// 每组先free再置0，未遍历元素，未调用元素callback或+04对象析构。
// 不触及5F4/608、N/current及11计数；数组释放后数量和部分状态可陈旧。
// 可重复清理的结论仅限这些已清0字段，不能称整个对象状态幂等。
//
// 622D50 / 有限旧依赖：逐元素回调ABI
// ----------------------------------------------------------------------------
// 四个栈参数(base,stride,count,callback)，RET10h由被调者清16字节。
// 每轮先32位count--，JS则退出；否则ECX=base间接call callback。
// callback无显式栈参数，结果不用；调用后base+=stride，重新判断count。
// 6A4A80本次stride=124，callback=60D34E，5字节E9目标6B7C60已核磁盘。
// 这是数组元素初始化实参，不是69DF50根对象构造的登记证据。
// count=0及除INT_MIN外负数首轮退出；INT_MIN回绕到INT_MAX不属该零次域。
// 回调完整端点6B7C60已补证：以R+8调用6B7BB0后清DWORD[R+4]，EAX=R。
// 其深调用6B7BB0仍仅导航，不能由完整包装本体推断全部初始化范围。
//
// 两个真实caller / 旧主体局部审阅
// ----------------------------------------------------------------------------
// 6AB5F0@6AB630：UI73/64查询及UI70(0,0)之后，以ECX=M调6A4A80。
// 本体该调用无前置N/索引/状态分支，输入arg未直接读；retn4。
// 后续+AB0/+AB4清0与+AB8写GetTickCount属于其他状态，不是数组成功判断。
// 69E600@69E658：先6A1190、6A2350、6A76E0，再6A4860，均ECX=M。
// 本体及异常尾没有直接5F4/608释放；深调用与基类释放尚未全部闭合。
// 6A2350完整旧源只释放4D4、4E0、4E4、4E8、4EC，不等同共享数组列表。
// 6A1190旧源无VA文本仍只导航；新增当前69B证实608024桥到82C4E0。
// 其本体随后写5E0/4F0=-1和BYTE+258=0；82C4E0深副作用未递归审阅。
// 补证6A76E0只清640..650指针及654..664计数；6B9AF0仅转6BA4A0。
// 不能从caller UI名称补造消息ID、网络包字段或服务端错误可达性。
