//   排12字节本地记录，其中+2 WORD=1、+4 DWORD取G+83784，+8 BYTE取当前槽；
//   本地行动者还排4字节继续记录(+2 BYTE=1)。
//   这说明退出通知具有解除部分等待的副作用；具体付款状态参见落点调度专题。
