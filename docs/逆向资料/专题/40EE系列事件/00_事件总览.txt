/* 公共门控 */
// 除 5000 外，本组 handler 普遍读取 packet+2 WORD，经607A2F跳到64F710。
// 此函数比较 G+83844 的 WORD，失败弹出 "Error GmsvID"；不是包长检查。
// G 表示处理函数的游戏对象 this，不能把其偏移写成独立线包字段。
// packet+4/+5 在卡片模板中是槽位/分组输入；当前角色从 G+0xE28 取得。
// 桥接先调用对应 handler，随后91F6D0做 RTC 检查；不是额外业务确认。

/* 本地消息与线包的区别 */
// 609D34 把局部消息加入队列；Size 是当前本地结构长度。
// 不能把 24B 文案消息、20B 指针载荷消息或其中的进程内指针当线包格式。
// 6061 消息模板有+6默认1；卡模板写+4当前角色、+5输入槽、+7输入组、+9=1。
// 6006消息中+2=1的后续含义需要继续看消费者；不能一概称为网络ACK。
// 1350/1000、1800/1350、3600/3600是提示消息参数，不是窗口像素尺寸。
