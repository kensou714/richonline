// 三者真实入口均为ECX=C、一个DWORD栈参数newID，结尾retn4。
// 调用前依次push newID、index、C+164，随后重新把C装回ECX，调用60DA8D。

//
// 对象层次与字段
// ----------------------------------------------------------------------------
// C       控件对象；C+384为enabled字节，C+385为visible字节。
// S=C+164 内嵌样式对象；S+0为类型，S+4为处理状态，S+12为当前索引。
// R=S+40*i 表示第i条记录的寻址基点；每条stride40，不是独立对象指针。
// R+16/+20为宽高缓存，R+24为图像ID，R+28为图像查询第二参数，R+36为路径。
// 当前默认样式输出尺寸可复制至C+352/+356；这些值不是纹理或图像资源句柄。
// 四个ID字段的控件偏移依次为188、228、268、308；newID按DWORD原样传递。
// 类型5时ID参与图像查询；负ID会使底层尝试路径来源，不能一概解释为无图。
//
// 底层语义复用，详见“控件图像状态记录”专题
// ----------------------------------------------------------------------------
// 8E1C70先比较旧ID与新ID；不同且旧ID!=-1时，调用全局接口U+44(owner,index)。
// 回调后才写新ID。外层未屏蔽重入，也不负责把旧宽高缓存或路径一并清零。
// C.visible非零且((enabled非零且i=0)或(enabled为零且i=3))时，进入状态刷新。
// 索引1、2的ID更新不由8E1C70立即刷新活动尺寸；后续悬停/按下切换另行驱动。
// 即使新ID与旧ID相同，也可能符合刷新条件；不能把整个函数当成相等即无操作。
// 8E2200写S+12，再按原S+4转8E1FB0；类型5和状态1才有图像尺寸查询路径。
// 查询回调返回及活动尺寸复制不等于绘制已经完成，也不等于资源加载一定成功。
// 该实现返回值可能来自字节状态或后续函数，外层未规范化成统一成功/失败码。
