// 槽位  getter    setter    C中路径DWORD偏移   底层style偏移
// 0     6FA930    6FA960    200               S+36
// 1     6FA9B0    6FA9E0    240               S+76
// 2     6FAA30    6FAA60    280               S+116
// 3     6FAAB0    6FAAE0    320               S+156
// 四个getter分别只执行mov eax,[this+偏移]后返回；没有复制、引用计数或空串替换。
// 返回的是当前内部路径指针，调用者不能据getter返回值取得释放所有权。
// 6FA9B0被IDA误名IsAlwaysLargeImage，实际返回路径DWORD，不能当BOOL使用。
//
// setter真实调用约定
// ----------------------------------------------------------------------------
// ECX=C，一个栈参src；push src、固定i、C+164后，重新以ECX=C调用5FFAFA。
// 5FFAFA -> 8E1DB0；底层三个栈参数均由callee回收，外层末尾retn4。
// 七个ID/path外层包装都没有判空C或验证指针生命周期，调用方需保证对象有效。
// 四个路径setter允许src=NULL传到底层；不能把它替换成对NULL执行strlen的API。
//
// 底层路径所有权，复用“控件图像状态记录”的8E1DB0原证
// ----------------------------------------------------------------------------
// 旧路径与src都非空且stricmp相等时，直接返回，不复制也不刷新。
// 因而仅改变大小写不一定更新保存的字节串；不能假定所有调用都会重新规范路径。
// 替换时若旧路径存在，先可选调用U+44(owner,index)，再delete旧内存并置空。
// src非NULL且首BYTE非零时，分配strlen+1并strcpy复制；否则保留NULL。
// src需为有效NUL结尾窄字节串；编码和路径搜索规则不能由lstrlenA/strcpy推出。
// 不给回调重入、分配失败和释放前后别名做外层兜底；这些风险由底层专题保留。
// 若传入与旧缓冲重叠但不相等的内部子串，底层释放后再复制，不能假定安全。
// 建议工具或补丁传入独立、调用期间有效的字符串，getter结果只作借用观察。
// 替换路径不会自动把同槽ID改成-1；要切换ID/路径来源，需遵循底层优先条件。
//
// 可见/启用刷新条件与ID包装相同，但只发生在真正进入替换分支时。
// 底层函数返回值未被包装规范化；不能把返回0一概当作替换失败。
// 以上是静态契约与调用前置条件，未执行实际资源替换或验证所有扩展回调。
