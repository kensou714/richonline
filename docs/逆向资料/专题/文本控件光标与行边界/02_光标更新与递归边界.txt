// ============================================================================
// 第二十四批 / 光标更新与递归边界 / 三新主体中的两完整主体
// ============================================================================
// 8FC6A0完整307字节/95指令；8FC830完整867字节/236指令；本批无客户端补丁。
// 位置定义沿用01：A=Y+R为绝对行，P=B+X为水平宽度；mode仅取有符号低BYTE。
//
// 8FC6A0：局部行更新，ECX=this，(amount,mode)，RET 8
// ----------------------------------------------------------------------------
// 首先以8F4BA0获取可见行容量V；V<0立即返回，不更新354h，也不先校验mode。
// mode为'+'/'-'/'='分别对R加/减/赋amount；其他mode返回首个helper残留EAX。
// 随后按顺序检查：A>C-1时令R=C-Y-1；否则R>=V时令R=V-1，若Y+R<C则Y++。
// 否则A<0时：Y!=0令R=-Y，Y==0令R=0；否则R<0时令Y=A并钳至0，再令R=0。
// 这是顺序分支，不是全局 clamp(A,0,C-1)；V==0没有门，可能留下R=-1。
// 首个A>C-1分支也不再次检验R/V；不能保证最终索引非负或位于数组。
// P=B+X非0时取当前行T，调用90CE80(T,P,&modeDWORD槽,1)。
// 该mode参数所在DWORD槽被deltaOut覆盖；随后调用8FC830(delta,'+')，amount不是字符索引。
// 8FC7C0通过[AD3CBC]间接call，返回EAX写this+354h(852)，并作为本路径返回值。
// 这只是调用结果戳；实际运行导入目标与该字段的业务时间意义不由本批证实。
// 本体没有选区四字段赋值、实际光标绘制、数组上限或整数溢出检查。
//
// 8FC830：局部水平更新，ECX=this，(amount,mode)，RET 8
// ----------------------------------------------------------------------------
// amount按完整DWORD宽度量读，旧反编译_WORD*类型不采用。
// 本体先按A=Y+R取array+A*A0h+8并读取T.text，之后才进行空文本/模式检查。
// 因而空文本门并不能保护非法行索引。T.text NULL/首WORD0时B=X=0，返回文本指针，无戳更新。
// 非法mode返回符号扩展低BYTE减61的算术残留，不是统一失败bool。
// '='且amount==-1专门令B=X=0；若关联this+19Ch非NULL，令其+46Ch=+464h并调用8EB410。
// 该特殊路径无354h更新；关联缺失时返回-1，存在时返回helper残留。
// 普通'+'/'-'/'='先更新X，再处理负值、可见宽度H与行尾。
// X<0且B!=0：B=max(B+X,0)，X=0；X<0且B==0：X=0。
// 后者若入口绝对行A>0，调用8FC6A0(1,'-')，重新取得当前行总宽W后递归8FC830(W-B,'=')。
// 仅该负水平路径跨到上一行；本体未发现向下一行的水平溢出处理。
// X>=0且X>H(8F4B10)：B+=X-H；90CE80(T,B,&slot,1)取得pos/delta。
// delta非0时90D310(T,pos,1)取得后续边界，再90D120(T,next)赋B；随后重新取H赋X。
// 如果随后P==T+0Ch且X==0，则B-=H，再转换与必要边界吸附，B钳至0并令X=H。
// 最后P非0时再次90CE80(T,P,&slot,1)，仅令X+=delta，没有再进行X/H边界钳制。
// 因此不能承诺最终0<=X<=H；H为负、宽度溢出或描述变动均不被本体禁止。
// 8FCB70通过同一[AD3CBC]间接call写354h；主路径并不同步关联对象+46Ch或选区字段。
//
// 短依赖契约与递归限制
// ----------------------------------------------------------------------------
// 以下仅指定旧主体调用契约，不增加本批完整审阅主体数；原证/当前字节绑定见验证报告。
// 8F4B10：this+78h为0返回0；this+1A0h不存在或其+183h隐藏时返回this+160h-4。
// 否则再减关联对象+160h；有符号结果无非负钳制，不能先给H一个正数不变量。
// 8F4BA0：this+78h为0返回0；先调用外部60B7D8，再以this+78h+this+24Ch为分母。
// 分子为this+164h减可见this+19Ch关联对象+164h；CDQ/IDIV未检查零分母或加法溢出。
// 8FC6A0和8FC830互相调用；正常稳定行记录及有限非负宽度可解释为上一行/前缀续接。
// 但本体未对零可见容量、非法索引、helper重入、动态修改描述、循环分段建立统一终止门。
// 8EB410不是纯刷新：先以+460h/+468h/+464h约束+46Ch，随后同步回调与自身虚表调用。
// 其外部回调可重入；本批不宣称实际paint、运行输入法、编辑器或全字符系统完成。
