// 主体90CE80、90D120、90D310按旧原证逐字段保留，再以本批当前完整块重新核字节。
// 以下偏移均为十六进制；括号内为十进制，避免将旧文十进制偏移误读为十六进制。
//
// 行记录与三种位置域
// ----------------------------------------------------------------------------
// this+250h(592)为行记录数组；绝对行A=Y+R，记录地址=array+A*A0h(160)。
// Y=this+31Ch(796)，R=this+344h(836)，行数C=this+310h(784)。
// 记录+8为文本描述T：T+0文本指针、+4分段链、+8单元BYTE宽度缓存、+0Ch总宽度。
// 记录+14h(20)因此就是T+0Ch的总宽度，不是第二个独立位置字段。
// B=this+318h(792)，X=this+348h(840)，绝对水平量P=B+X，以宽度量而非字符索引解释。
// this+314h(788)在插入后参与关联对象范围计算；不将它等同于当前行的T+0Ch。
// 行号、UTF-16单元索引、水平宽度是不同域；这里只证当前算术，不确证运行字体的像素单位。
// 分段节点N：+0单元数、+4整段宽度、+8 BYTE原子段标志、+0Ch下一节点。
// 读取BYTE宽度时先清高位再累加；累加/比较是32位，比较JLE/JG等按有符号值。
// 描述T本身无NULL门；链长度、缓存长度、无环与加法不溢出均是未验证前置条件。
//
// 90CE80：宽度到单元位置，四栈参，RET 10h
// ----------------------------------------------------------------------------
// ABI为(T,targetWidth,deltaOut,flag)；ECX在本体保存后仅用于递归续传，不是T来源。
// T.text为NULL或首WORD为0时写delta=0、返回0；deltaOut也无NULL门。
// 非空首先调用wcslen桥610283，保存整串UTF-16单元数；不是Unicode字素计数。
// 普通模式逐BYTE累加S；某单元后宽度>target时写delta=此前S-target。
// 若此前S==target，返回当前单元索引；否则递归查询此前S，以暂存delta接收内层输出。
// 外层delta保留此前S-target，不因内层返回位置再重算；不能一般断言delta=prefix(return)-target。
// 普通等宽且flag低BYTE=0时返回i+1、delta=0；flag非0继续扫描，包括零宽缓存。
// 普通扫描到末尾返回整串长度，delta=最终S-target；target超过末尾并不返回错误码。
// 分段普通节点按全局单元偏移查BYTE缓存；等宽flag0返回段起点+i+1、delta=0。
// 分段原子节点只比较N+4整宽：溢出写此前S-target，必要时递归，此前S==target则返回段起点。
// 原子等宽flag0在90CF70跳90D006：delta=0，返回当前段起点，而非段尾或整串长度。
// 此结论必须追踪ESP：90CEC0存整长于基准ESP+18h；90CF52/90CFC4存段起点于+24h。
// 90D00A、90D00B、90D00C连续pop三个寄存器后ESP增加0Ch，90D013的[ESP+18h]即原+24h。
// 原子等宽flag非0继续下一段；分段末尾统一回90CEF3，返回之前保存的整串长度。
// 普通分段溢出递归90D032先push flag，90D033的[ESP+24h]实际为原+20h，即T参数。
// 不是将段起点当文本指针；60 34 CF桥的E9目的90CE80已单列核验。
// 例：原子len=2,width=4后接普通width=7，target=5时外层delta=-1，递归target=4、flag0返回0。
// 因此该例返回0但delta=-1，不满足以返回0的prefix=0再减target=5的公式。
// 有限稳定、非负宽度、无溢出的正常域可用较小前缀分析递归；损坏链与负宽/溢出不保证终止。
//
// 90D120：单元位置到前缀宽度，两栈参，RET 8
// ----------------------------------------------------------------------------
// ABI为(T,pos)。空文本返回0；普通pos<=0返回0，pos>0累计缓存[0,pos)，不按wcslen截断。
// 分段消耗完整节点时累计N+4，即使普通节点也使用整段缓存宽，而非重新逐单元求和。
// pos落在原子段内部时返回此前整段累计S；普通段内部才逐BYTE累加所需前缀。
// pos超出整链返回完整链总宽；普通无分段pos超出缓存则可能越界，两模式边界不同。
// 不证明90CE80与90D120互为逆函数，原子等宽/内部位置及不一致缓存本来就可不同。
//
// 90D310：后续单元边界，三栈参，RET 0Ch
// ----------------------------------------------------------------------------
// ABI为(T,pos,flag)，不是绘制或Unicode字素分割器。普通模式直接wcslen(T.text)，无空指针门。
// 普通从pos+1开始：正宽单元直接返回该位置，零宽时flag0在循环里递增，flag非0改pos重入。
// 两种flag都可越过普通模式零宽缓存；不能写成只有flag1跳零宽。
// 普通抵达末尾返回wcslen；负pos无前置规范化，不能承诺所有输入返回合法索引。
// 分段原子节点返回该节点单元尾。普通节点内部零BYTE时flag0可直接返回，flag非0继续跳零。
// 普通节点尾恰为pos+1且flag0时返回pos+1；flag非0继续后继节点。
// 整段宽度为0且flag非0时另有pos推进路径；末链返回已遍历节点单元数。
// 分段链的单位总数与wcslen是否一致无检查；不作完整字符渲染或运行时文本边界验收。
