// 第二十四批 / 选区清理与插入续接 / 8FCCD0新主体与8FAE70指定复用完整主体
// ============================================================================
// 8FCCD0完整114字节/33指令；8FAE70完整978字节/286指令，以当前完整块复核旧原证。
//
// 8FCCD0：行删除续接，ECX=this，(rowIndex)，RET 4
// ----------------------------------------------------------------------------
// 入口无条件把this+358h/35Ch/360h/364h(856/860/864/868)四选区字段清为-1。
// 再调用60AEA0的E9后端8F4C20(rowIndex)，ECX仍为this；删除拒绝也不回滚选区清理。
// 调用后重新读Y、R、C；若A=Y+R>C才令R=C-Y；注意严格JG，A==C不进入修正。
// 若修正所得R<0则R=0、Y=C；C==0另调用8F39D0(0)。
// C非0时EAX仍是修正前重新读取的Y，即使Y随后改变也不据此返回新值。
// C==0则返回后端helper残留；不能命名为成功bool，也不更新354h。
// 8F4C20短契约只检查rowIndex<C，未先拒绝负索引；随后计数减一、回收描述/链、A0h搬移。
// 并重置腾空行及布局/回调；不能推导本入口参数可任意取负。
// 8F39D0短契约受this+324h及数量/上限334h/338h等门限制，可以不创建新行。
// 所以C==0调用不证明返回后必有一个可写空行；外部布局回调的全部行为未在本批展开。
//
// 8FAE70：文本插入与宽度光标续接，ECX=this，(source,flag)，RET 8
// ----------------------------------------------------------------------------
// 开头alloca 500Ch；this+370h(880)低BYTE非0、source NULL或首WORD0直接结束。
// 选区四字段均不为-1且两端行列任一不同才调用8FDEC0外部选区处理。
// 四项全有效不是自动顺序/范围证明；8FDEC0只指定调用窗口，未计完整owner审阅。
// 随后从栈+1Ch清零5000h字节，等于10240个UTF-16单元；不是5000h个WCHAR。
// 输入wcslen给单元数；全局[ACC3C8]+5128门选择直接单元数或8E0AA0转换数量。
// flag低BYTE非0时以this+334h数量和338h上限限制插入数，-1上限另行允许。
// 未验证数量与字符单元总数同域，数量上限也不是临时缓冲总容量证明。
// 有当前文本时90CE80(T,B+X,&scratch,1)取得前缀单元数；WORD循环复制前缀、输入、后缀。
// 本体未检验三者总和<=10240或预留NUL；零初始化不保证恰满或越界后的终止安全。
// 当前文本为空且入口绝对行A>=C时调用8F39D0(Y)；仍不保证创建成功或A已合法。
// 8E1800(temp,T,this+36Ch低BYTE)替换文本描述是外部依赖；完整分配/失败原子性不在本体。
// 之后以prefix+insertCount调用90D120得到宽度W，再调用8FC830(W-B,'=')。
// 参数须连读：8FB115 PUSH 3Dh先压mode；8FB117 PUSH单元数、8FB11E PUSH T交90D120。
// 90D120 RET8仅弹其两个参数，3Dh仍在栈；8FB12C减B、8FB12E PUSH结果后8FB12F调用8FC830。
// 固定窗口8FB11F起步看不到PUSH 3Dh，完整8FAE70主体提供这个必要ABI证据。
// flag为0且insertCount>0时重复调用8FBF70；该外部接口的全部语义未展开。
// this+33Ch(828)低BYTE非0才以当前绝对行调用901190；不能从条件直接断言整套编辑通知完成。
// 随后若this+19Ch(412)存在令其+46Ch=B并8EB410；this+1A0h(416)存在令其+46Ch=Y并8EB410。
// +19Ch范围+460h写max(this+314h,H)，+1A0h范围写max(C,V)，各自再通知8EB410。
// H/V helper在不同分支可能重新调用，不能强加所有调用间状态不变；通知也可能重入。
// 8EB410短契约：位置按range(+460h)-extent(+468h)与lower(+464h)约束。
// 对关联+190h回调对象虚表+80h交(position,61,this)，再自身虚表+20h；不是无副作用paint。
// 各早退/通知路径EAX或AL意义不一致；不命名统一成功返回，不建立整个输入法或容量不变量。
