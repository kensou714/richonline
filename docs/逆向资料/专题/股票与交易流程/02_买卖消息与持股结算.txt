// 原证：stock_core.json 全函数；stock_binding.json 的 ECX 与登记证据。
// 下列网络字段均小端；最低读取长度不是已经证明的唯一合法线上长度。
//
// 请求 0200 买入 / 0201 卖出：两者都精确提交6字节给 6BF380。
//   +00 WORD 消息号，由728840/728870只写此WORD。
//   +02 WORD 本局股票槽；+04 WORD 股数；由界面DWORD字段的低16位写入。
//   包 +02 不含 GmsvID 或上行回合同步值。
//   71C4C0、719E60 只在用户确认且数量>0和校验通过时提交。
//   6BF380 仍有全局状态<12及连接条件；函数返回不证明服务器已收到。
//
// 接收共同点：4200..4206 都先用64F710校验 +02 WORD GmsvID。
//   股票槽、角色槽、数量在handler里多为 movsx WORD，都是有符号16位。
//   handler内未见槽范围或消息长度验证；不能由此推断整个网络层完全无验证。
//
// 4200 -> 67AEB0，大盘初值/同步，至少16字节：
//   +04 float 前一大盘值；+08 float 当前大盘值；+12 float 行情因素。
//   -> 80F170；若+04<=0，沿用M+28为前值，否则用+04。
//   写M+24前值、M+28当前、M+32因素；M+36=(当前-前值)/前值*100。
//
// 4201 -> 67AF20，单股历史，至少128字节：
//   +04 signed WORD 股票槽；+06..07未消费；+08 float[30] 历史价格。
//   -> 80F1F0 追加30点，倒数第二/最后一点成为前价/现价，再算百分比。
//   本函数不会先清空历史环，也未检查追加失败的返回值；重复历史同步会继续追加。
//   一个模式分支弹“error game map”，之后仍调用历史写入；其模式谓词未深拆。
//
// 4202 -> 67AFC0，全体行情，固定字段读取到+52：
//   +04 float 当前大盘值；+08 float 行情因素；+12 起 float[n] 本局各股价格。
//   +52 BYTE 是否显示大盘涨跌提示；n=10时正好紧随40字节价格表。
//   -> 80F170(前值参数0)，再80F420遍历n调80F2D0。
//   刷新已开UI35和UI32；提示文本315/316。
//   最低长度须同时满足53和12+4*n，不能把固定标志位置当作动态移位。
//
// 4203 -> 67B180，单股行情，至少12字节：
//   +04 signed WORD 股票槽；+06..07未消费；+08 float 新价。
//   -> 80F2D0，并刷新UI35/32、文本317/318。
//
// 4204 -> 67B350 买入成交 / 4205 -> 67B560 卖出成交，至少20字节：
//   +04 signed WORD 角色槽；+06 signed WORD 股票槽；+08 signed WORD 成交股数。
//   +10..11未消费；+12 float 成交单价；+16 int 最终存款。
//   ECX = *(G+0xE00+4*角色槽)，不是无条件使用当前走子角色。
//   4204 -> 7F9760(数量,股票槽,显式价格=1,成交价)。
//   4205 -> 7F9850(数量,股票槽,显式价格=1,成交价)。
//   随后63F6B0用+16直接覆盖R+1508；它是最终存款，不是增量。
//   刷新UI35/8；若角色是本地玩家还刷新UI32及已开的银行UI17。
//   311/312报告“買進/賣出 ... %d股”。
//
// 7F9760 买入模型：
//   t = float(成交价 * float(数量))，经整数转换用于扣款。
//   7F9F10：存款-=整数金额，若变负则置0；之后买入函数若为0改1。
//   持股+=数量；总成本+=t；市场剩余数量-=数量（7FDC50）。
//   4204最后仍覆盖服务器给出的存款，所以本地“至少1”不约束最终+16。
//
// 7F9850 卖出模型：
//   均摊成本 = 原总成本 / float(原股数)，先计算，无零股数保护。
//   存款+=整数(成交价*数量)；持股-=数量；新总成本=均摊成本*新股数。
//   市场剩余数量+=数量（7FDCA0）。
//   原股数为0、超卖、负数量、非法索引都会破坏模型；服务端不能依赖界面检查。
//   正常非负有限数按浮点乘法后转整数，没有“每股乘100”的协议缩放。
//   x87反编译显示unsigned __int64转换，但存款/显示量最终用32位；异常浮点及溢出
//   的精确结果留待运行时转换例程审计，不把显示两位小数误说成定点分单位。
//
// 4206 -> 67B770，至少6字节：
//   +04 signed WORD RichStr文本编号；复制文本到全局缓存。
//   604A55跳板到6932B0；构造器写WORD 0x6003，不是6000。
//   排入24字节本地6003提示事件：+02 WORD=4，+04 BYTE=1，+06 BYTE=1，
//   +08 DWORD=1800，+12 DWORD=1350，+16文本指针，+20 DWORD=128。
//   再沿插入返回游标排入4字节6080阶段2；含指针的6003不是网络包布局。
//   补充原证：证据/stock_4206_constructor.json，保存67B770/6932B0及604A55跳板。
//   文本来自包选择，单凭此函数无法确定它只用于买卖失败还是另一个股票落点事件。
//   不更新持仓，也不覆盖存款；不要用它替代成交包。
//
// 非幂等性
//   重复4204/4205会重复加减持股和成本；+16覆盖只能校正存款，无法消除重复持股。
//   只有服务器最终金额校正不够，消息调度仍须保证成交事件恰当处理一次。
