// ============================================================================
// 配置、市场、角色持仓：三层编号和三种数据布局
// ============================================================================
// 原证：stock_core.json；resource_semantics.json；stock_binding.json。
//
// 配置对象 C：628B50 单例，分配 24 字节；80DCA0 读取 Data/Stock.kpd。
//   +00 DWORD 配置条数；+04 pointer 条目；+08 float 涨停阈值；+12 float 跌停阈值。
//   +16 float 涨停阈值-0.02；+20 float 跌停阈值+0.02。
//   缺省涨跌阈值 +10/-10；当前资源 RANGE 是 +8/-8，内阈值约 +7.98/-7.98。
//
// 每条配置 44 字节，按 indx 定位，不是按出现次序写入：
//   +00 char[32] name；+32 int asset；+36 int gushu；+40 float huopo。
//   原资源注释依次为“編號、名稱、總資產、總股數、活潑性”。
//   80FB60 返回 float(asset)/float(gushu)，是初始化基础单价。
//   80FBD0 返回总股数；80FC00 返回活泼性；80FCF0 返回名称起点。
//   当前资源 77 项，indx 连续 0..76，总股数最大 1000。
//   第一项：中信嘉華，asset=20000，gushu=800，huopo=1.0，基础价 25。
//
// 80DCA0 的边界：
//   先数 STOCK 节分配 44*n，再用 atoi(indx) 做下标，没有负数/上界校验。
//   重复 indx、缺号、非法数字、gushu=0 都没有在该读取函数统一拒绝。
//   name 交公共文本提取器写入最多 32 字节；不能将此当成 Unicode 字符数。
//   本地化转换分支存在；字符转换器的全部映射不在本专题重复分析。
//   当前资源按 Big5 解码，GBK 可解码部分字节但会得到错误文字。
//
// 本局市场 M = G+3280(0xCD0)，由 64F2A0 调 80E170 初始化：
//   地图 +124 是本局股票数，+128 是配置编号数组地址；691940/691960 取这两项。
//   +00 int n；+04 pointer 80*n 字节行情条目。
//   +08/+12/+16/+20 float 四个涨跌阈值，来自配置 C。
//   +24 float 前一大盘值；+28 float 当前大盘值；+32 float 广播行情因素；
//   +36 float 大盘涨跌百分比；+40 float[60] 临时曲线缓存；+280 int 曲线点数。
//   +284 int 交易限制字段（>0 时 692E80 返回真）；+288 DWORD、+292 BYTE 初始为0。
//   +284 的所有写入者和确切计时语义未闭合，不能直接称“闭市天数”。
//
// 每个市场条目 S = *(M+4)+80*i：
//   +00 int 配置编号 c；+04 int 市场剩余可买数量。
//   +08 float 活泼性；+12 float 初始基础价（加随机扰动后的值）。
//   +16 float 999.99；+20 float 1.0；+24 float 本地走势累计值。
//   +28 float 前价；+32 float 当前价；+36 float 涨跌百分比。
//   +40 20字节历史价格环形容器 {数据指针,容量,数量,读游标,写游标}。
//   +60 float 曲线最高值；+64 float 曲线最低值。
//   +68 int 连续方向计数；+72 int 强制走势剩余次数；+76 BYTE 强制上涨标志。
//   +77..79 对齐区，本次不赋业务语义。
//   80F130 用 S+0 查询配置名称；包和 UI 都操作 i，不直接使用 c。
//
// 80E170 初始化：
//   S+4=配置 gushu；S+8=huopo；基础价 asset/gushu 再乘 (1+(rand()%5-3)/10)。
//   扰动范围为 -30%、-20%、-10%、0、+10%；不是对称 +/-30%。
//   前价/现价均置这个结果；历史环分配容量61，单空槽约定实际最多60点。
//   M+24 累加各股初价，恰为0时改1；M+28 同值。
//
// 角色 R 的持仓：
//   +1508(0x5E4) int 存款；63F650读，63F6B0直接覆盖。
//   +1568(0x620) int[10] 持股数量；692FD0读，728750验证数量不负且持仓足够。
//   +1608(0x648) float[10] 持仓总成本；7F9CB0返回 总成本/数量。
//   7F3C70 的初始化循环归零上述十项；其余角色初始化仅作交叉引用，不全称已分析。
//   7F9CB0 数量<=0或成本<=0时返回0。
//   7F9DE0 遍历 n，将各股 数量*现价 转整数后逐项相加，返回当前持仓市值。
//   7F9E90 将现金字段 R+1504、存款 R+1508 与启用股票时的市值相加。
//
// 扩充内容边界
//   增加配置候选项与增加本局股票槽是两件事。
//   UI只遍历十行；角色数量数组与成本数组相隔40字节；4202的十个价格之后有标志。
//   仅改地图 n>10 会使持仓写入另一数组，并使4202价格遍历读到标志/后续字节。
//   77 个配置可供不同地图选股，不代表单局支持77支。
