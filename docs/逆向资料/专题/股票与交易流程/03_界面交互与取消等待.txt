// 三者职责
//   8：70CBF0列出本局股票、价格和四名玩家持仓；70D0F0只把点击ID/10-1存入+72。
//      本身没有提交0200/0201；调用方可以把选择用于道具操作。
//      658510是关联选择流程的一例，不能把“选择股票”都解释为买卖。
//   32：7199D0只列出本地玩家持股>0的股票，行压缩排列，股票槽存控件数据。
//       719E60通过控件数据恢复真实槽，提供买/卖弹层。
//   35：71B8F0完整行情列表，71D950详细信息，71D620画历史曲线，71C4C0操作。
//
// UI35/32共有业务字段
//   +72 int 操作：0买入、1卖出；+76 int 股票槽，初始-1；+80 int 输入数量。
//   +84 DWORD 提示起始tick；UI35 +88是存款显示刷新tick，+92..104是图片句柄。
//   UI35 +108、UI32 +92 是弹层输入抑制标志，下一tick归零，非成交等待锁。
//
// UI35 主要控件ID（71C4C0）
//   4/8：关闭整窗；a3==3分支也关闭整窗。
//   5/207、9：切换两种行情布局；201：关闭详细面板。
//   100..190、400..490：每10一个股票槽，分别打开详情/操作弹层。
//   210..219：切换详情股票；202/501买入；203/502卖出。
//   255：数量面板；256：买卖提示；257：数量和金额预览；280：短暂错误提示。
//   不把a3==3未经公共输入层审计就命名为Esc或右键；这里只确认事件值3效果。
//
// 数量编辑（32和35基本相同）
//   260..269：当旧值<99999999时，旧值*10+数字；判断发生在追加前。
//   270：当旧值<9999999时乘100。该常数被IDA误渲染为地址loc_98967D+2。
//   271：买入取 存款/股价 转整数，并压至市场剩余数量；卖出取全部持仓。
//   272：有符号整数除10；273：清零。
//   300..310：先算可买/可卖最大数，再乘(ID-300)/10，整数运算截断。
//   274：确认；275：取消数量面板，不发包。
//   UI35 71DF20显示“%d ($%d)”，金额为 float(数量)*现价 转整数。
//
// 买卖限制
//   727D40：涨跌百分比 < M+8 才允许买；达到涨停禁止买。
//   727DA0：涨跌百分比 > M+12 才允许卖；达到跌停禁止卖。
//   7287E0：买入数量>=0且市场剩余数量>=数量，无股票索引边界检查。
//   7F96F0：存款>=整数(数量*现价)，未在此检查负价格、NaN或无穷值。
//   728750：卖出数量>=0且角色持股>=数量，无股票索引边界检查。
//   确认还要求输入数量>0，因此0在正常界面不提交。
//   UI35打开卖出面板时另检查至少持有1股；UI32的路径依靠持仓列表与确认检查。
//
// 数量范围必须在服务端重新约束
//   输入变量DWORD允许很大的正整数；最终写包只取WORD低16位。
//   例如65536会发数量0；回复按signed WORD消费，32768..65535成为负数。
//   当前配置总股数最多1000降低了普通操作触发概率，不能将它当成程序边界保证。
//   新地图或管理员扩充股数后，应约束协议允许的正数量和各数组索引。
//
// 等待与取消
//   7061F0的按钮7直接开/关UI35；打开时先检查M+284>0的限制。
//   此路径未安装回合pending等待。65D520游戏入场时按地图能力直接显示UI32。
//   两个确认函数发送后立即隐藏255面板；本次未见设置“等待成交回复”锁。
//   4204/4205更新模型并刷新UI，不调用移动完成0011，也不排6080继续事件。
//   275只隐藏面板；关闭UI35也没有取消网络请求，不能当作撤销已提交成交。
//   UI35 tick每1000ms刷新存款文字；提示+84经过>1350ms隐藏。
//   这个1350ms是提示消失时间，不是网络超时、重发间隔或回合等待时间。
