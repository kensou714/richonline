// 下列长度是处理器实际最高读取偏移推得的下界，不是包长校验或线上抓包结果。
// 40D0/D1/DF至少8字节；40D4/D7/D8/DD至少7字节；40D5至少10字节；
// 40D2/D3/D6/D9/DA/DB/DC/DE至少6字节。目标角色多以signed BYTE读取，
// 地图位置与地产索引多以signed WORD读取；本层未见完整槽号/索引核界。
// 通用6061: +4=current低BYTE，+5=packet+4槽，+7=packet+5类别，+9=1。
// +6由构造器默认1，记录总长10字节。不要把网络packet+5误当扣除数量。
//
// 40D0 电脑公司卡（Prop 1067）：显示使用卡片提示并等待；6001 子事件
// 302；6079 读取 packet+6；6061 记录卡片消耗。当前玩家为本地玩家时写 6006。
// 40D1 房产公司卡（Prop 1068）：结构与 40D0 相同，6079 的 BYTE 参数为 6。
//
// 40D2财神卡（Prop1069）：更新全局计时字段并置G+83834。顺序为提示、
// 若P+1488!=-1排6050、6061扣卡、无条件6006(+2=0)、6051、6083。
// 6051写+2=current、+3=0附身种类、+4=2输入标记、WORD+6=-1、WORD+8=132、
// WORD+10=101声音。+8/+9未被67F8F0消费，具体用途未知，不能称动画编号。
// 6083仅2字节记录；计时更新没有饱和分支。
// 40D3福神卡（Prop1070）：置G+83834，但不调用694870；提示、可选6050、
// 6061、无条件6006(+2=0)、6051的顺序同上。6051种类3、WORD+8=148（用途未知）、
// WORD+10=108声音；随后slot标志为0时排资源文本149，没有6083。
//
// 40D4察看卡（Prop1072）：packet+6是目标角色。先排6061，再无条件排
// 6006(+2=0)，然后调用
// 7CD670 检查目标持有防侦卡（Prop 1073）和地图资格。成功路径显示文本 265、
// 写 6001 子事件 316、6063 目标角色、再写 6061；失败不产生这些记录。
// 当前玩家本地且检查失败时，6003 UI28 记录携带全局目标值，进入察看卡界面。
//
// 40D5 安全核弹（Prop 1075）：packet+9 为分支标志。标志为 0 时先写 6007
// 子事件 62，然后始终写 6005 目标和 6000 type23 动画记录；标志为 0 时再写
// 6005 当前、6061 扣卡、6006 恢复。全局8B载荷是两个DWORD：+0由
// signed WORD[packet+6]扩展，+4由signed BYTE[packet+8]扩展；并非2B+1B紧凑结构。
// 安全核弹的文本描述属于资源证据，爆炸资格仍需继续追。
//
// 40D6 惡魔卡（Prop 1077）：由 P+1464 位置，经地图表得到地产索引和街道/分组
// 字段。6000 type5记录20B载荷：DWORD+0=1、DWORD+8=分组字段、BYTE+16=0；
// 其余字段本处理器不赋值，不能据此声称整块被清零。
// 另写地产索引的 4B type24 记录，再扣卡；当前本地时写 6006。
// 40D7 清除卡（Prop1078）：目标 packet+6；分别检查 P+1488 与 P+1491，命中时
// 写 6050/6065，并显示文本 245“定時炸彈拆除~”；无论命中与否都写 606F，
// 再扣除当前卡。6065/606F 的真实武器状态消费者已归档。
//
// 40D8 一步卡 / 40DD 六步卡：目标 packet+6；先显示文本、写 6007 子事件34。
// 若 P+1696 狂暴
// 标志非零，写 6001 子事件 316 与资源文本 359，并以 1350ms 提示；否则调用
// 7F83B0 清理 P+1498、1501、1502、1496。目标不是当前角色时分别写 P+1501
// 或 P+1502。仅目标不同且当前本地时写 6006。
// 40D9..40DC 二步至五步卡：分别使用 Prop 1080..1083；提示和 6007 子事件34均确认，
// 之后写 6061 即结束，未见显式 6006；效果依赖 6007/后续阶段，保持部分分析。
