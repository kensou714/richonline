// 八字节角色根
// ----------------------------------------------------------------------------
// A766D0                 懒创建根指针；当前磁盘初值0不是运行时状态。
// root+00   DWORD        数组容量；装载器第一遍扫描结束时写max(0, indx)+1。
// root+04   POINTER      连续C84字节记录数组；构造7F2C20只清此字段。
// 6276A0分配8字节，非空才调用构造，然后发布A766D0；没有锁或原子发布。
// 7F2C40仅释放非空数组并清+04，不重置+00，不调用逐元素析构。
// 629750先执行上述清理，参数bit0为1时再删除根；返回值是原this而非有效性保证。
//
// 单条角色记录 / 步长0C84（3204）
// ----------------------------------------------------------------------------
// +000  DWORD     mood；由文本atoi写入，不在本体证明其业务枚举。

// +014  DWORD     landFlag；配置数值，不从键名推地图或地产合法编号。
// +018  DWORD[]   suit0、suit1...连续写入；下一档案字段从+098开始。
//                物理间隔可容纳32个DWORD，但循环没有32上限检查。
// +098  CHAR[128] enName              +118  CHAR[128] xingZuo
// +198  CHAR[128] birthday            +218  CHAR[128] bloodType
// +298  CHAR[128] age                 +318  CHAR[128] shengXiao
// +398  CHAR[128] height              +418  CHAR[128] weight
// +498  CHAR[128] work                +518  CHAR[128] interest
// +598  CHAR[128] pet                 +618  CHAR[128] favor
// +698  CHAR[128] dislike             +718  CHAR[128] idol
// +798  CHAR[128] language            +818  CHAR[128] tag
// +898  CHAR[200] trait               +960  CHAR[800] introduce
// +C80  BYTE      indx低8位；数组定位仍使用完整atoi结果，不用此BYTE代替。
// +C81  BYTE      sex；girl为0，boy为1；strcmp区分大小写。
