// 分配与第二遍
// ----------------------------------------------------------------------------
// 81A090(0,0)重置文本游标；7F2E0A按count*C84向91BD80申请数组。
// 32位乘法没有溢出防护；分配非空才调用622D50初始化count条记录。

// 本体覆盖旧数组指针前未释放旧数组；重复装载可能失去旧数组所有权。
// 若分配失败，root+04仍为0，而第二遍继续；不能把返回1看作分配或模式验证。
// 第二遍继续扫描ROLE；record=root+04+atoi(indx)*C84，无空指针/负数/容量检查。
// 7F2EE7只把indx低8位写+C80；大于255的索引不会因此变安全。
// 相同indx后出现的节重复写同一条记录；已写字段与未写字段可混合。
