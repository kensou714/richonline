// ============================================================================
// 资源配置分组 / 字段布局与两级生命周期
// ============================================================================
// 配置根C
// ----------------------------------------------------------------------------
// C+3ABFC  DWORD   组数N。6D7C00清零；OTHER计数段累加；signed比较控制分配/循环。
// C+3AC00  DWORD   组数组Q。6D7C00清零；装载结果直接覆盖；6D7C30仅清该指针。
// C+40     子对象  取槽入口的ECX；本批仅恢复其+0数组基址和+8剩余计数消费。
// C+580CC  指针表  以slot*4索引登记R，R是12字节记录自身的地址。
//
// 两级数组
// ----------------------------------------------------------------------------
// 第g组基址 = Q + g*1200 = Q + g*4B0h。
// 第i项地址R = Q + g*1200 + i*12；本段i从0到99，均为signed比较。
// R+0  DWORD  配置npid数值；6DA3D0返回值经6DA3F0写入。
// R+4  DWORD  池中弹出的slot值；6DA3F9返回值经6DA416写入。
// R+8  DWORD  辅助字段，本OTHER片段未写；初始化为FFFFFFFF，业务意义待追。
// 三字段没有文本缓冲或字符串指针。npid与slot不可互换，反向表存R而非npid。
//
// 6D7C00：根中8字节成员的构造
// ----------------------------------------------------------------------------
// 6D7D00@6D7DEC把ECX调整至C+3ABFC，@6D7DF2经60906E进入6D7C00。
// 6D7C11写[this]=0，6D7C1A写[this+4]=0，返回this，无栈参数。
// 两个零分别是组数与指针；自动库识别名并不能证明这是某个MFC公开容器类型。
//
// 6DFA10与6D76C0：每组100项的默认值
// ----------------------------------------------------------------------------
// 6DFA1E压入6053F6→6D76C0；随后压入100、12和this。
// 6DFA2B经607E5D进入622D50：计数先减1，负数退出；ECX传项地址并按步长推进。
// 减法是32位回绕后看符号；INT_MIN减1会变成正数，不能泛化为所有负count均跳过。
// 迭代器正常返回ret10h；6DFA30恢复原this，外层本体ret无栈参数。
// 6D76D1、6D76DB、6D76E5依次写R+8、R+4、R+0为FFFFFFFF，返回R。
// 因此尚未装载的项并非零，而是三个DWORD均为-1位型。
// 外层loader再按组数N、步长1200、回调6DFA10构造整个数组。
//
// 6D7C30：只释放组数组，不重建状态
// ----------------------------------------------------------------------------
// 6D7EF0@6D8039把ECX调整至C+3ABFC，@6D803F经612B5F进入6D7C30。
// this+4为零则跳过；否则6D7C5D经601CD3调用91F7E0数组释放包装。
// 调用正常返回后6D7C68写this+4=0；本体从未清this+0组数。
// 91F7E0只把参数转给底层operator delete；本文不重审堆实现。
// 本体没有逐项归还slot或清C+580CC反向表；不能据此推定整个outer析构有悬指针BUG，
// 因为outer其余析构次序和池/反向表清理不在本批完整语义范围。
// 对一个已析构成员重新调用loader不能假定从空状态开始。
