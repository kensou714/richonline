// 二、静态事实（由当前机器码直接支持）
// ----------------------------------------------------------------------------
// 6DFA10(this)：调用 vector constructor iterator(this, 0x0C, 100, 6D76C0)，
// 即连续构造100项、每项12字节，并把6D76C0作为每项构造器。不能由此推断容量可扩展或元素有析构器。
// 6D76C0(this)：依次将 this+0、this+4、this+8 写为 0xFFFFFFFF；未写其他偏移。
// 6D7C00(this)：仅将 this+0 与 this+4 清零；未清理其他字段。
// 6D7C30(this)：仅当 this+4 非零时调用 delete[]，随后将 this+4 置零；不清 this+0，
// 也不清记录内容。delete[] 的具体元素析构语义不在本片原证中。
// 6D7660(this)：经桥调用 6DFD10(this)，再执行 RTC 检查；它是薄转发，不增加参数校验。
// 6DFD10(this)：先把 *(DWORD*)(this+8) 减一，再从 *(DWORD*)this + 4*新计数 取值返回。
//        原证没有空池判断；计数为0或无效时仍会先减一并进行地址计算，必须视为调用前提。
// 622D50：count 先减一；若结果仍非负，则以 stride 参数推进指针并调用回调；
//        原始条件是“32位减一后的符号位为1则退出”。count=0退出；常规正数按数量执行。
//        不能把它改写为所有count<=0都安全退出：INT_MIN减一回绕为正，边界需另审。
//        6DFA10 传 stride=12、count=100，不触及该极值边界。
//
// 三、分组 loader 的生产链事实与审阅边界
// ----------------------------------------------------------------------------
// 6D8130 的 OTHER_%d 扫描从局部计数0开始；键命中后才递增对象 +3ABFC。
// 当前有限窗口显示：命中结束后，若 +3ABFC<=0，跳过 4B0h 乘法、分配、构造及槽填充。
// 若计数为正，以 count*0x4B0 作为分配字节数；分配返回空指针时把 +3AC00 写零，
// 非空时以 stride=0x4B0、count、构造器 6DFA10 调用 vector constructor iterator，
// 最后把原分配指针登记到 +3AC00（不是取iterator的返回值）。未见独立容量上限或分配失败重试。
// 外层组循环使用 +3ABFC，内层每组最多100项；O_%d_S_%d 首个缺键直接结束当前组，
// 跳往下一组。不能据此宣称“缺中间项后仍会继续搜索”。
// 每个命中项：读取 npid，调用 atoi 后写记录 +0；调用 this+0x40 的 601896 后写记录 +4；
// 随后以记录 +4 作为 slot，直接写对象 +0x580CC + slot*4 = 当前12字节记录地址。
// npid查键与取串的返回值未检查；缓冲区在本次取串前也未先清空，不能把缺npid擅自说成默认0/-1。
// 当前窗口没有 record+8 写入；record+8 的默认值因此只能由6D76C0的 FFFFFFFF 初始化支持，
// 不能推断后续代码永远不改它。slot 没有在该窗口内做非负、上界、重复或冲突检查。
// +3ABFC 在本片关键片段开始前未被清零；是否由外层构造、调用协议或前序阶段保证为0，仍需调用方证据。
// 乘法是32位 imul；异常、整数回绕、空分配后的重入和重载行为没有动态证据，保持未知。
//
// 四、与已有消费者的交叉核对
// ----------------------------------------------------------------------------
// SysRes 6DB9D0 固定遍历100项、步长12，测试 Q+0x12C4+i*12 是否为 FFFFFFFF。
// 0x12C4=4*0x4B0+4，故读取OTHER第4组的record+4，返回其非FFFFFFFF项数。
// 该函数没有组数>=5或数组非空门；“slot字段非FFFFFFFF”也不等于对应文件必加载成功。
// 角色查表6DBA40的case10以signed group>=0、group<count、signed column>=0且column<100为门，
// 返回 Q+group*0x4B0+column*12+4 的DWORD。本分支未另查数组指针，不推导其它case或slot合法性。
// 622D50 的构造步长及 6DFA10 调用参数与 100*12 字节布局一致；不等于证明 C++ 类型名称。
//
