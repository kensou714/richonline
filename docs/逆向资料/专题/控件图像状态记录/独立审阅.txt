// 8E2200/2230没有显式保存ECX，却直接传递给8E1FB0；调用者必须提供owner。

// ID路径分别压9/8参数并由调用者清栈；默认函数读取正确的输出指针偏移。
// 回调仅检查AL；默认6E4D00/40无条件AL=1，管理器-1结果可能被镜像且保留。
// 缺回调或AL=0仍保存P+4并返回new_type；AL=0清槽但不清owner活动尺寸。
// 回调参数指向进入时索引槽，返回后清零/镜像重新读P+12；回调修改索引会改变后半程目标。
// 模型保持固定索引，不证明重入、并发或回调修改索引时的安全性。
