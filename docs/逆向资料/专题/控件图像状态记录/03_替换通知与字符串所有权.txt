// 8E1C70 / 8E1D10 / 8E1DB0：更新字段前通知旧资源
// ============================================================================
// 8E1C70写P+40*i+24；旧值!=新值且旧值!=-1时，若U+44回调存在则cdecl(C,i)。
// 8E1D10仅在P.type==5时写P+40*i+28；通知条件相同；其它type直接返回。
// 两者通知后写新字段，回调返回值不决定是否提交；没有事务回滚。
// 旧标识-2与-1不同：只排除精确-1，不能泛化成“所有负ID免通知”。
// 两个setter本体没有把P槽宽高置0；是否由通知/虚函数清除必须另核，不假设自动失效。
//
// 8E1DB0字符串替换
// ----------------------------------------------------------------------------
// 旧串和新串均非null且_stricmp相等时立即返回并保留旧字符串，无分配、通知或自动刷新。
// 此处大小写比较遵循CRT当前语义；不是所有编码的Unicode等价判断。
// 不等或任一null：旧串非null时先通知U+44，通知后重读槽中指针再delete并把槽置0。
// 非重入时释放旧串；回调若修改该槽，实际释放对象也可能变化，不能承诺始终释放最初指针。
// 新串非null且首字节非0则new(strlen+1)，复制包含NUL的新内容；否则槽保持null。
// 目标拥有该副本；不是借用调用者字符串。只识别本次替换释放，不声明整控件析构闭环。
// 分配返回null后无局部保护；分配抛出或回调异常也没有本函数事务恢复。
// 先释放旧串再读取新串；若新串指向旧块内部且比较不等，存在悬空读取风险，需外层不别名。
// rep stos/movs/scas依赖DF=0与可读NUL源；没有可用长度上限或局部溢出检查。
// 返回AL在不同路径混合比较结果/门状态/刷新返回值，不应当统一解释成成功bool。
//
// 自动刷新门
// ----------------------------------------------------------------------------
// C+385!=0时，C+384!=0只刷新index0；C+384==0只刷新index3。
// index1/2不经此门刷新，0/3也不是仅因字段改变必然刷新；还有P+4/type等后继门。
// 8E1C70/8E1D10即使值未变也继续经过刷新门；字符串相等路径则提前跳过门。
// 自动刷新调用8E2200，同时把P+12设为此次index；因此是状态切换与尺寸查询组合。
