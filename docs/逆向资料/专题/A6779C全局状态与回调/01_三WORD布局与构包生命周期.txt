// ============================================================================
// 三个 WORD 的静态布局与临时构包
// ============================================================================
// 地址       宽度    静态初值   在栈参数中的位置
// A6779C     WORD    FFFF       +0..1
// A6779E     WORD    FFFF       +2..3
// A677A0     WORD    FFFF       +4..5
// A6779C 的 IDA 名为 dword_A6779C；这是前两个 WORD 的合并读取视图。
// 本专题用三个 WORD 表达已观察到的写入粒度，不据此宣称原源码存在同名结构体。
// 栈上保留 8 字节，当前可见写入只覆盖前 6 字节；+6..7 未见写入，不应命名。
//
// 直接交叉引用计数
//   A6779C：130 次 WORD 写、130 次 DWORD 读。
//   A6779E：130 次 WORD 写；它的读被 A6779C 起始的 DWORD 读覆盖。
//   A677A0：130 次 WORD 写、130 次 WORD 读。
//   130 组均在附近读回 A6779C DWORD 与 A677A0 WORD，复制到 8 字节栈区后回调。
//   这只证明可见直接引用；若存在计算地址、别名或动态写入，交叉引用不会自动覆盖。
//
// 代表指令链：840230 的 840278..8402EB
//   840278 写 A6779C=FFFF；8402A2 写 A6779E=605CB6 的 AX。
//   8402C9 写 A677A0=602D63 的 AX；8402D1 sub esp,8。
//   8402D6 读 A6779C DWORD，写 [esp+0]；8402DE 读 A677A0 WORD，写 [esp+4]。
//   8402E9 push 8；8402EB 经 ACB864 回调本地类别 8。
//   同函数 840300 再把前两字段置 FFFF，84031A 写第三字段，类别 105 回调。
//   82BBE0 高频数据入口专题已核 +16 指针链；此处只引用其 840230 局部消费结论。
//
// 写入形态统计；这是 130 个最近写入三元组，不是事件值域定义
//   FFFF/FFFF/FFFF：72；FFFF/FFFF/AX：29；FFFF/AX/AX：19。
//   FFFF/AX/FFFF：4；AX/AX/AX：3；FFFF/FFFF/FFFE：1。
//   1/AX/AX：1；AX/FFFF/FFFF：1。
//   AX 的来源因调用者而异，不能将同形三元组赋予统一的网络字段语义。
//   FFFF 常作缺省填充值；这里不证明所有消费端都按“无值”解释它。
//
// 生命周期界限
//   磁盘 .data 三 WORD 初值均为 FFFF。130 个可见构包点各自先写三个字段再读回。
//   复制后调用间接回调；不是网络发送函数，也没有观察到调用后统一复位。
//   因此它更像回调入参的共享临时缓冲，不能把上一次调用留下的全局值当持久状态。
//   局部窗口没有证明互斥、线程亲和或实际交错；并发安全性需运行时证据。
//   补丁若复用这里的数据，应在本次调用构包前完整写入三字段并明确定义栈区余字节。
//
// 例外：829FAA
//   该站点属于已声明函数 828F60，回调类别 24，经 ACB864。
//   它使用 ebp 局部变量中的两个 FFFF WORD 与从 A67790 取出的一个 WORD，
//   再组装同形 8 字节栈区；不访问本专题三个全局 WORD。
//   故 131 个回调调用只有 130 个能和 A6779C..A677A0 全局写入组匹配。
