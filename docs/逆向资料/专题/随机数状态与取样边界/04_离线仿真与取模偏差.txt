// 离线仿真与取模映射
// ============================================================================
// simulate.py只做整数模型；未运行客户端、未注入随机值、未连接服务端。
// 递推按uint32显式截断，并用16位分块乘法独立交叉核对6个种子共96步。
// seed=1的前5项：41、18467、6334、26500、19169。
// 其它种子含0、7FFFFFFF、80000000、FFFFFFFF、123456789，原状态与输出见simulation.json。
//
// 以下枚举0..32767每个可能输出各一次，只评价取模映射的基数。
// 不是对某条实际种子序列的概率测量，也不证明前后输出独立或任何短周期均匀。
// 令32768=q*n+k，则余数0..k-1有q+1个原像，其余有q个原像。
//
//   n=6      q=5461  k=2    0、1各5462个原像，其余5461。
//   n=16     q=2048  k=0    每项2048个原像；映射无基数偏差。
//   n=62     q=528   k=32   前32余数529个，其余528。
//   n=601    q=54    k=314  前314余数55个，其余54。
//   n=1401   q=23    k=545  前545余数24个，其余23。
//   n=32768  q=1     k=0    每项1个原像。
//   n=32769  q=0     k=32768，最后索引32768不可达。
//   n=6是算法边界示例，不是本批已经证明的骰子调用者。
//
// 区间反例
//   [10,10] -> 总是10；[10,9] -> 除数0；[10,8] -> 除数-1，总是10。
//   [0,32768] -> 最大只能32767，虽然代码写法看似两端包含。
//   [-2147483648,2147483647] -> 宽度按32位回绕0，发生IDIV0。
//   模型显式实现向0截断商及余数；Python原生负数%不同，不能直接照搬。
//
// short符号扩展
//   WORD 0000 -> 0；7FFF -> 32767；8000 -> -32768；FFFF -> -1。
//   这一步由7ECA7A MOVSX证明，不是根据反编译器__int16单独猜测。
//
// 使用范围
//   相同种子在相同存储槽和相同rand消耗顺序下可复现本模型序列。
//   实机调度、重播种时间、其它消费者、候选表和动态状态均会改变观察结果。
//   本模型适合补丁回归及资源边界检查；不冒充服务器公平性或掉落概率测试。
