// 取样与过滤器
// ----------------------------------------------------------------------------
// 7D83D0先rand，再32位计算b-a+1，CDQ/IDIV取余，最后机器32位相加。
// 正常正宽度两端形式包含，宽度>32768时尾部不可达；倒序不自动交换端点。
// a10/b9与整个int32区间宽度为0；a10/b8除数-1而结果恒10，模型与汇编相符。
// 这些是参数边界，不证明真实调用者已经传入错误值。
//
// 7E1420读取ECX对象+156计数和+160数组，返回DWORD元素而非取样下标。
// 7ECA40对this+45C容器取count，695010以2*index读AX，7ECA7A再MOVSX。
// FFFF返回-1、8000返回-32768，不能依据候选编号习惯改写为unsigned short。
// 两取样器都未检查零计数或数据指针，表的合法性仍依赖未闭合的写入链。
//
// 7E20A0入口ECX保存this，栈arg0为有符号次数上限，<=0直接返回-1。
// 每轮取short样本，前四过滤器用原this，第五在7E2136取[this]作为ECX。
// 五次只判断AL；任一非零继续，全部零才返回样本，次数耗尽返回-1。
// 正常short值-1也能进入过滤，因此返回-1的业务含义不能仅据返回值确定。
// 本地取样与包装指令未显式删除元素；未闭合过滤器内部副作用时，不能无条件
// 宣称整个流程一定有放回。重复取样结论须以过滤器不修改候选集合为前提。
