// 取样算术与容器契约
// ============================================================================
// 有符号区间：60B486 -> 7D83D0
//   参数a、b；先rand，再用32位SUB/ADD计算n=b-a+1。
//   CDQ + IDIV ECX取有符号余数，最后a+余数也按机器32位运算。
//   正常递增且宽度n可表示为正int32时，结果落在[a,b]，两端形式上包含。
//   n>32768时仅a..a+32767可达，不能覆盖整个区间。
//   n=0会IDIV异常；例a=10,b=9，或全int32区间宽度回绕为0。
//   倒序不能理解成自动交换端点：a=10,b=8导致除数-1，每次结果10。
//   无参数校验，也没有凭这些例子证明真实客户端已触发此错误。
//   仅已知调用点7B2CBB未归属IDA声明函数，业务用途仍保留未证。
//
// DWORD数组取样：60A685 -> 7E1420
//   this来自入口ECX；+156 DWORD为除数count，+160指向DWORD数组。
//   rand % count后读取base+4*余数；返回元素值，不返回随机下标。
//   必需条件是count>0且数组至少count个可读元素；函数内没有检查这些条件。
//   count=0发生除零；负count也不会获得合法集合语义；大于32768存在不可达尾部。
//   未声明调用点81011C、810233仅作导航；不能给数组元素强行命名角色/卡片/地图。
//
// short容器取样：6022BE -> 7ECA40
//   成员C=this+0x45C；695040返回[C+0]，作为有符号count除数。
//   695010从[C+12]读取base，以index*2加载AX；没有内部边界检查。
//   调用处7ECA7A执行MOVSX EAX,AX，所以结果是-32768..32767的有符号short。
//   此处不能改成unsigned short；0xFFFF返回-1，0x8000返回-32768。
//   count=0、空base、无效计数都没有在本函数处理。
//   集合装载逻辑及元素业务意义未闭合，不推断所有合法数据一定非负。
//
// 有限次数过滤：7E20A0
//   虽然伪码标__stdcall，汇编保存入口ECX为this；栈arg0是最多尝试次数。
//   arg0<=0直接返回-1；每次重新7ECA40取样，再依次执行5个AL布尔过滤。
//   前4次用原this；第5次7E2136先取[this]作ECX，不能把所有过滤都当同一对象方法。
//   5次AL均0才返回样本；任一非0进入下一次；次数耗尽返回-1。
//   本包装与取样器未显式移除元素；过滤器不改集合时可重复取样。
//   外部过滤器副作用未闭合，不能无条件认定整个调用链始终有放回。
//   即使集合不变且存在合格项，也不保证有限次一定选到。
//   返回-1既可能是次数耗尽，也可能是未被过滤掉的short值FFFF；调用者须自行判义。
//   过滤目标63EB50、691D00、691D40、691D80、7BFE20仅解直接跳板，不恢复其全部业务。
//
// 给资源与补丁作者
//   增加候选表时同步数量、元素宽度和初始化顺序；空表不能直接交这些入口。
//   保持x86有符号余数和short符号扩展，Python负数%行为不能直接当原机语义。
//   如需更多候选或无偏选择，应单独设计兼容补丁和测试，不把此处记录当已修改行为。
