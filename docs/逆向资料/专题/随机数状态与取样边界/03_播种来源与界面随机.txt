//   623ADE / 623AD0：启动入口的time(NULL)结果。
//   6AA558 / 6AA530：timeGetTime结果；后续按分支容器取模，复用计时专题。
//   81FA83 / 81F950：音乐初始化成功路径的timeGetTime结果，复用音频专题。
//   911CF0 / 911AB0：对话框初始化的time(NULL)结果。
//   914090 / 913E90：输入处理后的time(NULL)结果。
//   914474 / 914220：另一输入处理后的time(NULL)结果。
//   9158C4 / 9157F0：界面布局构造中的time(NULL)结果。
//   这里只统计静态直接引用；未声称排除任何间接调用或动态代码。
//
// 重播种的实际边界
//   同一CRT槽使用相同Seed重新srand后，会从相同首项重新开始。
//   time按秒得到相同值的多次输入可能产生相同前缀；timeGetTime也不是独立随机熵。
//   音乐初始化或效果选择如与其它消费者使用同槽，会重置其后续序列。
//   静态调用图没有证明实际执行线程/fiber关系，不夸大为所有模块必定互相干扰。
//
// 随机窗口位置：911AB0的WM_INITDIALOG局部
//   先取父窗口与对话框矩形，播种后分别rand%水平余量、rand%垂直余量。
//   余量是父窗口尺寸减计算出的目标对话框宽高，再叠加父左上角，最后MoveWindow。
//   目标宽高在ACC41C+4388/+4384，由非客户区差值加布局虚表+32返回尺寸得到。
//   这两值也传给MoveWindow；不是直接拿旧hDlg矩形宽高作为取模减数。
//   取模后没有+1，正余量时不会选到最大边界位置。
//   余量0时本分支没有防止IDIV0；未证明实际窗口配置能够触发。
//   完整对话框提交/关闭和认证业务未在此群闭合。
//
// 显示用随机字符串：913E90 / 914220局部
//   两者先维护this+400处实际文本，再按其长度生成显示Buffer。
//   r=rand()%62；0..25映射a..z，26..51映射A..Z，52..61映射0..9。
//   向this+392控件发0xCC，wParam='*'；再发0x0C，lParam=随机Buffer。
//   原始文本没有在该生成循环被随机串覆盖；不能把随机串称为密码加密或认证挑战。
//   这两个优化函数用EBP保存入口ECX，访问[ebp+190h]指对象字段，不是普通栈局部。
//   实际输入长度上限、按键映射及完整控件生命周期需沿原界面专题继续闭合。
//
// 布局宽度：9157F0局部
//   Lower/Upper两组普通字符控件各有一处rand%16+10，范围10..25。
//   915DB5、9163AF经对象虚表+36传位置、宽度、固定高度25和标志1。
//   编译后的AND 8000000Fh及负数修正是有符号%16模式；rand非负所以不走负数修正。
//   此处只确认宽度随机，不声称恢复整套软键盘或全部资源布局。
//
// 股票辅助浮点：已有专题复用
//   80E6B0为float(rand%601-300)/100，范围[-3,+3]。
//   80E710为float(rand%1401-700)/100，范围[-7,+7]。
//   A23388原始float为100.0；中间先FILD再FSTP float，最后FDIV。
//   步长形式为百分之一，但二进制浮点并非每格十进制数都精确。
