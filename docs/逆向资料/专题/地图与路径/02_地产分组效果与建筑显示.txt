// 模式3下actor经另一映射分支再用于地块资源变体；不是所有地图都直接actor+1。
// 7E3E60(actor,index)：执行特定大地产清理分支后owner=-1，重取中立地块图并刷新。
// 7E3B80(new,old)：遍历总格数，旧业主匹配的格先解除再赋予新业主。
// 7E32F0(a,b)：只交换建筑种类与等级，不交换业主、分组、价格、图像句柄。
// 因而调用者还需处理可视刷新；不能把它描述为完整地产互换。
// 7E3CE0：kind11返回500、kind12返回1500，其他-1；只是底层基础返回值。
//
// 升降级判据的差异
// ----------------------------------------------------------------------------
// 7E3D30：排除建筑种类8/9/10；模式0要求等级<5，其他模式要求等级<7。
// 7E3DF0：排除建筑种类8/9/10，并要求等级>0。
// 7E3F30：有符号BYTE等级扩成32位加delta，低8位先写回，再按有符号BYTE上夹。
// 模式3或4上夹7，其他模式上夹5，返回是否到硬上限。
// 7E3F4A为movsx，7E3F4F为DWORD加法，7E3F5E写AL；其后movsx并有符号比较。
// 静态例：等级1加delta127先写0x80(-128)，不会夹顶；大正delta并不保证夹到5/7。
// 7E3D30与7E3F30的模式条件并不完全相同，不应合并为一个不区分调用场景的常量。
// 7E3F30没有下夹0；必须由上层保证输入。也不自行刷新建筑图像。
// 7E4020：减等级，<=0时夹0；kind11重设建筑种类0，kind12重设为-1。
// kind11原种类10且有业主时还进行解除/重新归属以更新图像。
// 这些是底层实现事实；BOSS关卡可建种类、技能与上限仍需查对应配置和通信处理。

// 分组效果与WORD列表

// +6是有符号WORD分组编号，63F100返回；以下操作均遍历地图+1132普通地产列表。

//   7E34D0/7E3480将正数减一。具体效果名称未由本批消费端确认。
// +5效果B：7E3560直接接收分组号；7E3510把同组+5置5。

// 不把5直接写成“5回合”：本批没有完成递减入口与回合消息的时序追踪。

// 批量建筑效果
// ----------------------------------------------------------------------------
// 7E37B0/7E3670：同分组且等级<5时，kind11建筑种类非1则+1；kind12若等级0
// 先改建筑种类为3，再+1；逐格刷新7E73F0。
// 7E38C0/7E3840：同分组且等级>0，调用降级1并刷新。
// 7E3AF0/7E3950：匹配业主而非分组；kind11非种类1或kind12增加2级，上夹5；
