// 容量增删与所有权
// ============================================================================
// 这里的 capacity 与 count 是两个量；文本拥有关系独立于行状态。
// 主证：8F30A0、8F32C0、8F35D0、8F39D0、8F4690、8F4C20、8F4EA0。
// 内部依赖：8F6B00、8F6B50、8F6C10、8E1800、8E1620。
//
// 构造与默认容量
//   8F30A0 调父构造 90B800，写虚表 A307D4。
//   将数组与 capacity 置 0，再调用 8F35D0(256) 分配初始行数组。
//   count、宽度/偏移/字符计数等置 0；MaxCount=-1、Space=0、
//   MultiSelect=0、AutoChangeLine=1，两个滚动条指针为 0。
//   不能仅因初始容量为 256 就认为配置 MaxRow 固定或受此上限限制。
//
// 修改容量：8F35D0(newCapacity)
//   在入口用 32 位乘法 160*newCapacity 求分配大小并调用 operator new。
//   没有输入下界、整数溢出或最大容量检查；a2<=0 的分支在分配之后。
//   清零新数组，为每槽初始化两个文本子对象，并继承控件字体高度。
//   保留槽数=min(oldCapacity,newCapacity)，不是 min(count,newCapacity)。
//   复制状态/折行标记/样式，以 8E1800 与 8F6C10(mode=1) 复制文本。
//   count 若超保留槽数则缩减；遍历 oldCapacity 的所有旧槽释放两个对象。
//   delete 旧数组，保存 newCapacity，重算字符计数，重置两方向偏移。
//   已证是重新分配和深复制，不能视作原地 realloc 或裸内存移动。
//
// 插入：8F39D0(index)
//   index>=capacity：将 capacity-1 个槽前移，清末槽并复制两个模板；
//       重算字符计数，不增加 count。此路径承担满容量追加时的滚动行为。
//   index<capacity：先检查 MaxCount=-1 或 字符计数+1<=MaxCount。
//       当 count>index 时从 table[count] 开始向后复制现有槽；
//       清 index 槽，复制主/提示样式模板，count++；index!=0 时计数++。
//   仅 index 与 capacity 作有符号比较；没有 index>=0 检查。
//   当 count==capacity 且 index<count 时，首个复制目标是 table[count]，
//       指向容量之外的一槽。函数没有另行检查 count<capacity。
//   容量为 0 而进入滚动路径也会形成 table-160 的末槽地址。
//   这些是本函数的静态输入前提，外层限制与实机可达性尚未恢复。
//
// 插入并设置文本：8F4690(index,text)
//   只排除 index>capacity；count<=index 时连续调用插入，否则只插入一次。
//   当 index==capacity 时将最终设置文本的索引改为 index-1。
//   再经虚表+252 调用 8F42D0 设置文本。
//   A307D4+244 的跳板 60FD0B 指向本函数；
//   A307D4+252 的跳板 60FA1D 指向 8F42D0，已由磁盘虚槽字节确认。
//   本函数也没有负索引检查，不能将其作为安全的对外编辑接口。
//
// 删除：8F4C20(index)
//   只有 index<count 的有符号上界检查；没有 index>=0。
//   先 count--，从累计高度类字段减去被删行的字体高度与行间隔。
//   清主文本字符串、缓存与节点；后续行前移，逐个复制状态及折行标志。
//   主/提示子对象均调用 8F6C10(mode=1)，不是 memmove。
//   清新 count 的尾槽，释放两个子对象，更新滚动条、最大宽与字符计数。
//   前移期间没有把源指针转交给目标；文字经子对象 setter 深复制。
//
// 清空与析构
//   8F4EA0 遍历当前 count 的槽，释放两个文本子对象，重置 count、
//       字符计数、宽度类字段与偏移；保留数组与 capacity 以便复用。
//   8F32C0 处理四个背景风格资源，遍历全部 capacity 的槽释放两个对象；
//       delete 行数组并置空；对滚动条调用虚表+120，最后进入父析构。
//   清空与析构不能互换；“已清空”不等于“未分配行数组”。
//
// 子对象的资源规则
//   8F6B00 初始化：三个指针及度量置 0，默认高度 12、类型 0、
//       UseCtlText=0，背景色 0、前景色 0xFF000000。
//   8F6B50 清字符串和宽度缓存；链节点的 next 改连 ACC3C4 后重置对象。
//       控制节点不是逐节点 operator delete，而是回收到全局池。
//   8F6C10 清目标累计宽度并复制样式；mode=0 不改文本拥有指针，
//       mode!=0 经 8E1800 设置文本，不复制源字符串指针。
//   8E1800 文本相同时保持对象；否则释放旧字符串/缓存、回收旧节点，
//       为非空文本分配 2*wcslen+2 字节并复制，再调用 8E1620 重建度量。
//   因此不要直接 memcpy 一条 160 字节记录；那会复制多个拥有指针。
//   专用工具应在自身模型中保存字符串与样式，再通过受检查接口提交。
