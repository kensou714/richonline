// 文本布局与配置兼容
// ============================================================================
// 本文描述当前二进制的行为，不能直接替代未来编辑器的输入检查。
//
// 字符数与宽度不是同一单位
//   8F5260 遍历当前行；非空文本的计量加到 L+820，行间再加 1。
//   ACC3C8+0x5128 的 DWORD 非零时用 wcslen，零时用 8E0AA0。
//   8E0AA0 按 16 位字符计量：(character & 0xFF80)!=0 算 2，否则算 1。
//   这不是 UTF-8 字节数，也不是完整 Unicode 字符/字形数。
//   8E1620 另行分配 wcslen+1 字节的每字符宽度缓存；通过引擎回调
//       填充字形宽度或控制文本节点，并累计 P+12 像素宽。
//   8E1620 的伪码显示可变参数原型；这里只确认调用和对象字段，
//       未恢复所有字体/控制文本回调，不把该原型当成可直接调用的 ABI。
//
// 拆成多行：8F41B0(text,recognizeEscapedNewline)
//   遇到 LF 拆行；选项真时额外识别字面反斜杠+n 两个宽字符。
//   在输入字符串上临时写 0，虚表+244 追加当前 count 行，然后恢复。
//   输入必须可写；不得将只读字符串常量直接交给此入口。
//   同步消费期间输入会短暂改变；异步留存指针的扩展也须避免依赖此状态。
//   CR 的完整兼容处理不在本文承诺范围内。
//
// 设置一行文本：8F42D0(index,text)
//   只判 index<capacity；必要时插入空行直到 index 已存在。
//   MaxCount 检查扣除旧文本计量并加入新文本计量。
//   超限时清零 0x5000 字节栈缓冲，按宽字符复制 N 个字符再设置。
//   wcslen 模式：N=oldWcsLen+MaxCount-currentCount。
//   加权模式：超限比较扣 oldWeightedLen，但 N 仍使用 oldWcsLen；
//       因此比较的计量单位与截取的宽字符单位不同。
//   原证：8F43EA 读取 oldWcsLen，8F43F0 与剩余配额相加。
//   没有明确检查 0<=N<=10239；10240 个宽字符容量还须留下终止符。
//   已证为静态输入边界，未证实际资源/通信文本能够构造越界 N。
//   超限路径将 L+820 直接置 MaxCount；随后按 AutoChangeLine 折行、
//       更新最大宽度与滚动条；起始行被更新时水平偏移也会重算。
//
// 自动折行：8F5300(index)
//   不检查 index 范围，读取 R+8 和 R+20；当前计数恰等 MaxCount 时跳过。
//   文本像素宽超可用宽时，90CE80 返回切点，并填充一个局部输出值。
//   两个 0x5000 字节栈缓冲分别复制头部与尾部；未见显式容量检查。
//   写回头文本、重算字符数，R+4=1，再经虚表+244 插入 index+1 的尾部。
//   90CE80 的切点契约未展开，不能假定切点始终落在 [0,wcslen]。
//   未证明完整递归折行终止性；编辑器宜先在自己的安全模型中校验长度。
//
// 可用宽、高与可见行数
//   8F4B10：字体高度为 0 返回 0；否则 width=L+352-4。
//       若垂直条 L+416 非空且条+387 的 BYTE 为 0，再减条+352。
//       未将结果钳到非负数。
//   8F4B60：height=L+356；若水平条 L+412 非空且条+387=0，
//       再减条+356；没有字体高度为 0 的判断或非负钳制。
//   8F4BA0：仅先排除 L+120=0；重新计算可用高后做有符号除法。
//       visibleRows=height/(L+120+L+588)。
//       汇编 8F4BE4、8F4BF9 均为 idiv ecx；字体高度非零并不保证
//       高度与间隔的和非零，例如 Space=-Height；也未防整数溢出。
//
// 滚动行为
//   8F40D0 按来源是否为 L+412 或 L+416，将 '+'、'-'、'=' 路由
//       到水平偏移或起始行 setter。
//   8F5DE0 先将负起始行钳为 0；当 count-visibleRows>0 才在超界时
//       把起始行置为该差值。行数不足一页时不强制清除任意正起始行。
//   8F5E60 立即读取 table[startRow]+20；没有 startRow 有效性检查。
//       偏移超过当前行宽-可用宽时只减一次可用宽，再把负值钳到 0。
//       这不是标准的 min/max clamp，重复调用也可能产生不同结果。
//   8F5080 扫描 R+20 求所有当前行的最大宽，更新水平条范围。
//
// 配置解析兼容点：8F8080 局部审阅
//   MaxRow 调用 8F35D0，MaxCount 直接写 L+824，
//       MultiSelect 写 L+801，AutoChangeLine 写 L+828。
//   解析先调用父 label 解析器，再将模板样式复制到当前行；
//       随后才读取本控件的颜色键。未展开后续全部刷新时序。
//
//   检查存在的键        实际读取的键      写入偏移
//   NorFontBColor       NorFontColor      L+132
//   DownFontBColor      DownFontColor     L+136
//   InFontBColor        InFontColor       L+140
//   DisFontBColor       DisFontColor      L+144
//   上述四组同时由汇编 push 字符串、字符串原始字节与引用位置确认。
//   检查地址：8F8CCE / 8F8D10 / 8F8D51 / 8F8D92。
//   取值地址：8F8CED / 8F8D2E / 8F8D70 / 8F8DB1。
//   对应前景色配置顺序为 Nor/Down/In/Dis，写 L+148/+152/+156/+160。
//   不能只提供 FontBColor 就假定背景色值来自该键，也不应把其它控件的
//       状态次序机械套用到这里。取不到 FontColor 时的完整默认行为未追。
//   此兼容异常属于当前解析器；修补前须在不同组合的配置上做实机对照。
//   其它背景纹理、资源名与特殊显示分支未逐项审阅，见函数审阅清单。
//
// CapText 初始内容路径
//   8F8080 读取 CapText；非空时先清零局部缓冲，若 ACC3C8 的第18个
//       DWORD 为非空函数指针，先经该回调转换/查找输入文本。
//   随后调用 8E0650 的跳板入口 60DBA0 做宽字符转换；转换器内部未展开。
//   从转换结果固定复制 1024 个宽字符，再经虚表+232 调用 8F7D40，
//       传入缓冲和选项 1。slot232 跳板 606F99 与目标已核验。
//   本专题未展开 8F7D40 的主体，不把它直接等同于 8F41B0。
//   固定读取 1024 个宽字符是否依赖转换器的共享大缓冲，需另行恢复；
//       不能仅凭复制循环断言普通短 CapText 会发生读取越界。
