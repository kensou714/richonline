// 对象与行记录布局
// ============================================================================
// 记号：L 为 listbox 控件对象；T=DWORD[L+592]；R=T+160*i。
// 所有偏移按字节计。与伪码的 DWORD 数组下标不同，不能混用单位。
// 主证：8F30A0、8F35D0、8F6B00、8F6B50、8F6C10；颜色 setter 组。
//
// 控件字段
//   L+12     提示文本样式模板，76 字节；其字体高度在 L+44。
//   L+88     主文本样式模板，76 字节；其字体高度在 L+120。
//   L+120    主模板字体高度；不是每行高度的唯一来源。
//   L+124    主模板字体类型。
//   L+128    UseCtlText，BYTE。
//   L+132..144  四个主模板文字背景色，DWORD。
//   L+148..160  四个主模板文字前景色，DWORD。
//   L+352    控件宽度。
//   L+356    控件高度。
//   L+412    水平滚动条对象指针。
//   L+416    垂直滚动条对象指针。
//   L+588    行间隔；与字体高度相加参与可见行数计算。
//   L+592    行数组指针。
//   L+780    累计高度类字段；删除时减 R+40 与 L+588 之和。
//            本专题未穷尽所有写入，不能视作完整总高度契约。
//   L+784    当前行数 count。
//   L+788    最大行宽；8F5080 扫描当前行 R+20 后更新。
//   L+792    水平偏移。
//   L+796    垂直起始行索引。
//   L+801    MultiSelect，BYTE。
//   L+804    已分配容量 capacity。
//   L+820    字符计数，包含行间分隔计数。
//   L+824    MaxCount；-1 表示不限。
//   L+828    AutoChangeLine，BYTE。
//
// 一条行记录，160 字节
//   R+0      状态 DWORD；0 是普通行，1 或 4 被 8F3F10 当作选中。
//            未恢复其它所有状态及鼠标过程中的状态转换。
//   R+4      自动折行标记 BYTE；8F5300 折行后置 1。
//   R+5..7   未命名的填充/保留字节。
//   R+8      主文本子对象 B，76 字节。
//   R+84     提示文本子对象 H，76 字节。
//
// 文本子对象 P=B 或 H，布局相同
//   P+0      拥有的宽字符字符串指针。
//   P+4      格式/控制节点链；节点+12 指向下一节点。
//   P+8      每字符宽度缓存指针；8E1620 分配 wcslen+1 个字节。
//   P+12     累计像素宽度。
//   P+16..28 四个字体相关 DWORD 参数；业务名称未逐一恢复。
//   P+32     字体高度；8F6B00 默认 12。
//   P+36     字体类型。
//   P+40     UseCtlText，BYTE。
//   P+41..43 未命名的填充/保留字节。
//   P+44..56 四状态文字背景色。
//   P+60..72 四状态文字前景色；初始化为 0xFF000000。
//   字符串/宽度缓存由子对象管理；控制节点回收到全局 ACC3C4 链。
//
// 将子对象偏移展开到行
//   主文本：R+8 字符串，+12 节点，+16 宽度缓存，+20 总宽。
//           +40 高度，+44 类型，+48 UseCtlText。
//           +52/+56/+60/+64 背景色；+68/+72/+76/+80 前景色。
//   提示文本：R+84 字符串，+88 节点，+92 宽度缓存，+96 总宽。
//             +116 高度，+120 类型，+124 UseCtlText。
//             +128/+132/+136/+140 背景色；+144/+148/+152/+156 前景色。
//
// 样式 setter 的范围
//   8F4790/8F47E0/8F4830/8F4880：写 L+148/+152/+156/+160，
//       并同步 count 行的 R+68/+72/+76/+80。
//   8F48D0/8F4920/8F4970/8F49C0：写 L+132/+136/+140/+144，
//       并同步 count 行的 R+52/+56/+60/+64。
//   8F4A10：写 L+128 和当前行 R+48，随后重新生成主文本度量。
//   8F4A90：写 L+124 和当前行 R+44，随后重新生成主文本度量。
//   8F4710：模板 setter 8E2260 只在非零时改 P+32；当前行 R+40
//       却无条件写入该值并重算。因此传 0 时模板与已有行可能不一致。
//   以上组未同步提示文本的同名字段，不能泛化为整个行的样式统一接口。
//
// 选择与命中
//   8F3FD0 单选时先清所有行状态，再检查 0<=i<count，将目标状态置 1。
//   8F3F10 单选返回第一个状态 1/4 的索引；无选中返回 -1。
//       多选按 pow(2,i) 累加到 32 位 int；高索引的表示边界未完整恢复。
//   8F3E20 从起始行按每行 R+40+间隔累计鼠标纵坐标；越界返回 -1，
//       遍历到末端可能返回 count 哨兵。调用方仍须区分有效索引与哨兵。
//   引擎坐标来源和完整鼠标事件流程未展开。
