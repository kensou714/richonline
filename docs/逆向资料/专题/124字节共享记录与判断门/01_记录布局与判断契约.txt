// 124字节记录与判断契约
// ============================================================================
// 下述M代表传入ECX对象，B=DWORD[M+5D8]，N=signed DWORD[M+5DC]。
// R(i)=B+124*i；乘法与加法均为x86的32位结果，不自动保证内存已分配。
// 当前证据给出结构偏移与消费规则，不预命名为政治、权限或角色数据。
//
// 公共边界和取址
// ----------------------------------------------------------------------------
// 6B7D60@6B7D77/6B7D83用jl/jge实现 signed 0<=i<N；AL返回0或1，retn4。
// N<=0时无合法索引；函数不读B、不判NULL、不查记录+4，不证明实际存储容量。
// 6B7DC0@6B7DD1/6B7DD7直接算B+124*i并返回EAX，retn4，没有调用公共门。
// 它返回借用地址，没有分配和复制；调用者必须维持底层存储及索引有效性。
//
// 五类字段判断
// ----------------------------------------------------------------------------
// 6B7CE0：先公共门，再检查DWORD[R(i)+4]!=0；它不检查所指对象内容。
// 6B7DF0：先公共门，再检查DWORD[R(i)+78]==1；2、-1等非零值仍返回0。
// 6B7E70：先公共门，再比较signed DWORD[R(i)+60]>=signed DWORD[R(i)+3C]。
// 真实比较6B7EBD/6B7EC1使用jl；不能按伪码DWORD类型改成无符号比较。
// 6B7F10：先公共门，再检查signed DWORD[R(i)+60]>0；用jle排除0和负数。
// 6B7F90：先公共门，再取P=DWORD[R(i)+4]，读取DWORD[P+20]的bit0。
// F90在6B7FC9/6B7FCD直接两次读内存，未调用CE0，也没有P的NULL判断。
// 所有上述谓词均retn4、以AL返回布尔；其他返回寄存器高位不能当规范化DWORD布尔。
// 索引通过只能证明数值域，不足以证明B、P有效或数组未被释放。
//
// 当前已见字段
// ----------------------------------------------------------------------------
// R+00 DWORD：734460从此读取后续谓词的索引；本批不先假定它恒等原数组下标。
// R+04 DWORD指针：CE0判断非零，F90进一步读取指向对象+20 DWORD bit0。
// R+38 DWORD：6A5960送给四个分类谓词；分类函数按实际短依赖原证解释。
// R+3C DWORD：E70有符号比较的右值。
// R+48 DWORD：734460送6A39A0，不能与原数组索引混同。
// R+60 DWORD：E70有符号比较的左值，F10判断>0。
// R+74..77：四BYTE，旧6A6CD0逐字节清零。
// R+78 DWORD：DF0判断严格等1；旧6A6CD0清零。
// 未列出的间隙不是已证明保留字段，也不代表可安全填充。
