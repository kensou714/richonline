// A76704 单例与 7E8EB0 加载器
// ============================================================================
// 6015B7 -> 628C60：若 A76704 为零，分配 8 字节并交 6046B3 -> 7E8E40。
// 7E8E40 只把对象首 DWORD 设零，不初始化 +4 计数。分配失败时槽保存零。
// 此处无锁和局部并发保护；尚未证明该入口在多线程同时调用。
// 623FA2 推 Data\MapView.kpd，623FA7 取单例，623FAE 经60E375调用加载器。
// 623FB3 检查返回；零时走启动失败出口。该窗口不认领整个启动函数。
//
// 正常加载顺序
// ----------------------------------------------------------------------------
// 60FD9C -> 81B4C0 读取资源失败：清理临时资源对象，返回零；目标对象未清。
// 成功后建立解析器和临时 Map，用模式2读取解码内存；目标 +4 计数先清零。
// 第一遍重复找 ITEM，每成功一次计数加一；按有符号计数 >0 才进入分配。
// 60D524 -> 81A090 以(0,0)复位解析位置，再分配 count*0x114 字节。
// 调 607E5D -> 622D50：ECX 指向当前条目，间接调用612C5E -> 7ECD20，
// 每轮前减计数、按有符号非负继续，调用后指针加0x114。不是容器插入。
// 7ECD20 只清条目 +0 和 +128 两字节；其他内容不因构造就自动成为零。
// 分配数组写入对象 +0；第二遍再次找 ITEM，逐条读取字段与摘要。
// 完成后清理临时 Map、解析器、资源对象，返回一。
//
// 重复加载及失败
// ----------------------------------------------------------------------------
// 加载器不释放对象旧数组；正数条目时7E9045直接覆盖首指针。
// 零条目时 +4=0，但旧首指针保留，并返回一；不能将一解释为记录完整有效。
// 非零条目分配返回null时首指针变零，第二遍仍执行，局部没有安全退出。
// 两遍共享同一内存解析源；第二遍没有单独的 index<count 条件。
// 未分析解析器被外部改写的可达性；不能凭这一点声称正常样本必定越界。
// count*0x114 没有本地溢出预检。当前74条样本不触及该界限。
// SEH尾块会释放尚处构造阶段的候选数组；已写入对象后主要清理临时对象。
// 缺项或摘要读取失败没有在此处建立事务回滚；异常库契约保持未知。
//
// 关闭与所有权
// ----------------------------------------------------------------------------
// 6244B0..624500局部窗检查A76704；非零则push 1、ECX取对象，调用
// 6118BD -> 6293E0，返回后把单例槽清零。这里不认领整个关闭函数。
// 6293E0先经611976 -> 7E8E60析构，再按参数bit0决定operator delete(this)。
// 7E8E60首指针非零时交601CD3 -> 91F7E0的delete[]，随后首指针清零；
// 它不按条目遍历图像句柄，不清+4计数。对象随后被删除时旧计数已无用途。
// 此链只释放当前首指针；重复加载被覆盖的旧数组不会因此自动追回。
