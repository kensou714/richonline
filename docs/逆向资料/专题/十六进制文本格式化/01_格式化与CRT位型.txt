// 格式化与CRT位型
// ============================================================================
// 8E0380为cdecl：栈上单个32位Value，普通retn，调用方清理参数；不消费ECX对象。
// EAX返回ACC3D8，保存ESI/EDI，非空路径另保存EBX；没有返回独立分配的字符串。
//
// 入口实际写入顺序
// ----------------------------------------------------------------------------
// 8E0382取A679B0模板；repne scasb找NUL，再rep movsd/movsb复制含NUL的11字节。
// 模板原字节3078303030303030303000，即“0x00000000”加NUL。
// 写入ACC3D8..ACC3E2，末尾ACC3E2为NUL；这里不是调用strcpy函数，而是内联扫描/复制。
// 8E03B5、8E03BB、8E03C1分别清ACC3CC的4字节、ACC3D0的4字节、ACC3D4的2字节。
// 即临时区ACC3CC..ACC3D5共10字节；临时区不是反编译器名称Buffer暗示的栈数组。
// 8E03C8经5FF221调用92BBD0，实参Value、ACC3CC、radix=16。
// 先用lstrlenA检查结果非空，再用第二次长度作复制量N、第三次长度作起点偏移M。
// 目的地址为ACC3E2-M，复制N字节，不复制临时区末尾NUL；保留模板末尾NUL。
// 正常串行条件下N=M，数位向末尾靠齐，前面模板的零保留。
// 零也会生成一位“0”，所以合法32位输入的ltoa结果并不为空；空串出口是实际存在的分支。
//
// 92BBD0：ltoa包装
// ----------------------------------------------------------------------------
// 只有radix==10且Value按signed为负，才向92BAD0传sign=1；否则sign=0。
// 8E0380固定传16，因此80000000..FFFFFFFF不会加负号，也不会先做取负。
// 调用完成返回传入Buffer；不要把92BAD0内部的中间指针返回值当成ltoa结果。
// 此包装没有检查radix、Buffer是否为空或空间长度。
//
// 92BAD0：xtoa主体
// ----------------------------------------------------------------------------
// sign非零先写'-'，移动写指针并对输入DWORD做32位NEG；sign==0跳过这一段。
// 92BB04和92BB0F分别做unsigned DIV，EDX先清零，求余数及下一轮商。
// 余数0..9加30h；大于9加57h，基数16时得到小写a..f。
// do循环至少一次，输入0也产生'0'；商非零继续。
// 随后写NUL，首尾双指针交换数位；可选负号不参与反转。
// 一位数仍交换自身一次，不是“长度不足2便完全不进入交换”。
// 一般接口以radix=2..36、足够目标空间为使用前提；它没有校验这些条件。
// radix=0会触发除零；radix=1且输入非零时商不缩小，不能期待自动拒绝非法基数。
// 本题主入口固定16，无需把这些非法基数路径当作当前颜色保存的可达故障。
//
// 32位固定宽度契约
// ----------------------------------------------------------------------------
// unsigned除16每轮减少一位，DWORD至多8位；加NUL至多9字节，落在已清的10字节内。
// 临时区实际数位数L为1..8；结果覆盖区从ACC3E2-L到ACC3E1，不碰前缀0x或末尾NUL。
// 对应输出：0 -> 0x00000000；1 -> 0x00000001；10 -> 0x0000000a。
// 7FFFFFFF -> 0x7fffffff；80000000 -> 0x80000000；FFFFFFFF或signed -1 -> 0xffffffff。
// 结果固定10个可见ASCII字节、11字节含NUL。这里的32位值是位型，不推断ARGB通道顺序。
// 以上为指令及模型结论，没有运行旧CRT或调用原EXE验证。
