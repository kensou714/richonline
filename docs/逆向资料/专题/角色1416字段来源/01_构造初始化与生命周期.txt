// ============================================================================
// 两处直接写入：构造清零，无资料初始化置一
// ============================================================================
// 7F3840 / 7F398C：ECX是保存的构造this，写BYTE[P+588h]=0。
// 65B450的五条创建路径都先分配0x708字节，再以新指针为ECX调用611377→7F3840。
// 构造不是全对象清零；首272字节memset不覆盖1416，字段由单独byte写入初始化。
//
// 7F3C70的参数顺序
//   ECX=P；栈依次为G、资料指针、方向、格编号、参与槽号、合成序号。
//   P+1404保存G，P+1408保存参与槽号，P+1412保存合成序号。
//   资料指针非零：复制前272字节；这一复制不覆盖P+1416，也不主动把它复位为0。
//   资料指针为零：7F3D57写BYTE[P+588h]=1，随后按模式读取资源或设置角色类型。
//   置一发生在模式判断之前，因此不能将该标志等价为某一个地图模式。
//
// 4000启动器65B450如何决定传参
//   65B625和65B9DF：从资料表取得指针后传入，合成序号=-1。
//   65B765：模式3且启动槽ID=-1，传资料指针0；合成序号采用递增j，ECX=G表当前槽。
//   65B8E6：模式4的ID=-1分支，传0与合成序号-1，ECX=G表第n-1槽。
//   65BB3D：模式2的额外固定slot1，传0与合成序号-1。
//   模式数字由M+24及63E1A0/629E10/63EDD0判据证实，不单凭数字绑定中文玩法名。
//   资料表返回空指针时也会走初始化器的无资料分支；不能仅凭ID!=-1认定字段必为0。
//   以上是静态参数流；合法服务器资料、有效槽数和非空分配仍由外围约束。
//
// 再次初始化的准确边界
//   新构造P再传非空资料，在已证路径中字段保持0；传空资料则变为1。
//   若对已置1的同一P直接重调7F3C70并传非空资料，本函数没有复位该标志。
//   当前已检出调用者均为65B450的先构造后初始化路径；不宣称实际存在重初始化入口。
//   7F4550覆盖部分名称、外观和数值，再把getter传入子对象；它不写回P+1416。
//   当前位移扫描未见角色其他直接588h写入；别名、块复制及未定义代码仍不在排除范围。
//
// 与库存完全不同的维度
//   库存ID=-1是P+1520起8个六字节槽的逐槽空标记。
//   P+1416来源于构造/资料指针，不随7F8780插入或合成成功失败被写入。
//   该标志非零只改变7F8780最终返回值，不增加槽数、不保证入槽、不撤销前序副作用。
