// 字段写入与生命周期
//   7F398C明确写BYTE[P+588h]=0，属于0x708字节角色对象的构造路径。
//   7F3D57在资料指针为空时写BYTE[P+588h]=1，写入早于后续模式分支。
//   非空资料分支仅复制前272字节，没有覆盖该字段，也没有另行写0。
//   新构造再以非空资料初始化时保持0；空资料初始化后若直接复用对象，则可能保持1。
//   后一情况是函数静态边界，不是已经找到真实重复初始化入口的声明。

//   资料表返回空指针也会进入空资料分支，不能只靠启动ID是否为-1判定字段值。
//
// 七个getter消费点
//   7FD7A0只返回AL=BYTE[P+1416]，没有库存比较或布尔归一化。
//   七处调用前ECX均恢复保存的角色this，未变为地图、界面或绘制子对象。
//   7F3C70与7F4550把AL写入临时参数+60，再以ECX=P+864调用642740。
//   642740先比较子对象+0与输入+0、子对象+44与输入+36；至少一项变化才重建。
//   重建分支再读取输入BYTE+60；非零保留输入+36，零走可选资源编号转换。
//   随后按4*26个组合缓存type5资源；仅标志变化不越过上述身份字段门。
//   7F74B0按标志选择signed BYTE[P+272+k]或DWORD[R+1104+40*j+4*k]。
//   R由G+3576取得，不是G内地图子对象M；j与k的合法范围仍需调用场景约束。
//   7F8780先做库存扫描、条件插入/合成和UI处理，末尾标志非零才强制返回1。
//   该返回覆盖不保证入槽、不说明八槽已满，也没有撤销前序副作用。
//   7FA140、7FA1C0、7FA920使用标志选择现金阈值来源；只承诺正文所列局部路径。
//   7FA140的setnl和7FA1C0的jle均为signed比较，算术溢出及异常索引不能自行忽略。
//
// 同偏移字段排除
//   7DE4EA是DWORD[M+588h]写1；7BAF09以G+65Ch即G+1628构造地图成员M。
