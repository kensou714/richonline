// 当前IDA共扫描1039359条已解码指令，文本[基址+588h]命中5处。
//   7F398C / 7F3840：P的BYTE写0，角色构造。
//   7F3D57 / 7F3C70：P的BYTE写1，无资料初始化。
//   7FD7B1 / 7FD7A0：P的BYTE读取，返回AL。
//   7DE4EA / 7DE310：地图运行对象M的DWORD写1，不是角色标志。
//   69B611 / 69B600：M的DWORD读取，调用者69AA20将结果作为音频资源编号使用。
//
// 对象分离证据
//   65B450分配0x708字节后构造P，指针保存在G+E00+4*slot。
//   7BAE60调用7DE310时ECX=G+1628，即地图成员M；并非G的角色表某一P。
//   其他7DE310调用者存在分配0x5B8字节或栈上临时M，独立于P分配与构造。
//   69AA20先629C90取得G，再63E210取得M，之后才以M为ECX调用69B600。
//   仅看到DWORD/BYTE不同还不充分；本组同时保留调用前ECX来源。
//
// 证据导航
//   证据/functions.json：完整函数主块/尾块、声明块raw、指令字节、伪码、调用桥。
//   证据/scan.json：未被人工改写的原始5候选、20条构造/初始化/getter引用边。
//   证据/supplement_refs.json：地图对象与重配置调用者的补充引用边。
//   候选归属.json：逐候选人工分类；不覆盖原证的“待归属”标签。
//   证据/关键汇编上下文.txt：ECX和使用点的短上下文，完整指令仍以functions.json为准。
//   证据/伪码摘录.txt：自动生成的伪码与调用映射；IDA自动类型名不是恢复出的C++类名。
//
// 复核方法
//   只读IDA-MCP执行export_ida.py的collect(db)、supplement(db)、recheck(db)。
//   项目根执行 python -B "docs/逆向资料/专题/角色1416字段来源/render_evidence.py"。
//   再执行同目录build_review.py、validate.py；结果写验证结果.json。
//   验证器检查EXE指纹、指令/声明块/E9字节、IDA复读块与指令数、逐函数清单覆盖。
//   已有专题共享函数不能按目录数重复增加项目覆盖量；仅导出项不升级为语义完成。
//
// 仍然未知
//   官方字段名称、所有无资料角色与NPC/BOSS/AI身份的完整对应关系。
//   通过别名或块复制的写入、未定义代码、运行时生成代码及真实运行样本。
//   各模式合成序号=-1时后续读取的可达性与外围防护，不能默认索引总合法。
