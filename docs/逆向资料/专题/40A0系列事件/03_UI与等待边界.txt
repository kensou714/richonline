// 6003 -> 67DA40不选择P，真实ECX仍为G。BYTE+4非零时：若窗口已开先
// 关闭；经6E3B40按WORD+2显示窗口并设置DWORD+8为管理器超时值；随后
// 6E4640把DWORD+16交对应窗口虚表+16。BYTE+6非零时设置G等待，时长
// 优先DWORD+12，若为0则用DWORD+8。40A0..2均为1800ms窗口值与
// 1350ms游戏等待值，不应合并成一个“消息延迟”。
// DWORD+20在67DA40中没有读取，因此512/128/12不是该消费者执行的
// memcpy长度或安全界限。必须按真实UI回调解释+16指向的数据。
//
// UI4：Intf.kpd indx4 -> G_MsgBox.ui，工厂创建大小0x48，构造6FAEF0
// 安装虚表A24610。虚表+16 -> 60A937 -> 70B700。
// 70B700取得控件ID1，将传入指针交控件虚表+144文本接口，再通知根控件
// 虚表+164。资源ID1是191x73 label，无提交按钮，不能说等待玩家选择。
// 具体控件的复制/编码行为须追踪控件类型实现，此处只证调用时读指针。
//
// UI30：Intf.kpd indx30 -> G_News.ui；工厂大小0x214；构造6FB680安装
// 虚表A25A60并登记30；+4 -> 718DE0，+16 -> 7192F0，+64 -> 719290。
// 初始化718DE0经type10/id10类别加载图片句柄，主表存于UI+72后各DWORD。
// 7192F0消费三DWORD{kind,index,text}：kind0取DWORD[UI+72+4*index]；
// kind1取DWORD[UI+472+4*index]；kind2有两种模式资源分支，本群未闭合配置。
// 然后将图片句柄交控件ID1、text交控件ID2文本接口，调用根控件
// 6032CC(-236,null)设置纵向位置；不是一对x/y坐标。6032CC -> 8E3340
// 写this+348，第二参数为关联控件传播时的排除指针，本处为null。然后
// 调根虚表+164。40A2四收益分支均kind0；索引1/2/6/14的初始化图片
// 子号分别0/2/5/9。保留48分支对应子号58。
// G_News.ui：ID1为150x124图片label；ID2为450x32文字label；背景
// other_0_60、文字底fx_2_0。以上资源编号/键可用于后续新闻素材编辑。
// 719290关闭时读取ID1现有图片句柄，非-1则经图片管理接口处理；未凭
// 此处调用就认定所有共享句柄最终销毁，完整资源所有权仍须另一专题。
//
// 实际文本原文与代码参数
// --------------------------------------------------------------------------
// 24“獲得”；28“失去”；31“點券”。
// 184“在路邊撿到錢%d元” -> 600。
// 185“意外獲得遺產%d元” -> 1600。
// 189“銀行海外投資獲利%d元” -> 1800。
// 197“變賣傳家之寶獲得%d元” -> 800。
// 当前RichStr可严格cp950往返，当前UI/Intf可严格gb18030往返；这是
// 磁盘样本的编码证据，不把客户端Windows CP_ACP行为改称UTF-8。
//
// 镜头与继续记录
// --------------------------------------------------------------------------
// 6005 -> 67DB90 -> 7B6F60，目标格为signed WORD+2，地图对象G+0x65C。
// 608A -> 681C40：构造本地DWORD0游标载体，再调用7C0C50(G,&local,3,0,0)。
// 7C0C50清DWORD[G+60]；参数3进入它的case3继续分支，而非6080的阶段3。
// 该大函数继续链受游戏模式、角色状态、地图与其它谓词控制，存在后续
// 本地记录及网络请求路径。本群仅闭合本入口到case3，不把全函数出口
// 都称已分析，也不宣称608A3必然立即发送某个网络opcode。
//
// 对通信卡住排查的意义
// --------------------------------------------------------------------------
// 收到40A0..2并通过身份检查，不意味着数值消费者已执行或1350ms已消耗。
// 40A0库存写入早于队列动画/提示；40A1/2数值更改依赖队列被取出。
// 提示与三DWORD存放可写全局，队列只拷贝24B记录。如果再次收同分支
// 覆盖全局后前条才消费，显示可能反映后写内容；未运行复现这种重入。
// sprintf/strcat在入口没有长度约束；Source真实容量128B。N未钳到8，
// 当前角色未局部核范围，旋转表首访未校验索引。以上是静态边界，实际
// 可达性需结合接收层、服务器与运行证据，不能写成已复现崩溃。
