// 但调用者必须保证窄字符串在通知消费及转换期间有效、以 NUL 结束。
// 这个结论不自动覆盖排队期间：64FA50/6980F0只按字节搬运记录，不深拷贝+16文本指针。
// 6003记录中的+20不能凭“128”被解释为入队拷贝长度；本专题链中未见它被消费。
// 67F680的128字节栈文本是直接通知 UI4，不是把该栈地址排入6003队列。
// 66FC80排入6003的地址则为全局A7C140；地址存活不等于内容不会被后续事件覆盖。
