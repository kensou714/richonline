// 常规创建链
// ----------------------------------------------------------------------------
// 6E6080给管理器槽4工厂写605559 -> 6E6F40，分配48h后612AF6 -> 6FAEF0。
// 6FAEF0先6E1D90基类构造，后写虚表A24610；+0加载进入6E1E40，+16通知进入70B700。
// 6E1E40把资源根控件存于对象+4。8E4AD0/8E4DC0解析并创建根/子控件。
// 8E22C0用于根，8E23F0用于子项，均先询问引擎上下文+80的自定义创建回调。
// 回调未注册或返回0时落到8E24D0；type1分配250h并进入90B800标准label构造。
// 8E0080初始化上下文+80=0；6E2E60的15项常规注册没有改+80。
// 另有未声明范围8E23C0..8E23D3把同一参数写+72/+76/+80/+84，跳板5FF13B
// 当前静态交叉引用为空。未穷尽任意间接写者，因此不把标准工厂提升为所有运行态的保证。
//
// 同步通知与自有副本
// ----------------------------------------------------------------------------
// 67DA40按6003+2 signed WORD取UI号，+4非零时显示并把+16 DWORD交6E4640。
// 6E4640在UI槽对象存在时同步调用其虚表+16；UI4的70B700找ID1并调控件虚表+144。
// 8E2C10查找失败返回0，而70B700未检查0就解引用；必须保留资源中有效的ID1。
// 90B800写虚表A3131C；+144 E9->8F8040，+148 E9->90BFF0。
// 8F8040先8E0650转成宽文本，再同步调+148；90BFF0把String交8E1800，a2=label+88。
// 8E1800比较已有宽文本；内容相等时沿用旧自有副本，不重新分配。
// 内容变化时先删除旧文本、把分段节点归还ACC3C4、删除旧测宽字节数组。
// 非空输入分配2*wcslen+2字节，清零并逐WCHAR复制；之后才调8E1620重建测宽信息。
// 8E1620会再次使用转换暂存区，但此时label+88已经持有独立文本副本。
// 空/NULL输入令自有文本指针清0；不是把输入指针永久写入label。
//
// 主要字段，偏移均为字节
//   label+88  DWORD：自有UTF-16文本地址。
//   label+92  DWORD：文本分段节点链；节点回收到全局ACC3C4。
//   label+96  DWORD：测宽字节数组地址。
//   label+100 DWORD：累计测宽值。
//   label+576/+580 DWORD：90BFF0复制后交给后续布局方法的参数，未在本文完整命名。
//
// 释放与失败边界
// ----------------------------------------------------------------------------
// label虚表+120 ->902060 ->90B8F0；析构释放+88/+96，回收+92节点，再调8E0ED0基类清理。
// 管理器8EA2B0遍历根控件调+120，并最终释放ACC3C4节点池；隐藏不是释放的同义词。
// 8E1800在删除旧内容之后分配新内容，本体无失败回滚，也未在memset前检查new返回0。
// 不据此判断CRT一定返回0或一定抛异常；只证明该层不提供原文本保留的强异常保证。
