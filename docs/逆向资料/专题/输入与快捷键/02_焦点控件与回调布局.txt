// U 的输入相关字段：8E8A10、8E8800、8E93A0、8EA570 交叉确认
//   +20696(0x50D8) 顶层链入口；为 0 时消息分派返回 0。
//   +20700(0x50DC) 鼠标激活对象；+20704(0x50E0) 鼠标命中对象。
//   +20708(0x50E4) 按键开始时的控件；+20712(0x50E8) 离开时清理的对象。
//   +20716(0x50EC) 键盘焦点控件；629F80 直接返回此指针。
//   +20720(0x50F0) 长按/拖动对象；+20724(0x50F4) 焦点切换限制对象。
//   +20728(0x50F8) 双击对象。
//   +20736/+20740 客户区宽高；+20752 非零时整个消息分派返回 0。
//   +20764 模式值 1 可绕过部分可见/可用限制；真实业务名未确认。
//   +20780/+20784 已接受坐标；+20788/+20792 新鼠标坐标。
//   +20796/+20800 左键点击相对控件左上角偏移。
//   +20804 鼠标键枚举：左 1，中 2，右 3；滚轮回调另用 10/11。
//   +20808 鼠标按下时刻；+20812 进入控件时刻；+20816 鼠标相关时刻。
//   +20820 键盘辅助时刻（此批只确认释放清零）；+20824 键盘重复时刻。

// 键盘分派：8E8A10
//   WM_KEYDOWN/WM_SYSKEYDOWN -> focus.vtbl+100(VK)。
//   当 +20824 为 0：记录当前 tick，立即调用 +100。
//   后续消息须满足 delay=DWORD[C+452]、interval=DWORD[C+456]，
//   才再次 +100，继而 +112(VK)，然后 tick 改为 now-delay。
//   WM_KEYUP/WM_SYSKEYUP -> 清两个时刻，focus.vtbl+104(VK)。
//   WM_CHAR -> focus.vtbl+108(字符值)。
//   这是到来消息驱动的重复判断，不能误记成独立定时器自动产生按键。
//   时间戳属于 U，不是每 VK 单独一份；多键交错的重复行为需实机核查。

// 基础控件虚表 A305AC：虚表偏移 -> 正文 -> C 内回调字段
//   +36  -> 8EA000 -> +488  鼠标激活通知。
//   +40  -> 8EA020 -> +492  鼠标失活通知。
//   +44  -> 8EA040 -> +496  获得键盘焦点。
//   +48  -> 8EA060 -> +500  失去键盘焦点。
//   +52  -> 8E93A0 -> +504  鼠标按下，附键枚举。
//   +56  -> 8E9570 -> +508  鼠标释放，附键枚举。
//   +60  -> 8E95F0 -> +548  在同一控件按下并释放后的点击。
//   +68  -> 8E96E0 -> +516  滚轮，参数 10/11。
//   +72  -> 8E9640 -> +520  双击。
//   +76  -> 8E9730 -> +524  鼠标移动/命中过程通知。
//   +80  -> 8E9760 -> +528  鼠标进入。
//   +84  -> 8E97A0 -> +532  鼠标离开；并清 U+20712。
//   +88  -> 8E97E0 -> +536  长按/拖动处理。
//   +92  -> 8E9A40 -> +540  长按/拖动结束。
//   +100 -> 8E9AB0 -> +556  key-down。
//   +104 -> 8E9B40 -> +560  key-up。
//   +108 -> 8E9B90 -> +552  char。
//   +112 -> 8E9BE0 -> +564  重复键附加回调。
//   回调一般 cdecl(C, value)；虚函数入口使用 ECX=C。
//   派生控件可覆盖虚表，不可仅按基础偏移推断 edit/button 全部行为。

// 焦点选择
//   C+372 是焦点顺序字段；C+384 enabled、C+385 visible。
//   8E93A0：左键时，enabled&&visible（或特殊模式 1）下设置鼠标激活；
//   若 order>0 且 U+20724=0，则旧焦点 +48，新焦点 +44。
//   8EA570 显式设置焦点，只检查非空控件 order!=0；本函数没有检查
//   enabled/visible，因此不能将它与鼠标选择的限制混为一谈。
//   8E9AB0：Tab 且焦点非空、U+20724=0，调用 8EA080 找下一对象。
//   8EA080 先找后继兄弟中 order 与当前相同者，此快速分支未检查
//   enabled/visible；之后才扫描更大顺序或最小正顺序且可见可用对象。
//   快速分支可能选到隐藏/禁用同序控件，是待验证风险，未修改客户端。
//   此函数未读取 Shift，不能声称通用基础控件已实现 Shift+Tab 倒序。
//   8E0ED0 析构会解除多数 U 引用；焦点等于被析构对象时先找下一项，
//   若仍返回自身则清零。完整析构及资源释放见界面系统专题。

// 鼠标捕获与命中
//   8E8A10 down 调 SetCapture，up 调 ReleaseCapture；保存按下控件。
//   释放时命中仍等于按下控件才走 +60，否则只走 +56。
//   8E8800 更新命中对象，处理 enter/leave 及拖动；8E7E40 结合层掩码、
//   可见性、矩形与图像命中测试查对象。图像透明点回调另见纹理专题。
//   长按阈值 C+444；达到阈值且未双击时选择 +88；up 再 +92。
//   8E97E0 的 GetKeyState(VK_LBUTTON)&0x1F40 是实际掩码，
//   并非惯用 0x8000。本轮没有把这处可疑逻辑修饰成标准按下检查。
