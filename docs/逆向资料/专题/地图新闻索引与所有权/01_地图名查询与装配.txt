// ============================================================================
// 模式3：按地图名查询，并保持文件内局部记录顺序
// ============================================================================
// 原证：691AB0、6950D0、696BF0、695520、6963F0、696660、7AFE70、7B4B90。
//
// 查询链
// ----------------------------------------------------------------------------
// 691AB0(this=R,Str)把Str构造成28字节临时字符串，对R+0x2F0调用6950D0。
// 6950D0先经695CB0 -> 696BF0执行lower_bound形态查找。
// 696BF0从根沿树比较：node.key < key则走右链，否则保留候选并走左链。
// 到哨兵后返回最靠前的候选；6950D0再排除end与key < candidate.key。
// 查找不到时：构造空V、构造(key,V)临时pair、经695520提示插入，随后释放临时对象。
// 因而这是带默认插入副作用的查询，不能拿它实现“只读确认地图存在”。
// 返回地址是节点payload+28，即该地图V；691AB0随后析构栈字符串并返回V。
// 插入前有最大节点数门控及length_error路径；不把“map/set<T> too long”当业务提示。
//
// 写入链
// ----------------------------------------------------------------------------
// 7AFE70(this=R,FileName)打开并解包文件，逐行解析制表符字段。
// 每轮7B4B50把136字节运行记录清零，然后sscanf读地图名、类型、动画名和文本。
// 格式跳过五个整数及一列；这些列没有被本函数写入运行记录，不能据此断言其全局无用。
// +0保存第二列type；+4保存6DAA10解析动画名所得DWORD；+8开始为128字节文本区。
// 6DAA10的IDA名字CFile::GetFilePath是误名；其内部规则由图像运行时接口专题审阅。
// 文本存在条件转换分支，配置解包/编码证据见4090系列事件，不在此推断运行ACP。
// 用首列地图名构造临时字符串，对R+0x2F0调用同一个6950D0，再将记录追加到V。
// 7AFE70未检查sscanf成功项数，也没有在当前入口核实地图名、类型或文本长度。
// 未见装配前清空树或V；重复调用同文件会沿同地图名追加，不能视为覆盖加载。
//
// 顺序与索引
// ----------------------------------------------------------------------------
// 同一地图的记录按本加载函数实际读入顺序追加；type不是vector下标。
// 地图之间在树中的排序不改变各自V中的追加次序。
// 首列不是全局新闻ID；配置整文件行号也不是4096包中的p+4索引。
// 文件里的第N条有效业务配置，不自动等于V第N条：本入口没有本地过滤解析失败行。
// 精确索引须以实际输入字节、读取器行为和V内容为准，不能仅按非空行号猜测。
//
