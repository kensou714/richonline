// 复制与追加

// 7B4E20按136*n推进返回地址；元素构造最终落在7B6A00，本轮只核其调用契约。
// 7B5000先把输入136字节复制到栈，避免源记录与待移动范围别名影响当前插入。
// 不足容量时尝试旧容量+旧容量/2；不足size+n时改为size+n，另有最大条数门控。
// 扩容先建立新缓冲及复制区间，再清理旧区间、释放旧begin，最后更新三个指针。
