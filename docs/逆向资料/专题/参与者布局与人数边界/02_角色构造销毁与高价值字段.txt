// 分配与构造
// --------------------------------------------------------------------------
// G工厂629C90分配0x14794字节，调用7BAE60构造并存全局A7672C。
// 65B450的五条分支均分配P大小0x708（1800）字节，再调用611377→7F3840。
// P构造不是全对象清零：只memset首272字节及+1748起32字节，其他成员逐项初始化。
// +282、+330、+1520各构造8个6字节子记录；这不是可扩展到任意人数的动态数组。
// +1404=0、+1408=-1、+1412=-1；+1472和+1480两组8字节标志清零。
// +1493/+1494/+1495/+1497各置-1，与范围效果排除判据对应。
// +1504/+1508/+1512各置0；+1676/+1680/+1684的DWORD位型为1.0f。
// +1730/+1734置-1；+1740置0；不是所有float字段均显式初始化，必须按启用标志使用。

// 初始化契约：7F3C70
// --------------------------------------------------------------------------
// ECX=P；栈参数：G、资料指针或0、方向、位置、槽号、合成序号或-1。
// 写P+1404=G、+1408=槽号、+1412=合成序号。
// 有资料指针：复制其前272字节；初始化现金、存款及第三项数值；资源继续影响最终值。
// 无资料指针：P+1416=1，按地图模式的资源配置合成；不同模式的数值来源不可合并。
// 位置参数通过7F72A0写P+1464；同时按坐标生成P+540=64*x+63、+544=48*y+47。
// 方向写P+1460；本层没有证明方向一定0..3或位置必在地图范围。
// 初始化末尾7FAF80重算8个固定加成DWORD，随后现金增加cash*P[1776]/100+P[1772]。
// 因而基础现金表值不等于所有角色最终现金；资源/装备合法值域仍需各自资料证明。
// 7F46B0固定复制10字节到P+272，输入来源是启动槽记录+5位置，内部意义本专题不命名。

// 高价值字段与证据等级
// --------------------------------------------------------------------------
// 偏移          宽度        含义或已证用途                     主要证据
// +0..271       272字节     资料对象前缀副本                    7F3C70 memcpy
// +272..281     10字节      启动附加记录，内容待证              7F46B0
// +576          指针       可选拥有子对象；名称待证            7F3C70、7F3BB0
// +1404         指针       所属G                              7F3C70
// +1408         int32      参与槽号                           7F3C70
// +1412         int32      合成序号，普通资料路径为-1           65B450、7F3C70
// +1416         byte       无资料合成标志                     7F3840、7F3C70
// +1460         int32      方向值                             7F3C70
// +1464         int32      当前格编号                         7F72A0、63E410
// +1472/+1480   各8字节    关系/状态数组，语义未全部证实        7F3840、7F9640
// +1488         int8       0..3影响范围金额倍率，官方名待证     范围效果专题

// +1748..1779   8个int32   条件性资源效果累加结果              7FAF80
// +1748/+1756   int32      范围金额源固定加项/目标固定减项     7CE420（兄弟专题）

// 生命周期与释放
// --------------------------------------------------------------------------
// G析构7BB140固定检查8个指针，对非空P调用7D5CD0(1)后清空槽。
// 7D5CD0先调用7F3BB0，再按标志低位决定operator delete(P)。
// 7F3BB0：P+576非空则operator delete并置0；再清理P内其它子容器。
// P+576由初始化器某分支分配0x5C并构造；无法仅据此命名为宠物、载具或建筑。
// 初始化复制的272字节前缀是值副本；没有证据说明P会释放原资料指针。
// G析构先删除P，随后才TerminateThread/CloseHandle已保存线程；这里仅记录顺序，
// 是否线程仍能访问已删除P需要线程退出/外部同步证据，不能宣称并发安全。
