// 4036：读取 +4、+6、+8 三个 signed WORD。值为 -1 时跳过；有效项从 type=22
// 开始连续编号，每成功一项才递增，因此 [有效,-1,有效] 使用 type 22、23。
// 每项调用 0x7E2380，ECX=G+0x65C（Map），真实参数顺序是
//   (pos=signed WORD(+4/+6/+8), type=22..24, a3=-1, a4=-1)。
// 第二参数是效果类型/槽号，不能与地图位置号互换。
// 0x7E2380从DWORD[Map+60]取得池，按pos*4定位，写type、a3、a4的低BYTE，
// 记录第4字节本次不改；随后按类型谓词分别登记并刷新位置。
//
