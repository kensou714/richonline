// 证据对象：RnClient.exe 当前副本。函数指令、跳板和磁盘字节见证据目录。
// 本专题只记录已从汇编、栈描述符和直接消费者确认的事实；未追完的虚表
// 消费者保留“局部”状态，不把 IDA 自动套出的 MFC 名称当作业务语义。
//
// 分派关系：
//   4036 -> 0x661280：ECX=G，记录 +2 为 WORD 校验号，最多写三项效果。
//   4037 -> 0x661330：ECX=G，固定写效果槽 28。
//   4038 -> 0x6613A0：校验本地角色后排 UI1 通知，正数时扣本地金豆。
//   4039 -> 0x661470：空实现，只保存 ECX 后返回。
//   403A -> 0x661490：按 +0E、+04、+06、+0C 等字段构造本地事件。
//   403B -> 0x661D70：复制文本并驱动 UI40 文本队列。
//   403C -> 0x661EC0：按 signed BYTE 角色槽写入 Summary 槽状态。
//
// ABI 边界：这些入口均为 ECX=this、栈上一个记录指针、retn 4。4036/4037
// 不是 stdcall；把记录指针当对象基址会导致字段和地图对象全部错位。
// 4038 局部通知由栈描述符确认大小为 8 字节；403B 的 strcpy 目标由栈描述符
// 确认大小为 128 字节，UI40 对象另有四个 128 字节文本槽。
//
// 网络边界：这些 handler 内未见直接提交网络包的调用。6000 等编号是本地
// 队列记录；UI40 完成阶段才构造 0036 上行记录。真正发送仍受连接门槛影响。
