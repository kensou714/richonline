// 403A：角色配置切换与本地事件分支
// ============================================================================
// 入口 0x661490 为 thiscall。先以 0x63E5B0(G) 取得本地队列游标/状态，真实调用
// 把 ECX 改为 G+0x640；IDA 的 CDialog::OnInitDialog 名称不可信。
// 本地 0x64FA50 会复制记录，但 payload 可指向静态区，仍需后续消费时序核验。
//
// 本地记录构造器与布局（偏移均为记录内部）：
//   0x693A80 / 6008 / 12B：+0 WORD编号，+2 WORD UI槽，+4 payload指针，+8 DWORD长度。
//   0x6937D0 / 6005 /  4B：+0 WORD编号，+2 WORD地图位置。
//   0x6932B0 / 6003 / 24B：+2 WORD4，+4/+6 BYTE1，+5 BYTE0，+8 DWORD0x546，
//                        +12 DWORD1000，+16 文本指针，+20 DWORD128。
//   0x63F080 / 6000 / 20B：+2 WORD动画号，+4 BYTE暂停标志，+8 DWORD时长，
//                        +12 payload指针，+16 DWORD payload长度。
//   0x693980 / 6006 /  4B：+2 BYTE模式；构造器只写编号，+3保留栈填充值。
//
// 分支一：记录 +14 BYTE 非零。
//   绕过 GmsvID 校验，只排 UI0 的 6008：payload 24B 的前两DWORD为
//   {320,sign_extend(BYTE[+4])}；余部为静态区，本次入口未赋值。
//
// 分支二：+14=0，GmsvID校验成功，+4 signed BYTE != -1。
//   UI0 6008 payload首两DWORD={32,signed +4}；6005取 P[+4]+1464位置；
//   文本ID338格式化该角色名后排6003；6000动画45，payload8B首DWORD=signed+4、
//   +4 BYTE=记录+5。再排当前行动角色位置6005；行动角色等于本地槽时排6006(mode=1)。
//
// 分支三：+4=-1、+6 signed BYTE=-1。
//   只有 +12 signed WORD=0 且 0x7C0BB0(G) 非零才走常规事件：先排当前
//   P[DWORD G+116]位置6005；配置记录+272文本非空时排6003；6000动画26，
//   payload8B={当前位置,-1}。0x694170(G,DWORD[G+3624])确认行动槽有效时补6005。
//   否则 +12=-1 调0x7C0A60，+12=1调0x7C0AE0，其余不操作。
//   两个辅助函数另受0x604703谓词约束，分别减/增G+3620，写G+83846为1/0，
//   并向G+116对应槽提交两次标志更新；谓词产品名称仍未确认。
//
// 分支四：+4=-1、+6!=-1。
//   本段“当前P”明确为P(DWORD[G+116])；不同于最后补6005所读P(DWORD[G+3624])。
//   排6005(+2=记录+8 WORD)，ECX=当前P调用0x7F72A0(signed WORD+8)更新
//   P+1464及坐标；0x7F7940(signed WORD+10)更新P+1460及P+864子对象。
//   0x8074F0 / 0x8073C0按signed BYTE+6选择配置，再0x7F4550同步当前P；
//   配置+272文本非空时排6003。排动画26 payload={当前位置,1}，行动槽有效时补6005。
//
// 消费者：0x67DE20将6008的UI槽及指针交0x6E4640；0x67D750把6000动画号和
// payload交0x7A5C30。暂停BYTE非零时，以给定时长或0x694BC0默认时长再加100暂停。
// 本次未穷尽动画26/45的间接工厂和资源映射，以上记录不能当网络opcode发送。
