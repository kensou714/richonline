// ============================================================================
// 8E41D0 / 共享二层边框接口
// ============================================================================
// 输入栈五个 DWORD，按 caller 顺序记为 x、y、r、b、mode；ECX 不被本体使用。
// 8E432D retn 14h，由 callee 清五词；回调由 caller 每次清 18h，即六个 DWORD。
// 五词只是坐标和模式的局部接口，不保证矩形为正、坐标不溢出或实际像素端点约定。
// 8E41D7 先 mode-1，8E41D8/DB 用 unsigned >3 门；只有 mode=1..4 进入绘制。
// 其他 mode 跳共享退出，不访问函数表，EAX 为 DWORD 模 2^32 的 mode-1。
// 合法 mode 循环结束 EAX 为0；不应命名 BOOL 或把该返回解释为绘制成功。
// 跳表地址8E4330并不在352字节函数声明块内，必须引用另存16字节跳表原证。
//
// 固定颜色字与顺序
// ----------------------------------------------------------------------------
// mode1：FFFFFFFF、FFD6D3CE、FF000000、FF848284，锚8E41E8..8E4200。
// mode2：FF848284、FF000000、FFFFFFFF、FFD6D3CE，锚8E420A..8E4222。
// mode3：FF848284、FFD6D3CE、FF848284、FFD6D3CE，锚8E422C..8E4242。
// mode4：FF000000、FF848284、FF000000、FF848284，锚8E4248..8E425E。
// 这里只声明32位常量和顺序；RGB/BGR字节顺序、alpha混合及调色板语义仍需回调本体。
//
// 精确六词回调契约
// ----------------------------------------------------------------------------
// 每轮j=0、1，先后重新load E=DWORD[ACC3C8]、再load DWORD[E+04]并判callback非空。
// 四站点8E42AC、8E42CD、8E42F0、8E430D，每处六参按入口顺序为：
// (x+j, y+j, r-j, y+j, palette[j],   0)；
// (x+j, y+j, x+j, b-j, palette[j],   0)；
// (r-j, y+j, r-j, b-j, palette[j+2], 0)；
// (x+j, b-j, r-j, b-j, palette[j+2], 0)。
// 此顺序支持二层四边线段的用途推断；本体未提供回调实现，不声明其全部绘制细节。
// 8E4276/78保存 r-b 与 y-x；8E4319/1A执行 b--、x++，推导后也使 r--、y++。
// 交叉寄存器差值不等于参数传错；应按真实 push 顺序恢复坐标，不能照伪码变量名理解。
// callback返回值可任意；8E4312重新load剩余轮数，在最后循环强制EAX=0。
// 最多八次callback；每个NULL槽独立跳过，不能假定一次load后八次均为同一目标。
// 本体没有矩形正向门、宽高最小门、clip参数对象或异常保护；32位加减可回绕。
// 表指针E未先判NULL，callback成员NULL门不覆盖对E+04的解引用。
//
// caller端点差异
// ----------------------------------------------------------------------------
// 旧8E46E0@8E4790传(x-1,y-1,x+w+1,y+h+1,mode)，只在mode>0且mode<5路径。
// 902180@90223F及90A430@90A4F1传(x,y,x+w+L-R-1,y+h-1,mode)。
// 其中x=C+168、y=C+16C、w=C+160、h=C+164、L=C+68、R=C+70，均DWORD读取。
// 这些参数并不一致，不能将共享边框的r/b一概规定为基础控件原始x+w/y+h。
// 其他caller仅引用原证有限实参窗口，不据此宣称其完整控件类型或渲染路径。
