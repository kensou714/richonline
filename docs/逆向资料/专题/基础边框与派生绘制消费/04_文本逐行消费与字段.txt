// ============================================================================
// 90C070 / 文本逐行消费与字段
// ============================================================================
// 本体918指令；ECX=C，普通retn，无显式栈参。它负责文本分行及callback派发，并非纯边框。
// 全部出口保留路径相关EAX/AL；长度、几何、指针、行数或BYTE标志均可参与返回，不命名BOOL。
//
// 字段与前置门
// ----------------------------------------------------------------------------
// BYTE+181可见；DWORD+160/+164宽高w/h；DWORD+168/+16C位置x/y。
// DWORD+78为行尺度f，+7C作为callback附加参数；+68/+6C/+70/+74为四个局部几何/偏移值。
// DWORD+58为NUL终止16位单元串，+60为每单元的unsigned BYTE宽度串；容量与对应关系未本地校验。
// DWORD+5C为节点链首；DWORD+64只判非零，本体未解引用，不替它补造对象类型。
// BYTE+80选择节点分组路径；DWORD+238普通文本callback，+23C节点路径callback。
// DWORD+240乘水平余量一半；BYTE+248/+249控制多行继续；DWORD+24C加入行距。
// DWORD[C+B0]为样式索引；DWORD[C+84+4*s]及DWORD[C+94+4*s]传callback，后者有颜色高BYTE门。
// 这里的4字节样式索引消费不是基础28*s样式记录，不能因相同s合并结构。
// 90C07B/83可见为0退出；w<signed(f SAR1)、h<f、+58为0、+64为0退出。
// 90C0C1与90C0CF分别signed IDIV：h/f及(2*w)/f，商为0退出。
// 本体未先检查f=0；2*w先32位回绕，INT_MIN/-1及除0异常门未见，合法参数需外部保证。
// +68==+70或+74==+6C亦直接退出；不是自动纠正零尺寸或非法矩形。
// 90C104经610283调用924FC0，取16位单元NUL长度；不解析Unicode字符簇或代理对。
//
// 普通文本路径：BYTE+80为0
// ----------------------------------------------------------------------------
// i为当前单元索引、start为待输出首索引、used为行累计宽度、line为从0开始行号。
// 90C14F在探测标志有效时调用8E0A00(text+2*i,width+i,w-used)，第四个入栈词为used。
// caller实际push四词并清10h；旧callee只读三词，不能把第四词冒充已被其消费的参数。
// 若used=0且谓词AL=0，关闭本行后续探测并强制局部AL=1，避免立即按同一门再次截行。
// 每单元宽度以unsigned BYTE扩展；只在总宽<=w、非最后单元、无换行且谓词真时累计继续。
// 16位0Ah以及16位5Ch后跟6Eh（字面反斜杠n）均作为换行分隔；0Dh不在本体此门内。
// 8E0A00自身的分隔字符规则更广，不能混为90C070显式换行字符集合。
// 超宽且谓词真、换行或谓词假时输出end=i；其他终结情形包含当前单元，end=i+1。
// 90C235在ECX=E下调用8EA8D0(text,node_head,start,end-start,0)，先于颜色与callback门。
// 未见本体从text或node_head释放内存；helper暂存写入与所有权须独立补证。
// 输出后line++，重置探测；+248为0或+249非0时，只要line>0即退出。
// 否则若[C+6C]+(line+1)*(f+[C+24C]) > h则退出；这是下一行几何门，不保证实际callback裁剪。
// 结束单元已被包含且为末尾时退出；超宽且+248非零时i--，让此单元在下一轮重试。
// 普通换行消费一个0Ah或两个字面转义单元；start更新至分隔之后，used清0。
// 锚90C131..90C439覆盖这一完整循环及各出口。
//
// 节点分组路径：BYTE+80非0
// ----------------------------------------------------------------------------
// +5C必须非NULL，否则90C43D/44D退出；链不作环检测，累积长度不与wcslen结果复核。
// 节点N的DWORD+00是单元数、DWORD+04是块宽、BYTE+08是整块处理标志、DWORD+0C为next。
// 原证并不证明节点只16字节、其余字段无用途或生命周期已闭合。
// +08非零时：块宽+used<=w且next非NULL就整块累计；最后块或超宽时输出到块首/块尾。
// 超宽把当前块留到下一行；若它同时是最后块，90C66C再以块首和整块长度单独提交。
// +08为0且长度>0时：按该节点单元逐一执行宽度、换行及谓词门，与普通路径相似。
// 但节点尾有next时可继续累计，末节点才按尾部终结；长度<=0不逐单元，直接推进next。
// 节点内部输出站点90C915；整块站点90C4AE、末块单独站点90C66C，均在callback门之前。
// 末块/超宽/换行后的索引回退和字面转义跳过分别见90CAA3..90CB5B。
// 90CB84..90CB99累积DWORD单元数，沿next直至NULL；本体不创建/销毁节点。
//
// 十二词文本callback
// ----------------------------------------------------------------------------
// 普通路径站点90C355读C+238；节点路径90C5CE/90C790/90C9D3/90CA46读C+23C。
// 两类均callback非NULL、color非0且高BYTE非0、local_y>=0才调用；每次caller清30h。
// 记dx=[C+68]、dy=[C+6C]、gap=[C+24C]、a=trunc0((w-used)/2)*[C+240]。
// 十二词依次为：
// (x+dx+a, y+dy+line*(f+gap), x+w, y+h, 0, f, [C+7C], color,
//  [C+84+4*s], E+6C, line==0 ? 1 : 0, C)。
// color=DWORD[C+94+4*s]；local_y=dy+line*(f+gap)，负数只跳callback，不跳分行推进。
// 半余量通过cdq/sub/sar向0截断，再乘DWORD+240；不保证该乘数字段只有0/1/2。
// E+6C是在load表指针后计算；并非ACC434，也不是指针槽自身内联文本。
// 没有深目标时仅能认这十二词消费ABI；文本编码、绘制参数含义和返回值未闭合。
// 共享暂存跨callback重入和多线程的行为尚无证据，不能称线程安全或可安全保留指针。
