// ============================================================================
// 8E46E0、902180、90A430 / 基础与派生绘制比较
// ============================================================================
// C为入口ECX。共同先读BYTE[C+181]与DWORD[C+B0]，无论可见与否写DWORD[C+18C]=[C+B0]。
// 可见门是消费者用途的命名；本专题不从这一BYTE推断完整显示生命周期。
// s=DWORD[C+B0]，样式地址以C+28*s参与寻址；无s范围门，也不将整个40字节解释为已知结构。
// 常见样式字段为BC图索引、C0附加参数、C4颜色、C8字符串指针、CC/D0/D4/D8附加DWORD。
// 以上偏移均需加28*s；每项均为DWORD。本体没有s范围与C有效性门，合法性需由外部保证。
// 共享几何：DWORD+160/+164为w/h，+168/+16C为x/y；+68/+70参与派生右端点修正。
// E=DWORD[ACC3C8]；只有callback成员有NULL门，E本身无NULL门。
//
// E+00填充、E+08图索引和E+0C字符串分支
// ----------------------------------------------------------------------------
// 基础8E46E0以signed mode=C+A4 >=5进入图索引/字符串分支。
// 90A430同为signed >=5；902180只有mode==5，mode>5仍走颜色/边框路径。
// 图索引signed >=0时，经E+08以十一词调用，caller清2Ch；参数为：
// (x,y,x+w-1,y+h-1,index,style.C0,style.CC,style.D0,style.D4,style.D8,C)。
// 图索引signed <0时，经E+0C以十词调用，caller清28h；参数为：
// (x,y,x+w-1,y+h-1,style.C8,style.CC,style.D0,style.D4,style.D8,C)。
// 基础先判C8指针，再判其首BYTE非零（8E4813/17）；两派生只判指针非零，没有首BYTE门。
// 字符串借用/拥有、编码、附加参数含义和callback是否写入对象仍未知。
// 基础非图分支颜色!=0且高BYTE非零时，E+00六词(x,y,x+w,y+h,color,1)。
// 两派生的非图分支E+00六词为(x,y,x+w+L-R-1,y+h-1,color,1)。
// 此处高BYTE只作为非零门，不能据此认定完整ARGB规范或不透明度值。
//
// 边框调用门不能合并
// ----------------------------------------------------------------------------
// 基础mode<5时填充门失败仍可继续；mode>0才调用8E41D0，参数扩大一格。
// 902180非图分支无条件调用8E41D0，即使颜色为0或E+00为NULL；实际有效mode仍由callee门限制。
// 90A430颜色为0或高BYTE为0跳90A4F6，绕过边框；颜色合格但callback=NULL跳90A4BA仍调边框。
// 因而不能把90A430的颜色门、callback门和边框门合成同一个条件。
//
// 两派生附加标记的实际差异
// ----------------------------------------------------------------------------
// 902180在902317才开始检查BYTE+250，visible=0也会跳到这里，而非直接退出。
// 若+250非零、signed mode<5且E+00非零，调用内部小矩形填充；DWORD+254颜色不查高BYTE/非零。
// 记q=trunc0((w+L-R-2)/4)、t=trunc0((h-2)/4)、u=trunc0(h/4)。
// 参数为(x+q+1,y+u+1,x+w+L-R-q-1,y+h-t-1,[C+254],1)，锚902346..9023C4。
// cdq/and/add/sar实现signed向0截断，不能直接按负数算术右移取整。
// 无可见门保护这一附加fill，不等于实机必显示；callback实际行为未知。
// 90A430附加标记只在visible且signed mode<5分支内。
// DWORD+254非零且高BYTE非零、BYTE+250非零时，分别经E+04两次六词调用。
// 两组线端点：(x+2,y+2,x+w+L-R-3,y+h-3)，以及交换左右x端点的另一对角。
// 站点90A561/90A5B4；最后两词为color、0；分别有独立callback门和18h清栈。
// 这支持矩形中心标记与交叉线标记的用途推断，具体checkbox/radio类型未恢复。
//
// 文本委派与返回值
// ----------------------------------------------------------------------------
// 902180@9023CD始终以ECX=C调用5FF21C桥至90C070；包括不可见和无callback路径。
// 90A430可见路径通过90A5BB/90A637/90A6A2均委派90C070；不可见时仅返回最初AL=0。
// 基础8E46E0不调用90C070，AL可能为原visible、样式计算或callback返回低BYTE，非统一BOOL。
// 90C070退出值来自各路径寄存器/AL，不能据派生返回类型宣称稳定绘制成功信号。
// 本批未采具体实例构造、RTTI或注册表，不把两个绘制入口命名为确定的控件类别。
