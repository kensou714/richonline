// 641EE0 / 有限坐标装载消费
// ----------------------------------------------------------------------------
// i<N，j<16：R.prop[j]!=-1才尝试k<M版本，路径 "%s%s_%02d.avt"。
// 参数是A目录、R+64 coord与k；路径不含prop值。prop仅用于!=-1的资格门。
