// ============================================================================
// 同地图按读取次序追加，访问器返回值对象地址
// ============================================================================
// [事实] 806670每行把首列构造成临时字符串，经对象+0x4570调用808E40。
// 808E40返回一个地址，8068AA再对该地址调用808D40，参数是栈上136字节记录。
// 8069A0也构造同类临时字符串，对相同对象+0x4570调用808E40并返回结果。
// 因此它接收的是地图名字串，不是数值新闻ID，也不直接返回某一条136字节记录。
// [推断] 对象+0x4570是“字符串键 -> 新闻值容器”的树；值容器为vector形态。
// C++模板类名不以反编译器的COleSafeArray/Afx_clearerr_s误名为依据。
//
// [事实] 808E40先取得查找候选，再比较end/键顺序；不匹配分支构造默认值与pair，
// 调用提示插入包装，释放临时pair及默认值；最终经809D60取payload后加28返回。
// 809D60经80B490把迭代器节点传80A730；80A730返回node+12。
// 因而V为node+12+28=node+40；这只证明payload/值偏移，不证明完整节点大小。
// 默认值809000 -> 8090E0 -> 809FF0(0)，末函数直接清V+4/+8/+12并返回。
// [推断] 行为对应map::operator[]形态的默认插入查询；不当作无副作用find。
// [未知] 所有树旋转、比较底层、分配器以及整树释放/根对象生命周期未在本专题闭合。
// 空容器地址非空不能证明地图存在；调用访问器确认缺失键可能已创建空值。
// 809BF0下游的80B140执行候选遍历；80ABB0是插入及颜色/旋转修复流程。
// 本批不把80ABB0误作lower_bound，也不以其完整块导出声称树不变量全部已审阅。
//
// [事实] 808D40先比较size与capacity，有空间时对end构造一条并更新end；否则调用插入扩容。
// 136字节步长由size/capacity辅助与695260索引链交叉确认，字段形态为：
//   V+4 begin，V+8 end，V+12 capacity_end；V+0辅助字段的具体类型未命名。
// [推断] 同一地图的索引遵循该读取器实际追加顺序；type是元素字段，不是索引。
// [事实] 806670当前实现没有加载前clear调用，查找/追加在每行重复。
// [推断] 同一对象反复装配同一文件会继续追加；动态重复加载和对象换代仍需实机验证。
// G挂接的是V地址；V内部begin扩容时可变。未核节点删除和并发，不声明运行时重载安全。
//
// 与模式3的界线
// [事实] 模式3的R+0x2F0、691AB0/6950D0不是本链+0x4570、8069A0/808E40。
// 可复用其结构阅读方法；不能复用其析构函数地址作为本链所有权证明。
