// 7B9AD0装载主干
//   构造资源读取对象，尝试读取Data\GValue.kpd；文件打不开时只清临时对象，不写表。
//   成功后建立文本配置对象，以模式2挂入展开正文，循环查找重复ITEM节。
//   每个ITEM先查indx，以128为长度参数读到字符缓冲，经atoi得到索引。
//   8198E0复制到换行后才检查v4+1>a3并assert；128不是边写边限长的安全保证。
//   随后查value，用同一缓冲和atoi得到数值，写DWORD[A87080+4*indx]。
//   没有本函数可见的indx范围检查，value也没有按业务域统一裁剪。
//   本函数未检查字段查找及资源展开的返回值；异常输入不能沿用正常装载结论。
//   atoi的signed int结果与DWORD存储位模式并存；消费者可窄化或作signed比较。
//   循环结束析构配置/资源对象；返回清理调用结果，不能当整份配置成功标志。
//
// 装载的边界
//   本函数不预先清空GValue表。当前资源仅使用0..37；正常重复有效索引顺序覆盖此前值。
//   如果再次调用，也只覆盖实际遍历并写入的索引；不能据此推断程序存在热重载入口。
//   是否有外围清零及调用前实际表值需另查；不能把本函数不清表扩大为全程序不清表。
//   丢失indx/value时的底层查找及缓冲状态需要按解析器路径核对，不能假设自动补零。
//   atoi并不是严格十进制字段验证；编辑器应先检查整数文本、唯一索引和业务范围。
//   起点所在PE .data虚拟尾部没有原始字节映射，不把IDB初值写成磁盘默认配置。
//   文件打不开时保留本函数调用前的表值；其具体值及后续表现仍需初始化和实机证据。
//
