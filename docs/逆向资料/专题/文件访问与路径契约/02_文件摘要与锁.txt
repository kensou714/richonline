// 81B980 / 外层临界区
//   81B983把ECX设为ABAB9C，6BFA00进入该临界区。
//   文件名和输出地址交给827B30；正常返回后6BFA40离开同一临界区。
//   锁覆盖打开、循环读取、摘要终结和关闭，而非只保护某个摘要全局变量。
//   本函数没有初始化/删除临界区，也没有可见的异常展开解锁尾块。
//   伪码的int返回来自LeaveCriticalSection薄包装残留，不是文件校验成功标志。
//   已见调用在未声明窗口7DEF2B；不能因为入口存在便认定所有资源加载都走它。
//
// 827B30 / KetMd5GetDigest
//   fopen(FileName,"rb")失败立即离开，不写输出、不写默认摘要、不报告业务错误。
//   成功后建立局部88字节状态；4096字节栈缓冲以fread(buffer,1,4096,FILE)读取。
//   每次把实际返回字节数送入828DD0；返回0才终止循环。
//   之后828E90写16字节原始摘要并清理状态，然后fclose；不检查关闭结果。
//   未调用ferror/feof区分循环退出原因。读失败可能生成已读前缀的摘要。
//   输出地址由调用者提供，未验证空值/16字节容量；没有分配或转移输出所有权。
//   没有32字符十六进制编码，也没有NUL；需要文本时由工具自己显式转换。
//
// 状态布局 / 88字节，按本实现读写偏移复原
//   +00..+0F  四个32位链值A/B/C/D。
//   +10       累积比特长度低32位。
//   +14       累积比特长度高32位。
//   +18..+57  64字节未完成块。
//   8283C0置链值67452301、EFCDAB89、98BADCFE、10325476；两个长度DWORD为0。
//   初始化不清64字节块；算法仅使用之后写入的有效数据和终结填充。
//
// 828DD0 / 更新
//   旧低计数右移3并与3Fh取得当前块已用字节数。
//   低计数加len*8，溢出进位，高计数另加len>>29，按32位模运算保存。
//   新输入足够时补齐已有块，调用8284E0；随后每64字节压缩，尾部复制到+18。
//   不负责申请/释放输入，不保持输入指针。返回尾部复制计数，不是错误码。
//   本文件接口每次len<=4096；不把这条已知约束扩大为任意UINT32长度均安全。
//
// 8284E0 / 压缩
//   输入64字节手动组合成16个小端DWORD，读取旧A/B/C/D。
//   四轮布尔式依次是F=(B&C)|(~B&D)、G=(B&D)|(C&~D)、H=B^C^D、I=C^(B|~D)。
//   每轮16步；选字索引依次为i、(5i+1)%16、(3i+5)%16、7i%16。
//   循环左移序列：7/12/17/22；5/9/14/20；4/11/16/23；6/10/15/21。
//   全部64个加法常量与标准MD5对应，符号负常量应按32位无符号模值解释。
//   首步D76AA478、末步EB86D391；不能因为伪码有16位拼接就判成变种摘要。
//   结果按DWORD模2^32累加回原四链值；不更新长度，也不清本地16字工作栈。
//   该函数无外部调用，完整字节和伪码保存在digest_transform.json。
//
// 828E90 / 终结
//   先保存+10..+17原比特长度，按小端8字节形式暂存。
//   若当前块已用少于56字节，补到56；否则补到120，允许跨入第二块。
//   A67750填充区为80h后跟63个00h；随后再追加原长度8字节。
//   将四个链值逐字节写到输出，共16字节，然后rep stosd清零22个DWORD状态。
//   清理范围仅为88字节状态；未清文件4096字节缓冲或压缩函数的工作栈。
//
// 引用证据及继续研究边界
//   827B30经过60EA3C -> 827850 -> 60F4D2到达，另有A65688数据引用。
//   81B8B0只见60CDBD跳板引用，没有从该跳板继续找到直接调用者。
//   静态无直接调用不等于不可达，导出地址表/动态调用需单独闭合。
//   MD5用途为兼容原资源校验，不把它视作带身份认证的完整性协议。
