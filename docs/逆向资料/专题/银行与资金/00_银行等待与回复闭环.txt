// 地址与证据
// 4018 -> 7EF9B0桥接 -> 65E1B0；402A -> 660320（桥接见游戏分派映射）。
// 完整伪代码、带VA汇编、每个指令范围原字节和直接跳板在证据/bank_handlers.json。
// 逐函数比较当前磁盘均一致；本文没有通信连接、客户端运行或余额实测。

// 对象字段：G为游戏对象，P为当前行动角色
// DWORD[G+0xE28]为当前行动槽，P=DWORD[G+0xE00+4*slot]。
// WORD[G+83844]为GmsvID；64F710与回复+2比较，不同弹Error GmsvID并返回false。
// DWORD[P+1464]为当前位置，63E410读取。
// DWORD[P+1504]为现金，DWORD[P+1508]为存款；扣减函数按signed32判断结果，增加函数不夹紧。
// BYTE[G+83832]记录此次银行入口的中途标志；693CB0写入，不与队列抑制位混用。
// pending类型/时长/起Tick仍在G+83790/+83792/+83796，见回合等待专题。

// 4018的字段与最小读取
// +0 WORD消息号；+2 WORD GmsvID；+4 signed WORD目标格；+6 BYTE中途标志。
// 常规判断读取到+6；位置不匹配分支复制整8字节，因此整体调用契约至少8字节。
// 不能把“只见7字节字段”误写成允许7字节输入。
// 此handler没有独立长度参数；长度约束须在外部帧和分派层保证。

// 先等待角色位置，再建立银行选择
// GmsvID通过后，若中途标志为0，或目标格等于P当前位置，进入银行。
// 若中途标志非0且位置不等：复制原8字节记录，读队列当前head，
// 经64FA50在head之前重新插入记录；本分支不打开UI、不设置银行pending。
// 63E5B0实际先把this改为G+0x640，再经63F940返回Q+12的head。
// 它不是伪名CDialog::OnInitDialog所暗示的窗口操作。
// 队列消费者7BB290每次调用至多取一条；重插后返回，不在本handler内忙等位置。
// 错位持续时该记录仍排在后续记录之前；位置能否由外层角色更新推进须另查调用时序。
// 本轮未证明所有错位记录终将匹配，也不能将重排次数当网络重试次数。
// 插入ABI与head语义另见../基础对象与分派/01_游戏记录队列与消费门控.txt。

// 正式进入
// 保存中途标志到G+83832；63F760仅比较当前行动槽与本地槽G+8。
// 本地行动者打开UI17，界面持续参数8000，数据通知传一个DWORD行动槽。
// 当前资源UI17=G_Bank.ui，工厂对象0x60字节，见界面专题第二批逐槽导航。
// 所有客户端设置pending16、duration8000、start=GetTickCount；第4参数1未在setter使用。
// UI自身到期关闭与Game pending清除不是同一动作；不能只凭8000推导会自动发取消。

// 402A资金回复：直接字段跨度12字节
// +2 WORD GmsvID；+4 WORD动作；+8 DWORD金额。+6/+7本handler不消费。
// GmsvID匹配后关闭UI17；按当前行动角色P结算，不从回复指定角色。
// 四次资金调用各自在调用前重读G+0xE28并取P，再将P装入ECX；没有固定角色快照。
// 动作0：7F83F0扣现金（不足时还会扣存款），再7FA0A0把原金额加到存款。
// 动作1：7F9F10扣存款并在负数时归零，再7FA050把原金额加到现金。
// 其他动作：不改变这两个余额，但仍进入共同清pending与继续流程。
// 本函数未检查pending是否16、金额正负/余额足够/加法溢出/重复回复。
// 不能把客户端局部归零当成交易校验；服务端需要维护一次性待决和资金守恒。
// 这是一组静态契约，不声称当前服务端允许非法金额或已存在远程触发路径。

// 共同收尾与中途恢复
// 6939E0将pending类型写-1、持续值写0；保留旧起始Tick。
// 中途标志非0：对P调用7F5CC0(1)，将DWORD[P+548]清0、BYTE[P+552]置1，
// 并经693FB0把P+1456字节加1，再选择100/120/121音效入口。
// 7F5CC0还先调用一个内部状态setter；具体移动状态见移动与动画协议专题。
// 中途标志0：构造本地6080，+2=2，构造器+3=-1，按4字节插入队列。
// 插入位置使用66034C在GmsvID校验、关UI及资金操作之前保存的head，非收尾重读。
// 本轮未把6080所有落点处理语义展开；这里只确认其构造与队列交接。
