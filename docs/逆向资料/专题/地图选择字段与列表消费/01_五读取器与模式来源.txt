// ============================================================================
// 五个列表读取器：模式与选择值是两个维度
// ============================================================================
// 当前RnClient.exe SHA256：
// a23410e79637e312c932f861176d8d81cd1fd5d222a286f279feccdece6263c2。
// R表示628270返回的共享根对象；U表示地图选择界面对象，二者不能混用偏移。
// 所有偏移为十六进制；字段读宽度均来自汇编，不使用MFC/ATL自动名称推断类。
//
// 选择值s与五个返回指针
// ----------------------------------------------------------------------------
// 64F200返回R+64的地址，读取器再取该处DWORD，记为s；它不是返回回调函数地址。
// 6AA840：s=0取DWORD[R+520]；s=1取[R+52C]；s=2取[R+538]；其余返回0。
// 6AA8C0：s=0取DWORD[R+524]；s=1取[R+530]；s=2取[R+53C]；其余返回0。
// 6AA940：固定取DWORD[R+514]；不读取R+64，没有选择值检查，也不调用其他函数。
// 6AA960：s=2取DWORD[R+51C]；所有其他值取[R+518]，包括负数与3以上的值。
// 6AA9C0：s=0取DWORD[R+528]；s=1取[R+534]；s=2取[R+540]；其余返回0。
// 三组0/1/2布局相隔0x0C，但本体用显式比较和分支读取，没有index乘法或数组校验。
// 返回的是字段中的DWORD，不是R+偏移本身；后续以它作ECX访问链表对象。
// 五函数都没有验证R非空，也没有验证字段指针非空、初始化或仍有效。
//
// 模式m：只负责挑哪一个读取器
// ----------------------------------------------------------------------------
// 629DD0严格比较参数==0；629DF0比较==1；63EDD0比较==2；63E1A0比较==3；
// 629E10比较==4。均先xor eax,eax再sete al，返回32位0或1，cdecl普通ret。
// m=0 -> 6AA840；m=1 -> 6AA8C0；m=2 -> 6AA940；m=3 -> 6AA960；m=4 -> 6AA9C0。
// m与s分别选择模式和根对象字段，不能将它们统一为地图ID、页号、难度或频道枚举。
// s也被6AAA80用作候选门槛；本批沿用其数值矩阵，不由这个联系替s赋业务名称。
//
// 两条模式来源
// ----------------------------------------------------------------------------
// 73FC70：629E60(R) = DWORD[R+5D8] + DWORD[R+5E0]*0x7C，返回当前记录地址。
// 模式从该记录+38读DWORD。乘法及加法不验证索引，不能写成直接读取R+38。
// 73F420：模式直接读取U+4C。mask1可由输入参数+8覆盖此字段。
// 73F4B9调用73FC70之前已经写U+4C，但73FC70重读共享记录+38；二者相等的
// 运行时不变量未在本批证实，不能默认初始选项与列表刷新一定从相同模式取值。
//
// 版本与复用
// ----------------------------------------------------------------------------
