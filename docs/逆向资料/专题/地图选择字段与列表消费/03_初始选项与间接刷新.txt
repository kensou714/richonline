// 正常路径
// ----------------------------------------------------------------------------
// 从共享当前记录+38取得m，按01的五模式谓词选列表读取器；每次重新取得R再调用。
// 读取器返回值存[ebp-10h]，并把本地初始化标记BYTE[ebp-129h]设1。
// 73FDB0压index=0，再压局部out地址；73FDB9装列表指针到ECX，73FDBC调用79CA40。
// 返回的out指针交9204C0 strcpy，目的地址U+D0；无目标容量参数，无显式NUL检测。
// 128字节内存在NUL是字符串复制安全前提，不能从定长节点复制推得一定有终止符。
// 9204C0仅7字节入口，短跳920535进入9204D0共享块；复制到NUL的语义按该共享块核验。
// 历史来源为聊天发送与重复提示契约的chat_contract_discovery.json；本批重核当前PE。
//
// 间接调用的实际ABI
// ----------------------------------------------------------------------------
// 73FDD4只给[ebp-A4h]写DWORD 4；其余邻接栈区仍只有函数序言的调试填充值。
// 73FDE0取该地址压栈，ECX恢复U，73FDEF执行call DWORD[[U]+10h]。
// 因而已知输入是一个至少含首DWORD mask=4的栈参数地址；没有证据说明整个结构已初始化。
// 不能将该调用直接重命名成73F420，也不能把本地debug填充当业务默认值。
// 73F420的mask4路径只需输入首DWORD且读取U+D0，形态相容；仍需构造/vptr证据证明目标。
// 调用后检查栈平衡并保留返回EAX；正常返回值来源为实际虚槽目标，不能写死为成功1。
// 该栈参数在73FC70返回后失效；虚槽是否复制/同步消费之外的行为未知。
//
// 无模式匹配与NULL列表
// ----------------------------------------------------------------------------
// 73FC9A把初始化标记置0；若m不为0..4，73FDA8会调用922570("pMapList")。
// 标识原字节位于73FE40，为pMapList加NUL，共9字节，不是资源配置文件路径。
// 报告返回后代码继续读取[ebp-10h]并调用79CA40；该槽仍是0xCCCCCCCC调试填充值。
// 若m合法但读取器返回0，初始化标记仍设1；没有第二次NULL检查，仍将0作ECX消费。
// 因此本体没有保证“无匹配或空列表则安全返回”；这是静态前提，不是实机崩溃复现。
