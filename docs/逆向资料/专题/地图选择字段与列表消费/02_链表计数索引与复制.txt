// ============================================================================
// 五读取器返回的列表：节点前128字节载荷，+80链接
// ============================================================================
// 79A1E0、79CA40、79CAD0为本批三条完整补证，分别24/110/93字节。
// 这些实现是链式遍历；不能套用随机地图专题的128字节连续容器乘法或vector契约。
// 载荷宽度都是128字节并不表示容器相同，也不是MapView的0x114字节记录。
//
// 已恢复布局
// ----------------------------------------------------------------------------
// 列表对象+00 DWORD：首节点指针，79CA40/79CAD0都从这里开始。
// 列表对象+08 DWORD：计数字段，79A1E0不计算链长，直接返回该DWORD。
// 列表对象+04及完整对象大小未恢复，不能擅自填成tail或容量。
// 节点+00..+7F：128字节载荷，在消费者中作为地图名称/资源键字节串使用。
// 节点+80 DWORD：下一节点指针；其他字段和总节点分配大小未知。
// +80是链接偏移，不是数组步长；不得写成head+index*128。
//
// 79CAD0(list,index)：借用节点
// ----------------------------------------------------------------------------
// index为一个栈DWORD；i从0开始，node=head。只要node非0且i!=index就读node+80前进。
// 返回当前node；ret4。有效非负索引返回相应节点，无匹配而遇到尾部则返回0。
// 本函数不读count、不拒绝负数、不检测环、不验证指针。负数通常遍历至NULL，
// 但不能据此保证结束：损坏链/环及32位计数回绕都是未检查条件。
// 返回地址借用列表节点，没有复制；修改、释放或替换列表后不能假设仍有效。
//
// 79CA40(list,out,index)：复制节点载荷
// ----------------------------------------------------------------------------
// 使用同样的逐节点查找，随后无条件把node作为ESI，out作为EDI，ECX=32执行rep movsd。
// 总共复制128字节，EAX返回out，ret8；它不是strcpy，也不补NUL。
// 查找遇到NULL仍执行复制，因此空表或越界不是“输出空串”的安全分支。
// 调用者须保证目标可写128字节、节点可读128字节、DF=0；函数未设置DF或验证重叠。
// 本体没有分配/释放；复制得到的是独立字节快照，但是否为有效字符串另需NUL约束。
//
// 两种消费寿命
// ----------------------------------------------------------------------------
// 73FC70用index=0复制到栈缓冲[ebp-128h,ebp-A8h)，再strcpy到U+D0。
// 这条路径不在U中保存节点指针；strcpy要求复制的128字节内有合法NUL。
// 73F420用79CAD0取得节点指针，然后把它交控件文本、门槛及MapView查询调用。
// 这些同步调用期间要求节点仍活着；控件是否另复制字符串、异步保存或借用不在本批闭合。
// 根对象字段的分配、填充、替换、销毁与count/实际链长一致性均未由三短函数证明。
