// ============================================================================
// 73F420：输入掩码与界面字段，深化阅读仍保留部分分析
// ============================================================================
// 本体旧原证1849字节598指令逐条复读；本批新增字段来源和列表契约，不重采旧入口。
// 主要描述mask1/2/4与列表关系；所有外部配置对象、预览对象和控件虚槽没有全部闭合。
// U为ECX界面对象，a2为一个栈指针；本体不校验a2、U或控件查找结果非空，末尾ret4。
//
// 输入与局部字段
// ----------------------------------------------------------------------------
// a2+00 DWORD：更新掩码；三段分别按位1、2、4检测，可以同时执行。
// a2+04 DWORD：mask1写到U+48，用于选图标39/40或-1。
// a2+08 DWORD：mask1写到U+4C，作为五模式判定的参数m。
// a2+0C BYTE ：mask1相关比较按signed BYTE读，变化时写到U+158。
// a2+0D起字符串：mask1用strcpy写U+50；本体没有容量参数，来源长度未知。
// U+04 DWORD：控件宿主；U+48 DWORD：局部类别；U+4C DWORD：模式。
// U+50起：文本槽；U+D0起：当前名称；两段地址相距128字节，但本体不证明完整类容量。
// U+150 DWORD：列表起始索引；U+154 DWORD：外部摘要/预览对象；U+158 BYTE：signed选项。
// U+150与U+158是界面字段，不能与根对象R+514..540的列表指针布局相混。
//
// mask1：改变模式或signed选项时重置
// ----------------------------------------------------------------------------
// 73F471比较U+4C与a2+8；73F47C/486有符号扩展两个BYTE再比较。
// 任一不同则写新模式、U+150=0、新BYTE，并于73F4B9以U调用73FC70取首项。
// 之后无条件更新U+48/U+4C并复制a2+0D字符串。U+48==0取图像参数(10,21,39,-1)，
// ==1取(10,21,40,-1)，其他值保留局部-1，结果提交控件2。
// 73FC70读共享记录模式而73F420读U模式，相等关系需上层生产证据，详01。
//
// mask2：最多三个条目
// ----------------------------------------------------------------------------
// 按m=0..4选择五读取器，返回列表存本地L。未匹配调用922570后仍继续使用本地槽。
// 73F642以L作ECX调用79A1E0读count；交控件4的796B10，起始索引交727790。
// i=U+150，控件ID=10；有符号i<count且ID<=30时消费79CAD0(L,i)，每轮i++、ID+=10。
// 条目控件的+C8接收1，节点地址交8E15B0(节点,0)，桥607C32。没有检查返回NULL。
// m=2经6050F9到6A1610，m=3经601814到6A1850，其余用6AAA80判断可用性，取AL。
// 允许时取MapView的pic_enb，拒绝取pic_dis，结果交6FA7F0提交至条目控件。
// m=2/3时ID+2虚槽+C8接收0；其他模式接收“可用性为零”的BYTE结果，拒绝时
// 还调用73FE50按频道取提示图像。C8实参高位并非处处规范化，不能写成完整int布尔。
// ID+3收到MapView的new BYTE，但同样不能仅凭槽偏移命名为显示/隐藏。
// 未填满的ID10/20/30剩余控件+C8接收0；这不证明其他子控件所有状态都被复位。
// 本体没有i>=0检查，也没验证count与链长一致；有效非负起始索引是安全消费前提。
//
// mask4：选项图标或真实名称预览
// ----------------------------------------------------------------------------
// U+158被movsx读取。非负分支把U+D0传预览对象方法后以signed值+74取图像，
// 以signed值+879取外部文本，交控件1与3；控件7的+C8接收0。
// 负数分支以U+D0取得预览图像与摘要，并按模式求可用性，控件7收到反向BYTE结果。
// U+158不是节点索引：本体从不把它送79CAD0，也不把它当整数地图ID。
// 后尾m=4/0/1时向控件5132..5134的+C4传1；其它模式的对应复位逻辑不在此尾部。
// 本体末尾EAX受最后执行路径及外部调用影响，没有统一“成功”返回约定。
//
// 另一owner局部窗口
// ----------------------------------------------------------------------------
// owner75E6F0，窗口75E9B7..75E9E0：75E9C8调用6AA840，返回作为ECX给79A1E0。
// 这里只证明第一模式读取器返回对象+8计数被消费，不记75E6F0整函数完成分析。
// 后续随机/索引/列表替换路径未在该窗口闭合，不能据此扩大为完整地图随机选择功能。
