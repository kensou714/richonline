// 相对坐标、绝对坐标与布局传播
// ============================================================================
// 8E30D0（ECX=C）：有父则绝对坐标=相对坐标+父绝对坐标；无父则绝对=相对。
// 随后用绝对坐标减父绝对坐标回写相对坐标，清 C+28/+32/+36/+40。
// 本函数只刷新自身，不递归子树。
// 8E38A0：栈参是起始节点，保留入口ECX供递归调用；自身刷新时改ECX=当前节点。
// 遍历顺序为当前自身、后继兄弟子树、当前首子（沿首子循环）；retn4。
// 虽反编译标std_call，调用点还会设置ECX；不应擅自把保留上下文省略。
//
// 位置接口
//   8E31B0 水平 / 8E3340 垂直：ECX=C，参数是新相对位置和排除对象。
//   先写位置并调用自身虚表+8；基础+8为空函数8E3830，派生可能覆盖。
//   C+387为0时将位置限制在父尺寸或U客户区尺寸内；超大控件最后位置归0。
//   沿同层链找兄弟，排除自身和排除参数；仅对C+424数组中的关联对象递归移动。
//   关联对象新位置 = 当前最终位置 + 对方旧位置 - 当前旧位置。
//   递归时排除参数传当前C；只阻断直接返向，没有完整访问集合或任意关联环检测。
//   最后刷新自身坐标；有首子则以8E38A0刷新子链的绝对坐标；清四布局字段。
//   关联数组的有效数量在C+428；数组所有权构造/填充接口尚未独立闭合。
//
// 尺寸接口
//   8E34D0 宽 / 8E3610 高：请求值<=0，或C+164==5且C+168==1时直接返回。
//   C+387=0时按父或客户区边界截短；为1时允许越界。
//   遍历直属子链：越界且子+387=0，先把子位置改为父尺寸-子尺寸；仍越界再缩子尺寸。
//   宽调用60094B/601251，分别落到水平位置/宽度；高调用6032CC/603C4F。
//   最后调用自身虚表+12；基础+12=8EA240，只清C+28/+32/+36/+40。
//   请求为正不保证最终写入为正：截短使用“边界-相对位置”，没有第二次非负修正。
//   子尺寸调整也受<=0和样式门限制，不能宣称父缩小后所有子矩形必然被夹回。
//
// 层序 8E3750
//   新值负数归0；摘链后从父首子或U顶层链寻找插入点。
//   只跨过层序严格大于新值的节点，插在第一个<=新值节点之前。
//   既有链已按C+368降序排列时，本操作保持降序；同层新节点位于已有同层节点之前。
//   创建接口直接插头，默认层序0可能插到高层节点之前；不能把全链始终有序当作不变量。
//   此接口只摘插当前节点，不会替其它已有节点重新排序。
//   写回C+368；不更改父指针，不刷新坐标，不调用销毁。
//   8E48F0无条件先递归兄弟再画自身；在链已降序的前提下，低层先画、高层后画。
//   同层节点的相对顺序服从实际链位置，新头在对应兄弟之后绘制。
//   8E7E40也先处理兄弟，再由自身/首子命中覆盖，因此新同层节点通常更靠前。
//   图像透明度、层掩码、visible、输入模式等门仍会改变最终命中，不能只靠排序推断。
//   显示/启用时用既有C+368重新调用层序接口，可改变同层顺序。
