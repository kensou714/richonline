// C+384=enabled，C+385=visible；两者构造默认1。
// 8E3A70只在参数不同于C+384时进入动作，并且先写enabled。
//   启用：根据悬停/按住引用选样式1/2/0；从首子调用虚表+0刷新；重新插层序。
//   禁用：模式U+20764!=1时清理属于本树的输入引用，调用失活/失焦通知；自身样式设3。
//   最后用当前位置重新命中，若悬停对象变化则给旧/新对象发离开/进入，并更新时间。
//   返回值不是稳定的成功布尔值，可能是TickCount低字节或未进入动作时的输入值。
//
// 8E3EB0显示/隐藏
//   显示时，若旧visible=0先调虚表+20显示通知；随后+196转交当前enabled。
//   从首子调虚表+0刷新，再用当前层序重插。
//   隐藏时，模式!=1清输入引用；若旧visible非0调用+16隐藏通知。
//   最后才写visible参数，再重新命中并更新悬停引用与时间。
//   显示/隐藏通知看到的是旧visible。即使状态没有变化，也可能重新排序/命中。
//
// 输入清理不是简单比较C指针
//   U+20700、+20712、+20708、+20716、+20720、+20724、+20728分别取出引用对象。
//   每项以该对象的C+8名称，从当前this树进行8E2B50(name,0)查找。
//   仅查找返回指针等于原引用时清理；+20700和+20716清后分别调虚表+40/+48通知。
//   清+20708时还清U+20808重复计时。名称碰撞会让“同树判断”返回另一个对象。
//   模式1绕过这一组清理；析构8E0ED0另有直接指针清理，不能混用两套规则。
//   析构中U+20724只要非空即清零，未要求等于当前this；这是观察到的实际条件。
//
// 样式遍历 8E39D0
//   基础虚表+0 -> 612C95 -> 8E39D0。
//   先将后继作为栈参、ECX=后继，通过后继虚表+0调用；再处理本节点。
//   本节点visible且C+164==5时，按本节点enabled将样式切为0或3。
//   然后将首子作为栈参、ECX=首子，通过首子虚表+0调用。
//   这是虚调用遍历；派生+0覆盖能改变行为，不能说所有节点都直接调用8E39D0。
//   该函数不把父visible/enabled复制到子字段。两状态接口也没有递归写子布尔值。
//
// 实际遍历门控
//   绘制8E48F0：先处理兄弟；本节点hidden会跳过自身及首子绘制。
//   命中8E7E40：先处理兄弟；hidden且模式!=1会返回兄弟结果，跳过本树。
//   当前节点enabled为0会阻止进入其首子命中路径，但不是当前自身命中的统一门。
//   当前掩码与U+20756不交时也不查首子；图像、透明标记和模式继续约束结果。
//   子控件的visible/enabled可以保留1，同时因父节点门控而没有绘制或子树输入。
//   修改UI时应区分保存的局部状态与经父链实际可见/可交互状态。
