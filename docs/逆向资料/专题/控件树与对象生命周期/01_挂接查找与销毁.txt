// 链模型 / 根控件与子控件共享同一组父、首子、后继字段
// ============================================================================
// U+20696 是顶层链头；C+400 是父；C+404 是首子；C+408 是后继兄弟。
// 构造 8E0AF0 将三字段置零。链是单向结构，没有已确认的独立前驱字段。
//
// 创建并挂接
//   8E22C0：ECX=U，六个栈参；U+80 非空先调用自定义工厂。
//     工厂按 cdecl 接收原六参和第七参0；返回0才回退 603DA3 -> 8E24D0。
//     成功时把旧顶层链头接到新 C+408，然后写 U+20696=C。
//     以 ECX=C 调 601319 -> 8E30D0 刷新绝对坐标，返回新对象。
//   8E23F0：ECX=父C；自定义工厂的第七参是父C；回退用全局U。
//     成功时写新 C+400=父C、C+408=旧首子、父C+404=新C；再刷新新C坐标。
//   两接口失败输出 A67ADC 文本并返回0，均 retn 18h。
//   两接口只在旧头非零时写新 C+408；根创建不显式写 C+400=0。
//   因此自定义工厂必须返回已初始化且未挂接的对象，不能假设入口会重置旧链字段。
//   工厂槽是 U+80，不是旧资料误写的 U+20。
//
// 默认工厂 8E24D0
//   type 0..12 分配大小依次：240h、250h、250h、268h、384h、268h、264h、250h、
//   490h、268h、340h、32Ch、364h；随后分派构造跳板。
//   越界类型/分配失败返回0。这里未给各type强行套控件名称，也未闭合各派生所有权。
//
// 名称查找
//   8E2AC0：两个栈参（字符串、节点），retn8。
//     当前节点名称非空且非空串时不区分大小写比较；命中返回当前节点。
//     失败先查首子子树，再查后继兄弟子树，返回第一个命中；不筛visible/enabled。
//   8E2B50：ECX=this，字符串和可选起点a3两个栈参。
//     字符串null/空串输出 A67AEC 后返回0；a3=0时检查自身，再搜索首子。
//     a3非零时检查a3名称；比较成功却返回this，而非a3。
//     这是汇编中的 mov eax,edi，EDI保存入口ECX，不是反编译误读。
//     若a3名称不符，只进入a3的首子；不会直接搜索a3的后继。
//     610D96的15处已知直接调用均传a3=0（两状态接口14处、8E8800一处）。
//     非零a3分支应视为潜在接口陷阱；尚无已确认的现有调用触发它。
//
// ID查找 8E2C10
//   a3=0先比较this+4，再从this首子开始；a3非零比较该节点，再查首子，最后移兄弟。
//   深度优先、首个匹配返回；失败0。名称和ID都没有本地唯一性检查、循环检测。
//   重名会影响状态清理所用的“查找结果是否等于原对象”，不能只当作显示标签。
//
// 摘链与层序重排
//   8E2CA0：从父首子或U顶层头寻找前兄弟；当前是头或头为空返回0。
//     若非空链完全找不到this，则返回链尾，而非0；其调用方必须保证成员关系。
//   8E2D10：前兄弟非零则改其+408，否则改父+404或U+20696。
//     不清当前C+400/+404/+408，不销毁对象，不自动建立新父关系。
//   8E3750：在同一父/顶层链内摘下并按层序重插；不是跨父reparent接口。
//   8E0000..910000显式+190h/+194h/+198h写者归于构造、创建、析构、摘链和层序。
//   本扫描没有发现该区间的通用reparent入口；别名写、memcpy及其它区间未据此排除。
//
// 递归释放 8EA680 -> 60B71F
//   先递归 C+404；返回后重新读当前 C+408，再递归兄弟；最后调用虚表+120。
//   基础虚表+120 -> 60F3D8 -> 8E3850：基础析构8E0ED0，然后 operator delete。
//   因此此接口销毁的是“当前节点开始的整条兄弟链及其子树”，不能用于删除孤立单个节点。
//   子/兄弟基础析构会摘链；8EA680使用当前字段重读，不缓存释放前的后继指针。
//   8E0ED0先将虚表换为基础表、递归释放首子并置首子0；清引擎引用后再调用摘链。
//   其中若U顶层头恰等于this，会先置U顶层头0；这与销毁整条顶层链的路径相容，
//   但不能从这里推出“直接delete顶层头且保留其它根节点”受到支持。
//   派生析构覆盖、回调重入以及外部保存的裸指针尚未全部闭合。
// ============================================================================
