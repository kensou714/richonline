// ============================================================================
// 7FF240 / Prop.kpd两遍装载的限定路径
// ============================================================================
// ECX=M，一个文件路径栈参数，ret4。主块5775字节，声明异常尾43字节。
// 启动623CB0中的623D41经604CC1调用此函数，参数Data\Prop.kpd。
// 本题确认到part/ROLE、必要编号与初始化路径以及退出门；未认领全部属性。
//
// 打开、数量与数组
// ----------------------------------------------------------------------------
// 7FF295调用81B4C0打开；返回0时清理栈资源并返回0，尚未改变M数组与数量。
// 非零路径调用81B7F0解包；7FF2D1经646590取角色数量N，存一份装载时快照。
// 文本对象以mode=2、preprocess=0导入；本体未检查解包/导入的返回值。
// 7FF30C先令M+04=0，第一遍逐PROP找indx；键存在才读取、atoi、signed比较。
// 只在indx > 当前最大值时更新，7FF380最终加1得到C。
// 所以C是max(0,各有效定位indx的atoi值)+1，服从32位加法，不是PROP物理段数。
// 无PROP或只有非正编号仍产生C=1；正最大值7FFFFFFF会加法回绕。
// 复位文本游标(0,0)后申请C*1128+4字节；乘加无本地溢出拒绝。
// 有分配结果才写cookie、逐项构造；否则数组值选NULL。7FF436直接覆盖M+00。
// 第二遍不因NULL而整体退出；有indx的段继续按index*1128写首DWORD。
// 首次扫描忽略负编号，第二遍却未拒绝负编号；没有单独0<=index<C门。
// 这是坏输入的静态条件路径，不宣称当前原包或实机已经越界。
//
// part写入
// ----------------------------------------------------------------------------
// 7FF65D找part；缺键跳过，保留这条记录现有的+0C值。
// 首次填一条已构造记录时该值为-1；重复indx的后段缺part会保留前段类别。
// 存在时读取字符串(参数128)，7FF687调用7FF1D0，7FF69A保存完整EAX到P+0C。
// 未命中31项表返回FFFFFFFF，覆盖原类别；表序和大小写规则见04。
// 文本读取的128是实参；反编译String[132]来自槽间距，本专题不据此恢复数组容量。
//
// ROLE字节数组
// ----------------------------------------------------------------------------
// 7FF6EA..7FF710无条件申请N字节并覆盖本条P+14；没有旧指针释放或NULL门。
// i从0递增，7FF729/7FF72C按signed i>=N退出；N<=0时不写ROLE字节。
// 分配仍使用N的32位位型；负数计数不会在分配前被拒绝。
// 每个i先于7FF747写1，再格式化ROLE%d、定位当前段键。
// 缺键保留1；存在时取字符串并strcmp(value,"true")：完全相等写1，其它写0。
// 7FF7A4 neg / sbb / inc形成布尔值，7FF7BE只写AL；不是写DWORD。
// false、TRUE、空字符串及任何其它值均非精确true；比较不自动大小写折叠。
// ROLE10等更高键只有N相应足够大时才会查找；键的存在不会自行扩大N或数组。
// 以上分配只在第二遍实际存在且带indx的PROP段执行；稀疏缺号槽只经构造，
// 保持编号=-1、part=-1、P+14=NULL，没有为这些槽生成默认全1的数组。
// P+14没有伴随容量保存；消费者按另一次读取的档案数扫描，见04。
//
// 重载、重复编号与返回边界
// ----------------------------------------------------------------------------
// M+00覆盖前无旧数组释放；同index重复出现时P+14也直接覆盖前一指针。
// 两者均有丢失原分配引用的条件路径；没有动态证据证明实际热重载或泄漏发生。
// 重复编号不等于整记录重置：可选字段缺键保留旧值，但ROLE数组每次重新申请。
// 第二遍正常结束在800869设返回1，清文本/资源后800891恢复EAX；打开失败为0。
// 返回1只说明走到该静态退出，不能担保每个解析字段有效或所有依赖成功。
// 本体声明EH尾保存并核字节；未对CRT异常传播、越界输入或损坏包进行实机注入。
