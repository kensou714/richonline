// 旧道具记录 P / 构造与释放
// ============================================================================
// 7FE7D0：ECX=P，无栈参数，返回P；514字节、113条指令。
// 7FE9E0：ECX=P，无栈参数；77字节、24条指令；不承诺其EAX为业务返回值。
// 两者均未检查P是否为空，不是整个1128字节对象的memset。
//
// 构造写入，字段名只在本题有直接证据处给出
// ----------------------------------------------------------------------------
// 7FE7F0先调622D50(P+A4,12,8,8052A0)，构造8个12字节内嵌槽。
// 回调从5FF6EA的E9解析；本专题没有8052A0本体，槽内部字段初值仍未知。
// +00 DWORD=-1：编号哨兵；+0C DWORD=-1：part类别哨兵。
// +10 DWORD=0：suit值初始；+14 DWORD=0：角色BYTE数组指针初始。
// +18..+1B四BYTE分别置0；+1C/+24/+2C/+34四QWORD经x87写入+0.0。
// 浮点源A2B480的8字节全零已核，不依据IDA自动dbl名称猜常数。
// +3C..+64每4字节DWORD置0；+68 DWORD=1；+6C DWORD=0。
// +70..+73四BYTE分别置0；+74..+9C每4字节DWORD置0。
// +A0 BYTE=0；+104 BYTE=0；+294 BYTE=0；+2D4 BYTE=0；+464 DWORD=0。
// +294和+2D4分别为loader传入name/desc目标首址；构造只清字符串首BYTE。
// +04、+08及多处间隙未在该本体显式写；不能宣称缺type/chType时默认为0。
// 这些局部构造写入不恢复其它属性的完整业务含义，也不承诺padding已初始化。
//
// 角色数组的内层所有权
// ----------------------------------------------------------------------------
// 7FF6EE申请N字节；7FF710将返回指针直接存P+14，N来自装载时的角色档案数。
// 7FE9FA判P+14非空，7FEA0D交operator delete[]，7FEA18再清P+14。
// 析构本体没有重置类别、编号或其它字段，也没有独立容量字段可清。
// 此处证明本路径由记录回收ROLE数组，不把所有外部指针都泛称拥有所有权。
//
// 外层数组回收，复用旧原证并再次核当前PE
// ----------------------------------------------------------------------------
// 7FEBF0的7FF09A..7FF0CF：M+00非空时调8052E0(P,flags=3)，随后清M+00。
// 不清M+04数量；管理器其它数组的释放不纳入本题新分析范围。
// 8052E0：flags&2非零时从P-4读数组cookie，按1128字节步长调用析构迭代器。
// callback=60BDA5 E9到7FE9E0；flags&1非零再delete[](P-4)。
// flags&2为零时先单条析构P，flags&1非零再operator delete(P)。
// 7FF3D5..7FF408装载端写cookie、传构造/析构回调并将分配首址+4作为数组首址。
// 因此cookie数量、M+04和P+14的ROLE容量是三个不同层次，不能混用。
// 以上为静态调用链；CRT迭代器内部异常展开、分配失败策略未在本批新增证明。
