// 91F800的locale取法
//   930960返回线程对象，读取对象+100作为locale指针，与全局A69A34比较。
//   不相同才调用92DE70更新，并把其返回值作本次locale。
//   locale+40有符号<=1选择9305C0，否则选择930660。
//   每次分类的c由movzx BYTE取得，范围0..255；分类mask固定8。
//   两辅助函数在这个范围均读取WORD[*(locale+72)+2*c]并与mask相与。
//   因此虽然930660存在多字节辅助路径，本atoi调用路径不会以大于255的c进入它。
//   也不能由函数名宣称跳过整个多字节空白序列；这里只按输入BYTE逐个推进。
//
// 9305C0 / 分类表验证包装
//   检查(unsigned)(c+1)<=256，允许c=-1及0..255；超范围先调调试报告。
//   报告返回1执行int3；继续执行时仍读取分类表，没有可靠错误返回或范围钳制。
//   EOF=-1可能使用表前一个WORD；这不是本atoi movzx BYTE参数的可达值。
//   不能将调试断言误写成拒绝所有非法输入。
//
// 930660 / 分类表及多字节回退
//   c=-1及0..255仍直接查表；其余值按高BYTE的8000h标记决定传1或2字节。
//   外部crtGetStringTypeA使用locale+4码页及+20标识；失败返回0，成功与mask相与。
//   本专题只审该辅助外层，不展开外部字符串类型API和码页实现。
//
// 930960 / 既有复核
//   复用随机数状态与取样边界专题的完整原证，不重新声称线程运行库全量完成。
//   正常路径保存并恢复GetLastError，FLS空时分配8Ch线程对象并初始化。
//   分配或FlsSetValue失败进入终止报告路径；不把它描述成总能正常返回的纯查询。
//   FLS索引、对象初始化和locale的完整所有权不由此数字转换专题证明。
//
// 92DE70 / 更新包装
//   先以参数12调用运行库lock，再调用updatetlocinfo_lk，保存返回EAX。
//   正常路径执行本函数内92DEBA清理入口，以同一参数12调用unlock并返回保存值。
//   有SEH注册及TryLevel切换；本专题没有解码异常作用域表，不承诺所有异常都已闭环。
//   内部updatetlocinfo_lk、锁表与locale更新算法未展开，保持局部契约等级。
//
// 默认常量与运行态
//   navigation.json记录A69A34磁盘四字节原值；它只是可重核的导航证据。
//   没有导出运行中locale分类表，不能把默认指针或ASCII样本当所有locale空白枚举。
//   模型使用调用方提供的256项表，C类ASCII空白仅是一组明确假设的样本。
