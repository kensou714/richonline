// ============================================================================
// 91F950 -> 91F800 / 十进制前缀转换
// ============================================================================
// 包装
//   91F950共17字节：参数原样传给跳板60C863，再到91F800；返回EAX原值。
//   本目标是32位x86，两个入口在这条路径没有int/long宽度差异。
//   伪码atoi/atol名称只是定位标签，契约依据下列指令与调用证据。
//
// 解析顺序
//   从线程locale分类表跳过开头被mask8判为空白的单字节字符。
//   读第一个非空白BYTE并保存作符号判断，只接受一个ASCII '+'或'-'。
//   符号后不再次跳过空白；只连续接受ASCII '0'..'9'，遇其他BYTE停止。
//   digit=c-30h；acc初值0，每位执行32位imul acc,10，再add digit。
//   91F8DA/91F8DD没有jo或溢出比较；负号最后执行32位neg eax。
//   可读NUL结尾输入下，无数字、仅符号、首字符无效均返回0；不能据0区分错误和合法零。
//   无endptr输出，不能询问停止位置；没有检查整个字符串必须由数字组成。
//
// 32位结果；这些是本二进制静态语义，不是可移植C/C++溢出承诺
//   "2147483647" -> 2147483647；"2147483648" -> -2147483648。
//   "4294967295" -> -1；"4294967296" -> 0。
//   "-2147483648" -> -2147483648；"-2147483649" -> 2147483647。
//   "0x10" -> 0；"12abc" -> 12；"1.5" -> 1；"+ 7" -> 0。
//   十进制前缀连续累积低32位，不饱和、不自动拒绝超长整数。
//
// 输入与错误边界
//   原函数没有空指针、字节长度、终止符可达性或数字位数检查。
//   只有符号或首字符无效也需有可读内存；不把模型的有界拒绝当原函数保护。
//   全角数字、UTF-8多字节数字、十六进制前缀均未走专门数字解码路径。
//   数字循环及atoi包装没有直接errno写入，但locale/线程依赖仍有初始化和失败路径。
//   因而不声称本调用及所有传递依赖都不影响errno或其他线程错误状态。
