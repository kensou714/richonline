// 短字符串与缓冲所有权
// ============================================================================
// 对象：当前 Richonline/RnClient.exe；地址均为32位虚拟地址。
// 目标：从高频调用和错误库名中拆出字符串对象，明确缓冲归属与拷贝前提。
// 本专题不覆盖全部std::string模板实例，不修改IDA名称、类型或游戏文件。
//
// 阅读顺序
//   01_对象布局与操作契约.txt       对象字段、赋值、内部别名与终止符。
//   02_扩容异常与误名核验.txt       分配增长、异常尾块和自动命名陷阱。
//   函数审阅清单.json              每个导出入口的分级、结论、未知与出处。
//   validate_string.py             当前PE原字节、完整块与跳板验证。
//   query_string.py                现有IDA-MCP数据库中的只读取证入口。
//
// 已证范围
//   S表示这一组窄字节字符串对象，字段偏移不是游戏角色或控件偏移。
//   S+4内含16字节联合缓冲；S+20为长度，S+24为容量。
//   容量<16时data=S+4，容量>=16时data=DWORD[S+4]。
//   62BE10先写长度，再写data[length]=0；这不是字符编码转换。
//   62B8A0释放/reset字符串，IDA的CControlBar::OnInitialUpdate自动名不可信。
//   62C850返回本实例最大长度FFFFFFFE，不是任务面板提示方法。
//
// 证据强度
//   原证包含声明的全部函数块，指令范围与块原字节重叠，不能相加算覆盖。
//   仅导出的邻近对象析构器与CRT依赖不升格为完整语义分析。
//   三处消费点仅核ECX基址、参数和构造/释放顺序，不命名完整窗口业务。
//   28字节布局由字段访问和691AB0局部对象交叉支持；S+0具体调试代理未知。
//   未做实机、异常注入、超大输入或游戏资源回写验证。
