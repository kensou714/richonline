// A200虽尾字节为零，入口只测首字节A2，因此仍进入查表并覆盖该零字节。
// 818FA0在81903A做hi差乘376，再在81904F/81906F做lo差乘4加2/3。
// 汇编未检查负差；32位加法使上述值指向对象之前，而非表内第一行。
// 反向接受21949值，5460值尾字节不在40..FE；全部仍落在后表范围，但索引别名。
