// 642740 / 精灵状态更新窗口
// ----------------------------------------------------------------------------
// 输入对象+0x10与精灵+0x10不同才复制；复制后值>0才调用640020。
// 返回写精灵+0x1E8。输入+0x14对精灵+0x14同样处理，返回写+0x1EC。
// 相等或新值<=0的路径不在本窗口重算对应缓存；不能说自动清成-1。
// 证据：reused_verified.json的6428D4/642913窗口；两条链当前PE一致。
// +0x1E8/+0x1EC是映射结果，不能与原输入编号或NP文件编号互换。
//
// 6400B0 / 图像映射适配器
// ----------------------------------------------------------------------------
// 管理对象this仅存入局部，本体不读V或R，不是查表访问器。
// 输入arg0、arg1原样传递，arg2只取BYTE并归一为0/1。
// 627760取得图像管理器后调用6DBA40(type=4,arg0,arg1,bool(arg2))，返回其DWORD。
// 既有图像映射资料将type 4对应vehicle；此返回是运行时图像槽，不是indx本身。
// BYTE参数解释了调用者setz dl后push整个EDX：高24位不参与规范化。
// 无效arg0=-1等输入没有本体拒绝；不能宣称下游槽访问安全。
