// 记号 V 是8字节管理对象，R 是76(0x4C)字节记录；名称不推定玩法。
// 627CF0在A766EC为空时分配8字节，经605EAA调用63FB70，缓存并返回V。
// 63FB70只令V+4=0；V+0尚未初始化，不能在读表前使用记录数量。
// 证据：reused_verified.json的627CF0完整块，vehpet_raw.json的63FB70。
//
// 可证布局                         生产入口及默认值
// ----------------------------------------------------------------------------
// V+0   DWORD                     ALL/max经atoi所得分配槽数N。
// V+4   DWORD                     76*N字节数组首址；不含追加计数或容量独立字段。
// R+0   DWORD                     indx。63FB20默认-1，读取器改为配置索引。
// R+4   DWORD                     type三项表匹配值；构造器未初始化。
// R+8..R+68  16个DWORD             prop0..prop15；构造器逐项设-1。
// R+72  BYTE                      smoke；仅实际处理ITEM时先设1，再按键覆盖。
// R+73..R+75                      本专题没有业务读写；不得称为默认零或保留标志。
// 63FB20也未初始化R+4/R+72；未出现的槽只保证R+0与prop数组为-1。
//
// 63FBE0的有限读取契约
// ----------------------------------------------------------------------------
// FileName加载返回0时，本体直接返回0，不写V两个字段。
// 成功路径构建文本配置对象，调用819470找ALL、819660找max、8198E0取128B文本。
// ALL/max查找返回值未在本体检查，atoi结果直接写V+0；76*N直接交分配器。
// 622D50以步长76、数量N、构造桥612155→63FB20逐项初始化新数组。
// 分配返回NULL也照样写V+4；后续ITEM写入没有空数组保护。
// 每次819470找到ITEM后读indx，直接寻址R=V+4+76*indx，不是尾部追加。
// indx负值、indx>=N、重复indx、atoi失败没有本体拒绝分支。
// prop%d只遍历0..15；找键失败保留构造默认-1，成功才atoi后写DWORD。
// type找键返回未检查；字符串交63FFB0，结果写R+4。
// smoke默认BYTE 1；键存在时只有strcmp(value,"true")==0写1，其他写0。
// 没有大小写折叠；业务描述键desc不在本体读取，不能给它编造运行时用途。
// 正常遍历结束返回1；没有检查ITEM数量是否等于N、记录是否全部有效。
// 此处只证调用参数与本体分支；通用配置游标、解包与CRT规则见已有专题。
//
// 类型表与严格边界
// ----------------------------------------------------------------------------
// A672F8的三个DWORD依次指向A22740="CAR"、A22738="MOTO"、A22734="PET"。
// 63FFB0按0..2逐项strcmp精确匹配，返回0/1/2；全部不匹配返回DWORD -1。
// 表字串由128B有界首NUL原字节恢复，再逐字节核当前PE；不是IDA完整item声明。
// ALL/max也是固定4B ASCII+NUL数据，不把off_A226FC/off_A22700自动名当指针。
