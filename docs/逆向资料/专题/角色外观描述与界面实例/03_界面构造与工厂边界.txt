// 6FC210 / 0x2FC界面实例的构造顺序

// ECX=U，无栈参数，正常出口返回原U；主块125字节，另有32字节声明EH尾。
// 本体只调用3个构造/初始化入口及RTC检查，不分配实例本身。
//
// 基类和两个不同子对象
// ----------------------------------------------------------------------------
// 6FC236经605DA6调用6E1D90(U)；旧本体写基类表址、U+04=0、U+30=0、U+38=2。
// 6FC245把U+00改写为A27600，即派生实例使用的表址。
// 本批只采A27600起4字节，槽0字面值605A72；不宣称虚表总长度、槽0完整行为或类名。
// 6FC24E将ECX=U+94h，6FC254经6118B3调用642480构造运行时子对象S。
// 6FC260将ECX=U+2B0h，6FC266经602ACF调用6423C0初始化短描述D。
// 反编译器省略的第二次this偏移必须以汇编为准，不能误以为6423C0仍使用U+94h。
//
// 旧642480的可见初值，偏移相对S
// ----------------------------------------------------------------------------
// 先以ECX=S+214h、参数30调用81BC80；后仍以该子址、参数80调用81BCB0。
// S+00 DWORD=-2；S+04,+08,+0C三个DWORD=-1；S+10..+40逐DWORD置0。
// S+210 DWORD=0。S+44到+20F未在本体直接清零，不宣称图像数组已有确定内容。
// 两个214h子址调用的内部初值和时序机制沿旧来源，本题不把函数名当字段所有权证明。
// U+94h加S+210h对应U+2A4h；两个214h调用对应U+2A8h。
// 这给出可见位置，不据“最后一个直接写点”恢复S完整sizeof或隐藏成员。
//
// 旧工厂6E93D0
// ----------------------------------------------------------------------------
// 6E9400向91BD30传申请大小2FCh，即764字节；本题只认这一工厂路径的申请量。
// 6E9417比较结果，NULL时跳6E942A选择0；非空经5FF096调用6FC210。
// 6E943E正常返回选择的结果，无栈实参；不能把工厂NULL门扩大为构造器自带NULL门。
// 91BD30下层的抛异常、重试或返回策略不在本题新增分析范围。
// U内描述的明确写区为2B0h..2ECh；余下2EDh..2FBh没有被6423C0直接初始化。
// “工厂申请764字节”与“描述写61字节”各自有证据，二者不可互换。

// 使用与验证边界
