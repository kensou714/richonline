// 6423C0 / 短外观描述D的可见字段
// ============================================================================
// ECX=D，无栈参数，177字节/41指令；无call、无分配、无NULL门、无析构。
// 6423D1..64245C分别将D+00,+04,...,+38的15个DWORD置0。
// 642466仅将D+3C的BYTE置0；64246A返回原D，642470为普通ret。
// 直接写入连续61字节，不能推出sizeof=61或64，也不证明D+3D以后padding为零。
// 尾BYTE不是第16个DWORD；不要把“整描述清零”误写成64字节memset。
//
// 两个角色caller执行同一填充形状
// ----------------------------------------------------------------------------
// 7F3C70：7F438B取栈EBP-6C地址，7F438E初始化；7F4424消费。
// 7F4550：7F45D1取栈EBP-48地址，7F45D4初始化；7F466A消费。
// 两处均不使用初始化返回的EAX作后续地址，直接使用既定栈地址。
// 第二caller仅在外部参数a2非零的分支执行；不能据局部窗口宣称函数总会更新外观。
// 两者调用时ECX=A，即原角色对象；getter返回EAX写对应DWORD，最后AL写尾BYTE。
//
// D偏移  生产函数   已核实际来源                         两caller写点
// ----------------------------------------------------------------------------
// +00    691B70     DWORD[A+28h]，不掩码                 7F439B / 7F45E1
// +0C    63F170     DWORD[A+5B4h]，不掩码                7F43A6 / 7F45EC
// +10    7D7A00     DWORD[A+90h] & 0FFFh                7F43B1 / 7F45F7
// +14    7D7A30     DWORD[A+94h] & 0FFFh                7F43BC / 7F4602
// +1C    7D7AC0     DWORD[A+A4h] & 0FFFh                7F43C7 / 7F460D
// +24    728390     DWORD[A+ACh] & 0FFFh                7F43D2 / 7F4618
// +28    7283C0     DWORD[A+B0h] & 0FFFh                7F43DD / 7F4623
// +2C    7283F0     DWORD[A+B4h] & 0FFFh                7F43E8 / 7F462E
// +30    728420     DWORD[A+B8h] & 0FFFh                7F43F3 / 7F4639
// +34    728450     DWORD[A+BCh] & 0FFFh                7F43FE / 7F4644
// +38    7D7B20     DWORD[A+C0h] & 0FFFh                7F4409 / 7F464F
// +3C    7FD7A0     BYTE[A+588h]原样进入AL              7F4414 / 7F465A
// 未覆盖的D+04,+08,+18,+20保持初始化的DWORD零。
// 尾BYTE未规约为0/1；不能把任意非零原值在文档中替换为bool转换结果。

//
// 描述消费与缓存更新的有限边界
// ----------------------------------------------------------------------------
// 两caller均push D，并将ECX=A+360h交6007CF E9到642740；不是以ECX=D调用。
// 旧642740原证显示逐字段读取D，D+3C只作BYTE比较；不是将D解释为1128字节记录。
// 它先比较运行对象+00与D+00、运行对象+2C与D+24；任一不同才进入主图像重建分支。
// D+3C影响该分支内部角色/资源选择，但仅改变尾BYTE并不独立触发此入口条件。
// 随后其它槽有各自变化与正数门；描述字段全部置零不等价于强制清空所有缓存。
// 该旧consumer本题只承接输入和更新门，未重新认领全部资源后端或最终显示正确性。
