// 帧入口
// ----------------------------------------------------------------------------
// 811520 = BeginScene，返回HRESULT>=0的布尔值；629B40把结果保存对象+5。
// 811560 = EndScene，保留HRESULT；811590 = Present(NULL,NULL,NULL,NULL)。
// 8114D0(color,flags)在818BB0允许时Clear(0,NULL,flags,color,1.0f,0)。
// 因而第二参数是D3DCLEAR标志，不是颜色；1.0f是清除深度值。
// 不代表项目所有帧都严格按此顺序调用；整条应用主循环仍需另外枚举调用者。
//
// 低帧率门控
// ----------------------------------------------------------------------------
// 8117D0每调用计数加1；距离上次采样>=1000ms时更新ABA7BC为计数并清零。
// 当ABA7BC<30且距ABA7C0<1000ms时，byte_ABA7C4=0；
// 否则置1并更新时间ABA7C0。818BB0只返回这个byte。
// 8114D0清屏和813E70图像绘制都检查该门，不只是显示FPS数字。
// 在调用节奏符合帧循环时，它会在低帧率下显著抑制这些操作；具体屏幕表现未实测。
// 采样值是1秒窗口内调用次数，不是按真实间隔归一化的精确FPS。
//
// 基础渲染状态811A00
// ----------------------------------------------------------------------------
// ALPHABLENDENABLE=true；SRCBLEND=SRCALPHA；DESTBLEND=INVSRCALPHA。
// caps.AlphaCmpCaps含GREATEREQUAL(0x40)时：
//   ALPHATESTENABLE=true，ALPHAREF=4，ALPHAFUNC=GREATEREQUAL(7)。
// Sampler0的ADDRESSU、ADDRESSV均=CLAMP(3)。
// +276是SetSamplerState，不是纹理过滤器；这两条并未设置LINEAR过滤。
// 813E70遇对象+174完全不透明标志时临时关混合/alpha测试，绘制后再恢复；
// 故mode1部分alpha没有清此标志的分支差异可能影响实际透明表现，需运行时核验。
//
// 图像资源池和顶点结构
// ----------------------------------------------------------------------------
// 811BA0(CreateTexture)参数：Levels=1、Usage=0、Pool=MANAGED(1)。
// format21=A8R8G8B8；format26=A4R4G4B4，SDK枚举已核对。
// 对象+0是IDirect3DVertexBuffer9*，+4是IDirect3DIndexBuffer9*，
// +8数组元素是IDirect3DTexture9*；0xB0对象本身并不是COM对象。
// VertexBuffer长度112、Usage=WRITEONLY(8)、FVF=324(0x144)、Pool=MANAGED。
// IndexBuffer长度12、Usage=WRITEONLY、Format=INDEX16(101)、Pool=MANAGED。
// FVF0x144=XYZRHW(4)|DIFFUSE(0x40)|TEX1(0x100)，结合第二批写者证明：
//   顶点步长28：float x,y,z,rhw；DWORD diffuse；float u,v。
// +8/+12由FVF确认是z/rhw槽，但初始化具体取值仍需继续读写者，不凭默认值补齐。
// 索引为0,1,2,1,3,2，组成两个三角形；不是四边形专用D3D图元类型。
//
// 绘制813E70
// ----------------------------------------------------------------------------
// SetTexture(0,currentFrameTexture) -> SetFVF(324) ->
// SetStreamSource(0,vertexBuffer,0,28) -> SetIndices(indexBuffer) ->
// DrawIndexedPrimitive(TRIANGLELIST,0,0,4,0,2)。
// callback[0]在绘制前调用、callback[1]在绘制后调用；没有恢复回调可能修改的全部状态。
// 当前图像帧从对象+148选取，动画时长规则见01篇。
//
// 辅助资源与裁剪矩形
// ----------------------------------------------------------------------------
// 8147E0以全零创建参数建立ABA790辅助图像，再创建参数20/40的ABA794对象。
// 这两个对象最终由814870释放；ABA794的完整类用途仍未恢复。
// 813290与814C80的接口虚表+36实际是IDirect3DResource9::PreLoad，
// 不是Reset或Release；不能因它出现在Reset后就命名为资源重建。
// 8118B0保存两组4-float矩形；691B90选择ABA798，691BB0选择ABA7A8。
// 这是两个固定裁剪范围的选择器，本批没有发现或证明任意深度push/pop栈。
// 698D10初始化第一组为客户区，第二组为(7,30,622,568)。
//
// 开发约束
// ----------------------------------------------------------------------------
// 内容编辑器可据FVF和资源池做忠实预览；客户端补丁须保留顶点/UV/颜色的独立缓存。
// 新增D3DCREATE_MULTITHREADED只保护D3D内部调用，不替代CPU顶点缓存、临时数组、
// 动画状态或资源映射表的同步。Reset必须回到创建设备线程。
// 当前未执行设备丢失、窗口全屏切换、多线程压测或低帧率实机验收。
