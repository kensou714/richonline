// 新版只是每次创建都加4，不改变重试顺序、适配器号、设备类型或呈现参数。
//
// 811100 设备初始化
// ----------------------------------------------------------------------------
// Direct3DCreate9(31) -> 全局ABA788(IDirect3D9*)。
// 虚表+32 GetAdapterDisplayMode(0)，+56 GetDeviceCaps(0,HAL)，
// +36 CheckDeviceType，+64 CreateDevice。此映射由官方SDK接口声明顺序确认，
// 不是依赖IDA给COM虚调用猜的函数名。
// caps首DWORD&1用于门槛，首DWORD其实是DeviceType字段，不应称作“支持D3D9能力位”。
// CreateDevice设备类型=HAL(1)、Adapter=0；返回设备写ABA78C。
//
// 输入配置5个DWORD：
// +0 HWND；+4宽；+8高；+12色深选择(0/16/32)；+16 Windowed。
// 56字节D3DPRESENT_PARAMETERS被清零：
// BackBufferWidth/Height来自宽高；SwapEffect=DISCARD(1)；
// hDeviceWindow=HWND；Windowed来自+16；BackBufferCount/多采样/自动深度均维持0。
// 窗口模式取当前显示Format；全屏色深16->R5G6B5(23)，32->X8R8G8B8(22)，
// 色深0取当前显示Format；全屏刷新率来自GetAdapterDisplayMode的RefreshRate。
// 若caps.PresentationIntervals最高位存在，则Interval=IMMEDIATE(0x80000000)；
// 否则保留0(DEFAULT)。这里的判断源是caps字段，非文件配置中的独立帧率值。
// 成功后重新读设备显示模式/caps，关LIGHTING(137)，设基础渲染状态，再建辅助对象。
// Direct3DCreate9失败、设备类型检测失败或三种CreateDevice均失败分别弹消息并返回0。
//
// 线程标志的真实保证与限制
// ----------------------------------------------------------------------------
// Microsoft定义：MULTITHREADED让Direct3D内部更频繁持有全局临界区，可能降低性能。
// 它适用于窗口消息线程与D3D调用线程分开的程序，不等于项目所有资源表/FILE*线程安全。
// 官方Reset规则仍要求在创建设备的同一线程调用；新增4不能取消这个线程约束。
// 不能用三字节变化证明“已有线程故障全部修复”。当前只恢复标志含义，未运行并发验收。
// 图像管理器的共享全局路径/组号以及渲染的临时顶点数组仍需各自同步和生命周期检查。
//
// Reset 与上层恢复
// ----------------------------------------------------------------------------
// 8115C0(config,checkLost)：
// checkLost非零时，TestCooperativeLevel必须恰为D3DERR_DEVICENOTRESET
// (0x88760869，十进制-2005530519)，否则立即返回0。
// checkLost为0则跳过此门槛。重新构造56字节参数并调用Reset(+64)，非零返回0。
// 窗口重置分支无条件设置IMMEDIATE，和创建时“检查caps后设置”存在区别。
// 成功后重新设LIGHTING/混合等状态，并对ABA790/ABA794辅助资源调用PreLoad路径。
// 该函数不是全资源重建循环；调用链是否还有其它恢复动作应继续沿上层审阅。
//
// 6997C0先尝试checkLost=1，失败再填屏幕尺寸用checkLost=0尝试一次。
// 当前局部v8初始化为0，两个尝试都失败便返回0，没有可靠的无限重试保证。
// 699910则反复以checkLost=0重置，失败Sleep(100)，直到成功；本函数无退出上限。
// 698F50调用Present，只要返回值非0即置对象+6=1，未区分各HRESULT。
// 这些是实际控制流，不能把“返回1”一概理解为某个Direct3D API成功HRESULT。
//
// 生命周期
// ----------------------------------------------------------------------------
// 811460先销毁ABA790/ABA794辅助资源，再Release设备ABA78C和Direct3D对象ABA788并置空。
// 8117A0返回设备；8117C0返回显示模式地址。这两个getter本身不延长COM生命周期。
// 不应把取出的裸接口跨设备销毁长期缓存。
