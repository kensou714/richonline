// 日期业务分派、模式标志门与显示
// ============================================================================
// 7D89D0 的 this 是 C 日期状态；另外三个参数是 G、转发参数、输出指针候选。
// 本体读取 C+8/+10/+11，调用单例 7D8DE0，写 DWORD[C+10h]=索引。
// 无匹配时写入 -1 后返回一；C+10h 是十六进制偏移，与月 BYTE 的 +10 十进制不同。
// 命中后 6037AE -> 63E210 从 G 取 G+65Ch 的模式对象，再调用 7D8EB0。
// 门控低 BYTE 为零时直接返回一；命中且通过才进入 13 槽分派。
//
// 7D8EB0 模式门的优先级
// ----------------------------------------------------------------------------
// P0 = 602DBD -> 63ECA0(mode_object);
// 若 P0 低 BYTE 非零：返回 table[326h + slot]，不计算 P1。
// 否则 P1 = 606797 -> 63EDF0(mode_object);
// 若 P1 低 BYTE 非零：返回 table[333h + slot]；否则返回零。
// 组 A 全允许；组 B 槽 7、10 禁用；P0/P1 都真时仍使用组 A。
// 7D8EB0 没有 slot 范围比较；当前真实调用者的索引由 7D8DE0 产生在 0..12 内。
// 63ECA0 是 63ED10 或 63ED50 的低 BYTE 非零组合；63EDF0 是 63EE90、63EED0、
// 63E160、63E990 的低 BYTE 非零组合。上述组合原证已复用；更深模式语义未全审。
// 不用反编译器自动套用的 MFC/ATL 名称给模式命名。
//
// 13 槽分派导航
// ----------------------------------------------------------------------------
// 槽   表中 case 入口   调用跳板    真实业务入口
// 0    7D8A64           600586      7BC6D0
// 1    7D8AA3           603F1F      7BD060
// 2    7D8AB8           60538D      7BD140
// 3    7D8ACD           60BFD5      7BD220
// 4    7D8AE2           609CD5      7BD300
// 5    7D8B4E           60A3F1      7BE080
// 6    7D8A79           6001E4      7BC9B0
// 7    7D8A8E           60C3A4      7BCD90
// 8    7D8AF4           60838A      7BD3E0
// 9    7D8B06           60B107      7BD6C0
// 10   7D8B18           612452      7BD7A0
// 11   7D8B2A           605A86      7BDA70
// 12   7D8B3C           600419      7BDD50
// 真实表为 7D8B75 起 52 字节；这是独立数据原证，不强行并入函数声明块。
// 各 case 以 G 为 ECX，转发后两个参数，并原样返回业务函数 EAX。
// 索引 unsigned 大于 12 的默认分支返回一；负索引 -1 已在前门返回。
// 本批没有展开这 13 个业务本体，不能声称奖励、现金、动画或通信已经闭合。
//
// 实际调用者的返回消费
// ----------------------------------------------------------------------------
// 7C0C50 的 7C19AD..7C19E9 局部：603CCC 低 BYTE 非零且 607098 低 BYTE 为零，
// 才以 C=G+0C44h 调 609B90 -> 7D89D0。G、调用者 arg0、局部 var_24 地址为三参数。
// 返回非零继续 7C19EE；返回零跳到 7C2DE1。后者目标语义没有在本局部展开。
// 因此 7D89D0 的“返回一”在此是继续路径；“返回零”不是可直接认定的通信失败。
// 未追两个前门本体，也未证明每次 4052 同步都会立即触发此调用点。
//
// 7080D0 的日期图像消费
// ----------------------------------------------------------------------------
// 先从 G 经 63E590 得 C，再以表单例调用 7D8E60。
// AL 非零将图集基号由 5 改为 65；此门不读取两组模式标志。
// 月、日各用 "%02d" 格式化，只取前两个字符减 '0'，加基号选资源组 10 图像。
// 图像写入控件 81/82（月）、83/84（日）；85/86 使用 G+83804 的另一数值。
// 即使业务被模式组 B 拒绝，UI仍可能采用特殊日期图集，这来自门控路径差异。
// 负值或超过两位值的显示风险沿用 4050 专题；这里不补造缓冲容量或实机截图。
