// 从通用游标到真实包构造 / 按汇编恢复完整DWORD
// ============================================================================
// 所有字段为小端；以下是本轮静态确认的内存组包结果，不冒充加密后线上抓包。
//
// 大厅方向的12字节头
//   867CD0(payloadSize) -> 自有缓冲capacity=payloadSize+12。
//   +00 DWORD  10A1D85Fh。867D29的push立即数是完整32位，绝不是95。
//   +04 DWORD  107。867D27先压入，随后连续两次thiscall逐次消费各栈DWORD。
//   +08 DWORD  capacity-4，即payloadSize+8；不是总分配长，也不是仅正文长。
//   867DB0把capacity完整放到EAX，867D45执行32位sub eax,4后传给868590。
//   伪码中的char v3与Src95同属类型污染，不能截断长度到8位。
//
// 同一头模板的代表类型
//   869B60：type16；868FB0传payloadSize=4，再写一个DWORD。
//   869C40：type18；869170传16，再写[0,1,参数,1]四DWORD。
//   86C520：type48；86BE60传12，再写三个DWORD。
//   86C440：type56；86C260传16，再写[1,参数,参数,1]四DWORD。
//   正文参数伪码虽显示char，这些代表调用处按DWORD栈槽入栈再由868530复制。
//
// 游戏8字节头
//   87CA90(payloadSize) -> capacity=payloadSize+8。
//   +00 DWORD  299。87CAF0是push 12Bh，不能沿用伪码Src43。
//   +04 DWORD  capacity，即总帧长。第二个DWORD由原capacity值写入。
//   87BE40在此头后直接追加Src、Size字节。
//   87BC60先读类型DWORD；type1走虚表+4。其他类型再消费一个DWORD，
//   type299将当前读地址及w-r长度交虚表+8。这不等同游戏内0x4000操作码。
//
// 实际网络桥接
//   87B080(a1=缓冲对象)从传入对象取base+r和w-r，然后在87B0B8把ECX加4，
//   交内嵌socket写对象87B1E0。87B1E0的this是外层87B080 this+4。
//   87B1E0使用其this+8的socket及this+4的flags，折合外层+0Ch与+08h；
//   socket对象不是传入缓冲对象，不能把这三种this混为一个结构。
//   87CCB0构造收帧组件，缓冲内嵌this+8，容量1MiB，初始limit=8，阶段this+2C=0。
//   87C660分阶段填充，87C8B0取头+4总长，限制0<长度<=1MiB，再设置limit。
//   87C8F0只确认长度<=1MiB；不是魔数、签名、类型或payload结构校验。
//   完帧后87CF10/87D3F0先复制，再867570推进目标写位置，仍是后置检查。
//   该链与既有网络专题04交叉一致；本轮不扩展为全部网络业务已恢复。
//
// 字符串与多字段调用者
//   87E430正文144字节：三个DWORD、64字节字符串区、64字节字符串区、末DWORD。
//   87E7D0正文136字节：两个DWORD与两个64字节字符串区。
//   字符串使用871940，64是预留区宽度，不表示它会把任意输入安全裁到63字符。
//   88AB00/88ACC0调用读DWORD族、8929B0读double，再借用当前读地址为字符串，
//   分别推进32与128。这些调用证明多宽度组合，不证明字符串在区内一定有NUL。
//   87F4D0把源对象的w-r字节复制到目标，不推进源r；属于复制而非取走所有权。
//   8B9F50在派生头之后写五个参数DWORD、Size DWORD、0 DWORD，再复制Size字节；
//   本轮仅核验写入顺序，不为该业务包补造未证实的正式消息名。
//
// 合成样本 / validate_cursor.py
//   正文44 33 22 11，对应DWORD 11223344h。
//   大厅type107：5F D8 A1 10 6B 00 00 00 0C 00 00 00 44 33 22 11。
//   游戏type299：2B 01 00 00 0C 00 00 00 44 33 22 11。
//   样本明确区分长度字段口径；没有运行客户端、发送网络包或复用真实账户数据。
