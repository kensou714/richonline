// ============================================================================
// 原始宽度、端序与检查顺序
// ============================================================================
// 本客户端为32位x86；直接复制整数/浮点内存表示，未见字节反转或hton转换。
// 因此本机实现输出小端字节。这个结论不是跨CPU可移植性承诺。
//
// 写接口
//   867470(Src,len)：比较limit-w与len -> assert -> memcpy(base+w,Src,len)
//                     -> 867570(len)推进w -> 返回this。
//   868530 / 868590 / 8795F0：把[ebp+8]栈参数地址作为Src，固定len=4。
//   879650 / 87D000：把[ebp+8]起连续两个栈参数槽作为Src，固定len=8。
//   8719C0：strlen(Str)+1字节，包含NUL；长度计算依赖输入字符串有效终止。
//   当前867470的已发现15个直接调用者中，固定标量封装只见4/8字节。
//   这不等于证明整个EXE不存在1/2字节写接口；不能虚构缺失宽度的地址。
//
// char伪签名不能用于协议布局
//   868553 push 4；868555 lea eax,[ebp+Src]；86855C调用原始写；返回retn 4。
//   87D023 push 8；87D025取同一参数地址；返回retn 8。
//   虽然Hex-Rays显示char Src，两者实际处理4或8字节。符号性/枚举/浮点含义
//   必须回到调用者传值确认。879650在871720调用者接收x87存储的8字节浮点表示。
//   同样是4字节复制，也不能把868530与868590直接命名为已证明的int/unsigned重载。
//
// 读接口
//   87D060 / 87D380 / 892E60：base+r处读DWORD，再调用87D0D0(4)，返回原值。
//   893170：读WORD，再推进2；返回AX，本函数不决定调用者是否符号扩展。
//   8931E0：读取两个DWORD形成64位结果，再推进8，EDX:EAX返回。
//   8929B0：fld qword ptr读取double，再推进8，最终由x87返回。
//   上述解引用均发生在87D0D0边界检查之前；检查失败可能发生在实际读取之后。
//   不能把抛出BufferUnderflowException称作“读取前的完整内存保护”。
//   裸读地址87B140不检查范围；调用者自行读取字符串/结构时需另外证明容量。
//
// 相对推进
//   867570：若signed(limit-w)<delta，抛BufferOverflowException；否则返回旧w，w+=delta。
//   87D0D0：若signed(w-r)<delta，抛BufferUnderflowException；否则返回旧r，r+=delta。
//   两者均没有delta>=0检查，也没有加法溢出检查。负delta可能通过并回退位置。
//   负len进入memcpy时按size_t解释，不能把有符号剩余量比较当成长度合法性验证。
//
// 断言不是不可返回的安全门
//   867470的premaining() >= (int)len来自binarypackbuffer.h第25行断言。
//   实际_assert=9234A0：消息框返回5时923A89跳到923A90收尾，923A9D retn。
//   返回4时int3后也有收尾路径；某些输出模式走abort，但不是所有分支都终止。
//   因而其__noreturn伪签名也不可靠。用户忽略后memcpy仍可继续，后置867570
//   的异常不会撤回已经发生的复制。这里记录静态顺序，不宣称已实测可利用漏洞。
//
// 定长字符串871940(Str,width)
//   先8719C0复制strlen+1，再867570(width-strlen-1)。无截断、无补零循环。
//   短字符串：跳过剩余空间；那些字节保留底层原值，不保证是0。
//   长字符串：先完整写出，再以负delta回退；例如旧w=100、长度含NUL=8、width=4，
//   已写到107，却把最终w退回104。后续字段可覆盖已写字符串尾部。
//   若第一步就超过总limit，仍遵循assert/memcpy/推进的上述次序。
//   离线编辑工具应显式检查strlen+1<=width并初始化填充；这属于更严格的新实现要求。
