// PlusPrize 双消费与静态缓存
// ============================================================================
// 一、两个独立首次缓存
// ----------------------------------------------------------------------------
// 7D02B0：A8CE88的bit0缓存enable到A8CE84；bit1缓存card到A8CE80。
// 7D03C0：A8CE94的bit0缓存enable到A8CE90；bit1缓存bout到A8CE8C。
// 两条函数都在判断enable前完成两项缓存，后续调用直接使用缓存而不重新读单例。
// 两个enable缓存可在不同时间生成；后续重载配置不能使已置位缓存自动同步。
// 这是进程静态存储的once位，不是每局必然刷新；外部重置现场本批尚未证明。
// 7D02B0的A15114/A15122、7D03C0的A1513A/A15148异常尾块清对应初始化位。
// 可确认声明尾块字节和清位指令；没有因此宣称线程安全或实机异常行为。
//
// 二、7D02B0的card累计
// ----------------------------------------------------------------------------
// enable为零：7D035D直接进入尾声，不写累计槽，没有fld产生有效浮点返回。
// enable非零：7D0363经602890取得道具单例627C20，7D036A经611F84调用727E00。
// 727E00从道具对象首DWORD指向的记录区取[base+1128*arg1+28]的8字节double。
// 这不是PlusPrize字段；arg1是记录索引参数，函数本体没有索引范围检查。
// 7D036F fstp把ST0转换为float局部并弹出；7D0372 fild把有符号card转浮点。
// card也经fstp保存float；7D037B fld读道具float，fmul倍率，再fstp保留float积。
// 7D038D fadd this+5BCh+4*arg0的float，7D039A fstp把结果写回该槽。
// 由此确认：槽 += float(float(道具double) * float(card))，中间均有单精度舍入。
// 调用后没有显式ST0返回，retn8弹两栈参数；应按副作用函数解释，不按double API。
// 反编译的a2@st1和double result不受指令支持，不能从残留x87栈推导业务入参。
// arg0槽索引、arg1道具索引没有本地边界检查；外部保证未在本专题证明。
//
// 三、7D03C0的bout归一与汇总
// ----------------------------------------------------------------------------
// enable为零或7D047B状态检测非零，走7D0487装载零浮点并返回；不清this+5FC旧值。
// 状态检测使用this+65Ch的691A70；它再调用依赖，具体状态业务含义不可由自动名推出。
// 7D049B经606710调用7D6550(this+C44h)，后者直接返回子对象首DWORD。
// 因此n来自父对象+C44h；消费按有符号整数与缓存bout比较，生产者与计量单位未证。
// n>=bout时倍率为1；n<bout时单精度保存n/bout，没有下界钳制或本地正值验证。
// 原包bout=100下，非负n得到通常的0..1倍率；本体不保证n非负。
// bout=0并非必然除零：n>=0走倍率1；只有n<0进入除以0的分支。
// 7D04D2先把this+5FCh清零，遍历i<this+E20h的有符号数量，未钳制本地数组容量。
// 7D0503返回BYTE非零且7D0516返回BYTE为零才纳入该槽。
// 第一检查64EFA0读this+E38h+i；第二检查7D7ED0读this+E48h+i。
// 两个访问器都不检查索引；它们仅证明纳入谓词，不能据此命名BYTE的业务状态。
// 合格槽贡献：float(倍率 * this[59Ch+4*i]) + this[5BCh+4*i]，累计到this+5FCh。
// 7D0562 fld最终float返回；与7D02B0的无浮点返回尾声不同。
// card累计槽会被这里作为加项使用；这闭合两条链的共享+5BCh区域而不定义奖励单位。
// 循环数组、角色槽容量和状态来源要另行核证，本体没有据此给出玩家数量上限。
//
// 四、未证与扩展
// ----------------------------------------------------------------------------
