// 628D34只申请16字节，没有构造或字段清零；A76708磁盘为零不是堆内容初始化。

// 文件打开失败返回0且不写对象；首次失败没有默认值合同，重载失败可保留旧值。

// 四个EH清位指令已核；线程安全、外部缓存重置和实机异常结果没有证据。

// 三、x87和对象域复核
// ----------------------------------------------------------------------------
// 727E00来自道具单例627C20，其[base+1128*index+28]为8字节double，不属PlusPrize。
// 7D036F将其ST0弹出到float，card经有符号fild再fstp舍入到float。
// 之后乘法、加+5BCh槽及最终写回均核其单精度保存位置。
// 7D02B0正常路径最后为fstp并retn8；没有承诺ST0浮点返回，a2@st1伪类型不采信。
// 7D03C0读取+C44h首DWORD作有符号n，n<bout才计算float(n)/float(bout)。
// bout=0且n>=0走倍率1；n<0才进入除零路径，不能写成“bout为0总是除零”。
// 纳入谓词为this+E38h+i非零且this+E48h+i为零，两访问器都没有索引检查。
// 正常汇总清+5FCh，依次保存乘积、+5BCh加项和总值，最终fld +5FCh返回。
// 早返回装载磁盘零常量，不清旧+5FCh；不能承诺任何调用都会刷新累计槽。
// avatar消费者、状态BYTE含义、槽容量、索引生产与量值业务单位保留未知。
