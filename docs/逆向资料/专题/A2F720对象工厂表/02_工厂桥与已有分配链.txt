// ============================================================================
// A2F730 到 A2F050 的静态链
// ============================================================================
// A2F730 所在候选片段从 off_A2F72C 起，不属于 off_A2F720 的已证范围。
//
// 静态链逐段
// ----------------------------------------------------------------------------
// A2F730：当前磁盘 DWORD = 60ECC6，IDA 数据 xref 指向该入口。
// 60ECC6：五字节 E9 rel32 = e9 25 67 24 00，目标精确为 8553F0。
// 8553F0：既有 82BBE0 专题完整导出；先申请 D0h 字节，非空路径经
//         609DC0 的 E9 桥调用 82CAD0，然后返回构造所得指针。
// 82CAD0：既有专题完整导出；82CB20 把 A2F050 写入对象首 DWORD，
//         随后调用 this+84h、this+B4h 两处子对象初始化入口。
// A2F050：既有专题核过的 16 DWORD 表窗口，其第 3 项经 609A05 指向
//         未声明的 82D820 函数形代码；此处不重新提升其函数身份。
//
// 这条链的含义
// ----------------------------------------------------------------------------
// 已证的是“A2F72C 相邻表中的一个静态入口地址指向分配函数，分配函数有
// 到 82CAD0 的非空构造路径，构造函数写入 A2F050”。它可作为后续寻找
// 工厂调用现场的定位线索。表项存在、E9 桥正确和构造路径存在，均不证明
// 客户端在某局实际执行了该间接调用，也不证明返回对象由哪个系统持有。
// A2F720 的写表者 856090 与此链之间没有经本次原证证明的直接调用边。
//
// 后续可验证点
// ----------------------------------------------------------------------------
// 追踪读取 [对象+0] 后以 +4 偏移调用的现场，核对象来源是否为 856180；
// 核 8553F0 返回对象的存放、销毁和异常路径；再为各表项建立槽位语义。
// 在上述证据齐备前，不给 A2F730 命名具体虚方法或业务对象类名。
