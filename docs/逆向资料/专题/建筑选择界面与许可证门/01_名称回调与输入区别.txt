// ----------------------------------------------------------------------------
// ECX=界面U，一个显式对象参数S；完整144字节，无异常尾块。

// 8E1570旧契约与失败值
// ----------------------------------------------------------------------------
// 参数k与DWORD[DWORD(ACC3C8)+5160]作有符号上界比较，再检查S+1A4的数组指针。
