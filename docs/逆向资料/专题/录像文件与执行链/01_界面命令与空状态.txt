//
// 初始化：0x7045A0，仅核验其中的录像相关分支。
// ----------------------------------------------------------------------------
// 主状态 2：登记控件 150、151，文字分别为 1008“開始錄像”、1009“結束錄像”。
// 主状态 13：登记控件 160、161，文字分别为 1010“暫停播放”、1011“繼續播放”。
// 初始化后段 0x705186 附近又以参数 0 调用控件 150 的虚表 +200，即隐藏控件。
// 这说明控件注册、文字装配、可见性三者必须分别判断。
//
// 快捷键：0x705C70。
// ----------------------------------------------------------------------------
// 0x62A0F0 读取全局主状态 A6723C；0x691C60 检查虚拟键 122，即 F11。
// 状态 2 选择 150/151，状态 13 选择 160/161，选择依据包含当前控件可见性。
// 最终调用 UI0 对象的虚表 +120，参数为控件指针和 0。
// 当前虚表 A242D0 的 +120 为 0x60BD37；E9 跳至 0x7061F0。
// 控件回调桥 0x6EEA90 也取得 UI0 并调用同一虚表槽，避免只追键盘入口。
//
// 命令处理：0x7061F0，核验控制编号与默认路径。
// ----------------------------------------------------------------------------
// 高号 switch 覆盖 90..202，0x706E82 为索引表，0x7062B0 为间接跳转。
// 从磁盘 PE 独立重读索引及跳表得到：
//
//     控件编号      索引字节      最终目标
//     150           5             0x706C80
//     151           5             0x706C80
//     160           5             0x706C80
//     161           5             0x706C80
//
// 0x706C80 是该 switch 的默认落点。后段额外判断 101..116、210..213，
// 也不包含上述四个编号；正常返回 1，未进入开始、结束、暂停或继续实现。
// 结论：仅修改隐藏标志，不能修复这条入口的录像功能。
// 203 是前置单独分支，不属于 90..202 表域，不可按同样公式越界取表。
// 原证：controls_and_queue_navigation.json、control_data_navigation.json、
//       state_and_switch_data.json、binary_tables.json。
//
// 主状态表：0x624CA0 内的 0x624D93 间接调用。
// ----------------------------------------------------------------------------
// A6723C 是状态值，0x629DC0 负责直接赋值，0x62A0F0 负责读取。
// 索引 12 -> 0x603AA1 -> 0x6258F0：函数完整指令为建立栈帧、eax=1、返回。
// 索引 13 -> 0x609A55 -> 0x625900：同样仅 return 1。
// 索引 14 -> 0x607499 -> 0x625910：有实际的清理、状态归零与界面切换。
// 对 14 仅确认上述局部动作，未把全部子调用解释成录像结束器。
//
// 取证保存了表附近 64 字节，不据此宣称表有 16 项。
// 第 15 个 DWORD 已落到相邻 A6723C 的初值 5，不能继续当函数指针解析。
// 原证：replay_state_stubs.json、state_queue_references.json、binary_tables.json。
//
// UI104 与 UI116：列表存在不等于播放链存在。
// ----------------------------------------------------------------------------
// 0x751BD0 初始化列表、排序和分页；已有专题核验其先清空向量，空表仍为一页。
// 0x7526F0 每帧检查并隐藏控件 4、400。
// 0x752A00 的命令 4 保留显示录像面板的代码；410..520 的行命令打开 UI116。
// 0x761D50 只在 a3==1 时继续，只处理命令 2 -> UI117、3 -> UI118。
// 它没有编号 1 的播放分支；其他编号收尾返回。
// 因此重命名/删除功能不能作为已存在 RCD 解码器的证据。
//
// 局限：未运行客户端，没有通过内存强改状态或控件验证动态可达性。
// 本节所说的空路径来自当前版本机器码，不外推所有版本或所有潜在入口。
