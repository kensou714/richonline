// ============================================================================
// 启动参数与游戏记录队列 / 不把运行时事件误认为磁盘帧
// ============================================================================
//
// 启动参数：0x7A3D90 -> 0x622E20 -> 0x623030。
// ----------------------------------------------------------------------------
// 0x7A3BB0 从 Tex/ToolConfig.kpd 读取 pack 条目，接受 true/TRUE。
// WinMain 检查非空命令行；pack 分支逐字符检查 r、u、n、_ 前缀。
// 命中时跳过前四个字符，否则该分支会尝试启动 RichTool 并退出。
// run_ 由四次字符比较形成，不要求二进制中存在连续的“run_”字符串。
//
// 0x622E20 以空格分隔首个参数；第二个参数经 atoi 保存为整数选择项，
// 并把 A766A4 置为 1。首个参数交给 0x623030。
// 0x623030 加载 KPD，读取 [AREA] 的 num 以及 AREA%d 下的 name、pingip、
// login、server、black、intro 等字段，形成每项 3452 字节的区域配置。
// 这是服务器区域选择链，不是已确认的 RCD 文件名解析链。
// 该分词也不能视为完整的带引号 Windows 命令行解析器。
//
// 0x625310 的加载后分支根据 A766A4 选择 UI66 或 UI65，前者关联区域地址。
// 0x627020/0x627050/0x627060 是相关选择值与小型单例辅助。
// 本次未确认 --replay 或独立 RCD 参数；不把字符串检索阴性当作全局证明。
// 原证：startup_and_navigation.json、io_and_parser_navigation.json、
//       controls_and_flow_navigation.json、file_path_constants.json。
//
// 当前事件来源：接收包装与本地插入。
// ----------------------------------------------------------------------------
// 0x6BEE80 在数据处理成功后，把 A82610 缓冲与 A82ADC 长度交给 0x64F870，
// 随后更新 GetTickCount 时间。这里核验的是回调至队列的局部链。
// 0x64F870 按首个 16 位事件码分流；部分事件直接处理，默认路径才入队。
// 因此“所有收到的数据都会完整进入游戏记录队列”并不成立。
// 0x7CF630 也是该包装函数的调用者，说明调用关系不能单凭函数名一律当网络。
//
// 默认入队：0x64F870 -> 0x5FF1B3 -> 0x698050。
// 本地插入：0x64FA50 -> 0x60DB87 -> 0x6980F0。
// 两个底层容器函数复制固定 288 字节；后者还会移动队内记录并修正插入位置。
// IDA 对这两个函数给出 local variable allocation failed，伪码的巨大参数表
// 是反编译边界，不应直接照抄为 C++ 接口。本节按汇编中的复制长度与偏移核验。
//
// 消费：0x7BB290。
// ----------------------------------------------------------------------------
// 主游戏对象 G+0x640 持有队列；入口先检查处理门控、队空及等待条件。
// 0x7D8010 从队首复制一条 288 字节记录，递增队首并减少计数。
// 消费工作区为 A87B88；随后按事件码分派游戏事件。
// 0x7D7F20 是队空相关辅助，0x64FB70 是等待条件辅助。
// 完整门控字段与本地事件分类以“基础对象与分派”及各事件专题为准。
// 本专题没有重新宣称 0x7BB290 的全部事件分支都已分析。
//
// 为什么不能直接保存 288 字节作为 RCD 帧
// ----------------------------------------------------------------------------
// 288 是内部槽位大小，不是每个网络包的长度，也不是已知磁盘记录长度。
// 本地生产者可能只写入较短内容，剩余字节包含调试填充值或无效栈内容。
// 某些本地事件还带有进程内指针；原样保存不构成跨进程可重放数据。
// 接收侧直达处理器、队列内事件和 UI 本地事件的时序也不同。
// 本次未发现已确认的“RCD 读取 -> 队列生产”链，不能给队列改名为播放器。
// 原证：queue_and_ui_gate.json、controls_and_queue_navigation.json。
