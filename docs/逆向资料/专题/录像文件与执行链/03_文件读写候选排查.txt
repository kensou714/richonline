// RCD 直接操作
// ----------------------------------------------------------------------------
// 0x762060：拼接 .rcd 后调用 MoveFile；字面量位于 A2AB5C。
// UI118 的删除链见“存档与配置持久化”；这些操作不读取或解释文件正文。
// 当前 Richonline 目录树的 .rcd 扩展名扫描结果为 0 个，详见 sample_inventory.json。
// 没有样本就不能用正常/损坏录像提示推算头部、版本、校验或帧长。
//
// 已分类的读写入口；每行结论只覆盖列出的调用与字段。
// ----------------------------------------------------------------------------
// 0x69AAA0 / 0x69ABE0
//     Config/Voice.dat 的固定角色语音参数读写，不能因二进制 fopen 当录像。
//
// 0x6DA7B0 / 0x6DBE30
//     Tex/%s/Item%s.tb 与 Pack%s.npp 的索引、定位与读取，属于贴图资源路径。
//
// 0x7DF010 / 0x7E6F10 / 0x7E71E0 / 0x7E72A0 / 0x7E8EB0
//     地图加载、预览、摘要、描述与 ITEM 配置读取。
//     预览链跳过 16 字节后读取版本及缩略图等，不能据此发布 RCD 的 16 字节头。
//
// 0x81AE00 / 0x81E580
//     通用全文/缓冲读取与文本解析加载；没有专属录像签名。
//
// 0x81B150 / 0x81B310 / 0x81B4C0 / 0x81B670
//     KPD 压缩编码写入/读回：随机非零字节键、两个长度字段和编码载荷。
//     0x70F9E0、0x738F60 的调用明确用于 Private.tmp -> Private.kpd。
//     0x72B910 写出来自对象 +200 的 128 字节账户区，路径由 0x72A080 设置。
//     0x81B310 是已有 FILE* 形式的写出，当前引用只看到跳板，调用用途未闭合。
//     通用编码格式不能仅凭同一程序存在就宣称 RCD 也采用它。
//
// 0x81BEA0 / 0x81C190 / 0x81C2B0
//     Log/Game 与 Log/Sys 日期目录下的 game.txt / sys.txt，文本追加和刷新。
//     初始化来源 0x623AD0；与二进制录像流区分。
//
// 0x81E290
//     InternetOpenUrl / InternetReadFile 的下载封装，可选择写出文件。
//     有写文件能力，不代表可录制游戏。
//
// 0x81FAC0 / 0x81FC50 / 0x8247D0 / 0x824960 / 0x825230
//     资源包读取及定位，包含 12 字节头、16 字节索引记录等固定结构。
//     本专题只做用途排除导航；完整资源格式以对应资源专题为准。
//
// 0x827B30
//     KetMd5GetDigest 的分块读文件辅助，4096 字节工作块。
//
// 0x9109D0 / 0x9BEE30
//     前者生成 [section] 与 key=value 形式文本；后者是底层 seek/write 回调。
//     后者未恢复业务调用契约，保留候选级，不能据此判定录像写出器。
//
// 原证：io_and_parser_navigation.json、controls_and_flow_navigation.json、
//       controls_and_queue_navigation.json、file_path_constants.json。
//
// 未被 IDA 声明成函数的 I/O 也必须单独保留。
// ----------------------------------------------------------------------------
// 旧的仅枚举声明函数的方法会漏掉代码；本次补取四个原始窗口，不伪造函数边界。
//
// 窗口 0x7DEDC0..0x7DF010，人工核验其中 0x7DEDD0 起的正文校验路径：
//     先读 16 字节，再读取剩余正文，写成 GetTickCount 命名的 .tmp。
//     调用 0x60EAFF -> 0x81B980 -> 0x827B30（MD5）后删除临时文件，
//     再比较两个 16 字节区域。摘要辅助函数也已单独完整取证。
//     相等时向对象 +8 复制原始摘要区域。这里没有 RCD 扩展名检查证据。
//     当前 xref 只见 0x611EBC 跳板，未闭合业务调用者，不能定为 RCD 校验器。
//
// 窗口 0x81B8B0..0x81B980，核验至返回指令：
//     0x8000 选 wb，0x4000 选 wt，把对象 +0 的缓冲按 +8 的长度整块写出。
//     没有在该段添加版本/帧头的证据；当前只见 0x60CDBD 跳板引用。
//
// 窗口 0x81C740..0x81C830、0x827DE0..0x827F50：
//     仅保存 I/O 导航原证，尚未逐条恢复业务契约，不计入已分析函数数量。
//
// 原证：undeclared_io_windows.json、stage4_references.json、
//       state_and_switch_data.json、binary_tables.json、digest_helper.json。
//
// 搜索覆盖边界
