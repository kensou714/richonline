// ABI与身份
//   60CF11 -> 6F4AA0，两个栈DWORD参数，调用者add esp8，入口retn。
//   第一个是物品配置索引，第二个是类别0/1/2；绝非wchar_t* locale。
//   入口末尾add esp14h恢复自身14h局部区，不是清理图像函数实参。
//   三个期限getter均thiscall/retn4；图像查询6DBA40为thiscall/retn10h。
//   6F4AA0未直接执行配置索引的上下限校验；有效性依赖调用者。

// 配置对象与字段
//   602890 -> 627C20，返回A766E0所指0x14C字节配置管理器。
//   配置记录基址B=DWORD[管理器]，记录R=B+1128*itemIndex。
//   类别  getter    年字段  月字段  日字段  整数n
//   0     800AD0    +68     +72     +76     365*y+30*m+d
//   1     800B30    +80     +84     +88     365*y+30*m+d
//   2     800B90    +92     +96     +100    365*y+30*m+d
//   算术为32位imul/add，不作闰年或日历运算，不验证负数/溢出。
//   其他类别保留n=0，不调用配置getter。
//   Prop.kpd确含yearJ/dayJ、yearR/dayR、monthP/dayP等键。
//   尚未独立核对装载写入点，因此类别与J/R/P的对应不能按顺序推定。

// 映射表：最终请求6DBA40(type=10,group,frame,-1)
//   n             group    frame
//   1             38       40
//   2             47       15
//   3             38       41
//   5             51       87
//   7             38       44
//   15            38       42
//   30            38       43
//   180           38       45
//   365           38       51
//   >=1500        15       19
//   其他          38       -1
//   15及1500比较均为signed；1500是代码阈值，不能直接宣称为“永久”协议值。
//   2、5两项使用不同图像组；扩展资源时不能仅替换other_38的连续帧。
//   一年加一个月得到395，没有通用期限图标；>=1500则全部合并为同一槽。

// 图像查询的真实边界
//   type10分支6DBABD..6DBAFC先验证group>=0及group<DWORD[M+240636]。
//   frame先cmp0/jl再cmp100/jge，实际要求0<=frame<100。
//   伪码把frame声明为unsigned并省掉负数判断，必须以指令为准。
//   命中读取DWORD[DWORD[M+240640]+1200*group+12*frame+4]。
//   group非法、frame=-1或frame>=100返回-1；第四参数此分支不用。
//   因此所有未列出期限、负期限及非法类别得到空句柄-1，不形成负索引访问。
//   返回的是槽内DWORD；实际装载图像和句柄消费仍由图像专题核对。

// 调用者来源，限本组局部观察
//   756460/77F590/77FEF0传类别1；物品索引来自窗口+76/+72。
//   762A80/762E10从记录+80的signed BYTE取得类别，并交记录内物品索引。
//   744144、74AC03、75B51E、766EB1、7679A6从标志位取(bits&F000)>>12。
//   其余调用点取窗口+72/+76字段。完整记录归属和所有输入可达性未穷尽。
//   callers.json的11个期限调用者含12个E8调用点；13条references含1条E9入口。
