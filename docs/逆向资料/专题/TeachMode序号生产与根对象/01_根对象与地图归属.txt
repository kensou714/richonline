// 地址关系
// ----------------------------------------------------------------------------
// 角色+0x57C（1404） = 保存的G指针；7F3CAD将外部参数写入该槽。
// Map                  = G+0x65C（1628），是嵌入成员地址，不是读取该地址处的指针。
// 目标DWORD             = DWORD[Map+0x68] = DWORD[G+0x6C4]。
// 63E210在63E221执行add eax,65Ch；7284B0在7284C1执行mov eax,[eax+68h]。
// 这两条是既有读取链；第十六批证明目标值参与TeachMode记录选择，本批补生产者。
//
// 629C90 / 游戏根对象单例创建
// ----------------------------------------------------------------------------
// A7672C非0：直接返回槽中的指针，不重构对象。
// A7672C为0：以0x14794（83860）字节请求operator new；本调用者检查返回指针。
// 629CE6将分配结果放入ECX；629CE9经600C43 E9桥调用7BAE60构造G。
// 分配结果为空的局部分支保存0；非空分支保存构造器返回值；629D0A写入A7672C。
// 629D10把A7672C送入EAX返回；如果槽仍为0，后续调用会再次尝试创建。
// 声明异常尾块A11730..A1173B以var_14分配指针调用operator delete；随后为SEH跳转块。
// 这是构造异常清理证据，不是正常释放单例入口。allocator是否抛出由外部CRT决定。
// 入口内未见锁或原子发布；不据此认定当前游戏必定存在并发调用或已触发竞态。
//
// 7BAE60 → 7DE310 / 构造地图成员
// ----------------------------------------------------------------------------
// 7BAE60保存入口this为G；7BAF06从同一保存槽恢复ECX，7BAF09加0x65C。
// 7BAF0F经60700C E9桥进入7DE310，故此调用下7DE310的this就是G内的Map。
// 7DE310保存其入口ECX；7DE3BE取同一this，7DE3C1写DWORD[Map+0x68]=0。
// 邻接7DE3CB、7DE3D5也把Map+0x6C/+0x70各清为DWORD 0。
// 缺省0成立条件：该对象实际经过此构造调用、且此后没有成功或部分改写目标字节。
// 构造器包含很多其它成员；本批没有逐字段恢复其完整类布局或所有子对象生命周期。
//
// 相同构造器，不同对象
// ----------------------------------------------------------------------------
// roots_incoming.json还包含69E458、6A3CBC、6A45E9、6A556B、6A6F24、73F2C2、
// 740A21、75EC6B、7E8F4E等调用点，存在独立堆对象、栈临时对象等不同来源。
// 这些只是构造器引用导航，不能将各调用者中的this+104统称为当前G的教程序号。
// 仅7BAF0F已沿ECX闭合为G+0x65C；其它调用对象归属需分别证明。
