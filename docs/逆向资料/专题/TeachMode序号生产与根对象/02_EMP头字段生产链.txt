// EMP头读取 / 目标DWORD的真实文件来源
// ============================================================================
// 64F2A0 / G内地图装载的调用归属
// ----------------------------------------------------------------------------
// 64F2B6保存入口ECX为G；外部getter的EAX加8作为复制源。
// 64F2DB..64F2E8把22个DWORD（88字节）复制到G+0x40，范围为G+64..G+151。
// 该小复制不覆盖G+0x6C4，不能当作目标DWORD的写者。
// 64F323..64F329把G+0x40作为Source参数；64F32A恢复G，64F32D令ECX=G+0x65C。
// 64F333经60469A → 7DF010；7DF04B保存其入口ECX为Map。
// 因而7DF138的Map+0x68与真实读取链中的G+0x6C4是同一字节地址。
// 64F338检查装载函数的整体返回值；为0时64F33C返回0。
// 这不等于逐次fread都成功；整体装载函数的其它成功/失败条件不在本批逐项审阅。
// 外部getter的IDA自动MFC名称不是原始类名，复制源对象布局仍由旧资料或后续分析确认。
//
// 7DF010 / 头部读取次序
// ----------------------------------------------------------------------------
// 使用Source经608C4F构造文件路径，随后7DF0A6以rb调用fopen。
// FILE为空：7DF0BD将返回值置0并跳到函数退出；没有开始下列文件读取。
// 本批未展开路径构造助手，因此不把Source直接当最终完整磁盘路径。
//
// 位置推导（fopen起点0、两次SEEK_CUR成功、前序4×1读取完整时）
//   7DF0C4..7DF0CF：Origin=1，Offset=16，当前位置到16。
//   7DF0DE..7DF0E9：读4字节×1到Map+4；完整读取后位置20。
//   7DF0F1..7DF0FF：Origin=1，Offset=23268（0x5AE4），位置到23288。
//   7DF10E..7DF119：读4字节×1到Map+24；完整读取后位置23292。
//   版本signed >=2：读4字节×1到Map+104，再读4字节×1到Map+108。
//   版本signed >=3：再读4字节×1到Map+112。
// 已知版本正常布局下，成员+104/+108/+112的文件位置依次是23292/23296/23300。
// 版本1跳过后面三个成员；相同文件位置已属于后续载荷，不能照套成员名称。
// 版本2跳过+112；文件位置23300不因此自动表示Map+112。
//
// 有符号版本门
// ----------------------------------------------------------------------------
// 7DF124 cmp DWORD[Map+4],2；7DF128 jl 7DF15E。
// 7DF161 cmp DWORD[Map+4],3；7DF165 jl 7DF181。
// 这是signed比较：-1、0、1跳过+104/+108；2进入这两个读取；3及更大值还读+112。
// 例如原字节FFFFFFFF表示signed -1，不能用uint32>=2令其进入分支。
// 这些门没有在本片段限制最高版本；不能把服务端解析器仅接受1..3的策略归给客户端。
// 未知或负版本不代表有效地图；这里只描述分支行为，没有证明整函数能成功接受它们。
//
// 目标写入与错误边界
// ----------------------------------------------------------------------------
// 7DF135取Map，7DF138加0x68，7DF13B压入Buffer，7DF13C调用5FF1EA → 923F60。
// 参数是ElementSize=4、ElementCount=1。旧CRT证据证明返回的是完成元素数量。
// 7DF141仅清参数栈，7DF144直接准备下一字段；本调用点未校验返回数量是否为1。
// +104读取、其前序version/Map+24读取及两次fseek后的紧邻指令也未检查对应返回值。
// 不把此结论扩大到全程序，也不根据完整原证导出宣称全部EMP载荷都已逐次审完。
// fread返回0可伴随已改写部分字节；目标可能是新旧混合值，不保证完整保留原值。
// 构造后的0只对未被改写的新对象成立；重用对象加载版本1时，本片段不把+104复位为0。
// 正常资源文件能证明一个生产来源，不能排除网络响应、整体赋值或运行时其它写者。
// Map+104原始官方名称未知；“TeachMode记录序号”是已证消费者用途，尚非文件字段原名。
