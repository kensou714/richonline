// 取样方法
// ----------------------------------------------------------------------------
// 证据/capture_emp_samples.py只打开三份现有EMP，保存完整SHA-256、长度与头部原始字节。
// 不扫描全部地图、不执行客户端、不写资源，也不提供未经验证的EMP写回工具。
// 偏移按02文档的正常读取前提推导；证据/emp_header_samples.json保留条件和原始观察。
// 未进入版本门的观察明确标为不能赋给对应Map成员，而非读取成功。
//
// Map/BS_1_1.emp
// ----------------------------------------------------------------------------
// 长度27187；版本3（03000000）；文件23288字节=03000000。
// 文件23292/23296各为00000000，对应正常头路径的Map+104/+108各为0。
// 文件23300为0B000000，对应Map+112原值11；本专题不凭样本值恢复该成员官方名称。
// SHA-256：841d2e09abb60b2ce344c816c3c13c8d48a1d63ca674a98ae440be5c0428c55c
//
// Map/TC_CM_1.emp
// ----------------------------------------------------------------------------
// 长度28157；版本3；文件23288为02000000，三个可读目标字段均为00000000。
// 此样本证明存在目标值0；它不证明整个教程流程永远只使用记录0。
// SHA-256：f6992e8bcaa10bdf1779ee716dd943732f238469d8895e3e9af7c76abf9b52e2
//
// Map/CM_CS_2.emp / 版本1不能套版本3字段位置
// ----------------------------------------------------------------------------
// 长度27540；版本1（01000000）；文件23288为00000000。
// 文件23292原字节10000000（16），23296为12000000（18），23300为C163B5D8。
// 因版本门跳过+104/+108/+112，这些字节不是本路径写入三成员的值。
// 不将16/18/C163B5D8当作教程序号、邻接元数据或异常巨大地图ID。
// SHA-256：7e37eaa1569b90a84129cd9a6696990fc4ebab4911b99bdee2391b61df00a8b8
//
// 对后续资源工具和服务端的约束
// ----------------------------------------------------------------------------
// 编辑器应按版本推进游标，避免将版本1载荷位置当版本3扩展头写回。
// 保留+104的DWORD原始值，展示消费者用途时注明尚未知其完整生产/更新规则。
// 正常版式偏移不能作为截断、seek失败、短读文件的恢复保证；工具应主动检查读量。
// 服务端若复刻教程序号，不应仅凭这条本地生产链认定网络永不更新或值永远为0。
// 新建Map的缺省0、重用Map残留和版本门未读取要作为三种不同状态记录。
// 本批没有调整服务端代码结构、协议处理或客户端补丁，结论供后续实现审查使用。
