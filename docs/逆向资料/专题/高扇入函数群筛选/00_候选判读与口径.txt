//
// 0x91F7E0 / 删除包装，不优先展开
// ----------------------------------------------------------------------------
// 17字节，参数为栈上传入的void*，经0x604CFD调用operator delete，再retn。
// 直接入口只有来自E9跳板0x601CD3的一条交叉引用；该跳板有269条call引用。
// 既有音频容器专题曾沿此跳板记录delete[]符号。当前入口实际汇编目标是
// 0x604CFD，最终0x91FC60，符号为标量operator delete；符号差异需要以
// 分配端和完整对象析构路径复核，不能据此推断内存故障。
// 优先级低：通用CRT释放适配，无可见游戏事件字段。
//
// 0x9CA953 / 标量deleting destructor，不优先展开
// ----------------------------------------------------------------------------
// 28字节，ECX=this；先调0x607FAC -> 0x9CB0D5；栈参数bit0置位时
// 调标量operator delete(this)，末尾返回原this并retn 4。
// 跳板0x612367有95条call引用；原审阅已把0x9CA930与此入口区别开。
// 0x9CB0D5的对象语义和真正析构范围未闭合，故仅称删除包装。
// 优先级中低：需按具体对象类型追踪，单独高扇入不构成业务价值。
//
// 0x9DB4B6 / 诊断文本格式化入口，可复用既有专题
// ----------------------------------------------------------------------------
// 84字节，局部256字节缓冲交给_vs(n)printf形式的导入跳板；显式将
// Buffer[255]=0，再以"%s"交给0x60CDD1 -> 0x98E8C1，并把对象+0x40置1。
// 0x98E8C1已有“编译诊断与寄存器池”专题：构造文件/行号/错误号前缀，
// 追加诊断节点。跳板0x608A4C有72条call引用；调用集中在0x9D/0x9E段。
// 这是开发/着色器诊断链候选，不应把日志格式化误识别为游戏通信发送。
// 缓冲截断和具体编码只按现有汇编可证范围记录，未实机测试。
// 优先级中：其终点已有局部审阅，未来适合追具体错误来源与输出消费方。
//
// 0x85BB10 / 选择深入的高频对象首字段接口
// ----------------------------------------------------------------------------
// 63字节调试构建包装：填0xCC栈局部、保存ECX、经0x60B7F6调0x85C710，
// 然后__RTC_CheckEsp。0x85C710仅取ECX指向对象的首DWORD并返回。
// 跳板0x60C87C有55条call引用；完整选定调用者集中在0x85EA60等模板式
// 比较/交换、堆调整代码。详见01_对象首字段与调用者.txt。
// 优先级中：能界定这批高频边的真实作用，避免继续把通用算法当业务入口。
//
// 入边统计口径 / 不能混写
// ----------------------------------------------------------------------------
// 原始XrefsTo入口+E9别名：91F7E0=270、9CA953=96、9DB4B6=73、85BB10=56；
// 四者均包括一条“跳板跳向真实入口”的引用。剔除该引用后各为
// 269、95、72、55条跳板调用。这里保存的是当前IDA数据库的代码xref。
// 中央followup_queue.json的direct_incoming_edges取自callgraph/batch_*.json：
// 依次为212、95、73、56。它按export_callgraph.py的函数主范围提取调用，
// 与本专题全域XrefsTo不同。91F7E0的270对212少58：57条调用位于A11/A12/
// A14/A15异常尾块；0x7DEF11虽为代码xref但当前无函数owner。中央导出脚本
// 使用db.functions.get_instructions(f)，既有导出器已说明该接口只返回主范围。
// 91F7E0中央212是主范围内边，含跳板自身跳转；不能称全部静态调用。
// 9CA953的96对95少1：0x9D0DBA调用点当前无函数owner。9DB4B6和
// 85BB10两种统计均相等；勿叠加或互换不同口径的计数。
