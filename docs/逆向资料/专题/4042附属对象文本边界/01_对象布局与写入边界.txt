// 4042：P+576 附属对象的构造、写入和长度边界
// ============================================================================
// 记 P 为棋盘参与者，Q 为 DWORD[P+576]。无 0x 前缀的偏移为十进制字节数。
// 原证索引：证据/4042_child_raw.json#/functions、#/incoming、#/windows。
//
// 分配与构造：7F3C70 的一条条件分支
// --------------------------------------------------------------------------
// 7F4266 push 0x5C；7F4268 operator new，非空时 7F428C 调 60BA62→7FD7F0。
// 7FD7F0 对 Q+0x54 调 5FF366→81BC80，栈参数 0x1E；共享计时专题已将
// 81BC80 识别为基础周期器，不能把 0x1E 误解为在 Q+0x54 写 30 字节。
// 7F42BF 将所得 Q 写 P+0x240，即 P+576；7F42E0 调 60A536→640C90，
// ECX 是刚保存的 Q。这个分配只属于该初始化条件分支，不能推断每个 P 都有 Q。
// 条件判断与分支含义要看 7F3C70 完整原证；本篇不为 Q 取“宠物”等业务名。
//
// Q 内可直接核验的字段
// --------------------------------------------------------------------------
// 十进制偏移  宽度/操作          依据
// +0         DWORD 写参数 a4    640C90
// +4         DWORD 写参数 a3    640C90
// +8         首字节置 0        640C90；640D60 的 strcpy 目标
// +24        DWORD 写参数 a2    640C90
// +28..+59   8 个 DWORD        640C90 两层循环写资源返回值；即 +0x1C..+0x3B
// +80        BYTE 置 1         640C90
// +84        周期器子对象起点   7FD7F0 调 81BC80；内部布局沿用计时专题
// Q 的分配大小为 0x5C=92 字节；不能仅以对象总长推定文本可用 84 字节。
// Q+8 后的首个明确独立字段是 Q+24，两者之间只有 16 字节。
// 若 Q+8 是连续文本区，最多 15 个非 NUL 字节再加终止 NUL，才不触及 Q+24。
// 这是依据相邻字段得出的保守上界，不等于已经恢复了 C++ 成员声明。
//
// 4042 写入路径
// --------------------------------------------------------------------------
// 6629D0：包+2 WORD 通过 GmsvID 检查后，取包+4 signed BYTE 槽号；检查
// G 槽标志和 signed DWORD[P+144]>0，随后取 Q=DWORD[P+576]。
// 662A59 传 packet+5 给 60968B→640D60；640D60 把 Source 交 j__strcpy，
// Destination=Q+8。该函数没有长度参数或目标容量判断。
// 如果源字符串在第 16 个非 NUL 字节之后才终止，写入会到达 Q+24，可能
// 覆盖构造器写在这里的独立 DWORD；继续增长还可能覆盖其它成员。
// “可能覆盖”是静态内存布局结论，不宣称已观察到长包、崩溃或远程利用。
// 包从 +5 起须能读到 NUL；接收缓冲长度及上游服务端约束尚未联合核验。
//
// 复刻与补丁边界
// --------------------------------------------------------------------------
// 服务端生成 4042 文本时，按客户端字节编码计数，而非按 Unicode 字数计数。
// 保守约束是 packet+5 的内容不超过 15 字节并附 NUL；还须满足现有协议帧长度。
// 客户端补丁若要改变此限制，需确认所有 Q+8 读者、资源字段及内存生命周期。
// 不能直接把 0x5C 分配改大当作已完成修复，因为 Q+24 等字段仍会被 strcpy 覆盖。
// 当前没有运行时验证，也没有修改客户端或服务端代码。
