// ============================================================================
// EMP 尾部表：成员匹配、次数展开和随机索引读取
// ============================================================================
// 原证：证据/windows_and_incoming.json；证据/rechecked_raw.json；
//       证据/tail_picker_raw.json；证据/window_roots_raw.json。
// 以下按 Map 字节偏移描述，业务名称仍保留未知。
//
// 字段对照
//   +116 / +120：配对记录数量 / 8 字节记录数组，记录为两个 DWORD。
//   +124 / +128：尾部已装载字段；本群没有闭合确定消费者。
//   +132 / +136：成员数量 / DWORD 数组，7E10E0 窗口执行相等匹配。
//   +140 / +144：第一组输入数量 / DWORD 数组。
//   +148 / +152：第二组输入数量 / DWORD 数组。
//   +156 / +160：第一组展开数量 / 展开 DWORD 数组。
//   +164 / +168：第二组展开数量 / 展开 DWORD 数组。
//   +172 / +176：尾部已装载字段；本群没有闭合确定消费者。
//
// 配对查询：7E1140（已有函数，本轮复核）
//   遍历 +116 条记录，将 record+0 与实参比较；首次相等返回 record+4。
//   没有匹配返回 0；因此返回 0 不能区分“记录值为 0”和“不存在”。
//   多个重复键只使用首项，不在本地合并第二值。
//
// 成员查询：未声明窗 [7E10E0,7E1139)
//   遍历 +132 个 DWORD，对 +136 数组元素与实参执行相等比较。
//   找到返回 AL=1，遍历结束返回 AL=0；返回时清理 4 字节实参。
//   601E4F 是磁盘已核实的 E9→7E10E0 桥。
//   IDA 本轮未发现指向该桥的 incoming，不等于证明没有间接调用。
//
// 两组展开：未声明窗 [7E11A0,7E13FA)
//   第一组先清 +156，然后遍历 +140/+144。
//   每个输入值调用 603E43→7E1140，所得第二值保存为该项重复次数。
//   汇总次数到 +156，分配 4*汇总次数字节，保存指针到 +160。
//   再按每项次数，把原输入值反复写入 +160。
//   第二组对 +148/+152 执行同样步骤，输出到 +164/+168。
//   6074C6 是磁盘已核实的 E9→7E11A0 桥；其 incoming 也为空。
//
// 次数临时数组
//   栈索引形如 [ebp+index*4-0x414]。
//   尾随 RTC 描述符位于 7E13FA：一项，描述符指针 7E1402，
//   offset=-0x414、size=0x400、name 指针 7E140E，名字为 iRatioAry。
//   这证明局部数组为 1024 字节，即 256 个 DWORD。
//   它不证明 EMP 文件里的 +140/+148 数量必然不超过 256。
//
// 展开数组读取
//   7E1420（55 字节声明函数）：
//       return DWORD_at(Map+160)[ rand() % DWORD_at(Map+156) ];
//   [7E1460,7E1497)（未声明窗口）：
//       return DWORD_at(Map+168)[ rand() % DWORD_at(Map+164) ];
//   实际机器码均使用 cdq、idiv，从余数 EDX 形成 4 字节数组索引。
//   两处调用 60AE14→9208C0，IDA 符号为 rand；随机算法和状态种子未在本群展开。
//   重复次数决定某值占有的槽位数，已可称“按次数展开后随机索引”。
//   不宣称严格均匀分布；rand 的有限输出与取模可能产生偏差。
//   尚未查明两组输出值最终用于什么业务，也没有核查所有间接调用。
//
// 输入契约与失败边界
//   原输入计数应在临时数组容量内；本窗口没有显式 256 上限检查。
//   重复次数应非负；有符号 jge 的填充循环遇负次数会直接跳过，
//   但负次数仍参与总和，可能使分配字节数与实际填充数量不一致。
//   总和及左移 2 位没有溢出检查；分配结果未见空值检查。
//   随机读取要求展开数量为正且指针有效；为 0 时 idiv 会触发除法异常。
//   重复执行展开会覆盖 +160/+168 旧指针，本窗没有先释放操作；
//   是否保证仅调用一次、是否由外层释放，尚未闭合。
//   以上均为静态约束，现有资源能否触达这些异常没有实机验证。
