// ============================================================================
// 装饰链表：文件生产、初始化加载、逐格绘制
// ============================================================================
// 原证：证据/consumers_raw.json；证据/rechecked_raw.json；
//       证据/dependencies_raw.json；地图与路径/证据/map_runtime_core.json。
// 装载器与插入函数已由前批分析，本篇只复用其生产契约，不计新增审阅。
//
// 运行时布局
//   Map+1436（0x59C）保存逐格链头数组指针，格号乘 12 得到链头地址。
//   每个链头 12 字节；本群直接使用首节点+0、末节点+4。
//   每个节点 28 字节：五个 DWORD payload，然后 next+20、prev+24。
//   链头其余 DWORD 的生产维护见 7ED0E0；本群遍历不读取它。
//
// 文件到节点
//   7DF010 的装饰记录为 36 字节：x、y 加七个 DWORD F[0..6]。
//   F[0] 经类别 1 的图像资源查找转换成图像句柄。
//   7DF823 经 60633C→7ED0E0 传入四个值与句柄，写入节点的五个 payload。
//   这四个值来自 F[2]、F[3]、F[4]、F[5]；F[1]、F[6] 在本消费链未见复制。
//   不由这条路径推断 F[1]、F[6] 无效；可能的其他用途仍需独立原证。
//
// 容器叶函数
//   600CB1→7ECF40：返回链头首 DWORD 是否为 0，即 first==0。
//   60BA8A→7ED1E0：callback、first、last 均非空才开始遍历。
//   从 first 沿 node+20 前进，调用 cdecl callback(node,arg)。
//   callback 返回非零则提前结束并返回 1；到空指针或不满足前置条件则返回 0。
//   last 只作为入口条件，循环不会与 last 比较；prev 不参与这条遍历。
//
// 初始化资源路径
//   7E83D0 的 7E8761、7E8783 用 Map+1436 加 12*格号计算链头。
//   先调用空表谓词，非空时以 callback=6023B8→7E8890、arg=0 遍历。
//   7E8890 读取 node+16 图像句柄，经 60554A 取得资源对象，调用
//   60C057→6DB580(image)，然后返回 0。
//   6DB580 检查资源对象状态、图像索引及加载状态，未加载时要求加载资源。
//   该返回值不会终止链表遍历，也不会直接产生绘制坐标。
//
// 绘制路径
//   7E7530 的 7E79E0、7E7A07 采用相同链头地址计算。
//   非空链头以 callback=600E23→7E8240、arg=&viewport_pointer 遍历。
//   7E8240 运算为：
//       draw_x = payload[0] - payload[2] - signed_WORD(viewport+0)
//       draw_y = payload[1] - payload[3] - signed_WORD(viewport+2)
//       image  = payload[4]
//   经 60554A 取得资源对象，再调用 60C967→6DC470(image,draw_x,draw_y)。
//   6DC470 将两个整数坐标转成 float，交给 602917→8141A0 绘制，
//   并递增该图像的使用计数。7E8240 恒返回 0，因此不会提前结束遍历。
//   本群可确认前四个 DWORD 参与两组坐标差，与视口处于绘制运算坐标域；
//   尚不能把它们命名为中心、左上角、像素锚点或世界坐标。
//
// 对后续资源编辑的意义
//   单独替换装饰图像可能改变尺寸；原记录里的两个差值不会随之自动重算。
//   编辑器应保存原始五值和文件未消费字段，避免以猜测语义覆写原数据。
//   验证应同时比较初次显示、视口平移和资源加载后的定位结果。
//   本轮没有修改资源或运行游戏，上述验证尚未执行。
//
// 静态容器约束
//   first 非空而 last 为空会被跳过；损坏的 next 环可能让遍历不能结束。
//   callback 需要有效节点和有效 arg；绘制 callback 还要求可用视口指针。
//   未见容器自检或步数上限，不据此宣称现有文件会形成环或实机已复现。
