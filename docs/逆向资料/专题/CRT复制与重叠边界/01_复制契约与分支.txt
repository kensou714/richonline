// 复制契约与分支
// ============================================================================
// 核心：9213A0..9216DD、9217B0..921AED，均为半开区间。
// 两套实现的结构地址相差410h；以下先用9213A0实例说明。
//
// 调用与返回
//   cdecl参数：[入口ESP+4]=dst，[入口ESP+8]=src，[入口ESP+12]=n。
//   返回EAX=原dst，RETN不弹参数；ESI/EDI/EBP保存恢复，EBX未改。
//   ECX/EDX/EAX和算术标志可改；仅正常返回时讨论保存约定。
//   无NUL检测、编码转换、内存分配、对象析构或容量字段检查，n是字节数。
//   n=0不解引用src/dst；dst==src仍走正向复制，并非提前返回。
//
// 方向选择
//   入口令ESI=src、EDI=dst、ECX=EDX=n、EAX=src+n。
//   dst<=src走CopyUp；否则仅dst<src+n走CopyDown，其余走CopyUp。
//   比较是JBE/JB无符号地址比较；不能用有符号int指针关系复述。
//   有效不回绕区间下，CopyDown恰为目标落在源区间内部且位于源之后。
//   dst==src+n属于不重叠边界，走正向；dst<src时左重叠也走正向。
//   src+n本身没有溢出检查；本专题不为回绕地址构造有效对象模型。
//
// 正向复制
//   以目标地址对齐，不要求源地址4字节对齐；x86非对齐源读取按原机器码执行。
//   若目标已对齐：q=n/4、r=n&3；q>=8用REP MOVSD，q<8用展开跳表。
//   若目标未对齐且n<4：用尾字节表直接处理0..3，不强行读取一个DWORD。
//   若目标未对齐且n>=4：先拷4-(dst&3)个前导字节，使EDI对齐；
//   再对剩余长度作q/r分流。指令中先ECX-=4，再ECX+=dst&3，勿丢这一步。
//   正向展开表按q=0..7选择，复制低地址到高地址；结束把ESI/EDI前推4q。
//   尾表按r=0..3复制末尾字节，各出口最终取原dst返回。
//   对齐后的批量门为q>=8，即剩余至少32字节，不是原n一律>=32。
//
// 反向复制
//   起始ESI=src+n-4、EDI=dst+n-4，故[ESI+3]为最后一个源字节。
//   对齐的是目标尾端；若未对齐且n>=4，先倒序搬尾部EDI&3个字节。
//   剩余q>=8时STD、REP MOVSD、CLD；每次按DWORD从高地址向低地址搬移。
//   剩余q<8时ECX取负，表基址921638，使用921638-4q选倒序展开入口。
//   这不是只含q=0的单项表；IDA的switch 1 cases注释不足以描述负索引。
//   展开复制后ESI/EDI下移4q，再以r=0..3尾表补剩余最低端字节。
//   n<4可出现内部ESI=src+n-4低于src，但实际访问只用+3/+2/+1，
//   并不意味着读取src之前；已以访问钩子核对有效用例读写范围。
//
// DF前提
//   核心入口没有CLD。正常ABI调用的DF=0是正向REP MOVSD所需前提。
//   反向REP专门STD，正常完成后紧接CLD；其他标量/展开路径不改DF。
//   因此DF=0进入且正常返回时DF=0；不能称为无条件清DF或任意DF保存。
//   离线反证：DF=1、n=32、非重叠且对齐时正向REP产生错误结果，DF仍为1。
//   DF=1、n=0或3的标量路径仍保留1；反向大块路径才主动清成0。
//   内存故障若发生在STD与CLD之间，函数未正常返回，不承诺此时DF状态。
