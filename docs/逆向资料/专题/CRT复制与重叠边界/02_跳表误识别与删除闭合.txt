// 9217B0反向对齐分发
//   921991的间接JMP使用92199C+EAX*4，EAX为目标尾端地址低两位1..3。
//   因而真实三个DWORD位于9219A0、9219A4、9219A8。
//   原字节：AC 19 92 00  D0 19 92 00  F8 19 92 00。
//   小端目标：9219AC、9219D0、9219F8，分别处理1、2、3个尾端对齐字节。
//   9219AC真实首条为8A 46 03，即MOV AL,[ESI+3]。
//   IDA将9219A0误记LODSB，随后SBB跨过表项并吞掉9219AC首条的边界。
//   不能把这些伪指令当成函数行为，不能据此推断异常寄存器或越界操作。
//   本专题保留IDA原证，并用PE原字节+跳表目标+独立解码+原码仿真交叉核对。
//
// 跳表总览：位置 / 项数 / 索引含义；第二实例均在第一实例地址基础上加410h。
//   921404 / 3 / dst&3为1..3，使用偏移基址921400，前导搬3/2/1字节。
//   921480 / 8 / 正向q为0..7，入口按实际DWORD数展开。
//   9214EC / 4 / 正向r为0..3，尾字节。
//   921590 / 3 / (dst+n-4)&3为1..3，使用偏移基址92158C，倒序搬1/2/3字节。
//   92161C / 8 / 表物理顺序为q=7..0；执行时基址921638且ECX=-q。
//   921688 / 4 / 反向r为0..3，最低端剩余字节。
//   完整60个目标和原字节见证据/跳表原证.json，所有表项均映射到本函数可达代码。
//
// 字符串删除闭合
//   62BD10对象S的data由62BF70按容量选择内嵌/堆地址，length取S+20。
//   合法pos<=length时，count先裁为min(requested,length-pos)。
//   count=0直接返回S；否则n=length-pos-count，src=data+pos+count，dst=data+pos。
//   因此count>0时dst<src，删除尾部时n=0；绝不需要反向覆盖已有源后缀。
//   62BD82 -> 60082E -> 62BDE0 -> 6059F0 -> 9217B0。
//   对当前实例，正向复制支持上述同缓冲左移；搬完再62BE10缩长度并补NUL。
//   这关闭“短字符串与缓冲所有权”专题暂留的CRT重叠能力问题；原审阅记录保留历史边界。
//   它也支持62B910自赋值所用双删除路径的复制依赖，但未把所有外部别名输入证明为合法。
//
// 集成验证限制
//   离线直接调用原62BD10机器码，执行真实data/复制/终止符/RTC正常检查调用链。
//   合成对象覆盖容量15内嵌，以及容量>=16的独立堆地址；未调用宿主C++标准库替代。
//   6121用例覆盖0..129中的19个边界长度、所有合法pos、8类去重requested。
//   核结果正文、长度字段、末尾NUL、返回S及保存寄存器；未触发pos越界异常。
//   合成堆内存由仿真器提供，没有验证原分配器、Windows异常处理或游戏显示。
