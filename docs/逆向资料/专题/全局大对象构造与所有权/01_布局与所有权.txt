// 对象布局 / O 表示 A76734 指向的分配块，R 表示单条记录
//   O+00000..2A7FF：512 条 R，每条 0x154 = 340 字节。
//   O+2A800        ：DWORD，当前写入槽，64B880 以 340*该值定位记录。
//   O+2A804        ：DWORD，主记录数量；7976F0 直接读取。
//   O+2A808        ：DWORD，主记录可见起点；797720 直接读取。
//   O+2A80C..2BD4B：16 条 R，每条 340 字节。
//   O+2BD4C        ：DWORD，64A430 写入 0，职责尚未闭合。
//   O+2BD50        ：DWORD，64A430 写入 -1，职责尚未闭合。
//   合计 0x2BD54 = 179540 字节，数组没有重叠。
//   R+0..271 为文字；R+272..335 为关联字符串；R+336..339 为显示属性。
//
// 创建 / 62A1D0 -> 60E9F1 -> 62A2A0
//   A76734 非零：直接返回现有对象。
//   A76734 为零：operator new(0x2BD54)，ECX 接收分配块后调用构造。
//   分配返回空的分支将 0 写回全局；分配器是否抛异常另属外部契约。
//   62A2A0 对首段调用 vector constructor iterator(this,340,512,605D06)。
//   第二段从 this+0x2A80C 开始，调用相同迭代器构造 16 条。
//   605D06 -> 62A310，每条仅 BYTE[R+0x110]=0 和 BYTE[R]=0。
//   元素的其余 338 字节及对象五个 DWORD 不由此构造清零。
//   不得把 new 后整个对象当作初始化完成；应结合运行时 reset 使用。
//
// 运行时 reset / 64A430
//   O+2A800 / O+2A804 / O+2A808 / O+2BD4C 写 0；O+2BD50 写 -1。
//   不清两段记录数组，不重新执行元素构造。
//   byte_A67341 条件分支还修改多个全局标志并调用外部函数。
//   随后执行 6087D6、600FE5 等外部流程，result!=-1 时再调用其他对象。
//   本专题只闭合这五个 DWORD 的写入，不以 reset 一词掩盖外部副作用。
//
// 主记录清空 / 60C4B2 -> 64C340
//   主数组 0x2A800 字节被 memset(0)，三个主记录 DWORD 写 0。
//   16 条尾数组与尾两个 DWORD 不在 memset 范围中。
//   还向 60837B 返回的外部对象传入 (76,0) 和 (137,&4096)。
//   IDA 把目标命名为 CMFCColorPickerCtrl::GetCursorPos，名称不足以证明
//   Windows 控件类别；保留数值调用契约，真实消息接口另审。
//   6A21A0:6A2224 取得对象，6A2229 写 ECX，6A222B 调用本清空接口。
//
// 所有权与释放 / 6B8210
//   A76734 非零时直接 operator delete(A76734)，随后全局置 0。
//   没有逐条记录析构调用；这只说明所见释放代码，不证明无隐藏所有者。
//   624080 的 A76734 引用导航亦显示 delete 后置零，属退出上下文。
//   该大函数已有其他专题资料，本专题不重复宣称完整关闭流程完成。
//   游戏时间专题的 6AB5F0 原证显示 6AB64D 释放、6AB652 重新取得对象、
//   6AB659 调用 64A430；旧借用指针不能据全局仍存在而视为有效。
