// 单条布局 / R=O+340*W
//   R+0x000..0x10F：272字节，以零结尾的显示文字。
//   R+0x110..0x14F：64字节，以零结尾的可选关联字符串。
//   R+0x150..0x153：DWORD显示属性，追加参数a3原样写入。
//   第二字段没有独立长度成员。64C0A0返回它，736D10按字符串复制消费。
//   显示属性经64BFE0原样传到60527A；可疑似颜色，但真实编码不在此
//   专题解释，不能仅凭0xFFAF3333常量认定ARGB或其他排列。
//
// 追加入口 / 607138 -> 64B880
//   a2为空：立即返回空，不更新记录也不调用显示通知。
//   主记录数N>=512：调用64C340清主区，然后继续本次追加。
//   Source为空：改用A229F8常量地址；其内容本专题没有读证，不能先
//   假设为零长度。a2不为空但首字节为零，仍执行准备和末尾外部调用。
//   按R=O+340*W取当前槽，R+336写a3，strcpy(R+272,Source)。
//   字体相关接口取数值12和每个首字节的宽度；宽度来源未整体审阅。
//   显示行最大宽430像素，累积宽度v18从0开始。
//
// 字节推进与换行
//   首字节<0x80：一般按宽度接口返回值累加，适合时复制一个字节。
//   特例0x06且下一字节按signed char比较在20..70：复制两字节，宽24。
//   首字节>=0x80：复制该字节与下一字节，按首字节查询宽度累加。
//   这是字节分类协议，不等于已确定GBK、Big5、UTF-8或合法字符校验。
//   没有检查第二字节仍在输入有效区；孤立高位字节及结束处控制符要
//   由调用方/资源规范保证，不能把函数当作通用文本安全解析器。
//   一般ASCII换行会向后找空格、逗号或句号；匹配时保留该分隔符并
//   回退输入游标，使分隔符之后的尾词在新行重新处理。
//   特例标记放不下时找空格、逗号、句号或感叹号；匹配时把分隔符
//   本身置零，仍按其后字节数回退输入，两个分支的分隔符行为不同。
//   高位字节放不下时直接结束当前行，不做词边界回退。
//   每次结束一行调用6068AA，重新取当前槽并复制属性和关联字符串。
//   循环退出且累积宽度>0时补终止零并再提交一行。
//
// 容量与所有权
//   430像素是显示宽度约束，不是272字节数组容量检查。
//   所见循环每次写字节不比较R+272；关联strcpy也不比较64字节容量。
//   长Source会覆盖显示属性，继续越过记录；文字写入可能覆盖关联区。
//   是否被真实上游长度限制保护另核，不宣称所有调用均存在越界。
//   字体宽度函数返回零或大于430时的进展契约未闭合；不要把这个接口
//   当作无条件能处理任意字节串的换行器。
//   末尾还有76/137外部通知及128相关记录调用，功能未整体审阅。
//   返回值来自最后外部调用，不等于追加记录数量或输入字符串本身。
//
// 提交一行 / 6068AA -> 64BDF0
//   先令W=(W+1)%512。N<512时先++N，更新后N>5才C=(C+1)%512。
//   N>=512时不继续增加N，只令C=(C+1)%512；所有余数是有符号实现。
//   从正常零状态开始，提交第1..5条时C保持0，第6条时C变1。
//   第512条时W变0、N=512、C=507；同一次追加后续行还能覆写旧槽并
//   推进C。下一次进入64B880则见N>=512并清空，历史保留存在调用边界。
//   只更新元数据，不清新写入槽，也不补终止零；终止零由追加器写入。
//   如果调用者破坏W/C范围或N为负，提交器没有独立校正保证。
//
// 显示 / 60CE35 -> 64BFE0
//   从C开始，至多五条；先读R[0]，遇零则停止。
//   把R文字和R+336显示属性交给60527A，y每行加24。
//   下一槽=(槽+1)%512，为有符号余数；首次读之前没有C范围检查。
//   无N数量上限判断，依赖记录首字节和元数据初始化维持有效范围。
//
// 关联字符串 / 60D1B9 -> 64C0A0
//   从C遍历至多五条；遇文字为空则停止，槽推进同上。
//   行号等于参数a2时返回借用地址R+272，不复制、不分配。
//   未找到返回A229FC常量地址，其内容此处未读证。
//   参数负数或>=5不会匹配行号，但仍可能在遍历时先读记录首字节。
//   借用内容会被后续追加、清空和整个对象delete改变或失效。
//
