// ============================================================================
// 512 槽主记录游标 / 五条可见窗口
// ============================================================================
//
// 字段缩写
//   W=DWORD[O+2A800]，N=DWORD[O+2A804]，C=DWORD[O+2A808]。
//   7976F0 返回 N，797720 返回 C；不复制记录，不分配，也不检查范围。
//   这些接口具有环形索引分支，但64B880在一次追加开始时发现N>=512会
//   先清空主区。因此不能从游标接口独自推断主记录永远保留最近512条。
//
// 向前一条 / 6128D0 -> 64BEA0
//   以有符号比较判断 N<512。
//   未满：C>0 才令 C=C-1；否则不改变。
//   已满：T=(C-1)%512，T!=W 才令 C=T。
//   % 的机器码包含符号修正，是有符号余数，不能替换成无符号掩码。
//   例如 N=512,C=0,W=0 时 T=-1，可写入 -1；该局部状态是否可达还需
//   写入和显示路径约束，不能仅凭这一例宣称实机越界。
//   64BFE0/64C0A0先按340*C读记录首字节，再做后续取余，没有先验C>=0
//   检查；若C=-1到达消费者，首次地址为O-340。这是条件风险，不是
//   已重现的游戏BUG，正常状态可达性仍待审阅。
//
// 向后一条 / 60A2AC -> 64BF30
//   未满：有符号 C+5<N 时才令 C=C+1。
//   已满：(C+5)%512 != W 时才令 C=(C+1)%512。
//   五条窗口决定了边界检查；移动步长始终是一条，而不是五条。
//   加法及余数按32位机器码理解；本函数未钳制异常输入到合法范围。
//   返回 EAX 有路径依赖，调用者 737130 丢弃它并直接返回 BYTE 1。
//   因而不能把返回值统一解释为是否移动成功。
//
// UI 同步 / 7367B0
//   this+4 对象调用 610297(11,0)，返回的控件指针保存在局部变量。
//   60E073 的返回值写入 ECX，61218C 取得 N。
//   ECX 改为该局部控件指针，60771E -> 796B10 把 N 写入控件+0x460。
//   再取得主记录 C，ECX 仍切换为控件，6036E1 -> 727790 写控件+0x46C。
//   两个控件接口都调用 601742 后返回；后续刷新职责未展开。
//   控件偏移不属于 A76734，不能把它们并入本对象结构。
//
// UI 值变化 / 737130
//   相同控件调用 605342 返回 V，再从主记录取 C。
//   V>C：调用 64BF30；V<C：调用 64BEA0；相等：不移动。
//   即使 V 与 C 差距很大，每次仍只调整一条；不是赋值 C=V。
//   V 的取得接口未审，保留数值比较契约，不先命名滚轮或拖动事件。
//
// 原证
//   证据/consumer_methods.json：两个游标方法、两字段getter和两控件setter。
//   证据/accessors_and_consumers.json：7367B0、737130 及ECX数据来源。
//   以上仅闭合局部接口；记录文字编码、绘制和16条尾数组另核。
