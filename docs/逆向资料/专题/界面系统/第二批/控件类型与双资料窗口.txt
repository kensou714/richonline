// 控件类型与继承链
// ----------------------------------------------------------------------------
// 0x8E24D0决定分配大小；13种控件的构造器都写入本类虚表，属性入口位于虚表+124。
// 控件配置键目录.txt按类型列出原始键拼写，源VA与引用指令保存在原始JSON。
// 父解析链：公共0x8E4FF0 <- label/title 0x90D9B0；button、checkbox、progress、
// groupbox、listbox再调用label解析；edit/tree调用listbox；radio调用checkbox；
// scrollbar/slider直接调用公共解析。编辑器应合并继承字段，不能只取本类直接键。
// 构造链也支持这一关系：radio->checkbox->label，edit/tree->listbox->label。
// 虚表前缀导出是地址导航；未逐一解释13类的所有方法，不应宣称完整虚表语义恢复。
//
// 关键ABI纠正
// ----------------------------------------------------------------------------
// 0x8E4FF0反编译原型把对象误列为a1；汇编mov ebp,ecx，ID写[ebp+4]，尾部retn4，
// 故实际约束是ECX=控件对象、一个栈参数=节名。上层只传一个String2并非漏参数。
// 0x74D5E0同样ECX=this、栈参数为至少两个DWORD的数据指针，尾部retn4。
// 虚表+偏移均以字节计；DWORD数组下标须乘4，不得把this+203误写成203字节。
//
// 公共与文本字段：可直接用于编辑器规则的部分
// ----------------------------------------------------------------------------
// 公共解析0x8E4FF0：ID->+4；HintFontSize->+44；HintUseCtlText->+52；
// Hint背景四态色+56/+60/+64/+68，前景四态色+72/+76/+80/+84。
// 状态索引0=普通、1=进入、2=按下、3=禁用，可由Normal/MouseIn/MouseDown/Disable调用核对。
// Enabled/Visible调用虚表+196/+200；缺键时主动设true，不是保留构造器默认值。
// Ignore->+386，缺键设false；TabIndex->+372，缺键设0；EnableFlag->+380；
// CanDrag->+388；Attract->+389；InHighLight->+390；EdgeSize->+376。
// MousePressTime/MousePressSpaceTime/MouseStopTime->+432/+436/+448。
// label解析0x90D9B0：UseCtlText->+128；CapFontType->+124；Space->+588；
// 前景四态色+148/+152/+156/+160，背景四态色+132/+136/+140/+144。
// CapText可先经过引擎+72字符串回调，再转换为宽字符并交虚表+148；不是直接绘制原始字节。
// ALignH/ALignV、AutoSize、MultiLine走setter；本轮未将其内部语义/完整范围伪装成已证。
//
// button / checkbox / radio / progress
// ----------------------------------------------------------------------------
// button 0x90B500：InSound+592、DownSound+596、OutSound+600；
// DownOffsetX+604、DownOffsetY+608；CoolDown为+612单字节布尔。
// checkbox 0x90A8F0：Checked经setter，CheckColor+596；InSound+600、
// DownSound+604、OutSound+608。不能与button音效偏移混用。
// radio 0x902580先执行checkbox解析，CancelCheck写+612，然后执行组状态更新与虚表+12。
// groupbox 0x90A170只委托label解析，无本类新增直接键。
// progress 0x901D30：Max/Min/Step/Position通过setter，TopColor直接写+608、Kind写+612。
// 仅键和字段已核对，不据名称推定Position允许值或进度插值算法。
//
// edit / listbox / tree
// ----------------------------------------------------------------------------
// edit 0x900CD0：ShowTime+844、HideTime+848、PassWordChar取值首字节写+876；
// TextType+832、CheckColor+872、Paste+881、ImeType+884、ReadOnly+880。
// PassWordChar不是读取任意Unicode字符；修改为多字节符号须另审消费者。
// listbox 0x8F8080：MultiSelect+801、AutoChangeLine+828；MaxCount+824；
// InSound+808、DownSound+812、OutSound+816；MaxRow调用容量setter。
// listbox的Nor/Down/In/Dis字体色写入顺序可与label的MouseIn/MouseDown字段顺序不同，
// 不要机械替换名称。内部条目步长160，重置字体/提示数据时按此步长遍历。
// tree 0x908F80有值得优先复核的原始实现异常：Retract、ShowLine、LineType、LineColor、
// ShowPlus、PlusColor、PlusBColor、ShowIcon八个配置分支最终全写同一DWORD +812。
// 汇编写入VA：908FD0、90901C、909054、90908D、9090D9、909111、909149、909195，
// 均mov [ebp+32Ch],寄存器。不是仅凭Hex-Rays类型猜测的结论。
// 这些键同时存在时按函数顺序覆盖；+812还被父listbox用作DownSound，不能据键名
// 声称八项均独立生效。构造器却有不同字段，值得后续恢复真实意图并设计实机差异样本。
// 本轮未修改这些疑似错误；它们是静态风险，不是已验证功能修复。
//
// scrollbar / slider
// ----------------------------------------------------------------------------
// scrollbar 0x8EE7B0：Kind+1108、MidSize+1112、SideSize+1116；
