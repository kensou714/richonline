// 虚表+4=715410初始化；+8=7155D0重置；+16=715620按消息刷新；+20=715A30逐帧输入。
// +32=715B10只置W+589=1；+100/108=715FB0/7160C0鼠标提示进出。
// +120=715C80控件通知；+144=716120提示绘制；+68=6FA100转交根控件enabled。
// +64=6E2590隐藏关闭；不是专用商店取消函数。

// 窗口字段
// +72 DWORD 当前悬浮物品ID，重置为-1。
// +76..587 文本区：715FB0以sprintf("%s : %s",名称,说明)写入，未见长度参数。
// +588 BYTE 商品提示显示；+589 BYTE 允许商品提示；+590 BYTE 刷新金豆提示显示。
// +591..718：128字节刷新提示缓冲；715410先清零，再用文本803格式化共享花费。
// +720 DWORD 本次窗口刷新请求次数；7155D0置0；715C80每次点击15000加1。
// 715620只据计数>=5禁用刷新按钮；购买数量、库存槽数与该计数无关。

// 控件编号与刷新715620
// 1..12：商品图标；101..112：名称；1001..1012：价格文本；
// 10001..10012：另一个逐槽显示层，商品有效时调用其可见入口(0)。
// 10000：退出；15000：付费刷新；20000：当前角色点券；5000用于自定义绘制回调。
// 商品有效条件仅为signed WORD ID!=-1；数量不用于界面价格乘算。
// 图像调用6DBA40(type9,物品ID,-1,-1)，名称走693370，价格走6940B0。
// mask&1或force!=0时刷商品；mask&2时刷点券；每次均先启用根窗口。
// 刷新按钮先由本地金豆>=A87490决定可用，再被模式/配置门或次数>=5禁用。
// 状态/配置门：628270返回的对象经64F200取+100指针；调用点读该DWORD并与2比较。
// 相等且配置单例+544字节非零时禁用；此处不是直接读取地图mode字段。
// 本篇没有把这个配置字节强行解释为付费资格或VIP状态。

// 输入与立即效果
// 点击商品通过点券与空槽检查后，发0030；隐藏图标、名称、价格控件并禁用根窗口。
// 这些可见性/启用变化早于4031，不能当作库存已经增加的证据。
// 点击退出发0030(-1)并关闭UI20；点击分支本身没有6939E0清pending。
// 715A30仅主状态2处理：Esc按下沿发0030(-1)，再清pending并返回1供UI管理器关闭。
// Shift保持且Space释放沿直接转交控件15000通知；未在715C80内部再检查金豆或次数。
// 因此按钮disabled只是UI限制，网络端仍必须独立验证刷新资格和价格。

// 文案与编码证据
// RichStr.kpd：180“歡迎光臨道具商店”；181“您的點券不足！”；182“您的卡片欄已滿！”。
// 803“需要花費%d金豆”；304“商店停業中”；305“銀行停業中”；24“獲得”。
// 前两种货币命名来自消费字段与提示资源共同佐证，不能把点券/金豆都泛称现金。
// .ui每字节减RichNet循环密钥再模256；KPD先解头和载荷偏移，再LZO安全解压。
// 本次资源转录使用CP950 strict；Intf.kpd用GBK strict。客户端实际仍依赖CP_ACP路径。
// inspect_shop_resources.py保存原文件与解码后SHA256，只输出本专题，不回写资源。
