// 4030 / 6609B0：先同步商品，再决定界面与等待
// 64F710比较record+2 WORD与G+83844 WORD；失败弹Error GmsvID并返回，不继续交易。
// 810170将record+4起72字节memcpy到G+0xC84，即12槽；不校验ID/数量或长度。
// record+76==0：本地行动者显示UI20，期限10000；通知载荷mask=3、force=0；
// 再调用7125B0(1)启用卡片栏。所有客户端设置pending19、duration10000。
// record+76!=0：仅本地行动者通知UI20(mask=0,force=1)，再650110扣本地金豆。
// 此分支不打开新窗口、不重设pending、也未重置UI显示期限。
// force字段为BYTE；mask是DWORD；694080初始化这五字节为0。
// 不能据4030存在就认为它一定建立新商店等待；+76决定两种不同路径。

// 0030 / 7BC050：购买或退出请求
// +0 WORD=0x0030，由7D6020构造。
// +2 WORD=DWORD[G+0xC48]低16位；经G+0xC44及63E440读取。
// +4 BYTE=选择，0..11表示商品槽；0xFF表示取消。+5无业务显式写入。
// 原局部用0xCC填充，提交6字节；不要规定+5必须为零。
// 63F760仅在当前行动槽==本地槽时允许提交6BF380；提交不代表TCP已发或服务端接受。
// 整数实参严格等于-1时，在提交后关闭UI20；这个包装器不清pending。
// 购买按钮本地比较点券>=属性价格，再7F8E70确认8个库存槽中存在ID=-1。
// 不足点券提示181；无空槽提示182；通过后才发0030(slot)，并禁用商店操作。

// 4031 / 660B00：购买成功分支
// 核验GmsvID后读取record+4为signed BYTE；没有再次核对pending19或商品槽范围。
// choice!=-1：6940E0读取S+6*choice的signed WORD物品ID；
// 694110读取S+6*choice+2的signed WORD数量；6940B0按物品ID取属性+60价格。
// 7F8780(P,id,count)找group0第一个ID=-1的空槽并写入ID和数量。
// 接着7F9D70(P,price,0)扣一次价格；没有乘以商品数量，也没有检查7F8780返回值。
// 8101A0清商品槽ID=-1、数量=0，其余两字节不写。
// 本地行动者通知UI20(mask=2,force=0)刷新点券，并经6E4440重新启用UI20。
// 购买分支不清pending19，也不插入6080；玩家可继续交易，退出才继续落点。

// 购入不是简单写数组
// 7F8780成功插入后调用800FD0，可能按配方自动替换库存，再刷新本地UI12并显示合成提示。
// 800FD0遍历60字节配方，+56为启用字节，+48为要求条数，+52为结果物品ID；
// 匹配8槽中相同ID的槽数，而不是把每槽quantity累加。替换匹配槽后结果数量设1。
// 其资源约束和结果许可谓词仍为局部分析；不宣称全部配方和零要求条数均已验证。
// 7F8780末尾若P+1416非零会返回1；因此返回1也不能单独证明刚插入了新槽。

// 0031 / 711C80商店点击：出售
// 卡片栏通知发现UI20显示后设置W+72；左键枚举1、栏位可用且group==0时构造0031。
// 7281F0只写WORD=0x0031；+2身份来源同0030；+4 BYTE是卡片控件ID即库存槽。
// 提交6字节；+5仍没有业务显式写入；随后712610(0)禁用/复位卡片操作链。
// 这里不能用商品列表的1..12按钮ID；卡片栏控件为0..7。

// 4032 / 660CB0：出售回复
// 核验GmsvID，record+4 signed BYTE指定当前行动角色的group0槽。
// 先7F86A0读取ID、7F8710读取该槽全部数量；价格=属性+60 DWORD。
// 660D55执行SAR EAX,1，得到有符号算术右移的半价；不是无符号除法。
// 7F8920减去刚读出的全部数量；写WORD并signed比较<=0时置数量0、ID=-1。
// 7F9D20增加半价点券；没有乘以被移除数量。
// 本地行动者刷新UI12、启用卡片栏、通知UI20(mask=2)刷新点券并启用商店。
// 无清pending或继续阶段；交易仍在本次商店等待之内。

// 0035 / 715C80按钮15000：付费刷新
// 728360构造WORD=0x0035；+2身份同前；提交4字节，没有刷新次数或金额字段。
// 提交后禁用按钮，并将W+720的本次窗口请求计数加1；小于5还会禁用整个窗口。
// 刷新回复4030的force=1触发完整商品绘制；其中重启用根控件，按金豆/限制重算按钮。
// 650110从DWORD[G+1536+4*localSlot]扣DWORD[A87490]，再发本地通知41并刷新UI1。
// 该减法不检查是否已扣、是否负数或是否在商店等待；不应用重复回复模拟重试。
// A87490只证实为共享花费源；IDB无原始磁盘区间，本篇不提供固定运行时金额。

// 相邻弃卡链：0032 / 4033，不是出售
// 710D60在主状态2、左Ctrl未按、Shift保持、未选槽、栏位可用时检查F1..F8释放。
// 存在group0物品时经7280F0发送0032(slot)，6字节，并712610(0)。
// 该提交分支不以UI20显示为必要条件；普通无Shift的选卡路径才检查UI20未显示。
// 4033/660E30移除+4指定槽全部数量，不增加点券；+5经63E560与本地槽比较，
// 且本地是当前行动者时才刷新并恢复卡片操作。本篇不展开UI22确认窗口。
