// 候选扫描
//   在当前IDA已定义函数入口0x620000..0x900000内，查找
//   mov word ptr [寄存器/表达式], 0x6000..0x6090形式的立即数写入。
//   当前66项都是短thiscall构造：ECX存入局部，取回寄存器后对this写固定默认值。
//   已人工核对伪码与完整汇编；build_dictionary.py再将固定DEFAULTS逐项对照指令。
//   导出不对IDB改函数名、类型或注释，不创建缺失函数定义。
//
// 调用映射
//   从实现入口反查xref；遇E9跳板递归反查，直到直接call站点。
//   每个site保存opcode、constructor、真实被调用target及所属caller。
//   没有间接调用数据流恢复，不声称1351站点是所有可能运行调用的穷尽集合。
//   273调用函数完整chunks保存在callers.json，跳板单独保存、逐PE核验。
//
// RTC容量
//   仅匹配构造call前紧邻lea ecx,[ebp+负偏移]。
//   在同函数RTC_CheckStackVars前恢复EDX指向的描述头：DWORD数量、DWORD条目指针。
//   每条描述12字节：signed栈偏移、DWORD容量、名称指针；以偏移严格等值对应。
//   描述头、全部条目及名称原始字节都保存到contract_links.json/metadata_ranges。
//   未登记或无法对应时留未知，不采用Hex-Rays数组容量作为替代。
//
// 入队前缀候选
//   一种模式：同一直线片段后出现64FA50调用，Src的lea偏移与构造对象相同，
//   倒数第二个push为立即Size。遇另一构造、分支或返回即停止，不跨基本块猜测。
//   另一种模式：Size在构造前压栈，构造返回this，立即push EAX、恢复ECX再调用609D34。
//   对象地址/Size/调用site均可回到callers.json逐条审阅；保留“候选”名称。
//   当前同时得到RTC和入队候选的站点，容量与Size未出现不一致。
//   其它36个站点只留下构造及RTC事实，不宣称没有入队操作。
//
// 验证命令
//   在Richonline目录执行：
//   python -X utf8 docs/逆向资料/专题/本地消息构造契约/build_dictionary.py
//   验证器只读当前EXE与原证，重建本专题字典/导航/JSON清单/验证结果。
//   对每个代码chunk、E9跳板、RTC元数据用PE节表映射到当前文件并比较全部字节。
//   任何版本差异、无原始映射或默认写入不符都会终止，不能宣称验证通过。
//
