// URL 对象：字段、生命周期与一次读取
// ============================================================================
// 所有偏移均为字节；R 为传入 ECX 的对象地址。
// R+0       DWORD：InternetOpenA 会话句柄。
// R+4       DWORD：InternetOpenUrlA 请求句柄。
// R+8       256 字节：HttpQueryInfoA 的目标缓冲。
// R+264     DWORD：正文缓冲指针。
// R+268     DWORD：正文缓冲容量。
// R+272     DWORD：先写查询所得长度或默认估计，随后写实际读取字节数。
// 已见字段跨度至少 276 字节；未由分配现场证明精确类尺寸。
//
// 生命周期
// ----------------------------------------------------------------------------
// 81E0C0 只清 R+264、R+4、R+0；不清容量、读数或查询缓冲。
// 81E130 清五个 DWORD 后 InternetOpenA(NULL,0,NULL,NULL,0)，返回句柄非零。
//   本体没有先释放原资源；若对仍持有资源的活对象重调，存在丢失保存句柄
//   与缓冲指针的条件路径。未确认有此调用序列，不宣称已发生泄漏。
// 81E100 保存并恢复 ECX，再经 60AE82 -> 81E1C0 清理；伪码漏掉 this，
//   依据汇编 81E10B..81E111，不能把它解释为无对象的全局清理。
// 81E1C0 删除正文缓冲并清零，清容量与读数，依次关闭请求和会话并清零。
//   无句柄时返回寄存器值可为对象地址；有句柄时受最后关闭调用影响。
//   不能将反编译 BOOL 返回类型当作统一成功契约。
// 6B7610 返回 R+272；6B7640 返回 R+264。IDA 的 MFC 库匹配名不证明
//   它们属于 MFC 日期对象；实际语义依字段和消费者调用位置判定。
//
// 81E290：参数 (URL, 保存标志BYTE, 可选文件名指针)
// ----------------------------------------------------------------------------
// 保存标志非零时才准备文件名。文件名指针非 NULL 就直接 strcpy；
// 即使它指向空字符串也走该分支。NULL 才从 URL 末尾倒找 '/'，随后复制
// 斜杠之后的文本。目的局部数组260字节，未见复制上限或倒找下界。
// 不把 NULL 与空字符串混同，也不宣称 URL 解析、解码或文件名清洗。
//
// InternetOpenUrlA：会话取 R+0；headers、headersLength、flags、context
// 均为零。返回值写 R+4，零则返回0。旧请求句柄未在本体开头先关闭。
// HttpQueryInfoA：infoLevel=5，缓冲 R+8、容量256，index初值0。
// 查询成功经 atoi 写 R+272；失败用 0xFA000，即1024000。
// 81E3F6 为 jbe：估计长度与容量做 DWORD 无符号比较，不能照伪码当作
// signed int 比较。估计大于容量时删除旧缓冲，按估计值精确分配，
// 没有额外的终止NUL空间。本篇不认领分配器失败或异常完整语义。
//
// 81E48E 只有一次 InternetReadFile：请求R+4、缓冲R+264、读取上限R+268，
// 实际读数输出到R+272。返回零则返回0；非零继续，没有循环读到EOF。
// 本体没有检查HTTP状态码，没有比较实际读数与先前估计，没有追加NUL。
// 实际读数为0也可沿正常末尾返回1；大厅消费者另有非零门控。
//
// 保存标志非零时 fopen(filename,"wb")；失败返回0。随后写
// fwrite形态的四参数助手60FEAF -> 9243E0(buffer, 实际读数, 1, stream)，
// 再 fclose；两者返回值未用于门控。9243E0本体内部未审，不认领其完整
// CRT写入或异常契约；这里只确认参数形态和调用方忽略返回值。
// 末尾返回1。因此该返回值仅说明本体通过了显式失败分支，不能证明
// 完整正文、业务可解析、无磁盘错误或持久化成功。
// 请求与会话由后续清理释放；早退分支未就地关闭已取得请求句柄。
//
// 证据边界
// ----------------------------------------------------------------------------
// API 名称由磁盘导入表复算：AD4004 InternetOpenUrlA，AD4008 HttpQueryInfoA，
// AD400C InternetReadFile，AD4010 InternetCloseHandle，AD4014 InternetOpenA。
// IDB 导入槽 DWORD 与磁盘不一致，不用于证明业务字节或版本一致。
// 原证保存了本体完整声明块和桥；不访问 URL，不抓包，不断言实机错误。
