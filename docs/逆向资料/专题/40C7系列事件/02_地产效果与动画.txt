// 地产记录和动画底层
//
// 地产条目以 68 字节为步长，G+65C 的对象持有地产表指针：
//   +0 BYTE：地产类别；+1 BYTE：建筑/设施类型；+2 signed BYTE：楼层；
//   +6 signed WORD：街道组；+28 DWORD：图像句柄。63F290 判断楼层为 0，
//   63E2D0 判断类别为 12，63F2D0 写入类型字节。
//
// 7E3F30（6114D0）把 +2 按 signed BYTE 增量，模式 63E160 或 63E990 为真
//   时上限 7，否则上限 5；返回值表示是否到达对应上限。它不负责写图像。
// 7E4020（60244E）按增量减少楼层；降到 0 后，类别 11 把类型写 0；其中
//   原类型为 1 且 owner!=-1 时先调用 604F55/5FFFDC。类别 12 把类型写 -1。
//   三谓词分别为 63E290/63F500/63EC30；附加清理的全部副作用仍未闭合。
// 7E73F0 通过 607084 后：楼层为 0 写图像句柄 -1；有主特殊地产按
//   60D46B/608452 选子图 0 或 1；普通地产使用楼层-1；图像由 60F3B5 生成。
//
// 天使卡遍历：7E37B0 把地图 this+0x38（+56）的地产表及 street 放入上下文，调用
//   7ECFD0；回调 7E3670 对 +6==street 且 +2<5 的条目执行条件升级，然后
//   608F51 刷新该地产。其它类别不改楼层但仍走刷新；这里使用街道组筛选。
//
// 开路动画 20：虚表 A2C0E0，634550 启动、6347D0 tick、634780 结束。
//   对象至少 96 字节；+52..+61 保存十个方向，+64 步号，+68 tile，+72方向，
//   +76帧，+80 tick，+84累计距离，+92完成标志。横向 64、纵向 48 像素走完
//   一格后通过 7E1580 调方向邻居 getter；每格若 63EB50 为真则 7E28B0 清理。
//   结束函数在未完成时调用 634B00，从当前角色位置重新按十步清理，保证超时
//   收尾。6347D0 汇编在步号达到 10 时写 done=1、EAX=1；否则返回 0，
//   反编译的 void 名称掩盖了这个完成返回值。
//
// 建屋动画 21：虚表 A2C0F0，634BB0 启动、634D20 tick、634CF0 结束；
//   +12 tile、+16 资源句柄、+20/+24 坐标、+28 tick、+32 done。tick 达到
//   1000ms 调一次 634DA0，结束路径在 done=0 时补调用。
//
// 核子飞弹动画 22：虚表 A2C100，635030 启动、6351C0 tick、635170 结束；
//   +12 attacker、+16 target、+20 飞弹图、+24/+28 坐标、+36 step、+76 delay、
//   +80 state、+84 applied。落点后换爆炸图，500ms 后且未 applied 时调用
//   635610；结束路径同样补调用。635610 的完整模式、防御和金额依赖另行审阅。
//
// 动画管理器 7A6030 将动画编号映射到工厂：动画 19 使用 A2C0D0，20 使用
//   A2C0E0，21 使用 A2C0F0，22 使用 A2C100；7A5C30 按槽创建对象、调用
//   虚函数、记录 GetTickCount，并把槽置为 active。虚表首三项已与当前 PE
//   字节核验；634280/634420 两段动画 19 代码未被 IDA 声明为函数，必须按
//   范围原证引用，不能伪造函数边界。
//
// 动画 5：6307D0 复制 5 DWORD 上下文；type1 分支把 street、owner 和 flag

//   字段不参与筛选，因此共享上下文未写+12不等于本次读未初始化值。
