// 40C7—40CF 卡片效果回复专题
//
// 研究对象：当前版本 RnClient.exe 的 0x40C7 至 0x40CF 事件回复。
// 这些入口均由 0x4000 消息分派桥接到 672020、6722C0、672600、672850、
// 672AE0、672D90、6730A0、6732B0、6734C0；桥接只转交一个 32 位指针，
// 不在桥接层读取网络长度。本文把“消息回复”和“本地动作记录消费”分开。
//
// 40C7 涨价卡：读取当前角色所在地产，转成街道组，写入街道收费效果。
// 40C8 天使卡：读取街道组，播放街道升级动画，随后逐项提升该街道建筑。
// 40C9 同盟卡：读取当前角色和目标角色槽位，建立双向同盟记录。
// 40CA 开路卡：解压 10 个两位方向值，播放清路动画并清除沿途效果。
// 40CB 建屋卡：读取地产位置，等待建筑动画，调用模式相关的升级/建造逻辑。
// 40CC 核子飞弹：+9 标志决定完整流程或简化流程；该分支的上游用途仍待核。
// 40CD/40CE/40CF：把研究所、贸易中心、饭店类型写入地产记录并刷新图像。
//
// 当前结论是客户端本地状态和界面回复证据，不等价于服务端权威规则。
// 资源描述中的 3x3、5x5、2 天、1500 等文字只作为版本资料，不替代 635610
// 中实际的模式分支和防御谓词。未命名函数、未映射全局和未闭合网络上行均保留为未知。
//
// 证据目录：
//   handlers.json             九个 40C7—40CF handler 及其桥接调用。
//   direct_dependencies.json  地图、角色、地产、记录构造依赖。
//   local_consumers.json      600x/607x/606B/6079 等记录消费者。
//   animations.json           动画 4、5、19、20、21、22 的已声明函数。
//   animation_effects.json    动画结束时的地产、路面和核爆效果函数。
//   property_core.json        地产记录、升级、拆除和街道遍历底层证据。
//   visual_and_gate.json      动画工厂、构造、显示标志及操作资格门。
//   predicates.json           类别 11、子类型 1、owner 有效三个独立谓词。
//   function_review.json      107 个唯一已声明函数逐项结论和分析状态。
//   undeclared_ranges.json    三段无 IDA 函数声明的动画范围原证。
//   binding.json/data_audit.json 注册、虚表与共享上下文的字节核验。
//   resource_semantics.json   1058—1066 道具与动画资源原文提取。
//   export_evidence.py        当前 IDA 只读取证，可复跑函数与附加范围导出。
//   build_review.py/validate.py 人工审阅清单生成及静态校验，结果见 validation.json。
