// ============================================================================
// 0x4044 | 字段、处理与注册
// ============================================================================
// 入口：0x662B20；直接读取范围为 record[0..5]，所有多字节字段按小端解释。
// +0 WORD：记录类型 0x4044；分派器依据此字段选择处理入口。
// +2 WORD：GmsvID；0x64F710 与 G+0x14784 的 WORD 比较。
// +4 signed WORD：目标逻辑格位；0x662B63 使用 movsx 扩展为 32 位。
// 此布局描述处理器最低直接读取范围；网络层的帧头、校验与实际长度须另查。
// 本入口和桥接没有局部长度参数校验；不要把“最少读 6 字节”写成所有外层校验都存在。
//
// 处理顺序
// ----------------------------------------------------------------------------
// 1. 0x662B52 -> 0x607A2F -> 0x64F710：校验 +2 GmsvID。
//    不一致时 MessageBoxA 显示 Error GmsvID，并返回假；入口跳到退出位置。
// 2. 读取 G+0xE28 当前槽，再从 G+0xE00+4*槽取得 R。
//    本入口没有角色槽字段，不根据记录 +2 选择参与者。
// 3. 0x662B7A -> 0x60FFD1 -> 0x63E410：返回 R+0x5B8 的 DWORD 格位。
//    0x662B7F 比较目标 signed WORD 扩展值与此 DWORD；相等直接退出。
// 4. 不相等时，0x6942C0 在临时缓冲区 +0 写 WORD 0x4044。
//    紧接着 memcpy(temp, record, 6) 覆盖整个临时记录，原 +2/+4 均保持不变。
//    因而构造器先写的类型不能被解读为“重新生成了新的目标格或 GmsvID”。
// 5. 0x63E5B0 -> 0x63F940 读取 Q+0x0C 的当前 head。
//    0x64FA50(temp, 6, head) 以 Q=G+0x640 调用 0x6980F0，returnMode=1。
//    指定 head 插入会让该记录成为下一条，入口不使用插入函数返回的后继游标。
//
// 栈缓冲区：以 RTC 描述为准
// ----------------------------------------------------------------------------
// 0x662BD6 的 RTC 表：一个变量，描述位于 0x662BDE，栈偏移 -0x14，容量 6。
// 0x64FAE8 的 RTC 表：一个变量，描述位于 0x64FAF0，栈偏移 -0x12C，容量 0x120=288。
// 0x64FA50 先按调用者 Size 复制，再用 rep movsd 传递 72 个 DWORD 的完整内部槽。
// 4044 此处传入 Size=6，未写入的槽尾仍保留调试初始化值；尾部不是额外业务字段。
// 伪代码出现 v5[3]、v5[74] 或几十个参数，是栈分配/按值记录恢复的表现。
// 不能据这些数组数字把 4044 临时记录写成 12 字节，或把插入缓冲区写成 296 字节。
// 0x64FA50 本身未先检查 Size<=288；这里只确认 4044 的 6 字节调用不超过该容量。
//
// 注册链与分派表
// ----------------------------------------------------------------------------
// 0x7EE5DB：mov DWORD[0xA9E1F0], 0x60B1C5。
// 0xA9E1F0 = 0xA8E0E0 + 4*0x4044，与 0x7BB290 的按类型索引访问一致。
// 0x60B1C5 是 E9 跳板，目标 0x7EFF30；桥接把 G 与 record 指针交给处理器。
// 0x7EFF3A -> 0x60A469 -> 0x662B20，record 指针未被转换为另一种布局。
// IDA 当前读槽为 0xFFFFFFFF；此地址没有对应磁盘原始节字节，不能据此推断启动初值。
// 本专题确认的是注册写入与桥接链，没有观测运行时表槽。
// 0x64F870 对 4044 不走其即时处理分支，而走默认的游戏队列记录复制路径。
//
// 原始证据
// ----------------------------------------------------------------------------
// 证据/check_entry.json：入口完整指令、调用解析与字节范围。
// 证据/check_helpers.json：GmsvID、格位 getter、head 包装、插入包装、4044 构造器。
// 证据/check_layout_and_registration.json：RTC 原始数据、注册写入、跳板与调用点字节。
