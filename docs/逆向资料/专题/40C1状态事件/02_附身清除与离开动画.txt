// 6050 · 67F680；附身状态与动画3
// ============================================================================
// 6050使用record+2 signed BYTE选择P(target)。ECX由G+0xE00数组取得。
// 693E80先读signed BYTE[P+1488]，保存为old；然后7F7D50原地写：
//   P+1488 BYTE=-1，P+1489 BYTE=-1，P+1490 BYTE=0。
// 原证只确认这组三字段与附身离开链相关；不把后两字段擅名为所有完整规则。
// 7F7D50还按7016B0门条件调用7FDBA0：检查P+1740为正后清该DWORD。
// 未清P+1744；附属值的产品含义仍未知，详见神明附身与元数据专题。
//
// 界面与动画
//   用old查询72字节元数据行名称，拼接RichStr15“離開”。
//   UI4显示1800ms并交文本；64FB10记录1800等待，声音入口使用编号103。
//   xAnim003为8B：DWORD[0]=target，DWORD[1]=old。
//   7A5C30以动画号3启动，将这份参数传到动画对象虚表+0。
//   6947C0判old属于{1,2,6,7,18}时，另排6002(type3,target,+6=1,+8=1350)。
//   6079B7 -> 693260构造6002；它与入口6007的构造器6944A0不同。
//   67D880先设置目标动作，再以P(target)+40!=-1为UI/声音/等待整段门。
//   门通过且+6非零才用+8写1350等待；+8为0才回退1800，并非无条件等待。
//   本机目标且old==4或6时，还按7FB150条件向UI1交DWORD1。
//   这些额外资格/界面效果保留局部范围，不因资源名称推定完整神明机制。
//
// 容量
//   67F89C RTC：szTmp为128B，xAnim003为8B，后继xPack为12B，xZy001为8B。
//   伪码Buffer[132]包含邻接区域，不能称本地字符串容量132B。
//
// 动画3对象A
//   工厂7A66E0分配0x1C；构造7AA1D0写虚表A2BFE0。
//   虚表启动605739 -> 6304B0，结束60E825 -> 63E6A0，更新600C11 -> 630580。
//   +0x04 DWORD：内部节流阈值；启动写16。
//   +0x08 DWORD：内部节流起始tick，81BCB0写GetTickCount。
//   +0x0C DWORD：x=P(target)+540的值 -16 - 镜头signed WORD x。
//   +0x10 DWORD：y=P(target)+544的值 -96 - 镜头signed WORD y。
//   +0x14 DWORD：步长6。
//   +0x18 DWORD：72字节元数据行+40的图像编号；行索引来自old。
//
// 630580每次先调用绘图入口，再检查A+4计时器。
// 81BD10要求now>start且now-start>=16才通过；通过后重写start。
// 门通过时y-=6，最终返回y<=0作为动画完成布尔值。
// GetTickCount回绕和低帧率不能用理想16ms公式证明准确动画总时长。
// 管理器还有配置time=2000ms的计时门；其调度契约见角色与精灵动画专题。
// 本篇只确认更新返回条件，不宣称只由y决定全部动画生命周期。
//
// 对故障定位的意义
//   状态三字段在启动动画之前已清，不等待630580返回true。
//   目标有效性、old元数据值域、资源可绘制性均依赖上游，不在这里补校验。
//   本组启动/更新/空结束未直接发网络包；后继网络时序尚未实机验证。
