// 40C1入口 · 66FC80
// ============================================================================
// 注册：7EE923把603A2E写入A9E3E4；603A2E -> 7F09B0。
// 桥接：ECX=首个G参数，push第二个输入指针，61071F -> 66FC80。
// 处理器66FC80以retn4返回；桥接7F09B0自身以retn返回，调用方清两参。
// A9E3E4是运行时分派槽；不把当前IDB观察值当作磁盘初值。
//
// 输入读取前缀
//   +0 WORD：40C1登记码；入口本体不重新比较它。
//   +2 WORD：GmsvID，由64F710与WORD[G+0x14784]比较。
//   +4 BYTE：扣除库存槽；进入6061后movsx为signed BYTE。
//   +5 BYTE：库存组；进入6061后movsx为signed BYTE。
//   +6 BYTE：目标角色slot，入口使用movsx取P(target)。
//   最高读取到+6，最低读取前缀7B；不等于已经证明线协议固定长度7B。
//   本体未检查target值域、P非空、库存槽/组及外部消息长度。
//
// 本地构造顺序
//   6007：12B；+2 WORD=47，+4 BYTE=current，+5 BYTE=0，+8 DWORD=0。
//   6003：24B；+2 WORD=4，+4 BYTE=1，+5 BYTE=0，+6 BYTE=1。
//          +8 DWORD=1350，+12 DWORD=1000，+16指向A7C140，+20 DWORD=128。
//   6050：4B；仅当P(target)+1488 != signed -1时排入，+2 BYTE=target。
//   6061：10B；+4 BYTE=current，+5 BYTE=input[4]，+6 BYTE=1。
//          +7 BYTE=input[5]，+8 BYTE=0，+9 BYTE=1。
//   6006：4B；仅当current==local时排入，+2 BYTE=1。
//
// 这些是内部记录复制跨度，不能用作网络回复长度。
// 63E5B0取得插入位置，64FA50逐次返回新的位置以保持本组事件顺序。
// 本组未直接调用6BF380，也没有6005或6080构造；后续服务端推进另需取证。
//
// 文案顺序
//   66FD4C调用sprintf到共享全局A7C140（66FD47压入缓冲地址）：
//   RichStr41 + P(target)+112名字 + 两次换行 + RichStr40 + Prop1048名称。
//   结果形如“對<目标名>\n\n使用送神卡”。
//   63E1C0只返回P+112，不以其IDA的MFC库名命名业务。
//   +20的128不是本篇确认的A7C140容量；67DA40也未读取该成员。
//   sprintf本身无长度参数；实际字符串上限和全局缓冲总容量仍未知。
//
// RTC校正
//   66FE6F的5项：EBP-28/12B、-60/24B、-72/4B、-92/10B、-104/4B。
//   对应6007、6003、6050、6061、6006；容量不是伪码拆分数组显示的大小。
//   整片栈先填0xCC；构造器仅初始化已见字段，不把尾部/保留字段称清零。
//   6061的+2 WORD在扣除路径不消费，因此未写不等于此路径有未初始化ID。
//   6007的+6/+7、6003的+7、6050/6006的+3均不能凭复制跨度补成0。
//
// 等待边界
//   6003 +6=1会调用64FB10，以1000写入消费等待字段并记录起始tick。
//   6050另写1800等待；不能把两次等待简单相加为固定整条事件时长。
//   64FA50的队列容量/失败、动画消费者与操作门均见各专题，未实机闭环。
