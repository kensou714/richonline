// ============================================================================
// 图像缓存 / 6DC090的真实筛选与循环
// ============================================================================
// 字段沿用已证图像管理器布局
//   +240652 +4*slot：图像指针。
//   +480652 +4*slot：使用计数字段；绘制包装有递增路径。
//   +600652 +slot  ：单字节状态，完整业务命名仍未知。
//
// 第一遍统计
//   遍历slot=0..29999，统计图像指针非空的loaded。
//   后续固定执行floor(loaded/4)轮；每次释放后不重新计算目标轮数。
//
// 每轮选择
//   局部比较阈值置FFFFFFFFh，候选slot置0。
//   再遍历全部槽，要求图像非空、使用计数unsigned<FFFFFFFFh、状态byte==0。
//   符合条件时只覆盖候选slot，没有把阈值更新为该槽的计数。
//   结果总是本轮最后一个合格slot；计数只排除FFFFFFFFh，不实现最小计数排序。
//   6DC15F/6DC162使用cmp+jnb，不能把伪码中的!=-1误解为有符号大小关系。
//   遍历结束后调用6DC310释放候选；释放实现由图像资源专题负责。
//
// 失败边界
//   没有任何合格槽时仍调用6DC310(0)，可能针对受保护状态的槽0继续尝试释放。
//   不先验证是否选中过，不把“循环完成”作为成功释放四分之一图像的证明。
//   每轮完整扫描30000槽，静态工作量约30000*floor(loaded/4)。
//   本函数未显式获取锁；被调单槽释放有锁不等于整个扫描/选择原子化。
//   使用计数字段、byte状态及实际回收调用点必须联合考虑，不能独立实现成LRU策略。
//
// 内容工具价值
//   编辑器可显示槽号、是否加载、使用计数和状态byte，保留未知含义原值。
//   资源替换和缓存释放是不同操作；本函数没有读取修改时间、替换映射或重新解码。
//   未证明客户端存在通用热加载支持，不应以调用这个函数作为热更新完成标志。
