// 帧控制 / 原图透明位图
// ============================================================================
// 运行时槽不等于NP文件编号
//   manager+240652保存30000个图像对象指针；图像+144帧数，+148当前帧。
//   映射记录的NP编号与运行时槽是不同域；图像名称又经6DAA10解析，见04。
//
// 6DCBA0 / 到达末帧
//   槽对象非空且currentFrame==frameCount-1时返回真，否则假。
//   不要求frameCount>1，不检查slot范围；单帧图像的第0帧也满足条件。
//   不表示动画已经停止，也不锁住末帧；绘制时推进动画的逻辑在813E70。
//
// 6DCC00 / 重置帧号
//   已加载对象存在时只写+148=0，不重置+152上次切帧时间，不改帧时长。
//   不触发加载、不校验slot；返回寄存器残值不是稳定的重置成功协议。
//   因而“重播”调用不能据此保证第一帧重新停留完整duration毫秒。
//   当前813E70原证复核：先推进至多一帧，再检查全局就绪及对象+173是否允许绘制。
//   即使裁剪不可见，时间达到阈值也能推进帧号；结束固定置+173=1。
//   可选参数为前/后回调指针对；只有进入绘制分支才调用它们。
//
// 6DCC40 -> 6DFB40 / 读取透明位
//   外层只判断slot对象非空；不触发加载，不校验slot、x、y或掩码指针。
//   pixel = x + width*y按x86低32位计算，byteIndex=pixel算术右移3，bit=pixel&7。
//   从image+164指向位图读取byte，并返回该byte & (1<<bit)。
//   非0结果可为1/2/4/.../128，外层再归一成bool。
//   width来自完整DWORD image+16；伪码位表达式中的BYTE只反映低3位等价优化。
//   位为1表示原NP解码判为透明：来自图像资源专题的置位写入证据。
//   首帧位图不会跟随当前动画帧改变；不能把当前帧的alpha图直接替换作此契约。
//   未做缩放、旋转、镜像或屏幕坐标逆变换。消费者需要提供原图局部坐标。
//   负坐标可产生负byteIndex；x超宽可能借位到下一行，不能当自动裁剪。
//
// 6DFA80 / 已有入口范围检查的边界复核
//   汇编分别使用jl拒绝index<0，jg拒绝index>30000；可接受0..30000。
//   真正表容量是30000项，合法元素0..29999；index==30000会通过检查。
//   部分帧/命中接口完全绕过此检查，不能宣称整个图像接口均有上界防护。
//   本专题复核入口边界，不把旧已审函数重新算作新增完成。
