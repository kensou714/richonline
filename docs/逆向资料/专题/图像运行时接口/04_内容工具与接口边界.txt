// 6E5100 / 6E5160的命中包装
//   输入x/y各减1，再将负结果归0；没有上界裁剪。
//   6E5100第三参数为运行时槽；6E5160第三参数为名称字符串，由6DAA10解析。
//   IDA的int参数及CFile::GetFilePath名称均为误导性推断；不能据此解释成文件路径。
//   两者取反6DCC40的透明判断：透明返回false，非透明返回true。
//   在有效槽内，槽对象为空时6DCC40返回false，所以包装会返回true；未加载不等于无命中。
//   6E5160不另行拦截解析失败的-1；这条错误路径不具备安全槽访问或false返回保证。
//   编辑器若要精确复现必须记录这一兼容差异；安全预览可以明确拒绝未加载对象。
//
// 6DAA10 / 名称解析到映射入口
//   前缀和参数数量：road=2、thing=1、event=2、build=3、vehicle=3、role=3，
//   npc=2、fx=1、mood=2、card=1、other=2、extend=1；字段用下划线分隔。
//   按此顺序把类型0..11及atoi整数传给6DBA40，未使用的参数传-1。
//   空指针、空串返回-1；首段成功提取后未知前缀返回-1。
//   等待下划线的循环没有同时检查字符串终止符，缺分隔符不能保证安全失败。
//   局部文本复制没有容量检查，atoi也不是严格数字验证；工具应拒绝缺字段/超长输入。
//   本专题审阅解析分支；6DBA40的完整类型表和槽分配规则仍是既有映射研究的边界。
//
// 回收和内容替换
//   6DC090按当前条件选择最高合格槽，不是最少使用计数；无候选仍选择槽0。
//   7A3B00中的周期片段在间隔>1000毫秒且条件函数AL为0时触发该回收。
