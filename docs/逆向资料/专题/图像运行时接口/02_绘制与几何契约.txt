// 几何布局；偏移均为图像对象内字节
//   +16/+20：原图宽高DWORD。+24/+28：裁剪UV比例所用横纵范围float。
//   +32..63：四顶点xy。+64..95：当前UV。+96..127：裁剪所读基础UV。
//   +128..143：四个DWORD颜色。+168：镜像模式；完整枚举尚未闭合。
//   +172：启用矩形裁剪。+173：本次可上传/绘制。不要合并这两个byte。
//   818BC0/818C40写读+172；818BE0/818C00写读+173；非拥有型薄接口。

// 入口层
//   6DFAD0读取manager+630756中指针所指BYTE，调用者据AL决定是否继续。
//   这里没有空指针检查；它不是manager+630752的资源包标记。
//   该指针的初始化位置和所有权尚未展开，“就绪”是消费门槛描述而非正式字段名。
//   6DC650：检查就绪及槽范围，按需加载，整数矩形转float，调用814320。
//   6DC730：同样检查并按需加载，调用814120，使用现有图像位置。
//   两者在调用绘制后递增使用计数，未按设备绘制成功与否决定递增。
//   成功路径返回slot原值，slot=0时仍返回0；不能把返回值统一解释为成功bool。
//   6DCD60：按需加载后重建原图矩形；6DCDD0：按需加载后绕整数支点旋转。
//   后两者没有同样的就绪检查，也没有前两者的使用计数递增。
//
// 矩形和顶点
//   813410将原图宽高转float，构造(0,h),(0,0),(w,h),(w,0)，并置+172=1。
//   814320使用外部left,top,right,bottom；814120使用对象已有顶点矩形。
//   两入口先置+173=1；+172非0调用814400裁剪，再进入813E70绘制。
//   不启用裁剪时，814320直接设置(left,bottom),(left,top),(right,bottom),(right,top)。
//   8134F0比较四顶点；无变化直接返回。+173=0时只更新CPU侧位置。
//   +173非0时锁定顶点缓冲，成功才同步CPU字段和设备xy；失败两者均不更新。
//   8136D0和813810分别比较并更新颜色、UV；都不检查+173，锁定失败不更新。
//
// 814400 / 裁剪边界
//   裁剪区来自全局指针ABA7B8。重叠条件为：
//     top<clip.bottom && right>=clip.left && bottom>=clip.top && left<clip.right。
//   无重叠置+173=0，仍将原矩形位置写入CPU字段；这不是删除图像。
//   有重叠时依次裁bottom、left、top、right，直接修改传入矩形。
//   有帧纹理数组时，先复制+96基础UV，再按原矩形宽高和+24/+28比例调整UV。
//   模式0修正横向UV，模式1修正纵向UV；不据此给所有其他值命名。
//   没有明确的零宽/零高除数保护；混合严格/非严格比较允许某些接边退化矩形。
//   全局临时矩形和UV被复用，函数内没有锁；编辑器不能假定可跨线程重入。
//
// 813B20 / 旋转消费与矩阵分派边界
//   输入角度乘pi/180，四顶点减支点进入全局临时数组，经矩阵调用后再加支点。
//   末尾8134F0设置顶点，并清+172以禁用轴对齐矩形裁剪；它不改首帧透明掩码。
//   818C20只是返回ECX原值，不是初始化16项单位矩阵的函数。
//   95E781、95C7EB间接调用A6AB00/A6AB74。磁盘槽分别指向5FF055/6106E3，
//   两个E9又指向95E75E/95C7D6；后者调用977A09(1)初始化后重试同一槽。
//   因而不能把磁盘默认槽循环解释为真实旋转或向量变换算法。
//   977A09首次复制284字节分派表，再调用9804E5，依据配置及CPU能力可改用其他表。
//   这些表填充实现未展开；实际矩阵约定、方向、归一化及运行态选择保留未知。
//   已确认角度和支点的数据流，不宣称完整D3DX数学库语义已闭环。
//
// 无纹理几何
//   6DC7D0把整数矩形转float，814930先给全局图像ABA790设置四顶点颜色再绘制。
//   6DC850写两顶点xy和颜色，调用814EC0；顶点数2、索引数2、图元类型2、图元数1。
//   6DC8F0每轮画左、上、右、下四边，随后left/top加1，right/bottom减1。
//   厚度<=0不画；没有检查线框缩到反向矩形的情况；内部使用全局管理器。
//
// 设备缓冲包装；814970 / 814C10 / 814CD0
//   16字节包装含：+0顶点缓冲接口，+4索引缓冲接口，+8顶点容量，+12索引容量。
//   顶点stride=28：x/y/z/rhw各float，+16颜色DWORD，+20/+24 UV float。
//   创建参数：顶点字节数28*n、usage=8、FVF=324、pool=1；索引2*n、format=101。
//   创建结果按有符号>=0接受；Lock结果则严格要求==0，不能统称所有非负结果通过。
//   创建后顶点只初始化x/y/z=0、rhw=1、颜色FFFFFFFF；此处不初始化UV。
//   814C10释放非空COM接口并清槽，不释放16字节包装本身。
//   814CD0容量不足时释放旧接口、删除包装、重建；重建失败后未判空就继续解引用。
//   上传仅写输入顶点的xy和颜色；不复制输入z、rhw、UV。索引逐WORD复制。
