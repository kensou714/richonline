// ============================================================================
// 9100A0 / 9105D0装载；910450 / 9109D0保存
// ============================================================================
// Config+16/+20/+24/+28为行/节名/键名/值的分配容量；+32/+36/+40/+44为指针。
// 90F7D0初始容量1102、256、256、256，四指针为NULL，首次装载时才分配。
// 9100A0用rt打开，每次fread一个字节；9105D0用rb，要求keyLength>0且key!=NULL。
// 后者每个输入字节先减key[index]再以(index+1)%keyLength推进，按BYTE模256。
// key索引跨行连续，不在LF重置；这是循环字节偏移，不是KPD九字节容器或LZO。
// 明文路径的CRLF处理由CRT文本流完成；二进制偏移路径未见主动删除CR。
//
// 文本语法：不套用819xxx TextCursor或通用INI库的行为
// ----------------------------------------------------------------------------
// LF结束行；TAB在整行所有位置丢弃，包括值内。普通空格不会trim。
// 第一个字节恰为';'才整行忽略；前置空格使注释失效；没有行尾注释解析。
// 首字节'['且最后字节']'才识别节，内部字节作为名字，不修剪空格。
// 非空普通行查第一个'='，左边为键名、右边为完整值；值内其它'='原样保留。
// 不解析引号、反斜杠转义或反引号+n；空键不入树，空值由setter保存为NULL。
// 重复节合并到原Section；重复键按输入顺序更新原Entry，因此后读值覆盖前值。
// 字节0会干扰strlen/strstr，而不是合法的字符串内容；未见BOM或UTF-8识别。
// 开头没有有效节却先出现键时，+36节名暂存尚未被有效写入；不得假设默认节存在。
//
// 游标与错误返回
// ----------------------------------------------------------------------------
// 持久对象保存的是配置树和四个暂存，没有TextCursor的+8C/+90/+94读指针。
// 行内位置和循环key索引在调用栈上；查找函数不改变装载状态。
// 两装载器进入前不清已有配置；再次装载会合并/覆盖旧树，文件打不开则旧树保留。
// 返回0覆盖打开失败和偏移模式参数错误；到读取结束就返回1，不检查ferror，
// 不统计拒绝行，也不保证每行或所有必要字段成功进入树。
// fread返回值未被检查；循环以流EOF位结束，部分读取错误和异常EOF需另行分析。
// 不能把返回1解释成资源语法验证或完整装载成功。
//
// 行末NUL的静态容量边界
// ----------------------------------------------------------------------------
// 91014F..9101AC在追加普通字节之前，若当前长度>=容量则按256B扩容；
// 当第1102字节写到合法末位后长度等于1102，随后的LF走9101B8，写buf[1102]=0。
// 该NUL位超出1102B分配；后续每个容量边界同理。9105D0也保留此控制形状。
// 这是指令级边界事实，未构造畸形配置运行客户端；离线工具应预留终止符空间。
// 节名/键名/值暂存按所需长度+1扩容，不据此推导整层对任意大输入安全。
//
// 保存与往返限制
// ----------------------------------------------------------------------------
// 910450用w输出[section]+LF，各键输出key=value+LF，空值输出key=，节后额外LF。
// 9109D0用wb，要求有效key参数；将格式化输出逐BYTE加key，索引跨节/键连续。
// 偏移输出没有明文保存器的节后额外空行，因此解码后的两种输出布局并非逐字节相同。
// 两保存器都按容器现有顺序输出，不保留原注释、TAB、空行、重复节或重复键来源。
// 不转义名称/值中的'='、LF、TAB、']'；重新读入未必得到相同树。
// fopen失败返回0；正常收尾返回1，但未把fprintf/fwrite/fclose失败反映到返回值。
// 精确写入完整性、CRT错误路径与大整数长度溢出仍未作运行验证。
