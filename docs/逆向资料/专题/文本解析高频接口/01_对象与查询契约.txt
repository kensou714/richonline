// ============================================================================
// 两级配置树；名称查询没有持久文本游标
// ============================================================================
// Entry：90EA40清两个DWORD；90EA60字符串构造、90EAA0整数构造。
// +0 自有NUL结尾名字指针；90EB50直接返回。+4 自有值指针，可为NULL。
// 90EB00释放二者并置NULL；构造器分配量8B见90F1D0/90F4D0。
// Section：分配量20B见90FA80；+0自有节名，+8 begin、+12 end、+16 capacity_end。
// 容器元素是Entry*，每项4B；+4的BYTE初始化取this指针最高字节，未赋业务名称。
// Config：8E4AD0分配48B；+4 begin、+8 end、+12 capacity_end，元素是Section*。
// +0的BYTE同样取this指针最高字节，业务用途未知，不能将其误称为未初始化栈值。
// ctor90ED30的90ED33、ctor90F7D0的90F7D8机器码均为8A4C2403，读[esp+3]；
// 两入口首条push ecx已把this压栈，因此该BYTE等于(this>>24)&0xFF。
//
// 名字查找
// ----------------------------------------------------------------------------
// 90F150(this=Section,name)：NULL或空name返回0；从begin到end线性扫描，
// 通过90EB50取Entry名字，用94E560 _stricmp比较，返回第一个相等Entry*。
// 90FA00(this=Config,name)同形，容器字段为+4/+8，90EED0取Section名字。
// 没有推进游标、创建对象、复制结果或修改容器；返回的是借用指针。
// 没有检查内部Entry*/Section*/名字指针为NULL，依赖合法对象不变量。
// 名字参数只检NULL/strlen非0，非NUL终止缓冲不在该接口的合法契约内。
// 90F110/90F9C0为索引访问，负索引、begin为NULL或越界返回0。
// 90EEA0/90F990以(end-begin)>>2返回数量，begin=NULL时为0。
//
// 名字与值的所有权并不相同
// ----------------------------------------------------------------------------
// 90EB70、90EEF0名字setter：NULL/空输入返回0，保留原名；非空时先释放旧名，
// 再strlen+1分配并复制，新名字归对象所有。无编码转换，也无共享字符串计数。
// 90EC30值setter：先释放旧值且置NULL；NULL/空输入最终保留NULL，非空才复制。
// 因此“存在但空值”和“没有该键”在字符串组合接口里都会得到NULL。
// 90EC10直接借出值指针；90ECC0在非NULL值上调用atoi，否则返回0。
// 0可能代表缺键、空值、合法字符串0或atoi无法转换，调用者若要区别应先查Entry。
// 90ECF0把整数sprintf到共享全局暂存，再调用90EC30复制；没有锁的并发保证。
//
// 别名与失效边界
// ----------------------------------------------------------------------------
// 名字/值setter先delete再读取输入，所以不能把对象当前借出指针直接传回对应
// setter；这会形成对已释放内存的读取路径。该静态路径未用游戏运行复现。
// 更新值使旧值指针失效；换名使旧名指针失效；清树/析构使所有借出对象及字串失效。
// 扩容搬移的是指针数组，不移动已分配Entry/Section；不能把数组槽地址当稳定句柄。
//
// 重复节、重复键与清理
// ----------------------------------------------------------------------------
// 90FA80为取或建Section：名字比较相等则直接返回旧对象，不追加重复节。
// 90F1D0为取或更新Entry字符串；同名时只换值，保留原名字拼写和原插入顺序。
// 90F4D0为对应整数更新；不存在时分配8B对象并追加指针。
// 90EDE0释放节名和所有Entry后令end=begin，保留数组分配；90ED60再释放数组。
// 90F8F0释放所有Section、令end=begin；90F820另释放四个暂存及Section指针数组。
// 新增项或数组分配失败路径没有完整回滚：90FA80的NULL对象仍可被传入名字setter，
// 90F1D0/90F4D0亦存在NULL新项进入后续插入逻辑。不能承诺内存不足时安全失败。
// vector搬移辅助函数只保存原证，未逐项恢复异常安全或最大容量契约。
