// ============================================================================
// 名称查找 / 6B20A0与6B81D0
// ============================================================================
// 入口契约 / 以汇编恢复，不采用自动原型
// ----------------------------------------------------------------------------
// 6B20A0保存ECX为对象M，栈[EBP+8]为输入NUL字节串地址S，retn4。
// 因此这是ECX对象加一个栈参数的本地契约；旧伪码__stdcall丢失ECX不能照抄。
// 6B20BD调用60A06D直接E9至6B81D0；并非Windows LoadCursorW API。
// 6B81D0仅把ECX加42Ch（十进制1068字节）放EAX，普通retn，无栈参数。
// 该getter没有读[M+42Ch]、没有索引、没有NULL门；返回内嵌区域地址而非字段指针值。
// 容量、字符编码、终止和写者不由这个26字节本体提供。
// 原证：formal_functions.json#/functions/0与#/functions/1；桥见bounded_raw。
//
// 排除自己 / 6B20C7
// ----------------------------------------------------------------------------
// 压getter地址再压S，call61038C桥至922830，caller平衡8字节，检查完整EAX==0。
// 相等就返回NULL，完全跳过候选循环；不把“自己的名称”命中算成找到外部记录。
// 本体没有tolower、去空格、全半角处理或另建归一化缓冲区。
// 922830补证确认无符号字节序比较，等值至NUL返回0；不等返回-1/+1。
// Str1即S可能按WORD/DWORD宽预读，物理读取可越过NUL；见05的精确读宽边界。
// 本体及比较helper无S或getter结果的NULL门，也未检测NUL字符串可读长度。
//
// 候选循环 / 6B20D7至6B2125
// ----------------------------------------------------------------------------
// 610CCE桥至858E50返回count快照N，i从0开始；cmp i,N / jge是有符号上限判断。
// N<=0时无候选访问，返回NULL；本体不检查N是否与实际容器长度一致。
// 每次call60093C桥至858EA0(i)，getter重新取count并signed校验范围；结果P保存原样。
// 通过范围门后getter取ACB8E8容器槽地址，再读其中DWORD为P；失败返回NULL。
// 查找不检测P是否NULL；外层count快照不等于内层检查期间数量稳定的证明。
// 压20h、S、P，call603759桥至9228E0，caller平衡0Ch；相等返回P。
// 等值检查是EAX==0；最多32字节比较，返回第一个相等记录地址。
// 非匹配才i++；全未匹配返回NULL，失败值没有另分“自己”“空容器”“无命中”。
// 9228E0先在P最多32字节内扫NUL，再比较含NUL的扫描长度；两阶段均使用BYTE读取。
// DF=0是该helper未自行建立的ABI前提。count为容器+4为零时0，否则32位(+8减+4)SAR2。
// 85B870内部串联三helper，未闭合实际取槽映射，不能把候选顺序解释为连续结构数组顺序。
//
// 所有权与二次开发含义
// ----------------------------------------------------------------------------
// 本体不分配、不复制、不释放P，返回值就是候选getter当次给出的原地址。
// getter只读取槽内DWORD而无分配或复制；这条返回路径未出现所有权移交动作。
// 返回有效期、是否允许调用者释放及其他所有权规则仍须容器生产清理共同限定。
// 不能据此承诺跨容器清理、重建、连接变更后仍有效。
// 内嵌自己的串、玩家对象+70h串、邮件entry+10h串和候选P是不同来源，不能合并结构体。
// 32字节相等不证明超过32字节的名称完整相等；发生同前缀时静态路径选择最先出现项。
// 字符编码未证前，不能把32字节宣称32个汉字、Unicode字符或网络固定字段容量。
// 调用者要保留自名称被排除和候选结果的区别，不能把NULL统一解释成断线。
// 原始伪码、汇编与声明块均无损保留，文档修正ABI不改动IDA函数名或函数类型。
