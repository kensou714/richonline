// 自名称比较 / 922830
// ----------------------------------------------------------------------------
// 两栈实参Str1/Str2，普通ret。比较采用CMP产生的无符号进位，返回-1、0或+1。
// 相同且遇Str1的NUL返回0；第一次不同按unsigned BYTE序返回符号。
// Str1奇地址先读BYTE；随后可读对齐WORD，达到4字节对齐后循环读DWORD。
// Str2按BYTE读取并逐个比较；Str1的宽读取早于逐字节NUL检查，可能读NUL之后字节。
// 因此逻辑的NUL终止语义不等于物理上只读到NUL；本体没有地址、容量或NULL检查。
// 6B20A0把用户传入S放Str1，对象+42Ch放Str2；宽读风险属于S的实际可读区域。
// 不做locale、大小写或中文编码转换；语义是字节序而不是文字排序规则。
//
// 候选比较 / 9228E0
// ----------------------------------------------------------------------------
// 三栈实参Str1、Str2、无符号MaxCount；普通ret，保存EBX/ESI/EDI。
// n==0立即返回0，不加载或解引用两个串。n>0先令EDI=Str1、AL=0作repne scasb。
// DF=0时扫描到第一个NUL或n字节；得到k=min(n,首NUL位置+1)。
// 然后EDI=Str1、ESI=Str2，repe cmpsb比较k字节，遇不等提前停。
// 最后按两串最后比较的unsigned BYTE生成-1/0/+1；无字符差值返回约定。
// Str1扫描会先读完k，即使两个串的第一个字节就不等也不会减少该预扫描读量。
// 两阶段访问宽度都是BYTE，Str2按比较结果提前停；函数未CLD，依赖DF=0调用约定。
// 6B20A0的Str1=P、Str2=S、n=20h。前32字节无NUL但全相等时也返回0。
// 如果P在32字节内含NUL，S必须在相同位置匹配NUL才等值；不是固定32字节memcmp。
