// ============================================================================
// 三类型结果请求与容器 / 事件泵主区间与连接清理
// ============================================================================
// 8BB090、8BB2E0主区间逐字节及逐指令复核见reused_preparation.json。
// 来源只证明已保存主区间；本文不把调试栈校验元数据当完整异常尾块。
// 连接析构60090F真实E9目标8BB270已补完整正文；成员析构8BA5B0另列补证。
//
// 初始化与全局状态
// ----------------------------------------------------------------------------
// 8BB090接收三个栈参数：地址字符串、端口和回调函数指针。
// WSAStartup请求2.2，地址经inet_addr存ACBD58，端口低WORD经htons存ACBD5C，
// 回调存ACBD60；本函数未检查WSAStartup和地址转换的返回有效性。
// ACBD64是当前单连接指针；这里只能确认静态引用，不能读取BSS快照推断运行值。
// 8BB2E0看ACBD64==0直接退出；连接+8 BYTE==0时建立TCP socket和WSA event，
// WSAEventSelect mask=0x33，即READ/WRITE/CONNECT/CLOSE四位，随后调用connect。
// socket、event、WSAEventSelect、connect的返回结果均未在该路径检查。
// 最后连接+8=1并结束本次泵；不能把这个BYTE称为已连接成功标记。
//
// 事件与发送
// ----------------------------------------------------------------------------
// 后续调用WSAWaitForMultipleEvents，event数1，waitAll=0，timeout=0，alertable=0。
// wait返回不用于条件判断，继续WSAEnumNetworkEvents并使用其写出的本地事件结构。
// 事件结构始于[ebp-0x54]；各错误字段由确切栈地址核对：
// CONNECT位0x10读[ebp-0x40]，即iErrorCode[4]。
// WRITE位0x02读[ebp-0x4C]，即iErrorCode[1]。
// READ位0x01读[ebp-0x50]，即iErrorCode[0]。
// CLOSE位0x20也读[ebp-0x50]，仍是iErrorCode[0]，并未读常规下标5。
// 事件错误非零会写本地失败BYTE；后继READ/CLOSE先检查该失败BYTE。
// WRITE无错时取发送reader剩余数；非零才send，返回非-1直接推进该返回字节数。
// send==0不推进也不设错；send==-1直接失败，未再区分WSAEWOULDBLOCK。
// READ无错时调60C110->8BA950，只检查返回AL；AL==0设置失败。
//
// 关闭与失败顺序
// ----------------------------------------------------------------------------
// CLOSE所读错误字段为0时，调用当前连接60090F(this,flags=1)，再ACBD64=0。
// 此路径不额外触发成功回调；成功通知发生在reader消费完整正文时。
// 任一失败BYTE非零时，先push success=0，经608826取得失败type，
// 再push type并调用ACBD60；随后重新取ACBD64，flags=1释放并清全局。
// 608826->8BA7B0从发送reader重置游标、跳过2字节并读DWORD，取得请求type。
// 回调后再读取全局连接的顺序值得审核：若回调替换连接，清理目标可能随之变。
// 当前只是静态调用顺序，未证明实际UI回调会替换、销毁或重入连接。
//
// 待闭合项
// ----------------------------------------------------------------------------
// 8BB270先经61123C调用8BA5B0，flags低位为1再operator delete(this)，ret 4。
// 8BA5B0正常路径对+0C/+28非零reader调用8BA740(flags=1)；+8非零才
// WSACloseEvent(+4)、closesocket(+0)，不检查返回值；最后8CC660(this+18)。
// 完整异常尾块也调用内嵌reader析构。8BA740/8CC660内部释放实现仍外依赖。
// 8BBA00/8BBCD0在分配新连接前flags=1释放旧连接，详见04。
// FD_CLOSE错误下标异常和send==-1处理可作为后续补丁研究点；这里未改客户端。
// 非阻塞发送失败、短响应、关闭事件的实机表现需要独立实验，不能用静态结论代替。
