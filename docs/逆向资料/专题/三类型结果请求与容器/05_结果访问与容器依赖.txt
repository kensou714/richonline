// 8BC220与8BC2C0均用ACBD70、完整栈上DWORD key地址调用8BD240，并比较end。
// 8BD430比较两个迭代器的首DWORD，相等返回1；8BD480对其AL取反表示不等。
// 查询发现end时返回0；否则调用8BCF20取得值区地址。
// 8BC220返回该地址；8BC2C0返回其+4400处DWORD，步长与type1数组44字节一致。
// 因此返回0分别可能是未命中或零count；不能单凭count==0断言网络错误。
// 伪码可能把key参数恢复成char，但caller和比较路径传递的是DWORD地址。
//
// find与operator[]层
// ----------------------------------------------------------------------------
// 8BD130将树this+4存入end输出：8C00C0->8C3900写迭代器首DWORD。
// 8BD240先调用8BFD70包装的8C3430取得候选；后者本批只保外部调用边界。
// 候选为end，或比较器返回1时，输出end；否则输出候选迭代器。
// 比较器8BE000沿用整数键树专题完整原证，是DWORD无符号严格小于。
// 8BCF20先取下界并比较；缺键分支调用8BD060默认值、8C04B0复制pair，再hint插入。
// 末尾8C0120->8C3950->8C2AD0返回指针，再+4；8C2AD0本体尚未由本篇证明。
// 因而可确认返回形态，不能由这两包装器单独推导节点N+12/N+16。
// 8BC220/8BC2C0先find再调用此层，避免正常串行未命中路径进入默认插入。
// 线程安全、迭代器失效和回调期间容器变更未实机验证，不能凭此保证并发安全。
//
// 当前边界
// ----------------------------------------------------------------------------
// 8BD060调用vector构造迭代器，参数stride44/count100，之后mapped+4400=0。
// 44字节元素构造指针60EFE6、vector内部实现外依赖，不据此称所有字段全零。
// 8C04B0写pair首DWORD key；随后rep movsd 0x44D，将4404字节值区复制到pair+4。
