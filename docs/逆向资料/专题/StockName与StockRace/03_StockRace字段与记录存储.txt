// StockRace / 配置字段与记录存储
// ============================================================================
// 装载入口 6C14E0；名称只沿用原文件名，不把 RACE 直接解释为赛事业务。
// 打开、解包、解析器模式 2 与 StockName 同族；打开失败只销毁资源局部对象。
// 未构造 bool 成功信号；最后业务调用为资源析构，随后执行 CRT 收尾。
// CRT 收尾叶子未在本专题全审，不能把出口 EAX 当装载成功值。
//
// 配置字段 / 相对对象偏移
//   UNIT / unit       atoi 后写 DWORD +014。
//   URL  / bbs        字符串写 +018，传入容量 260。
//   URL  / help       字符串写 +11C，传入容量 260。
//   URL  / comment    字符串写 +220，传入容量 260。
//   URL、bbs 来自 A23C44 / A23C48 实际 ASCII 数据，而不是 IDA 指针名猜测。
//   节/键查找结果未检查后就继续读值；缺失键的默认值由解析器决定，未在此承诺。
//
// 顺序记录
//   i 从 0 开始；sprintf(buf,"RACE%.2d",i+1)；首个找不到的节即退出。
//   %.2d 是最少两位，RACE100 仍可生成；不是仅支持 RACE01..RACE99。
//   RACE01 缺失则不读任何记录；RACE02 缺失则即使有 RACE03 也不继续读。
//   找到一节后，6C5580 把局部 info 清零 0x484 字节。
//   +000  areaid：读取到 buf，atoi 后写 DWORD。
//   +004  name：调用容量 128；语言标签 1 时调用 818FA0 前向字码转换。
//   +084  desc：调用容量 1024；同样在语言标签 1 时前向转换。
//   总尺寸 4+128+1024=1156=0x484，与 RTC info 描述符和存储步长一致。
//   buf 是 128 字节，info 是 1156 字节；伪码 String[136]/desc[1028] 含间隙。
//
// +324 存储对象的最小布局
//   相对容器 +004：begin 指针；+008：end 指针；+00C：capacity_end 指针。
//   6C5D70：begin==0 返回 0；否则 (end-begin)/0x484，使用有符号 idiv。
//   6C7A40：begin==0 返回 0；否则 (capacity_end-begin)/0x484。
//   6C5CC0：比较 size 与 capacity；有空位则向 end 委托复制一条。
//   6C7BE0 转交复制依赖 6CACF0，返回 dest+0x484*count；返回指针写回 end。
//   满容量路径取得 end 迭代器，6C7AE0 委托 6C8B10 插入一条并重建输出位置。
//   6C7AA0 只是以 end 委托 6CA540 构造迭代器，不是内存扩容器。
//   IDA 把 6C7AE0 标成 COleSafeArray::ResizeOneDim，真实 retn 0x0C 与参数不符。
//   已恢复容器步长与包装调用；没有全审 6CACF0/6C8B10 的搬移、分配和异常回滚。
//   不凭包装返回步长宣称底层 memcpy 正好复制 0x484 字节或分配永不失败。
//
// 重复装载与失败边界
//   本体没有清空 +324 容器，记录按现有 end 追加；这不是替换式重载。
//   成功再加载覆盖 unit/URL 并继续追加；打开失败不主动清除旧字段和旧记录。
//   首次加载失败时，上述字段是否具备可用默认值必须继续审构造与消费者。
//   数字解析没有业务范围检查，areaid/unit 的负值、非数字内容只交给 atoi。
//   未确认业务消费者、RACE 选择规则、UI 展示或联机消息，不能提供协议替代实现。
//
// 原证：文本过滤与字码转换/证据/functions_raw.json：6C14E0，复用后补字段审阅。
//       证据/core_raw.json：6C5580 / 6C5CC0；supplement_raw.json：五个存储包装。
//       证据/supplement_data.json：RTC 6C17F0 和 URL/bbs 字面量。
