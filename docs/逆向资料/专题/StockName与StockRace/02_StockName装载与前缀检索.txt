// 装载入口 6C1260
//   打开 81B4C0 -> 解包 81B7F0 -> 8191D0 构造解析器 -> 819250 绑定模式 2。
//   6C5510 判断游标 EOF；81A2E0 逐行读入 buf，再 sscanf("%u%s",code,name)。
//   6C134B 调用 sscanf 后仅回收参数；返回匹配数没有被检查。
//   语言标签为 1 时，对名称调用 8190B0 反向字码转换，见字码转换专题。
//   code 与字符串构造成 pair，再复制临时 pair，向对象 +008 插入。
//   临时 pair 的键在 +0、字符串子对象在 +4；6C5550 只析构 +4。
//   文件打开失败也清理资源对象；未构造 bool 成功信号。
//   最后业务调用为资源析构，随后执行 CRT 收尾，不能把出口 EAX 当装载成功值。
//
// 栈空间的真实边界
//   RTC 6C1474：buf 位于 EBP-348，容量 128；code 位于 EBP-360，容量 4。
//   name 位于 EBP-432，容量 64；反编译器 Str[72] 包含栈保护间隙，不能采信。
//   %s 没有宽度限制：合法写入至多 63 字节正文加终止零。
//   缺键、空行或匹配不完整没有本体校验；是否在上游过滤空行仍待解析器闭合。
//   RTC 检查位于返回路径，不能视为 sscanf 的容量保护。
//   未做畸形资源动态试验；这里记录静态缺少检查，不宣称实机已发生溢出。
//
// 名称索引的最小契约
//   6C7A10 比较 DWORD 键，cmp/sbb/neg 实现无符号小于，返回 0 或 1。
//   6C66F0 / 6C8200 复制首 DWORD，再委托 62B7B0 构造 +4 字符串。
//   6C88D0 返回 node+0x0C；6C82C0 取 iterator 首 DWORD 后转交该函数。
//   6C6740 -> 6C82C0；6C6770 -> 6C6740，首字段键与 pair 地址相同。
//   6C8250 向输出写 iterator DWORD 和 +4 成功 BYTE，不覆盖 +5..+7。
//   6C5930 的重复键分支返回原 iterator/false，不替换已有名称。
//   6C6C90 为提示插入；不合适的提示回退 6C5930，快捷链接复用 6C7470。
//   插入、迭代器递增、红黑链接的全部依赖未闭合，保留部分分析状态。
//   本体没有清空名称索引；重复装载的同键仍走“不替换”分支。
//
// 前缀入口 6C1A60
//   参数区域为 28 字节值传字符串及一个输出容器指针，返回 retn 0x20。
//   伪码 a2..a8 是同一字符串被拆开，不是七个独立业务参数。
//   输入非空、首字节等于 '6'、长度 <=6 才继续，没有逐字符数字检查。
//   length 在补零前保存；向副本尾部补 6-length 个 '0'，再 atoi 得 low。
//   high = low + 10^(6-length) - 1；数字合法输入的六位区间不会 DWORD 溢出。
//   先精确查 low；若不存在，每次加 1 重查，直到命中或达到 high。
//   首键缺失时没有直接跳到 lower_bound；最大可尝试十万个整数键。
//   命中后遍历至 key>high 或 end，每个候选 unique 插入输出容器。
//   插入后才检查输出 count>=10；输出容器本体没有清空。
//   因而只有“输出原本为空”的前提下可称最多十项。
//   输出原有十项且首候选是新键时，仍会插入到十一项再退出。
//   输出原有重复键且达到十项时，也可能一次失败插入后立刻退出。
//
// 可复现的静态例子
//   "6"      -> 600000..699999；"60" -> 600000..609999。
//   "600001" -> 600001..600001；若该键没有记录则结果不变。
//   "6x"     -> 补成 "6x0000"；atoi 得 6，区间变成 6..10005。
//   后者是没有数字校验的结果，不能假定“首字符 6”等于“六位股票代码”。
//   具体代码业务命名与 UI 消费者尚未闭合，文档保留为无符号名称索引键。
//
// 原证：资源容器候选/证据/candidate_owners.json：6C1260 / 6C1A60。
//       证据/dependencies_raw.json 与 supplement_raw.json：最小索引依赖。
//       证据/supplement_data.json：RTC 名称、尺寸和描述符双份字节。
