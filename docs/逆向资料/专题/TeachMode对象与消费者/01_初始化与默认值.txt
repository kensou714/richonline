// T = DWORD[0xA76714]，N=DWORD[T+0]，R=DWORD[T+4]。
// 原证按 functions[].va 定位：628E30 / 810330 / 8102F0 / 8103B0。

// [事实] A76714 的当前磁盘四字节及 IDB 四字节都是 00000000。
//         628E30 仅在 A76714=0 时传入分配大小8；非空分配经 60AF9A→
//         810330 构造，回写 A76714；空分配分支保持0。返回该全局指针。
//         628E30 异常尾块 A116A0..A116B5 另有释放未完成分配的路径。
// [事实] 810330 明确 mov DWORD[this],0 与 mov DWORD[this+4],0：首次
//         构造后 N=0、R=0。自动 unknown_libname/MFC 名不改变这两处写入。
// [事实] 628E30 getter 本体未见锁或原子比较交换；不据此宣布线程安全。
// [事实] raw.globals 是 getter 的数据引用候选：仅 A76714 确认为本对象
//         指针；A116AB 是异常处理入口引用，A55158 是尾块引用数据。
//         不把原证键名 globals 或地址区间当成变量语义。
//
// 装载分配 / 8103B0（复用旧专题，补构造器责任）
// ----------------------------------------------------------------------------
// [事实] loader 不重置 N；第一遍每遇 MAP 都递增 N，随后复位解析游标。
//         N>0 时请求368*N字节，向 vector constructor iterator 传步长
//         0x170、元素数N和5FF852；5FF852 的 E9 指向8102F0。
// [事实] 8102F0 调 memset(this,0,0x170)，完整记录字节0..367清零。
//         因此名称区、12项装备、奖励和尾部八个DWORD首次都有零默认值。
//         第二遍只在可选装备键存在时改写相应DWORD，缺键保留这个初值。
// [事实] N/R 构造只发生在 getter 发现全局空时；再次取对象不会清零。
//         810360 释放非空 R 并置 R=0，本体不清 N；loader 再次调用前
//         本体也未释放旧 R。不能把首次 N=0 推广为每次装载都重新计数。
// [推断] 当前资源六 MAP、indx0..5，在首次构造且两遍扫描稳定的条件下
//         N=6、表长2208B，全部记录默认值已由构造清零。
