// 类型7辅助树0x7CD440
// 先用7F85C0查询物品1071的槽位和来源，再要求800A50(1071,map)成立。
// 失败返回0，主函数选择6063状态6；成功返回1，主函数追加6050。
// 成功树自身依次排6003提示、6001编号316、6063状态4、6061。
// 6061字段+4=行动槽，+5=物品槽，+7=来源，+9=1。
// 物品1071业务名称、800A50地图限制和6061实际消耗未在本轮逐级证明。
// 因此仅称“物品1071参与的保护候选分支”，不宣称已恢复完整免疫规则。

// 类型26辅助树0x7CC970
// 调7CE420，输入动态条目+1、行动槽，另传两个输出区及常量-1、26。
// 返回值保存为resultCode；一个输出DWORD作为比较及6060数值amount。
// 随后调用7F5D50(3)，并排6001编号124、6060(+4=1,+5=1,+8=amount)。
// 若resultCode不等于100，设置槽位全局结果并排6000事件37。
// 事件37使用40字节全局载荷；其内部布局和UI消费仍待展开。
// 最后排6009(+4=500)，返回现金+存款严格大于amount的结果。
// 7CE420共179行伪码本轮只导出，金额公式及分配结果不能算已核实。

// 数值解释边界
// 693220汇编读取行动者+1504和+1508，32位相加后有符号比较参数。
// 63F5F0读取行动者+1512；63F620读取+1504。
// 7D6E00读取资源表基址+72*type+68；694790返回该72字节记录首地址。
// 资源表记录的中文名称、显示文案和金额单位需要资源加载器另证。
// 受限于32位加法，不能改写为无限精度余额条件而声称完全等价。
