//
// 6001 / 长12 / 构造器693420
// +0 WORD=6001；+2 WORD子事件13；+4/+5 BYTE初始化0；+6 BYTE写0；+8 DWORD初始化0。

// 6002 / 长12 / 构造器693260
// +0 WORD=6002；+2 WORD子事件；+4 BYTE演员；+5 BYTE初始化0；
// +6 BYTE写1；+8 DWORD时长1350。+7未证明有意义。

//
// 6003 / 长24 / 构造器6932B0
// +0 WORD=6003；+2 WORD子事件4；+4 BYTE=1；+5 BYTE初始化0；+6 BYTE=1；

// 文本129/304/305使用strlen+1；文本181/344路径使用全局缓冲且固定128。
// 文本查询629D90直接返回base+stride*index，此处没有查询索引边界检查。

//
// 6005 / 长4 / 构造器6937D0
// +0 WORD=6005；+2 WORD目标位置。
//
// 6060 / 长12 / 构造器693320
// +0 WORD=6060；+2 BYTE演员；+3 BYTE=1；+4 BYTE初始化0；+5 BYTE=1；
// +6 BYTE初始化0；+8 DWORD数量；+7未证明有意义。

// +0 WORD=6062；+2 BYTE演员；+3 BYTE与+4 BYTE初始均0；+6 WORD数量。

// 6063 / 长4 / 构造器63F730
// +0 WORD=6063；+2 BYTE演员；+3 BYTE=2。
//
// 606C / 长6 / 构造器693800
// +0 WORD=606C；+2 BYTE演员；+4 WORD目标位置；+3未由构造器清零。
//
// 608B / 长2 / 构造器7D6F60
// 仅+0 WORD=608B；不是携带现金数值的完整网络购物请求。
//
// 队列插入：64FA50 -> 跳板60DB87 -> 6980F0
// ----------------------------------------------------------------------------
// 64FA50收到G/Src/Size/cursor，先memcpy指定字节到288字节栈槽。
// 汇编64FA91固定push 1；64FA97分配0x120字节实参并rep movsd复制整个槽，
// 随后以G+0x640为this调用6980F0。额外参数是cursor与模式1。
// Hex-Rays报local variable allocation failed且把尾部参数写成STACK[...]
// 属于恢复局限；不能把伪代码列出的64个DWORD误认成64个业务参数。
// 6980F0使用固定288字节环形槽，字段按相对队列对象：
// +0 槽数组指针；+4 容量；+8 元素数量；+12 头索引；+16 尾索引。
// 698640检查head==(tail+1)%capacity；满时返回-1，不插入。
// 698680给出(next+1)%capacity；6986B0给出previous（零向capacity-1回绕）。
// 根据插入点到头部的距离，与剩余长度比较，选择搬移头侧或尾侧。
// 搬移完成后数量+1；模式1返回新插入槽的next，模式2返回previous，其他返回槽自身。
// stage1每次把返回值写回*a2；所以多个消息和上层追加stage2保持预期插入顺序。
// 不应以“push_back”概括此接口，也不能把*a2当网络动作计数器。
//
// 存储生存期与限制
// ----------------------------------------------------------------------------
// 消息记录复制的是固定槽，指针字段的目标不随记录自动复制。

// 64FA50没有检查Size<=288；当前stage1最大Size=24，不能扩展成通用安全接口保证。
