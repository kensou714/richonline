// 两层计算不能混合
// --------------------------------------------------------------------------
// 第一层7CE420：每一个中心对某槽命中，生成调整金额D与未调整基础B。
// 第二层7CBD50：连锁累加后，对各槽做5%阶梯增幅，再生成本地6060扣款事件。
// “伤害”只用作范围效果工作名；本地实际扣的是cash/deposit，不是独立生命值字段。

// 第一层 ABI 修正
// --------------------------------------------------------------------------
// 7CE420实际上保留ECX游戏对象，并读取6个DWORD栈参数，尾部retn 18h。
// 顺序：sourceSlot、targetSlot、outAdjusted、outBase、tableIndex、dynamicType。
// Hex-Rays显示double a1@st0和unsigned __int64 edx:eax是误识别，不能复制成真实调用接口。
// 末尾浮点转整结果只把EAX暂存并返回；目标函数调用产生的ST(0)不是额外输入参数。
// 本轮tableIndex=-1，所以基础值来自7D6E00：资源对象+4指向数组，记录72字节，金额在+68。
// 取dynamicType（12或27）为索引，先令outAdjusted=outBase=该整数值。
// 通用分支tableIndex!=-1则从另一资源数组（步长1128、记录+108）取基础值，本专题不命名资源。

// 第一层倍率因子 F
// --------------------------------------------------------------------------
// F从1.0开始；下述P偏移以字节计，float须按32位读取。源和目标字段不得互换。
// 源处理前提：sourceSlot!=-1、槽有效、7C0C00不将其判为特殊槽。
//   源P+1488==3：乘1.5；若int(P+1740)>0，则改乘1.5+float(P+1744)。
//   源P+1488==2：乘0.5；若int(P+1740)>0，则改乘0.5-float(P+1744)。
//   short(P+1734)!=-1：以signed byte(P+1736)查来源倍率；
//       两类已证模式分别使用7014D0（资源float索引78+3*i）或701500（74+3*i）。
//   signed byte(P+1660)>0：乘float(P+1652)。
//   signed byte(P+1672)>0：乘float(P+1664)。
//   int(P+1752)!=0：乘1+int(P+1752)/100.0。
//   byte(P+1696)!=0：乘float(P+1676)。
// 目标处理总是执行：
//   目标P+1488==0：乘0.5或0.5-float(P+1744)；增强前提仍是int(P+1740)>0。
//   目标P+1488==1：乘1.5或1.5+float(P+1744)。
//   short(P+1730)!=-1：以signed byte(P+1732)查目标倍率；
//       两类模式分别为701790（float索引54+3*i）或7017C0（50+3*i）。
//   signed byte(P+1661)>0：乘float(P+1656)。
//   signed byte(P+1673)>0：乘float(P+1668)。
//   int(P+1760)!=0：乘1-int(P+1760)/100.0。
//   byte(P+1696)!=0：乘float(P+1680)。
// 这些偏移只确认参与公式；装备、状态、技能的官方名字和合法值域仍待资源写入链核对。

// 第一层取整和加减项
// --------------------------------------------------------------------------
// D=trunc(float(B)*F+0.5)，实际经x87计算、float中间落盘与__ftol2，最终只存低32位。
// 源满足上述前提时：D+=int(source+1748)。随后总是D-=int(target+1756)。
// D<1则截为1；B保持原始资源值。函数返回trunc(float(D)*100/float(B)+0.5)。
// 7CC490使用两个输出，不使用返回百分数；不得把返回值当伤害金额。
// 函数还写目标+1648/1649/1650/1651上下文字节，来源经槽标志筛选；并非无副作用纯函数。

// 第二层累计调整
// --------------------------------------------------------------------------
// 令D[i]为第一层调整金额累加，B[i]为基础金额累加，K为共享的类型27命中计数。
// C12/C27分别从7D6E00索引12/27取得。仅D[i]>0且B[i]>0才进入此层：
//     N = signed_integer_divide(B[i] - K*(C27-C12), C12)
//     若N>0：
//         ratio = float(D[i]) / float(B[i])
//         B[i] = trunc((1.0 + (N-1)*0.05) * (C12*N)) + K*(C27-C12)
//         D[i] = trunc(float(ratio*float(B[i]) + 0.5))
// 原证7CBFF7是IDIV；0.05、1.0、0.5分别读A2D460、A226E0、A23394。
// 不能把K擅自变成每槽值，也不能把逐层float落盘优化成一次double运算后称为精确复刻。

// 目前未解决与可验证假设
// --------------------------------------------------------------------------
// A870D0、A8708C、A870F0在IDA数据库显示均为-1，三者无PE原始数据映射。
// 不能将这些值当成磁盘初始化字节或当前运行时参数；原证中disk_hex/matching为null。
// 运行时加载来源和值域未闭合，本专题不声称实际范围半径或停留回合数。
// 本路径未见C12==0、B==0的除法防护，也未证明配置保证正值；只记录静态前提风险。
// 多角色命中同一27格时K共享；需对照官方实际行为判断设计意图，不能直接判定原程序BUG。
// 7CC490局部覆盖数组为固定栈空间，扩散上限来自配置；未见每次写入前独立容量检查。
// 7CBD50清8个百分数标志，槽循环用+0xE20；全局合法槽数约束需在初始化入口另证。
// 动画9/37的消费与完成回调、金额显示和网络权威状态对齐尚未闭合。
