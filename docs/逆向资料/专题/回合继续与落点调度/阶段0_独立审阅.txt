//   63E3E0：有符号WORD [map+48所指数组 + 8*pos + 2]。
//   63EB50/63EB90：有符号BYTE [map+60所指数组 + 4*pos]。
//   7D6E30：同一动态条目+1的有符号BYTE。
//   7C327E先读静态关联引用但不参与此switch；7C3293检查动态存在。

//   7C32F0及7C330D先检查map+24==4和game[3672+行动槽]非零。
//   type8先清理A/B，type26不清理；两者经8074C0返回1。

// 通过项三：指定停止串联分支
//   type0：7C34A0..7C350A，6051前缀12字节，再6083前缀2字节，xor eax。
//   type1：7C350F..7C3579，同样6051→6083，资源值135/102，返回0。
//   type12/27：7C41A5..7C42C8，6002编号25→6000事件13→608F，返回0。
//   type32：7C4F6F直接xor eax，没有此分支自己的入队动作。
//   type33：7C4F73清理请求A→7C4F85 xor eax，没有此分支自己的入队动作。
//   对0/1还必须计入普通switch前的共用事件；文档已明确这一点。
//   共用类型集合6926A0是unsigned(type)<8或type==18；
//   6947C0的额外6002集合是1/2/6/7/18，均与结构索引一致。

// 通过项四：type26/28资金边界
//   type26的7C4DE0调用7CC970，后者7CCADB调用603F3D跳板→693220。

//
// 通过项五：返回0的准确含义
//   6813DC调用阶段0，6813E1 TEST EAX；零则跳过下一阶段插入。
//   非零才693BE0构造WORD 0x6080，写消息+2=1，以4字节前缀排入。
//   因此返回0只表示本次调用不自动串联阶段1；不是网络等待标志。
//   0/1、12/27先排本地事件；32/33未见本分支的直接继续事件。
