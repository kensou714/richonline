// 结论边界
// --------------------------------------------------------------------------
// 已证：7CBD50 处理动态地图格类型12或27，筛选参与者、递归收集范围、排入动画和资金事件。
// 已证：60EF4B 的 E9 归一目标为7CC490；它是范围递归求值器，不是普通数值归一化函数。
// 已证：资金事件6060最终先扣现金，不足部分扣存款；这里只复原客户端本地计算。
// 未证：12/27的官方道具名、动画9/37画面含义、对应服务端权威结算和网络应答契约。
// 本专题函数和跳板字节已与磁盘对照一致；没有把静态分析升级为实机验收。

// 入口与返回值
// --------------------------------------------------------------------------
// continue_sources.json：608F本地事件处理681F60取当前角色位置，调用607A7A→7CBD50。
// 7CBD50(this=游戏对象, position, int* eventTail, arg3, arg4)，retn 10h。
// 最后两个显式参数在本函数主体未使用；不能把它们命名成网络字段或资源ID。
// 若位置没有动态格，或动态格类型不是12/27，返回true且没有本轮范围效果。
// 真正处理后，仅当以下两项均未发生才返回true：
//   1. 有效槽i获得正数动画效果值，而且i==游戏对象+0xE28的槽号；
//   2. 任一受资金事件影响的角色 cash+deposit <= 本轮应扣金额。
// 第二项为严格大于比较的反面；资金恰好耗尽也返回false。
// 681F60只在true时经693BE0构造6080事件，写byte+2=1，再按4字节追加stage1续行。
// false仅省略这条stage1续行，不会撤销此前已经排入的范围效果事件。
// false不等于网络失败，也不代表“没有生成事件”：此前的动画和扣款事件可能已经排队。

// 参与者与对象偏移
// --------------------------------------------------------------------------
// 游戏对象G：+0x65C为地图子对象M；+0xE00为角色指针数组；+0xE20为参与者循环计数。
// +0xE30+i是槽有效字节（63E7D0）；IDA误名CPaneContainerManager::IsAutoHideMode。
// 角色P：+1464为当前位置；+1493、1494、1495、1497为带-1哨兵的状态字节。
// 初始筛选：槽无效，或上述任一状态字节不等于-1，则其候选位置写-1；否则取当前位置。
// 这些状态本专题只确认偏移和判据，尚未把它们命名为住院、坐牢、隐身等具体状态。
// 三个结果数组按槽存储：动画效果值T[i]、调整金额D[i]、基础金额B[i]，入场均清零。

// 动态格与四方向扩散
// --------------------------------------------------------------------------
// M+60指向每格4字节动态记录：有符号byte0是类型，byte1被当作来源槽传入伤害公式。
// byte0==-1表示无动态对象；12/27由63E710精确识别，不是建筑类型枚举。
// 7CC490首先把当前中心加入本地覆盖格数组，再遍历方向0..3。
// 每方向最多读取全局A870D0步；每一步先检查二维边界，再求邻格，越界/不可走即停止该轴。
// 7E1600只作坐标拆分：x=pos%width，y=pos/width。
// 7E1580另按方向分派邻格计算：0为pos+width，1为pos-1，2为pos-width，3为pos+1。
// 0/2分别检查y+1/y-1，1/3分别检查x-1/x+1；屏幕视觉朝向本专题未命名。
// 邻格还须满足0<=pos<M+36，以及M+48指向的8字节地形记录byte0不等于-1。
// 因此不能按线性位置加减直接绕过横向边界，也不是沿可行走路径转弯扩散。

// 递归连锁与删除顺序
// --------------------------------------------------------------------------
// 覆盖到另一12/27格时，在A8B410的DWORD列表中查重；A8B8DC是本轮共享列表长度。
// 未出现过才入共享列表及本层递归待办；遇到此格不会立刻停止该轴继续探查。
// 先遍历本层覆盖格和角色位置，累计效果；再清除本层中心；最后递归处理待办中心。
// 普通动态对象也可能被范围清除；7E28B0按类型维护对应稀疏索引后写byte0..2=-1。
// 类型32经7ECAF0判断会保留动态记录；12/27走7E2520删除索引。
// 0..10或15..21额外调用7E2810重置相应8字节表记录并减计数；不擅自命名该表。
// 中心初始没有直接登记到共享列表：连锁邻格回查时仍可能登记先前中心，不能凭图论直觉改写算法。
// 实際源码是先删再递归，复刻时须连同动态状态变更次序一起重放。

// 两类效果结果
// --------------------------------------------------------------------------
// 63ECA0判定的一组地图模式走动画效果值分支：类型12尝试取A8708C，27尝试取A870F0。
// 每槽T取此前值和配置值较大者；两类类型各自的比较/写入分支已在7CC490原证保存。
// 63EDF0判定的另一组模式走资金分支：7CE420(sourceSlot,targetSlot,&D,&B,-1,type)。
// D/B按每次格—角色命中累加；类型27每次命中会增加同一个共享整数K。
// K不是每槽数组，也不是单纯“27格总数”；多角色被同一范围命中会影响它。
// 两组模式的数字分类包装器已导出，尚未将每个数字硬绑定成官方模式中文名称。

// 本地通知与队列
// --------------------------------------------------------------------------
// 609D34→64FA50按指定长度复制事件到本地排队入口，并返回新的eventTail；不是直接socket发送。
// T[i]>0：排20字节6000事件，子类WORD(+2)=9，byte(+4)=1，+12指向12字节持久全局载荷。
// 载荷在A8B398+12*i：{slot, 原候选位置, T[i]}；事件+16载荷大小=12。
// D或B非零：排12字节6060事件；byte+2=slot，+3=0，+4=1，+5=1，+6=0，DWORD+8=D[i]。
// 若D!=B，置A8B8E0+i标志并写A8B8E8+4*i=trunc(float(D)*100/float(B)+0.5)。
// 任一前8个标志非零：再排6000子类37，byte+4=0，指针=A8B8E0，载荷40字节。
// 此40字节是8个标志字节+8个DWORD百分数；只清8字节标志，未本轮重算的百分数可能保留旧值。
// 消费者必须结合标志读取；类型9/37的视觉动画和完成回调仍是后续入口。

// 资金事件消费
// --------------------------------------------------------------------------
// 分派桥：6060→5FF64F→7F16F0→60711A→67FA90。
// 当前字段组合进入6057BB→7F83F0：cash-=D；cash<0时deposit+=cash、cash=0；deposit下限0。
// cash/deposit分别为角色+1504/+1508；动画通知另经6093A2调用，本专题未完整追显示消费者。
// 该扣款实现与693220的cash+deposit>D前置判据一致；恰好扣空返回耗尽标志。
// 通用6060也有加现金、加存款、减存款分支；本轮7CBD50只生成上述扣现金组合。
