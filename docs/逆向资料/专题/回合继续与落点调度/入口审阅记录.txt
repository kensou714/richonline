// 6932B0在6932C1明确执行mov word ptr [eax],6003h；伪代码十进制24579同义。

// 6080入口核对一致项
// 6813B6以movsx读取record+2，681446以movsx读取record+3，均为signed BYTE。
// 6813BD..6813CA以无符号ja筛掉负值及大于6的值；3/4/5走默认出口。
// 阶段0、1、2、6分别调用7C3220、7C54B0、7C6640、7CB050。
// 前三阶段仅返回非0才依次追加阶段1、2、6；阶段6没有本入口追加后继。
// cursor与scratch传地址，追加使用子函数执行后的cursor，不重新取head。
// 693BE0只初始化WORD消息号6080和BYTE+3=-1，阶段+2由调用者写入。
// 非0是本地串联条件，不能命名为服务端成功；返回0也不等价于一定等网络。

// 旁路来源核对一致项
// 660B00只在record+4 signed BYTE等于-1时清pending、关UI20并追加stage2。

// 681890要求7CB3F0返回非0且record+4非0，才插入stage6。
// 6818C6只mov dl,[ecx+3]后push edx；正文正确保留高位未重新赋值的ABI边界。
// 681F60取当前行动角色位置，7CBD50返回非0才插入stage1。
// continue_sources并非所有6080来源的穷举，银行660320保留独立交叉引用。

// 银行消息与等待核对一致项
// 4018错位分支复制原8字节记录插回head前；不是发送网络重试请求。
