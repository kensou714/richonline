// 结论范围
// ----------------------------------------------------------------------------
// 已展开主函数全部 switch 分支、直接业务依赖、模式判断和队列插入算法。
// 这里的 0x6000、0x6060、0x6062 等是本地消息队列标识，不能当网络 opcode。
// 事件消费者、UI 完成后重新继续的完整闭环未在本篇展开；审阅清单明确保留。
// 伪代码的 COleDocument/CPaneContainerManager 等名称与实际短函数不匹配，
// 本篇按地址和指令解释，不沿用这些库函数名称给游戏字段命名。
//
// 入口与返回值
// ----------------------------------------------------------------------------
// 签名按汇编：this=游戏上下文，a2=队列插入游标指针；a3 本函数未读取。
// 上层 0x681380 收到本地 0x6080、stage=1 后调用本函数。
// 返回 1：上层在已更新游标位置插入 0x6080(stage=2)，继续后续落点阶段。
// 返回 0：上层不插入 stage=2；不能笼统翻译成“等服务端响应”。
// 有些返回 0 分支已经插入本地窗口/动画事件；另一些没有入队，须查其他调度。
// 0x681380 的证据在证据/continue_entry.json；本篇不把其其他阶段计入审阅完成。
//
// 必要结构视图：G=本函数 this，M=G+0x65C，A=当前演员对象
// ----------------------------------------------------------------------------
// G+0xE28       DWORD 当前演员索引；G+0xE00+index*4 指向 A。
// G+0xE58+index BYTE  演员标志；本篇只称 flag，不以此独立证明 NPC/BOSS 身份。
// G+0xE30+index BYTE  参与者扫描标志；G+0xE20 为扫描数量。
// G+0x14776    BYTE  不等于 -1 时跳过 stage1（0x7D5E10）。
// G+0x14761    BYTE  大于 0 时 type9/10 排提示并继续（0x7D6F90）。
// G+0x14778/79 BYTE  type9、type67 特定等待分支分别清零；完整字段名待证。
// G+0xDF8      指针 type67 条件/奖励对象；+0x524 为门槛，+0x528 为金额。
// M+0x18       DWORD 模式值；M+0x6C 为模式2使用的子类型值。
// M+0x34       指针 格子表；每格8字节，首字节按有符号静态类型读取。
// M+0x4C/0x4E  WORD  type28 配对位置；M+0x50/0x52 为 type61 配对位置。
// A+0x5B8      DWORD 当前格位置；A+0x5D0==7、+0x5DB!=0、+0x5DC>0 均跳过。
// A+0x5E0      DWORD 数量字段，在本篇参与现金门槛比较；A+0x5E8 参与点券分支。
// A+0x5D6/+0x5D7 BYTE 参与者 type2/type3 阻断扫描，比较值均为 -1。
// 以上偏移由 this 调整和被调用 getter 联合确认；业务名称仍须消费者/资源佐证。
//
// 公共前置：0x7C54ED 至 0x7C55DC
// ----------------------------------------------------------------------------
// 若模式4且当前 flag 非零，直接返回1。
// 再读取当前位置；若 G+0x14776 非-1、位置类型不被允许、A+0x5D0==7、
// A+0x5DB非零或有符号 A+0x5DC>0，直接返回1。
// 0x7E2730 允许类型0..10、28、41..43、51..62、67..70。
// 负类型例如-1不满足首项无符号比较，提前跳过；不能说负值落入type0。
// 通过前置后才按静态类型分派；零类型最终走默认返回1。
//
// 模式谓词缩写（按已展开代码定义）
// ----------------------------------------------------------------------------
// P0 = 模式0，或模式2且子类型0。实现 0x63ECA0。
// P1 = 模式1，或模式2且子类型1，或模式3，或模式4。实现 0x63EDF0。
// P3 = 模式3。实现 0x63E160 -> 0x63E1A0。
// P4 = 模式4。实现 0x63E990 -> 0x629E10。
// H2 = 存在扫描标志非零且演员+0x5D6非-1的参与者。实现 0x7C07D0。
// H3 = 存在扫描标志非零且演员+0x5D7非-1的参与者。实现 0x7C0850。
//
// 分支：type 1、55、56、58、59、60、62、68、69、70
// ----------------------------------------------------------------------------
// 每个分支直接返回0，没有调用入队函数，也没有自行发送请求。
// 不能据此猜测各类型对应事件名称或回包；需追本地事件/网络分派闭环。
// switch 的70个分支目标均保存在 stage1_switch.json，包括合并前的独立地址。
//
// 分支：type 2，入口 0x7C5624
// ----------------------------------------------------------------------------
// P0 && H2：返回0，不入队。
// 否则若 P1：amount=min(A点券*dword_A87104, dword_A87108)，
// count=amount/dword_A87104；仅 count>0 时依次入队6062和6060。
// 6062：演员=当前，偏移4=1，偏移6=WORD(count)。
// 6060：演员=当前，偏移3=1，偏移5=1，偏移8=DWORD(amount)。
// 其余情况及队列构造完成后返回1。
// 此处未显式检查除数为零或乘法溢出，不能推广到任意自定义资源值均安全。
//
// 分支：type 3，入口 0x7C5758
// ----------------------------------------------------------------------------
// P0 && H3：返回0，不入队；非P1：返回1。
// P1：先入队6063（演员，偏移3=2）；再更新全局 A8A948/A8A94C/A8A950，
// 分别为当前演员DWORD、当前位置DWORD、dword_A87110。
// 入队6000：子事件11，偏移4=1，偏移12指向A8A948，偏移16长度12。
// 返回0；使用全局载荷而非栈地址，后续消费者需要独立展开。
//
// 分支：type 4，入口 0x7C584A
// ----------------------------------------------------------------------------
// 0x7D9D10 的this=G+0xC5C，扫描该子对象偏移1..32，存在值-1才进入后续分支。
// 无空槽：返回1。存在空槽且 A+0x5E0>1000：入队仅2字节的608B，返回0。
// 存在空槽但数量<=1000：入队6003提示，文本索引129，返回1。
// 空槽与金额条件在此已确定；具体库存对象与608B完成回调仍待消费者验证。
//
// 分支：type 5/6/7，入口 0x7C5924
// ----------------------------------------------------------------------------
// P3 && flag：不入队，返回1。否则分别选择80、50、30。
// 顺序：6001（子事件13，偏移6=0）->6062（演员，偏移3=1，WORD数量）。
// 仅type5额外入队6002：子事件由0x69B0E0(80)=19，演员、偏移6=1、时长1350。
// 最后返回1；stage2在这些效果之后插入，不是收到4013就同步结束全部动画。
//
// 分支：type 8、41、42、43、51、52、53、54
// ----------------------------------------------------------------------------
// P3 && flag 时返回1；其余返回0。此处没有入队。
// 这些类型判断语句等价但具有各自跳表目标，不能漏记成仅type8。
//
// 分支：type 9/10，入口 0x7C5AD1 / 0x7C5B7D
// ----------------------------------------------------------------------------
// G+0x14761>0：排6003提示；type9用文本305，type10用文本304，然后返回1。
// 否则type9清 G+0x14778 后返回0；type10直接返回0。
// 文本305/304的具体内容及UI消费者本篇未解码，不以猜测代替名称。
//
// 分支：type 28/61，入口 0x7C5C1F
// ----------------------------------------------------------------------------
// 0x7E6910 按类型在两个配对位置中找不同于当前位置者；找不到时返回0。
// 不存在“目标0必非法”的额外检查，编辑地图需验证配对和目标有效性。
// 依次入队四项：6000(子事件26,旧位置结构8字节)、6005(目标WORD)、
// 606C(演员,目标WORD)、6000(子事件26,目标结构8字节)，然后返回0。
// A8A938保存旧位置，A8A92C保存目标；两处各有第二DWORD初始化为0。
// A8A944的位1/位2只用于一次性结构初始化，不能解释成业务完成标记。
// 位置何时修改、动画何时继续，需要对应606C/6000消费者闭环。
//
// 分支：type 57，入口 0x7C5F5C
// ----------------------------------------------------------------------------
// flag非零：6060(演员,偏移3=1,偏移5=1,数量2000)，然后6002(子事件19,1350)。
// flag为零且点券>=25：6001(13) ->6062(偏移4=1,数量25) ->6060(2000) ->6002(19)。
// flag为零且点券<25：文本181复制到全局A8A890，再排6003，载荷长度固定128。
// 三条路径最终均返回1；不得把25点与2000金额这对常数套用到其他格。
//
// 分支：type 67，入口 0x7C6213
// ----------------------------------------------------------------------------
// 此分支给0x7FABE0/7FAB70/7FACB0的this为当前演员A，见7C621F/7C6330/7C634E。
// A+0x6C0为WORD计数；A+0x6A4为WORD位置数组，A+0x6B6为BYTE状态数组。
// 0x7FABE0：所有状态非零返回1；计数为0也返回1，不能省略空数组情形。
// 全部完成：排6060（数量取G+0xDF8指向对象+0x528）；
// 用文本344与该金额sprintf到全局A8A7F0；排6003固定128字节载荷；清零状态数组。
// 非全部完成：0x7FAB70按当前位置查状态；找不到返回1。
// 若找到状态0且A+0x5E0严格大于门槛+0x524，清G+0x14779，返回0。
// 其余情况返回1。状态数组容量、文字长度与业务命名仍需要资源加载方约束。
//
// 默认路径与队列错误边界
// ----------------------------------------------------------------------------
// 其他类型走返回1；多数不在公共允许表中的类型会更早跳过。
// 每次入队执行 *a2=insert(...,*a2)，不是仅递增消息数。
// 队列满时底层返回-1；本函数没有对每次返回值检查，不能声称此路径无丢队列风险。
// 事件结构包含指针而非自动深拷贝；两项文本全局缓冲与配对位置全局载荷需保持生存期。
//
// 尚未闭合的边界
// ----------------------------------------------------------------------------

// type4空槽对象的准确业务名字，type67资源数组容量及全局文本128字节限制。
