// 阅读约定

// 用 G 表示主游戏对象；P 为当前参与者对象；M 为 G+0x65C 的地图子对象。
// 当前参与者槽 = DWORD[G+0xE28]；P = DWORD[G+0xE00+4*当前槽]。
// 不可把下面的 P+1488 状态字段与 G+1488 混为一谈。
// 模式值以 M+24 的原始整数记录：mode3、mode4 指精确值 3、4。
// mode3 由 0x63E160 -> 0x63E1A0 判断；后者曾被误标 MFC 函数名。
// mode4 由 0x63E990 -> 0x629E10 判断；以指令与比较常数为准。
//
// 四个参数与入口条件
// ----------------------------------------------------------------------------
// 0x7C6640 的 this 为 G；a2 是可更新的队列插入游标指针；a3 指向本地时序量；a4 为重入编号。
// a3 在此处用于时长运算；“累计”是用途描述，具体单位和完整更新协议须结合消费者核查。
// a2 的精确容器协议以队列专题为准；本函数每次将 sub_609D34 返回值写回 *a2。
// 0x64FA50（sub_609D34 实现）复制局部事件结构，再交给下游队列函数。
// 这些含指针的 0x6000/0x6003 结构是本地结构，不能照抄成网络载荷。
//
// 0x7C66A3：若 mode4 且 BYTE[G+3672+当前槽] 非零，立即返回 true。
// 0x7C66E5：从 P+1464 取得当前地形编号 t。
// 0x7C6707：若 BYTE[G+83830] != -1，或地图地形 t 的地产引用为 -1，返回 true。
// 地形记录地址 = DWORD[M+48] + 8*t；+2 的有符号 WORD 为地产编号 p。
// 地产记录 L = DWORD[M+56] + 68*p，不能直接拿地形编号索引地产表。
// mode3/mode4 下先读 L+3 所有者、L+2 等级、L+1 建筑种类、P+1488 状态编号。
//
// 主入口的返回值含义
// ----------------------------------------------------------------------------
// handler 0x681380 收到本地 0x6080：+2 为 stage，+3 为有符号重入字节。
// stage=2 调用 0x7C6640 后，返回非零才追加本地 0x6080(stage=6)。
// 返回零时不追加 stage6；本函数通常已排入一个交互事件或指定恢复事件。
// 因而 true 只代表允许后续阶段；false 不等于崩溃、错误或永久卡局。
//
// a4 重入表：与汇编跳转位置逐项核对
// ----------------------------------------------------------------------------
// a4=3  -> 0x7C9259：普通地产的升级判定；跳过前面的类型2/类型6效果。
// a4=4  -> 0x7CA1AA：后段特殊类型3/4/5/6处理；跳过租金前段。
// a4=5  -> 0x7CAB1B：直接调用 0x7CB3F0(分支4, 停止穿透标志0)。
// a4=7  -> 0x7C6E05：特殊建筑类型效果，跳过新建/升级选择。
// a4=8  -> 0x7C6B34：特殊建筑新建/升级判定。
// 其它值 -> 正常入口；不能把 -1、0、3、7、8 统一当作“继续即可”。
// 重入仍经过前述入口条件；3/4/7/8 不是无条件跳到任意内部地址。
//
// 正常分支树：mode3/mode4
// ----------------------------------------------------------------------------
// 无所有者（L+3 == -1）：先检查参与者抑制状态，再检查特殊旁路。
//   mode4 且 P+1488 == 5 时，调用 0x7CB3F0(5,1)，随后返回 true。
//   其余用 L+8 价格，经 0x7CF5E0 调整，与 P+1504 比较。
//   现金严格大于价格 -> 排本地 0x6081，返回 false；相等也归入提示文本129。
// 已有所有者且非本人、且 P+1480+所有者 标志为零：走类型效果的他有分支。
//   mode4 的 P+1488==5 旁路可先调用 0x7CB3F0(5,1)；其余进入类型16效果。
// 本人所有或 P+1480+所有者 标志非零：进入特殊建筑新建/升级流程。
//   特殊旁路在 0x7C6AFF 先调用 0x7CB3F0(5,1)。
//   0x7C6B07 构造 0x6080，+2=2，+3=8，长度4；排队后返回 false。
//   这是明确写入重入8的来源，不能被解释为默认构造时的 -1。
// 特殊建筑的选择、满级和类型效果详见 阶段2_02_建筑选择与本地事件.txt。
//
// 正常分支树：其它模式
// ----------------------------------------------------------------------------
// 类型8/9/10：仅未归属且类型10且没有抑制状态时允许 0x6081 选择；否则直接 true。
// 已归属且本人所有：检查类型2、类型6效果，然后走普通升级检查。
//   类型2未命中既有记录 -> 本地0x6086，登记等待状态10，返回 false。
//   类型6 -> 检查/找回资源或关联地产，生成提示及本地动画事件；细节尚未完整命名。
//   可升级时严格比较现金>费用 -> 本地0x6082，清 G+83808，返回 false。
//   无需升级/余额不足 -> 调用后续效果函数 0x7CB3F0(4,0)。
// 已归属且本人所有但被抑制：跳过前述本人流程，直接 0x7CB3F0(4,0)。
// 已归属且他人所有：先检查免收/暂停效果，再区分类型0/1租金和类型3/4/5/6。
// 未归属且不属于类型8/9/10：普通模式且没有特殊抑制时检查购地条件。
//   现金>调整后 L+8 -> 0x6081 并 false；否则提示129后走后续效果。
