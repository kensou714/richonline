// 二、入口与对象
// 7CB3F0 的 this 是 G；7CB414/7CB429/7CB448 明确加0x65C后查询地图模式。
// 7CB459读取G+0xE28；7CB462由G+0xE00中的角色指针数组选出P。
// 模式门为 M+24==0，或(M+24==2且M+108==0)，或M+24==4。

// 三、阶段、状态与返回
// 7CB4B0/7CB4B8/7CB4C3/7CB4CE分别辨认start=4/3/5/6。
// 其他start值进入状态4；条件失败且允许继续时，顺序为4→3→5→6。
// 7CB708/7CB936/7CBAFE/7CBC20读取oneStage的低BYTE，而不是整DWORD。
// 727B40/701530/7D7400/727B70从P+0x5D0读取signed BYTE，
// 经sub常量、neg、sbb、inc判断是否等于4/3/5/6，返回0或1。
// &scratch在7CB3F0本体未使用，不应解释成此函数填写的错误结果。
// 状态5只排除“当前角色已经拥有”；原owner=-1仍能进入，也未排除mode4。
