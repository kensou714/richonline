// 输入路径与随机显示
// ============================================================================
// 事实：真实串保存于键盘对象 +400；随机串只是临时生成给 EDIT 的显示内容。
// 912ED0 只有 lea eax,[ecx+190h]; retn，实际返回 this+400。
// IDA 的 MFC GetPaneContainerManager 名字不符合本处用途，不据误符号解释结构体。
//
// 软键命令：913E90，登记为 WM_COMMAND (0x111)
//   HIWORD(wParam)=0x100 且 lParam==this+392 时，SetFocus(this+272) 然后返回 0。
//   即 EDIT 的 EN_SETFOCUS 通知被转到键盘窗口；没有从 EDIT 读取真实文本。
//   其余命令先调用 919960(lParam)，非零才把返回对象交 917130 取 +656 首 BYTE。
//   919960 通过外部映射 9192D0 找节点，比 ACD728 哨兵，命中返回节点 +16。
//   映射查找内部和节点值有效性未审；不能称任意 lParam 都会被安全验证。
//
//   字节 <0xF7：仅 strlen(this+400)<64 时，用 sprintf("%c") 追加一个字节。
//   0xFF：非空时删除真实串最后一个 BYTE；不是多字节字符删除。
//   0xFE：SendMessageA(this+268, 0x401, 0, 1)，请求提交。
//   0xFA：同消息 lParam=0，请求取消。
//   0xFB：隐藏 Upper、显示 Lower，模式写 1。
//   0xFC：调 913DE0(this,0)，隐藏 Lower、显示 Upper，模式写 0。
//   0xFD：在结尾写 WORD 9，追加 TAB 和 NUL；此分支无 64 字节检查。
//   0xF9：在结尾写 WORD 32，追加空格和 NUL；此分支无 64 字节检查。
//   其它特殊字节没有编辑动作；有效对象命令仍进入显示刷新。
//
// 当前固定布局的可达性
//   9157F0 读取 A6917C 起八个行指针，前四个 Lower，后四个 Upper。
//   A315A4 数字行两组共用；其余六行明确区分大小写。
//   已保存八行字节只包含 F8、FF、FE、FC、FA、FB 这些特殊值。
//   F8 是 10 px 空白；普通字符宽 rand%16+10，高 25 px；F7 分支是 5 px 空白。
//   FF 标签为左箭头，动作是退格；FE 标签为确定，FA 为取消，FC 为大写，FB 为小写。
//   F9 Space、FD Tab、F7 的构造/处理分支存在，但八行数据未使用它们。
//   因而不能宣称当前固定 UI 能无限追加空格或 TAB，更不能宣称已复现溢出。
//   如以后允许编辑键盘行表，应重新验证特殊键长度门、对象容量及显示 Buffer 上限。
//
// 物理键：914220，登记为 WM_KEYDOWN (0x100)
//   A..Z：默认转小写；SHIFT 高位按下或 CAPSLOCK 低位为 1 就保留大写。
//   两条件是 OR；不是通常键盘的 SHIFT 与 CAPSLOCK 异或翻转。
//   顶排 0..9 原样，小键盘 0x60..0x69 减 48 后变为字符 0..9。
//   三类追加都先查 strlen<64；本轮恢复的是按字节长度检查。
//   BACKSPACE 删除最后 BYTE；ENTER 发 0x401/lParam=1；ESC 发同消息/lParam=0。
//   CAPSLOCK 按 +388 分支切换显示；其它键不追加，仍刷新显示。
//   空格、TAB 和通常标点没有已证物理键追加路径；未见 WM_CHAR 登记。
//
// 切换与显示
//   913DE0 参数 0 显示 Upper，1 显示 Lower；其它值只保存到 +388。
//   9157F0 初始按 GetKeyState(CAPSLOCK)&1 选层，并写对应 +388。
//   EDIT 建窗样式 0x50800001，位于 (5,5)，高度 16；本轮未恢复全部资源外观。
//   初始 WM_SETTEXT 取 A316D0，Big5 解码为“請輸入密碼...”；这只证明本地提示文案。
//   两输入函数都以 time(NULL) 重播种，按真实串 strlen 生成同长度随机字节串。
//   rand%62：0..25 -> a..z，26..51 -> A..Z，52..61 -> 0..9。
//   向 EDIT 先发 EM_SETPASSWORDCHAR(0xCC,'*')，再 WM_SETTEXT(0x0C,随机串)。
//   随机串不回写 +400；提交读取 +400，不读取显示串，不存在本处加密证据。
//   最后发外层 WM_COMMAND(0x111,0,this+272)；外层 911AB0 对该消息返回 0。
//   同秒重播种可能产生相同随机前缀；实际显示和焦点变化仍需实机验证。
