// ============================================================================
// 审阅结论：最终四份正文与二十个入口清单未发现阻断性语义错误。
// 结论限于保存的静态证据；没有启动游戏、加载 DLL 或修改客户端。
//
// 独立方法与结果
//   独立解析当前 RnClient.exe 的 PE 节表和导入表，以 Capstone 5.0.6 解码。
//   SHA256 为 a23410e79637e312c932f861176d8d81cd1fd5d222a286f279feccdece6263c2。
//   16 个本轮新入口、4 个历史复用入口共 20 个地址，与最终清单完全对应。
//   70 个声明/指令范围比磁盘 PASS；声明块共 8439 B，不重复计入指令范围。
//   29 个 E9 桥以独立反汇编核目标 PASS，32 个 incoming 记录比磁盘 PASS。
//   324 B 常量与表窗口 PASS，其中 A31690 的 13 个表槽逐项核指针。
//   34 个关键语义指令锚点 PASS，6 个 Win32 调用独立核导入名称。
//   历史来源哈希与复用声明块一致；原证 validate_evidence.py 也运行 PASS。
//   独立脚本与结果见 证据/independent_verify.py、independent_validation.json。
//
// 核准的关键契约
//   912ED0 返回键盘入口 this+400，是真实串；917130 返回按键入口 this+656。
//   913E90 保存键盘 this 后，将 HWND 映射结果作为 getter 的 ECX；两对象不可混同。
//   914220 的 SHIFT 高位或 CAPSLOCK 低位进入大写路径，条件为 OR。
//   软键普通追加和三类物理追加有 strlen<64 门；F9/FD 分支没有同一门。
//   独立读取 A6917C 八行及行内容只见 F8/FA/FB/FC/FE/FF，未见 F7/F9/FD。
//   这限定当前固定行表，不证明外部永远不能构造其它控件或命令。
//   911AB0 提交复制真实串至 ACD5D0 包含 NUL，EndDialog 返回 100。
//   911E40 仅在 100 时复制全局真实串至 out；显示用随机串不进入这条返回路径。
//   模态分配 708 B、尺寸字段与两处 IDIV 均有指令支持，风险采用条件性表述。
//   WM_DESTROY -> 虚表首槽 -> 917040 -> 9154F0 链与 flags 低位释放门一致。
//
// 未闭合范围
//   919A60 基础构造、基础 WNDPROC、91A4F0、91A2A0 和子控件析构本体未审。
//   9157B0 查找、916C10 插入维护、915180 递归清理与完整树状态行为未审。
//   真实串与输出缓冲的精确容量、外部业务调用者和 DLL 资源未闭合。
