// 提交返回与清理边界
// ============================================================================
// 调用入口：911E40(HWND parent, char *out)
//   若 ACD708==0，调用 GetWindowLongA(parent,-6)，本体没有把返回值写回 ACD708。
//   LoadLibraryA("idguardlibr.dll") 成功后 ShowCursor(TRUE)。
//   DialogBoxParamA(该模块,"KeyboardDlg",parent,60CD09,0) 调模态对话框。
//   60CD09 的 E9 指向 911AB0；退出后 ShowCursor(FALSE)，再 FreeLibrary。
//   Dialog 返回 100：从 ACD5D0 逐字节复制到 out，返回 1。
//   其它正返回值：返回 0；零/负值或者 DLL 加载失败：弹错误框，返回 -1。
//   拷贝包含 NUL，没有 out 容量参数；本轮未审调用者 72B180 的缓冲契约。
//   72B492 -> 606602 -> 911E40 只有导航证据，不把整段外部业务标为已审。
//
// 外层消息过程：911AB0
//   WM_GETDLGCODE (0x87) 返回 4；WM_COMMAND (0x111) 返回 0。
//   WM_PAINT 只 BeginPaint/EndPaint；未在本体绘制键盘。
//   WM_INITDIALOG (0x110) 分配 708 B，调 916E80，结果保存 ACC41C+4440。
//   读取自身窗口、客户区矩形，非客户差值加虚表 +32 返回尺寸得到目标大小。
//   +32 已证为 918EF0 的 +380/+384 复制叶；这些尺寸的基础生产过程仍未全审。
//   取父窗口矩形并按两次 rand%余量定位，MoveWindow 后 InvalidateRect。
//   新分配失败保存 NULL 后仍有尺寸虚调；本体无相应拒绝路径，未实机触发。
//   水平/垂直余量为零会到 IDIV0；有效窗口是否可能产生零余量未实机确认。
//
// 提交与取消
//   0x401 且 lParam==1：调用 912ED0 得真实串 +400，逐字节复制至 ACD5D0。
//   复制包括 NUL，代码无长度参数，然后 EndDialog(hDlg,100)，消息过程返回 1。
//   0x401 其它 lParam：仅清 ACD5D0 首 BYTE，EndDialog(hDlg,200)，返回 1。
//   WM_CLOSE (0x10)：同样清首 BYTE，EndDialog(200)，但消息过程返回 0。
//   这里没有确认非空或用户名/口令合法性的检查；是否存在外部业务校验未知。
//   ACD5D0 与附近全局的距离不是已证容量；不把全局数据项跨度当数组声明。
//
// 外层销毁到实际析构
//   WM_DESTROY (2) 若 ACC41C+4440 非零，虚表 0 调用 flags=1。
//   A31690+0 -> 606067 -> 917040，先调 9154F0，再按 flags低位决定 operator delete(this)。
//   911AB0 不把 ACC41C+4440 写零；这只是指针字段事实，未证明重复销毁实际可达。
//
//   9154F0 先 DestroyWindow(this+392)。
//   遍历 +664..+668 字符按钮，逐个非空对象虚表 0(flags=1)，释放指针数组并清边界。
//   再遍历 +680..+684 两个层容器，以相同方式销毁并清边界。
//   调 915180 清消息树、delete +696 哨兵，清 +696/+700；然后进入基础析构 91A2A0。
//   子控件虚表 0、树递归、基础析构本体均未审，不声明所有 HWND/节点已成功释放。
//   本体没有直接 DeleteObject(this+396) 或 UnregisterClassA。
//   基础析构可能接管刷子、窗口及类注册；本轮不据缺少本地 API 就宣称资源泄漏。
//
// 开发使用边界
//   修改键盘行表必须区分显示标签与控件 +656 的操作字节。
//   替换随机显示应保留真实串 +400 与返回 100 的拷贝路径，避免把显示串当业务输入。
//   新增空格/TAB、中文输入或长输入前，应补容量、字节删除、编码与 out 长度契约。
//   本轮没有修改 EXE、DLL、资源或游戏运行状态，也没有对线上通信作功能修补。
