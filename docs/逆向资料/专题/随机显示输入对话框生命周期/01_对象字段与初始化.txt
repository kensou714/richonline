// 键盘已证字段

//   +396               CreateSolidBrush(0xD8E9EC) 返回值。
//   +400               真实输入串起点；构造只清首 BYTE，不把整块初始化为零。
//   +664 / +668 / +672  字符按钮指针序列的起始、末尾、容量边界消费字段。

//
// 按键控件已证字段
//   +656               917130 返回按键控件 this+656，命令处理读取该处首 BYTE。
//                     其余内容和分配容量未闭合；这个 this 不是 JoyparkKeyboard 对象。
//
// 大小与容量边界
//   WM_INITDIALOG 在 911BED 调 new(0x2C4)，分配对象大小 708 B。
//   +400 的真实串与 +664 的已证字段相距 264 B；这不等同已经恢复 char[264] 声明。
//   按键控件 +656 字节不属于同一 this；不能据它推导真实串容量 256 B。
//   正常字符追加的 64 字节检查是操作契约，不是对象实际容量声明。
//   随机显示栈 Buffer 在两个输入主体中为 260 B；只清显示结尾，不清真实串。
//
// 构造与注册
//   916E80 先调基础构造 60C421 -> 919A60，再写虚表 A31690。
//   初始化两个指针序列、消息树、刷子和真实串首字节；模式置 1。
//   类名和窗口类名均为 JoyparkKeyboard，样式字段写 0x50000000。
//   最后调 6037D1 -> 91A5C0(this, 1)，但忽略其成功/失败返回值，构造仍返回 this。
//
//   91A5C0 首先无限等待共享句柄；不检查 WaitForSingleObject 的返回值。
//   91A5F8 虚调表 +44；A31690+44 -> 611093 -> 9169B0。
//   后续查询/注册类、调 91A4F0，再尝试 CreateWindowExA，返回 1 或 0。
//   91A4F0、基础 WNDPROC、窗口与对象的映射仍未知，不能假装整条 Win32 消息入口已审。
//   类注册失败时只容忍 GetLastError=1410 或 0，其他错误返回 0。
//   容忍分支可能 DeleteObject(this+308)；本轮不推导刷子的完整所有权。
//
// 消息表
//   9169B0 以 this+692 为容器对象，提交五对消息键与回调地址：
//   0x087 -> 608632；0x100 -> 60B8D2；0x001 -> 6068AF；
//   0x00F -> 6054B9；0x111 -> 60C17E。
//   已审回调：0x100 为 914220，0x001 为 9157F0，0x111 为 913E90。
//   0x087 / 0x00F 回调本体未审，不把外层对话框返回值套给内层控件。
//   916AA0 主体按无符号消息键找插入位置；已有键时返回原节点且 inserted=0。
