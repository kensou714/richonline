// 调用闭环
//
// 0x625310 / 0x729220 取得配置记录：文本地址位于 +3394，端口 +3410。
//   → 0x612010 跳板 → 0x8CD310：WSAStartup(2.2)、inet_addr、htons。
//   → 保存回调跳板 0x60152B，实际函数 0x6BEFB0。
// 0x749A20 / 0x74B720 → 0x603F56 → 0x8CD9E0：缓存槽请求。
// 0x74D650 → 0x6119F8 → 0x8CDC80：即时槽请求。
// 0x624CA0 → 0x60667F → 0x8CD400：每次泵处理两个槽。
//   → FD_READ → 0x6036F5 → 0x8CCC20：收头、收体、文本回调。
//   → 0x6BEFB0：名称匹配后更新 UI91 或 UI94 的多行文本控件。
// 0x8CD890 统一关闭；0x8CDEB0 / 0x8CDF60 分别取消即时槽和缓存槽。

// 全局变量：不要与连接对象偏移混用
//
// 0xACBDB0   IPv4，来自 inet_addr；直接写 sockaddr 地址字段。
// 0xACBDB4   WORD 端口，已通过 htons；连接时不再变换。
// 0xACBDB8   __stdcall 回调(name, text, slot)。
// 0xACBDBC   即时槽对象指针；回调 slot=1。
// 0xACBDC0   缓存槽对象指针；回调 slot=0。
// 0xACBDC4   缓存文本指针，销毁缓存槽时同时释放。
// 0xACBDC8   收包本次剩余字节数暂存，两个槽顺序复用。
// 0xA678C0   两项全局指针地址表：先缓存槽，再即时槽。

// 连接对象：0x8CC970 构造；调用方分配 0x2C 字节
//
// +00 DWORD   SOCKET；初始化连接分支才写入。
// +04 DWORD   WSAEVENT；初始化连接分支才写入。
// +08 BYTE    已执行连接初始化标志；不等于 TCP 连接成功。
// +09..0B     未归类对齐区，不能当线上字段。
// +0C DWORD   待发送缓冲对象指针。
// +10 DWORD   接收阶段：1=头，2=体；本通道收完体恢复 1。
// +14 DWORD   当前响应类型；构造时 -1，只接受线上类型 0。
// +18..27     内嵌 16 字节收头缓冲对象，初始容量为 8。
// +28 DWORD   动态收体缓冲对象指针。
//
// 0x8CCA10 释放待发缓冲；已初始化时再释放收体缓冲并关闭事件/socket；
// 随后销毁内嵌缓冲。0x8CD820 是带删除标志的外层析构包装。

// 缓冲对象：0x8CE040 分配数据，0x8CE0D0 释放数据
//
// +00 DWORD   分配基址。
// +04 DWORD   读游标，也是 send 的当前位置。
// +08 DWORD   写游标，也是 recv 的当前位置。
// +0C DWORD   容量，不是已写入数量。
//
// 0x8CD270：可接收量 = 容量 - (写游标 - 基址)。
// 0x8CD220：可读取量 = 容量 - (读游标 - 基址)。
// 0x8CD2C0 / 0x8CD7D0：无边界检查地推进写/读游标。
// 0x8CE1B0：从读游标取 DWORD，再推进 4；不做长度检查。
// 0x8CE140：返回读游标，再推进请求长度；不做长度检查。
// 0x8CE220：复制至写游标并推进；不校验目标容量。
// 0x8CE2A0：清零整块容量，并将两个游标都恢复基址。
//
// 因此该对象不是通用安全字节流；容量与已写入量分离，
// 当前请求路径依赖一次填满，响应路径依赖 recv 填满后才读取。

// 客户端请求：固定 42 字节，由 0x8CDBF0 构造
//
// 偏移  宽度  值
// +00      2  0D 0A，即 CRLF。
// +02      4  类型 0。
// +06      4  载荷长度 32，不含前 10 字节。
// +10     32  请求名称，以 strncpy 限制复制；恰好 32 字节可无末尾 NUL。
//
// 0x8CD9E0 与 0x8CDC80 均构造以上请求，没有普通大厅的 XOR/反转步骤。
// 这个结论仅覆盖本条已追踪路径，不能外推为其它连接均不加密。

// 服务端响应：与请求不对称，不带 CRLF
//
// +00 DWORD   类型，只接受 0。
// +04 DWORD   载荷长度 L，只检查 L <= 432 (0x1B0)。
// +08..       L 字节载荷。
// 载荷 +00..31 为名称槽；后面 L-32 字节作为正文复制，再补 NUL。
// 接收完成后：缓存槽替换 0xACBDC4，再同步调用回调；即时槽不保存正文。
// 回调返回即释放临时正文。因此回调参数不是可长期持有的指针。
// 当前代码没有证明 L>=32，协议实现应将这个下界作为防护约束。

// 事件与断连
//
// 0x8CD400 注册 0x33：FD_READ、FD_WRITE、FD_CONNECT、FD_CLOSE。
// 已初始化时以 0 毫秒 WSAWaitForMultipleEvents 轮询。
// FD_WRITE 单次 send；正数返回推进读游标；-1 直接走销毁。
// FD_READ 错误或接收器返回 0 均销毁；FD_CLOSE 无条件销毁。
// 接收器把 recv==0 与 WSAEWOULDBLOCK(10035) 都返回“暂可继续”。
// 正常关闭依赖外层 FD_CLOSE；不能把接收器返回 1 当成收到有效包。

// 缓存与替换
//
// 0x8CD9E0：已有缓存时直接用新请求名称和旧缓存回调，不再请求网络；
//           无缓存且已有在途连接时忽略新建请求。
// 0x8CDC80：每次先销毁已有即时槽，再创建新请求。
// 0x8CDF60：销毁缓存槽并释放缓存，是名称切换时的重要失效入口。
// 尚未证明所有上层名称变化都调用该入口；不得声称缓存按名称分区。

// UI 消费端：0x6BEFB0
//
// slot=0：UI91，名称控件21，多行正文控件10。
// slot=1：UI94，名称控件11，多行正文控件16。
// 回包名称与名称控件按前32字节比较，不匹配即丢弃显示。
// 按30字节宽度分行，>0x80 作为双字节字符处理；没有 UTF-8 解码器。
// “双字节编码习惯”是代码事实，具体码页需结合资源和运行时进一步确认。
