// ABI、容器和返回域
// ----------------------------------------------------------------------------
// 五主体入口ECX保存为M，后续所有地图谓词/字段读都恢复ECX=M；不是伪码所写无this的__stdcall。
// 7E4750有三个完整DWORD参数(owner,threshold,excludedRecord)，7E4824 RET0Ch。
// 另四入口有两个完整DWORD参数(owner,threshold)，各自末尾RET8。没有栈参低BYTE截断。
// 容器C=M+46Ch：695040读取[C+0] DWORD计数n；每个入口只在循环前读取一次n。
// 695010读取WORD[[C+0Ch]+2*i]，即基址槽M+478h；各入口紧接MOVSX EAX,AX得signed16候选r。
// 循环i从0递增，以signed i<n继续；n<=0直接返回-1，不读取元素。
// r作为地产记录编号传给各getter，再以r*44h(68)索引[M+38h]数组；返回被选中的r，不是循环i。
// 本体不排序、不打乱容器、不生成随机数、不求和、不读金额、不按与当前位置的距离评分。
// 返回值先设FFFFFFFF，只有通过全部过滤与比较才被r覆盖；没有合格候选时仍为-1。
// 容器填充者/容量与地图加载全过程不在本批；这里只确证该实例M+46Ch的读取路径。
// n与实际分配容量、r非负及上限、M/[M+38h]/[C+0Ch]非NULL均无本体检查。
// WORD 8000h至FFFFh被符号扩展为负，可能在谓词里越界；不能把-1元素当自动跳过哨兵。
// 若非法r=-1恰好通过读取，返回与失败哨兵相撞；合法元素域需由容器生产者保证。
//
// 68字节地产记录字段：均以同一M实例调用旧契约
// ----------------------------------------------------------------------------
// 定义R(r)=[M+38h]+44h*r；下列+0/+1/+2/+3都是单个BYTE，不是DWORD价格字段。
// K=sign8(R+0)：63E290判断K==11，63E2D0判断K==12；本批称类型11/12，不猜其显示名称。
// S=sign8(R+1)：6BC0D0判断S==0，63F500判断S==1；不从数值擅自合并建筑类型或附加标志。
// L=sign8(R+2)：63E960返回完整32位符号扩展值，范围-128..127；是搜索实际比较量。
// O=sign8(R+3)：63F5B0判断O==owner完整32位值；owner不会先截为BYTE。
// 上层以L作为加/减等级的输入并写回R+2，支持称该量为等级；没有金额或地产价值参与搜索。
// 这些getter没有索引/NULL边界检查；五入口取谓词AL作真假，读取等级则用完整EAX作signed比较。
// 既有短契约及完整来源记录分别存formal_functions.json的dependency_contracts，不计新增函数审阅。
//
// 五入口矩阵：过滤按列出的顺序短路
// ----------------------------------------------------------------------------
// 7E4660：K==11 → S==0 → O==owner → L<threshold；通过后result=r、threshold=再读L。
// 7E4750：K==12 → r!=excludedRecord → O==owner → L<threshold；通过后同上。
// 7E4830：K==11 → S==0 → O==owner → 第一次L>0 → 第二次L<=threshold；通过后threshold=第三次L。
// 7E4930：K==11 → S==1 → O==owner → 第一次L>0 → 第二次L<=threshold；通过后threshold=第三次L。
// 7E4A30：K==12 → O==owner → 第一次L>0 → 第二次L<=threshold；通过后threshold=第三次L。
// 7E4750只有它显式排除excludedRecord；后三入口没有对应排除参数，不能凭业务期望补上。
// 前两入口是严格小于：7E4717/7E47F8 JGE拒绝。同等级后出现者不会替换，保留最先遇见者。
// 后三是正值且小于等于：7E48E6/7E49E6/7E4ACF JLE拒绝非正值；7E48F7/7E49F7/7E4AE0 JG拒绝较大值。
// 因而后三同值允许替换，保留容器中最后一次出现的最低合格等级候选；不等于最大等级。
// 前两允许0及负L，只要严格低于初始threshold；后三排除L<=0。
// 前两初始threshold为最小合法等级也可能完全无结果；后三初始threshold<=0在稳定值域下无结果。
// threshold仅写当前调用者栈上的按值参数槽，不修改上层保存的当前地产等级变量。
// 同一候选前两读L两次，后三最多三次，未缓存为一次；并发修改/损坏/重入下不能套用稳定最小值证明。
// 容器count只读一次，但元素基址与记录基址经helper多次读；不是整批快照或事务。
//
// 可核例子与边界
// ----------------------------------------------------------------------------
// 已按其他谓词过滤后的顺序(r=10,L=2),(r=20,L=2),(r=30,L=3)，初始threshold=4：
// 7E4660/7E4750对应严格模型选r=10；7E4830/7E4930/7E4A30对应非严格正值模型选r=20。
// threshold=2时严格模型无结果，正值非严格模型选r=20；输入全L=0时后三个正值型无结果。
// 本段例子仅解释比较与同值规则，仍须满足各入口独立K/S/O/exclusion条件，不能跨入口混类。
