// 七个有限复用区间、旧source SHA+Pointer、assembly与bytes切片、当前PE核对在formal_functions.json。

// 实例与参数来源
// ----------------------------------------------------------------------------
// G为7C6640入口ECX保存在[ebp-8]的对象；五搜索使用ECX=M=G+65Ch。
// owner输入取DWORD[G+E28h]，该值同时用于[G+E00h+4*owner]选参与者对象P；无本段索引有效性检查。
// 7C66E5经60FFD1到63E410，从P+5B8h取DWORD当前位置存var_C，不把P与M混成同一结构。
// 7C6737经6066CF到63E3E0，将var_C索引到[M+30h]+8*var_C+2，读取signed WORD存var_10。
// var_10因此是当前节点映射的地产记录编号，既不同于路径节点var_C，也不同于候选容器循环下标。
// 7C8F88与7CA8F5各以var_10调用63E960，得到当前地产等级Lcurrent，保存var_2C。
// 两搜索和三搜索每次调用都重新压同一个var_2C；callee阈值槽收缩不会把结果阈值传给下一步搜索。
// G+E28h的赋值/网络同步来源及合法参与者编号域不在本批窗口；这里只核本局部读取和比较。
//
// 第一链：类型/自身归属等门之后，两类候选只按-1回退
// ----------------------------------------------------------------------------
// 7C8BB9的63EC30检查当前R+3!=-1，非零跳7C8DA2；后者63F5B0检查当前R+3==G+E28h。
// 7C8DDC/7C8DFF/7C8E22三个参与者状态helper与7C8E3F地图helper还必须低AL为0。
// 这些helper的完整状态词义不在本批；不能把“当前地产归自己”单独当整条路径充分条件。
// 7C8E5C的692940判断当前S==2；否分支7C8F5E再经692B00要求当前S==6，才到搜索。
// 当前type的所有更早可达路径也未全部复核，本文仅描述该有限分支，不推导所有地图业务入口。
// 首先7C8FCB调用7E4660(M,owner,Lcurrent)，要求类型11、S=0、自己所有且等级严格更小。
// 只有7C8FD3比较FFFFFFFF、7C8FD7 JZ时，才进入7C9018并于7C9049调用7E4750。
// 第二入口ABI：7C9031 PUSH var_10、7C9035 PUSH var_2C、7C903F PUSH owner；ECX=M。
// 7E4750 RET0Ch闭合三个DWORD实参，按(owner,Lcurrent,currentRecord)读取，排除当前地产。
// 固定call前五条窗口漏掉前两PUSH，不能只看固定窗口推出两参；扩展旧case切片承担此证据。
// 第二入口选择类型12、自己所有、不是当前地产、等级严格更小的候选；不是随机备选。
// 找到第二类候选后693DA0检查其S是否2..6；不在该范围时63F2D0把S低BYTE写3，再调用7E3F30。
// 首次找到候选则直接调用7E3F30(candidate,Lcurrent)，取AL是否抵达模式上限保存var_411。
// 该helper按DWORD等级相加后只写低BYTE，再以signed BYTE比较模式上限5或7，不等于逐级+1。
// 首次找到后即使7E3F30返回低AL=0，也在7C9013跳7C90BE，不回退第二搜索。
// 返回0表示未抵达上限等路径，不是“搜索失败”；不能用后续升级结果替代-1的回退门。
// 7C90BE只要candidate!=-1，就构造局部消息：文本编号165、G+E28h和候选写A8AB5C/A8AB60。
// 后接消息种类7、8字节数据，以及种类5/参数1、A8AB44(0)/A8AB48(candidate)的20字节数据。
// 仅var_411非0时追加种类6及参与者低BYTE的12字节消息；构造使用609D34，传输/消费后端不在本批。
// 两次均-1时不构造上述候选消息，后继7C9259仍可继续其他逻辑，不能称整个回合直接结束。
//
// 第二链：有序三类正等级候选，只有-1继续下一类
// ----------------------------------------------------------------------------
// 7C67EA阶段参数==4可直接跳7CA1AA；参数==3跳7C9259、==5跳7CAB1B，彼此不可合并。
// 7CA1AA附近先检查60DCDB/610E18两地图helper，非零各走其他消息并返回；60ECEE为0才跳7CA8CB。
// 此三前置helper只保留调用及真假路径，不猜显示名称或将第二链强行标为“敌方地产专用”。
// 7CA8D8再次以692B00要求当前S==6，失败到7CAB1B；成功从当前地产取Lcurrent开始三搜索。
// 7CA931先7E4830：自己所有、类型11/S=0、0<L<=Lcurrent，选最低，等值最后者。
// 结果-1才7CA96C调用7E4930：自己所有、类型11/S=1、0<L<=Lcurrent。
// 再次-1才7CA9A7调用7E4A30：自己所有、类型12、0<L<=Lcurrent；无显式当前编号排除。
// 7CA93D与7CA978非-1直接跳后继，候选优先级是第一类→第二类→第三类，非三类合并求最低。
// 每类独立以原Lcurrent开始；第二类哪怕有更低L，也不会替换第一类已成功结果。
// 三步全-1时7CA9B3跳7CAB1B；找到则7CA9E0调用7E4020(candidate,Lcurrent)作等级扣减。
// 7E4020读signed BYTE等级后减完整DWORD，再写低BYTE；写回后的signed值<=0才清0并走类别续接。
// 类型11清等级后S写0；其中S==1且已归属时还先调用两个旧后端；类型12清等级后S写FFh。
// 这些旧后端完整效果、所有权更新和动画未展开；不能简单声称只做整数max(L-amount,0)。
// 有候选时构造文本编号166、A8A970(owner)/A8A974(candidate)，及A8A958(0)/A8A95C(candidate)局部消息。
// 随后7CAB1B以(a2,a3,4,0)继续600928并依据EAX转本次bool返回；600928完整状态机不在本批。
//
// 边界与解释限制
// ----------------------------------------------------------------------------
// var_74A与iLevel字符串/__RTC_UninitUse属于局部未初始化检查路径，不是额外土地筛选谓词。
// 两链升级/扣减使用的是原当前地产等级，不是搜索收缩后最低等级，也不自动等于1。
// 五搜索本体只读容器与记录；等级/子型写入发生在上层另调的7E3F30/7E4020/63F2D0。
