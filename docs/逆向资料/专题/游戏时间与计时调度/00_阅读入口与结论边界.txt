// 本专题以完整函数声明块、指令与磁盘匹配为底稿，函数台账单独标明审阅深度。
// 伪码中的MFC名字可能来自IDA错误签名；没有对象原证时不据此命名业务。
//
// 阅读顺序
// ----------------------------------------------------------------------------
// 01_定时任务调度与超时.txt      36字节任务槽、启动模式、回收条件与调用边界。
// 02_高精时钟与连通性探测.txt    QPC毫秒换算、RAW探测时间戳、收发线程的时间窗口。
// 03_局部节拍与排除项.txt        短提示、UI节流、随机种子、加载循环与既有专题索引。
// 函数审阅清单.json             va/status/conclusion/unknown/evidence逐项登记。
// 验证结果.json                 EXE指纹、声明块、指令数、跳板与IDA复读结果。
//
// 原证和复核
// ----------------------------------------------------------------------------
// 证据/functions.json           当前IDA完整主块/尾块、伪码、调用边和两类原始字节。
// 证据/ida_recheck.json          从当前IDA重新读声明块、指令VA/size和字节。
// 证据/伪码与调用边.txt          注释式阅读摘录；保留IDA原符号，不替代机器指令。
// 证据/完整汇编.txt              全部已解码指令；声明块内原始数据另看JSON。
// 种子导航.json                 旧全量归档筛选结果，仅为检索线索，不是当前字节证明。
//
// 维护步骤
// ----------------------------------------------------------------------------
// 本机Python运行build_review.py重建显式台账；新函数没有人工结论会立即报错。
// 运行render_evidence.py重建阅读摘录，运行validate.py核对当前磁盘EXE与原证。
// export_ida.py在IDA-MCP当前数据库中执行，collect/supplement等只读取数据库；
// get_chunks逐块取证后用recheck复读，不能只靠旧functions.json声称已核当前版本。
// 参数回调不是直接call；更新效果登记时还需capture_contract保存E9目标与常量。
// 独立审阅记录由审阅者另写，作者不要用重跑导出替代独立语义复核。
//
// 已有资料的职责
// ----------------------------------------------------------------------------
// 启动线程与退出：WinMain消息泵、阶梯Sleep预算、资源线程与退出句柄。
// 回合等待与自动选择：Game pending倒计时、0x6004、超时自动选择及补偿链。
// 角色与精灵动画：81BC80/81BCB0/81BD10基础周期器与动画帧节拍。
// 诊断消息与类型字典：本地通知队列计时器与单条弹出节拍。
// 本地事件剩余消费者：基础暂停、事件执行及结束分支。
// 本篇不把这些既有资料的引用列为新完成的函数整体语义。
//
// 修复通信卡住时的使用边界
// ----------------------------------------------------------------------------
// 同一个GetTickCount导入可能用于提示绘制、加载等待、局部任务和玩法倒计时。
// 必须先确认对象、字段写者、完成回调和状态推进，才可判断服务端缺少哪种响应。
// RAW探测延迟与游戏TCP响应时间属于不同链；QPC换算不证明玩法使用了该时钟。
// 静态差值公式可确认比较宽度与边界，实际阻塞、调度粒度和恢复顺序需实机记录。
