// 625D70：短提示绘制及关闭
// ----------------------------------------------------------------------------
// A76694非零时绘制MultiByteStr；随后取GetTickCount并相减。

// 该入口没有发送协议或清Game pending，不能用提示关闭替代回合完成证据。
//
// 71FC00：局部控件刷新节流
// ----------------------------------------------------------------------------
// 先调用对象+72的既有周期器；返回非零才调用71FD10，随后无条件调用71FFE0。
// 这段调用关系不受后面的200ms分支限制。
// 71FC50/71FC5B：无符号timeGetTime()-A842C8>=200ms才进入控件刷新。
// 通过后再次timeGetTime并存A842C8，取ID17控件后调用vtbl+200。
// 对象+96为0时传0，否则按6FA210的BYTE结果构造调用参数；产品名称未恢复。
// 只刷新一次，起点更新为第二次读取的now；没有while补齐遗漏200ms周期。
// A842C8是共享全局，不是保存在每个对象中的独立节拍；写者穷尽另属后续工作。
// 控件虚函数的全部副作用未闭合，不从这个门控证明网络事件以200ms轮询。
//
// 6AB5F0：局部初始化时间戳
// ----------------------------------------------------------------------------
// 一组UI和对象重置调用后，this+2736 DWORD清零，+2740 BYTE清零，
// +2744写GetTickCount；当前入口本身没有差值比较、超时或等待循环。
// 字段消费者尚未归属，台账保留“局部分支”状态，不给它命名游戏超时起点。
//
// 6AA530：timeGetTime用于随机种子
// ----------------------------------------------------------------------------
// 每次进入先srand(timeGetTime())，再按三种资格和选项0/1/2取rand()%表长。
// 结果对应this+1352..1480之间、步长16的九组字段，随后交6AA450。
// 当前对象是这条调用链的对象，不能把+1416混作角色P+1416无资料标志。
// 两个业务调用者为625070和740000；后者选项5132..5134映射选项0..2。
// 这里只证明时钟用于重新播种；随机分布、表长零、内容筛选与字符串容量未审全。
// 同毫秒连续重播种可产生相同序列，是公式可推导边界，不是计时等待卡住。
//
// 641EE0：加载循环的Sleep(1)
// ----------------------------------------------------------------------------
// 623EE0资源线程末端调用本函数；按资源表寻找%s%s_%02d.avt并读方向/帧坐标。
// 642260的Sleep(1)在最外层每条资源记录结束处，未按elapsed判断任何完成状态。
// 这是加载期间让出处理器的调用，不是玩法tick、网络收包线程或回合等待重试。
// 资源格式完整语义、分配与坐标容量不在本篇审阅范围。
//
// 81BC30：日历时间
// ----------------------------------------------------------------------------
// time(NULL)写this+0，再localtime并拷36字节到this+4，用于事件日期/时间文字。
// 既有“事件文字记录器”和“断线与离席恢复”已恢复调用用途，本篇只作对照。
// 日历时间可随系统调整；不能与QPC毫秒值或GetTickCount差值直接相减。
//
// DWORD回绕与暂停：不同公式需要分别判断
// ----------------------------------------------------------------------------
// 本篇625D70/71FC00及效果槽使用32位减法后无符号比较，可跨一次回绕计算模差；
