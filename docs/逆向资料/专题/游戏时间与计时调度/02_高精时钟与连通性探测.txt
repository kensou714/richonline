// ============================================================================
// 高精时钟与RAW连通性探测
// ============================================================================
// 本组的作用是探测往返延迟，不能据此推导游戏TCP心跳或回合响应超时。
// 完整函数原证：证据/functions.json；线程生命周期另见“启动线程与退出”。
//
// 81ED10：64位毫秒来源
// ----------------------------------------------------------------------------
// byte_ABABD9==0时调用QueryPerformanceFrequency，随后无条件写标记1；
// 每次调用QueryPerformanceCounter，返回(counter*1000)/frequency，EDX:EAX。
// 81ED70调用__allmul，81ED85调用__alldiv：64位整数乘法及有符号除法。
// 换算会截去不足1毫秒的部分，不是原始QPC tick，也不是系统本地日期时间。
// 两API的BOOL返回均未据此分支，未检查frequency==0，也未保护乘1000溢出。
// 首次频率缓存未见锁；本篇不声称已经复现并发初始化错误或计时器故障。
// 没有检查API成功不意味着Windows正常运行时必定失败，风险和事实需分开记录。
//
// 81F1A0：探测请求中的时间戳
// ----------------------------------------------------------------------------
// 外层按参数+8的轮数循环，内层遍历参数+4的目标数，每目标记录宽度36字节。
// 目标地址来自记录+0；固定发送52字节，buf+16为目标下标。
// 81F286取81ED10的EDX:EAX，分别写buf+8与buf+12：完整64位毫秒戳。
// buf+6为WORD序列号，逐包增加；buf+2先清零，再计算校验和。
// 每轮目标全部发送后Sleep(10)，并不是每包间隔10ms；目标多会延长整轮。
// sendto返回未作为重试或计数的条件，发出尝试不等于收到有效回应。
//
// 81EE60：回应识别与往返时间
// ----------------------------------------------------------------------------
// 用首DWORD低4位乘4算h，即IPv4头长；先要求received_length>=h+8。
// 取buf+h为后续头：+0须为0，+4的WORD须等于本进程ID低16位。
// 通过后取头+16为目标下标，返回now64-头+8的64位时间戳。
// 汇编81EEFC/81EEFF为sub/sbb，不能仅凭伪码LODWORD将其缩成32位时间。
// 任一先行检查失败返回64位9999；此值同时作为接收端延迟上界哨兵。
// 头长检查只保证h+8，后面还读h+8..15与h+16..19；未确认这些字节在本次
// recvfrom有效长度内。调用者分配4096字节不等于这些字段来自完整网络回应。
// 本篇记录长度检查边界，不据此声称每个短包都会访问进程未映射内存。
//
// 81F360：接收窗口与统计
// ----------------------------------------------------------------------------
// 开始时保存now64；每轮recvfrom之前检查(now64-start64)>窗口。
// 81F3DB先将参数+12的32位窗口cdq扩展，再以无符号64位ja/jb比较差值。
// 正常非负窗口的终止条件是严格大于；负值扩展结果不是“立即超时”。
// recvfrom进入后没有本循环内部的再次计时；外围设置接收/发送超时，调用结束仍
// 取决于套接字等待和线程处置，不能把循环顶部窗口当作每次调用的严格截止点。
// 延迟按无符号64位须<9999，目标下标以有符号jge拒绝index>=count。
// 未见index>=0检查，负下标是待复现实机的静态边界，不能当作合法目标。
// 有效回应更新36字节目标记录：+4计数，+8最大值，+16最小值，+24整数平均值，
// +32字节写1；平均值为(rtt+old_mean*(count-1))/count，累计截断会损失精度。
// count及count-1先经cdq扩展，最终调用__aulldiv作无符号64位除法。
// 计数及乘加未见饱和保护；短窗口正常使用不证明所有极端输入都安全。
//
// 外围生命周期与协议归属
// ----------------------------------------------------------------------------
// 81EFB0创建AF_INET/SOCK_RAW/IPPROTO_ICMP套接字，并以参数+12设置
// SO_RCVTIMEO(0x1006)/SO_SNDTIMEO(0x1005)，任一setsockopt返回-1则退出。
// socket结果以DWORD和0作cmp+jnb，非负无符号比较恒成立；不能视作有效失败检查。
// 两个探测线程创建后，仅a2!=0才Sleep(参数+12)，a2==0立即进入强停路径。
// 随后TerminateThread及CloseHandle两个线程；本函数未见closesocket/WSACleanup。
// 线程创建返回值未作成功门控；具体资源回收是否在别处完成，不由此入口断言。
// 这种等待是一次探测作业生命周期，不能写成客户端每帧tick或服务器请求pending。
// 81EDD0初始化探测头，81EF20计算16位校验和；不能把RAW头字段搬进游戏包格式。
// 跨进程、修改时间戳、异常长度、负下标和窗口负值尚未用真实回应样本验证。
