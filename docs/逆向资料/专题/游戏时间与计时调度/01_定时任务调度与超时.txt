// ============================================================================
// 六类画面效果的定时槽调度
// ============================================================================
// 6BC3A0的调用者是六个“更新后绘制”包装器；并非网络连接或回合等待队列。
// 名称“效果”由位置、速度、纹理获取与绘制调用共同支持；具体美术名称未恢复。
// 证据：functions.json、回调与常量.json、引用闭合.json，以及完整汇编。
//
// 管理对象M与36字节效果槽S
// ----------------------------------------------------------------------------
// M+0 分配槽数；+4扫描上限；+8活跃计数；+12每槽附属缓冲字节数；+16启动模式。
// M+20槽数组；+24启动回调；+28更新回调；+32绘制回调，三个回调接收槽指针。
// 6BC220分配4+36*N字节，数组头存N；附属缓冲按M+12分配到S+32。
// 6BC110以memset清零完整36字节槽；6BC140析构释放非空S+32并清该指针。
// 6BC190仅清M+20；6BC1B0在其非零时经6BDF90(flags=3)逐槽析构并释放数组。
// S+0/+4为浮点坐标，+16/+20为浮点每次调用的增量；+24为DWORD寿命兼活跃标记，
// +28为启动tick；+32为附属缓冲指针。未给本群没有消费的S+8/+12附会用途。
// 6BE050判断S+24!=0；6BE030仅把S+24清零，不释放槽、重置坐标或改M+8。
// 6BE070仅清this+8；不是“清所有效果”，也不是初始化整个36字节槽。
//
// 执行顺序与比较边界
// ----------------------------------------------------------------------------
// 6BC3A0先6BC3D0启动，再6BC560更新/回收；外层包装器随后6BC670绘制活跃槽。
// 启动条件用有符号M+8<M+4，扫描下标亦为有符号；不是无符号容量检查。
// 模式0每次最多启动一个空槽；模式1扫描并启动多个，计数到M+4时停止。
// 其他模式不启动。六个已闭合登记入口均传模式0，不能说游戏实测使用了模式1。
// 启动回调执行后才写S+28=GetTickCount并增加M+8；回调耗时不计入新槽elapsed。
// 调度器不验证回调真的留下非零S+24，计数一致性依赖回调契约。
// 6BC560仅当有符号M+8>0扫描：先更新，再检查活跃标志，再检查时间。
// S+24已清零，或者DWORD(now-S+28)>=S+24，都执行清零并M+8减1。
// 6BC61D相减、6BC62D比较、6BC631的jb证实时间比较为无符号且含等号。
// 因而已到期槽仍先执行一次更新；本次才启动的槽也会在同一调用里更新。
// 外层绘制只遍历仍活跃槽，回收不会当场补新槽；下次启动阶段才可复用。
//
// 六组登记：分配数/扫描数/附属字节，启动→更新→绘制
// ----------------------------------------------------------------------------
// 6BC700：80/50/0，6BC7A0 → 6BC860 → 6BC8E0；包装6BC770。
// 6BC990： 5/ 5/4，6BCA30 → 6BCB30 → 6BCBA0；包装6BCA00。
// 6BCC50： 3/ 3/8，6BCCF0 → 6BCE60 → 6BCEC0；包装6BCCC0。
// 6BCF70： 3/ 3/4，6BD010 → 6BD110 → 6BD180；包装6BCFE0。
// 6BD230： 3/ 3/8，6BD2D0 → 6BD440 → 6BD4A0；包装6BD2A0。
// 6BD550： 5/ 5/0，6BD5F0 → 6BD780 → 6BD880；包装6BD5C0。
// 登记时压入的是E9跳板，回调与常量.json保存20个构造/析构/回调桥的真实目标。
// 不把“压入函数地址”伪造成直接call边，绘制/更新是经M字段的间接调用。
//
// 寿命字段中的真实数值
// ----------------------------------------------------------------------------
// 6BC7A0：寿命1000*(rand()%10+2)，即2000..11000ms；每次更新x+=dx、y+=dy。
// 其他五类先初始化位置/纹理，再用共享全局tick决定S+24如何赋值：
// 6BCA30 / A8249C：elapsed>8000；6BCCF0 / A824A0：elapsed>8000。
// 6BD010 / A824A4：elapsed>5000；6BD2D0 / A824A8：elapsed>5000。
// 6BD5F0 / A824AC：elapsed>1000。
// 不超过阈值时S+24=1；超过时S+24=GetTickCount，并再次取tick写共享全局。
// 之后公共启动器还会再读tick写S+28。这个S+24值不是上述门控阈值。
// 因此“1”槽可能同帧被回收，也可能到下一次更新才满1ms；不能称为完全不生成。
// 通过门控的槽常靠出界回调结束，或当elapsed达到保存的tick值时结束。
// 本篇不替原程序改写公式，也不把异常设计直接归为玩家通信卡住原因。
//
// 移动与结束条件
// ----------------------------------------------------------------------------
// 6BC860在位置累加后比较三个全局浮点界限；字节另有常量原证。
// 6BCB30/6BD110在x达到6919F0返回边界时清槽，然后仍执行x+=dx。
// 6BCE60/6BD440在x<-附属缓冲+4的纹理宽度时清槽，然后仍执行x-=dx。
// 6BD780在纹理高度+y<=0时清槽，然后仍执行y-=dy。
// 这些位移是每次回调固定增量，没有乘elapsed或补遗漏帧，速度随调用频率变化。
// 绘制入口最后调用6DC470；多数先扣世界视口偏移，首组6BC8E0直接按槽坐标绘制。
// 纹理获取使用6DBA40，编号包括24、352/353、394..396、503..505、1655。
// 编号不能证明具体天气/场景名称；美术资源映射与实际显示仍待单独验收。
//
// 已核边界与剩余工作
// ----------------------------------------------------------------------------
// 分配槽数与扫描数由登记者分别提供，公共函数不验证扫描数<=分配数；本群六组成立。
// 附属指针分配失败、尺寸用于rand取模为0、极端DWORD回绕均没有实机故障样本。
// 本篇闭合本组声明的回调与生命周期，不证明所有间接调用者、全局暂停或帧门控。
