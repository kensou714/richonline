// 请求→响应/失败→收尾
//
// 常规路径：855790→87DFE0，wire58，scheduler_key58。
// 扩展路径：855950→87E640，wire600，scheduler_key600。
// 二者默认ErrorBundle处理器均为855CB0，输出错误回调类别58。
// 对扩展路径，回调类别58不是“错误key用了58”；只是一层UI兼容映射。
//
// 请求入口先登记key与相关等待记录，再调用87EE40连接及密钥握手。
// 连接失败本地派发error=-143，常规用key58，扩展用key600。
// 成功才构造认证包并调用87F970发送；后者若+112或+116对象为空则不发送。
// 因此“请求对象已构造”“已登记等待”都不等于网络上已发认证帧。

// 认证载荷
//
// 87E430常规载荷144字节：三个DWORD、64字节字符串槽、另一个64字节槽、
// 最后DWORD。包头构造88D260写魔数0x10A1D85F和type58。
// 87E7D0扩展载荷136字节：两个DWORD和两个64字节字符串槽，
// 88D340写type600。字段业务名称和保密策略沿既有认证资料再核对。
// 写DWORD的函数在伪码常被标char；长度与字段宽度以汇编为准。

// 初始化成功不是单包ACK
//
// wire1：跳过载荷首DWORD，再取数量写大厅对象+124。
// 数量为0时立即调用登录对象虚表+4；否则等待后续wire3对象记录。
// wire3：先将+124减1，再解析80字节对象并执行884F80；
//        只有减后恰好等于0，才调用登录对象虚表+4完成批次。
// 少发一条wire3会使批次永远不触发完成；多发或重复会继续减到负数。
// 此处没有以“收到多少不同ID”替代计数，也不能盲发重复wire3补卡住。
//
// 登录对象具体虚表+4为855B10（IDB未声明函数，已保留完整范围汇编）。
// 它保存描述、初始化管理数据，对对象逐个发本地类别0，最后发类别14。
// 类别14经6BE2E0→6AB9A0进入登录UI收尾：清this+601，关闭UI66，
// 按资源/状态分支继续大厅UI73或“LobbyLogin”提示。
// 分支不是统一成功一键切屏：604CA8、6049C9等条件仍影响后继动作。

// wire9→wire7→wire30的对象依赖
//
// wire9保存自身ID到+128，另一个DWORD经886E00查找对象并设置当前对象。
// wire7基于当前对象初始化基础数据；887E30会区分初始化/更新状态。
// wire30读取DWORD和三个double，设置大厅对象+192=1，
// 合并先前保存的数值，再调用房间管理对象虚表+4。
// 这几条不是任意可交换的“初始化包”：对象缺失和数据未齐仍可能失败。
// 包体具体偏移和272字节wire7参见上层03_大厅与房间协议.txt。

// 登录错误完整收尾
//
// 855CB0将错误送ACB868(category58,error,-1,-1)。
// 6BE8D0先检查应用全局A76728!=0及管理器this+600!=0；
// 通过后category58→6AFB60（IDA错误命名CDockBar::DockControlBar）。
// 6AFB60按错误码选文本，操作UI66/73/64，然后调用6A1190。
// 6A1190调用82C4E0连接清理入口，将this+1504和+1264置-1，+600置0。
// 回到6AFB60最后将this+601置1，表示错误路径留下的状态标志。
// 调度器bundle释放和erase在回调返回后由87E170继续完成。
// 因而此路径已经有明确状态清理，不能记录成“失败后未清等待”。

// UI错误文本索引
//
// error -144→文本773，并读取附带reason/date标签。
// -108→884；-107→711；-104→515；-103→517；-102→516；-101→514。
// 其它包括本地-143走默认513。文本中文含义未在此批逐条解包核实。
// UI显示分支只按静态索引记录，不用猜测文案替换真实资源。

// 大厅主接收容量补证
//
// 87D9D0构造大厅管理对象时分配+120业务buffer容量1MiB，
// 与88FF40内部收帧buffer的1MiB一致。此前1024构造参数属于传输组件。
// 网络专题04记录的memcpy先于推进检查仍是局部事实；
// 但正常默认构造链并没有因此被证明使用1024目标接收1MiB帧。
// 此结论只覆盖本构造链，重绑/替换buffer路径仍需独立检查。
