// 类型字符串与列表布局 / 静态事实
// ============================================================================
// 证据：bounded_raw.json#/functions/0；type_tables/bounded_raw.json的7个data_windows。
// 69F6D0是cdecl单字符串实参，retn后由caller加ESP,4；无NULL/长度上限门。
// 69F6F6先strlen并存局部var_8，后续不读取该长度，不能把它当输入验证。
// 69F71C读A673A4[index*4]，按unsigned index<4遍历；69F728调用strcmp。
// 四指针及首NUL字节为：
//   编号0  A237BC  43 48 55 00          CHU
//   编号1  A237B4  5A 48 4F 4E 47 00    ZHONG
//   编号2  A237B0  47 41 4F 00          GAO
//   编号3  A237AC  58 49 4E 00          XIN
// strcmp返回0才匹配，首个匹配写result后退出；result在69F6EB已清0。
// 因而未知字符串、空串、大小写不同、尾空格均不另报错而返回0；原样CHU也返回0。
// 输入从第一个NUL截断；不把该原始字符串接口称为Unicode或自动去空白解析。
// 这些字面量不单独证明等级权限或汉字业务名称，本文按原字符串保留。
//
// 根与列表 / 十六进制偏移，宽度单位字节
// ----------------------------------------------------------------------------
// 记M为两个parser与6A0B50的this。每列表L是16字节内嵌结构：
//   L+00 DWORD count       当前元素数。
//   L+04 DWORD capacity    已分配DWORD元素数；追加比较使用signed JL。
//   L+08 DWORD growth      扩容时增加的DWORD元素数。
//   L+0C DWORD base        DWORD数组指针，清理函数把它置0。
// M+198/M+1A8/M+1B8/M+1C8分别对应类型0/1/2/3，互相间隔10h。
// M+5C是308(134h)字节频道记录数组指针，M+60是频道记录总数。
// 列表数组只存DWORD索引，不拥有单条频道记录，不可把16字节列表和308字节项混作同类型。
// M的完整构造/分配大小、其他字段所有权不由本专题恢复。
//
// 数据到列表
// ----------------------------------------------------------------------------
// 两parser每条记录先把R+0类型写0；LobbyType查键失败直接保持0。
// 查键成功才取文本并调用69F6D0；未知文本同样得到0。
// ChannelID经atoi写R+130h，随后类别分派压栈的却是局部var_1C8。
// var_1C8在69FAA6/6A0486清0，每个频道处理完在69FF78/6A0958加1，跨area累计。
// 所以元素是当前连续频道表的零基顺序索引，既不是ChannelID也不是类别内序号。
// 例如输入频道ID为900、3、777且类别GAO、XIN、GAO，类别2保存[0,2]，类别3保存[1]。
// 该例是静态契约推导，未连接服务器运行。
//
// 两张真实跳表
// ----------------------------------------------------------------------------
// 69FF11引用6A0083，四目标69FF18/69FF2F/69FF46/69FF5D；
// 6A08F1引用6A0A63，四目标6A08F8/6A090F/6A0926/6A093D。
// 各目标分别给对应M偏移调用6B8A60；不是仅依据IDA case注释重建映射。
// 分派先unsigned比较类型<=3；超范围走默认不追加，仍递增全局索引。
// 正常本地查键/转换链只产生0..3；外部修改或状态损坏引起的越域不作实机结论。
