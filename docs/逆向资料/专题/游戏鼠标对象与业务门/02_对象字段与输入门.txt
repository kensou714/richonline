// 创建入口 6278F0
// ----------------------------------------------------------------------------
// 627920检查全局A766C0；已有对象直接返回，没有观察到锁或原子初始化。
// 空指针分支申请0x1AC字节，627949经60046E调用6BAAC0。
// 分配返回空时跳过构造并将零写回；62796A保存指针，627970返回全局值。
// A112D0附属异常块包含delete调用；它不能证明所有运行期失败都被恢复。
//
// 构造入口 6BAAC0
// ----------------------------------------------------------------------------
// ECX为对象；6BAADC经60FFDB调用920BF0，传入this+0x0C、零、0x190。
// 调用形态对应memset；底层920BF0算法未在本批展开。
// 限定清零区间为+0x0C..+0x19B，即100个DWORD表槽，最后返回this。
// +0x00..+0x0B和+0x19C..+0x1AB未在本构造体中写入。
// 因而不能写“整个对象清零”“默认允许输入”或“默认光标已经有效”。
//
// 已见字段                           证据与使用边界
// ----------------------------------------------------------------------------
// +0x00 BYTE                         7A47C4写入；691CD1读出AL。
// +0x0C + index*4 DWORD              6BAD9E比较，6BADAD/6BADC0读取。
// +0x19C DWORD                       6BAD98读旧值，6BADB1写选中表值。
// +0x1A0 DWORD                       6BADC4写入同一选中表值。
// 其他字节                           本轮未建立稳定字段语义。
//
// 光标选择入口 6BAD80
// ----------------------------------------------------------------------------
// ECX为对象，栈上一个索引参数，ret 4；本体没有索引越界检查。
// 表值与+0x19C相等时直接返回已有+0x19C，不调用系统接口，也不更新+0x1A0。
// 不相等时更新+0x19C/+0x1A0，并在6BADD6间接调用IAT槽AD3F88。
// 当前PE导入表确认AD3F88为USER32.dll!SetCursor，参数为选中光标句柄。
// 这一分支返回系统接口的旧光标句柄；不是新句柄，也不是布尔成功值。
// 表句柄的完整装载路径及首次使用前的初始化顺序，尚未在本轮闭合。
//
// 输入门读写
// ----------------------------------------------------------------------------
// 7A47B0：ECX为对象，栈参数低BYTE写到this[0]，返回this，ret 4。
// 691CC0：读取this[0]到AL，不写字段；它不是“恢复鼠标”操作。
// 691CC0的EAX高24位未清零，消费者必须按AL理解该结果。
// 复用7A29E0消息路径：先更新输入状态；7A2B71的604BB8门允许且ACC3C8非空才分派UI。
// UI消费消息后，7A2BB1把首BYTE置零，随后提前返回。
// 未消费或未分派的路径在7A2BC9再次检查604BB8；门允许才在7A2BDE置一。
// 第二次门不允许则保持首BYTE并继续；不能推定所有写者都在此函数。
// 三个业务入口先改变光标，再做后续检查；失败返回并不自动撤销该光标变化。
//
// 退出路径的已知边界
// ----------------------------------------------------------------------------
// 6249EA判断A766C0；6249F3取对象；624A14压入1；624A1C经60DEF7调用629890。
// 629890先经604627调用6BAB00；随后按栈参数bit0决定是否调用delete，ret 4。
// 退出传入1，因而该局部路径请求释放对象内存，之后624A33把A766C0清零。
// 6BAB00遍历+0x0C开始的100个DWORD槽，非零时调用AD3ACC导入槽。
// 当前PE确认此槽为GDI32.dll!DeleteObject；代码忽略其BOOL结果，也不清空表槽。
// 它并未调用DestroyCursor；不能据此保证表项类别正确或所有句柄释放成功。
// +0x19C/+0x1A0没有额外独立释放；借用、别名或重复句柄风险尚未闭合。
// 629890返回原this地址；在bit0为1的路径中不能继续解引用该返回地址。
// 此处仅对应624080退出局部，不证明正常运行时所有指针借用都已结束。
