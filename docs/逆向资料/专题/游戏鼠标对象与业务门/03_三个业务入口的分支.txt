// ============================================================================
// 游戏鼠标对象与业务门 / 三个业务入口的分支
// ============================================================================
// 共同约定
// ----------------------------------------------------------------------------
// 三者均使用ECX业务对象、两个栈参数，读取参数低BYTE，ret 8。
// 外层803280/8032C0/803560把首个栈参数放入ECX，后两参逆序压栈后调用业务体。
// 因而外层有三个栈参数，业务体只有两个栈参数；本轮仅核调用附近窗口。
// 输入对象由627270取得；鼠标对象由6278F0取得。
// 返回0表示执行到6BF380的本地提交调用之后；不表示服务端确认或动作完成。
// 返回2、3只是本体分支常量，不能擅自命名为“非法地产”“网络错误”。
// 本轮未展开构包器，因此不命名消息码，也不推定剩余包字节已如何初始化。
//
// 6516E0 / 光标索引38
// ----------------------------------------------------------------------------
// 651700压入0x26，651709调用6BAD80，早于全部业务检查。
// 651715检查691E50，AL非零返回3。
// 通过输入坐标及this+0x65C调用7E1640取得目标。
// 63E820、63E880必须返回非零；63EB50、7BFE20、691D00、691D40、691D80必须为零。
// 依赖函数的业务含义尚未闭合；这些地址只能作为分支排查入口。
// 651820先调用650730(target,0)，之后才检查最终输入与鼠标门。
// 65182C的691E30及65183F的691CC0均须AL非零；否则返回2。
// 因为650730在门检查之前，不能把失败分支描述成“没有任何本地副作用”。
// 691F90构造局部记录；63E440返回值低WORD写+2。
// 参数低BYTE依次写+4、+5；目标低WORD写+6。
// 65187F经610977调用6BF380，传8字节；随后返回0，其他失败汇合到2。
//
// 651960 / 光标索引3
// ----------------------------------------------------------------------------
// 65197B压入3，651984调用6BAD80；691E50非零则返回3。
// 7E1640产生初始目标；随后7E4440接收目标地址，可能改写后续使用的目标。
// 63E820、7E4440、63EC30必须非零；692030、63F290、691FF0必须为零。
// 63EC00取得一个局部值；以下附加检查并非所有路径都执行：
//   当63E160非零且63F5B0(target,[this+0xE28])为零时，调用63F7E0。
//   第二实参是+0xE28的DWORD字段值，不是字段地址。
//   其ECX取自this + [this+0xE28]*4 + 0xE00的DWORD，参数为该局部值。
//   63F7E0为零会阻止提交。索引域和值的业务名称仍待依赖分析。
// 651B08调用650730(target,1)，之后691E30、691CC0均须AL非零。
// 6920C0构造记录；+2为63E440的低WORD，+4/+5为参数低BYTE，+6为目标低WORD。
// 651B67提交8字节并返回0；其余拒绝路径返回2。
//
// 653850 / 光标索引18及管理槽25
// ----------------------------------------------------------------------------
// 653873取得6279C0管理对象；653894切换光标索引0x12。
// 691E50非零时，仅槽25未激活才立即返回3；已激活则先调用6E4020后继续。
// 管理对象、槽25和各依赖的领域名称均未确认。
//
// 槽25未激活：由坐标和8字节临时缓冲调用64FF10取得结果与目标。
//   结果等于1：按条件调用6E4020，再要求691E30及691CC0均AL非零。
//   通过后构包、653996提交8字节、6E4020清理局部状态，返回0。
//   结果大于1且槽仍未激活：6E3B40(25,0,0)后6E4640(25,&临时缓冲)，返回2。
//   其他情况返回2。
//
// 槽25已激活：6924A0(25)返回地址，读取其DWORD作为目标。
//   目标为-1则返回2；其他值直接进入构包提交，不再经过上述两个最终输入门。
//   653A2D提交8字节，6E4020清理局部状态，返回0。
//
// 两个提交分支都调用692540构包；+2写低WORD，+4/+5写参数低BYTE。
// 目标只写BYTE到+6，区别于前两入口的WORD；+7来源仍需构包器证据。
// 因而“全部业务提交均受鼠标首BYTE约束”和“目标总是16位”都不成立。
