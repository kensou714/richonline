// 八角色命中筛选契约 / 筛选顺序与字段
// ============================================================================
// 主入口 0x64FF10；别名 0x61193F。机器入口保存 ECX=G，结束 retn 0x18。
// 六个栈参数按顺序为 x、y、last指针、八字节out指针、a5、a6。
// 反编译标成 __stdcall 并省略 G；实际需同时传入 ECX 游戏对象。
// a5/a6 只读栈槽低 BYTE，调用方用 DWORD push；非零判定不是等于1。
//
// 八槽与对象来源
// ----------------------------------------------------------------------------
// 循环 i=0..7，边界固定8，不读取 G+3616 的实际参与人数。
// 每轮先写 BYTE[out+i]=0，再检查其他条件；不能只覆盖命中槽。
// 可用性 0x60B49F -> 0x63E7D0：读 BYTE[G+3632+i]，低 BYTE 非零继续。
// IDA 的 IsAutoHideMode 名称属于误识别，此处无窗格自动隐藏语义。
// 可用位通过后，从 DWORD[G+3584+4*i] 取 P，作为四状态函数和命中函数的 ECX。
// 主循环不对 P 判空；需要调用方保证可用槽的 P 指针及所读成员有效。
//
// 短路条件，按机器执行顺序
// ----------------------------------------------------------------------------
// 0x608F1A -> 63F4A0：signed BYTE[P+1493] != -1 时排除。
// 0x5FFE74 -> 63EF50：signed BYTE[P+1494] != -1 时排除。
// 0x60263D -> 63EF80：signed BYTE[P+1495] != -1 时排除。
// 0x60274B -> 63EFB0：signed BYTE[P+1497] != -1 时排除。
// 这些谓词读 P，不能把省略的 ECX 解释成 G；任一非零即跳到下一槽。
// 已有资料确认1494医院、1495监狱、1497绑架；1493本题保留字段名。
//
// a6 低 BYTE 非零，直接跳过特殊槽排除；否则调用 6053AB -> 7C0C00(G,i)。
// 64FFE1/64FFE9实际重复读a6：首读非零放行，首读零后第二读非零会排除。
// 两读之间没有写入或调用，稳定栈参数下后一个非零分支不可达；模型按稳定参数。
// 特殊槽谓词为地图模式4且 i==DWORD[G+116]，为真时排除。
// a5 低 BYTE 非零，跳过当前行动槽排除；否则调用 61064D -> 63F470(G,i)。
// 当前行动槽为 DWORD[G+3624]；它与 G+116 特殊槽、G+8 本地槽不能混同。
// a5/a6 只豁免对应一项，不绕过可用位、四状态或几何命中。
// 最后调用 5FF1BD -> 7F7400(P,x,y)，AL非零才命中。
// 主函数的所有谓词返回值均用 movzx AL 检查，不读高24位。
//
// 输出与副作用
// ----------------------------------------------------------------------------
// 命中后 BYTE[out+i]=1，count++，DWORD[*last]=i；遍历不会在第一次命中时退出。
// 返回 count，范围0..8；多个重叠角色都可置1，last最终是最高命中槽号。
// 零命中时 last 保留调用前旧值，不能把它当无条件有效的输出。
// 所有八个输出字节都会先清零，但主函数没有初始化 last、没有写 out[8]以后。
//
// 前置条件及未决边界
// ----------------------------------------------------------------------------
// out需至少8个可写字节；命中时last需可写DWORD，槽对象和坐标子对象需有效。
// 契约模型默认 out、last 与 G/P、输入参数栈及彼此不重叠，输入参数保持稳定。
// 机器码不检查别名或访问范围；输出重叠输入存储可改变后续状态、坐标与flag读取。
// 固定8与实际人数的关系由有效位建立；本题没有证明所有非法初始化都被拦截。
// 0x91F6D0 的栈诊断依赖编译器标志，不是业务成功码或网络响应。
