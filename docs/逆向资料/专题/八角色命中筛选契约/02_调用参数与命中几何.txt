// 八角色命中筛选契约 / 调用参数与命中几何
// ============================================================================
// 0x7F7400(P,x,y) 保存 ECX=P，结束 retn 8；返回 AL=0或1。
// 7F7420 从 DWORD[P+1404] 取关联游戏对象 G；此函数不构造或校验该关联。
// 606535 -> 63E0E0(G) 返回 C=G+3092，再以 C 调用 60BE81 -> 63E000。
// 63E000 返回 C+4 地址，非该地址中的 DWORD 内容；库函数名不是类型证据。
// 两次调用分别用 movsx WORD[C+4]、movsx WORD[C+6] 得到镜头偏移。
// 角色坐标读取 DWORD[P+540]、DWORD[P+544]，此处不按16位截断。
//
// 无32位算术溢出的坐标域
// ----------------------------------------------------------------------------
// right  = DWORD[P+540] - signed WORD[G+3096]
// bottom = DWORD[P+544] - signed WORD[G+3098]
// 命中条件为 x > right-64 且 x < right 且 y > bottom-96 且 y < bottom。
// 7F746A/7F7472/7F747D/7F7485 的 signed jle/jge 排除四条边。
// 宽64、高96是坐标差；整数坐标实际接受63列、95行，共5985点。
// 本函数没有图像尺寸、透明像素、缩放因子或地图格号检查。
// 两次偏移读取之间没有建立锁或快照；静态分析不保证并发坐标一致性。
// sub 指令本身按32位回绕，比较使用有符号条件；普通数学式不覆盖极端溢出。
//
// 四种筛选组合，参数顺序是(a5,a6)
// ----------------------------------------------------------------------------
// (0,0)：排除当前行动槽与特殊槽。
// (0,1)：排除当前行动槽，允许特殊槽。
// (1,0)：允许当前行动槽，排除特殊槽。
// (1,1)：允许当前行动槽与特殊槽；仍检查有效位、四状态与矩形命中。
//
// 全部可见直接入边的参数导航
// ----------------------------------------------------------------------------
// 下列18项是 caller_navigation 局部窗口；每项经61193F别名到64FF10。
//  owner     callsite   (a5,a6)  last地址
//  6535E0    6536A1     (1,1)    ebp-28
//  653850    653911     (1,1)    ebp-28
//  653AC0    653B81     (1,1)    ebp-28
//  653D30    653DF1     (0,1)    ebp-28
//  654380    654441     (1,1)    ebp-28
//  654780    654960     (1,0)    ebp-28
//  654B10    654BD1     (1,0)    ebp-28
//  654DC0    654E81     (0,0)    ebp-28
//  655030    6550F1     (0,0)    ebp-28
//  6552A0    65538A     (0,0)    ebp-28
//  655570    655631     (0,0)    ebp-28
//  655A60    655B21     (0,0)    ebp-28
//  656EA0    656F61     (0,0)    ebp-28
//  657410    6574D1     (1,0)    ebp-28
//  657680    657741     (1,1)    ebp-28
//  657B30    657BF1     (1,1)    ebp-28
//  658510    65862F     (0,0)    全局DWORD A77754
//  658BD0    658C91     (1,0)    ebp-28
// 各项out均为ebp-18的8字节局部区；除658510外，last由lea局部地址传入。
// 658510的全局last可保留先前值，窗口不证明所有零命中后续都不读取它。
//
// 已选择四个完整调用者，审阅范围仍限定本题参数与输出消费
// ----------------------------------------------------------------------------
// 6535E0/653D30/654780/654DC0 分别覆盖(1,1)/(0,1)/(1,0)/(0,0)。
// 入口ECX保存至ebp-8，再在命中调用前恢复；所以主函数G来自调用者this。
// 这四者先清零8字节mask，last只有调试填充值，未设业务有效槽默认值。
// 六次push顺序为 a6、a5、&mask、&last、y、x；调用后保存EAX并先比较1。
// x/y分别来自609956 -> 627270的返回对象，经60D5B0 -> 629BB0与
// 6064F4 -> 629BD0取得；本题仅确认传参链，未追完整输入对象坐标更新机制。
// IDA误识别为CSize或MFC控件方法的名字，不用来给真实类命名。
//
// 单命中：两层AL谓词61138B、60DD35通过后，取last低BYTE填入8字节局部
// 数据，并调用610977 -> 6BF380(数据地址,8)；其余分支可能返回2等待后续。
// 多命中：count>1且编号25界面状态未打开，调用5FFB04(25,0,0)，随后
// 605B76(25,&mask)；这是候选选择流程的局部证据，完整控件协议另行恢复。
// 已有编号25选择状态时，另从601D00(25)指向的DWORD取目标；非-1可发送。
// 四者在零命中的本次调用路径不消费last；此结论不外推其他14个调用者。
// 6032EA的设置参数分别为30、9、7、32；本题未恢复它们的业务枚举名称。
// 654780在命中筛选前还有地图区域扫描，未将这部分列为完整新语义成果。
// 返回0/2/3与局部发送行为不能直接解释成网络ACK、服务器处理成功或失败。
