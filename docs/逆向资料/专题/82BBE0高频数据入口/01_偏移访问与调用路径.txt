// ============================================================================
// 偏移访问与调用路径
// ============================================================================
// 记号：+偏移为十进制字节；DWORD 为四字节；U 表示传入 ECX 的对象指针。
// 82BBE0 的唯一业务读取位于 82BC06：mov eax,[eax+10h]。
// 前面把 ECX 暂存至局部变量，随后读 DWORD[U+16] 并以 EAX 返回。
// 函数没有 NULL 检查、范围判断、分配、写回或所有权转移。
// 该返回值可作为另一个对象的 ECX；这一事实不能单独证明它始终指向同一种对象。
// 60BFDA 的完整五字节为 E9 01 FC 21 00，目标精确为 82BBE0。
//
// 最常见的后续调用形态
//   61 个有归属窗口中，33 个在调用 60BFDA 后执行 mov ecx,eax，再调用 602D63。
//   602D63 是 82BEE0 的 E9 别名；后者返回 DWORD[传入对象+8]。
//   因此这 33 处可确认“先取 U+16 指针，再读其 +8 字段”的表达式。
//   另 7 处紧接 611D7C（指向 84B860）、6 处紧接 606EEF（指向 856C30）、
//   2 处紧接 607188（指向 887AF0）；这些是窗口内的调用形态，不直接命名字段类型。
//   其余 13 处经过条件、其他调用或局部变量交接，不能归入上述直接两调用链。
//
// 代表上下文
//   82EDD0：从当前 this 取 +16，再读返回对象的 +8，赋给 this+192；
//           同函数还写 this+180=0、+184=2、+196=5。这里仅确认字节偏移及赋值。
//   840230：沿 8976E0 -> 82AB80(+32) -> 82A900(+80) -> 82BBE0(+16) 链读取，
//           先经 8403F0 取值放 A6779E，再次经 82BEE0(+8) 放 A677A0，随后回调事件 8。
//   846AB0：同一上游链两次取得 +16 指针；一次经 82BEE0 取 +8，
//           一次传给 856C30 生成其内部记录视图，并向 this+368 的下游函数传值。
//           856C30 返回传入对象 +128 的既有结论见“大厅玩家记录与装备字段”；
//           本文不能据单个调用者把所有 U+16 指针都定名为玩家对象。
//   82AB80 和 82A900 的 +32/+80 读取已有“文本解析高频接口”原证；这里只复用。
//
// ABI 与补丁边界
//   82BBE0 为 thiscall 风格，输入为 ECX，返回为 EAX，普通 retn 不清理栈参数。
//   通过 60BFDA 的 E9 入口进入时，寄存器和栈契约不变。
//   新资源或补丁在解引用返回值前须自己确保 U 及 DWORD[U+16] 有效；
//   不得把该只读访问器误当作生命周期管理入口，也不能直接把 +8 当作网络包字段。
