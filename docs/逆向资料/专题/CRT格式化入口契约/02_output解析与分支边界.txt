// output解析与分支边界
// ============================================================================
// 932FC0..933C88主声明块3272字节，856个指令记录；逐分支阅读仍不等于全部依赖闭合。
// 本体为cdecl，FILE、Format、可变参数游标为三个32位栈参数；返回累计输出计数。
// EBP-23Ch是累计计数，初始0；932FF3每轮读格式BYTE并将格式指针加1。
// NUL或累计值为负从933C76返回；不能把Format为NULL的入口断言当成该处保护。
//
// 状态机与格式字段
// ----------------------------------------------------------------------------
// 933023..93304C将有符号字符32..120映射为[A33F60+字符]&0Fh，其他类别为0。
// 93306A..933081取[A33F80+类别*8+当前状态]，signed扩展后SAR4产生下一状态。
// 这两组读都使用同一紧凑表，低半字节是字符类别，高半字节是迁移信息。
// 8个状态经9330A6间接跳转；状态0输出字面字符，状态1重置当前转换上下文。
// 状态1：width=0、precision=-1、flags=0、前缀长度=0、宽字符串标识=0。
// 状态2：'-'置4、'+'置1、空格置2、'#'置80h、'0'置8。
// 状态3：宽度数字为32位width*10+digit；'*'消费4字节signed值，负值NEG并置左对齐位4。
// 状态4把precision设0；状态5数字为precision*10+digit，'*'负值改为-1。
// 数字积累没有溢出拒绝，INT_MIN宽度NEG仍为INT_MIN；仅为静态位型边界，未验证可达输入。
// 状态6：h置20h，l置10h，w置800h；I64消费后续两字符置8000h，I32清8000h。
// 裸I仅在后继d/i/o/u/x/X时接受；其他后继使状态回0并从字面字符路径输出I。
// 格式宽度是最小补齐量，precision是相应转换的限制；二者都不是目标Buffer容量。
//
// 窄%s与精度
// ----------------------------------------------------------------------------
// 93351F..93354A：precision=-1时扫描上限为7FFFFFFFh，否则采用precision，并消费一个指针槽。
// 未置810h时走窄串：NULL替换为A69DA4槽所指默认串；9335DD循环先减扫描余量。
// 余量为0即跳出且不读取源BYTE；否则读源BYTE直到NUL，实际长度为游标-起点。
// 933C17..933C2A把源和已计算长度交写者，源内容中的百分号不重新作为格式串解析。
// %s默认没有业务长度上限；%.Ns只约束源扫描/数据长度，前后padding仍由width决定。
// %Ns中的N是width，并不截断长字符串；不要把它当成安全替代%.Ns。
// 宽路径按WORD扫描；最终逐WORD交wctomb，转换结果<=0中断该次宽串输出。
// 本体未把该宽串失败分支直接置累计计数-1；locale/转码内部及实际编码需另核。
//
// 字符、计数指针与计长串
// ----------------------------------------------------------------------------
// %c窄路径消费DWORD，取低BYTE，数据长度1；可输出NUL，返回计数不等于strlen。
// %C默认在830h未置时置800h；%S采用同样默认规则；显式h/l/w会影响宽窄分支。
// %n在933625消费一个指针，h标志时写WORD，否则写DWORD，值为当前累计计数。
// 写后置跳过输出标识；没有指针NULL检查，不能宣称格式器不修改可变参数指向内存。
// %Z消费计长串描述符：+0为signed WORD长度，+4为数据指针；未读取+2容量字段。
// w标志时长度signed除2并标为宽串；描述符或数据NULL使用默认窄串。
// 描述符边界、负长度及字符串真实分配范围没有在此分支完整校验。
//
// 整数与前缀的已审局部契约
// ----------------------------------------------------------------------------
// d/i置signed标识40h、base10；u为base10，o为8，x/X为16，p设precision=8走大写十六进制。
// I64从参数游标取8字节；h仍消费DWORD再取低WORD，signed路径MOVSX，unsigned路径MOVZX。
// 普通signed值CDQ到64位，unsigned值高DWORD清0；非I64在取绝对值后再清高DWORD。
// 负值设置100h并生成'-'；否则依次考虑'+'与空格。'#'十六进制前缀0x/0X，零值清前缀长度。
// 整数precision默认1；显式precision清零补齐位8，且大于512钳到512。
// 数字反向生成，自EBP-39h向低地址写；求余/除法经60F388→93E900与60F1FD→92A430。
// 这两个64位算术依赖仅确认调用ABI和桥，本专题没有审阅内部全路径。
// 不能以CRT名字替代其商余数实现证明，也不将上述局部整数链升级为全闭合。
//
// 浮点、字面双字节与未完成范围
// ----------------------------------------------------------------------------
// e/f/g及E/G浮点链：默认precision6，g的0改1，最大512；超过163尝试分配precision+349。
// 分配失败把precision改163；参数游标前进8字节，两个DWORD交A69DB0间接回调。
// '#'且precision0时调用A69DBC，g无'#'调用A69DB4；最终strlen计算长度并释放临时块。
// 9337C0明确跳到共同输出，伪码的浮点case紧邻%n不代表浮点会写%n指针。
// 指针槽初始化、回调真实实现、allocator与locale边界未闭合；不认领完整浮点格式。
// 状态0用A69D74所指分类表的8000h位判断双字节首字节，额外读取并输出下一个BYTE。
// 第二BYTE为NUL只断言后继续；运行时分类表来源和不同ACP行为尚未验证。
// 格式表、switch映射与写者的原证详见证据目录；所有未审依赖仍保留续查入口。
