// ============================================================================
// 记录布局 / 不能混淆的三个编号域
// ============================================================================
// 序号i：决定dice%d/move%d/back%d/deng%d段名，范围0..num-1。
// prop：段内atoi得到的DWORD，是访问器比较键，不是数组下标或图像槽。
// 图像槽：字符串经627760取图像对象，再由6DAA10名称解析生成的返回DWORD。
// NP编号：由图像映射记录决定，ASTable字段不直接保存该编号。
//
// DICE / 记录步长0x1C
// ----------------------------------------------------------------------------
// +00 DWORD       prop：64045A写入。
// +04..+13        内嵌DWORD序列容器；追加this=record+4，元素值取图像解析返回。
// +14 DWORD       geng：值精确为NULL时-1，否则写6DAA10返回，无本地失败门。
// +18 DWORD       luo：处理方式同geng；不能据中文近义词替代原始配置键。
// comm%d从0连续递增，查键失败或值strcmp精确等于NULL时停止；本体无固定上限。
// 无效图像返回值可被追加，NULL停止和无效名称返回-1是不同控制路径。
// 611AB6 -> 646480构造回调：把record+4交6466C0，不初始化prop/geng/luo。
// 60E28A -> 646450销毁回调：把record+4交646720。
// IDA的COleSafeArray/MFC自动名称不证明真实类；按实际指针和DWORD元素操作解释。
// 主体没提供DICE prop访问器认领，本专题不扩成骰子动画完整状态机。
//
// DICE内嵌容器 / 以下偏移以record+04作为this
// ----------------------------------------------------------------------------
// +00             构造链把此地址交allocator相关包装；其存储内容尚未证明。
// +04             首元素指针；对应DICE记录+08。
// +08             已用末尾指针；对应DICE记录+0C。
// +0C             容量末尾指针；对应DICE记录+10。
// 6466C0先经6101D4调用646B50，再经609B40调用646B10，最后以参数0调用646960。
// 646B10只把栈参数地址交612461 -> 6470C0，并返回this；本体没有对象字段写入。
// allocator包装与6470C0未全审，不据这一调用宣称+00已清零或真实allocator类型。
// 646960先清+04/+08/+0C；参数0时AL=0返回，所以本构造链得到空序列。
// 非零参数路径经外部上限/失败/分配接口，再令end=begin、cap=begin+4*N。
// 这些是本地字段写入，分配失败和异常语义仍由未审后端决定。
// 63F870：begin为0时size=0，否则(end-begin)>>2；646800同样求(cap-begin)>>2。
// 646750用unsigned size<capacity分支；有容量时传end、1和元素地址给646AC0，
// 返回值存end；无容量时走646860/6468A0。该插入/扩容后端只认领调用边界。
// 646720经60E1CC调用646A20；646A20在begin非空时先把begin/end交646BA0，
// 再把begin与(cap-begin)>>2交6470E0；随后无条件清+04/+08/+0C。
// 646BA0/6470E0未逐函数审阅；区间处理、最终释放与异常仍为部分闭环。
// 空容器销毁跳过上述两调用，但仍清三指针；+00未在646A20本体清写。
//
// MOVE / 记录步长0x14
// ----------------------------------------------------------------------------
// +00 DWORD       prop。
// +04/+08/+0C/+10  dir0、dir1、dir2、dir3图像槽；循环恰好读取四项。
// dir序号本专题只确认四槽排列，尚不能把0..3无条件命名为东南西北。
// 键查找、图像转换均无本地失败分支；不会以NULL为特殊空槽哨兵。
//
// BACK / 记录步长8
// ----------------------------------------------------------------------------
// +00 DWORD       prop。
// +04 DWORD       value图像槽；直接写名称解析返回。
//
// DENG / 记录步长0x0C
// ----------------------------------------------------------------------------
// +00 DWORD       prop。
// +04 DWORD       wait图像槽；直接写名称解析返回。
// +08 DWORD       anim整数；通过atoi，不是wait名称解析出的图像槽。
// 7FB1C0读+08，642740读+04；两个消费者证明字段被分别使用。
//
// 图像名称转换失败
// ----------------------------------------------------------------------------
// 6DAA10支持十二名称前缀；空指针、空串、成功拆首段后的未知前缀返回-1。
// 缺下划线的内部扫描没有字符串终止保护，不能把所有格式错误都写成安全-1。
// 6DBA40在合法类型/索引下取运行时槽，无效查询可返回-1；支持域见角色专题03。
// ASTable的各字段不检查解析返回值，失败不回滚，也不自动加载替代图像。
// 这里只复用已审契约，不重复宣称整个图像映射分配和缓存系统已经闭环。
