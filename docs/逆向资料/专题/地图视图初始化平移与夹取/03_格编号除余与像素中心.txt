// 7E1600 / 50字节、20指令，历史本体深化
// ----------------------------------------------------------------------------
// ECX=M，三个DWORD栈槽为index、outX、outY，ret0Ch。
// 7E1611读取index；CDQ；IDIV DWORD[M+1C]；EDX余数写*outX。
// 再次读取同一index，重复CDQ/IDIV，EAX商写*outY并作为返回值。
// 这不是无符号除法：负index按向零截断求商，余数符号跟随被除数。
// 无除数零门、无INT_MIN/-1溢出门、无负编号/地图高度/指针有效性检查。
// 两次独立除法说明代码会再读除数；不把本体虚构成并发安全或一次取值快照。
//
// 7B6F60 / 221字节、77指令，历史本体深化
// ----------------------------------------------------------------------------
// ECX=V，栈a1=index、a2=M，ret8；7B6F98经607EB7调用7E1600。
// outX/outY局部实际为DWORD，不能照伪码把结果称为16位格坐标。
// centerX=32位(x<<6)+32；centerY=32位(y*48)+24。
// 第一矩形left=low16(centerX - (s16(width1) SAR 1))，top用height1同理。
// 第二矩形left/top以width2/height2重复相同运算。
// 7B7017经611697调用7B6D50；居中后再夹取，故边界格不一定视觉居中。
// SAR是有符号右移：例如尺寸-3的半尺寸为-2，不是C++有符号除2的-1。
// centerDWORD计算与最终WORD写回都可回绕；本体无格式/范围/资源生命周期门。
//
// 尺度与初始化相互校验
// ----------------------------------------------------------------------------
// 同一M+1C既作格编号除数，也由6919F0乘64产生横像素界；
// M+20由691A20乘48产生纵像素界；中心是每格64×48格内的32、24偏移。
// 静态证据支持矩形格坐标到该像素空间的关系，不证明地图渲染的其他投影或缩放。
// 初始化621×569的第一矩形与610×536的第二矩形均使用此中心与共享像素界。
// 初始编号0产生中心32、24，随后夹取；界足够大时两矩形初始左上都会夹到0。
// 地图界不足或回绕时须遵守02中的例外，不能将该示例推广成所有地图的初值。
//
// 调试尾部与返回限制
// ----------------------------------------------------------------------------
// 7B7026经6127BD到91F700，传7B703D调试检查描述；该data引用不算界面文案或字符串。
