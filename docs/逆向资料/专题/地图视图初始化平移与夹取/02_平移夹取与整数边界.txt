// 地图视图 / 平移、夹取与整数边界
// ============================================================================
// 下列s16表示WORD按有符号16位解释，low16表示只保留低16位。
// 算术中间结果按实际32位x86指令回绕；不是数学整数或无溢出C++算术承诺。
//
// 7B6EF0 / 106字节、33指令
// ----------------------------------------------------------------------------
// ECX=V，栈a1=dx、a2=dy，各DWORD；ret8。
// V+04=low16(s16(V+04)+dx)，V+06=low16(s16(V+06)+dy)。
// V+20=low16(s16(V+20)+dx)，V+22=low16(s16(V+22)+dy)。
// 位移是完整DWORD参与加法；不能照伪代码缩成__int16参数。
// 7B6F45经611697→7B6D50，无栈参数，ECX仍为V。
// 四次回写之后才夹取；本体不写游戏角色位置，不等于角色移动或回合推进。
// 7B6F4F外部91F6D0为栈诊断依赖，未展开深层行为；无统一成功返回约定。
//
// 7B6D50 / 408字节、128指令，历史本体深化
// ----------------------------------------------------------------------------
// 先处理第一矩形，再处理第二矩形；第二使用+1C/+1E及+20..+26。
// 每矩形按以下实际顺序处理，四边均为WORD：
//   left<0时写left=0；top<0时写top=0（均先movsx再signed比较）。
//   right=low16(s16(left)+s16(width))；bottom同理。
//   若s16(right)>s16(boundX)，right复制boundX，left=low16(s16(right)-s16(width))。
//   若s16(bottom)>s16(boundY)，bottom复制boundY，top同理。
// 两套共享V+18/+1A边界；超界回推后没有再次检查left/top是否负。
// 7B6DC3/7B6DF9/7B6E86/7B6EBD是signed JLE，不能按旧伪码写成unsigned比较。
// 本体无内部调用、无参数校验，结尾EAX随最后执行路径变化，不是bool成功结果。
//
// 开发时必须保留的例外
// ----------------------------------------------------------------------------
// 例如横界500、第一宽621、原left=0：right621超界，最终right500、left=-121。
// 第二宽610同样得到left=-110；因此“始终非负”与当前指令不符。
// 例如left32760、width621：right写WORD后变成signed -32155，signed超界判断
// 未必成立，不能把原算法改述为无限精度 min(max(x,0),bound-width)。
// 负宽高、负地图界、极大DWORD位移均没有门；是否能被上游合法输入触发尚无实机证据。
// 第一、第二尺寸不同，在各自超界后左上不一定相等；“同步位移”不等于“永远同坐标”。
