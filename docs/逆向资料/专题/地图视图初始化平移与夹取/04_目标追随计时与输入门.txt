// 638150 / 404字节、134指令，部分分析
// ----------------------------------------------------------------------------
// C=this；629C90取得G；63E0E0取得V=G+C14；63E000取得P=V+4。
// P+0/+2是第一矩形left/top的signed WORD，非宽高、角色坐标或第二矩形位置。
// C+18/+1C是DWORD目标；C+C/+10是DWORD步进；C+4内嵌计时门对象。
// 当前两轴均等于目标，6381B2立即return1，发生在计时门之前。
// 未达时6381C2经6107F1调用81BD10(C+4)，仅消费AL；门不通过return0。
// 对每轴：目标>当前时取step，若当前+step越过目标则delta=目标-当前；
// 目标<当前时取-step，若当前-step越过目标则delta=目标-当前；相等轴delta=0。
// 比较为signed DWORD；加减/NEG仍按32位指令回绕；未校验步进为正。
// 负步进、零步进、超signed WORD可表达范围的目标不保证收敛。
// 6382CF经60EE10调用7B6EF0(V,dx,dy)，写回及夹取后6382D4仍return0。
// 到达当步返回0，下一次入口两轴已相等才返回1；被地图界夹取时也可能始终未达。
// 目标/步进/计时间隔初值、C对象生产者与调用周期未闭，故保留部分分析。
//
// 81BD10历史局部契约 / 111字节、38指令，不新增业务认领
// ----------------------------------------------------------------------------
// T=this，有两个DWORD字段：+0间隔，+4前次tick。
// 旧原证将IAT AD3CBC命名为GetTickCount；当前call指令字节与IAT槽地址已复核。
// 第一次tick n与前次p作unsigned比较：n<=p直接拒绝；否则n-p<间隔拒绝。
// 通过时第二次调用取得tick写T+4，AL=1；拒绝不写前次tick，AL=0。
// 第二次tick不是第一次的快照；AL才是返回契约，不把EAX高位当规范bool。
// 间隔0仍要求n>p；DWORD tick回绕后n<=p会拒绝，不能称完整回绕安全节流器。
// C+4调用意味着C+4间隔、C+8前次tick；C字段初始生产者未闭。
//
// 650C10 / 316字节、101指令，部分分析
// ----------------------------------------------------------------------------
// 保存ECX=G，step=25，dx=dy=0；627270取得外部对象。
// 629BB0返回横向比较值x，629BD0返回纵向比较值y；来源与坐标空间未闭。
// x<=32 或 64ED60(input,37)的AL真：dx=-25，直接跳过右分支。
// 否则x>=603 或 64ED60(input,39)的AL真：dx=+25。
// y<=55 或 64ED60(input,38)的AL真：dy=-25，直接跳过下分支。
// 否则y>=574 或 64ED60(input,40)的AL真：dy=+25。
// 阈值来自25+7、621-25+7、25+30、569-25+30的实际指令。
// 条件是短路OR；坐标条件成立时不调用对应64ED60；左右同真左优先，上下同真上优先。
// dx或dy任一非零才在650D39调用7B6EF0(G+C14,dx,dy)，可同次产生对角位移。
// 本体没有统一成功返回；边缘检测、键值含义及是否采用WinVK不能凭37..40推定。
// 627270/629BB0/629BD0/64ED60当前仅闭桥与调用点，没有展开输入生产链，仍计部分。
//
