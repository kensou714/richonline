// 载荷格式与 CRT 消费
// ============================================================================
// 0x64A520 共享载荷布局：A77090+0 模式标签，+1 语言标签，+2 过滤并转义后的文本。
// 两个标签分别由 _snprintf(dst, 1, "%d", value) 产生；标签之间没有单独 NUL。
// 语言值来自 0x627160 与 0x64ED90；该选择逻辑复用文本过滤专题，不在此扩语言表。
// 文本随后 strcpy，最终 NUL 与 strlen+3 构成长度；例如 mode=2、language=1、abc 为 21abc\0。
// 这是消息 13 的进程内 payload；不能据此跳过传输层而把它当成完整 TCP 帧。
//
// 旧 CRT 的 count=1 语义
// ----------------------------------------------------------------------------
// 0x922930 _snprintf 构造 FILE：cnt=count，flag=42h，base=ptr=dst，交 0x932FC0 _output。
// _output 的整数十进制路径生成数字串，经 write_string / write_char 消费 FILE。
// 字符写入先减 cnt；有余量才写 ptr 并前移，容量不足调用 0x932CD0 _flsbuf。
// _flsbuf 发现 flag 的 40h 位即设置错误位 20h 并返回 -1，不补写目标字符。
// 格式化结束后 _snprintf 还尝试写 NUL；count=1 的一位数字已耗尽容量，NUL 写入失败。
// 因而一位 0..9 保留该字符且不 NUL 终止；不能套用 C99 “count=1 只写 NUL”。
// 一位数字的 _output 返回 1，尾部 NUL 失败不覆盖该返回；多位截断路径 _output 返回 -1。
// 多位正数只保留首位；负数先保留 '-'，后续写失败；调用方没有消费格式化返回值。
// 正常 mode 0..3、正常单数字语言得到一字节标签；非法 mode 仍继续路由，不能写成安全拒绝。
// 本题只审 _output 的 %d 消费路径，不声称浮点、宽字符、locale 状态机都已闭合。
// 两个%d常量与前缀指针/目标串均已单独回证当前EXE；A67341文件初值为1。
//
// Source 的变换顺序
// ----------------------------------------------------------------------------
// 0x64A520：缓存原文 -> 过滤(64C9E0) -> 转义(64CDC0,1) -> 复制载荷 -> 分派 -> 恢复转义/历史。
// 64CDC0 mode=1 把 '%' 写为 01；mode=0 把 01 写为 '%'；详细字码语义见文本过滤与字码转换。
// 原文已有 01 时不能视为无损往返；恢复转义也不撤销过滤，所以返回后的 Source 可能改变。
// 此入口判断重复用原始文本，历史去重用过滤并逆转义后的文本，两者不是同一个键。
//
// 另一入口：0x64A820
// ----------------------------------------------------------------------------
// thiscall，栈仅 Source，retn 4；非空检查和两层门控共用状态，没有 mode=2 特例。
// 缓存原文后先转义，再过滤，与 0x64A520 的调用顺序相反，不按经验替它交换。
// 栈参数 +0=0、+4=1、+8=0、+12=0、+16=3；载荷为 off_A67308 指向的前缀拼接文本。
// 指令注释显示前缀 [gm]；实际字节与指针另保存在 static_data，不能只靠注释下结论。
// 长度为 strlen(A77090)+1；分派返回后同样无条件进入历史函数。
//
// 0x828F60 case 13 的限定阅读
// ----------------------------------------------------------------------------
// 首先调用 0x82AEA0(payload) 作前缀判定；为真则跳过 strlen("[gm]") 字节，调用 0x612411。
// 这里 strlen 使用 A2F048 的独立常量，不是入口 off_A67308 的指针目标 A228FC；两份字节均回证。
// 本题未完整审 0x82AEA0，不把该调用扩写成权限校验或服务器 GM 认证。
// 非前缀路径按结构 +16：0 交 0x82E4B0，1 交 0x82E660。
// 2/3/4 先用结构 +12 调 0x872310，所得目标与 payload 交 0x82E810。
// 上述目标由 E9 字节回证；5/6 分支与其他消息不属于本题新增成果。
// 82A3BD 七项跳表单独保存；2/3/4 三项同指向 829D5F，而非仅依据反编译case标签。
// 分派内部仅在当前调用帧传递指针；下层是否复制、排队或异步持有仍须复用/补查传输层。
