// 历史与复制边界
// ============================================================================
// 0x64C140 thiscall，栈 Source；先调用 0x64CDC0 mode=0 恢复百分号，再比较历史。
// this+2A80Ch 起共 16 个槽，步长 154h=340；逐槽 strcmp，相同立即离开，不移动游标。
// 新文本 strcpy 到 this+2A80Ch+340*[this+2BD4Ch]。
// 然后写游标=(旧游标+1)%16，读游标 this+2BD50h=新写游标。
// 指令用有符号余数序列；只有旧游标为 0..15 时，才是常见 16 槽环形推进。
// 本函数没有检查游标范围；不能把损坏/负游标的行为套入正常环形模型。
// 340*16=5440，2A80Ch+5440=2BD4Ch，写游标紧邻最后一个槽。
// 当前初始化入口清游标，不清这 16 槽的文本；完整槽初值要追构造/其他清空路径。
//
// 复制函数的真实边界
// ----------------------------------------------------------------------------
// 0x9204C0 strcpy 只有 3 条指令，跳到 0x920535；共享复制主体属于 IDA 的 0x9204D0 函数块。
// 导出同时保存该块；不能看入口 3 条指令就当作完整复制函数，也不能把共享块算两份新成果。
// 主体按源地址对齐逐字节/逐 DWORD 找 NUL，复制含 NUL 并返回原目标；没有容量参数。
// strcat 在同一块先找到目标 NUL，再进入共享复制主体；重叠或不可读源不具备安全保证。
// DWORD 扫描可读取终止字节之后的同一字；可读地址范围不能只依据 strlen 算术假定。
//
// 全局邻接不是容量声明
// ----------------------------------------------------------------------------
// A76E70 到下一业务命名 A76F80 相差 110h=272，但 IDA 把前者定义为 1 字节项。
// A76F80 有 272 字节项定义且另有许多命令输入引用；本题只记录邻接，不命名成双缓冲结构。
// A77090 到长门 A772A0 相差 210h=528；其后 8 字节是短门 A772A8。
// 载荷缓冲的 IDA item_size=528 不是源代码数组声明，更不是 strcpy 自动截断的证明。
// 可以明确的算术前提：若允许写到 A772A0 之前，普通载荷文本应至多 525 字节含外部约束。
// 原因：两个标签+文本+NUL 总长 L+3<=528，因此 L<=525；这不是已证明的可达输入上限。
// 若原文长 L=272，写 A76E70 的 NUL 已落到 A76F80；若载荷文本 L=526，NUL 落到 A772A0。
// 这些是地址写入边界模型，不是已复现漏洞；过滤后长度、UI 限长、串行性都需现场确认。
// 历史槽若要留 NUL，单槽文本 L<=339；本函数无强制检查，不能仅凭步长证明真实可触发溢出。
//
