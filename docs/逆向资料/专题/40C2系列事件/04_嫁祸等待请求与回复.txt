// 608C由7D7640构造，仅2字节；7F1C30桥接到681D30，读取G中已缓存的上下文。
// 63E560检查signed BYTE[G+83813]是否等于DWORD[G+8]，也就是受害者是否本机。

// 用户选择与自动选择
// ----------------------------------------------------------------------------
// 717760取7278E0返回的选择值，调用G.7BC100(choice)。
// 717650在状态/界面门控通过后调用7BC100(-1)，再6939E0清pending。
// 本专题只证明调用与返回值传递；控件树、鼠标命中与7278E0内部选择存储留界面专题。
// 自动选择入口也调用7BC100，详见“回合等待与自动选择”。
//
// 7BC100提交记录
//   +0 WORD=0x0076，由7D6050构造。
//   +2 WORD=DWORD[G+0xC48]低16位，由G+0xC44子对象的63E440取+4 DWORD。
//   +4 BYTE=choice；+5未见业务显式写入，调试局部填充0xCC不作网络规范。
//   提交6字节至610977 -> 6BF380，随后关闭UI27。
//   RTC描述表也标记EBP-16的该记录为6字节；伪码v4[3]不能作为包长依据。
//   参数-2才自动从0到参与者数量-1寻找首个合格且不是原受害者的槽；找不到改-1。
//   参数-1不执行搜索。其他显式槽值沿用低字节；资格检查完整产品语义未恢复。
//   此入口没有current==local门。进入提交接口不等于实际TCP成功，也不清除所有pending。
//
// 40C6的入口与共同操作
// ----------------------------------------------------------------------------
// 60CF20 -> 7F0A50 -> 608D8F -> 6712B0。
// ABI同本组：cdecl桥接(G,p)，ECX=G，handler retn4。
// 校验p+2 WORD GmsvID后，6939E0令pending WORD[G+83790]=-1、duration[G+83792]=0；
// 再关闭UI27，按p+4 signed BYTE选择值分支。最小读取范围5字节，非完整协议长度。
// 此处说明限G+83812==3的陷害嫁祸，0/1/2是其他金钱流程，未在本篇完整审阅。

//   扣嫁祸卡、声音314、6063(新目标,1)。查卡返回值此处未用于阻止后续扣卡。

// 选择槽 == -1
//   type3仍对原受害者排动画11；不扣嫁祸卡。
