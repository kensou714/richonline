// 音效资源记录 R（new 0x28，即 40 字节；0x826B60 初始化）
// ----------------------------------------------------------------------------
// +0   4 指针     已加载音频数据      0x825230 写；0x824D40 读；0x825660 释放清零
// +8   4 指针     缓存链下一节点      0x825500/0x825660/0x825890 读写
// +12  4 指针     缓存链上一节点      同上
// +16  4 整数     活动播放引用数      0x824D40 加一；0x825770 减一；0x8255F0 检查

// +28  4 uint32   载荷绝对文件偏移    0x824960 写；0x825230 读

// 此结构不是文件的 16 字节索引；其中有指针、引用数和链表字段。

// 音效播放记录 P（new 0x20，即 32 字节；0x826BE0 初始化）
// ----------------------------------------------------------------------------
// +0   4 句柄     Miles sample handle       0x824D40 写；AIL_* 消费
// +4   4 float    左声道乘数                0x824D40 写并乘 S+636
// +8   4 float    右声道乘数                同上
// +12  4 指针     对应资源记录 R            0x824D40 写；0x825770 读
// +16  1 字节     完成标志                  0x824D40=0；0x825770=1
// +24  4 指针     下一播放记录              0x8254A0/0x825940 读写
// +28  4 指针     上一播放记录              同上
// +20 构造器清零，语义待验证；+17..19 未恢复。
// 同一个 R 可关联多个 P，因此播放结束不能立即无条件释放音频数据。

// 音效生命周期
// ----------------------------------------------------------------------------
// 0x824960：登记 FILE* 与索引；数据指针保持空，未播放不加载载荷。
// 0x824D40：取空闲 sample handle / P；首次调用 0x825230；识别 WAV/MP3；
//   设置循环次数、左右音量，加入 P 活动链，R 引用加一，启动播放。
// 0x825500：把资源放缓存头；0x8255F0 仅在尾项引用数为零且数据非空时回收。
// 0x825770：轮询 AIL_sample_status，非零且 <=2 时触发回调、移走 P、R 引用减一。
//   这里不能把未经 Miles 枚举核对的所有值武断命名为某种状态。
// 0x825940：摘除 P 并把 handle/P 放回池；不是直接 delete。
// 0x825A40：遍历全部 ID 槽，释放数据并回收 R，最后删除索引指针表。
// 0x825C10：销毁空闲 R/P，结束并释放 sample handles。
// 0x825D00：弹出 FILE* 并 fclose；0x825D60：关闭 digital driver。
// 这些入口各自语义已恢复，调用方的完整关闭顺序仍需追踪，不能任意交换。

// 音乐管理对象 M（0x81F950 的 this；与 S 无继承关系证据）

// 音乐生命周期
// ----------------------------------------------------------------------------
// 0x81FC50 登记 HANDLE/偏移/长度；0x8200B0 创建可复用播放记录并返回列表索引。
