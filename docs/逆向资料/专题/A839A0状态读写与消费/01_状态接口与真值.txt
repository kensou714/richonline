//
// 位置与宽度
// ----------------------------------------------------------------------------
// A839A0 在八个短函数中均以 DWORD 访问。它不是BYTE，也不是某个已恢复对象内偏移。
// IDB数据显示 ffffffff，但对应4字节无磁盘raw映射，只落在节的虚拟范围。
// 这不是文件初值、运行初值或已验证启动值。需要启动写入/加载器与运行时证据才可定初值。
// 目前可以称共享状态字；不按自动符号 UnDecorator 命名业务，不先称教程或联网状态。
//
// 完整接口契约
// ----------------------------------------------------------------------------
// 6B8320：cdecl，读取栈参数[ebp+8]，整DWORD覆盖A839A0，EAX返回原参数，普通ret。
// 它不校验范围、不规范化为0/1，不保留旧状态的未知位；新参数中的未知位也会写入。
// 798D10：无显式参数，读DWORD到EAX直接返回，调用者取得完整32位状态。
// 6B77B0：EAX = ((A839A0 & 2) == 0) ? 1 : 0。
// 796DB0：EAX = ((A839A0 & 4) == 0) ? 1 : 0。
// 7978B0：EAX = ((A839A0 & 8) == 0) ? 1 : 0。
// 三个查询都执行 AND / NEG / SBB / INC，结果严格为32位0或1；含义是位未设置。
// 798D20：A839A0 |= 2；EAX返回修改后的整个DWORD。
// 798D40：A839A0 |= 4；EAX返回修改后的整个DWORD。
// 798D60：A839A0 |= 8；EAX返回修改后的整个DWORD。
// 三修改器的读-或-写均无LOCK，也没有临界区调用。不能据此声称跨线程原子性。
// 它们保留所有其他位；重复调用同一修改器在值层面幂等，没有本批发现的清位接口。
//
// 位与调用关系
// ----------------------------------------------------------------------------
// 记录1 -> 查询6B77B0 / 置位798D20 / 掩码00000002。
// 记录2 -> 查询796DB0 / 置位798D40 / 掩码00000004。
// 记录3 -> 查询7978B0 / 置位798D60 / 掩码00000008。
// 记录与修改器的映射来自768307..768329；查询消费者的局部窗口另见03。
// 0x0E以外各位本批没有赋予业务名；bit0尤其不能因未使用就认为保留或恒零。
// 若状态为0，三查询均为1；为0x0E，三查询均为0；高位不影响这三个查询。
//
// 修改注意
// ----------------------------------------------------------------------------
// 若未来补丁直接写整个DWORD，需要先知道未知位来源，不能把状态简单压成0/1。
// 若未来修改三查询的返回值，需要保留调用方读取AL的事实，而不是改成掩码本身。
