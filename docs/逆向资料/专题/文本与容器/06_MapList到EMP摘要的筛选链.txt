// Data/MapList.kpd解包 -> 模式2复制文本 -> 四组按节读取；每组前均回到缓冲首。
// XIN_MAP、CHU_MAP、ZHONG_MAP、GAO_MAP均按item0起递增，首个缺键结束该组。
// 值调用容量128，因此有效路径文本最多127字节，但下游FileName还有更小约束。
// 每值调用7E6F10(name,0)，只读取EMP摘要，不读取预览像素。
// 成功后根据摘要对象+24的32位模式判断是否加入当前目标列表：
// XIN_MAP：691A70 -> 63EDD0，mode==2。
// 另外三组：63ED10 -> 629DD0，mode==0；或63EE90 -> 629DF0，mode==1；
//            否则63E990 -> 629E10，mode==4。
// 这些是已证数值，不擅自把枚举2/4翻译成玩法名称。
// 四组末尾还遍历另一管理器类别0与2，取记录+4路径；摘要成功且63E160谓词通过再加入。
// 因此地图目录可来自MapList之外，缺少列表行不必然意味着完全不可出现。
// 63E160转调一个被误标COleDocument::GetNextItem的模式谓词，下一实现待核。
//
// 7E6F10读取摘要；对象偏移为十进制
// ----------------------------------------------------------------------------
// 路径经7DED90格式化Map\\%s，目标局部FileName由IDA显示72字节（含调试布局）。
// 尚未证明真实可用容量72，不能只遵守上游127字节就宣称路径安全。
// fopen(rb)失败返回0；成功后跳过16字节，读4字节到对象+4（版本）。
// 后续0x5AE4=23268字节区，在参数0时直接seek跳过；参数非0才读出并交图像接口。
// 紧接着读4字节到对象+24（上述模式）。
// 版本>=2：再读DWORD到+104、+108；版本>=3：再读DWORD到+112。
// 随后各读4字节至临时区，但仅取低字节分别赋DWORD字段+28和+32。
// 再读20字节到+1292、100字节到+1312；本函数没有保证字符串尾部NUL。
// 最后关闭文件返回1；fread/seek结果未检查，不能把返回1解释为完整有效EMP。
//
// 列表节点与复制关系
// ----------------------------------------------------------------------------
// 603C5E -> 6BA070分配136字节节点；前128字节从调用参数复制，后8字节为链指针。
// 节点+128=next，+132=prev；列表对象+0=head、+4=tail、+8=count。
// 插入时新prev=旧tail，旧tail.next=新节点；更新tail并增加count。
// 数据是按值复制，临时文本缓冲释放后节点仍保有路径；不是借用解析器内存。
// 此函数的反编译器提示局部变量分配失败，把128字节整体误拆成32个形参。
// 结论只依赖已核汇编中的分配长度、复制长度和字段写入，不采信其32参数签名。
// 删除节点及目标列表的具体对象偏移尚未闭合，本批不声明完整列表生命周期。
