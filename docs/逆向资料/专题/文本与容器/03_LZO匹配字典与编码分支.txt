// 调用约定与变量角色
// ----------------------------------------------------------------------------
// 8282C0在输入长度>13时调用；长度通过EAX传入，其余参数按栈传递。
// a1：输入长度；a2：输入首地址；a3：输出首地址；a4：输出长度指针；a5：字典。
// v5：输出位置；v6：当前扫描位置，初始src+4；v39：尚未输出字面量起点。
// v41：src+输入长度；v10：当前字典槽地址；v9：字典中的候选匹配地址。
// v37：当前匹配距离备份；v38：用于长距离编码的归一化距离。
// 正常退出写 *a4=已产出字节数，返回v41-v39，即尚待外层处理的尾部字面量数。
// 所以返回值不是错误码；外层8282C0继续写剩余字节并追加11 00 00终止标记。
//
// 字典布局
// ----------------------------------------------------------------------------
// 主哈希使用当前位置四字节，按反编译无符号32位运算：
// h = (33 * (p[0] ^ (32 * (p[1] ^ (32 * (p[2] ^ (p[3] << 6)))))) >> 5;
// primary = h & 0x3FFF；槽地址 = workspace + primary*4。
// 由索引可证明工作区需要16384个32位指针槽，即65536字节寻址范围。
// 包装827860提供0xABB338；未仅凭IDA把unk的1字节类型当作真实工作区大小。
// 若首候选距离>0x800且第4字节不同，会尝试 secondary=(h&0x7FF)^0x201F。
// primary或secondary是本次最终槽；匹配成功或失败都会把当前扫描指针存回该槽。
// 候选必须不小于src、不是当前位置，且无符号距离<=0xBFFF。
// 不通过上述条件则更新槽并前进1字节；通过还需前3字节相同。
// 本函数不清空整张字典；跨调用遗留指针靠范围/距离过滤而非每次memset隔离。
// 并发互斥见01专题；这也说明独立实现不应把此工作区当成只读常量。
//
// 字面量与匹配输出
// ----------------------------------------------------------------------------
// 命中匹配前，先输出v39..v6间的未压缩字面量。
// 长度1..3并入前一匹配编码倒数第二字节的低2位。
// 长度4..18写长度-3作为标记；更长写0和按255扩展的长度，再写字面量。
// 匹配先判断前三字节；后续第4..9字节展开比较，再循环扩展到输入末尾。
// 长匹配和短匹配都按距离决定编码族。外层在长度>13时进入本函数的首轮，
// 后继迭代要求 v6 < 输入末尾-13；这是继续扫描的条件，不是固定保留13字节。
// 已命中的匹配可扩展至输入末尾，返回的尾部字面量数 v41-v39 因而可能为0。
//
// 距离族：仅为本函数的编码分支说明
// ----------------------------------------------------------------------------
// 短匹配且distance<=0x800：用distance-1；长度与低3位距离装入首字节，
//                              后一字节写(distance-1)>>3。
// distance<=0x4000的较长匹配：归一化distance-1，首字节含0x20。
//                              长度<=33时直接存length-2，超过则扩展length-33。
// distance>0x4000：归一化distance-0x4000，首字节含0x10及距离高位。
//                              长度<=9时直接存length-2，超过则扩展length-9。
// 后两族距离剩余编码：一字节写4*归一化距离，后一字节写归一化距离>>6。
// 输入候选过滤允许的最大距离为0xBFFF；不能从容器长度推导字典窗口无限大。
// 此处未给读者一个“照抄即可兼容”的完整编码器，位宽和溢出需按汇编确认。
//
// 工程价值与验证缺口
// ----------------------------------------------------------------------------
// 现在可以解释共享64KiB工作区、外层尾部处理，以及为何压缩返回值不是状态。
