// 下行共同前缀
// 64F710比较WORD[packet+2]与WORD[G+83844]；失败弹Error GmsvID后不进入业务分支。
// 处理器本身未校验网络包长；以下为相应合法分支读取下界，不是恢复的完整帧长度。

// 401C -> 65E590：下界9字节
//   +4 signed WORD position；+6 signed BYTE type；+7/+8 signed BYTE两参数。
//   type26：以ECX=G调用7CEF30(position,param1,param2)。
//   type12：以ECX=M调用7E2380(position,type,param1,param2)。
//   其他type：同样调用7E2380；汇编有单独分支，行为与type12调用点相同。
// 65E632与65E662两调用点对+6/+7/+8全部movsx，Hex-Rays默认分支的无符号显示不可靠。
// 401C不是全部单格同步；26会展开为多格，中心是否最终写入也服从过滤条件。

// 26范围投放 -> 7CEF30
// 7E1600以signed除法拆中心：x=position%width，y=position/width。
// r=DWORD[A870E8]；x-r/x+r、y-r/y+r组成含端点矩形。
// 下界不合法则分别置0，上界不合法则分别置width-1/height-1。
// 这是代码原有的边界替换，不能泛化成任意无效中心/负半径下的数学clamp保证。
// 按y外层、x内层逐格换算position=x+width*y，再依次要求：
//   地形M+48首signed BYTE!=-1；动态记录为空；静态类型不是28/61/58；
//   7BFE20确认没有满足其状态条件的角色或附属位置占用。
// 通过才7E2380写26/两参数，接着7E2D40登记26索引。
// 不是四方向十字扩散，也不是7CC490沿轴递归连锁的同一算法。

// 7BFE20占用门控：本组按字段说明，不猜状态中文名。
// 遍历i<G+3616；槽有效字节G+3632+i非0，且角色P[i]+1497==-1才检查。
// 若P+1464==position则占用；或P+144>0、Q=DWORD[P+576]、DWORD[Q+68]==position，
// 且P+1493==-1时占用；P+1493!=-1且P+1468==position时也占用。
// 这些条件依赖参与者实例，不是仅查询地图动态层。

// 402F -> 660860：下界16字节
//   packet+4/+6/+8/+10/+12/+14是六个signed WORD格号；-1逐项跳过。
//   先插本地6001记录：子编号309，+6=0，其余按693420构造初始化。
//   再插6064记录：+2=BYTE[G+3624]，+3=low8(A87080)，+4=-1。
//   每个非-1格直接调用7E2380(position,12,-1,low8(A870CC))。
// 六格设置在处理器内立即发生，6064角色状态更新则等待队列消费。
// 没有地形/动态为空/格号边界检查；与26范围投放的过滤规则不同。
// 重复格号也不会跳过；不得用“最多六个不同合法空格”描述此代码。

// 6064 -> 67FDC0 -> 694640
// 本地+2按signed BYTE索引G+0xE00角色指针，+3/+4按signed BYTE传参。
// 消费者写P+1491、P+1492；没有地图格写入。
// A87080的正式状态含义与动态配置值域未恢复，不能据名称认定住院或坐牢。

// 类型字典交叉
// 诊断4057字面表中12=地雷、26=火焰陷阱、27=超级地雷、28=小强、29=栅栏。
// 这里仅引用已核验的诊断字面映射，不据此推定所有类型字段为统一NPC枚举。
// 32在清除谓词中有特殊保留行为，诊断4057字面表的默认分支不能替它命名。
// A87080/A870CC/A870E8的IDB静态初值均-1；实际游戏配置来源与覆盖需另取证。
