// 地图对象M=G+0x65C；以下偏移均为字节。
// 动态格D=DWORD[M+60]+4*position。
//   +0 signed BYTE类型；-1表示空。
//   +1 signed BYTE参数：类型12/27的范围效果会按来源槽读取。
//   +2 signed BYTE参数：26的生命周期递减此字节；其他类型不可直接套用倒计时含义。
//   +3 BYTE标记：63E8C0写入；本组设置路径写1，完整显示消费者未闭环。
// 63E750构造初值{-1,-1,-1,1}；63EB50判+0!=-1，63EB90有符号返回+0。

// 7E2380通用设置
//   先写D+0/+1/+2，写入参数都只保留低8位。
//   类型12或27：7E2420登记到M+180表。
//   类型28：7E3080登记到M+204表。
//   所有分支最后63E8C0(position,1)写D+3。
// 本函数没有精灵分配、图像查找或socket发送；登记索引不是构造可见对象。
// 不检查position范围，不清理旧类型索引，不查重；重放同一设置可能产生重复表项。
// 表满仍先写了D，登记函数也无扩容路径；不能凭返回值认定状态和索引事务成功。

// 三张WORD稀疏索引表
//   类型12/27：M+180指针，+184 signed WORD最高占用下标，+186 signed WORD容量。
//   类型26：   M+192指针，+196最高占用下标，+198容量。
//   类型28：   M+204指针，+208最高占用下标，+210容量，+212 WORD已登记数量。
// 三表都以-1标空；最高下标不是数量，也不是可扩容数组的capacity。
// 7E2420/7E2D40/7E3080从0查第一个空槽，写low16(position)，必要时提高最高下标。
// 只有28表同时增加+212；12/27和26表没有同样的数量字段写入。
// 7E2380本身不登记26；7CEF30范围投放26时另调用7E2D40。

// 初始化与释放
// 7DE310清三表指针，最高下标均设-1；本函数不设置三表容量。
// 7DF010在7DF566..7DF621：12/27与26容量取signed WORD[M+40]，
// 分别分配2*capacity并把两个表的全部槽设-1。
// 在7E0C17..7E0CA2：28容量取WORD[M+256]，+212清0；容量>0时分配并填-1。
// M+256的上游格式含义、负容量和分配失败处理，本组不新增结论。
// 7DE5C0分别delete[]三表和动态记录数组并置空，未同时重置所有最高下标/容量。
// 原证保留完整加载/析构函数，但本组只审阅以上相关区间。

// 查找与删除
// 7E24B0/7E2DD0/7E3120扫描整个容量，返回匹配position的第一个槽，否则-1。
// 7E2520/7E2E40/7E3190允许传明确下标；传-1时才执行上述查找。
// 找到后写该槽-1；若删的是最高下标，逆向找此前最后一个非空槽，全部空则最高=-1。
// 28删除额外递减+212；提供的非-1下标没有本组可见的边界校验。
// 重复position只会删除第一个匹配槽，不能把查找后删除解释成批量去重。

// 7E28B0按类型清理
//   12/27删M+180表；26删M+192表；28删M+204表。
//   29经7E3270恢复M+272起对应运行记录，来自M+268的8字节源记录第二DWORD。
//   32由7ECAF0判定保留动态格；其他类型最后把D+0/+1/+2设-1。
// 本函数未写D+3，也不直接销毁整个地图对象。
// 7E2320则仅写type、两参数-1和标记1，不维护以上索引；两种设置入口不可互换。

// 26生命周期的局部观察
// 7E2F00遍历M+192表至最高下标，只处理非-1项。
// 根据当前槽、动态来源槽及参与者有效字节/另一个门控选择是否递减signed D+2。
// D+2>0才减1，随后若D+2==0调用7E28B0清除；负数不会因该分支归零。
// 调用节拍、门控的正式含义和完整上游调用者仍未知，不能承诺“每秒”或“每回合”递减。
