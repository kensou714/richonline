// 同一状态串的复合索引
// ----------------------------------------------------------------------------
// [事实] 6A14B0 的 this+604 非空、strlen 的无符号长度大于索引，且被选
//         signed BYTE 为2时返回真。旧 TeachMode对象与消费者已完整审阅，复用。
// [事实] 6A1660 同样读取 this+604；参数按有符号除法拆成 a2/10 与 a2%10，
//         外部64F200返回地址的首DWORD为2时，索引=175+4*(a2/10)+a2%10；
//         否则基数为5。6A1688先解引用返回地址，没有先检查该返回地址非空。
//         本体检查状态串指针、无符号长度及字节2；条件对象来源/业务语义未知。
// [事实] 6A18B0 计算 base=110+7*a2，初值返回4。只在strlen>base时循环
//         i=0..6，遇字节1停止，未遇时每轮更新返回值i+1。
//         本体未先检查指针非空，也没有逐轮检查 base+i<strlen。
// [推断] 这不是一条只含 TeachMode 进度的专用串；至少存在上述三类消费索引。
//         数字1/2的完整枚举、索引区域是否相互独立、参数合法范围均待核。
// [未知] strlen边界不足以证明全部七次访问在合法分配内；是否发生实际越界
//         取决于底层容量、内容和外层参数，不在没有实机证据时宣布已重现 BUG。
//
