// [事实] 628270 首次分配 0xABC 字节，经 610B7A→69DF50 构造，保存 A76728。
//         69DFFC 明确写 H+604=0；其它成员初始化不在本专题整体提升。
// [事实] 6A11E0 构造三 WORD 均为 FFFF 的6字节参数，压入分派号47，调用
//         60F1E4→82B090。6A122E 将返回 EAX 直接覆盖 H+604。
//         本体没有分配、复制状态串、释放旧缓存或判断返回空指针。
// [事实] 82B090 的 case47 原证为 82B779..82B793，逐次恢复 ECX=EAX：
//         8976E0 返回 M=&ACBB30；82AB80 返回 U=DWORD[M+32]；
//         82A900 返回 A=DWORD[U+80]；82BC80 在 ECX=A+104 上调用62B8E0。
//         62B8E0 保持 ECX，调用62BB80；此处的 +104 是字符串对象地址。
// [事实] 62BB80：无符号 DWORD[S+24]<16 时返回 S+4，否则返回 DWORD[S+4]。
//         因而 H+604 缓存的是内嵌缓冲或堆缓冲地址，不是字符串对象本身。
//         82BC80 的伪码省略 add ecx,68h，不能据伪码认定它为无 this 函数。
// [推断] 该内嵌/堆切换形态符合小字符串优化访问器；本专题只按汇编布局
//         认定，不凭库自动命名恢复精确 std::string ABI 或源码声明。

// 刷新与退出边界
