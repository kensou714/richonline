//
// 接口 / 返回宽度与参数
// ----------------------------------------------------------------------------
// 7D98E0：arg0为signed规则行，arg1为prop列；合法行返回原DWORD，非法行
// 返回EAX=-1。仅验证行，retn 8；列的无界风险见布局文档。
// 7D9940：本体只mov al,1；对象及两个参数不参与业务读写，retn 8。
// 声明包含运行时栈检查，不能据mov al,1声称完整EAX恒等于1。
// 7D99D0：AL读取gate_enable[arg0]原字节，retn 4，无范围/布尔归一化。
// 6B76D0：EAX读取DWORD[this+0x186A8]，无验证或转换；原ICCode语义仍未知。
// 原证：grant_core_raw.json/4、7、8、9。
//
// 6A3640 / 资格包装中的恒真支路
// ----------------------------------------------------------------------------
// signed参数<5直接AL=1；否则取6280E0单例，调用7D9940(arg,0)，以AL判定。
// 7D9940当前恒AL=1，所以在正常调用契约内，该包装所有参数均返回AL=1。
// 参数<5包括负数；这里不是0..4有效索引检查，也没有读取gate_enable表。
// 可能触发懒建单例，不能把它描述成完全无副作用的数学常量函数。
// 若分配失败导致单例为空，仍需遵守实际调用/EH行为，本文不模拟运行。
//
// 6A35B0 / 同桩影响的动作入口
// ----------------------------------------------------------------------------
// 参数<5，或单例7D9940(arg,0)低字节非零，均调用828F60(15,arg)。
// 当前恒真桩使Grant拒绝提示分支在正常契约下不可达。
// 潜在拒绝支路涉及6279C0、6E3B40(64,1350,0)，随后629D90取文本890，
// 以及6E4640显示调用。仅保留地址与参数，不用自动MFC名推导原UI类。
// 828F60全文业务、提示资源文本与显示依赖未完整审阅，不声称已联网。
// 函数返回值来自依赖，不将整个6A35B0提升为bool接口。
//
// 6A1730 / 实际gate字节参与的局部资格链
// ----------------------------------------------------------------------------
// 64F200(this)返回地址并解引用得到标识；627F40标识、7B2850获取列表计数。
// 先调用6A1C10(this,arg)，低字节非零立即true；否则取Grant单例并调用
// 7D99D0(arg)，原字节非零也立即true。此支路确实消费gate_enable表。
// 若仍未通过，遍历627F40(标识)->7B29B0(i)，解引用元素指针取当前ID。
// 遍历前previous=-1；未命中当前ID时记录previous=current继续。
// 命中后6A1660(this,current)非零返回true；否则previous<0返回true；
// previous>0且6A1660(this,previous)非零返回true；其他情况false。
// previous=0不会进入第二个检查；没有命中或空列表返回false。
// 这不是简单的“上一项必须通过”，更不是gate表以外的完整关卡规则。
// 多个外部依赖未逐体恢复，因此清单将该函数标为字段/路径局部审阅。
// 已见链无消息构造现场；本地资格提前通过不证明服务端许可。
//
// 7113A0 / 动作表调用前的Grant限制
// ----------------------------------------------------------------------------
// 复用窗711738..711803；对应原函数仍只沿用局部语义审阅状态。
// prop来自先前局部var_54；当前规则由6037AE->63E210后再取规则依赖，
// 先压prop，再压rule，以6280E0单例调用7D98E0(rule,prop)，保存DWORD限额。
// this+0x58非零且限额!=-1时，读取次数依赖返回EAX并加1，以signed比较
// “EAX+1 > DWORD限额”；次数叶返回不能在未闭合前假定非负。
// 超过时走本地提示，清除动作许可标志；未超过或限额=-1则可继续。
// 许可标志非零才调用dword_AB5368[prop]动作表，传入对象及既有动作参数。
// 该窗口的-1确实跳过限制；不能将此哨兵用途推广为所有PROP消费者。
// 次数含义、规则依赖与动作表全文不在此窗闭合，不称已消耗或已发送。
// 旧道具原证SHA与当前不同，但所选来源IDB原字节重核当前磁盘相等；
// 旧自动函数名只导航，实际调用目标另由当前磁盘E9桥链复核。
//
// 7CDAB0 / 固定prop=1076的本地限制窗
// ----------------------------------------------------------------------------
// 复用窗7CDAD0..7CDB3B；原消息专题标记“仅导出”，本批不提升全文语义。
// this+0x65C取得规则依赖，调用Grant7D98E0(rule,0x434)，0x434=1076。
// EAX=-1直接跳过限制。否则零扩展WORD[this+10000*arg0+0x1708]到ESI，
// ESI加1，再次读取同规则同prop限额；signed ESI<=限额时继续，超过则AL=0。
// +0x1708=5896；计数宽度WORD与限额DWORD不同，不混成同宽存储。
// 当前局部说明Grant能在消息构造前拒绝；后续道具资格、次数递增、
// 本地消息入队须遵守本地消息构造专题已有边界，本文未重核后续全链。
// 两次限额读取现场均已核桥，但不据此保证并发读取一致。
// 本地队列构造或入队不等同网络发送成功，更不等同服务端权威校验。
