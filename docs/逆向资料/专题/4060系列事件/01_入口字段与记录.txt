// 共用记录约定
// --------------------------------------------------------------------------
// T4(text)：6003，24B；WORD+2=4、BYTE+4=1、BYTE+6=1，DWORD+8=1800、
// DWORD+12=1350，DWORD+16=text、DWORD+20=128。
// 构造器清BYTE+5；BYTE+7未赋值。本记录形状不能当作网络包保留字段约定。
// T30(data)：6003，24B；WORD+2=30，其余同上；DWORD+16=data、DWORD+20=12。
// data 为静态三 DWORD {0, signed WORD[packet+4], 文本指针}，不是网络包。
// C(slot,amount,mode)：6060，12B；BYTE+2=slot，DWORD+8=amount；构造器清
// BYTE+3/+4/+5/+6；各入口再按下文设置。+7 未赋值，不能视为协议保留字段。
// S(slot,amount)：6002，12B；WORD+2=69B080(amount,DWORD[G+83804])，
// BYTE+4=slot、BYTE+5=0、BYTE+6=1，DWORD+8=1350；BYTE+7未赋值。
// 声音编号算法见下一篇。
// E：6080，4B；BYTE+2=2、BYTE+3由构造器置-1。它续阶段2，并非网络确认。
// packet+4/+6 均 movsx signed WORD；所列最小长度只是最远静态读取端点，
// 不意味着 handler 或更早接收层已经实施长度校验。

// a=packet+4，资源183格式化到 A78C18；T4 -> C(current,a,+3=1,+5=1)
// -> S(current,a) -> E。current=BYTE[G+3624]。

// 4061 @ 663A50 / 4062 @ 663C50 / 4066 @ 6644C0 / 至少8B
// --------------------------------------------------------------------------
// a=packet+6，标签值=packet+4；资源分别184/185/189，sprintf 参数只有a。
// 全局 data 分别 A78CB4/A78D64/A79004，文本 A78CC8/A78D78/A79018。
// 单次 T30 -> C(current,a,+3=1,+5=1) -> S(current,a) -> E。
// 4066 没有角色循环，不能与4067混淆。

// 4063 @ 663E50 / 4064 @ 664040 / 至少6B
// --------------------------------------------------------------------------
// a=packet+4；固定格式 "%s%d%s"，前缀资源186/187，后缀资源10。
// 文本分别 A78E18/A78EB8。T4 -> C -> S -> E；4063 C的+3=1,+5=1，
// 4064 C的+3=1,+6=1，故前者加现金、后者加存款（6060消费者另证）。

// 4065 @ 664230 / 至少8B
// --------------------------------------------------------------------------
// 先7C0230(G,临时8字节标志)；i从0到G+3616，须BYTE[G+3632+i]!=0且
// flag[i]!=0。每个命中角色以P+112名字和packet+6格式化资源188。
// 三DWORD data A78F54={0,packet+4,A78F68}。逐命中插 T30 ->
// C(i,packet+6,+3=1,+5=1) -> S(i,packet+6)，循环后只插一次E。
// 每轮复用同一个全局文本和data，记录携带指针；多个命中会覆盖先前内容，
// 是否复制文本由6003消费者决定，本群不能假定独立快照。

// 4067 @ 6646C0 / 至少6B
// --------------------------------------------------------------------------
// 7C03C0(G,临时8字节标志)，同样检查有效槽和flag。每命中i，将packet+4
// 以资源190写到A790B8+128*i；T4 -> C(i,a,+3=1,+5=1) -> S(i,a)，
// 最后E。与4065不同，这里的文本按i分槽；未证明i上界在本群被钳到8。

// 4068 @ 664930 / 至少6B
// --------------------------------------------------------------------------
// T30 的data A79584={0,packet+4,资源191指针}，然后扫描有效槽，跳过
// DWORD[G+3624]。读取每个P+1508存款，以cdq/idiv10有符号截断求v。
// 每槽 C(i,v,+4=1,+6=1)，并以32位add累计sum；没有溢出保护。
// 随后 C(current,sum,+3=1,+6=1) -> S(current,sum) -> E。
// 先扣其它有效角色的存款，再给当前角色加存款；数值取客户端当前
// 状态，packet+4只进入提示data，不能当作实际转移金额。

// 4069 @ 664BC0 / 406A @ 664DF0 / 至少6B
// --------------------------------------------------------------------------
// T30 data A795BC/A795F4={0,packet+4,资源192/193指针}。
// 遍历有效槽，分别检查signed BYTE[P+1494]!=-1 / signed BYTE[P+1495]!=-1。
// 命中i时DWORD[A79594+4*i]或[A795CC+4*i]=i，插6000（20B）：
// WORD+2=10或12，BYTE+4=1，DWORD+12=该数组项指针，DWORD+16=4。

// （相对+12），664CF4写EBP-38h（相对+16）；406A的664F21/664F24同形。
