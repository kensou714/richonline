// 队列游标与插入
// --------------------------------------------------------------------------
// 63E5B0 的ECX改为G+0x640，再调用63F940读取Q+12（head）。IDA误标成
// CDialog::OnInitDialog，实际是获取当前插入游标，不能解释为弹出对话框。
// 64FA50(Src,Size,cursor)以Size复制栈记录，再按288字节传给6980F0，
// 返回新记录后一槽。每个handler顺序使用返回游标，无失败回滚。
// 满队列时返回-1；后继仍把此值作游标传入，handler不检查。
// 共用门控与环形队列完整资料见 ../基础对象与分派/。

// 现金与存款（6060消费者）
// --------------------------------------------------------------------------
// 67FA90以G为this；各资金调用用signed BYTE[record+2]选择G+3584中的P
// 作为ECX。+3非0表示加：优先+5加现金，
// 否则+6加存款；+3为0而+4非0表示减：优先+5先扣现金再扣存款，否则
// +6仅减存款并将负余额归零。本群生成的标量均为DWORD+8。
// 7FA050：P+1504 += amount；7FA0A0：P+1508 += amount。
// 7F9F10：P+1508 -= amount，负则归零；以上32位算术无上限检查。
// 7F83F0：P+1504 -= amount；负差转入P+1508，现金清零，存款<=0归零。
// 这些函数还发动画通知，动画函数具体内容未在本群深挖。
// 6060减现金路径在模式条件和现金<=0时可设G等待500ms，参见既有
// ../回合继续与落点调度/阶段外_范围效果.txt 与证据/funds.json。
// 模式谓词63EDF0以G+0x65C为this；现金判断取被扣款P+1504，不是总财富。
// 包体金额经signed WORD扩展，本群没有正数或数额上限校验。

// 提示声音分级
// --------------------------------------------------------------------------
// 69B080(a,b)：a < 1000*b返回18；a >= 5000*b返回16；其余返回17。
// 比较和imul都是signed32位，乘法溢出不保护。406x调用者b取G+83804。
// 返回值截为WORD写6002+2；不能把返回编号直接解释成声音文件名。

// 最多/最少筛选（局部闭环）
// --------------------------------------------------------------------------
// 7C0230、7C03C0在G+0x65C上依次调用7E69B0、7E6B40、7E6C30，
// 将三项返回值相加，写入临时DWORD[8]，对所有有效槽求相等极值标志。
// 7C0230最大值初始0，命中多个相等值则全部flag=1，返回命中数量。
// 7C03C0最小值初始取子对象+42/+44的两个signed WORD之和，再逐槽缩小；
// 因初值可低于所有有效槽之和，不可断言始终存在“最少角色”。
// 三个7E6xxx函数枚举该子对象条目、比较所有者槽并增加计数；具体条目
// 类型与谓词尚只导出，不能未经核对命名成资产价值/土地数。
// RTC描述原字节确证7C0230/7C03C0的iNum容量32B、栈偏移-40；4065/4067
// 的bPlyMax/bPlyMin容量8B、栈偏移-28。不是伪码显示的9 DWORD数组。
// 人数循环
// 取G+3616，均没有本地钳到8。可达前提另见 ../参与者布局与人数边界/。
// 栈描述证据见证据/registration_and_rtc.json；不据此断言上游可传任意人数。
