// ============================================================================
// 6D8130 / 十二文件类别共用一个slot池
// ============================================================================
// 15处直接取槽均在同一旧loader内，将同一个Destination作为C，令ECX=C+40。
// 每次把返回slot写12字节记录R+4，再以slot*4写DWORD[C+580CC+slot*4]=R。
// 下表Q是对应C成员内保存的数组基址，g/i/d/f仅为阅读变量，不冒充原源码名。
// 字节原证、每站精确指令Pointer、磁盘文件名观察见证据/shared_sites.json。
//
// 文件         取槽站点   R+4写入   反向登记   Q成员     R的寻址步长
// ----------------------------------------------------------------------------
// road.dat     6D84DB     6D84F8    6D8539     +3ABB0    Q+180*g+12*i
// road派生     6D8595     6D85B2    6D8615     +3ABB0    同组i+2
// thing.dat    6D8851     6D8865    6D888E     +3ABB8    Q+12*i
// event.dat    6D8AF4     6D8B0E    6D8B49     +3ABC0    Q+120*g+12*i
// build.dat    6D8DF6     6D8E1D    6D8E6E     +3ABC8    Q+1200*g+120*l+12*f
// vehicle.dat  6D9120     6D9147    6D9198     +3ABD0    Q+480*g+120*d+12*f
// vehicle派生  6D9200     6D9227    6D92A2     +3ABD0    同组d=3
// role.dat     6D9557     6D9581    6D95D8     +3ABD8    Q+4800*g+1200*d+12*f
// role派生     6D9646     6D9670    6D96F4     +3ABD8    同组d=3
// npc.dat      6D996D     6D998A    6D99CB     +3ABE0    Q+1200*g+12*i
// fx.dat       6D9C07     6D9C1B    6D9C44     +3ABE8    Q+12*i
// mood.dat     6D9EB3     6D9ED0    6D9F11     +3ABF0    Q+1200*g+12*i
// card.dat     6DA14D     6DA161    6DA18A     +3ABF8    Q+12*i
// other.dat    6DA3F9     6DA416    6DA457     +3AC00    Q+1200*g+12*i
// extend.dat   6DA693     6DA6A7    6DA6D0     +3AC08    Q+12*i
//
// 为什么15站只有12类
// ----------------------------------------------------------------------------
// road正常项i<15；i=11或12时额外分配slot给i+2项，复制原npid并写R+8=i-11。
// vehicle正常遍历d<4、f<10；d=1时额外复制到d=3，另取slot并写派生R+8=0。
// role正常遍历d<4、f<100；d=1时同样复制到d=3，另取slot并写派生R+8=0。
// 所以槽消耗包含派生站，不能用npid去重数或不同记录最终数量代替取槽次数。
// 若后续正常项覆盖已派生目标，不能假设自动归还先前slot；这些写入之间未见归还call。
// 本段仅说明静态顺序，不声称当前样本必然触发重复覆盖或已发生泄漏。
//
// 总容量与计数关系
// ----------------------------------------------------------------------------
// 初始化只给共享池30000个slot，不是每个类别独立各有30000个。
// 在没有中间归还且所有取槽正常的前提下，N=30000减去实际执行的15站累计取槽次数。
// 动态消费者若使用同一C也消耗此余额；不能只给OTHER保留一个独立配额。
// C+580CC的初始化清零长度1D4C0h=120000字节，正好对应30000个DWORD。
// 这个范围与池容量相符，但所有取槽/归还/反向表写均不因此自动获得slot有效域门。
// 当前未模拟十二文件全部解析及运行分支，不给出未经证明的实际剩余slot数量。
// 旧loader完整2486指令仅机械复核，本批业务覆盖是15站、外层文件分类和三派生条件。
