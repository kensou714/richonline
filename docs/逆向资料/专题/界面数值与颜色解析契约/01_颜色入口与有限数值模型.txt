// 颜色入口与有限数值模型
// ============================================================================
// 实现8E0450；常见调用先经过60C9A3的E9跳板。
// 入口为窄字符串指针；按lstrlenA遇NUL终止，不是宽字符解析器。
//
// 两种路径
//   NULL或空串返回EAX=0。
//   仅首字节'0'且次字节小写'x'进入十六进制路径。
//   其它输入调用atof，再调用__ftol，保留EAX低32位。
//   '0X'、前导空白、符号后再跟0x都不进入此十六进制分支。
//   这些非0x写法实际怎样被CRT接受，不能用Python int或float替代证明。
//
// 十六进制循环：不是通用strtoul
//   i=lstrlenA(text)-1；exponent=9-i；从尾向前遍历，直到i<=1。
//   每个位置仅接受0..9、A..F、a..f。
//   接受的字符：先pow(16.0,exponent)，再__ftol取低32位，
//       再与该位数值做32位imul，累加到32位结果。
//   不接受的字符：不加任何值，但照常i--、exponent++。
//   关键汇编：8E0495载入9，8E049B减i；8E04B8/4DE/507调用pow，
//       8E04BD/4E3/50C调用ftol；8E0517 imul，8E051A add。
//   先截断幂再乘位数，不能交换为先乘浮点后截断。
//
// 有限常规输入中的等价位置解释
//   前8个0x之后的位置依次对应位28、24、20、16、12、8、4、0。
//   少于8个位置时靠左；无效字符相当于该位置填0，不会缩短字符串。
//   第9个及以后位置的指数为负，先转整数后权重为0。
//   本专题模型限定最多32个后续ASCII字节，避免宣称极长字符串、
//       下溢环境、异常浮点状态或不可读内存都已有兼容保证。
//
// 例子：输入             返回低32位
//       0x               00000000
//       0x1              10000000
//       0x12             12000000
//       0x1234567        12345670
//       0x12345678       12345678
//       0x123456789      12345678
//       0x000000001      00000000
//       0xffffffff       FFFFFFFF
//       0xAbCdEf01       ABCDEF01
//       0x1g3            10300000
//       0x 1             01000000
//       0x-1             01000000
//   以上例子来自静态算法及参考模型，不是游戏窗口颜色截图。
//
// 十进制的有限模型
//   参考模型仅接受普通有符号十进制、至多6位小数、有符号32位范围内的值。
//   1.9->00000001，-1.9->FFFFFFFF，+12.25->0000000C。
//   数字先截断小数再取低32位；FFFFFFFF是位型，不是承诺所有消费者都按无符号。
//   指数、尾随文本、locale、NaN/Inf、64位溢出和异常控制状态均未模拟。
//   含小数的示例用于说明向零截断；完整atof舍入与语法仍依赖未展开CRT。
//
// 模型校验
//   颜色模型.py 用逆向循环与独立位置公式互证。
//   枚举1..32长度、每一位置与ASCII 1..127，共67056个位置场景。
//   另测短串、长串、非法字符、大小写、NUL终止和6个十进制示例。
//   该检查验证模型自洽和文档公式；它不能替代原EXE执行或数学CRT全量测试。
