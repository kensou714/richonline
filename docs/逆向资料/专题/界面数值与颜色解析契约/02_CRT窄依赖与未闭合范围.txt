// CRT窄依赖与未闭合范围
// ============================================================================
// 十六进制入口虽然调用pow/ftol，不能因此把整套CRT当作已逆向完成。
// 本专题只恢复参数交接、选路、向零转换和颜色实际用到的有限域。
//
// 8E0450 -> 60E8D9 -> 92BE80：__CIpow
//   入口先fld double[A305A0]，原始8字节按小端double解析为16.0；
//       再fild整数指数，调用时ST0=指数、ST1=16.0。
//   Hex-Rays的x/y和ST参数注释可能颠倒，不直接照搬参数名。
//   92BE80读取AD0E80运行时开关。非零且MXCSR&0x1F80==0x1F80、
//       x87控制字&0x7F==0x7F时，跳60F464->93EBC0。
//   其它情况走默认入口92BEBB：fxch后把底数和指数落栈，再call92BEDD。
//   AD0E80的运行时写入来源未展开；磁盘初值不代表实际启动后选路。
//
// 93EBC0：Pentium4桥接入口
//   保存EBP，分配并16字节对齐栈，fxch后将两个x87参数存成double，
//       调用93EBD9；随后leave/retn。
//   本函数是参数桥，不是数学运算的全部实现。
//
// 92BEDD：默认pow分支，局部审阅
//   保存x87控制字，比较0x027F；必要时调用__load_CW。
//   有普通正底数的fyl2x及__twoToTOS路径，也分派特殊指数、零底数、
//       负底数整指数检查和错误处理。
//   声明块还包含60E9E2的跳转块及93FFCE..93FFDB的控制字恢复出口。
//   93FFCE比较保存控制字，必要时fldcw恢复；随后pop/retn。
//   这两个块不是异常处理证据，不能仅因非连续就称为异常尾块。
//   __load_CW、__fload_withFB、__twoToTOS、__powhlp及错误支持未闭合。
//   本函数Hex-Rays反编译失败；结论以保存汇编为依据，不补造伪码。
//
// 93EBD9：Pentium4数学核心，局部审阅
//   入口按double拆指数/尾数，用SSE与查表进行计算，并另有特殊值路径。
//   本专题仅确认桥接目标、输入装载、普通路径的结构和错误支持出口。
//   未逐项恢复查表常量、多项式误差界、NaN/Inf、反规格化与错误处理。
//   即使函数完整字节均一致，也不能据此宣称所有pow输入已数学验证。
//
// 92BE08：__ftol
//   fstcw保存控制字；将高字节OR 0x0C后fldcw，设向零舍入。
//   fistp将ST0写入64位整数，再恢复原控制字；低DWORD返回EAX，高DWORD返回EDX。
//   颜色入口的imul/add或直接返回只使用EAX，因此最终是32位位型。
//   有限且落在有符号64位表示范围内的值可按向零截断理解。
//   NaN/Inf、超界及未屏蔽浮点异常依赖CPU/运行时状态，本专题不套用Python异常语义。
//
// 924720：atof窄包装，局部审阅
//   跳过isspace判定的前导字符，计算strlen，调用938370的__fltin2，
//       最后fld返回结构+16的double。
//   8E0450先判0x再调用该包装；不能把atof会跳空白理解成十六进制入口也跳空白。
//   未展开__fltin2、locale和整个字符分类表，不承诺任意CRT十进制语法。
//   此范围与CRT数字转换契约专题的atoi/atol不同，只记录颜色路径的窄依赖。
//
// 8E1C40：四态颜色setter
//   栈参数style、state、value；写DWORD[style+40*state+32]=value。
//   汇编8E1C4C lea计算5*state，8E1C4F以8倍索引写入，retn 0x0C。
//   不依赖ECX作为对象参数，也没有state的负数/上界检查。
//   返回EAX=5*state是指令结果，不赋予它稳定业务返回值含义。
//   现有颜色call传state=0..3；不能推导该setter对任意外部索引安全。
//   只恢复颜色DWORD位置；风格块的其它40字节状态字段与完整布局未展开。
