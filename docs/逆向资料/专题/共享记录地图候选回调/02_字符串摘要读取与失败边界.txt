// ============================================================================
// 第二十八批 / 路径摘要读取、16字节比较和失败边界
// ============================================================================
// 7E71E0是旧完整主体，本批只复用原证并补当前字节，不计新增函数。
// 它按 __thiscall(this,a2) 调用7DED90生成 Map\\%s 路径，fopen(path,"rb")，
// fread(this+8,0x10,1,Stream)，随后无条件fclose并返回this+8。
// fopen返回NULL、fread短读/失败的返回值在本体均未检查；this+8在调用前也未清零。
// 因而失败时this+8可能保留旧内容或部分覆盖，仍可能被后续16字节比较消费；这是静态风险边界，不是实机失败已证。
// RTC补证7E727A头count=1，7E7282描述符给EBP偏移-76、容量64、名称szFullMapName。
// FileName实际64字节；68只是到相邻保存槽的间隔。该RTC为后置检查，不能把sprintf描述成限长复制。
// 7DED90本身调用sprintf("Map\\%s")，未见长度门；保存ECX但不消费对象，两个DWORD参数、RET8。
// 路径字符串与地图文件格式不能据此扩展为协议鉴权。
//
// 6A54F0摘要比较边界
// ----------------------------------------------------------------------------
// 候选回调和模式门通过，或候选全部失败但R+38h的DWORD等于3时，6A5898取得比较源Q+8。
// 循环i=0..15，逐字节比较[R+28h+i]与[Q+8+i]；R+8为文件名文本，两字段不可混合。
// 任一字节不同立即将本地bool清0并结束；16次全相等才保留成功。
// 该循环没有哈希算法调用，也未证明R所属数组的索引/容量有效；Q是本函数栈上构造的地图对象。
// 返回前经61224F调用7DE5C0析构Q，不能把返回0解释成网络错误码。
//
// 未知和工具边界
// ----------------------------------------------------------------------------
// 地图文件实际摘要来源、记录B的生产者、摘要算法、服务端响应字段、NULL/短读处理策略均未闭合。
// 资源编辑器只能把该链标为“候选字符串/16字节窗口校验”，禁止把相等结果当MD5授权。
//
// 模式门与局部摘要初值
// ----------------------------------------------------------------------------
// 调用对象H经64F200取H+64h地址，其DWORD作为模式；它不是局部地图Q的模式字段。
// 6AAA80把文件名压栈后调628C60取全局配置对象，再以该对象为ECX调用7E9610。
// 628C60无参数，先压的文件名供后续7E9610消费；不要把getter误记为一参函数。
// 7E9610逐个比较276字节配置记录首文本，首个strcmp相等返回记录+108h的DWORD，否则FFFFFFFF。
// 6AAB34四槽把H模式0/1/2/3映射6AAADC/6AAAEE/6AAB06/6AAAD0。
// 模式3只接受配置值3；模式0接受3/0；模式1接受3/0/1；模式2接受3/0/1/2。
// 超出0..3的H模式或查询返回-1均落到AL=0；成功仅AL=1，上24位不承诺清零。
// 十路候选先看相应模式(3一条、0/1/2各三条)，每条按“搜索EAX非零且模式AL非零”置本地成功BYTE。
// 本地成功后后续九路均被门跳过；全失败时只有R+38h==3的旧63E1A0谓词可给最后兜底。
// 6A54F0入口REP STOSD以CCCCCCCCh填充局部栈区，覆盖Q+8..17h；随后构造Q。
// 旧7DE310完整直写没有清Q+8..17h；其子构造只见偏移4C/50/138/45C/46C/47C。
// 因此可确认本层没有明确摘要清零写入，不能只从构造函数名称假定全0；子调用的任意副作用仍非本批穷举。
// 若子调用不改该区，读零字节时可能仍为CC初值；7E71E0单独用于其他对象也可能留下此前摘要。
// 这是有前提的残留路径；fopen返回NULL或fread短读后的CRT行为未闭合，本批不保证必然走到比较。
