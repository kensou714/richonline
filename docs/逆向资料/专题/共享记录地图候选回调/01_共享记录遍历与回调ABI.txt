// 6BA170：共享链表遍历器
// ----------------------------------------------------------------------------
// 入口为 __thiscall，ECX=this；栈上两个DWORD依次是回调地址 callback、回调上下文 value。
// [this+0] 是首节点指针，[this+4] 只证实DWORD非零门，其完整业务字段身份不由本体定名。
// callback先判NULL；非NULL后检查上述两字段，任一为0即EAX=0。this自身无NULL门。
// 进入循环后把首节点保存为 p；p为0结束。每次调用 __cdecl callback(p,value)。
// 6BA1B7 的间接CALL前压 value再压p；6BA1BA由遍历器清理8字节；callback非零EAX立即转EAX=1停止。
// 返回0表示空门、链表为空或所有回调返回0；不存在未命中节点指针哨兵返回。
// 回调失败只让遍历继续读取 *(p+0x80)，不重置链表、不跳过后继；+80h是next字段偏移，不是节点步长或大小。
// 回调上下文是调用者压入的DWORD；本体不解释其内容，也不检查节点NULL以外的可读性。
// 入口RET8，RTC桥不属于业务结果；每次间接回调返回后以完整EAX作零比较。
//
// 6AAA40：字符串相等谓词
// ----------------------------------------------------------------------------
// 入口为 __cdecl，栈参数依次node、context；6AAA54先压node，6AAA58再压context。
// strcmp实际收到(context,node)，两指针均未加偏移；把节点首地址当NUL结尾文本读。
// 6AAA61测试完整EAX是否为零；相等时写EAX=1，不等时xor EAX,EAX；RET无栈清理。
// 因而对调用者可表述为 BOOL/32位EAX布尔结果，不能缩写为只保留AL后再推断其他位。
// 参数是NUL结尾char指针；NULL、无终止符和编码均未在本体检查。
// 603FC9桥当前跳到6AAA40；6BA170中没有直接调用该谓词，二者通过上层callback参数组合。
//
// 真实消费窗口
// ----------------------------------------------------------------------------
// 6A54F0将共享记录R(i)=B+124*i的字段R+8作为callback上下文，经ECX对象+514/+520/+524/+528/+52C/+530/+534/+538/+53C/+540逐项调用6BA170。
// 每次先压上下文，再压603FC9；call后test EAX，非零才调用旧6AAA80的模式兼容门，并以AL判断成功。
// 十处call与模式/对象字段一一对应：
// 6A55A3：3/+514；6A55EB：0/+520；6A5633：0/+524；6A567B：0/+528；6A56C3：1/+52C。
