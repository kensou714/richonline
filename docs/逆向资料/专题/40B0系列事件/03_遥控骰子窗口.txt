// UI24：从选择按钮/快捷键到0067请求
// ============================================================================
// 工厂登记6E62D7写经理+0xA8，即72+4*24，值608862 -> 6E7A80。
// 工厂申请0x4C；ctor6FB440写虚表A25580。资源槽24是G_YaoKongDice.ui。
// 本专题核对完整172B虚表与所述跳板，UI经理通用加载生命周期复用界面系统资料。
//
// UI对象W+72 DWORD选值
// 虚表+0x58 -> 60D713 -> 6FB480返回&W+72；6924A0将指针返回给6534C0读取。
// 虚表+0x10 -> 716BF0每次显示/数据处理时写W+72=-1，再调+0xA4基础处理。
// 初始化716B60遍历控件ID1..6，登记回调槽5 -> 6EF990 -> 虚表+0x64。
// 该回调只走基础音效，不写骰值；不能误将所有按钮回调认作选择成功。
// 全局状态2时另登记槽10 -> 6EFA30 -> 虚表+0x78 -> 716D90：
//     调基础确认音效；读取回调第一个参数控件+4 DWORD ID写W+72；
//     再调用虚表+0x44(0)。第二个参数在该选择函数没有参与点数计算。
// 各回调slot的底层鼠标时机不在本专题穷尽；这里不擅自把slot10命名为左键释放。
//
// 快捷键716C40（被自动误名CWinApp::SetAppID）
// 先查左Ctrl(VK162)及Shift(VK16)实时按下；任一按下则不处理选值。
// 否则依次读键盘状态F1..F6，首个成立分别将W+72写1..6。
// 各键状态的具体按下/释放语义参见输入与快捷键专题，不套用Windows消息参数名。
//
// 操作轮询6534C0
// UI24不存在或未显示时先6E3B40(24,0,0)打开，再6E4640(24,0)触发选值重置。
// 右键取消：隐藏UI24、返回3，不构造0067请求。
// W+72==-1：返回2继续等；其它值：0067 +6取该DWORD低BYTE，发12B后隐藏、返回0。
// 本入口没有显式1..6值域检查；当前六按钮/F键生产者恰好提供1..6。
// 若扩展按钮ID或脚本写W+72，必须同时考虑这一截断与服务端合法值检查。
// 请求+8 DWORD由构造器清0，+7保留调试栈0xCC；不能把+7写成已确认保留0。
//
// 资源边界
// G_YaoKongDice.ui以RichNet循环逐字节相减解码，严格gb18030往返；不是KPD容器。
// 6个按钮ID1..6；图片other_23_68..79，双号普通/按下，单号悬停。
// 背景other_1_90，根面板294x84；布局/图片可编辑，ID同时是请求点数语义。
// 资源文本与SHA256在资源原证.json；04_资源摘录.txt保留中文注释式选取内容。
// 40B7确认只读身份/库存槽组，提示后消耗卡；实际骰值应用的其它协议不在本专题宣称闭环。
