// Map+48指向8B地图格记录，+2 signed WORD为地产号；Map+56指向68B地产记录。
// D+0 signed BYTE地产种类；D+1建筑种类；D+2 signed BYTE建筑等级；
// D+3 signed BYTE所有者（-1无主）；D+4 BYTE查封计数；D+6 WORD分组号；
// D+8 DWORD价格；D+24 DWORD地产图像句柄；D+28 DWORD建筑图像句柄。
// 各字段是本群读写证据，不宣称68B完整结构已恢复。
//
// 6071 -> 6806D0：处理所有权
// 先取旧owner/分组号；已有owner则先清相关模式4辅助登记，再7E3E60将D+3=-1。
// 新owner不为-1才调用7E3C00写D+3，并更新地产图像；专用建筑再挂相应索引。
// 新owner=-1时只解除。+5非零才有音效12及三块同组地产等附加分支。
// 本组调用者均将+5写0，因此这些附加队列不是本组一定发生的结果。
// 7E3C00/7E3E60会依模式改变图像用色索引，逻辑owner仍存D+3。
//
// 6074 -> 680D60：预先解除所有权及特殊建筑登记
// +4 signed BYTE=-1直接不做；模式4按建筑种类13/14/12清各自登记，
// 种类11还遍历角色与Map内64个12B登记；最后7E3E60解除所有权。
// 6075 -> 680F00 -> 7E32F0：只交换D(p/q)+1与+2两个BYTE；随后两地产重建图像。
// 地产种类、位置、分组、owner、价格没有在交换函数中交换。
// 6076 -> 680F80 -> 694E40：D+1=1,D+2=1，重建建筑图像。
//
// 模式4的即时限级
// 63E990(Map)实际是Map+24==4，不是网络模式通用枚举getter。
// 40B1先用目的地产的新所有者P[owner]的7F74B0(kind-11)限制其等级，
// 每次都在6071真正执行前直接写D+2并刷新图像；本地入队失败没有可见回滚。
// 40B2交换建筑前，用接收方owner的容量限制即将移出的另一端建筑；
// 非空owner才走该分支，然后6075交换。代码没有把该限制延迟至6075。
// 7F74B0普通路径读signed BYTE P+272+kindIndex；另一分支读配置表与角色档位。
// 40B1在模式4路径没有本地owner!=-1防护，P[owner]寻址前置条件需上游证明。
// 不能由此直接认定已复现崩溃；本专题没有运行畸形地图或服务器回复。
//
// 6077 -> 680FE0 -> 7E33F0：查封不是单格写
// 保存选中D+6 WORD分组号，7ECFD0遍历Map内地产号表，回调7E33A0比较D+6。
// 相同分组的D+4全部写5；不以owner一致为条件。这里只证计数5，周期递减另证。
//
// 6072 -> 680A90：拆屋卡
// packet+2 signed WORD地产，+4 signed BYTE减量。7E4020对D+2做BYTE减法，
// 再按signed BYTE<=0归零；不能把它改写成不会截断的int饱和减法。
// 归零时按地产种类分支把建筑种类设0或-1，必要时重建所有权外观。
// 模式4更新特殊建筑登记，再7E73F0更新建筑图像，启动动画4(payload含地产和11)。
// +5=0所以不由此处理器设动画等待；40B5的画面动作不等于阻塞整个记录队列。
//
// 40B6的怪兽破坏：6000 -> 67D750 -> 7A5C30(id17)
// 6000 +12指向一个DWORD地产号；+16=4不是67D750的memcpy长度，后者不读+16。
// +4=1且+8=0，67D750取动画17默认时长，再加100交64FB10设等待。
// 当前Anim.kpd记录17 time=2500/free=true，因此该组合等待2600ms。
// 工厂7A6EC0申请0x2C，7AA510构造虚表A2C0B0；当前PE和虚表字节均匹配IDA。
//
// 动画17对象A（偏移十进制）
// +12 DWORD目标地产；+16 DWORD固定减量5；+20 DWORD启动时等级；
// +24 DWORD图像句柄；+28/+32 DWORD绘制坐标；+36 DWORD起始tick；+40 BYTE已破坏。
// 6332F0启动：拷贝payload首DWORD，减量设5，取图像(type10,main2,sub34,-1)，
// 保存tick并清已破坏；将相机移到目标，计算坐标，按地产种类调整横向居中。
// 该启动入口当前未声明为IDA函数，证据单列，未创建函数或修改IDB。
// 633500更新：未破坏且无符号elapsed>=1000时，7E4020减5、7E73F0刷新图像，
// 再标记已破坏；每帧绘制并返回0，等待动画管理器time到期结束。
// 633420结束：未破坏时也执行减5/刷新；模式4清辅助登记，恢复当前角色视角。
// 因而业务修改可由tick或结束兜底触发，不能仅修40B6提示而漏掉动画生命周期。
// 当前配置2500ms大于1000ms；修改time会改变是否主要依赖结束兜底。
// 动画管理器按ID复用单实例、同ID重启不新增实例。连续怪兽事件的重入性未实测。
//
// 合作开发边界
// 建筑资源扩展需同步D+1/D+2、模式4容量、特殊建筑索引与7E73F0图像选择。
// 不能仅以“所有权写了”判断事件完成；队列顺序和动画回调各有实际副作用。
// 本专题未修改服务端规则或原始资源；用户操作与网络同步实机测试仍待安排。
