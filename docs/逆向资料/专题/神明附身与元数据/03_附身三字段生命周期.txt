// P+1488/+1489/+1490的局部生命周期
// ============================================================================
// +1488 signed BYTE：当前附身ID，-1为无；资源ID映射见02。
// +1489 BYTE：6051的输入标记；有默认1及显式2样本，完整业务含义尚未证实。
// +1490 signed BYTE：从NPC affix初始化的剩余计数，后续增减均保留窄BYTE行为。
// 7F3840角色构造直接写-1/-1/0；不能把第三字段为0单独当成无附身标志。
//
// 写入：本地事件6051 / 67F8F0
// ----------------------------------------------------------------------------
// 桥7F16D0将G装ECX、record入栈；处理器retn4。
// +2 signed BYTE为角色slot，ECX=P=DWORD[G+0xE00+4*slot]。
// +3 signed BYTE为神明ID，+4 signed BYTE为标记，+6 signed WORD为地图位置。
// 7F7DB0(P,位置,ID,标记)先写两字节，再读T行+63，窄写P+1490。
// 位置不是-1时，经P+1404所指游戏对象取M，再调用7E28B0清相关地图动态物件。
// 位置=-1只跳过地图清理，不阻止附身写入。
// 随后播放+10 signed WORD声音，显示UI6并交ID；ID在0/3/4/5时设置动作值4。
// 本机角色且ID为4/6时，还按7FB150条件通知UI1；最后写1800消费等待。
// 最高读取至+11，最低前缀12B；是内部记录读取范围，不是已证明的网络包长。
// 本体未检查角色slot、ID表范围或重复附身，也没读取+5和+8/+9。
// 694810构造只写WORD6051和+4=1，其他成员由生产者决定。
// 673AF0、673D50样本分别写ID0/3、标记2、位置-1，证明标记并非永远为1。
// 当前直接偏移扫描未发现+1489读取者，不能据2这个值就称它为等级或技能倍率。
//
// 减少与过期
// ----------------------------------------------------------------------------
// 7F7CF0：若ID=-1返回-1；否则先对+1490减1，再读取signed结果。
// 剩余>0返回-1，剩余<=0返回旧ID；该函数本身不清ID，也不构造事件。
// 7C0C50的当前角色路径收到非-1后排6050，再排另一个内部续接记录。
// 6050消费才清三字段；排队和实际清除之间存在静态可见间隔。
// 调用点有较多外围状态门，本篇未把一次调用等同一次日历日或任意一条网络消息。
// 7D7430只是对+1490减参数；7C6640两处分支紧接7F7CF0，因此还会再减1。
// 那些分支的技能数值来源仍未全部恢复，不把这个组合简写成仅扣参数N。
//
// 延长与上限
// ----------------------------------------------------------------------------
// 7F7E30先做加法并窄写BYTE，再把signed BYTE结果与DWORD[A87114]比较。
// 超过上限才窄写配置低字节；当前GValue[37]=5的正常装载路径据此限制为5。
// 因为先窄化再比较，极端输入可能绕回负值，不是数学上的饱和加法。
// 该函数也未自己检查有无附身；调用者应保证角色与状态前提。
// Npc.affix决定初次附身计数，GValue[37]决定这里的延长上限，两个配置分别生效。
//
// 清除与重置
// ----------------------------------------------------------------------------
// 7F7D50无条件写-1/-1/0；随后7016B0判断P+1740>0，是则7FDBA0只清该DWORD。
// 本次没看到它同步清P+1744；不得把附属值的完整生命周期都归到该清除函数。
// 40C1/6050已核实在离开动画3前调用此处，详见该专题，不重复当新增玩法。
// 7F91F0状态清理以及7BE160/7BE450参与者清理分支，均在附身存在时调用本函数。
// 7FAA40却只在ID==7时调用清除；这个重置入口不是所有神明的通用移除入口。
// 这些大函数只核到附身分支，退出、破产及模式资格的全部规则未恢复。
