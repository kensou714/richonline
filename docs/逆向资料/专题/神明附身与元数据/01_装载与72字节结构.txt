// NPC元数据装载 / 72字节运行行
// ============================================================================
// 6287F0首次分配8B单例A766CC；7ED400只把T+4表指针置0。
// T+0是装载后的条数，不能凭构造器称整对象已清零。
// 623EE0首先调用7ED490(T,"Data\\Npc.kpd")，失败返回0。
// 7ED490统计NPC块数N，再分配4+72*N字节；数组头保存N，数据地址交T+4。
// 先逐行调用7ED340，再回到文件开头按indx写对应行，不是按块顺序自动编号。
// N是块数而非最大indx+1；本体未核indx范围/重复，不能用稀疏大编号直接扩表。
// 当前文件34块，编号连续0..33，恰好符合现有装载方式。
//
// 行R = DWORD[T+4] + 72*id；以下偏移全部为十进制
// ----------------------------------------------------------------------------
// +0 ..31  32B名称区。name读取接口参数32；随后可能经本地文字转换接口处理。
// +32      DWORD，动态分配的图像句柄数组指针；通常1项，id14特殊为8项。
// +36      DWORD，可选bAni图像句柄；构造置-1，只有文本精确等于true才装载。
// +40      DWORD，可选bHead小头像句柄；构造置-1，63E260返回该值。
// +44      float，绘制浮动偏移；构造位模式0，7EDAD0按0.2增减并夹在-6..6。
// +48      DWORD，浮动阶段0/1/2；构造0，绘制时约每3000ms随机取rand()%3。
// +52      DWORD，上述阶段切换tick；构造0。
// +56      DWORD，图像选择分支计时tick；构造0，绘制时比较2000ms差值。
// +60      BYTE，动态图选择标志；构造0，已审绘制链只见清0，置1来源尚未找到。
// +61      BYTE，bShadow与"true"比较所得布尔值。
// +62      BYTE，indx窄化保存；数组索引仍使用完整atoi结果，不能据BYTE反推边界保护。
// +63      signed BYTE，affix；7FDBD0读取，进入角色附身初始计数。
// +64      signed BYTE，anew；7ECAC0读取，进入地图重生记录。
// +65      BYTE，6926A0(id)的结果，即unsigned id<8或id==18。
// +66 ..67 2B，已审构造/装载/直接步长消费者未读写；暂保留未知，不擅定有用字段。
// +68      DWORD，hurt的atoi结果；7D6E00读取供后续结算使用。
//
// +44至+60是T中共享行的运行状态；多个同ID对象共用，不能当成每角色独立计时器。
// 7ED340未初始化名称、+61..+71全部字节；装载器只对已说明的字段补写。
// name接口的长度参数不证明最终运行名一定以NUL结尾；长文本须另核解析器契约。
//
// 资源组6的子图消费顺序
// ----------------------------------------------------------------------------
// 每个id的子图索引从0开始。普通行先取1个基本图，id14先取0..7八个基本图。
// bAni为true时取下一子图写+36，并递增索引；bHead为true再取下一子图写+40。
// 因而bAni切换会改变bHead的预期子图索引；不是两套互不相关的资源开关。
// 当前所有行bAni=false；有头像的普通条目由子图1提供头像。
// 7ED3B0只释放+32句柄数组；图像实际缓存寿命另属资源管理器。
// 7ED420经7EE290析构行数组后清T+4，不重置N。
// 7ED490本体未在重新分配前释放旧T+4，不应把它直接当现成的安全热重载接口。
//
// 装载先后与成功边界
// ----------------------------------------------------------------------------
// WinMain/7A3D90先调用623B60，后进入主循环；初始化内先经7B74C0调用7B9AD0。
// 7B9AD0尝试读取GValue.kpd；主循环经624CA0状态表到625310，再创建623EE0线程。
// Npc因此属于后续数据阶段；625310看到线程退出0会提示InitData Failed，1才推进。
// GValue装载失败路径没有本处明确失败标志强制终止；不能用主循环存在证明配置已加载。
// 以上是正常可见调用顺序，不是对当前运行进程加载结果的采样。
