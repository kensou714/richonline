// 邮件与礼物分组 / 规则与副作用
// ============================================================================
// 重建 / 6A8E00
//   进入先清两组计数，直接将全局 A80D1C 写成 70。
//   类别 0 先扫描，类别 1 后扫描；每轮从 total-1 向 0 倒序。
//   entry+4 == -1 跳过；类别不是当前轮则跳过。
//   6A9270 返回 AL 非零的条目跳过，不进入普通组或礼物组。
//   剩余条目 +324 signed >0：追加到礼物视图。
//   剩余条目 +324 <=0：普通数小于 70 时追加，否则调用 6A8C20。
//   类别 1 共用类别 0 已占用的普通额度；不存在每类别独立 70 条额度。
//   倒序是槽索引顺序；未证明槽索引等同邮件时间，不能记为“最新优先”。
//
// 常量 / A80D1C
//   IDA 基线值为 0xFFFFFFFF；此地址位于 .data 仅虚拟区，没有磁盘原字节。
//   PE 映射与 IDA 值分别记录，不把 IDA 的值解释成磁盘初值。
//   原指令明确每次重建写入 70；真实运行前的值和 IDA 基线来源未闭合。
//   当前 IDA 精确直接引用只有 6A8E00 的一次写与两次读。
//   本专题未发现从配置装载该值；直接引用不排除运行期动态别名写入。
//   想修改上限必须同时检查固定视图容量与消费方，不能只改 IDA 值或写入常量。
//
// 过滤谓词 / 6A9270
//   NULL 输入：AL=0。否则把 entry+123 起 8 字节复制到零填充的 9 字节局部。
//   第 3 索引等于 ASCII '1'，且第 5 索引等于 ASCII '2' 时 AL=1。
//   等价于 entry+126=='1' && entry+128=='2'；其他 6 字节不参加比较。
//   不要求源字符串 NUL 终止，不要求八字符完整编码相等。
//   RTC 描述 6A9311 指出局部大小 9；不能把它说成只复制 9 字节源数据。
//   IDA void 伪声明漏掉返回意义：尾部 RTC 用 push/pop 保留 EAX。
//   security cookie 检查 91FBB0 正常路径不改 EAX；失败路径进入安全处理。
//   未恢复该编码的官方业务名称，暂称“特殊编码谓词”，不编造邮件类型。
//
// 超额条目操作 / 6A8C20
//   将 entry+4、+8 写入局部前两个 DWORD，调用 828F60(50, local)。
//   RTC 6A8C92 描述该局部为 8 字节，即两个 DWORD。
//   紧邻局部的 0xCC 调试栈填充不属于第三字段；详见独审补充原证。
//   操作返回后将 entry+4、+8 都改为 -1。
//   因而分组是有副作用的重建，并非只对视图排序或简单截断显示。
//   828F60 的本地 case50 最终调 843BC0(first, second)。
//   843BC0 进入服务/请求对象链；本专题尚未追到最终线上包编码。
//   不把 50 称为网络 opcode，也不宣称服务端已成功删除邮件。
//
// 类别 0 查询 / 正序，均跳过 +4==-1
//   三个入口仅以 movzx 读取参数低 8 位；下列 arg 均指截断后的 BYTE。
//   因此 256/-256 等效 0，257 等效 1，不能直接对宽整型参数取 bool。
//   6A90E0(arg=0) : 任意有效类别 0 存在；arg!=0 则要求谓词返回 0。
//   6A91A0(arg=0) : 计所有有效类别 0；arg!=0 则排除谓词返回 1。
//   6A9330(arg=0) : 找首个谓词返回 0 的有效类别 0。
//   6A9330(arg!=0): 找首个谓词返回 1 的有效类别 0；未找到返回 0。
//   这三个入口的 arg 不具有统一“过滤开关”语义。
//
// 容量边界
//   初始化固定 100 槽时礼物组最多 100；6A8E00 自身没有礼物 70 上限。
//   本函数不验证 total<=100，也不验证条目数组非空；调用前置条件待闭合。
