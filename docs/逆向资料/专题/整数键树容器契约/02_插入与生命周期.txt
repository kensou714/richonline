// 插入、分配、哨兵与清理 / 局部契约

//
// [唯一键插入]
// 8C0700 沿比较器找位置：严格小于走左，否则走右；等价键返回旧迭代器及 false。
// 等价键不覆盖 mapped。新节点由 8C09C0 链入并返回 true。
// 8C07B8 xor eax,eax；8C07BA jz 8C07F6 恒取该分支。
// 另一处直接插入分支不可按伪码推成当前实例允许多键；机器码实际是唯一键路径。
//
// [hint 插入]
// 8BD5E0 检查空树、begin / end 及邻居区间，部分区间可直接 8C09C0 插入。
// 不满足相邻排序条件时回退 8C0700，仍不替换等价键。
// 本轮核到调用和排序边界，未逐边证明非法 hint 指针行为或所有迭代器有效性。
//
// [链入与红黑修复]
// 8C09C0 先检查 unsigned(max_size-1) <= size 并抛 length_error，
// 然后分配/复制节点，++size，更新 root / 最小 / 最大连接，再修复颜色与旋转。
// 8C3DF0 左旋，8C4000 右旋：更新父子连接及 head.parent，
// isNil 子节点不会被当成真实子节点写 parent；修复结束根置黑。
// 这是局部插入修复契约，没有据此宣布所有树操作完整复原。
//
// [分配与容量常量]
// 8C6DD0 调 operator new(3624 * count)，此函数内没有乘法溢出检查。
// 当前已核 8C41B0 / 8C7200 都传 count=1，不代表其他调用均安全。
// 8C59D0 的机器码常量为 0x122A01 = 1190401，8C3D90 包装返回。
// 它等于 floor(UINT_MAX/3608)，不是 floor(UINT_MAX/3624)=1185145。
// 因此 max_size 检查不能直接拿来证明节点字节数乘法安全，也不是可承诺的容量。
//
// [节点构造与失败]
// 8C41B0 先取得一个 3624 字节块，再 placement new，再 8C6AD0 构造。
// 正常返回先前分配指针；8C4276..8C428B catch 调 8C1090(delete) 后重新抛出。
// A1B1C0 尾块通过 60E4EC -> 697780 清理包装；该实现为空。
// 这闭合该分配块的失败释放，不等于已验证全程序异常安全。
//
// [head 初始化]
// 8C6F50 -> 8C6FC0 -> 8C7080；前面的包装类型初始化仍有未命名字段。
// 8C7200 分配一个同尺寸块，只分别构造三个 link DWORD 为零，再 color=1/isNil=0。
// 8C7080 存入 T+4，改 head.isNil=1，三个 link 全部写回 head，T+8=0。
// head 的 pair 区没有经 mapped 默认构造，不能按普通值节点访问。
// 8C7570 -> 8C76C0 是 link DWORD 的 placement 构造；8C7420 -> 8C7610 空析构。
//
// [clear 与节点释放]
// 8BC610 从 head.parent 调 8BDE10 删除子树，随后根/最小/最大全重置 head，size=0。
// 8BDE10 遇 isNil 停止；递归释放右子树，再保存左子节点并循环处理，
// 经 8C10F0 -> 8C6D10 空值析构后调用 8C1090(operator delete)。
// 该路径释放全部真实节点，保留 head；所有已借出的 mapped 指针失效。
// 8BB180 中 8BB1F0..8BB1F5 明确以 ACBD94 调本 clear。
// 同函数随后处理 ACBD88 / ACBD7C 的另一实例，不能混用其节点字段。
//
// [析构边界]
// 8C8F90 -> 8C8FE0 -> 8C9030 先 range erase，再清理 head 三个 link 并释放 head，
// 最后 T+4 / T+8 清零。8C9150 的完整范围走 clear，其他范围转逐项 erase。
// 本轮只核到完整范围选择、head 释放；任意 erase 的删除修复留待后续。
// A20640 为已声明退出包装，启动窗口 A1E390 注册该 atexit 地址但没有函数声明。
// 此两处仅用于上下文观察，本轮不将未声明窗口算成完整函数。
