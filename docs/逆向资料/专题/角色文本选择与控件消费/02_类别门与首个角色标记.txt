// ============================================================================
// 6F4DB0 / 类别门、扫描次序与返回契约
// ============================================================================
// ABI：cdecl，一个32位input，普通ret，由caller回收4字节参数；本体179字节/59指令。
// 7014A0：ECX=R、一个栈索引、ret4，本体38字节/13指令。
// 7014B1乘0x468，7014BC返回DWORD[DWORD[R]+1128*input+0x0C]。
// 两函数都未对input的负值、记录总数、乘法溢出或R的NULL做本地检查。
// 合法调用域应由生产者保障；这里没有运行证据证明实际发生过越界。
//
// 类别门
// ----------------------------------------------------------------------------
// 6F4DDA第一次读类别，6F4DDF比较2；为2立即进入扫描。
// 第一次不为2才在6F4DEB以同一R/input再读，6F4DF0比较7；不为7返回-1。
// 这不是一次读取后缓存类别再双比较；文档保持二次调用这一真实控制流。
// 2与7为已证数值类别，具体游戏业务枚举名未恢复。
//
// 角色标记扫描
// ----------------------------------------------------------------------------
// 6F4DF5取独立H，6F4DFC经646590读取N=DWORD[H]；从i=0递增。
// 6F4E19/6F4E1C以有符号i>=N退出；N<=0时直接返回-1。
// 6F4E29调用646610，ECX仍是R；栈参数顺序为(i,input)，不能交换。
// 646621以input乘1128；64662C读record+14h指针；646633返回BYTE[pointer+i]到AL。
// 6F4E2E把AL零扩展，零继续循环，任意非零值都命中，不限于1。
// 这里的i是档案枚举序号，不是地图玩家席位；数组生产/映射关系仍须上游证实。
//
// 首命中规则
// ----------------------------------------------------------------------------
// 首个非零i形成6DBA40(T,10,47,i+40,-1)；6F4E4B调用后直接走共同出口。
// 6F4E50无条件跳转，资源查询即使返回-1也不继续找下一个角色标记。
// 类别不符、没有命中或查询门失败，都可能产生同一个FFFFFFFF返回值。
// 因而仅凭最终-1无法分辨失败原因，诊断需要同时记录类别、N、首命中i和T的数量。
//
// 局部结构表达，仅展示已用字段
// ----------------------------------------------------------------------------
// R+00                 DWORD数组基址，不是记录数量。
// R数组+1128*input+0C   DWORD类别；本题允许2或7。
// R数组+1128*input+14   角色标记BYTE数组的指针；本体未记录其容量。
// H+00                 DWORD档案数量；本题作为signed上界消费。
// 所有算术服从32位机器指令；未恢复的域不能按宿主语言无限整数默认处理。
