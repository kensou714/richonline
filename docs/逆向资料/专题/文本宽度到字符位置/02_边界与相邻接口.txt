// 文本宽度到字符位置 / 边界与相邻接口
// ============================================================================
// 普通域示例，宽度列表不是Unicode字形数或字节文本长度
// ----------------------------------------------------------------------------
// widths=[1,0,0,7]，target=1：flag低BYTE=0返回1；非零返回3；delta均为0。
// 同样文本target=4：flag低BYTE=0返回1；非零返回3；delta均为-3。
// 原子跨度2宽4，后继宽1，target=4：flag=0返回0；flag=1返回2；delta均0。
// flag=256等价0，257等价1；负数也按低BYTE判断，不按整个DWORD是否非零判断。
// target超过实际累计宽时返回n，delta为负的实际宽-target；不是错误码。
// target负数没有预先钳制：常规非负宽度会先以0重查，外层delta=0-target为正。
// 零宽前导项可被flag=1穿过，所以负目标也不保证返回0；[0,0]、target=-2返回2。
// 分段模式且链为空时，非空文本直接返回n、delta=-target；不是普通缓存模式。
//
// 终止性与访问边界
// ----------------------------------------------------------------------------
// 对有限无环、非负宽度、无溢出且字段稳定的合法输入，递归目标是已到达的前缀。
// 第二次遍历会在该边界返回或越过同宽零宽项；此普通域只需至多一层递归。
// 非负宽度是条件，不是机器校验：原子N+4可为负，节点跨度也可为负或过长。
// signed加减按32位回绕后比较，极值不能套用无限精度数学模型。
// 链循环、负长度、跨度超缓存、文本未终止、输出别名与并发更新均未被主函数检查。
// 节点跨度和wcslen不一致时，函数有时在节点内返回位置，有时在尾部返回n。
// 因此“始终返回[0,n]”只可在合法输入假设下使用，不是任意内存输入的保证。
// deltaOut必须可写且避免与文本/节点/缓存别名；每个正常出口都会写DWORD。
//
// 90D120：位置到前缀像素宽
// ----------------------------------------------------------------------------
// 栈参数T、position；retn 8。该函数主体不使用传入ECX，不应额外猜隐藏成员。
// T文本为空返回0。普通模式循环0<=i<position，累加unsigned BYTE宽度。
// position<=0返回0；没有wcslen检查或上界钳制，position过大可能越过缓存。
// 分段模式令B=0、S=0；若节点末尾B+length<=position，直接S+=N.width。
// 连普通节点的整段消费也用N.width；只有position落在普通节点内部才逐BYTE相加。
// position落在原子内部时不消费该节点，直接返回S；精确到原子末尾才加整体宽。
// 链耗尽返回S；该函数不以T+12充当快捷答案，也没有验证N.width与缓存和相等。
// 故90D120与90CE80并非任意分段数据上的互逆函数。
//
// 90D310：从位置求下一个可选边界
// ----------------------------------------------------------------------------
// 栈参数T、position、skipZero；retn 0Ch；skipZero只读低BYTE。
// 普通模式从position+1起，返回首个缓存非零位置；没有则返回wcslen。
// 稳定普通模式下，skipZero=0与非零结果相同；非零路径碰零会重新调用wcslen。
// 这不是字素簇或UTF-16代理对识别，只依赖缓存是否0；position<-1可能负下标。
// 普通模式直接调用wcslen(T.text)，没有90CE80那样的空指针检查。
// 分段模式先找覆盖position或紧邻position+1的节点，原子节点返回节点末尾。
// 普通节点内skipZero=0可返回零宽位置，非零则向后找非零缓存或继续后继节点。
// 若当前节点整体宽=0且skipZero非零，position会增加该节点跨度再继续。
// 恰到普通节点末尾时，skipZero=0立即返回position+1，非零继续后继节点。
// 节点耗尽返回累计跨度，空链返回0；与90CE80链尾取wcslen的规则不同。
// 模型完整保留节点分支，但合法分段的全输入空间未穷举；见结果计数与显式边例。
//
// 8E0A00：相邻断点探测，不参与90CE80主循环
// ----------------------------------------------------------------------------
// cdecl参数为宽文本、BYTE宽度数组、target；先读ACC3C8+0x5128模式DWORD。
// 模式为0直接返回AL=1；模式非零时遍历到文本0或可见断点也返回1。
// 只有当前缓存BYTE非零才识别逗号、句点、空格、LF、CR及字面反斜杠+n。
// 断点检查先于宽度累加；其余项累计宽>=target返回AL=0，不保证EAX高24位。
// target<=0且非空非断点时，连0宽项也可立即返回0；空文本则返回1。
// 90E4B0窗口仅提供主定位的调用导航，未将整个文本选择流程列为已完成语义。
