// ============================================================================
// 复核结论：旧正文和两套有限模型的返回B正确，无需语义勘误。
// 疑点来自把不同ESP状态下相同的18h位移误认成同一物理槽。
// 本补证仅引用既有证据/width_position.json，不重复导出或调用IDA。
//
// 入口基准S与物理地址，以下偏移均为字节
// ----------------------------------------------------------------------------
// S是90CE80入口的ESP；[S]是返回地址，四参数位于S+4、S+8、S+12、S+16。
// 90CE80 sub esp,0Ch，90CE83/84/89/8A依次push四寄存器，稳定ESP=S-28。
// 90CEA4临时push文本地址，ESP=S-32；90CEA5 [ESP+14h]清零S-12的scratch。
// 90CEAD经610283跳板调用924FC0；924FED是C3裸retn，不清理长度函数参数。
// 90CEB9 add esp,4后ESP恢复S-28；90CEC0 [ESP+18h]把长度n保存到S-4。
// 90CF52 [ESP+24h]把节点起点B初值0写到S+8，复用了原target参数槽。
// target已经由90CEB5保存到EBX；遍历后90CFC4继续把累计B写回S+8。
//
// 原子等宽且flag低BYTE为0的出口
// ----------------------------------------------------------------------------
// 90CF70跳到90D006；此时ESP仍为S-28。
// 90D006 [ESP+28h]读取S+12的deltaOut指针到EAX。
// 90D00A/00B/00C依次pop EDI/ESI/EBP，ESP变为S-16。
// 90D00D写*deltaOut=0；90D013 [ESP+18h]实际地址为S+8，读取B。
// 因此90CEC0写n和90D013读B虽然机器位移同为18h，却相距12字节。
// 90D017 pop EBX，90D018 add esp,0Ch，90D01B retn 10h完成正常返回清栈。
// 原子宽溢出且已累计宽等于target的另一出口90CFFA直接mov EAX,ESI返回B。
// 两出口都可返回B，但比较条件和delta写入路径不同，不以名称相似替代控制流证据。
//
// 核验范围
