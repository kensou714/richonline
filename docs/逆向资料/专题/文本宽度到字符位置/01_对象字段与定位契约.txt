// 文本宽度到字符位置 / 对象字段与定位契约
// ============================================================================
// 主入口90CE80，E9别名6034CF。ECX=this被保存，供三条递归调用恢复。
// 四个栈参数依次为T、target、deltaOut、flag；所有出口retn 10h。
// T是文本记录地址，不能把ECX误当T；函数不解引用this成员但递归保留这个值。
// 返回EAX为UTF-16码元位置；deltaOut写DWORD；flag仅消费低BYTE。
//
// T与节点N，偏移均为字节
// ----------------------------------------------------------------------------
// T+0   DWORD：以0结尾的16位文本地址；本函数只检查该指针与首WORD，不校验T自身。
// T+4   DWORD：分段链首节点；T+40低BYTE非零时启用。
// T+8   DWORD：按文本码元位置索引的unsigned BYTE宽度数组，不是窄文本字节串。
// T+12  DWORD：缓存总宽；90CE80与90D120并不直接读取它。
// T+32/+36：8E1620传给测宽及分段回调的参数，本题保留字段名。
// T+40  BYTE：分段模式开关，非零即启用；不是只有1有效。
// N+0   DWORD：节点跨度，按码元位置累计，机器计算与比较使用signed 32位。
// N+4   DWORD：节点整体宽；原子节点90CE80直接累加它，不读取缓存BYTE来代替。
// N+8   BYTE：非零表示原子节点；零表示可逐码元消费的普通节点。
// N+12  DWORD：下一节点，0结束。
// 节点来自引擎回调；这些结构字段不证明所有资源控制码的语法已被恢复。
//
// 缓存生产者的局部证据
// ----------------------------------------------------------------------------
// 8E1620先清除旧T+8、置T+12=0；非空文本分配wcslen+1个字节并清零。
// 非分段模式通过ACC3C8上下文+32回调逐码元测宽，仅将返回AL存入BYTE缓存并累加。
// 分段模式通过上下文+64回调建立T+4，608AB0->8EAA30给出总宽T+12。
// 原子节点在起点只写N+4的低BYTE，其余跳过位置保持0；普通节点继续逐码元回调。
// 因此原子整体宽可能大于255，不能把其首缓存BYTE当成完整节点宽度。
// 8EAA30与两类回调未在本题完整恢复；不保证任意外部生成缓存与节点宽始终一致。
// 8E1800负责自有文本副本、旧链回收与重建；详细所有权沿用提示文本生命周期。
//
// 90CE80普通模式
// ----------------------------------------------------------------------------
// T+0为空或首WORD=0时：*deltaOut=0，return 0，忽略target。
// 其余情况先wcslen得到n，累计宽S=0，从i=0逐项读取unsigned BYTE[T.widths+i]。
// next=S+width[i]。next>target时进入溢出分支；比较为signed jg。
// next==target且flag低BYTE==0：写delta=0，return i+1。
// 其余情况令S=next并继续，直到i==n；链尾出口写delta=S-target，return n。
// flag低BYTE非零会继续穿过精确等宽点及其后的零宽项；它不是四舍五入开关。
//
// 分段模式
// ----------------------------------------------------------------------------
// 从T+4遍历，累计码元起点B=0、累计宽S=0，初始n仍来自wcslen。
// 原子N+8非零：next=S+N.width；大于target走溢出，等于且flag低BYTE==0返回B。
// 这条等宽路径返回原子节点起点，不是B+N.length；不能套用普通字符的i+1规则。
// 否则消费整个原子节点，然后B+=N.length并转到N.next。
// 普通N+8为0：在N.length内逐项读widths[B+j]，等宽flag=0返回B+j+1。
// 普通节点长度<=0直接跳过内部循环；仍把该长度加到B，未校验合法性。
// 节点耗尽的公共出口返回最初wcslen的n，而非累计B；空链同样走此出口。
// 所有节点累计跨度是否等于n由生产者负责，主函数没有重新验证。
//
// 三条递归与deltaOut
// ----------------------------------------------------------------------------
// 普通溢出90CF25、原子溢出90CFEB、普通节点内溢出90D03E均调用6034CF。
// 溢出时先写外层*deltaOut=S-target；若S==target直接返回当前普通/节点起点。
// S!=target时以相同T、this、flag递归，新的target=S，输出指针改为局部scratch。
// 返回值使用递归EAX；外层delta仍为旧S-target，不会被递归局部结果覆盖。
// 所以delta不是可无条件写成prefix_width(returned_position)-target的恒等式。
// 例：原子跨度2宽4，后继字符宽7；target=5、flag=0会返回0而delta=-1。
// 这不是把原子起点的真实前缀0减5；差值来自外层刚消费的节点边界4减5。
