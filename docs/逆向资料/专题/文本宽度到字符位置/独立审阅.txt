// 重点人工复核
// ----------------------------------------------------------------------------
// 90CE80的普通BYTE宽循环在精确等宽且flag低BYTE为0时返回i+1。
// 90CF6A测试原子分支的flag低BYTE，90D006直接返回该原子节点起点B，未加N.length。
// 90CF1A、90CFDF、90D02E三处递归参数均指向栈内scratch；外层delta先写入调用者指针。
// 因此原子跨度2宽4、后继宽7、target=5、flag=0得到位置0和差值-1，
// 不能把差值泛化成返回位置的真实前缀宽减target。
// 负target、前导零宽、空分段链均无主入口钳制；这些是可观察边界，不是错误码契约。
// 90D120整段直接累加节点DWORD宽；仅普通节点内的部分跨度逐BYTE读缓存。
// 90D310普通模式跳过零缓存，不论skipZero低BYTE；分段模式依skipZero走不同节点分支。
// 零宽分段且skipZero非零时，会把当前position再加节点跨度后续查，不是普通缓存规则。
// 8FA298到8FA2AA的WCHAR拷贝没有写NUL，随后直接wcslen；只限定此局部路径。
// 8E0A00的断点探测仅证明本函数的模式门控、断点优先与累计阈值，不扩大成排版引擎。
