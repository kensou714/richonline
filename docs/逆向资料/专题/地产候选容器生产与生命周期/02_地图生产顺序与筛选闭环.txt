// ============================================================================
// 第二十七批 / 地图载入生产顺序 / 接续第二十六批五筛选器
// ============================================================================
// 原证map_runtime_core.json中的7DF010已被旧专题完整导出；本批只提取十个必要有限窗口。
// formal_functions.json的caller_windows保留旧来源SHA、JSON Pointer、原行号与逐字节当前PE校验。
// 本文偏移统一十六进制：M+24h是总格/记录数，不是旧文十进制+24所指的模式字段。
// R(j)=[M+38h]+44h*j；K=sign8(R+0)，S=sign8(R+1)，L=sign8(R+2)。
//
// 记录顺序与分流
// ----------------------------------------------------------------------------
// 7DF9BC置DWORD j=0；7DF9C3首轮跳过递增；7DF9C5..CB每轮j加1。
// 7DF9D4比较j与DWORD[M+24h]，7DF9D7 signed JGE离开；7DFCC7回跳递增点。
// 在合法非负且稳定的总数域里，记录处理次序是0,1,2……N-1，每个j只走一次分流。
// 7DFA10/16把文件本记录首DWORD的低BYTE写K；7DFA25/2B把第四DWORD的低BYTE写S。
// 原文件每项88字节，运行时每项68字节；这些低BYTE转换不能扩大成完整DWORD枚举验证。
// 7DFBF8经607084到63F540：依次读取K，低AL表示K==11或K==12；失败跳7DFC96，两个地产表均不追加。
// 通过后先生成地块图像并调用7E73F0更新建筑图像，然后7DFC4E经606D69到692030检查S。
// 692030依次比较S==8、S==9、S==10，低AL为真时进入M+47Ch路径。
// 特殊路径7DFC66把R+18h图像槽写FFFFFFFF；7DFC6E取WORD(j)，7DFC76设M+47Ch，7DFC7C追加。
// 普通路径7DFC83取WORD(j)，7DFC8B设C=M+46Ch，7DFC91经603F74到7ECE30追加。
// 输入实参只先写AX/CX低16位再PUSH整寄存器；高16位可能保留旧值，但7ECE30只读取低WORD。
// 因而普通C包含运行时K为11/12且分流时S不属于8/9/10的记录号，特殊表包含其余三种S。
// 三类判定不检查当前owner、等级、价格；这些后续字段过滤由第二十六批五入口另做。
//
// 必要勘误：K与S不能互换
// ----------------------------------------------------------------------------
// 旧地图与路径/00_EMP运行时对象与装载.txt第62行把特殊归一化写为“运行时种类改为-1”。
// 本批核7DFB21..7DFB60：文件K DWORD为FFFFFFFF，或者运行时K=12且S=0时，写的是R+1=FFh。
// K所在R+0没有在此改写。类型12、S原为0的记录变为K=12/S=-1，仍通过63F540且进普通C。
// 文件K=-1时其低BYTE已是FFh，故类型门不通过；不能把两种输入因为同走R+1写入而混为同结果。
// 若文件K DWORD不是12却低BYTE为12，运行时类型判定使用低BYTE，归一化分支同样需按实际K/S解释。
// 本批保留历史文件与原证，不重写旧冻结结论；以后查容器来源须以这里的具体写入地址为准。
//
// 与五个筛选器闭环
// ----------------------------------------------------------------------------
// 第二十六批7E4660/7E4750/7E4830/7E4930/7E4A30都按C中下标0..n-1读取WORD并MOVSX为signed16。
// 单次正常加载、j范围0..32767、没有后续重排/追加或记录并发改写时，C顺序就是合格原记录号升序。
// 前两筛选用L<threshold，同级保留首次命中；因此上述前提下同级最终落到合格记录号最小者。
// 后三筛选要求L>0且L<=threshold，同级替换；因此上述前提下同级最终落到合格记录号最大者。
// 类型、S、owner、排除编号等各入口过滤仍独立有效；不能只依记录号选择，也不能把三类合成一个搜索。
// j=32768写WORD8000h后读成-32768；j=65535写FFFFh后读成-1，与筛选失败哨兵冲突；j=65536低WORD回0。
// 因而WORD存储本身不保证合法索引，源记录递增也不保证消费者看到的signed编号始终递增。
// 本体未提供32768格限制；服务端或未来编辑器的尺寸限制需明确标为新校验规则。
//
// 静态推导的前提
// ----------------------------------------------------------------------------
// 容器初始化/追加仅保证局部写入顺序；字符串无界复制、分配失败、整数回绕可破坏后继前提。
// 本批没有枚举整个程序所有对C的写者，故不宣称地图加载是唯一生产者或数组永远不变。
// 第二十六批只承诺容器中首次/末次的规则依然成立；本批把它与加载记录号的关系补到有限有效域。
