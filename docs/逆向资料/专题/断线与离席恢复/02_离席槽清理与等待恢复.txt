// ============================================================================
// 400A -> 65C700：本机退出与远端槽失效
// ============================================================================
// packet直接字段：+2 WORD GmsvID；+4 signed BYTE slot；+6 signed WORD；
// +8 DWORD；+12 BYTE提示分支。最小直接读取跨度13字节，不等于完整线上包长度。
// +5在本handler未消费。+6/+8的完整业务名称未知，不按常见协议猜测为积分/经验。
// 入口先读BYTE[G+3632+slot]并保存队列head，然后才验证GmsvID。
// 因此身份校验不能替代slot范围和缓冲长度校验；也不能称无效ID路径“没有读任何状态”。

// 共同前置：当前行动槽与角色动作状态
// 若packet.slot==DWORD[G+E28]且DWORD[P(slot)+384]==1，取得单例A766C4并调用69A5D0。
// 69A5D0只在单例+8字节非零且+32句柄非零时调用609FEB处理句柄，再将+32清0。
// 此处没有直接清G的pending；句柄的完整资源类型和播放结束语义尚未恢复。

// 本机离席
// packet.slot==DWORD[G+8]时调用65C0D0(0)，立即离开远端清理分支。
// 65C0D0接受空参数时跳过重复GmsvID检查，取得A76724连接对象，6BE240(0)写其首字节0。
// 随后629DC0(7)写全局A6723C=7，请求主状态切换；不直接证明socket关闭、G已析构或回到大厅。
// 本分支不执行以下160字节槽写入、离线文字或pending20旁路。

// 远端清理7BE450(G,slot,0)
// 先看BYTE[G+3640+slot]，为0则此清理函数返回；第二个栈参数在实现中未使用。
// 保存oldActive=BYTE[G+3632+slot]。mode4另有条件性8074C0(G,-2)调用，效果未全部命名。
// oldActive非0时清理地产/地图关联、普通模式角色库存类数据，以及多种角色附加效果。
// 地图清理7E6200的this为G+0x65C；完整地图模式差异未在本批逐个闭环。
// 7D9CC0的this为G+0xC5C，遍历其+1..+32字节，将等于离席slot的项写-1。
// 遍历G+3616角色数，对仍存在的P(i)调用63EFE0，清BYTE[P(i)+1472+离席slot]。
// 7F9560清离席角色P的1496/1498/1499/1500/1501/1502等字段和若干互相关联状态。
// oldActive非0时最后将DWORD[G+3620]减1；不将此数直接命名为在线人数总计。
// 清理末尾始终写G+3632+slot=0、G+3640+slot=0、G+3656+slot=oldActive。
// 此层没有delete角色指针；不能将“槽失效”写成“角色对象已释放”。

// 160字节槽记录写入：清理调用返回之后继续执行
// 65C7FE：DWORD[G+160*slot+0x128] = sign_extend16(packet+6)。
// 65C81B：DWORD[G+160*slot+0x12C] = DWORD[packet+8]。
// 65C832：BYTE [G+160*slot+0x135] = 0。
// 65C84A：BYTE [G+160*slot+0x136] = 1。
// 以G相对地址准确记录，不凭这四次写入推断槽记录真正起点或所有字段名称。
// 这些不是P(slot)字段；即使7BE450因槽有效标志0早退，上述写入仍会发生。

// 远端显示文字
// +12非0：RichStr[97]为“玩家 %s 已離線”，参数取P(slot)+112名称。
// +12为0：RichStr[12]+姓名+RichStr[18]，资源原文为“玩家”和“退出遊戲”。
// 649A30颜色0xFF80FFFF；这两种文字不改变前述slot==local分流条件。

// 特定pending20旁路：不是所有离席都恢复回合
// 只有WORD[G+83790]==20、signed BYTE[G+83813]==packet.slot、signed BYTE[G+83812]==3，
// 才由693950构造本地6004：+2 WORD=1，+4 DWORD=DWORD[G+83784]，+8 BYTE=当前槽低字节。
// 以12字节插入入口保存的head，获得返回游标；未显式赋值+9..+11，不命名为业务字段。
// 6004消费者67DB40只读+2/+4，经7BB430设pending1、对应时长及新Tick；不读取+8。
// 这不是6939E0的pending=-1/时长0；收到400A也不等于该6004已经消费。
// 若current==local，随后在更新后的游标插入4字节6006，+2=1；否则不插6006。
// 两条本地记录保持顺序，但最终操作允许仍受6006消费者的三项角色状态判据约束。
