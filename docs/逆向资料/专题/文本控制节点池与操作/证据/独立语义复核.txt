// 6FACF0 只清 +0、+4、+8、+C；+9..B 未写，不能描述为完整 16B 清零。
// 6FAD40 只检查 ACC3C4：空池返回 1，非空返回 0，不回收节点。

// 空池申请 16B，非 NULL 调构造；NULL 返回 NULL。6E52D0 的六处生产点未见空返回保护。

// arg1 为零终止 WORD 串；arg2 经两个外部调用取得测宽对象；arg4 的 WORD 决定低字符遮罩测宽。
// >=0x80 字符走原字符测宽；其它普通字符在 arg4 非零时测 '*'，不意味着修改原文本。
// WORD 6 且后一 WORD 在 0x14..0x46 内：先刷新普通段，再产生 count=2、width=24、special=1 节点。
// 后一 WORD 数值仅参与范围判断，本函数不把它保存到节点字段。
// 六处生产：6E53AF/6E53E7 普通段，6E5444/6E547C 特殊段，6E5522/6E555A 尾普通段。
// 每对分别为首节点/追加节点；next 清零，head/tail 保持正向活动链，返回 head。
// 普通段写累计字符数与测宽和、special=0；本体不持有原串指针、不回收活动链。

// 求和与过滤
// ----------------------------------------------------------------------------
// 8EAA30 有 this=ECX 与 4 个栈参数，ret 0x10；NULL/空串直接返回 0。
// 第二参数非零时遍历其链求 DWORD+4 之和，保留 caller 提供的链。
// 第二参数为零时通过 this+0x40 函数指针槽生成链，压 string/context3/context4/0，caller 清 16B。
// 自动生成链求和后逐节点头插 ACC3C4，次序反转；没有虚表间接一级读取，不能称为虚函数证据。
// 复用注册路径：6E2F0E push 609537，6E2F13 取 ACC3C8，6E2F19 经 610797 调 8E8720。
// 8E8720 仅参数非零时写 this+40；609537 单条 E9 指向 6E52D0。
// 这条注册路径闭合到已核生产器；所有运行期管理器实例、改写者及实际绑定状态仍未闭合。
// 8EAAF0 同样有 4 个栈参数并 ret 0x10，无 this 消费；第二参数仍为链头。
// 栈算术：sub 0x420 + push EBX/EBP/ESI=0x42C，此时 [ESP+0x434] 对应入口 +8。
// 第三/四参数分别 [ESP+0x438]/[ESP+0x43C]；通过 [ACC3C8]+0x40 槽压四参数并由 caller 清栈。
// 两个局部缓冲各初始化 522B=261 WORD；仅首个缓冲用于后续过滤，第二个的目的未证明。
// 有非空链时把 wcslen 个 WORD 复制到首缓冲，没有显式容量检查；没有额外复制源 NUL。
// 长度 <=260 才能依赖预清零保留缓冲内 NUL；长度 261 可用尽缓冲，>261 可越过邻界。
// 该静态风险受输入长度和链条件限制，运行时可达性及破坏程度未实测。
// 随后原 buffer 按 wcslen 个 BYTES 清零：shr 2 的 stosd 加 and 3 的 stosb，无乘 2。
