// 文本控制节点池与操作 / 节点布局与生产
// 基线：RnClient.exe，SHA256 a23410e79637e312c932f861176d8d81cd1fd5d222a286f279feccdece6263c2。
// 原证：证据/bounded_raw.json；逐块核验与语义锚点见证据/verify_bounded.py。
//
// 一个节点占 16 字节
//   +00  DWORD  段内 WCHAR 数。普通段累加字符数，控制段固定为 2。
//   +04  DWORD  段宽度。普通段累加测宽返回值，控制段固定为 24。
//   +08  BYTE   控制段标志。生产器写 0 或 1，消费者以非零为控制段。
//   +09..+0B    本批没有有效访存证据，不能命名，也不能说初始化为零。
//   +0C  DWORD  next。活动链与空闲链复用此字段，责任由持链者决定。
//   证据：6FAC5E push 10h；6FACF0 分别以 BYTE/DWORD 清上述四个字段。
//   节点不保存原文本地址；字符串与逐字符宽度缓存是文本子对象的另外两项资源。
//
// 取得节点：6FABE0
//   6FAD40 检查全局 ACC3C4 是否为空，不使用传入 ECX 中的池头副本。
//   非空时先保存旧头、把全局头改为旧头+0C，再清字段并返回旧头。
//   空池时分配 10h，非空结果调用 6FACF0 初始化；分配返回空则返回空。
//   主块 6FABE0..6FACBA 与附属块 A13D00..A13D15 均已核当前字节。
//   附属块含构造失败的释放 funclet 和 C++ 异常处理桥；不扩展为完整 CRT 契约。
//   生产器取得后直接写字段，未见 NULL 防护；分配异常和失败传播不能宣称安全。
//
// 生产活动链：6E52D0
//   输入是 NUL 终止的 WCHAR 序列；返回活动链首节点，局部另保存尾节点。
//   先经 627830、6DDCF0 取得测宽对象；8171A0 的完整字体算法本批未复核。
//   每个 WCHAR >=80h：普通段字符数+1，以原字符测宽，文本指针推进 2 字节。
//   每个 WCHAR <80h：若不是下述控制对，同样累计普通段。
//   仅在此小于80h的普通路径，第四实参低 WORD 非零时改用 '*' 测宽。
//   第三实参在本入口未见读取；不能据参数个数附会其用途。
//
// 控制对的确切条件
//   当前 WCHAR ==6，且下一 WCHAR 在 14h..46h（20..70，含端点）。
//   先把已累计的普通段写入节点，然后追加控制节点：count=2、width=24、flag=1。
//   累计量清零，输入推进 4 字节。未证明第二 WCHAR 的图形或资源语义。
//   当前 WCHAR 非零时会读取下一 WCHAR；这里未验证调用者缓冲区的实际边界。
//
// 六处建链分支，不是六种节点
//   6E53AF / 6E53E7：控制对前的普通段，分别建立首节点或追加尾节点。
//   6E5444 / 6E547C：控制段，分别建立首节点或追加尾节点。
//   6E5522 / 6E555A：NUL 前最后一个普通段，分别建立首节点或追加尾节点。
//   每个新节点 next 清零；追加时把旧尾+0C 指向新节点，再更新尾变量。
//   空文本没有节点；连续控制对可以产生连续控制节点，不必夹普通节点。
//   输入本身不被该生产器改写；测宽值的溢出、负值和线程同步仍未证明。
