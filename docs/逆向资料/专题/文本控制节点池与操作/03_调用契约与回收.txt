// 文本控制节点池与操作 / 调用契约与回收
// 范围：保存汇编、当前 PE 字节与有限注册路径；没有执行回调或游戏。
//
// ACC3C4 与 ACC3C8 是不同责任
//   ACC3C4 是可复用节点的全局空闲链头；活动节点由返回值或文本子对象持有。
//   ACC3C8 是 UI 上下文管理器指针，其 +40h 字段保存可调用地址。
//   +40h 不是虚表槽：调用直接读管理器字段，没有先取对象首 DWORD 的虚表步骤。
//   全局 ACC3C4 位于静态虚拟零填充区。IDA 快照不证明运行中头指针为零。
//
// 已闭合的注册路径
//   6E2E60 的 6E2F0E 压入桥 609537，6E2F19 经 610797 调 8E8720。
//   8E8720 仅在参数非零时写管理器+40h；609537 的单条 E9 指向 6E52D0。
//   旧 lifecycle.json、registration_setters.json 的声明块已独立对照当前 PE。
//   来源摘要和注册桥字节保存于 bounded_audit.json 的 binding_reuse。
//   这证明该注册路径的目标；不证明运行期所有管理器对象或改写者都用同一目标。
//
// 求链总宽度：8EAA30
//   外层：ECX=管理器，四个栈参数为文本、已有链、两个不透明测宽参数；ret 10h。
//   文本空指针或 wcslen==0 时返回 0，不消费、回收传入的已有链。
//   已有链非零：逐节点把 DWORD+4 累加到返回值，不修改 next，不回收该链。
//   已有链为零：8EAA63 从 [管理器+40h] 调回调。
//   回调栈参数按调用者视角为（文本，测宽参数1，测宽参数2，0）。
//   压栈顺序相反，调用后 add esp,10h；返回 EAX 作为临时活动链头。
//   回调为调用者清栈 ABI，ECX 此处只是参数临时值，不能解释成回调 this。
//   求和后仅临时链逐项入空闲池：先保存 next，再把节点+0C 写为旧池头。
//   8EAA99 写新的 ACC3C4，最终临时活动链顺序反转并接在原空闲链之前。
//
// 原地过滤入口：8EAAF0
//   外层四个栈参数与上例对应，以 ret 10h 返回；不接收外层 this。
//   缺少已有链时，8EAB37 用 ACC3C8+40h 调同形回调，随后 add esp,10h。
//   原文本非空且链结果非零时，将 wcslen 个 WCHAR 复制到已清零的 522B 栈暂存。
//   没有长度裁剪；不能把固定暂存区称为通用安全文本容量。
//   在执行复制的分支，长度<=260个 WCHAR 可保留预清零的终止 WORD；261个会耗尽522B。
//   长度>261个会越过暂存边界；261个也不能依赖该暂存区内仍有终止零。
//   8EAB8D 起重新取原文本 wcslen，并按该数值清字节，未乘以 WCHAR 的 2。
//   随后按暂存文本扫描：保留 >=20h 的 WCHAR，原地紧缩并清掉相应尾部 WCHAR。
//   不依据节点+00/+04选择保留字符；链在这里用于取得临时链及判断是否复制文本。
//   若回调返回空，暂存保持空，后续过滤不写回；前面的按字节清源仍会执行。
//   仅未传已有链时回收临时链；传入链不回收。本段容量、终止符及异常行为保留局部级别。
//
// 释放空闲节点：8E02F0
//   ECX 指向上下文，先分别释放并清 +5118h、+5120h 两个指针字段。
//   全局 ACC3C4 非空时，经 6FABE0 取下头节点，再 operator delete。
//   本循环自身先检查非空，所以不会走空池新分配分支；最终全局池头写零。
//   活动链未挂在空闲池上时，该入口不会遍历它。两个上下文字段的完整用途未命名。
//
// 管理器退出顺序：复用 8EA2B0 的局部路径
//   先遍历根控件调用 +78h 析构接口；本专题不展开所有控件的析构体。
//   8EA2D7..8EA2F5 直接按节点+0C 释放空闲链并持续更新 ACC3C4。
//   随后对 ACC3C8 管理器调用 8E02F0，再 delete 管理器，并清 ACC3C8。
//   正常单次顺序中后一入口看到池已空；不能据此证明双销毁或并发清理安全。
