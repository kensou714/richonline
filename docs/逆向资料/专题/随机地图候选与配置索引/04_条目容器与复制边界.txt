// ============================================================================
// 128字节候选容器：局部契约
// ============================================================================
// 6B8C50：begin!=0时(end-begin)算术右移7，否则0；6B8E00同理取capacity。
// 容器要求begin<=end<=capacity_end且差值为128倍数；本函数不会验证这些不变量。
// 6B8E60输出begin迭代器；6B8EA0输出end迭代器；6B9920包装6B9A60写首DWORD。
// 6B8CB0由begin -> 6B91E0加index -> 6B91B0/6B99E0取指针，缺范围检查。
// 6B91E0实际thiscall且两个栈参数，伪码stdcall丢ECX；通过局部迭代器调用6B9960。
// 6B9960将迭代器DWORD加(index<<7)；6B9A90取两个迭代器差算术右移7。
// 6B9990包装差值；这些是地址运算，不检查有效对象或数组边界。
//
// 追加与复制
// ----------------------------------------------------------------------------
// 6B8D20若size<capacity：向end复制1条并把end设为返回的新尾；否则走6B8EE0。
// 6B9100调用6BA210复制，再返回dest+128*count；它不分配目标空间。
// 6BA210从6BA5C0取AL标签，再将dest/count/source/上下文/标签五个栈值传6BA620。
// 6BA5C0仅返回调试填充值0xCC；不应从误反编译推导业务布尔判断。
// 6BA620正常循环每次调用6BA800 -> 6BA970，以同一source复制count份，dest每次+128。
// 6BA970做placement new(128,dest)，非null时rep movsd复制32个DWORD。
// placement返回null时跳过复制，但6BA620/6B9100外层仍推进dest或计算新尾，不能解释为安全失败。
// 正常复制需要DF=0、源128字节可读、目标可写；本函数无cld，无范围及重叠保护。
// count是unsigned循环门；把负数当参数会解释成极大数量，不能当无操作。
// 异常路径按已构造范围调用60FF36销毁并重新抛出，依赖未全审，记部分分析。
//
// 满容量插入：保留部分分析
// ----------------------------------------------------------------------------
// 6B8EE0计算插入相对begin的位置，调用6B92E0插入1条，再重建输出迭代器。
// 6B92E0先复制source128字节到局部，避免正常插入覆盖借用源，再检查size上限。
// 容量足够时分两种尾部数量路径移动/填充；空间不足时约1.5倍增长，并至少容纳size+count。
// 更新begin/end/capacity_end前调用复制、析构、释放依赖；异常尾块及分配失败未闭合。
// 因此不把本专题写成通用vector的完整替代实现，也不认定插入过程永不丢失数据。
// IDA的COleSafeArray::ResizeOneDim自动名错误；此处处理固定128字节条目容器。
