// 6AA530与6AA450：随机起点后顺序环筛选
// ============================================================================
// 600F36 -> 6AA530；已知调用点62523B(625070)、74055B(740000)，仅核导航字节。
// 6AA530每次先timeGetTime再srand，即使模式/尺寸无效也先重置随机状态。
// a2==0由629DD0判定选CM；a2==1由629DF0判定选PK；a2==4由629E10判定选KO。
// a3==0/1/2分别选SMALL/BIG/ALL；其它模式或尺寸正常返回0。
// 不将数值枚举擅自翻译成完整玩法规则；名称CM/PK/KO来自资源节。
// 每个有效分支rand() -> 容器count -> signed idiv，余数为初始索引。
// srand/rand局部范围契约见随机数专题；模型使用0..32767，不声称真实种子均匀。
// count==0前无局部门检查，idiv会有除零风险；未证明现有菜单能走到此状态。
// 相同毫秒种子可重复同一路径的初始抽样，跨系统线程状态影响需复用CRT契约。
//
// 6124D4 -> 6AA450；ECX=R，两个栈参数为start和目标容器，retn8。
// 先取start条目，调用6041C2 -> 6AAA80；AL!=0则返回容器内部条目指针。
// 拒绝后按索引递增，达到count-1则回0，回到原start才结束并返回0。
// 正常前提count>0且0<=start<count；每条最多访问一次，最多访问count条。
// 无空列表/索引越界保护；非法起点下不能沿正常前提宣称必定终止或安全读取。
// 返回值是借用容器条目，重分配后地址可能失效；不是新分配的字符串。
//
// 概率与验证
// ----------------------------------------------------------------------------
// 拒绝后不再次rand。假设四条可用性为[真,假,假,真]、起点等概率，结果0占1/4、3占3/4。
// 因此调整候选排序会改变最终概率；ALL顺序不是无关紧要的展示顺序。
// rand()%count本身还可有模偏差；32768不能整除9/22/25/26等现有数量。
// 证据/model.py枚举count1..9、全部可用性组合和全部起点，共8194例。
