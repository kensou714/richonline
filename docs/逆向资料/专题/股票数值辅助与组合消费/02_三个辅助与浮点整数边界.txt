// ============================================================================
// 股票数值辅助 / 三个辅助的ABI与浮点整数边界
// ============================================================================
// 以下u32表示DWORD按无符号解释，low32表示只取低DWORD；不是32位饱和转换。
// R=this；n是一个栈DWORD槽；三helper均ret4，由callee清该参数槽。
//
// A(R,n)=6C1C80 / 123字节、38指令
// ----------------------------------------------------------------------------
// 6C1CA0取n；清EDX后DIV100，得到q=u32(n)/100，整除余数没有使用。
// 将q存qword低DWORD、高DWORD写0，再FILD signed qword；因此输入零扩展，
// 不是signed DWORD FILD。q最大42949672，DIV除数固定非零且EDX=0。
// 6C1CB9 FSTP dword保存到float32临时，再FLD临时；该窄化在乘法之前。
// 6C1CC2 FMUL float32[R+33C]；乘积留在x87中，没有额外FSTP32后再转换。
// 6C1CC8经60C4C6→922798；只取EAX低32，EDX高32被本体忽略。
// 最后CMP与[R+340]使用JBE：转换低DWORD<=下界则返回下界，否则返回转换低DWORD。
// 即unsigned max；相等返回字段下界，其位值相同。没有失败标志或有效范围门。
//
// B(R,n)=6C1D00 / 123字节、38指令
// ----------------------------------------------------------------------------
// 与A同输入、DIV100、零扩展qword、FSTP32、FMUL、转换和unsigned max次序。
// 唯一局部数据差别是系数[R+344]、下界[R+348]；不是正负两种除法或不同舍入方式。
// 6C1D48同样只消费922798的EAX；ret4。
//
// C(R,n)=6C1D80 / 29字节、10指令
// ----------------------------------------------------------------------------
// 不读取n，直接返回DWORD[R+34C]；依然ret4，忽略参数不代表调用者可省掉槽。
// 无内部调用、无NULL/类型检查，也不按参数变化产生分段或百分数结果。
//
// 922798 / 历史窄运行库契约，117字节、37指令
// ----------------------------------------------------------------------------
// ST0输入、EDX:EAX整数结果；无栈参数。副本FISTP qword后FILD重新加载整数，
// 原浮点减所得整数形成残差，按符号与残差位型用ADC或SBB修正两个DWORD。
// 普通有限且可转换输入的局部指令支持向零截断；本体未写x87控制字。
// 低DWORD为0时另测高DWORD去符号位，特定路径用两次FSTP清x87栈。
// 不照IDA标签给所有特殊值命名，也不把该运行库机制登记成股票业务。
// NaN、Inf、超64位可表示范围、异常掩码或陷阱行为没有运行验证。
// invalid被掩码时的integer-indefinite位型只是条件路径，不是本项目统一错误码。
// 旧原证来自高扇入界面操作辅助/证据/dependency_raw.json#/functions/2；
// 当前PE117字节已核一致，未额外采证或认领新函数覆盖。
//
// 使用及复刻边界
// ----------------------------------------------------------------------------
// n低于100时q=0，而不是保留n/100的小数；若系数为普通有限数，通常转换部分为0，
// 最终仍由unsigned下界决定；0乘NaN/Inf不适用此普通数示例。
// q超过float32连续精确整数范围时FSTP32可丢精度；如q=16777217在nearest环境
// 可存成16777216。不能删除此临时窄化，再声称与原算法逐值等价。
// FSTP32与FMUL受x87环境影响；本批没有记录运行时控制字/精度/异常mask初值。
// 负系数产生负整数后，low32被作为unsigned比较，可能呈很大值，不是负数钳到零。
// 高32丢弃使超32位结果回绕；unsigned max不是饱和，不保证单调或数值经济含义。
// 七本体未建立特殊输入错误码；资源缺项/坏系数的实际呈现须先闭字段producer再实测。
