// ============================================================================
// 股票数值辅助 / 四个比较函数的参数矩阵
// ============================================================================
// A/B/C见02；add32、mul32只保留低32位。a、b均直接记录指针，两个DWORD栈槽。
// 四本体不保存入口ECX为this，返回RET无立即数，由caller负责两个参数槽。
// 比较算术在CMP/SBB/NEG后使EAX为0或1；尾部栈诊断异常与真实回调执行另列未知。
//
// 第一对：6C08B0、6C0960 / 各175字节、61指令
// ----------------------------------------------------------------------------
// 为每个r取n(r)=mul32(DWORD[r+1C],DWORD[r+10])。
// S(r)=add32(A(R,n),B(R,n),C(R,n))；第三项无条件加入，不根据r的+4门控。
// 6C08B0：先S(a)到ESI、S(b)到EDI；CMP ESI,EDI后SBB EAX,EAX、NEG EAX。
// 产生unsigned S(a)<S(b)的0/1；相等产生0。
// 6C0960仅交换CMP方向为EDI,ESI，产生unsigned S(a)>S(b)的0/1。
// 同一R在入口取一次；每个分数独立调用A、B、C，不缓存本体字段一致性快照。
//
// 第二对：6C0BF0、6C0CE0 / 各226字节、79指令
// ----------------------------------------------------------------------------
// 为每个r取n(r)=mul32(DWORD[r+C],DWORD[r+8])。
// S(r)=add32(A(R,n),B(R,n))，仅r+4 DWORD等于1或2时再add32 C(R,n)。
// a与b分别判断自己的+4；不是一个参数的标签同时控制两分数。
// 6C0BF0产生unsigned S(a)<S(b)；6C0CE0产生unsigned S(a)>S(b)。
// 相等均产生0；0BF0/0CE0没有改变比例辅助内部的字段或舍入规则。
//
// 调用点矩阵 / VA为真实callsite
// ----------------------------------------------------------------------------
// 08B0 a：A@6C08FC B@6C090A C@6C0918；b：A@6C0926 B@6C0934 C@6C0942。
// 0960 a：A@6C09AC B@6C09BA C@6C09C8；b：A@6C09D6 B@6C09E4 C@6C09F2。
// 0BF0 a：A@6C0C3A B@6C0C48 C@6C0C8A；b：A@6C0C59 B@6C0C67 C@6C0CAE。
// 0CE0 a：A@6C0D2A B@6C0D38 C@6C0D7A；b：A@6C0D49 B@6C0D57 C@6C0D9E。
// A经610468→6C1C80；B经60D263→6C1D00；C经605CE3→6C1D80。
// 桥是5字节E9，不是额外数值运算函数；全部callsite、桥与当前字节独立核验。
//
// 合作者应保留的约束
// ----------------------------------------------------------------------------
// 此接口是方向谓词，不是qsort式负/零/正三态；不能把EAX0解释成必然相等。
// unsigned比较由CMP进位CF消费决定，不能由伪码int类型误写signed排序。
// 分数加法可回绕；两项各有unsigned下界也不能推出总分总大于每项。
// 第一对常量第三项同时加两侧，回绕仍可改变unsigned大小关系，不能随意约去常量。
// 不检查参数/R为空、记录已释放、字段合法范围，也没有快照/锁或稳定排序保证。
// 91F6D0是编译器栈诊断依赖，不给它股票含义；实机异常分支尚未运行验证。
// 本批恢复局部算术与ABI，真实消费方的排序方式、方向按钮及所有回调触发尚未闭合。
