// 岔路入口：6080阶段6 -> 7CB050
// ----------------------------------------------------------------------------
// 7CB050在其他回合效果处理后，读取当前格与方向。
// 7E1BD0确认可走邻居>2；角色不处于两类禁止状态且不是特殊参与者，才插本地608E。
// 部分地图/模式分支可直接跳过；不能将每个几何分岔都视作必定弹选择窗。
// 608E=681EF0：当前槽等于本地槽时打开UI31，期限6000，传入空参数；
// 无论本地与否均安装等待编号22、期限6000。UI31路径G_SelectDir.ui见界面系统导航。
// 这里没有新的服务端“岔路请求”入站号；分岔判断由本地回合阶段产生。
//
// 四方向按钮与取消
// ----------------------------------------------------------------------------
// 719540为控件1..4注册选择回调；7195D0逐方向检查目标地形可走性。
// 不可走方向按钮被禁用；再将当前方向的反方向按钮禁用，即便那一格可走。
// 7197D0以控件ID-1作为方向调用7BC320；因此按钮1..4对应方向0..3。
// 719750在游戏外层状态2时接受Esc或另一输入谓词，提交-1并清交互等待。
// 7BC320构造6字节上行：+0 WORD=0034、+2 WORD=G+3144低16位、+4 BYTE=方向。
// 仅当前槽等于本地槽才送出并关闭UI31；第5字节保留栈初始化0xCC，是填充字节。
// 0..3或-1表示合法客户端选择域，服务端仍需独立验证方向与当前可走邻居。
//
// 方向广播：401F -> 65E850
// ----------------------------------------------------------------------------
// +2 WORD校验GmsvID，+4 signed BYTE为角色槽，+5 signed BYTE为方向。
// 汇编65E891..65E89F用包+4选择G.roles[slot]，再调用7F7940。
// 7F7940写R+1460并同步R+864子对象的方向；此处理器本身不校验0..3或角色槽边界。
// 401F不在此函数启动移动、不安装新路线、不清交互等待；后续需有相应回合消息。
//
// 投资入口：4012 -> 65DAA0
// ----------------------------------------------------------------------------
// +2 GmsvID，+4 int16位置，+6 BYTE控制标志；直接字段最低访问7字节。
// 当+6非0且位置!=当前格，复制原8字节4012重新排队，等待角色真正到格。
// 否则G+83833=+6；若当前槽等于本地槽，打开UI43 G_Invest.ui，期限8000。
// 然后安装等待编号27、期限8000。这里的+6不是方向，也不是骰子个数。
// 71F9D0键盘确认/取消提交1/0；71FA70控件ID1/2同样提交1/0。
// 7BC600构造6字节上行：+0 WORD=002B、+2 WORD=G+3144低16位、+4 BYTE=布尔选择；
// 只在当前槽等于本地槽时发送并关闭UI43。第5字节同样保留初始化0xCC，无业务语义。
//
// 静态9对应的另一途中等待
// ----------------------------------------------------------------------------
// 4018=65E1B0结构与投资类似：位置不符且标志非0则重排原8字节；
// 到格后G+83832=标志，当前本地槽打开UI17，安装等待16、期限8000。
// UI17为G_Bank.ui，来自界面系统导航；其存取款具体字段不在本轮闭合范围。
// 不应将银行等待16、投资等待27和岔路等待22统一成一个响应处理器。
//
// 自动选择的时间条件不能误读为窗口期限
// ----------------------------------------------------------------------------
// 7BB530是另一自动操作入口，需消费抑制位为0、模式条件、**(G+52)!=0，
// 并且7D5D20要求等待编号!=-1且从等待开始已过1000ms。
// 该判据没有比较G+83792；因此自动模式的触发时间不能直接写成6000或8000ms。
// 等待22提交方向-1；等待27提交rand()%100>15的布尔值。发送后本地槽清等待。
// UI通用生命周期如何在非自动模式到期时触发回调，本轮未穷尽，留作明确未闭合项。
