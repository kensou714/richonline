// KPD容器
//
// 实现已核实：第1字节是减法偏移量；余下字节逐字节减去它。
// 解混淆后前两个小端DWORD分别为解码长度和压缩长度。
// 其后为LZO压缩数据；当前实现通过lzokay执行解压。
// 必须检查长度、解压返回值和最终实际字节数，不能截断后继续解析。
// 通用读取默认文本预算4MiB，地图解码可用更高的显式预算。
// 最大支持解码预算64MiB属于当前实现限制，不是格式固有上限证明。
// 文本解析前保留原始字节；历史资源文字可能存在混合编码。

// EMP地图容器
//
// 当前解析器读取偏移16的版本DWORD，仅接受1至3。
// 版本决定元数据长度；地图压缩块位于固定头及版本字段之后。
// 宽高必须非零，当前实现要求总格数不超过32768。
// 解码载荷依次跨过背景、地形记录、装饰、类型和地产记录。
// 地形文件记录步长64，装饰步长36，地产文件记录步长88。
// 客户端运行时地产步长68，不可直接拿文件步长索引运行时结构。
// 数据块截断或数组计数越界应作为资源错误拒绝。

// BS_1_1实例
//
// 静态档案记录Map/BS_1_1.emp为版本3、模式3、地图ID11。
// 尺寸16乘18，解码载荷46452字节。
// 档案记录SHA-256：
// 841d2e09abb60b2ce344c816c3c13c8d48a1d63ca674a98ae440be5c0428c55c
// 这些是已归档资源证据；更换资源后要重新计算指纹并核实字段。
// 行走判据来自地形有符号字节不等于-1；服务端还需验证地图边界。
// 左右移动不能跨行绕回，方向不能只靠整数加减判为合法。
// 地图中两个格子可以指向同一地产，位置不是地产唯一标识。
// 已核实地形231、232共同指向地产216。

// 地图与关卡选择
//
// BossWar记录包含mapIndx和mapName，分类决定使用哪张BOSS表。
// 分类2选择BossWar_v；其他已追踪分类走BossWar。
// BS_1_1与V_BS_1_1可以同为地图ID11，不能仅按数字ID取配置。
// 地图模式、资源ID、房间分类、BOSS序号是独立字段域。
// 人类房间容量1仍可对应棋盘参与槽2：另一槽是合成BOSS。
// BOSS序号只在合成参与者间递增，不等于绝对槽位。

// 初始数值
//
// BS_1_1地图提供人类基础现金20000、存款0、票券150。
// BossWar提供BOSS基础现金100000；初始化分支保留存款和票券为0。
// 装备效果可能改变最终现金，不能把基础值当成所有账号最终值。
// 档案中“人类现金20000”的无加成结论要求32个资料槽全为0。
// 地图scale为1，Option.kpd的priceBase为10，两者不可互换。
// 当前普通地产价格由地产单位价格乘priceBase得到。

// 建筑映射
//
// 种类    资源键    名称        许可证物品    BS_1_1上限
// 11      Yan       研发中心    509           5
// 12      Pao       飞弹基地    510           5
// 13      Chang     长城        511           5
// 14      Zhong     图腾柱      512           5
// 15      Kong      空中花园    513           0
// 16      Mi        金字塔      514           5
// 17      Ba        巴比伦塔    515           0
// 18      Shan      山海关      516           0
// 19      Zhao      召神台      517           0
// 20      Shou      狩猎所      518           0
// 当前关卡默认11免许可证；其他合法首次建造需要对应许可证。
// 上限0的类型在当前关卡不开放，不能用全技能7绕过。
// 技能、关卡上限、物理写入硬上限必须分别保存和验证。
