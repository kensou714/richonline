// 操作码命名空间
//
// 大厅外层wire/type使用十进制，例如22、58、759。
// 游戏外层type使用十进制，例如0、1、299。
// 游戏内层opcode使用十六进制，例如0x0011、0x403E。
// 本地事件使用明确的“本地”前缀，例如本地0x6070。
// 日志可能以十进制输出内层opcode，引用时需注明转换。
// 例如十进制55是0x0037，十进制16446是0x403E。
// 不可将大厅wire22、游戏type22和内层0x0022视为同一消息。
