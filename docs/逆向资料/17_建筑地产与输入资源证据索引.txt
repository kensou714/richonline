// M+46C容器的count只读一次，M+478槽给WORD数组；候选经MOVSX转signed16地产编号r。
// 地产R(r)=DWORD[M+38]+68*r；+00类型、+01子型、+02等级、+03归属均按signed BYTE消费。
// 五搜索返回r或-1，不返回循环下标；不排序、不随机、不读金额或按距离评分。
// 7E4660筛类型11/子型0/自己所有；7E4750筛类型12/自己所有，并显式排除传入地产编号。
// 前两要求等级严格小于threshold，同值保留最先者；0或负等级只要满足比较也未被排除。
// 7E4830/7E4930/7E4A30分别筛类型11子型0、类型11子型1、类型12，并要求0<L<=threshold。
// 后三同值允许覆盖，稳定合法域下留下最后出现的最低合格等级候选，不是最高等级。
// 7E4750是三DWORD参数，其余四入口是两DWORD；7C9049须结合扩展旧窗口读取提前压栈。
