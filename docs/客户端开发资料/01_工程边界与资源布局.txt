// 可构建边界
// ----------------------------------------------------------------------------
// ../admin/RichOnline.Admin.csproj 构建 RichOnline.Admin.exe。
// 工程目标 net8.0-windows，使用 Windows Forms，启用可空引用和警告即错误。
// ../native-server 是当前 C++ 服务端共享源码；管理器通过本地管理接口操纵它。
// RnClient.exe 是原始游戏二进制，当前资料不提供其完整源码工程。
// IDA 伪代码可以解释局部行为，不能作为可重新编译客户端的源码承诺。
//
// 当前版本与历史兼容代码
// ----------------------------------------------------------------------------
// 当前只以 richonline 配置、新版繁体客户端和 Big5／CP950 账号编码为开发目标。
// 上级旧客户端已弃用；共享源码中的 original 兼容分支不属于当前维护范围。
// 枚举映射见 ../admin/ClientProfile.cs，界面说明见 ../admin/MainForm.cs。
// 当前启动固定选择 richonline，不要因共享源码保留枚举就切换到旧客户端。
// 未标记迁移库的编码登记不会转换已有密码，也不会自动重建账号。
// 采用旧库前需要明确其来源；切换版本选项本身不是迁移流程。
//
// 原始运行目录
// ----------------------------------------------------------------------------
// RnClient.exe                  新版游戏程序
// Config/                      原始客户端配置和 KPD 文件
// Data/                        游戏数据资源，如 Build、BossWar、Role
// Map/                         EMP 地图资源，如 BS_1_1.emp
// Interface/                   UI 资源，如 G_SelectBuild.ui、G_UpvLand.ui
// Avatar/                      角色外观资源
// Tex/                         图像资源容器
// Music/、Sound/                音乐和音效资源
// CoreDump/                    已存在的客户端转储文件
//
// 这些名称用于定位文件，不构成对所有内部格式的证明。
// 例如发现 G_SelectBuild.ui，不足以证明哪个网络消息一定显示该窗口。
// 字段语义仍需沿资源读取、处理函数、显示回调逐段确认。
//
// 开发与运行文件分离
// ----------------------------------------------------------------------------
// RnClient.exe.i64 及 id0、id1、id2、nam、til 属于逆向数据库或相关分析文件。
// 它们不是客户端正常游戏运行所需的发布内容，也不是源码替代品。
// RichOnline.Admin.launch.json 是管理器旁置启动配置，记录所选程序与数据位置。
// native-data 和运行目录中的 SQLite、WAL、锁文件属于实例状态，不是资源模板。
// 发布管理器时不要把开发数据库、抓包、转储和私人测试账号混入程序包。
//
// 启动资源与旧补丁器
// ----------------------------------------------------------------------------
// iniurl.ini、patch.ini、script.ini 保留历史补丁来源配置。
// 原始补丁 URL 的存在不代表现在可用，也不属于本地服务启动契约。
// 本地管理器调用 RnClient.exe 和已验证的 local.kpd，不通过 RichPatch.exe 更新。
// 维护通信时先保持原始资源不变，避免协议修改与资源替换混成一个变量。
//
// 管理器发布
// ----------------------------------------------------------------------------
// 在当前 Richonline 根目录执行以下命令，可输出 Windows x64 自包含管理器：
// dotnet publish ../admin/RichOnline.Admin.csproj -c Release -r win-x64 --self-contained true -o ../admin/publish
//
// 单文件发布增加以下参数，输出目录使用独立位置：
// -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
//
// 自包含发布无需用户另装 .NET；普通框架依赖发布需要 .NET 8 Desktop Runtime。
// 发布成功只证明管理器构建成功，不证明 RnClient.exe 能登录或完成一局。
//
