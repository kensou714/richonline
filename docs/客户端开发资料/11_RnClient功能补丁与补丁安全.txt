// 补丁目标
// ----------------------------------------------------------------------------
// RnClient.exe 没有可重新构建的完整客户端源码；功能补丁属于二进制维护，
// 必须以当前文件 SHA-256、映像基址和原始字节为前提，不能沿用上级旧客户端地址。
// 优先使用资源替换、配置调整或服务端兼容修复；只有客户端确实拒绝内容时才评估补丁。
// 资源补丁与代码补丁分开提交和回归，避免把通信缺包误判为客户端逻辑缺陷。

// 当前版本证据
// ----------------------------------------------------------------------------
// 当前 RnClient.exe SHA-256：
// CB35F69F3D49C2093897D4EA2CB547A1E38B213F3A8DF0AF52B859F9E661DE77。
// IDA 映像基址为 0x400000；地址必须同时记录 RVA、映像地址和函数上下文。
// 任何发布补丁前重新计算哈希；哈希不一致时停止应用旧补丁并重新取证。
// IDA 数据库文件、补丁脚本和临时输出不放入客户端发布目录。

// 值得优先研究的候选
// ----------------------------------------------------------------------------
// 资源加载入口：0x623CB0 依次初始化文本、动画、道具、角色、BOSS、界面等资源。
// 音频装配入口：0x69A3C0 设置 Sound/，访问 snd%04d.dat 和 mus%04d.dat。
// 地图列表入口：0x6A9530 读取 Data\\MapList.kpd 的 XIN_MAP/item%d 记录。
// 界面索引入口：0x6E2F70 读取 Intf.kpd 的 INTF/indx/file 及显示属性。
// 地图路径入口：0x7DED90 生成 Map\\%s；它不能单独证明 EMP 字段已经可编辑。
// 这些入口适合记录调用关系、失败处理和资源依赖；不应直接改写其机器码。

// 补丁候选的多维度评选
// ----------------------------------------------------------------------------
// 价值一：能解除明确的内容限制，例如资源编号、地图列表或界面索引上限。
// 价值二：能复用到多个地图或资源，而不是只修复单个样本的偶然偏移。
// 价值三：静态证据能看到比较、分支和错误处理，且有可构造的成功/失败样本。
// 风险一：补丁影响初始化、线程、内存边界、文件格式或通信状态时，默认高风险。
// 选题记录同时填写收益、复用范围、证据强度、验证成本和回滚难度。

// 安全取证步骤
// ----------------------------------------------------------------------------
// 1. 复制 RnClient.exe，计算原文件哈希，保存 PE 节区、入口点和目标函数反汇编。
// 2. 用 IDA-MCP 记录目标函数的调用者、被调用者、字符串引用、读取字段和失败分支。
// 3. 先构造资源或配置层面的最小样本，确认问题不是服务端回包或资源缺失。
// 4. 记录原始字节、替换字节、文件偏移、RVA、映像地址、指令长度和跳转落点。
// 5. 在隔离副本中启动，完成登录、大厅、棋盘、目标功能、退出和崩溃转储检查。
// 6. 对照未打补丁原版重复同一操作；只要行为差异无法由目标功能解释就回滚。

// 不允许的做法
// ----------------------------------------------------------------------------
// 不把 IDA 伪代码中的变量名直接当作正式字段，不以单个字符串引用推断完整格式。
// 不在运行中的唯一客户端上写补丁，不覆盖原始文件，不删除转储和日志来掩盖失败。
// 不使用旧客户端地址、旧包长或网上未知来源的通用补丁；不把 VirtualProtect、
// LoadLibraryA 或 CreateThread 的导入存在本身写成“客户端支持热补丁”。
// 不把资源可解析、程序能启动或服务端测试通过写成客户端补丁已实测。

// 交付格式
// ----------------------------------------------------------------------------
// 补丁记录必须包含：目标哈希、目标功能、证据地址、原始/新字节、应用工具版本、
// 资源与服务端前置条件、成功场景、失败场景、回滚步骤和未覆盖条件。
// 可发布补丁另存校验和与版本匹配清单；不把账号、令牌、私有路径写入脚本。
// 未完成真实客户端回归时，状态只能写“静态候选”或“隔离启动验证”，不能写“可用”。
