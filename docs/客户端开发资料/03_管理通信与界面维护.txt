// 通信边界
// ----------------------------------------------------------------------------
// 管理器通过当前用户命名管道连接本机服务，每次请求建立一条连接。
// 管道通信使用 UTF-8 JSON；它与 RnClient.exe 的游戏 TCP 加密协议完全独立。
// C++ 服务端是数据库写入者，管理器只提交管理命令，不直接改 SQLite。
//
// 一帧的布局
// ----------------------------------------------------------------------------
// 偏移 0：四字节小端正文长度。
// 偏移 4：正文 JSON，最大 65536 字节；空响应帧被拒绝。
// 请求字段：version、requestId、command、payload。
// 成功响应：匹配 version 和 requestId，ok 为 true，result 为对象。
// 失败响应：error.code 和 error.message 转成 ControlException。
//
// SendAsync 对连接、写入和读取使用同一个 5 秒取消期限。
// ReadExactlyAsync 读取完整头部和正文，不能把一次底层读取等同于一帧。
// 请求标识用于关联本次结果；不能删除校验，只因某个手工响应缺了字段。
//
// 界面线程
// ----------------------------------------------------------------------------
// 服务输出和进程退出事件可能从后台线程触发。
// 普通控件更新通过 Post 投递到有效窗口句柄；日志只进入并发队列。
// RunUiAsync 用 busy 状态阻止重叠的管理命令，并在结束后恢复按钮状态。
// 不要在输出回调中直接修改控件，也不要通过同步等待冻结界面消息循环。
//
// 日志容量
// ----------------------------------------------------------------------------
// ServerProcess 分块读输出，单行最多保留 64 KiB，超长行发出截断说明。
// LogsPage 的待处理和历史队列分别限制为最近 2000 行。
// 界面每 200 毫秒最多消费 500 行，然后按当前级别筛选重绘。
// “暂停展示”仍然消费并裁剪队列；恢复展示不意味着能看到期间的全部日志。
// 界面列表便于操作观察，完整通信证据应读取数据目录下的日志文件。
//
// 账号编辑
// ----------------------------------------------------------------------------
// accounts.list 每次请求最多 100 条；搜索框只筛选当前已加载页。
// 编辑时克隆所选账号快照，提交 expected、changes 和修改原因。
// 过期快照交给服务端拒绝，避免静默覆盖其他协作者的更新。
// 金额按固定区域格式解析，支持有限小数；等级等字段使用整数。
// 创建密码仅用于请求，输入框立即清空；账号表与日志不展示创建载荷。
// 脱敏不是简单隐藏输入框，新增日志时也必须避免输出密码正文。
//
// 配置与备份
// ----------------------------------------------------------------------------
// config.get 返回 settings 和 revision；保存提交 expectedRevision。
// 保存失败不清空编辑框，操作者可以保留输入并核对版本差异。
// 备份使用 database.backup，界面展示服务实际返回的路径。
// 配置保存成功不代表尚未实现的游戏功能已经生效。
//
// 维护验证入口
// ----------------------------------------------------------------------------
// --self-test SERVER_EXE EMPTY_TEST_DATA_DIR richonline
//     使用空目录验证真实管理接口；具体执行参数见 ../admin/ControlTests.cs。
// --log-self-test OUTPUT_JSON
//     在隔离控件实例中验证日志队列边界，不代表真人操作帧率已验收。
// --render-diagnostics OUTPUT_DIR
//     从控件绘制布局诊断图片；不是操作系统截图或人工交互验证。
//
