// 资源现状
// ----------------------------------------------------------------------------
// Music/ 当前有 19 个 mus%04d.dat，合计约 39.8 MiB；文件头为 ASCII "mus%"。
// Sound/ 当前有 44 个 snd%04d.dat，合计约 87.4 MiB；另有 mssmp3.asi、msssoft.m3d 两个 Miles Sound System 组件。
// RnClient.exe 的静态证据：0x69A3C0 调用 AIL_set_redist_directory("Sound\\")；
// 0x6049D3 按 Sound\\snd%04d.dat 访问音效，0x6030E2 按 Music\\mus%04d.dat 访问音乐。
// 当前 RnClient.exe SHA-256：CB35F69F3D49C2093897D4EA2CB547A1E38B213F3A8DF0AF52B859F9E661DE77。
//
// 格式边界
// ----------------------------------------------------------------------------
// mus 文件样本头：mus% + 小端字段，偏移0x1C出现 ID3 标识；这只证明文件包含可识别音频元数据，
// 不证明可把任意 MP3 直接改名替换。snd 文件样本头：snd% + 小端索引/偏移字段，内部音频编码尚未完整还原。
// 不要手工改写头部偏移，不要把 mus 与 snd 互换，也不要删除 Sound 目录下的运行库。
// KPD 的逐字节减法 + LZO 规则不适用于 mus/snd，除非另有针对该格式的静态证据。
//
// 推荐工作流
// ----------------------------------------------------------------------------
// 1. 复制整个 Music/或 Sound/到隔离工作目录，记录原文件 SHA-256、大小和前16字节。
// 2. 先做只读识别：确认编号、容器头、索引范围和音频时长；无法识别时保留原文件。
// 3. 只替换同一编号、同一容器类型、满足原索引容量的资源；发布前恢复目录结构。
// 4. 启动管理器，进入大厅、棋盘、移动、落地产权、结算等场景逐项播放并观察日志。
// 5. 任一资源导致启动崩溃或无声，立即用备份回滚，不要同时修改通信或地图。
//
// 可接受的当前变更
// ----------------------------------------------------------------------------
// App.ini 的 Sound/Music 开关和 SndVol/MusVol 音量字段已在当前文件中确认；
// 修改这些字段只能验证开关和音量，不等于完成容器替换。
// 静态证据已确认目录和编号模板；编号到具体事件的映射、循环/淡入淡出和采样率限制为待验证。
// 0x8245E0 与 0x81F950 使用 44100 Hz、16 位、双声道初始化输出设备。
// 这是播放设备设置，不是输入资源格式限制；snd 初始化的 20 是播放句柄数。
// 不应据此把资源编号限制为 0 至 19，也不能把全部音频强制转成同一种编码。
// Voice.dat 由 0x69AAA0 读取，VoiceFace.kpd 由 0x69AC60 读取 role/face%d。
// 为角色新增语音时需要同时维护编号和表引用，具体事件映射仍需逐场景取证。
//
// 回归清单
// ----------------------------------------------------------------------------
// 启动、登录、大厅背景音乐、进入棋盘、骰子/移动音效、建筑选择、回合结束、退出。
// 每次只改一个文件；记录无声、错音、爆音、延迟、崩溃及最后一条客户端日志。
