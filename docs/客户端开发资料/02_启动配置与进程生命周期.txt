// ============================================================================
// 启动配置与进程生命周期
// ============================================================================
// 核对日期：2026-10-09；路径相对当前项目根目录 Richonline；../ 指向共享源码所在上级。
//
// 配置覆盖顺序
// ----------------------------------------------------------------------------
// 默认值先建立，再读取管理器旁的 RichOnline.Admin.launch.json，最后处理命令行。
// 后一层覆盖前一层；配置文件的相对路径相对管理器目录解析。
// 命令行相对路径由 Path.GetFullPath 按进程当前工作目录解析，二者不要混淆。
// 配置只接受已知键、非空字符串，拒绝重复键和未知键。
//
// 支持键名
// ----------------------------------------------------------------------------
// server          C++ 服务端完整路径或可解析的相对路径
// data-dir        服务实例独立数据目录
// client          所选 RnClient.exe
// client-config   已验证的客户端 KPD 配置
// client-profile  当前项目固定使用 richonline；original 仅为共享源码历史分支
//
// 未提供旁置配置时，默认服务路径为管理器目录下 server/RichOnline.Server.exe；
// 默认数据目录为 native-data，默认客户端为 RnClient.exe；
// 默认配置为 local-server/fixtures/local.kpd，默认版本为 richonline。
// 当前项目使用 Richonline 内的这份本地配置，不改用上级旧客户端的启动文件。
//
// 当前工作区快照
// ----------------------------------------------------------------------------
// RichOnline.Admin.launch.json 当前指向：
// ../local-server/runtime/native-boss-live-20261009/RichOnline.Server.channels.exe
// 数据目录为同一 runtime/native-boss-live-20261009。
// 这是 2026-10-09 读取到的配置，不是固定发布路径；运行前以实际文件为准。
// 不能根据 server/ 中有某个 exe 就认定管理器正在使用它。
//
// 游戏启动
// ----------------------------------------------------------------------------
// ClientLaunch.Prepare 将工作目录设置为 RnClient.exe 所在目录。
// 第一个参数是配置的相对路径，第二个参数是区域编号。
// 配置参数过长、含空白、非 ASCII 或引号时，复制到专属 ASCII 子目录。
// 副本形如 richonline-admin-launch/<随机标识>/local.kpd，保留原文件字节。
// 不覆盖原 KPD；副本保留供客户端后续读取，也不会隐式启动或重启服务。
// 当前 local.ini 示例把登录与服务列表 HTTP 指向本机 18680。
// 实际启动传入 local.kpd；不能只改 local.ini 就声称客户端读取了新配置。
//
// 服务启动与就绪
// ----------------------------------------------------------------------------
// ServerProcess 生成本实例独立管道名，并传入数据目录、管道和客户端版本。
// 同时读取标准输出与标准错误，以免子进程因输出缓冲区填满而阻塞。
// 15 秒内等待 ready 公告，随后主动请求 status。
// PID、instanceId、pipe、protocolVersion、clientProfile 与运行状态都必须吻合。
// 启动失败会回收本次创建的服务进程，保留可用的结构化失败原因。
// 管理就绪、端口监听正常、游戏流程可用分别显示，不能互相替代。
//
// 服务停止与窗口关闭
// ----------------------------------------------------------------------------
// 正常停止先发送 stop 请求，再等待服务退出；8 秒超时后回收所持有进程树。
// 关闭管理器窗口会先等待自有服务清理，随后真正销毁窗口。
// OwnedJob 使用关闭作业句柄时终止进程的策略，约束管理器所拥有的服务实例。
// 用户正在执行管理操作时，窗口关闭被暂时拒绝，避免中断编辑中的操作。
//
// 结束客户端
// ----------------------------------------------------------------------------
// 先用进程名找候选，再用完整镜像路径确认是当前配置的 RnClient.exe。
// 路径无法核实的候选会跳过；不会仅凭同名终止另一套客户端。
// 先请求关闭主窗口，等待 3 秒；仍未退出则结束单进程，最多再等待 5 秒。
// 这项操作与服务是否在线无关，统计正常关闭、强制结束、失败和未核实数量。
//
