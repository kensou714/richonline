// 不能按 PNG/JPEG 处理，也不能仅凭扩展名推断可直接替换。
// Interface/ 当前有117个 .ui，另有 Intf.kpd 索引；G_SelectBuild.ui、G_UpvLand.ui 为待完整还原的二进制样本。
// IDA 静态证据：0x6E2F70 读取 Intf.kpd 的 INTF/indx/file 字段；这证明 UI 索引入口，
// 不证明单个 .ui 的字段布局。0x623CB0 位于启动资源加载链，具体资源依赖需逐项跟踪。

// 界面索引的可执行校验规则
// ----------------------------------------------------------------------------
// Intf.kpd 的重复 [INTF] 节按原顺序保留；indx 必须在0至159内，重复编号报冲突。
// 0x6E2F70 分配160项、每项132字节，indx直接参与索引，不能只改一个常量扩容。
// file 最多63个原编码字节；draw/dynPop/center/nadjust 与 true 精确比较。
// offsetX/offsetY 使用 atoi；free 的枚举含义尚未证实，不自动归一化。
// prev_0、prev_1… 和 dvs_0、dvs_1… 首个缺号就停止，依赖关系不能用无序字典合并。
// 上述是索引层约束；单个 .ui 的控件结构、命中范围和事件绑定仍需要独立取证。

// 图片资源工具的分层
// ----------------------------------------------------------------------------
// Tex 有19592个 .np 散文件；14个 .dat 并非全部图片资源，盘点必须包含子目录。
// 0x6D8130 读 ToolConfig.kpd 及类别映射；磁盘缺失某种文件时不能臆造模板补齐。
// 0x6DA7B0 另有 Item%s.tb 的4000字节读取和 Pack%s.npp 包句柄路径。
// 此路径的索引记录、图片编码、透明度与压缩尚未完整确认；先保留只读能力。
// build映射的10等级/10帧、role的4方向/100帧是视觉槽位容量，不等同于玩法等级上限。
//
// 安全编辑流程
// ----------------------------------------------------------------------------
// 1. 以资源文件为单位备份并记录 SHA-256、大小、编码和依赖索引。
// 2. 先替换一份同类型、同尺寸或已知兼容资源；禁止跨 Tex/Interface/Data 目录混用。
// 3. 保持 Intf.kpd 索引与实际 .ui 文件名一致；文件缺失时记录首个加载失败资源。
// 4. 启动、登录、大厅、棋盘和目标窗口逐层回归；界面异常时保留日志和转储。
// 5. 任何未知格式只做只读分析，不把猜测写成可发布编辑规范。
//
// 依赖与限制
// ----------------------------------------------------------------------------
// 资源修改可能改变界面文字长度、字体回退、按钮命中区和通信等待提示；客户端补丁与服务端回包必须分开回归。
