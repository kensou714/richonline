// 已核实该样本版本3、模式3、地图ID11、尺寸16×18，不能将这些值套到其他地图。
//
// 已知解析约束
// ----------------------------------------------------------------------------
// 解析器从偏移16读取版本DWORD，仅接受1至3；宽高必须非零，总格数当前不超过32768。
// 版本决定元数据长度，随后读取背景、地形、装饰、类型和地产记录；文件地产步长88，
// 客户端运行时地产步长68，二者不可直接混用。损坏、截断、计数越界必须拒绝。
// 地形有符号字节不等于-1是当前行走候选判据；左右移动必须检查行边界，不能只做整数加减。
// 两个格子可共享同一地产 ID；编辑地图时不能把位置坐标当作地产唯一键。
//
// 地图编辑流程
// ----------------------------------------------------------------------------
// 1. 复制 EMP，保留原始哈希；先用只读解码器导出版本、模式、ID、尺寸、地形和地产引用。
// 2. 编辑前检查 Data/MapList.kpd、BossWar.kpd、BossWar_v.kpd 与地图模式/分类的对应关系。
// 3. 变更拓扑后重新检查入口、可走性、边界、共享地产、事件格和初始落点。
// 4. 重新编码并做解码往返：编码结果必须可被当前解析器完整读回，尺寸和记录数一致。
// 5. 使用隔离服务数据目录测试启动、进棋盘、移动、地产事件和结算；失败即回滚。
//
// IDA 与运行时边界
// ----------------------------------------------------------------------------
// IDA 已确认 0x6A9530 读取 Data\\MapList.kpd 的 XIN_MAP/item%d；这只说明地图列表索引入口，
// 不说明 EMP 的全部字段或编辑工具格式。地图列表、BossWar 和 EMP 必须作为一组变更审查。
// 当前仓库没有已验证的官方 EMP 写回工具；直接十六进制改写属于高风险操作。
// MapList 的四节为 XIN_MAP、CHU_MAP、ZHONG_MAP、GAO_MAP。
// 每节从 item0 顺序读取，首个缺号即结束；新增 item2 前必须保留 item0、item1。
// 每个值的读取容量为 128 字节；公共读取器复制后才检查长度，编辑器应限制为127字节以内。
// 长度按原编码字节数计算；读取器还有运行时筛选，新增条目不保证必定显示。
// 本文步骤4是未来写回工具的验收要求，当前资料没有提供可直接使用的EMP写回命令。
//
