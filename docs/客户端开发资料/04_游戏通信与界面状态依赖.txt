// 对象仅为 RnClient.exe 新版，IDA 映像基址 0x400000。
// 以下地址来自已保存证据，本次文档整理没有新增 IDA 动态验证。
//
// 大厅初始化不是独立包的集合
// ----------------------------------------------------------------------------
// 新版分发器 0x87FD30 先读四字节 wire，再跳过四字节未明字段。
// 大厅文档的 payload 偏移从这八字节之后开始，不等同于整个传输帧偏移。
// wire3 创建对象；wire9 第二个 DWORD 用于查对象并保留当前上下文。
// wire7 经该上下文创建记录，记录 ID 必须与 self-id 关联一致。
// wire30 会访问此前保存的状态并调用当前对象的界面回调。
// 因此“每包长度正确”不能证明顺序、对象键、槽位和界面状态正确。
//
// 大厅事件在分发器尾部同步执行，再销毁事件对象。
// 不要把这条大厅路径写成后台异步队列，也不要用游戏动画队列逻辑替代它。
// wire140 在已审计的新版分发器中被默认忽略，不应当成必要的刷新命令。
// self-id 数组索引等风险是静态候选；缺少现场堆栈不能定为某次崩溃根因。
//
// 棋盘初始化
// ----------------------------------------------------------------------------
// S2C 0x4000 的处理函数为 0x65B450。
// p+17 为参与槽循环计数，p+18 为本机选择槽，不能交换含义。
// 非哨兵参与者引用预先存在的对象表，位置必须对应已加载地图。
// 初始化末尾调用 C2S 0x0001 发送入口，但实际发包仍受共用发送门槛限制。
// S2C 0x4004 在 0x65BEF0 写入计数和各槽位数值；无效槽洞不能随意压缩。
//
// 普通移动与特殊动画
// ----------------------------------------------------------------------------
// S2C 0x4011 在 0x65D770 建立路线，后续本地事件启动逐格移动。
// 普通移动推进函数 0x7F5D90 到终点后可发 C2S 0x0011，正文长度 6。
// 其中 +2 是 calendar counter 低 16 位，+4 是当前位置 u16。
// 这个计数域与 S2C +2 校验的 GmsvID 是不同概念，不能混用。
// C2S 0x0015 是特定动画类型 6、10、12 的条件完成回报，长度 4。
// 普通走格不能统一等待 0x0015；本地队列 wait 标志也不是网络 ACK 契约。
//
// 服务端观察到 C2S 后，应按当前房间等待状态识别下一步。
// 一个客户端发送点的静态证据，不足以推导原官方服务端的完整响应顺序。
// 本项目的等待、超时和回合推进规则还需与当前服务端源码交叉核对。
//
// 自有地产：本项目已实现的分支
// ----------------------------------------------------------------------------
// 玩家踩到自有空地：发送落点确认后，等待建筑选择，再处理确认、取消或超时。
// 玩家踩到可升级自有建筑：等待升级选择，决定完成前不推进下一行动者。
// BOSS 踩到自己的空地或建筑：自动建造或升级；达到适用上限则继续回合。
// 上限同时受场景和参与者技能约束，不能把某个 BOSS 上限用于所有玩家。
//
// 建造发送点 0x7BC3D0：C2S 0x0037，长度 6。
// 建造响应处理 0x661F50：S2C 0x403D，已证消费前缀 5 字节，阶段 6。
// 升级发送点 0x7BC480：C2S 0x0038，长度 6。
// 升级响应处理 0x662280：S2C 0x403E，已证消费前缀 5 字节，阶段 7。
// 两个响应进入不同阶段，不可仅改操作码而共享错误的界面结束逻辑。
// 重复或迟到选择不能二次改变建筑；已退休的选择应与当前事件区分。
//
