// 明文 INI
// ----------------------------------------------------------------------------
// Config/App.ini：[SETUP] Windowed、Sound、Music、Save、Help、SndVol、MusVol 以及提示/频道字段。
// Config/Chat.ini：[SETUP] max=160、page=8；ChatTip.ini 为聊天提示文本。
// Config/Font.ini 使用 Big5 可读，NAME 节登记 GB2312=宋體、BIG5=細明體、EN=Courier New。
// Config/Serverlist.ini 使用 Big5 可读，每个 [LOBBY] 记录 serverid、channelid、name。
// Config/Web.ini 保存 INTRO.url；Config/Private.ini 含本地私有显示字段，发布时不得带入个人数据。
// 修改 INI 时保留 CRLF、节名、键名大小写和原编码；未知键不要假设会被客户端忽略。
// 0x7B74C0 确认 App.ini 的 Sound/Music 与字符串 true 精确比较，音量按 atoi 读取。
// 公共节/键解析器 0x819470、0x819660 使用 strcmp，不能擅自改变键大小写。
// 数值读取处没有证实统一范围夹取；工具应单独定义已核实的字段范围，未知范围不自动改写。
//
// KPD 配置
// ----------------------------------------------------------------------------
// ChatTip.kpd、Private.kpd、Serverlist.kpd、User.kpd 属于压缩/混淆资源，不能按 INI 直接编辑。
// 本项目服务端通用 KPD 解码器：首字节为减法偏移，后续逐字节减去；解码头含小端解码长度和压缩长度，随后 LZO。
// 解码前后检查长度、LZO 返回值和实际字节数；当前实现文本预算4MiB、总预算上限64MiB。
// 这是服务端工具的实现事实；每种客户端 KPD 均需逐份确认容器一致，不能据此推断内部表结构。
// 修改 KPD 应使用可复现的解码—编辑—编码工具，并保存原始/解码/重编码三份哈希。
// 0x8198E0 读取值时以 LF 结束，高位字节成对复制，反引号加 n 才是该解析器的换行转义。
// 它复制后才检查缓冲区容量，不能依赖客户端阻止超长内容。
// 工具必须校验编码字节长度、末尾换行、双字节完整性；不要合并重复节或改变原顺序。
//
// 安全与回滚

// 先复制 Config/，修改一个文件后启动并完成登录、大厅、房间、棋盘最小流程。
// Serverlist 改动需确认服务端监听和登录入口同时可用；Font 改动需覆盖中文、英文和 Big5 文本。
// 认证、密码、Private.ini 私有字段和账号数据库不得提交到公开仓库或日志。
