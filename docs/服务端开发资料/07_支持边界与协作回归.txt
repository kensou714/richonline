// 已有具体实现入口
// 地产购买、自有地建造和升级：gameplay/property.cpp、gameplay/construction.cpp。
// 商店买卖、退出与超时：gameplay/shop.cpp；卡片库存：gameplay/cards.cpp。
// 普通骰子、卡片遥控骰、付费骰与恢复响应：gameplay/boss_turns.cpp。
// 路口选择：gameplay/junction.cpp；玩家建筑上限由开局技能快照约束。
// 单局资金：gameplay/ledger.cpp；银行等待：gameplay/bank.cpp。
// 机会落点与有限状态效果：gameplay/chance_landing.cpp、actor_status.cpp。
// 这些入口有状态和资源前提，不等于所有变种都支持。
// runtime 已向会话注入账户扣费接口；付费骰成功扣款后提交预先计算的移动。
// 没有 payment 或余额不足时返回恢复响应；重复事务/待恢复状态会拒绝继续。
// 依据：richonline_boss_runtime.cpp:load_richonline_boss_runtime；boss_turns.cpp:action。
// runtime 日志仍含 paid_rolls_supported=false，不能用该历史字段否定上述源码路径。
